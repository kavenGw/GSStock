## 分红/价值股（横切 · consumer/materials/energy/industrial/financial 默认跑识别）

### 【识别信号】
- sector 为 `consumer` / `materials` / `energy` / `industrial` / `financial` 的传统行业标的。
- 强信号：稳定现金流、成熟业务、低增长但高分红；管理层/财报提及分红政策/回购。
- **成长股/亏损股不命中**：持续亏损或高增长再投资的标的跳过本节，分红率填 `null`。

### 【必查清单（采证 face）】
- **历史分红率（股息率）**：最近 3 年每股股息 / 年末股价（或分红总额 / 市值），取算术平均或最新值。
- **分红政策**：公司章程 / 公告的分红承诺（如"不低于 X% 可分配利润"）、分红频率（年度/中期/季度）。
- **派息能力**：自由现金流 / 净利润覆盖率、资产负债率、账面现金是否支撑持续分红。
- **分红稳定性**：是否连续 N 年分红、分红增长率、是否有削减/暂停分红历史。
- **回购**：近期回购计划 / 已执行回购金额（与分红合计为股东回报）。

### 【撰写落点（撰写 face）】
- §3 盈利能力：补充分红率 / 派息覆盖率 / 股东回报率（分红 + 回购）。
- §11 风险/监控：分红削减风险作为监控指标。
- **valuations.yaml 同步**：`dividend_yield` 字段必填（取最新年度股息率），见 `finalize.md`。

### 【双面必答】
- 高分红是否**可持续**（自由现金流覆盖 vs 借债分红 / 一次性特别股息）？
- 分红是否"补偿增长缺失"——高分红 + 低增长股的总回报是否跑赢再投资型成长股？
- 股息率高是否因为股价暴跌（价值陷阱信号）？

### 【监控指标模板】
- 分红率较前三年均值下降超 X ppt；公司公告削减/暂停分红。
- 自由现金流连续 N 季无法覆盖分红；资产负债率超 X%（派息能力恶化）。
- 股息率异常走高（股价暴跌 vs 分红增加，需区分）。
