# lenses（板块视角 · 按精确粒度拆分）

> 每份 lens 一个文件，由 `sr-a3-lens` / `sr-writer` / `sr-reviewer` **自读**，控制者不再摘原文内联。
> A3 按自身定义内的映射表判命中；写手与审查员由控制者直接给命中文件名（三方必须是同一批）。
> 拆分前身是单文件 `sector-lenses.md`（261 行）——当时因为「自读会挑错节」而要求控制者代读；
> 拆成精确粒度后该前提消失。

## 选取规则

- **`x-` 前缀 = 横切 lens，默认对每只股都跑识别**（`x-ai` / `x-growth` 恒跑；
  `x-dividend-value` 在 consumer / materials / energy / industrial / financial 默认跑）。
- 其余为板块专属，按 subsector 匹配 1–2 份。
- **可叠加多选**：一只股可同时命中多套（如 `pcb-ccl` + `x-ai` + `x-growth`）。
- 无板块专属命中时只跑横切，并在产出里明写「无板块专属 lens 命中」。

## 每份 lens 的五段式

1. **【识别信号】** — 命中本 lens 的 subsector / 关键词 / 业务特征
2. **【必查清单（采证 face）】** — Phase A 必须联网核实的问题
3. **【撰写落点（撰写 face）】** — 发现落到正文哪些节
4. **【双面必答】** — 本 lens 最强反驳点，正文必须正面写
5. **【监控指标模板】** — 带阈值、可执行的卖出/复盘触发器候选

## 铁律

本目录只写「必查调查清单 / 问题」，**绝不写死会过时的事实**（具体时间表、报价、
退出范围等一律由 Phase A 实时联网采证）。**看到 lens 文件里出现具体数字 / 日期即是 bug。**

新增 lens：加一份文件 + 在 `sr-a3-lens` 定义的映射表里加一行；横切 lens 用 `x-` 前缀。
