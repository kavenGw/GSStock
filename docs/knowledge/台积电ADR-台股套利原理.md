# 台积电 美股 ADR ↔ 台股 套利原理

> 机制/知识档,讲清楚 TSM(NYSE ADR) 与 2330.TW(台股本尊) 的价差套利如何成立、为什么长期存在结构性溢价、散户能用到哪一层。非个股 thesis,不含买卖评级。

## 一句话结论

这是**跨市场同一资产的价差套利(ADR 溢价/折价套利)**,理论上无风险,但真正吃到价差的门槛很高——能吃的是有存托银行转换通道的机构,散户基本吃不到,只能把溢价当情绪/资金温度计用。

## 一、同一家公司,两个市场两个价

| | 台股本尊 | 美股 ADR |
|---|---|---|
| 代码 | 2330.TW(台湾证交所) | TSM(纽交所 NYSE) |
| 计价货币 | 新台币 TWD | 美元 USD |
| 交易时段 | 台北时间白天 | 美东时间白天(两地基本不重叠) |
| 存托比例 | — | **1 ADR = 5 股 2330 普通股** |
| 存托银行 | — | Citibank N.A.(花旗,负责发行/注销 ADR) |

## 二、平价公式(理论锚)

ADR 和本尊是同一份现金流,价格应满足:

```
TSM(USD)  ≈  5 × 2330价(TWD) ÷ 汇率(TWD/USD)
```

举例:2330 = 1000 TWD,汇率 = 32,则理论 TSM = 5×1000/32 ≈ **156.25 美元**。
若 TSM 实际报 180 美元 → **ADR 溢价约 15%**。

## 三、套利机制:靠"发行/注销"通道抹平价差

价差最终靠存托银行的双向转换来收敛,这是整个原理的核心:

**ADR 溢价时(美股比台股贵,最常见):**
1. 在台湾买入 2330 普通股
2. 把普通股交给存托银行(Citibank)托管 → 银行**发行 (issuance)** 对应 ADR(每 5 股换 1 ADR)
3. 在美国卖出 ADR,赚取溢价

**ADR 折价时(反向):**
1. 美国买入 TSM ADR
2. 向存托银行申请**注销 (cancellation)**,换回 5 倍的普通股
3. 在台湾卖出普通股

这个"发行↔注销"通道存在,理论上会把价差压回平价——**这才是套利成立的根本,而不是单纯两边对敲**。

## 四、为什么台积电 ADR 长期存在结构性溢价(价差不被抹平)

这是 TSM 最特殊的地方——溢价长期存在(历史上常见 10~20%+),因为发行通道被限制住了:

1. **台湾对 ADR 发行有额度/比例管制**:当 ADR 程序"额度用满"时,存托银行**无法再新发 ADR**,上面第 2 步走不通 → 溢价无法通过套利消除,只能长期存在。
2. **外资持股限制 + 资金管制**:美国投资者透过 ADR 买 TSM 比直接进台股市场省事,需求端天然更强。
3. **指数/基金被动买盘**:大量美国 ETF/基金只能持 ADR。

所以 TSM 溢价更多是**制度套利被堵住的结果**,不是市场没发现——这点要和"两地价差 = 免费午餐"区分开。

## 五、真正的摩擦与风险(为什么散户吃不到)

- **汇率风险**:一腿 TWD、一腿 USD,从建仓到转换交割有时滞,TWD/USD 波动能吃掉全部价差 → 机构要用 NDF/远期对冲。
- **时区不重叠**:台北收盘美东才开盘,无法真正同一时点两腿锁死,隔夜裸露风险。
- **转换 T+N 时滞**:发行/注销要几个工作日,期间价差可能已变。
- **交易成本**:台湾证交税 0.3%、存托费、托管费、两地佣金叠加。
- **额度墙**:溢价套利那一腿在额度用满时根本做不了。

## 六、给散户的实操含义

1. **别指望做套利本身**——转换通道和对冲能力散户没有。
2. **有价值的是"看溢价当情绪/资金温度计"**:ADR 溢价大幅走阔,往往反映美股这边对台积电(AI 算力主线)的追捧超过台股本地;溢价收敛可能是外资降温信号。
3. **同一标的选哪个买**:若你在美股账户,直接买 TSM 即可,但要意识到你买在结构性溢价上;能进台股的资金,2330 本尊更"便宜",但要承担 TWD 敞口和台湾证交税。
4. **两地财报/估值要换算成同一口径**再比,别被 ADR 名义价差误导。
