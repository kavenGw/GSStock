# 业绩页与研究流程数据合同

## 用途

`/performance/` 独立展示已研究公司的单季度营收、扣非归母净利润、季末存货及各自环比。
默认统一到最新报告季度，可切历史季度、按公司名称/代码搜索、按六个数值列排序。
金额为亿元人民币，金额和百分比均显示两位小数；存货增长不标为经营利好。
原 `/earnings/` 继续使用原财报估值快照。

## 数据流

```mermaid
flowchart LR
    A[正式财报与同口径基数] --> B[A1 底稿 performance 数据块]
    B --> C[sync_performance.py 合并并校验]
    C --> D[本公司 performance.yaml]
    D --> E[独立审查与收尾校验]
    E --> F[业绩页按请求读取]
```

每家公司的 `performance.yaml` 与 `index.md` 同目录，按公司代码及自然年季度识别记录。
分公司文件避免不同标的研究同时改写同一个总表；不新增数据库表或迁移，不依赖调度器。
写入使用同目录临时文件加原子替换，更新同季度时保留其他历史季度。
同一公司仍应串行研究，脚本不提供跨进程的同公司合并锁。

字段与采证合同见 [stock-research 业绩合同](../../../.agents/skills/stock-research/references/performance.md)。
页面不解析研究正文表格；本股文件经校验落盘后，下次访问即可显示。财报数据不依赖行情，
市值由页面异步请求 `/performance/market-caps` 取得，不写入 `performance.yaml`。

## 市值与年化扣非 PE

- 年化扣非 PE = 当前市值 ÷（所选季度扣非 × 4），不是 TTM；历史季度同样用当前市值。
- 市值统一为亿元人民币。A 股取腾讯 `[45]`；H 股口径取现价 `[3]` × 总股本 `[69]`，
  再按腾讯 `whHKDCNY` 折算。A+H 公司跟随研究档的跟踪主体，汇率取不到时该公司显示“—”。
- 缓存沿用交易时段 30 分钟、收盘后 8 小时；过期条目保留 7 天，只在行情整批失败时降级展示。
- 亏损显示“亏损”，零或缺失显示“—”，这些情况排序恒沉底；PE 列首次点击升序。
- 右上角显示所有市值中最旧的行情时间；行情失败不影响财报列，也不触发 503。

## 计算与异常

- 营收与扣非都是单季度；累计差分必须有同口径原数和来源。库存是季末账面净额。
- 环比使用紧邻上一季度：Q1 对上年 Q4；缺 Q2 不可拿 Q1 计算 Q3 环比。
- 比较基数与当期数来自同一公司，基数修正后页面自动重新计算。
- 缺失值保留 `null` 和原因；真实零值保留零。缺失值排序始终在末尾。
- 扣非亏损、扭亏、转亏及零基数显示文字，不展示易误读的百分比。
- 校验失败时返回 HTTP 503 并显示数据错误，避免将损坏文件当作正常空数据。

公司名链接到本地 Markdown 研究阅读页，支持表格及七文件内相对链接。
阅读路径限定在 `docs/stock-analytics/sectors/` 的现存 Markdown 内，越界或缺失返回 404。
来源展开显示报告链接、科目/页码、原数及差分说明；外部报告在新标签打开。

## 初次回填

首批为长鑫、沪电、普冉、胜宏、澜起、兆易、联讯、通富、江丰、兴森、天孚，共11家公司。
回填2026Q3及可取得的Q1/Q2，合计32条季度记录。11家Q3的三项原数和环比基数全部齐全。
优先复用已核实研究与A1底稿；长鑫比较基数补自招股书经审阅历史数据，兴森补自一季报原件，
江丰存货补自更正后半年报。部分旧期只保留研究证据的显示精度，已在来源说明，不伪补精度。
Q1缺少上年Q4及个别旧期缺存货时，相关环比显示“—”。
