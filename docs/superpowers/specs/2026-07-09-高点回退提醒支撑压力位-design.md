# 高点回退提醒 — 增加支撑位 / 压力位

> 设计日期：2026-07-09
> 状态：待实现

## 背景

每日简报的「高点回退提醒」（推送到 `news_daily`）当前每只股一行紧凑格式：

```
📉 *高点回退提醒*（90日高点）

  · 兆易创新（A） 现价100.5 / 高点120.0 → *-16.25%*
```

股票从高点回落时，用户想同时看到**下方最近支撑**（可能止跌处）和**上方最近压力**（反弹天花板），辅助判断。

## 目标

在每只回退股末尾追加下方最近支撑与上方最近压力，各带距现价百分比，**保持单行紧凑格式**。

目标格式：

```
  · 兆易创新（A） 现价100.5 / 高点120.0 → *-16.25%* | 下方支撑98.20(-2.29%) | 上方压力105.00(+4.48%)
```

## 涉及文件

- `app/services/value_dip.py` — `_calc_stock_changes` 计算 S/R；`get_pullback_ranking` 透传字段
- `app/strategies/daily_briefing/__init__.py` — `_format_pullback_message` 渲染
- `app/utils/support_resistance.py` — 复用现成 `calculate_support_resistance`，**不改**
- `tests/test_*.py` — 新增单测

## 数据来源（零额外 API）

`get_watch_performance` 已拉取 90 日完整 OHLC，`_calc_stock_changes(code, name, data)` 的 `data` 每项含 `high/low/close`。直接喂给现成工具：

```python
from app.utils.support_resistance import calculate_support_resistance
sr = calculate_support_resistance(highs, lows, closes)
# sr = {'support': [价格...最多3], 'resistance': [价格...最多3]}
```

无需任何新增网络请求。

## 取值逻辑

工具返回的 support/resistance 列表按**强度**排序，但需求是**离现价最近的 1 个**：

- 下方最近支撑 = `support` 列表中**最大值**（离现价最近、仍在下方）
- 上方最近压力 = `resistance` 列表中**最小值**（离现价最近、仍在上方）

距现价百分比 = `(位价 - 现价) / 现价 * 100`，保留 2 位小数：
- 支撑在下方 → 负值（如 `-2.29%`）
- 压力在上方 → 正值（如 `+4.48%`）

位价保留 2 位小数。

## 数据流

```
_calc_stock_changes(code, name, data)
  ├─ 提取 highs/lows/closes
  ├─ calculate_support_resistance(...)
  ├─ 取 nearest support (max) / nearest resistance (min)
  └─ info['support'] = 价 或 None
     info['resistance'] = 价 或 None
        ↓
get_pullback_ranking  →  透传 support / resistance 进结果 dict
        ↓
_format_pullback_message  →  渲染 | 下方支撑X(-a%) | 上方压力Y(+b%)
```

`support`/`resistance` 字段加进 `_calc_stock_changes` 的 info dict 是纯本地计算、无副作用；`get_watch_performance` 的其他消费者忽略多出的字段即可，不受影响。

## 边界处理

- **数据不足 20 日**：`calculate_support_resistance` 返回空列表 → `support`/`resistance` 为 `None` → 渲染时不追加 ` | …` 后缀，回退到现有格式
- **仅单侧命中**（如现价高于所有位价，无上方压力）：只渲染存在的一侧，缺失侧整段省略
- **两侧皆无**：整行同现有格式，不追加任何后缀

## 渲染细节

`_format_pullback_message` 每行在原有 `→ *{pullback}%*` 后：

```python
suffix = ''
if s.get('support') is not None:
    sp = s['support']
    pct = round((sp - s['price']) / s['price'] * 100, 2)
    suffix += f" | 下方支撑{sp:.2f}({pct:+.2f}%)"
if s.get('resistance') is not None:
    rp = s['resistance']
    pct = round((rp - s['price']) / s['price'] * 100, 2)
    suffix += f" | 上方压力{rp:.2f}({pct:+.2f}%)"
```

`| ` 分隔符遵循 `notifications.md` 紧凑列表规范；百分比用 `{:+.2f}%` 含正负号。

## 测试

新增 `tests/test_pullback_support_resistance.py`（平铺目录）：

1. `_calc_stock_changes` 在含 ≥20 日 OHLC 时返回 `support`/`resistance` 非 None，且 support < price < resistance
2. `_calc_stock_changes` 在 < 20 日数据时 `support`/`resistance` 为 None
3. `_format_pullback_message` 含 S/R 时渲染 `下方支撑X(-a%)` / `上方压力Y(+b%)`，百分比符号正确
4. `_format_pullback_message` 缺 S/R（None）时回退现有格式，无 ` | ` 后缀
5. 仅单侧命中时只渲染该侧
