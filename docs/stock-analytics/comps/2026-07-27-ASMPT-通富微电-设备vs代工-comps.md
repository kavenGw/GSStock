## §0 结论摘要

**同一条 AI 先进封装链的两端，生意质量不是一个物种；而过去五周，两者的相对吸引力发生了明显分化。**

- **ASMPT**：维持 watch，但**贵得程度大幅收窄**——安全边际从建档时（6/20）的 **−27.9%** 收窄至 **−4.5%**，基本贴到期望内在价值线（HK$63.2B / 每股 151）。**中报 7/29 上午公布**，在此之前不做任何动作。
- **通富微电**：**减仓纪律仍在触发中**。PB 7.26x 同时击穿两份独立档案的减仓线（AMD 档 5.5x / comps 档 6.5x），距加仓买点（~36 元）还有 **−52%**。
- **若只能持一个：ASMPT。** 生意模式、资产负债表、利润质量、估值收敛度四项全面占优。**但两者当下都不是 buy。**

**本档最该记住的一条**：ASMPT 与通富当前的资本回报都不及格（ROIC 4.85% / 扣非 ROE 5.57%），但**成因完全不同**——ASMPT 是周期性的（2021 峰值年 ROE 约 18.6%），通富是结构性的（**2021 峰值年 ROE 也只有 9.51%**）。同样一句"当前回报不高"，一个是"等周期回来"，一个是"回来了也就这样"。

## §2 生意质量：定价权归谁

| 维度 | ASMPT | 通富微电 |
|---|---|---|
| 商业模式 | 后道封装**设备**（die/wire bonder + TCB + SMT） | 封测**代工**（IC 封测占营收 97.6%） |
| 毛利率 | **38.06%**（SEMI 分部 46.4%） | ~15%（推算，销售净利率 4.93%） |
| 净利率 | 7.29% | 4.93%（2025）/ 4.68%（26Q1） |
| **定价权** | 自主定价，TCB 认证壁垒 | **17.5% gross markup 协议锁死，净利率上限 8–9%** |
| 客户集中度 | 分散（全球 OSAT + IDM） | **AMD 占 60%+**（TFAMD 苏州 + 槟城） |
| 护城河类型 | 安装基数（>500 台 TCB，全球第一）+ 客户认证 + 整线方案 | 规模 + 客户绑定 |
| Franchise 判定 | 部分满足 | **明确 commodity** |

按 buffett 1991 年致股东信的 franchise 三条标准（被需要 / 客户认为无近似替代 / **不受价格管制**）：

- **ASMPT** 在 TCB 环节大致过关——AI HBM 堆叠必需、当代无成熟近似替代、价格自主。
- **通富** 第三条直接不成立。**它的价格不是市场定的，是合同定的。** 17.5% markup 在会计上是"成本加成"，在经济实质上等价于价格管制——只不过管制者不是政府，是客户。

AMD 自身毛利率 55% 且在扩张，没有任何动机上调这个 markup。**这条链上，利润的分配是极度不对称的：AMD 越好，通富越拿不到那部分高毛利。**

**客户绑定的双面性（必须写清）**：绑定 AMD 让通富拿到了 A 股 OSAT 里最优质的订单结构（26Q2 扣非净利率 6.07%–7.22%，创公司历史最佳），这是真实的护城河成分；但绑定同时意味着定价权外部化。**"最好的客户"和"最强的议价对手"在这里是同一个人。**

## §3 穿越周期的盈利能力上限——本档核心

| | ASMPT | 通富微电 |
|---|---|---|
| **ROIC（当前）** | **4.85%** | ROA 5.21%（2025） |
| ROE（TTM / 最新年） | ~6.2%（推算：TTM 净利 1.07B / 权益 ~17.1B） | **8.08%**（扣非仅 **5.57%**） |
| ROE（26Q1 单季） | — | 2.10%（扣非 1.10%） |
| **ROE（周期峰值年 2021）** | **~18.6%**（净利 HK$3.18B，推算） | **9.51%** |
| 净利谷底/峰值 | 2024 谷 HK$342M vs 2021 峰 3.18B（**−89%**） | 2023 谷 1.69 亿 vs 2021 峰 9.57 亿 |

**两家当前的资本回报都远低于 buffett 的 15% 门槛——但这是本档唯一需要拆开看的相似点：**

- **ASMPT 的低 ROIC 是周期性的**。它 2024 年在周期谷底（净利较峰值 −89%），FY2025 净利虽 +163.6% 但绝对值仍只有 2021 峰值的 28%。周期顶时它能做到接近 19% 的净资产回报。
- **通富的低 ROE 是结构性的**。它**在有史以来最好的年份（2021）ROE 也只有 9.51%**。markup 天花板 + 重资产（总资产周转率 0.64）决定了它的盈利上限，不是周期决定的。

> 这是两家最本质的差别，比任何估值倍数都重要。买 ASMPT 是在买"周期回来 + 结构台阶"；买通富是在买"周期回来"，而它的周期顶只有对方的一半。

**ASMPT 的低 ROIC 也不能一笔带过**：4.85% 这个数字补上了 ASMPT buffett 档标【缺】的关键项，**它验证了该档的保守取向是对的**——该档 bear 14x / base 26x 的倍数已偏保守反映"盈利质量未达优质门槛"，不需要在期望值上再打一道无锚折让。若中报后 ROIC 未见抬升趋势，按该档 §11 风险 4，base 倍数应下调。

## §6 风险不对称

**ASMPT Top 3**
1. **hybrid bonding 代际颠覆（最大长线）**——TCB 当代领先可能被下一代掀桌，BESI + Applied Materials 联盟（2025 AMAT 入股 BESI ~9%）卡位更受关注。"一个需要不断重建的护城河，最终不是护城河。"
2. **周期均值回归**——b/b 1.43 是四年新高，历史上设备股 b/b 冲高后常见均值回归；净利波幅 −89% 的前科在。
3. **FCF 转负（本档新增）**——复苏在吃现金，ROIC 4.85% 尚未证明这轮扩张能创造超额回报。

**通富 Top 3**
1. **markup 天花板 + 单一客户**——净利率上限被合同锁死 8–9%，60%+ 营收系于 AMD 一家。**这不是周期问题，是结构问题。**
2. **持股重估是双向放大器**——H2 若半导体板块回调，同一科目反向运转；持仓标的与规模**至今未披露**，反向敞口无法量化（本档最大残余风险）。
3. **定增稀释 34%–44%**——12 个月发行倒计时中；当前市值 1,182 亿是披露时（~600 亿）的两倍，管理层有"高位发行"动机，这与当前的乐观叙事之间存在需要留意的张力。

## §8 操作含义

1. **两者当下都不是 buy。** ASMPT 是"接近但仍需等 7/29 中报 + 更深回撤"（买点 HK$97）；通富是"纪律要求减仓"（PB 7.26x vs 5.5x/6.5x 两条线）。
2. **ASMPT 的 watch 状态质量在提升**，不需要下调也不需要上调——安全边际 −4.5% 意味着它从"贵得离谱"回到"公道价附近"，但公道价不是安全边际。**押 bull 的安全边际已从 +9.6% 扩到 +45%**，这是五周内唯一实质性的好消息。
3. **通富不因主业创历史最佳而松动减仓线。** 立场是"好公司 + 已跑到 PB 7.26x 的价格 = 不是好投资"，不是"通富是坏公司"。若股价回到 36–41 元区间，这份基本面**值得优先重新认真对待**。
4. **不改任何 quality 星级。** 本档未改变任一方的护城河或可持续利润中枢，改变的是估值位置与已披露的财务事实（ROIC / 净现金 / FCF）。通富目前无 valuations 条目（无独立 buffett 档）。
5. **若要为通富建独立 buffett 档**：7/14 theme 档已提出"若择一建档，先建长电"（长电利润质量、杠杆、客户分散度、稀释风险四项更优且 PB 更低）。本档不推翻该排序，但补一个不同维度的判断——**若目的是配置 AI 先进封装敞口，设备端（ASMPT）比代工端（长电/通富任一家）的生意质量高一个量级，优先级应高于 OSAT 内部选谁。**
