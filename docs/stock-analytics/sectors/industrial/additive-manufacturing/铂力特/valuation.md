# 铂力特 — §9 估值（场景加权）

> 结论与评级见 [index.md](index.md)；业务与护城河见 [business.md](business.md)；论点与周期见 [thesis.md](thesis.md)。

## 9.0 为什么主锚不用 PE

四重失真同时存在，PE 在本标的上不具备锚定能力：

1. **利润基数过小且不稳定**：2026H1 扣非归母仅 1,617 万，TTM 扣非 1.2242 亿。分母越小，PE 对任何扰动越敏感。上市 7 年归母峰值仅 2.038 亿，路径为 亏损(2021) → 0.795 → 1.102 → 1.044 → 2.038，**没有一年可外推**。
2. **利润的 68.4% 是非经常损益**：政府补助 2,948 万 = 扣非归母的 1.82 倍。用归母 PE 等于给补助估值。
3. **一致预期已失效**：东财研报 API（`code=688333`，2026-01-01~09-03）**hits = 0**，三轮检索未见任何 2026-08-25 中报之后发布的预测；现存三组（2.88 / 3.05 / 3.05 亿）经反推均为一季报后口径（其中一组自标「2026 年 PE 91.59 倍」，按 EPS 1.11 反推股价约 101.7 元，属 4–5 月区间）。
4. **历史数字本身带可信度折扣**：2023 年经监管认定「控制权未转移即确认收入」并全面重述，2025-12-31 起立案未结。

**故主锚用 PS，辅以对 2028E 的场景化盈利推演，并在每一档显式披露隐含 PE。** 此处的 PS 不是「因为亏损所以用 PS」，而是**营收是三项财务口径中受非经常损益污染最小的一项**；但必须同时承认：2023 年重述正是发生在营收确认环节，故 PS 的分母同样带一个无法量化的可信度折扣（这是本档判 exclude 而非 watch 的算术表达）。

> **一致预期使用披露（规格要求，与引用同段）**：下文 bull/base 使用的 2028E 归母 5.29 亿及其打折值，来源为同花顺 F10 五家机构一致预期中值（采集 2026-09-03，页面无更新日期），**该预期发布于 2026 中报（8/25）之前**。其 2026E 口径（2.88 亿 / 最乐观 3.05 亿）隐含**下半年归母同比须 +86% ~ +99%**（2025H2 实际 1.275 亿），而 2026Q2 实际是**营收 +0.95%、归母 −62.35%、扣非 −85.7%**。历史准确度亦差：东吴证券 2025-09-01 给 2025E 归母 2.38 亿，实际 2.038 亿，高估 17%。**一致预期不作主锚，仅作 bull 的上界参照。**

**正常化利润口径说明（红线 3）**：三档的 2028E 归母（2.25 / 3.97 / 5.29 亿）分别为当前 TTM 归母（1.7863 亿）的 1.26x / 2.22x / 2.96x。**没有任何一档取财报顶部年化**——2026H1 归母年化为 1.02 亿、2025 全年 2.038 亿，三档均落在「未来三年爬坡后」的口径上，而非把某个好季度乘 4。bull 之所以不再上调，是因为一致预期本身已经是最乐观的公开口径且已被中报证伪一半。

**倍数是否破框架（规格 §3 自检）**：27x / 37x / 45x 均高于 buffett 框架对「周期/衰退型 <8x、窄护城河 8–12x」的口径。本档不假装这是框架内的倍数——它们是**A 股高增设备股的实际交易倍数上沿**，取用理由是本档主锚为 PS + 场景化盈利推演，PE 倍数在此只作「市场愿意付多少」的换算器。按框架回查：以 bull 的 2028E 归母 5.29 亿对当前归母净资产 52.43 亿，隐含 ROE 仅 **10.1%**；base 隐含 ROE **7.6%**；bear **4.3%**。**三档隐含 ROE 全部低于本标的应有的股权成本**（无股息意义、立案未结、有息负债 20 亿、扣非 ROE 0.32%，合理股权成本 ≥12%）→ **公允 PB 应在 1x 附近，即每股约 19.1 元**（52.43 亿 ÷ 2.74322 亿股）。这个资产法下界与 bear 的 22.15 元同量级，互相印证；本档保留利润法为主锚（bull > base > bear 成立，未出现倒挂），但把「PB 1x ≈ 19.1 元」作为估值下界明写入档。

## 9.2 概率赋权理由（每档一句，引 §6/§8 证据）

- **bear 40%**：赋权依据是**已发生的事实**——2026Q2 营收 +0.95%、扣非 −85.7%（[§6](thesis.md)）；毛利率 −3.14pct 且下滑来自高毛利设备与原材料两块（[§3](business.md)）；一致预期在中报后无一家更新；海外同赛道已完整演过一遍（3D Systems −94%、Desktop Metal 2025-07-28 Chapter 11、Markforged 从 1.16 亿被 4,250 万甩卖，[§8](thesis.md)）。
- **base 40%**：赋权依据是航空航天板块 2026H1 +43% 确为真实增量、认证壁垒（空客合格供应商、A320 O-Ring 工作包）真实存在、粉末-设备-服务全链自制在国内独一份（[§5](business.md)），支持「慢速但不崩塌」的中性路径。
- **bull 20%**：**概率封顶**。按 x-growth 证据包门控三要素逐项判定：**(a) 扩产达产确定性【软】**——募投主项目投入 41.61%、2027-06 才达可用状态、本年度效益仅 1,165 万；粉末产线 800→3,000 吨扩产按 2025 年原材料收入 1.13 亿线性外推增量仅约 3 亿，对 309 亿市值无意义。**(b) 客户 capex / 出货能见度【软/缺】**——合同负债仅 +10.1%、在手订单金额从未披露、具名客户（空客 A320 工作包、OPPO Find N6）均无金额期限。**(c) TAM 跑道【软偏负】**——Wohlers 全球 AM +10.9%、设备端仅 +3.6%。**三项全软 → bull 概率上限 20%**（规格 §3）。且 bull 的三个前提全部尚未发生，而 bear 的证据全部已发生，故 bear ≥ bull 成立。

**Σ概率 = 40% + 40% + 20% = 100%** ✔

## 9.3 期望内在价值与安全边际

```
期望内在价值 = 22.15 × 40% + 53.55 × 40% + 86.77 × 20%
             = 8.86 + 21.42 + 17.354
             = 47.63 元/股
市值口径      = 47.63 × 274,322,174 = 130.66 亿元
安全边际      = (130.66 − 308.94) / 308.94 = −57.7%
```

| 检验项 | 值 | 判读 |
|---|---|---|
| 期望内在价值隐含 PE-TTM（归母） | 130.66 / 1.7863 = **73.1x** | 即使按本档偏空的期望值，市场也仍在付 73 倍归母 PE |
| 期望内在价值隐含 PE-TTM（扣非） | 130.66 / 1.2242 = **106.7x** | 扣非口径下更贵 |
| 期望内在价值隐含 PS-TTM | 130.66 / 19.5475 = **6.7x** | vs 3D Systems 0.9x / Stratasys 1.3x —— **本档的期望值对海外同业仍是 5–7 倍溢价**，已给足中国增速与军工壁垒的溢价 |
| bull 每股 86.77 vs 现价 112.62 | **−23.0%** | 最乐观情景也在现价之下 |
| 资产法下界（PB 1x） | **19.1 元** | 与 bear 22.15 元同量级 |

**bull 单独压力测试（红线 4）**：把 bull 的倍数从 45x 提到该股在 2026 年 4–5 月曾被给出的 85x（某券商 2026E 口径，目标价 94.35 元——**注意该目标价本身仍低于现价 112.62 元**），bull 每股 = 5.29 × 85 / 2.74322 = **163.9 元**。即：**要让现价成立，需要 2028E 归母 5.29 亿全额兑现、并同时维持 60x 以上的 2028 年 PE**（112.62 × 2.74322 / 5.29 = **58.4x**）。这正是消化路径表要说的事。

## 9.4 估值消化路径（口径：中报前一致预期，**已失效**，仅示意所需斜率）

| 年份 | 归母（亿） | 来源 | 隐含 PE @308.94 亿 |
|---|---|---|---|
| 2025A | 2.038 | 年报【硬】 | 151.6x |
| TTM(2026H1) | 1.7863 | 自算【硬】 | **172.9x** |
| 2026E | 2.88 | 一致预期中值（中报前，**已失效**） | 107.3x |
| 2027E | 4.03 | 同上 | 76.6x |
| 2028E | 5.29 | 同上 | **58.4x** |
| 2029E | 6.87 | 本档外推（+30%） | 45.0x |
| 2030E | 8.94 | 本档外推（+30%） | 34.6x |

**读法**：即使 2026–2028 三年一致预期 **100% 兑现**，PE 也只从 173x 压到 58x；压到 45x 要等 2029 年、压到 35x 要等 2030 年，且前提是**五年复合增速约 34%、其中 2026 当年要从 H1 的 −33% 逆转为全年 +45%**。若 2026 实际归母只有 1.5 亿（H2 与去年持平的悲观情形），2026 实际 PE = **206x**，整张表右移两年。

**倒推验证**：要让 PE 落到 40x，需归母 **7.72 亿**；按公司历史最好净利率 11.0%（2025 年）反推，需营收 **70.2 亿 = 2025 年 18.52 亿的 3.8 倍**、= 2028E 一致预期 43.83 亿的 1.6 倍。按 2026H1 实际净利率 6.64% 反推则需营收 **117 亿**。**当前价格 price-in 的不是「高增长」，是「高增长 + 净利率翻倍 + 持续十年」。**

## 9.6 未进入估值的项（红线 5 / x-ai 铁律）

- **苹果折叠 iPhone**：半年报全文 214 页**无「苹果/Apple」字样**，源头为郭明錤推演经媒体转述，公司答复「保密协议不便披露」。**在情景加权中给零基准权重**，仅作为文字中提及的期权。
- **人形机器人**：仅「验证、试制、测试」+ 展会样件（2024 年报），从未披露任何相关收入；具名优必选来自自媒体；2026-01-04 由同花顺挂上概念标签。判【蹭概念】，按 x-ai lens 铁律**不进 owner earnings 基础**。
- **商业航天**：已助力蓝箭航天、东方空间、九州云箭、星际荣耀等完成发射任务（公司列名，硬），但**无金额披露**，不进估值。
