## 12.4 已知局限 —— 明确标注「未找到公开证据」的项（不编造）

2. **产能利用率**（设备与定制化产品）——定期报告未披露。
3. **PE / PB 历史分位数序列**——无可靠公开来源；且该指标对本股因多年微利/亏损而**本身失效**，不作估值论据。
4. **2025H1 分部与分下游收入同比**——半年报未披露上年同期分部数；本档中「航空航天 +43%、非航空航天 −7%」为**【推算值】**（按各期领域占比推算），非披露值。
5. **2026H1 设备销售台数**——半年报全文检索确认不含产销量表（该表仅年报口径披露），不推算。
6. **2026 年任何实控人/5% 以上股东的减持计划公告**——检索 2026 年全部 87 条公告标题，无此类（**反向证据**）。
7. **在手订单金额**——公司从未披露；仅合同负债（1.5848 亿，+10.1%）可作弱代理。
8. **设备市占率的第三方量化数据**——公司仅自述「较高市场份额」。
9. **分地区收入的更细拆分**（境内/境外之外的国别口径）。
10. **军机型号用量、单机 AM 价值量、是否独家/主力供应商**——军品保密属常态，任何此类说法目前仅为媒体叙事级。

## 12.5 三路冲突的处理

A2 §6 与 A3 §2.3 曾并列 2023 年「11.52 或 12.32 亿」两套数字、A2 给出 2024 年「≈14.13 亿」倒推值——**本档一律采用 A1 §2.2.5 核定的唯一权威口径**（2022–2025 营收 9.1808 / 11.5245 / 13.2557 / 18.5167 亿，归母 0.7950 / 1.1024 / 1.0444 / 2.0380 亿），并在 [valuation.md 变化清单](valuation.md) 逐条标注作废数字。A2 的「政府补助占归母 57.65%」与 A1 的 57.7% 同源（税前补助 2,948.28 万 ÷ 归母 5,113.90 万），本档取 A1 精算值；「非经常占归母 68.3% / 68.39% / 68.4%」同理取 A1。
