## 0 结论摘要

**Exclude（排除）** — 自 watch 下调一级。

旧档（2026-08-08）把全档最大不确定性明写为「中报未披露，Q2 毛利率/现金流/海外分部全空白，结论有在 1–2 周内被证真或证伪的风险」。**中报 2026-08-24 落地，答案是三条同向的不利。**

**① 报告的 2.08 亿归母净利 100% 由非整车收益支撑，主业可比是亏的。** 两项支撑**科目位置不同、互不重叠、可以分别剔除**：碳积分约 8.5 亿计入**营业收入**的「服务及其他销售」（近 100% 毛利），其他收入 + 其他收益净额 − 金融资产减值 10.61 亿（政府补助为主）计入**营业利润上方**，合计 **19.1 亿 = 报告净利的 9.2 倍**。
**主口径 = 仅剔碳积分**（一年一签、100% 毛利、协议期只到 2026-12-31 的关联方协议性收入，明确非经常）→ **可比归母 −6.42 亿、可比毛利率 9.65%**；**政府补助对中国车企具经常性，全剔会低估可持续盈利能力**，故**双剔后的 −17.03 亿只作最严格下界同时披露，不作主口径**。主口径交叉验证：9.65% 与管理层自述整车毛利率 10–11% 量级一致。→ 旧档「四家可比中唯一 TTM 盈利」须改写为**会计口径唯一盈利、可比口径仍亏损**；**PE 完全不可用**（[§3](business.md)）。

**② 经营现金流转正是供应链占款驱动，不是盈利驱动。** DPO 从 2025H1 的 202.8 天拉到 **253.1 天**，每天 DPO ≈ 1.86 亿 COGS；账期若维持去年同期，期末应付应为 377.2 亿而非实际 470.80 亿 → **超额占款 93.6 亿 = 全部 OCF（21.7 亿）的 4.3 倍**，**账期不拉长则 H1 OCF 为 −71.9 亿**。

**③ 公司自己下调指引，且不再重申销量目标。** 全年净利指引下调约 40%（媒体口径 50 亿→约 30 亿人民币，单一机构来源待公告确认），归因原材料涨价；业绩会**全程未重申 100 万辆目标**（最后一次公开重申 **2026-07-16**）——**同场下调了净利指引 40%、也明确给了海外 15 万辆目标，却独独没碰交付目标，「不提」比「重申」更该进风险段**。按 30 亿测算 H2 需赚 27.9 亿 = H1 的 13.4 倍，即便实为 20 亿仍需 8.6 倍，**任一档位结论不变**。反向发现同样重要：**50 亿原目标本身就是 FY2025 实际归母 5.384 亿的 9.3 倍，激进的是原目标。**

**主锚为何取 8/25 盘中**：中报与业绩会 8/24 收盘后消化，8/25 是首个完整定价窗口，当日**开 43.860（+2.57%）→ 最低 41.000（−4.12%）→ 09:32 报 42.520（−0.56%）**，振幅 6.98%。代价是它只是一个时点，故并列 8/24 收盘；可比公司表统一以 8/24 收盘为基准日。

**买点为何仍是期望值 ×0.65**：折价率补偿的是**估值本身的误差**，已知负面已进三情景、不重复惩罚；本档离散度 bull/bear = 3.92× 与旧档 3.86× 相当，故不变。旧档取 ×0.65 而非小鹏的 ×0.70，多出的 5pp 专对应「监管公开质疑盈利质量」——本轮该因素不但未消除且被量化坐实（贸易应收 82.9% 为关联方、应收周转 21.7→41.5 天）。改用 ×0.70 则买点 13.62 HKD，仍远低于 52 周低点，**结论不变**。

### 10.2 评级翻转：翻转的是什么、不是什么

**翻转的是**：① **盈利质量**——旧档把「四家可比中唯一 TTM 盈利」列为上修 exclude→watch 的第三条理由，剔碳积分口径证明它只是会计口径的，**那条上修理由本身被推翻**；② **赔率**——旧档上修的核心论据是「bull 上行 +35.4%，赔率已实质存在」，本轮仅 **+6.5%**，论据消失；③ **现金流叙事**——旧档把「H1 经营现金流转正」设为证伪自身的阈值之一，它数值上转正、驱动却是账期，**阈值被数值满足、被机制证伪**；④ **摊薄的性质**——旧档判「定增 ≈14.1% 摊薄已触发放弃跟踪线」，实为发行价 50.03 **人民币** = 58.18 HKD、摊薄 **9.48%**，现价较发行价**折让 27%**，属**溢价发行**，数学上增厚而非摊薄每股内在价值；本档撤销该判断，改判为**治理风险（实控人持股下降，正是证监会第 4 问）+ 认购方按原价履约的实质不确定性**。

**没有翻转的是**：① **生意质地**——无品牌、无切换成本、无网络效应、无有效规模，护城河仍判「弱」（[§5](business.md)）；② **无定价权**——本轮实证更硬：**公司在成本上行时选择下调利润指引而非提价**，是无法转嫁成本的公司自认；③ **智驾不给溢价的结论**（但理由必须换，见 [§7](thesis.md)）；④ **交付爆发是真的**——7 月 101,267 台、H1 欧洲注册 +526.7% 全欧增速第一，本档一个都不否认，只是它们无法自动转化为「高毛利可持续」。

**为何不维持 Watch**：安全边际量级不同、赔率论据消失、第三条上修理由被证伪；旧档「中报是唯一能证真/证伪的数据点，此时 exclude 会错过它」的时间性理由已随中报落地失效。

**本档最脆弱的一条（诚实前置）**：若 base 的**净利率与倍数同时**取有利端（2.5% + 市场口径 25×），期望值升至 36.28 HKD、安全边际 **−14.7%**，**大概率对应 watch 而非 exclude**——存在一个能推翻本档的参数组合。不采用它的理由是它让 **base（51.51）反超 bull（45.29）**、隐含 PS 0.625× 高于 bull 自己的 0.525×，逻辑上不成立；且 2.5% 净利率目前零证据（公司整车毛利率指引仅 10–11%，历史整车口径净利率从未转正）。**但它需要的证据不多——剔碳积分口径综合毛利率站上 12–13% 并保持两季即松动**（完整推演见 [§9.10](valuation.md)，证伪闸门见 §11.3）。**Exclude 不等于「会倒闭」**——销量新势力第一、表内总现金 258.42 亿、有息负债仅 40.06 亿，行业尾部出清对它净受益；Exclude 表达的是「按当前价格不值得占用跟踪与资金」。

### 10.3 「跌了 ≠ 便宜」与「量的胜利 ≠ 价值」

期望内在价值从 490.98 亿降到 276.69 亿 HKD（**−43.6%**），而**市值同期反而涨了 8.8%**（39.08 → 42.520 HKD）——**分子在跌、分母在涨，安全边际的恶化是双向的，不是「跌出来的便宜」**。交付 +60.8%、7 月 +102%、欧洲 +526.7% 本档全部采信，但同一份中报里 ASP 同比 −2.2%、综合毛利率同比 −2.47pct、剔碳积分后可比归母 −6.42 亿（双剔下界 −17.03 亿）——**销量的漂亮与利润的难看是同一件事的两面**。方法变更的诚实交代与双向展开见 [§9.10](valuation.md)。
