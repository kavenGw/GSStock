**Watch（观察）** — 维持。**卖车这一侧好于旧档，钱这一侧只是表观缓解。**

### 10.2 评级：**Watch（维持，不翻转）**

**不上调 Config**：① 期望值口径安全边际 −12.0% / −10.8% 仍为负；② bull 上行跨线有约 10pp 来自汇率订正；③ 成长证据包无一项为硬，bull 封顶 20% 不解除；④ 四条触发器命中（§11.2）；⑤ 净现金改善的质量未改善；⑥ PS 0.80× 是同业最高且仍亏损（[§4.1](business.md)）。

**不下调 Exclude**：① 旧档两条 bear 支柱被证伪，C1 / C6 / C9 三条链中断；② 正式季度指引连续两季兑现；③ Q3 是有质量的增长（价驱动、整车毛利改善）；④ bull 上行 +50% 说明赔率在真实改善，且距买点只差 38%——这是一只**值得盯着等价格**的股票，不是该扔掉的。

**旧档行动规则 vs 封顶（显式分歧）**：行动规则「整车毛利率 ≥13% 且 Q3 指引同比转正 → bear 35→25、bull 20→25」**字面成立**（13.06%、+2.05%）——**行动规则要求 bull → 25 / 本档裁定维持 20**，理由：bull 封顶的解除条件（Q3 落入指引**且**大众量化多年期 guidance **或**第二具名技术客户）只满足前半，封顶是更具体的条款，优先。bear 由证据定为 33 → 27（较规则目标少降 2pp，承载 C8 / R3 / R5 / R4 命中）。规则口径 25 / 50 / 25 的期望值 35.38 HKD、安全边际 −8.0%，见 [§9.7](valuation.md)。

**管理层**：55–60 万诚信条款**未触发**（Q2 / Q3 两场电话会均无全年总量目标），不扣分；新增「乐观口头目标三次静默降级」中性偏负观察项（55–60 万 → Q4 月均 6 万 → 巴黎新客户），口头指引一律打折引用（[§6e](thesis.md)）。

### 10.3 「触发器命中 ≠ 必然变坏」的对偶交代

旧档写「触发器全绿 ≠ 变好」；这一季反过来：**四条触发器命中，但利润表是两年来最好的一季**。两者都要诚实：
- 存货 168.60 亿触发 C8——但存货 / 季营收 0.694 环比持平，与 Q4 +43~47% 环比交付量级匹配；**它不是「卖不动」的证据，是「押注 Q4」的证据**。押注的结果 2027-03 才知道。
- 月度交付 7–9 月 3/3 低于 +10%——同期大盘 −4%~−17%，小鹏跑赢 7.5–15.9pp；但新势力里零跑、极氪 +50% 以上。
- 净现金 +40.61 亿中止了 C9 计数——但 Q3 天然有季节性正偏（上年 Q3 应付 +44 亿），**Q4 / Q1 才是检验期**。

**一句话：短期最坏路径（失血、稀释）被 Q3 推后了，没有被消除；它们都把检验点押在了同一个季度——Q4。**
