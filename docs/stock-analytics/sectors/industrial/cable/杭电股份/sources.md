## §12.4 已知局限（逐条明写，不掩饰）

### （a）三项不可消除的信息缺口 —— 本档最大的不确定性

1. **光纤产销量与单价不可得**。A 股半年报非强制披露主要产品产销量表，5.533 亿收入**无法拆成量 × 价**。**「83.78% 的毛利率还能维持多久」在公开信息范围内不可判定** —— 这是本档最大的、且**不可通过更努力的检索消除**的不确定性。[valuation.md §9.5](valuation.md) 以价格中枢敏感性表处理，而非假装能算出答案。
2. **在手订单久期不可得**。半年报「分摊至剩余履约义务的说明」勾选「不适用」、「按合同期限分类」为空 → 无法判断高价能锁多久。
3. **券商覆盖 n = 1**。截至采证时仅中信建投一家给 2026/2027 预测，**不构成「一致预期」**；其 2026E 15.12 亿隐含 H2 净利 11.19 亿 = H1 的 2.85 倍（26Q2 实绩仅 3.12 亿），斜率完全押注光纤价格继续上行。**本档不采信，并在所有引用处标 n=1。**

### （b）lens 覆盖缺口（结构性，非本档可弥补）

**`references/lenses/` 目录下不存在光纤 / 光通信板块专属 lens。** 本轮命中的四条中，`metals-copper` 覆盖的是占营收 76.6% 但只贡献微利的缆线/导线/铜箔，`x-ai` / `x-growth` 是横切恒跑线，`x-dividend-value` 判定不命中 —— **本轮最大的利润来源（光纤，占主营利润 50.60%）没有对应的板块专属 lens 覆盖**。本档**不硬套其他 lens**，光纤维度按 A3 专项处理（裸纤/光棒价格序列、运营商集采量价、光棒自给率、行业扩产窗口四条，均已落入 [thesis.md §6/§8](thesis.md) 与 [index.md §11](index.md) 触发器）。建议后续新建 `optical-fiber-cable.md` 补齐。

### （d）方法论局限

- **半年报未经审计**（半年报本身即如此声明），本档全部财务数字建立在此基础上。
- **三路数字冲突的处置**：本档遵循「以 A1 数据锚为准并显式标注」。本轮实际发生的三处冲突及处置：
  1. **减值后折旧对毛利率的贡献** —— A1 估 1,000–2,000 万 / 2–4ppt，A3 独立测得 1,322 万 / 2–3ppt。**同量级、不构成冲突**，本档取 A1 的区间表述（[thesis.md §6.3](thesis.md)）。
  2. **基准 PE 锚** —— A2 给 26H1 直接年化 28.1x，A1 给剔税盾年化 ≈35.3x。**取 A1 的 ≈35.3x 为基准锚**（剔税盾口径更接近可持续），A2 的 28.1x 作为「未剔税盾口径」**并列披露**（[valuation.md §9.1](valuation.md)）。
  3. **主营收入合计** —— 控制者前置观察与部分口径写 50.96 亿，A1 从半年报原文核为主营 50.646 亿 + 其他业务 0.321 亿 = **50.967 亿**。**取 A1**。另：总股本以 A1 的 **691,375,616 股**（半年报股本科目原文）为准，控制者前置的 691,384,712 为反推值，**作废**。
  4. **富春江通信集团持股口径** —— A2/A3 引媒体给「22.13% → 20.06%（截至 6-17）」，A1 从公告给「21.4659% → 18.47%（截至 8-05，减持实施完毕）」。**取 A1**：一致行动人合计 51.41% → **48.41%**。
- **资产法托底的主观性**：[valuation.md §9.3](valuation.md) 的 bear 采 0.8× 账面净资产，其中应收 9 折、存货 85 折的折价率为本档判断，非市场观测值。**该假设已在正文明写，读者可自行替换。**
- **股权质押的证据性质**：东方财富股权质押数据页质押明细表为空，且半年报前十名股东质押/冻结栏全部为「无/0」。**后者是【硬】的正面披露**，故本档表述为「质押率 0%」而非「未发现质押风险」。
