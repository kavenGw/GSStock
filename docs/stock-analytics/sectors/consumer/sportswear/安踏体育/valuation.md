# 安踏体育 — §9 场景加权估值 + 相对旧档变化清单

> 结论与评级见 [index.md](index.md)｜业务与护城河见 [business.md](business.md)｜论点与周期见 [thesis.md](thesis.md)｜来源见 [sources.md](sources.md)

## 9. 估值（场景加权 + SOTP）

### 9.1 估值架构：为什么必须做 SOTP

安踏持有 **Amer Sports 39.54%（权益法，不并表）**，并拟收购 **PUMA 29.06%（权益法或公允价值计量，不并表）**。这两笔权益：

- **不进收入**（安踏 H1 收入 435.07 亿元不含 Amer 的 240.8 亿元）；
- 只通过"分占联营公司损益"影响净利，Amer 本期贡献约 **7.08 亿元**（占经调整前净利 8.9%）【软·推算上限】；
- 账面价值（权益法）远低于市价，**且不随市价波动**。

因此**用单一 PE 给整个安踏定价必然出错**——要么把 Amer 的市价价值漏掉，要么把它的利润贡献重复计算。本档采用：

> **期望内在价值 ＝ 主业场景加权估值 ＋ Amer 权益 SOTP ＋ PUMA 权益 SOTP**

其中主业 owner earnings **已剔除** Amer 分占损益与一切一次性项目，避免与 SOTP 部分重复计算。

### 9.2 主业正常化 owner earnings 的确定

| 步骤 | 金额（亿元 RMB） | 说明 |
|---|---|---|
| FY2025 股东应占溢利（法定） | 135.88 | 已是剔除 FY2024 式一次性后的口径，同比 +13.9% |
| 减：Amer 权益法贡献（年化估计） | −14 | H1'26 为 7.08 亿，年化约 14 亿【推算】。**FY2025 的确切贡献额未找到【缺】** |
| ＝ 主业 FY2025 经营性净利 | ≈122 | |
| 考虑 2026 年主业增长（集团经调整 +9.6%，主业增速低于集团） | — | |
| **主业正常化 owner earnings（base）** | **130** | 【推算】与独立粗算的"本体 ≈131 亿"相互印证 |

**⚠️ 三条纪律**：

1. **绝不取顶部年化**。H1 经调整净利 72.3 亿若简单年化为 144.6 亿，会把 H1 结构性高于全年的季节性（OPM 27.0% vs FY 23.8%）当成常态。本档 base 取 **130 亿**，**低于任何形式的顶部年化**。
2. **纯经营 PE 无法精确计算**——缺 FY2025 Amer 权益法贡献额【缺】，故上表第二行是推算，不是披露值。本档在正文中一律标注。
3. 三档的正常化利润差异**只反映经营假设**（主品牌是否失速、其他品牌降速路径），不掺入一次性项。

### 9.3 三情景构造

**共同参数**：总股本 **27.9665 亿股**；汇率 **1 CNY = 1.1663 HKD**（2026-08-26，ECB/frankfurter）；Amer 权益市价基准 = $180.8 亿 × 39.54% = **$71.5 亿 ＝ 480.5 亿元 RMB**；PUMA 对价 **122.8 亿元 RMB**。

---

#### Bear（概率 30%）｜1,618.9 亿元 RMB ＝ 1,888.2 亿 HKD ＝ **67.52 HKD/股**

| 组成 | 计算 | 金额（亿元 RMB） |
|---|---|---|
| 主业 | 正常化 owner earnings **118** × **11.0x** | 1,298.0 |
| Amer 权益 | 480.5 × **60%**（Amer 股价自 52 周低位再跌约四成） | 288.3 |
| PUMA 权益 | 122.8 × **26.5%**（计提约七成减值） | 32.6 |
| **合计** | | **1,618.9** |

**情景叙事**：其他品牌增速从 44% 直落至个位数（高基数 + 户外总量仅 +2.7% + 竞品围攻），同时主品牌分部经营溢利同比转负。集团利润增速一年内从 +13% 掉到 0–5%，市场按"失去增长的成熟消费股"重估，倍数下杀至 11x。PUMA 交割后确认大额减值。

**倍数是否破框架**：11.0x 落在 Buffett 框架"窄护城河 8–12x"区间内，**未破框架**，无需转资产法主锚。

**资产法交叉验证**：bear 市值 1,618.9 亿元 RMB 对应 PB ≈ **2.29**（净资产 707.3 亿元），仍高于 1×。这**不矛盾**——因为净资产中的 Amer 权益按权益法列账，**账面值远低于其市价**（bear 情景下仍值 288.3 亿元）。剔除这部分后的主业隐含 PB 更接近 1.8x，对一家 ROE 22.5%、净现金占净资产 55% 的公司仍属合理下限。

| 组成 | 计算 | 金额（亿元 RMB） |
|---|---|---|
| 主业 | 正常化 owner earnings **130** × **14.5x** | 1,885.0 |
| Amer 权益 | 480.5 × **75%**（流动性折价 + 少数权益折价 + 大中华减速折价） | 360.4 |
| PUMA 权益 | 122.8 × **59.9%**（按对价约六折，反映 2026 年经营亏损指引与无控制权） | 73.5 |
| **合计** | | **2,318.9** |

**情景叙事**：主品牌 0–3% 平台期、FILA 低个位数、其他品牌按 40%→25%→18% 自然降速；集团收入 CAGR 8–11%、利润 CAGR 10–13%（[§8.2](thesis.md)）。Amer 维持上调后的指引但大中华增速继续常态化。PUMA 不发生反转也不发生崩塌。

**倍数是否破框架**：14.5x 落在 Buffett 框架"宽护城河 12–18x"区间内，**未破框架**。

**隐含 ROE 校验**：主业 130 亿 ÷ 净资产 707.3 亿 = **18.4%**，高于该风险档位对应的股权成本（净现金、无杠杆、有股息，约 10–11%），**14.5x 有 ROE 支撑，不是靠抬倍数凑数**。

**情景叙事**：其他品牌三年降速路径 40%→25%→18% 完整兑现且内生成分被证实；主品牌换将见效、OPM 回升；Amer 维持上调后指引；PUMA 在安踏介入后止血。

**倍数是否破框架**：17.0x 仍在"宽护城河 12–18x"上沿之内，**未破框架**。但见下条门控。

**⚠️ bull 增长证据包门控（命中 x-growth lens 必算）**：

| 要素 | 证据 | 评级 |
|---|---|---|
| (a) 扩产达产确定性（此处＝开店与店效能见度） | DESCENTE 270–280 家 / KOLON 210–220 家 / MAIA 60–70 家，基数小仍有空间【软】；但 Amer 全年大中华净开店仅 **10–12 家**【硬，且偏少】 | **软** |

| (c) TAM 跑道 | 中国户外运动用品 2026E 增速仅 **+2.7%**【软·第三方咨询】——跑道本身在收窄 | **缺/负面** |

**三项无一为硬证据 → 按证据包门控规则，bull 概率封顶 ≤20%。本档取 20%，恰在上限。** 这也是本轮把旧档 bull 概率从 25% 下调至 20% 的直接依据。

### 9.4 概率赋权与期望值

| 情景 | 每股价值（HKD） | 市值（亿 HKD） | 概率 | 赋权理由 |
|---|---|---|---|---|
| Bear | **67.52** | 1,888.2 | **30%** | 上调（旧档 20%）。理由：①PUMA 是自指引亏损的困境资产且交割在即（[§6.6](thesis.md)）；②主品牌 OPM 连续两期下滑且 CEO 刚辞任（[§6.4](thesis.md)）；③增长单点依赖占收入仅 24.6% 的分部。三条都是**旧档时点不存在的新增下行源** |
| Base | **96.71** | 2,704.7 | **50%** | 下调（旧档 55%）。中枢情形仍最可能，但 PUMA 交割的会计处理未定【缺】、其他品牌内生增速未拆出【缺】，两个关键输入的不确定性都高于旧档时点，故让出 5pct 给 bear |
| Bull | **128.03** | 3,580.5 | **20%** | 下调（旧档 25%）。**由 §9.3 的增长证据包门控封顶**：三要素全软/缺 → ≤20% |

**算术自检**：0.30 × 1,888.2 + 0.50 × 2,704.7 + 0.20 × 3,580.5 = 566.46 + 1,352.35 + 716.10 = **2,634.91 亿 HKD** ✅
每股：2,634.9 ÷ 27.9665 = **94.22 HKD** ✅

**安全边际** = (2,634.9 − 2,202.36) ÷ 2,202.36 = **+19.6%** ✅

### 9.5 对 bull 情景的单独压力测试

若 bull 情景中把三项证据全按最保守处理——其他品牌内生增速仅为报表 44.2% 的一半（即约 22%）、Amer 权益按 base 的 75% 折价、PUMA 按 base 的六折——则 bull 市值降至：

145 × 17.0 × 0.92（利润下修 8%）+ 360.4 + 73.5 = 2,267.8 + 433.9 = **约 2,701.7 亿元 RMB ＝ 3,151.1 亿 HKD ＝ 112.68 HKD/股**

即：**即便在乐观情景里，一旦增长的内生性被打折，每股价值就从 128.03 掉到 112.68（−12%）**。这说明 bull 的价值高度依赖"其他品牌 44.2% 是内生"这一**尚未被证实的假设**（[§6.2](thesis.md)），是本档最脆弱的一环。

### 9.6 "贵"与"便宜"的诚实结论

**便宜的一面（硬）**：经调整 PE-TTM **13.03x**（法定 11.77–12.09），低于旧档 17.2x 约 31%；PB **2.67** 为四年最低（3.48→3.09→2.80→2.67）；股息率 **3.29%**；半年 FCF 116.3 亿元对应年化 FCF 收益率约 **5.8%**（116.3×2 ÷ 1,888.2 亿元 RMB 市值）；净现金占净资产约 55%，账面成色干净（[§5.3](business.md)）。

**不够便宜的一面（硬）**：安全边际 **+19.6% < 30%**。安踏的确定性档位是"一般优秀"而非"很高"——增长单点依赖、管理层刚换将、三年内约 248 亿元 RMB 现金承诺【推算】未落表，三条都指向预测区间偏宽，**要求 30% 折价而非 20%**。

**⚠️ 本档明确拒绝的两种稀释手法**：

1. **不用"PE 已跌破 14x"论便宜**。14x 是旧档设的**观察触发线**，不是估值结论。本轮独立重估得到的买点 **72.5 HKD**（对应经调整 PE ≈ 12.0x）**比它更严**。
2. **不用"护城河上修"稀释"价格不够便宜"**。本轮护城河判断是**降级重述**（[§5.2](business.md)），不是上修。

### 9.7 未落表的资本承诺（必须计入判断，但未计入上述三档的资产负债表）

6/30 的净现金 391.1 亿元**尚未反映**：

| 项 | 金额（亿元 RMB） | 性质 |
|---|---|---|
| PUMA 收购对价 | **−122.8** | 现金流出，拟 2026 年内交割 |
| €15 亿零息票据（2029 到期） | **+118（负债）** | 转股价 **99.80 HKD**（高于现价 26.7%）；若三年内未达价，需现金偿付约 **125** |
| **三年内现金承诺合计** | **约 248** | **≈ 当前净现金的 63%**【A3 推算】 |

**这是旧档"净现金充裕"定性必须重估的直接原因。** 上述三档的 SOTP 已把 PUMA 按不同折价计入资产侧，但**票据的偿付义务未单独扣减**——若按最保守处理（bear 情景下票据全额现金偿付且不转股），bear 每股价值还需再下修约 **4.5 HKD**（125 ÷ 27.9665）。本档把这一项作为**bear 的额外下行风险披露**，不并入表内数字，以免与 PUMA 折价重复计提。
