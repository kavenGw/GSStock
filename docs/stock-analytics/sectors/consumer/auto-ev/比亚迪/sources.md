## §12.2 已知局限

1. **26Q2 单季数据为 H1 − Q1 反解**，非公司单独披露；毛利率、单车净利、财务费用等单季指标同理。**Q2 财务费用 29.97 亿这一关键推论即来自此反解。**
2. **汇兑损失金额在附注七·50 财务费用表中可得（47.03 亿 / 31.60 亿），但公司未在管理层讨论中单列**；剔汇兑后的利润总额 193.17 亿与归母约 163 亿为**按有效税率折算的估算**。
3. **境外收入 1,812.68 亿无法按分部拆分**：第 193 页分部表与第 194 页地区表**互不交叉**，报表未按「分部 × 地区」披露 → **52.57% 是集团口径含比亚迪电子代工出口，不得表述为「汽车业务海外收入占比」**。汽车海外收入占汽车分部收入只能给 **43.8%（台数下界）~ 65.8%（全归汽车上界）** 的区间，中枢无法用公开披露确定。电子分部境外占比无披露 →【缺】。
4. **存货周转天数原文未披露**：本档正文的硬口径用**存货占总资产 15.66% → 20.18%**（p27）；周转天数 83.7 → 122.9 天为**期末余额自算**【软】，cnevpost 平均余额口径 79 → 109 天【软】，两者方向一致、口径不同。应付周转 148.6 天同为自算【软】。
5. **存货性质未拆分**：在途 / 海外铺货 vs 渠道压库无披露 →【缺】。这是本轮最重要的未决问题（[§11](index.md) 监控首位）。公司在 p23 自陈供应紧张正在缓解，与存货占比上升 4.52pct 存在张力，两者可能对应不同车型，无法据以定性。
6. **国内销量为倒算值**：总销量 180.85 万 − 海外 79.2 万 = 101.65 万；同比降幅落在 **−35% ~ −39%** 区间，取决于 25H1 海外基数口径（A1 首版按 25H1 海外 58.1 万得 −34.9%；按 +67.8% 反解 25H1 海外 47.2 万则得 −39.3%）。A2 媒体口径记「超 −40%」、A3 记「约 −39%」。**本档统一写区间而非点值。** 另：海外销量含皮卡与商用，与境外收入口径不完全可比。
7. **海外工厂达产率 / 良率从未硬披露**：匈牙利、土耳其的投产时点、暂停状态均为媒体口径【软】，公司口径仅有「建设进度符合预期、产能不变」这一定性表述。
8. **智驾业绩层全【缺】**：璇玑A3 装机量 / 单颗成本 / 是否外供、天神之眼选装率与智驾相关收入，均无公司量化披露；本档三档估值均记 0 收入。
9. **管理层前瞻部分（p23）未给任何量化指引**：全年销量、出口、毛利率均无数字目标。旧档记录的「出口目标 150 万辆」在半年报中**未被重申**，证据级别仍停留在 2026-03 的媒体口径【软】；「全年 500 万辆」及据此推出的「目标下修风险」同属推断而非披露。
10. **欧盟关税量化影响【缺】**：半年报未对 17% 反补贴税单列量化影响；MIP 机制截至采证日未落地。
11. **stockanalysis 市值口径不自洽**（自报 919.80B HKD vs 其列示股本 × 价 = 835.8B，差 9.8%，旧档记录的同一坑复现）→ **已弃用其市值**，采腾讯自洽值 8,383.26 亿 HKD。其 Net Income (ttm) 33.84B 为 CNY 含少数股东口径，非归母，未混用。
12. **A2 / A3 与原文的数字冲突已全部取原文并显式标注**：
    (a) 出口量 A2/A3 记 78.9 万 / +67.9% → **原文 p14 为 79.2 万 / +67.8%**，台数占比相应由 43.6% 改为 **43.8%**；
    (b) 汇兑摆动 A1 首版倒算 83.43 亿、剔汇兑归母 ≈190 亿 → **原文附注为摆动 78.63 亿、剔汇兑归母约 163 亿（+26.8%）**，**剔汇兑年化上沿因此由 380 亿降至约 326 亿，[§9](valuation.md) 三档分子已据此下修**；
    (c) 隐含 ASP A3 记 +10%（误用集团收入 −7.13%）→ **改用汽车分部收入 −8.98%，正确值 +8.0%**；
    (d) 海外毛利率 A2 记「22%、外媒引述业绩会口径」→ **原文 p26 精确值 21.71%，且属 A 股半年报法定披露项【硬·原文】**，A2「非报表口径」的判断不成立；
    (e) 存货周转天数 A2 引 cnevpost 109/79 天、A1 首版自算 122.9/83.7 天 → **原文未披露周转天数**，硬口径改用存货占总资产 15.66%→20.18%；
    (f) 股息率 A3 记 0.42%（用旧汇率 1.08）→ **H 股口径 0.454%，frontmatter 取 0.45**；
    (g) A3 引用的「H 股 PE 23.21 / PB 3.34」→ 实测 **PE 24.73 / PB 3.03（按 26H1 净资产自算 2.76）**；
    (h) A3 记 AH 折价「约 −7.8%」→ 三源汇率实测 **−14.61%**，阈值未触发。
