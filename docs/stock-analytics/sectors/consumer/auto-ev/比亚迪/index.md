## §0 结论摘要

**Keep Watching（跟踪不持有）｜评级未翻转。**

- **期望内在价值（场景加权）≈ 29.54 HKD/股**；现价 **91.95 HKD**（2026-08-28 收盘，成交 1,094.6 万股，非集合竞价），总股本 9,117,197,565 股，H 口径市值 **8,383 亿 HKD**（自洽校验 91.17 亿 × 91.95 ✓）。**安全边际 = (29.54 − 91.95)/91.95 = −67.9%。**
- **三情景一句话**（算术与赋权理由见 [§9](valuation.md)）：
  - **Bear（32%）**：国内基盘塌陷（26H1 倒算约 −35~−39%，而行业国内新能源 +7.3%）快于海外补位，比亚迪电子分部利润 −85.5% 成新拖累源，汇兑成结构性敞口 → **17.96 HKD**。
  - **Base（45%）**：减量提质可持续但不可加速，境内外毛利率剪刀差（21.71% vs 15.67%，半年内由 285bp 扩至 604bp）撑住利润率、抵不过国内量的流失 → **32.37 HKD**。
  - **Bull（23%，门控封顶且较旧档下调 2pct）**：海外达产兑现、利润率修复延续 → **40.12 HKD**（倍数已由 14x 收紧至 11x，因该档隐含 ROE 不支持 1.5× 的 PB，见 [§9.4](valuation.md)）；**即便此最乐观档，安全边际仍 −56.4%。**
- **相对旧档（2026-06-20，watch，期望 38.6 HKD / 安全边际 −52%）**：**未翻转，仍 watch，但安全边际进一步恶化 16pct**。原因是分子分母同向不利——股价 80.85 → 91.95 HKD（+13.7%），而 26H1 归母 −20.54%、分红率 30%→10.01%、业主盈余折扣被实测下修（26H1 业主盈余 68.1 亿 = 报表归母的 55%）、剔汇兑后的正常化上沿仅约 326 亿（原文口径，非 380 亿）。**旧档 HKD 数字全部作废**：旧档用汇率 1 RMB = 1.08 HKD，实为 **1 CNY = 1.1665 HKD**（A1 三源交叉），本档所有 HKD 派生数按新汇率重算。
- **口径复核**：AH 折价 **−14.61%**（H 91.95 × 0.8573 = 78.83 CNY vs A 92.32 CNY），与旧档 −15% 基本持平，旧档 §11「折价收窄至 ≤5% 则重评切回 A 股」阈值**本轮复核过、未触发**，跟踪口径继续留 H 股。

## §10 评级决策

**Keep Watching（watch）｜评级未翻转。**

**期望内在价值 29.54 HKD vs 现价 91.95 HKD / 市值 8,383 亿 HKD → 深度高估，安全边际 −67.9%。**

**为什么 26H1 的好消息不足以翻转评级**（逐条对冲，避免只讲一面）：

| 本轮多头侧硬升级 | 对冲它的同等或更硬证据 |
|---|---|
| Q2 归母 +29.6%、扣非 +51.5%、毛利率 18.88%（+2.61pct），五季来首次同比转正，**且是在 Q2 汇兑压力（财务费用 29.97 亿）大于 Q1（20.99 亿）的情况下做到的** | 这是**单季拐点不是穿越周期中枢**；低于大摩/瑞银/花旗等卖方一致预期（预期 Q2 +48%，实际 +30%，低约 12%）；且利润改善有一部分来自**研发投入同比 −6.54%**（费用化口径 −21.2%）而非纯经营杠杆 |
| 境外收入 1,812.68 亿、占集团 52.57%（首次过半），境外毛利率 21.71% vs 境内 15.67%（原文 p26 法定披露，剪刀差半年内由 285bp 扩至 604bp） | 52.57% 是**集团口径含比亚迪电子代工出口**，汽车海外收入占汽车分部收入只能给 **43.8%~65.8%** 的区间（分部表与地区表不交叉）；海外量增 +67.8% 而收入仅 +33.92%，**隐含海外单车收入同比降约 20%**；且 +67.8% 仅与行业汽车总出口 +65.3% 持平，**远跑输行业新能源出口 +120%** |
| 汽车分部毛利率 22.33%（+1.98pct），T1 卖出触发器被明确证伪 | 存货 1,899.91 亿（+34.9%）而营收 −7.1%，**占总资产由 15.66% 升至 20.18%**；有息负债 216 → 1,138 亿，且筹资净额 −87.14%、**资本结构由股权融资转债务融资**，报表口径由净现金 +901 亿转为**净负债约 −551 亿** |
| capex 447.03 亿（−44.49%），分部资本性支出 −58.0%、权责制 capex 已降至 D&A 的 0.83×，重资本压力实质收敛 | 含营运资金的真实 FCF 仍为 **−73.7 亿**；业主盈余近似 68.1 亿仅为报表归母的 **55%**；且**政府补助 67.26 亿占剔汇兑后利润总额的 34.8%** |
| 匈牙利 2026-02 试生产；闪充站已建成 7,018 座（年底目标 20,000 座） | 有推迟至 26Q4 才启动整车组装、放弃自建电芯的报道；**土耳其厂据报已暂停**；达产率/良率仍【缺】——旧档封顶 bull 的原因未消除反而加重 |
| — | **比亚迪电子分部塌方**：分部利润总额 13.35 → **1.94 亿（−85.5%）**，毛利率 7.70% → 5.04%；汽车分部利润总额 111.61 亿（−12.8%）→ 集团利润拖累有相当部分来自电子而非汽车 |

**结论**：本轮唯一有资格支撑上修的是「利润率修复」，而它按 [§9](valuation.md) 的纪律只能进 **base 的分子（正常化利润上修）**，不能进分母（倍数上修）——毛利率修复来自产品结构 mix 而非定价权，mix 改善可持续但不可加速。而它在 base 分子上的上修，又被原文披露的下修侧（剔汇兑年化仅 326 亿、政府补助占比 34.8%、电子分部塌方、研发投入 −6.54%）抵消——故 base 每股价值由 38.4 降至 32.37，而现价上涨 13.7%，**安全边际净恶化**。

**买点阈值**：H 股价回到 **≤ base 内在价值 × 70% ≈ 23 HKD** 时进入可买区间；或出现下列任一硬催化后重评——(a) 匈牙利/土耳其**达产率或良率的公司口径硬披露**（bull 门控要素 (a) 从【缺】转【硬】的唯一路径）；(b) 存货在途/海外铺货拆分披露且证明非渠道压库；(c) 连续两个季度单季毛利率维持 ≥18.5% 且国内销量降幅收窄。当前 91.95 HKD 远高于买点。

**卖点/不持有理由**：当前不持有，无卖点。若已持仓，价格层面满足「价格严重高估」这一条卖出标准（安全边际 −67.9%），但**无护城河破坏、无管理层诚信问题**（26H1 首次给出境内/境外毛利率拆分，披露维度是增加而非减少）——即属于「贵到该走」而非「坏到该逃」。

**A+H 口径决策**：H 股 PE(TTM) 24.73 / PB 3.03（腾讯，分母为旧净资产）、**按 26H1 新归母净资产 2,608.18 亿自算 PB 2.76**；A 股 92.32 CNY、PE 28.60 / 自算 PB 3.23。H 侧全面更低，维持 H 口径。两个 PB 并列的原因是分母口径差：腾讯 PB 用的是上一期净资产，26H1 归母净资产已增至 2,608.18 亿，自算值更贴近当期。

## §11 关键风险 Top 7 + 监控指标 / 卖出触发器

**关键风险（按本轮证据强度排序）：**

1. **存货性质未拆分——本轮最重要的未决问题。** 存货 1,899.91 亿（**+34.9%**）对营收 −7.1%，**占总资产由 15.66% 升至 20.18%**（原文 p27 硬口径；周转天数 83.7 → 122.9 天为**自算**【软】，原文未披露周转天数）。半年报**未拆在途/海外铺货 vs 渠道压库**【缺】。若是渠道压库，则 26H2 存在降价去库风险，将直接逆转 [§8](thesis.md) 的「价格战阶段性缓和」判断，并把 Q2 的毛利率修复打回原形。公司在原文 p23 自陈「随着相关产能稳步提升……有效缓解供应紧张局面」，即**承认二代刀片/闪充车型供给紧张**——但缺货叙事与存货占比升 4.5pct 仍有张力，两者可能分别对应不同车型，无法用一句归因盖过。
2. **国内跑输行业、海外只是随大流。** 国内销量倒算约 101.65 万辆、同比 **−35% ~ −39%**（区间取决于 25H1 海外基数口径），而**行业国内新能源销量 +7.3%**（原文 p12 引中汽协）——不是行业问题，是份额问题：国内销量第一已让位吉利，20–30 万价格带份额从 40% 降至 28%【软】，动力电池装机与份额逆势双降【软】。海外侧 +67.8% 看似强劲，但**行业汽车出口 +65.3%、行业新能源出口 +120%** —— 比亚迪只是与总出口持平、**跑输新能源出口近一倍**。「海外强、国内弱」为真，但「海外强」是随大流而非跑赢。
3. **海外达产反向恶化 + 关税尾部风险。** 匈牙利延至 26Q4 启动整车组装、首年仅数万辆、两年内不满产【软】，土耳其厂据报已暂停【软】，达产率/良率**从未硬披露**【缺】。欧盟综合税负约 27%（17% 反补贴 + 10% 进口），MIP 最低进口价机制截至采证日未落地；另有欧盟拟对 PHEV 加征反补贴税的新增敞口【软】——比亚迪出口结构中 DM 插混占比高。
4. **资本配置转向的双面性（x-dividend-value 留存收益回报率判断）。** 2025 年度分红 32.64 亿、分红率 **30% → 10%**（−72.9%），26H1 董事会决议**不派中期股息**，股息率 0.46%。这发生在 OCF +17.3%、账面资金充裕的背景下 → 是**主动的资本配置转向（回报股东 → 投未来产能），不是现金不足**。按巴菲特「1 美元留存须创造 >1 美元市值」的检验：若海外产能达产并赚回超额 ROIC 则留存正确；**若达产 miss，则留存收益回报率被证伪，分红削减就成了重资本沉没风险的放大器**。当前 base 隐含 ROE 仅 8.6%（见 [§9](valuation.md)），这一检验目前**不通过**。
5. **汇兑已从一次性扰动变成结构性敞口。** 附注七·50 原文：26H1 汇兑**损失 47.03 亿**、25H1 汇兑**收益 31.60 亿**，摆动 **78.63 亿**（税前）。连续两个报告期把利润下滑归因汇兑，而境外收入占比已 52.57% —— **不能再当非经常性项目剔除**。但反解 26Q2 财务费用 **29.97 亿 > Q1 的 20.99 亿**，汇兑压力在 Q2 更大而非消退，Q2 却仍归母 +29.6%/扣非 +51.5% → **主营改善强于「一次性汇兑」这一解释本身**。本档在 [§9](valuation.md) 的处理是：用剔汇兑口径（年化约 326 亿）校准正常化利润的**上沿**，但三档均不假设汇兑归零。
6. **资本结构由股权融资转为债务融资。** 有息负债 216 亿 → **1,138 亿（+922 亿）**，货币资金 587 亿，报表口径由净现金 +901 亿转为净负债约 −551 亿；筹资活动现金流净额同比 **−87.14%**，原文归因「上期配售 H 股收到的现金大于本期借款取得的现金净额」——即 25H1 靠一次性 H 股配售、26H1 改靠举债，两条互证。这笔加杠杆**未流向 capex**（分部资本性支出 −58.0%），主要对应营运资金占用（存货净增 532 亿），**故不构成 T3 触发**，但须独立盯。注意公司口径「现金储备 1,674 亿」含货币资金以外科目，**与报表货币资金 587 亿不得混用**。
7. **比亚迪电子分部塌方 + 利润质量的两处限定。** 电子分部利润总额 13.35 → **1.94 亿（−85.5%）**，毛利率 7.70% → 5.04%；汽车分部利润总额 111.61 亿（−12.8%）——**集团利润拖累有相当部分来自电子而非汽车**，且该分部单一客户集中度上升（对某单一客户收入 460.17 亿、占集团 13.3%，上年 11.3%）。另两处利润质量限定：**政府补助 67.26 亿，占剔汇兑后利润总额 193.17 亿的 34.8%**；**研发投入 288.61 亿、同比 −6.54%**（费用化 233.07 亿、−21.2%）——即利润率修复中有一部分来自**减少投入**而非纯经营杠杆，旧档「高研发再投入 634 亿/年」的叙事在 26H1 须纠正。

**⚠️ 旧触发器失效裁决（不静默沿用、不静默删除）：**

旧档监控项「**capex/OCF 连续 2 季 > 0.8 视为扩张超现金造血能力**」经上年同期回测判定**无判别力**：该比率 25H1 为 **2.530**、26H1 为 **1.197**，**形式上连续两期命中阈值**，即按旧规则应「常年触发」——一个常年为真的指标不测量任何变化。成因有二：① 重资产扩张周期使 capex 绝对量本就接近或超过半年 OCF；② 半年口径下上半年是营运资金占用高峰（26H1 存货净增 532.31 亿），OCF 被系统性压低。**该比率在半年口径下测的是「日历与营运资金周期」，不是「扩张是否超出现金造血能力」。**

**修正方案（本档采用①+②）**：① 改用**全年口径**，半年口径作废；② 主看**趋势**——2.530 → 1.197 收敛 53%，配合分部资本性支出 −58.0%、权责制 capex 已降至 D&A 的 0.83×，方向明确是**收缩**；③ 若保留绝对阈值，合理线应设 **半年口径 1.5 / 全年口径 1.0**，而非 0.8。按修正判据：**T3 未触发，且方向相反。**
