# 比亚迪 — §9 估值（场景加权）

## §9 估值

### 9.1 钢轨与假设（严守）

- **币种统一 HKD**。市值/股价为 HKD、财报利润为 RMB。**正常化业主盈余先以 RMB 估算，再 ×1.1665 折 HKD**，再乘倍数、除股本。
  **汇率假设 1 CNY = 1.1665 HKD**（三源交叉：frankfurter.dev 2026-08-28 HKD→CNY 0.8573；open.er-api.com 0.85902；新浪 fx_shkdcny 0.85816）。
  **旧档使用的 1 RMB = 1.08 HKD 已被证伪并作废**，旧档全部 HKD 内在价值被系统性低估约 8%，本节所有 HKD 数字均可由 1.1665 复算。
- **总股本 9,117,197,565 股（91.17 亿）**；现价 **91.95 HKD**（2026-08-28 收盘）；H 口径市值 **8,383 亿 HKD**（自洽校验偏差 0.00%）。
- **正常化 owner earnings 绝不取顶、也不取当期塌陷。** 可用锚点：

| 锚 | 值（RMB） | 说明 |
|---|---|---|
| 2024 年度归母（周期高点） | 约 402 亿 | **三档上限，任何一档都不得触及** |
| TTM 归母 | **294.33 亿** | 2025 全年 326.19 − 25H1 155.11 + 26H1 123.25 |
| 26H1 报表归母年化 | 约 246 亿 | 含汇兑塌陷，是下沿而非中枢 |
| **26H1 剔汇兑后归母年化** | **约 326 亿** | 半年报附注七·50 原文：26H1 汇兑损失 **47.03 亿**、25H1 汇兑收益 **31.60 亿**，摆动 **78.63 亿**（税前）；剔汇兑后 26H1 利润总额 193.17 亿（+22.6%）、归母约 **163 亿（+26.8%）** |
| 26Q2 单季年化 | 约 330 亿 | **绝不直接采用**——那是把单季拐点当穿越周期中枢，与兄弟档特斯拉共用的纪律不允许 |

- **业主盈余折扣改用 26H1 实测值，不沿用旧档定性表述**：
  - 现金制 capex / D&A = 447.03 / 391.83 = **1.14**；**权责制（分部表）capex 327.15 亿已低于 D&A 391.83 亿（0.83×）**，其中汽车分部资本性支出 **315.51 亿、−58.0%** → 投入强度是**收缩**方向。
  - 业主盈余近似（净利 + D&A − 现金制 capex）= 123.34 + 391.83 − 447.03 = **68.1 亿 = 报表归母的 55%**
  - 含营运资金的真实 FCF = 373.35 − 447.03 = **−73.68 亿，仍为负**（存货占用 −532.31 亿是主因）
  - 折扣取法：实测 55% 处在营运资金占用高峰的半年度口径，长期不应外推为常态；但 capex/D&A 在 0.83–1.14 之间是结构性的。故三档折扣设 **bear 0.60 / base 0.68 / bull 0.75**（bull 假设海外达产后 capex 强度进一步下降 + 存货占用释放）。
- **政府补助的敏感性处理（原文新发现）**：与日常活动相关的政府补助 **67.26 亿**（25H1 64.10 亿），**占剔汇兑后利润总额 193.17 亿的 34.8%**。这是利润构成中不可忽视的非经营性来源。本档不把它从正常化利润中剔除（它历史上稳定存在、且同比仅 +4.9%），但**它是三档分子共同的脆弱点**——若补助政策退坡，三档需同步下修，故已列入 [§11](index.md) 监控。
- **智驾（璇玑A3 / 天神之眼）收入三档均记 0**，见 [§7](thesis.md)。它对报表当前是**净成本**（研发投入 288.61 亿 > 归母 123.25 亿），且该成本**已含在 Q2 18.88% 的毛利率里，不做二次扣减**。
- **不给营收成长溢价**。营收 −7.13%、销量 −15.72%，**不许套 PS/PEG**。本轮唯一的正面变化是利润率修复，按纪律**只上修 base 的分子（正常化利润），不上修分母（倍数）**——毛利率修复来自产品结构 mix，不是定价权（见 [§5](business.md)）。
- **bull 分子必须按区间而非点值处理**：半年报第 193 页分部表与第 194 页地区表**互不交叉**，境外收入 1,812.68 亿无法拆出汽车与比亚迪电子各自多少 → 汽车业务海外收入占汽车分部收入落在 **43.8%（台数下界）~ 65.8%（全归汽车上界）**，中枢无法用公开披露确定。故 bull 的「海外高毛利占比抬升」这一分子驱动**存在一个 22pct 宽的口径带**，本身就要求 bull 概率被压低。
- **无重要联营/合营需 SOTP 拆分**；比亚迪电子（手机部件、组装分部）为并表分部，已含在合并归母中，不单独拆估——但其 26H1 利润总额 **1.94 亿（−85.5%）** 的塌方对集团利润的拖累已在合并数中体现（见 [§3](business.md)）。

**期望内在价值 = 17.96×0.32 + 32.37×0.45 + 40.12×0.23 = 5.75 + 14.57 + 9.23 = 29.54 HKD/股。**

> **关于 bull 倍数 11x 低于 base 12x**：这不是笔误。按 `buffett-doc-spec` §3「按各档隐含 ROE 重排整条 PB 阶梯」，**PB 阶梯才是主锚**——bull 相对 base 的更高价值全部来自**分子**（正常化归母 380 vs 310 亿、折扣 0.75 vs 0.68），而其隐含 ROE 10.9% 仍低于股权成本，**不应再享有高于 base 的盈利倍数**。每股价值仍严格 bear < base < bull（17.96 < 32.37 < 40.12），PB 阶梯亦单调递增（0.54× < 0.97× < 1.20×）。

三档分子相对锚点的位置：bear 260 亿 < TTM 294 亿；base 310 亿落在 TTM 294 与剔汇兑年化 326 之间；bull 380 亿高于剔汇兑年化但**仍低于 2024 周期高点 402 亿**——铁律「三档都应低于顶部」满足。

### 9.3 逐档赋权理由（引 §6/§8 证据）

- **Bear 32%（旧档 30% → +2pct）**：正常化归母 260 亿（低于 TTM 294 亿），对应国内基盘继续塌陷（26H1 国内倒算约 −35~−39%，而行业国内新能源 **+7.3%**，即显著跑输行业）、海外亦进入以价换量（海外量增 67.8% 而境外收入仅增 33.9%，隐含海外单车收入同比降约 20%）、比亚迪电子分部利润塌方（−85.5%）成为新的拖累源、汇兑成结构性敞口。折扣 0.60 假设 capex 重回扩张且营运资金持续占用。**准商品给周期性低倍数 9x**。权重上调 2pct 的依据：本轮空头侧拿到四条原文级证据升级（国内跑输行业、海外跑输行业新能源出口 +120% 近一倍、存货占总资产 15.66%→20.18%、有息负债 +922 亿且资本结构由股权转债务融资），全部劣于旧档假设。
- **Base 45%（维持）**：正常化归母 310 亿（旧档 320 亿 → **−10 亿**）。分子的两股力量相互抵消：**上修侧**是 [§3](business.md) 六项独立同向的利润率修复证据（ASP +8.0%、汽车分部毛利率 22.33%/+1.98pct、Q2 毛利率 18.88%/+2.61pct、扣非 −9.02% 远好于归母 −20.54%、OCF +17.28% 高于净利增速、境内外毛利率剪刀差由 285bp 扩至 604bp）；**下修侧**是原文披露的剔汇兑年化仅 **326 亿**（低于我按 A1 首版所用的 380 亿）、政府补助占剔汇兑利润总额 34.8%、电子分部塌方、研发投入同比 −6.54%（即利润改善部分来自减少投入而非经营杠杆）。净结果略低于旧档。**倍数维持 12x（中等护城河），无新证据支持上调**。
- **Bull 23%（旧档 25% → −2pct，门控封顶且下调）**：正常化归母 380 亿（旧档 420 亿 → **下修 40 亿**：420 亿高于 2024 周期高点约 402 亿，违反「正常化利润绝不取周期顶」铁律；380 亿高于剔汇兑年化 326 亿、低于 402 亿，属乐观上沿）。**bull 门控三要素逐项标记**：
  - **(a) 扩产达产确定性 ——【软】且反向恶化**：匈牙利 2026-02 试生产【软】，但有推迟至 26Q4 才启动整车组装、放弃自建电芯的报道【软】，**土耳其厂据报已暂停**【软】；**达产率/良率仍【缺】**。旧档把 bull 封顶 25% 的直接原因是这一条，本轮该原因**未消除反而加重**。
  - **(b) 需求能见度 ——【硬·但内容偏空】（自身出货兑底，非客户具名兑底）**：整车 To C，无「大客户 capex 指引」可兑，已降级到自身出货口径。三条硬数——海外销量 **79.2 万辆 +67.8%**、境外收入 **+33.92%**、境外毛利率 **21.71%（原文 p26 法定披露）**——**证据等级由软升硬，但内容本身对 bull 不利**：+67.8% 仅与行业汽车总出口 +65.3% 持平，**远跑输行业新能源出口 +120%**；且量增两倍于价增，海外亦在以价换量。**须明写这是自身出货兑底而非客户具名兑底，且兑到的是「随大流」不是「跑赢」。**
  - **(c) TAM 跑道 ——【软】**：全球新能源渗透仍在上行、海外空间大，但国内已从渗透率红利转入存量份额战（[§2](business.md)）；且汽车海外收入占比只能给 43.8%~65.8% 的区间，跑道的财务厚度无法定量。
  - **门控结论**：(b) 的**证据等级**升级了，但**证据内容**是中性偏空的；(a) 反向恶化，(c) 未变。**净效果 bull 概率不上调，且因 (a) 恶化（土耳其暂停 = 旧档假设被证伪）与 (b) 内容转空，概率由 25% 下调至 23%，且**倍数由 14x 收紧至 11x**（理由见 §9.4——不是概率问题，是该档隐含 ROE 撑不起 1.5× 的 PB）。

### 9.4 隐含 ROE / PB 交叉验证（防「倍数破框架」）

26H1 末归母净资产 2,608.18 亿 CNY，BVPS = 28.61 CNY = **33.37 HKD**。

| 情景 | 隐含 PB（每股 ÷ 33.37） | 隐含 ROE（业主盈余 ÷ 净资产） | 判读 |
|---|---|---|---|
| Bear | 0.54× | 6.0% | 远低于股权成本，PB <1 合理 |
| Base | **0.97×** | **8.1%** | 8.1% 明显低于本标的对应的股权成本（净负债约 −551 亿、真实 FCF 为负、股息率 0.45%，取 ≥12%）→ **公允 PB 应在 1× 附近，与 0.97× 吻合** |
| Bull | **1.20×** | 10.9% | 隐含 ROE 10.9% 低于股权成本 12% → **PB 阶梯不支持 1.5×**。倍数已由 14x 收紧至 11x，PB 落到 1.20×（见下）|

**bull 倍数收紧（本轮的实质修正，非口味调整）**：初稿沿用旧档与兄弟档特斯拉的「准商品整车 14x 为乐观上限」惯例，给 bull 14x → 每股 51.05 HKD、隐含 PB **1.53×**。但该档隐含 ROE 仅 **10.9%**，**低于本标的应有的股权成本 ≥12%**（净负债约 −551 亿、真实 FCF 为负、股息率 0.45%、政府补助占剔汇兑后利润总额 34.8%）。按 `buffett-doc-spec` §3「倍数被迫破框架 = 该档每股价值本身没有支撑，回查隐含 ROE 而非抬倍数」，**隐含 ROE 低于股权成本时公允 PB 应在 1× 附近，1.53× 无支撑**。故按 PB 阶梯重排：bull 倍数 **14x → 11x**，每股 **40.12 HKD**、PB **1.20×**（略高于 1× 以反映其相对 base 更高的 ROE，但不再给「乐观上限惯例」的溢价）。

**双面披露**：旧档（2026-06-20）与兄弟档特斯拉均沿用 14x 的乐观上限惯例，**本档不再沿用**——不是因为对海外故事更悲观（bull 的分子 380 亿与概率 23% 均未因此再动），而是因为**隐含 ROE 检验不通过**。若后续 ROE 回到 12% 以上（需正常化归母升至约 420 亿且折扣不降），14x 可重新讨论。这一收紧使期望内在价值由 32.06 降至 29.54 HKD、安全边际由 −65.1% 加深至 −67.9%。

**框架自检通过**：三档倍数（9x/12x/11x）全部落在 buffett 框架内（周期/准商品 <8–12×、窄护城河 8–12×），无「破框架」项；每股价值 bear < base < bull 成立，PB 阶梯 0.54× < 0.97× < 1.20× 单调递增且与三档隐含 ROE（6.0% < 8.1% < 10.9%）同序，无需改资产法主锚。base 的利润法结论（PB 0.97×）与资产法交叉验证一致，是本轮估值最可靠的一点。

### 9.5 安全边际与压力测试

- **期望口径**：(29.54 − 91.95) / 91.95 = **−67.9%**（深度高估）。较旧档 −52% 进一步恶化 16pct。
- **对最乐观 bull 单独再压一次**：(40.12 − 91.95) / 91.95 = **−56.4%** —— **即便假设海外达产全兑现、利润率修复延续，现价仍高估 56.4%。**（若不做 §9.4 的倍数收紧、沿用 14x 的旧惯例，bull 每股 51.05 HKD、安全边际 −44.5%——两种口径下结论方向一致，均无买点。） 这是「诚实面对贵」的硬落点：Q2 拐点是真的，海外结构改善是真的，**但它们都已被 +13.7% 的股价吃掉且吃过了头**。
- **智驾期权单独压力测试（不进主算术）**：唯一可证伪锚是天神之眼 B 激光版**选装价 12,000 元/车**（硬）。假设 2026 销量 380 万辆、选装率 10%，年化智驾选装收入 ≈ **46 亿元**，即使全额落到毛利也仅相当于 26H1 归母的约 1/3 量级，折 HKD 给 12x 约 644 亿 HKD ≈ **7.1 HKD/股**。**期权存在但价内深度不足，不改变估值中枢**，base/bull 均记 0 收入。（写法对齐兄弟档特斯拉对 Robotaxi/Optimus 的「单独压力测试、不进主算术」处理。）
- **政府补助敏感性**：若 67.26 亿补助永久退坡一半（约 −34 亿税前，税后约 −28 亿），三档分子各下移约 28 亿 → base 每股由 32.37 降至约 **29.4 HKD**，安全边际恶化至 −68%。**补助退坡不改变结论方向，只加深幅度。**
- **AH 口径压力测试**：若改用 A 股 002594 口径（92.32 CNY、PE 28.60、自算 PB 3.23），同一模型下期望内在价值 = 29.54 / 1.1665 = **25.32 CNY**，安全边际 = (25.32 − 92.32)/92.32 = **−72.6%**，比 H 口径差 4.7pct。**H 侧确为估值更低一侧，口径选择成立。**
