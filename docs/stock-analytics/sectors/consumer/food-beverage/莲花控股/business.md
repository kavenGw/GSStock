# 莲花控股 — §1-§5 能力圈 / 市场规模 / 盈利能力 / 全球竞争力 / 护城河

## §1 能力圈 & 本次建档触发

### 1.1 一段话说清它怎么赚钱

莲花控股（600186，原名莲花味精、莲花健康）以玉米为原料，通过谷氨酸发酵生产味精及氨基酸调味品，
辅以鸡精等复合调味品、面粉面制品、料酒等液态调味品，经由**超 3,000 家经销商**分销到 C 端零售终端赚钱。
2026H1 调味品业务分部收入占比 **97.44%**，另有一个占 2.85% 的"科技业务分部"（GPU 服务器转租的算力租赁）。
**这是一家食品调味品公司。**

**能力圈判定：主业在圈内**（消费品、可解释的量价模型、有历史数据可验证）；
**题材部分（类 ABF 封装膜）在圈外或边界**——判断其技术兑现需要材料学与半导体封装认证的专门知识，
本档不假装能预测其技术成败，只用**可核验的财务与产业位次事实**处理它（见 [§6](thesis.md)、[§7](thesis.md)）。

### 1.2 本次建档触发

用户提出的原始问题是：**「莲花味精能否对标味之素的 PBF/ABF 薄膜路径」**。触发变量有三：

1. 2026-04 全资子公司杭州莲花科创参与受让深圳纽菲斯新材料（类 ABF 增层膜）股权；
2. 2026-08 集微网传「味之素对中国大陆砍单 30%」（**该传闻原文自陈无第三方印证**）点火 ABF 国产替代情绪；
3. 股价 3 个月内翻倍，2026-09-07 收 12.55 元（+5.64%），PE(TTM) 57.49、PB 11.16。

**本仓此前无该股任何存量档，本次为首建档。**

## §2 市场规模与跑道长度

### 2.1 味精 / 调味品

- 国内味精总产能约 **332 万吨**（2023 年口径），CR3 = 阜丰 133 万吨（43.5%）+ 梅花 105 万吨（34%）+
  > **口径警示**：上述个体份额与 332 万吨分母不自洽（133/332 = 40.1%、105/332 = 31.6%，而非标注的 43.5% / 34%），个体份额疑似引用了另一年份或另一统计口径的总产能基数。CR3 合计 280/332 = 84.3% ≈ 85% 大致吻合。**本组数字仅用于行业格局背景陈述，不进入 §9 估值分母**；精确份额待原始产能报告核实。
  伊品 42 万吨 ≈ **85%**，2024 年升至约 89%【中】。**莲花不在 CR3 之列**。
- 莲花 2025 年味精销量 **25.42 万吨**（同比 +28.28%）【硬｜公告 2026-043】，
  对比阜丰 133 万吨产能**约为其 1/5**。
- **跑道长度（x-growth lens 必答）**：莲花在**终端零售**市占率约 26%+（历史峰值 43.4%，1997 年）【软】，
  已是该细分第一。**渗透率已高、剩余空间有限**，且行业本身低增长。
  → **这正是公司必须持续讲跨界故事的根本原因**：主业跑道短，只有讲新赛道才能支撑估值扩张。

### 2.2 算力租赁

- TAM 与增速：**未取得可引用的第三方机构口径**【缺】。
- 行业侧仅找到**反向证据**：「花几个亿建智算中心，八成的 GPU 租不出去」（2024-12 报道）【软】，
  指向该赛道供给过剩。莲花在其中的份额**未取得可量化数字**【缺】。

### 2.3 类 ABF 增层膜

- 味之素在高性能 CPU/GPU 载板级 ABF 全球份额 **95%–100%**，中国进口依赖度约 90%【软】。
- ABF 膜全球市场规模（美元/吨口径）与增速预测**未找到第三方机构数字**【缺】。
- 纽菲斯在该市场的份额：现有产能 12–14 万㎡/年 vs 味之素月产能 200 万㎡+，**份额可忽略**。
  且纽菲斯**不并表**，其 TAM 对莲花合并报表**无传导路径**。

## §4 全球竞争力

### 4.1 味精 / 氨基酸

| 公司 | 产能 / 体量 | 位次 |
|---|---|---|
| 阜丰集团（0546.HK） | 133 万吨（43.5%） | 全球/国内龙头 |
| 梅花生物（600873） | 105 万吨（34%），TTM 营收 241.63 亿元 | 国内第二 |
| 伊品生物 | 42 万吨 | 第三 |
| **莲花控股** | **2025 年销量 25.42 万吨**，TTM 营收 37.46 亿元 | **CR3 之外，约为阜丰 1/5** |

**关键区分（务必读进结论）**：莲花在**终端零售/C 端品牌**有历史知名度（零售份额第一），
但在**上游谷氨酸/味精产能**上是二线。**终端零售份额 ≠ 上游产能份额。**
以体量论，莲花是**跟随者而非价格制定者**，涨价周期的产能杠杆在阜丰、梅花手上。

### 4.2 类 ABF 增层膜

见 [§6.2](thesis.md)：全球由味之素垄断（份额 95%–100%），国内替代第一顺位是**华正新材**，
纽菲斯与其量级差约两个数量级，且不并表。**莲花在这条链上没有全球竞争力可言。**

### 4.3 算力租赁

无自研芯片、无自建大规模智算中心运营能力，**属采购 GPU 服务器转租的最下游模式，无技术壁垒**，
不构成任何全球竞争力。

## §5 核心优势 / 护城河

### 5.1 逐类型评估

| 护城河类型 | 强度 | 趋势 | 判据 |
|---|---|---|---|
| **无形资产（品牌）** | **中** | **稳定偏弱** | 「莲花」是国民级味精品牌，终端零售份额约 26%+ 连续多年第一；但历史峰值 43.4%（1997）已大幅回落，且 **2021 年「莲花」商标曾被拍卖**【中】，品牌资产曾一度脱离公司控制 |
| **成本优势** | **弱** | **稳定** | 上游产能仅为阜丰 1/5，规模效应显著弱于 CR3；公司「将核心味精业务转为采购贴牌而非自产」【软】进一步削弱成本控制 |
| **转换成本** | **无** | — | 味精是标准化商品，终端消费者切换成本为零 |
| **网络效应** | **无** | — | 不适用 |
| **有效规模** | **无** | — | 行业已有 3 家规模远超的对手，不存在利基垄断 |

### 5.2 定价权测试（Q4）

**答案是否定的。** 2025 年销量 +28.28% 而单吨售价 −7.4%，是在**降价换量**；
经销商超 3,000 家、前十大客户仅占味精收入 **13.63%**——客户高度分散虽无大客户依赖风险，
但也意味着**无 B 端锁定、议价能力弱**。

### 5.3 护城河总判

**窄护城河，且趋势是稳定偏弱。** 唯一实质资产是 C 端品牌认知，而这份认知在 2019 年破产重整
与 2021 年商标拍卖中已被证明是**脆弱且可与公司分离的**。上游产能、成本、定价权三项均为跟随者位次。

**这直接决定了 [§9](valuation.md) 的倍数框架**：按 buffett 框架，窄护城河对应 8–12× 的 PE 带宽，
本档 base 给到 15× 已是对品牌溢价的让步，并已按 spec 要求做了隐含 ROE / PB 回查与披露。
