## §1 能力圈 & 本次重审触发

### 1.1 能力圈判定：**圈内（边界清晰、可一段话说清）**

泡泡玛特签约艺术家、把其形象工业化为**盲盒 / 毛绒 / MEGA / 衍生品**，
通过**自有零售网络（676 家门店 + 2,827 台机器人商店）+ 8,244 万注册会员 + 电商与批发**分发，
赚的是「IP 授权 + 设计溢价 + 自有渠道零售差价」三层叠加的钱——毛利率 69.7%、净利率 29.3%。
**商业模式本身不复杂；难以预测的是「下一个爆款何时出现」，这是不确定性而非能力圈问题。**

- **10 年存续性**：公司大概率存在（现金 124.4 亿、零银行借款、8,244 万会员、676 店）。
  **但「10 年后更有竞争力」不确定**——这门生意需要每 18–24 个月重造一个爆款，三丽鸥用了 10 年才回到 2014 峰值。
- **反向思考（哪三条路径会亏钱）**：① 用峰值 E 定价、正常化后 E 下台阶而 P 不跟随；② 星星人重复 Labubu 的 18 个月半衰期且无第三个 IP 接棒；③ 存货减值兑现叠加乐园重资产周期把高 ROIC 做没。

## §2 市场规模 + 跑道长度（x-growth lens 落点）

### 2.1 TAM 口径：机构分歧达约 27 倍，**禁止用「TAM × 份额」倒推估值**

Art Toy / Designer Toy 全球市场规模的第三方口径从 **USD 18 亿到 499.5 亿**不等（约 27 倍分歧），
**无权威单列口径**。**本档铁律：任何「TAM × 份额」的倒推估值不可用。** 只能做定性的跑道判断。

### 2.2 跑道长度（物理口径，可验证）

| 维度 | 2026-06-30 | 半年变化 | 跑道判读 |
|---|---|---|---|
| 全球门店 | **676 家** | 净增 46 | 内地 419 / 港澳台 36 / 亚太 90 / 美洲 86 / 欧洲及其他 45 |
| — 美洲 | **86 家** | **64 → 86（+34%）** | 逆势加速，欧洲及其他 45 家仍是「新市场铺店」阶段 |
| 机器人商店 | **2,827 台** | 净增 190 | — |
| 中国内地注册会员 | **8,244 万** | 半年净增近 1,000 万（+13.6%） | 会员销售占内地收入 **92.9%**，复购率 **51.6%** |

- **物理跑道未到天花板**：海外门店 221 家 vs 内地 419 家，海外仍有数量级空间。
- **但扩张节奏已主动放缓**：FY2025 全年新增 100 余家 → H1'26 仅 46 家（年化约 92 家）；
  管理层明示海外开店「**质量要远大于数量**」，欧洲重新审查全部计划门店、部分直接放弃。
- **增量来源判读**：门店数同比增幅约 +7%（推算）远低于营收 +23.76% → **增量主要来自同店效率与新品，而非门店扩张**。

### 2.3 客户增长预期（x-growth lens ②：无 B 端具名大客户 → 降级到终端兑底）

- **本标的无 B 端大客户，客户 = C 端消费者**，按 lens 规定**降级到终端市场总量**处理，**明写这是终端兑底而非具名**。
- 终端总量兑底证据**薄弱**：潮玩终端总量无权威第三方口径【缺】。
- 可用领先指标：① **二手溢价**（Labubu 已从 +44.7 倍跌至 −88%，星星人批次溢价 3.2×~14× 跳动）；
  ② **会员复购率 51.6%**（【缺】1H2025 同口径复购率，无法做严格同比）；
  ③ 会员数半年增速 **+13.6%** vs 内地收入 +47.3% → **国内增量中客单价 / 购买频次贡献大于新客，这在需求退潮期是更脆弱的增长结构**。
- **门店与产能是【硬】，达产（单店产出）是【软/缺】**——见 [valuation.md §9.5 门控表](valuation.md)。

**干净归母 55.8–57.6 亿，干净同比 +25.3%~+29.3%，与营收增速匹配。**

### 3.2 增长拆量价与增长质量（x-growth lens 落点）

- **量价拆分【缺】**——公司未披露销量 / ASP，中报无量价表。
- **可判定的增长质量拐点（已发生，非未来风险）**：
  - 归母 **+10.14% < 营收 +23.76%**：增长开始需要费用去买。
  - 集团增速 **+184.7%（FY2025）→ +23.76%（H1'26）**，一年降 161ppt；**Q2'26 单季反推约 −5%~−6%**【软-推算】。
  - 毛利率与营收增速**同步走弱**（72.1% → 69.7%、+184.7% → +23.76%），命中 lens 的「增长质量恶化」监控项。
- **反面（必须写）**：毛利率仅降 **0.6ppt**，**产品结构从手办切向毛绒并未伤到定价权**——
  这是本轮最硬的正面证据之一。

|---|---|---|---|---|

- Shopee 渠道 **−62.1%**。
- **海外下滑全部来自线上，线下反而双位数增长** —— 因果链与双面解读见 [§6.1](thesis.md)。

### 3.5 资产负债与运营效率

| 项目 | 2026-06-30 | 对比 |
|---|---|---|
| 现金及现金等价物 | **RMB 124.4 亿** | 【硬】 |
| 银行借款 | **零** | 【硬】 |
| 资产负债率 | **24.9%** | 【硬】 |
| **存货** | **RMB 61.02 亿** | **同期可比：H1'25 22.74 亿 → +168.4%**（原文口径）。⚠️ 媒体与旧档常用的「2025 年末 54.73 亿 → +11.5%」是**跨季节对照，把问题缩小了一个数量级，本档禁用** |

### 3.6 股东回报（x-dividend-value lens 落点）

- **trailing 股息率 1.79%**（FY2025 末期 DPS 2.744 HKD / 153.00）；**2026 中期不派息，本期分子为零，前瞻性为零**。
- **派付率 25.0%**（FY2025 末期股息 31.94 亿 / 归母 127.76 亿），含回购口径 **36.7%** → **低派息、高留存**，不是高分红标的。
- **回购须分两个窗口写，缺一句都不完整**：
  **① 旧窗口（已执行）**——2026 年 1–4 月累计回购约 **17.44 亿 HKD**：1 月约 3.48 亿；3/26–4/2 连续 6 个交易日约 13.97 亿，
  其中 **3/26 单日 5.99 亿**、**3/30 斥资 1.99 亿回购 134 万股（价区间 144.3–153.5 HKD）**；H1'26 累计回购并**注销 1,122 万股**。**公司有真实执行力，不是空头支票。**
  **② 新窗口（执行情况【缺-检索失败】）**——2026-08-20 宣布 6 个月内回购 **RMB 20–50 亿**（人民币）、全部注销、至 2027-02-20，占市值 **1.15%–2.87%**；
  **截至本档撰写日未检索到新授权下的《股份购回报告表》，且**港交所检索本轮受限**（A1 扫描 hkexnews 编号空间触发 IP 限流、整站 403），故**只能记为【缺-检索失败】，不得写成「零执行」结论****。
  旁证（媒体零报道；09-01 起收盘价窄箱体、日均成交仅 7.7M 股——若真有 23–58 亿港元回购在跑，难以不留量价痕迹）**倾向尚未执行，但只能写成旁证**。
  **裁定：不得把新回购写成估值下界支撑。** 触发器 = 新授权下**首份《股份购回报告表》的披露日与金额**。
- **股东回报按下限 20 亿元（≈ 23.4 亿港元）保守取值**，并注明**一次性 6 个月授权不可永续外推**。双面必答见 [§6.6](thesis.md)。

### 3.7 ROIC / ROE

- **ROE 已结案，不再是【缺】项**：FY2025 **76.2%**（平均净资产口径）/ 期末 56.4%；**TTM 70.2%**；**H1'26 年化已降至约 43.9%**。PB 自算 7.53x（腾讯 7.67）。
  **ROE 从 76.2% 一路降到 43.9%，是「峰值回落」最强的单一指标**——水平仍然极高，但斜率明确向下，且它与本档把 base 倍数由 13x 下修到 11.5x 指向同一件事。
  旁证：FY2025 净利率 35.1%（2024 年 25.4%）、毛利率 72.1%、基本 EPS RMB 9.61。
- **ROIC 未重算【缺】**。但轻资产 + 高毛利 + 低有形资本占用 → 水平大概率极高；
  **真正的问题不是 ROIC 水平，而是可持续性：分母（存货 + 门店 + 乐园）在扩张，分子（利润）在减速。**
- 估值侧的隐含 ROE 校验（44%~57%）见 [valuation.md §9.4.1](valuation.md)。

## §4 全球竞争力

| 维度 | 判定 |
|---|---|
| **全球份额** | 潮玩品类**全球第一梯队、中国第一**（GMV 口径中国潮玩零售第一，TOP TOY 第二、份额 4.8%）【软】 |
| **分部披露的结构性限制（【硬-原文依据】）** | 公司**只有「中国业务」与「海外业务」两个可呈报分部，根本没有美洲分部**；且公告原文明载「**由於主要經營決策者並不使用分部資產及分部負債資料…故並無向主要經營決策者單獨提供此資料**」。**因此「美洲分部 ROIC 无公开口径可验」是结构性不可验证，不是尽调缺失。** 替代硬指标：**H1'25 海外分部经营利润率 44.2%**（中国 48.9%）；H1'26 同口径未取到，列为中期报告发布后的一级复核项 |

## §5 核心优势 / 护城河（重评旧档判断）

| 护城河类型 | 强度 | 趋势 | 判据 |
|---|---|---|---|
| **无形资产（IP 组合）** | **中** | **单 IP 层：变窄；组合层：稳定** | THE MONSTERS −7.5%、手办品类 +0.3% 是单 IP 衰减的实证；但 6 个十亿 IP / 11 个亿元 IP 是组合层的分散度提升。**分散只能削峰，不能去波动**（见 [§6.3](thesis.md)） |
| **成本优势** | 弱 | 稳定 | 毛利率 69.7% 来自 IP 溢价与直营渠道，不是成本结构 |
| **切换成本** | 弱 | 稳定 | 消费者随时可切到 TOP TOY / 52TOYS |
| **网络效应** | **中** | **稳定** | 8,244 万会员 + 92.9% 会员销售占比 + 51.6% 复购率 + 艺术家签约网络（爆款 → 吸引艺术家 → 更多爆款）。**这是最真实的一条** |
| **效率规模（自有分发）** | **中强** | **稳定，海外线下仍在加宽** | 676 店 + 2,827 机器人店，Funko / Mattel 不具备。海外线下双位数增长证明可复制 |

### 5.1 护城河归位：**一般护城河 / 窄护城河上沿，不是「稳固护城河」**

- **护城河未被摧毁**，但**其经济价值的载体正在从「单个超级 IP」向「需持续重建的矩阵」迁移**，而后者的合理倍数更低。
- **不能给「稳固护城河」的判据**：稳固护城河的定义是竞争优势可持续、**需求可预测**。
  一门需要每 18–24 个月重造一个爆款才能维持体量的生意，**不满足「可预测」**。
  Labubu 实测半衰期约 **18 个月**（+44.7 倍 → −88%）；星星人已重复同一形态。
- **平台层 vs 单 IP 层必须分开说**：
  - **平台层**（艺术家网络 + 676 店 + 8,244 万会员 + 复购率 51.6% + 海外线下双位数增长）——**趋势稳定甚至加宽**；
  - **单 IP 层**（THE MONSTERS −7.5%、手办 +0.3%、Labubu 二级 −88%）——**趋势明确变窄**。
- **该给平台溢价吗？** 支持溢价的硬证据确实存在（会员 / 复购 / 自有分发 / 69.7% 毛利率）。
  **但溢价的兑现条件是「下一个星星人能按时出现」——这是一个每 18–24 个月要重新赌一次的条件，不是护城河的稳态。**
  **结论：给「一般护城河上沿」合理，给「稳固护城河」不合理。** 这直接决定 base 倍数 11.5x（见 [valuation.md §9.4](valuation.md)）。
