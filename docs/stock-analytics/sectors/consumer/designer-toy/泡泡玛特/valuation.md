### 9.1.1 为什么 TTM 不能当主锚（本轮最重要的口径裁定）

TTM（2025H2 + 2026H1）归母 = 82.01 + 50.38 = **RMB 132.39 亿**，PE-TTM 13.17x 看起来便宜。
**但这个分母的 82.01 亿（占 62%）来自 2025H2 —— Labubu 全球峰值的那一个半年**；且 TTM 同比 +95.3% 描述的是已经过去的爆发。
管理层已于 2026-08-20 自行撤回 20% 年度目标、定义 2026 为「经营调整年」。**用峰值分母算出来的便宜是幻觉。**

**本档主锚 = FY2026E 归母（前瞻），不是 TTM。** PS / PB / DCF / 资产法均不作主锚，理由：

- **不用 PS**：营收增速正在塌（+184.7% → +23.8%），PS 会把塌陷藏在分母里。
- **不用 PB**：PB 7.67x 对轻资产 IP 公司无意义，净资产主要是现金与**正在恶化的存货**。
- **不用 DCF 主锚**：IP 生命周期使终值假设不可靠（三丽鸥 2014 后连跌 7 年，正是 DCF 无法提前建模的形态）。
- **不用资产法主锚**：按 `buffett-doc-spec` §3 准入判据，资产法主锚需同时满足 bull < base **且** 资产法托底；本标的 bull > base（见 9.4 单调性自检）、隐含 ROE 44%~57%（见 9.5），两个条件都不满足。

## 9.4 倍数框架合规性（兄弟档安踏体育口径：每档明写是否破框架）

**Buffett 倍数框架**：宽护城河 + 5% 增长 **20–25x**｜稳固护城河 + 3–5% 增长 **15–20x**｜一般护城河 + 低增长 **10–15x**｜窄护城河 + 竞争威胁 **8–12x**｜周期性/衰退型 **<8x**。

| 档 | 倍数 | 框架归位 | 是否破框架 | 为什么不给更高 |
|---|---|---|---|---|
| **Bear** | **8.5x** | 「窄护城河 8–12x」**下沿**（与「衰退型 <8x」交界） | **未破框架** ✅ | bear 的定义就是护城河被证伪为 fad。给到 8.5x 而非 6–7x 的唯一理由是资产负债表：现金及等价物 124.4 亿 + **零银行借款** + 资产负债率 24.9%，占 bear 内在价值 850 亿的 14.6% |
| **Base** | **11.5x** | 「窄护城河 8–12x」**上沿**（亦落在「一般护城河 10–15x」下半区） | **未破框架** ✅ | **这是本档最需要诚实交代的一格。** 旧档给 13x，本档下修至 11.5x，理由不是结果导向：① 一门需要每 18–24 个月重造一个爆款才能维持体量的生意**不满足「可预测」**，不是稳固护城河；② base 的增长中枢约 0%，不是 +3–5%；③ 同业锚（口径限制见 9.6）：Mattel 8.33 / 名创 ~10 / Bandai 16.1 / Hasbro 16.28 / Sanrio 24–28，11.5x 落在名创与 Bandai 之间——泡泡玛特毛利率 69.7% 远优于 Hasbro/Mattel（40–50% 量级），故不应低于名创；但盈利可预测性明显差于 Bandai/Hasbro 的数十年长青 IP，故不应给到 16x |

> **框架合规自检**：8.5 / 11.5 / 15.0 **三档全部落在 buffett 框架内，无一档需要破框架才凑得出「像样」的每股价值 ✅**，
> 故不触发 spec §3 的「隐含 ROE 回查 → PB 阶梯重排」路径。
