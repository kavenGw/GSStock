**三句话**
1. **Bear 30%**：反向硬证据合力最强——营收 miss −14.0% / 归母 miss −24.4%、管理层**自行撤回** 20% 指引并自评 2025「一美遮百丑」、存货同期口径 **83 → 201 天（+142%）**、杰富瑞目标价已降至 146（低于现价）。**但不给更高**：剔汇兑后干净归母 +25.3%~+29.3% 与营收增速匹配，「经营性恶化」证据不足。
2. **Base 55%**：一轮正常化下台阶，不是崩塌。毛利率仅降 0.6ppt 至 69.7%（定价权未伤）、费用率未失控、海外**线下**双位数增长证明实体零售模型在海外未被证伪；但增长质量拐点已发生（归母 +10.14% < 营收 +23.76%），单一新 IP 扛 **68%** 增量。
3. **Bull 15%（封顶）**：四条门控无一解除（(a) 进行中 / (b) 方向已验体量未验 / (c) 有新闻无数字 / (d) 新授权回购执行情况【缺-检索失败】）。**须明记一笔——(b) 的松动是自旧档以来 bull 证据强度首次净增加，但它降的是 bear 左尾，不是抬 bull 天花板。**

**本轮最有解释力的一条**：**不是海外扩张失败，是线上渠道崩塌。** 海外 −11.1% 全部来自线上（亚太 −39.8%、美洲 −45.6%、Shopee −62.1%；**线上占海外收入 45.8%**，一个占近一半的渠道塌掉 40% 量级正好解释整体 −11.1%），
而线下反而增长（亚太 +16.2%、美洲约 +20%，门店 64 → 86 家）。因果链起点是公司 2025 年把 Labubu 月产能 1,000 万扩至 5,000 万只**自毁稀缺性**。
双面解读见 [thesis.md §6.1](thesis.md)。

> ### ⚠️ **本档最重要的一级触发器：H1'26 经营现金流「尚未披露」，不是「找不到」**
> 香港**中期業績公告结构上不含现金流量表**（2025 年同类文件 40 页全文「現金流量」出现 0 次）；现金流量表只在完整《中期報告》里，
> 按上市规则须于期末后 3 个月内刊发 → **最迟 2026-09-30 公开**。**这是本档的一级触发器，不是证据缺口。**
> 为什么它最要紧：**存货同期口径 H1'25 22.74 亿 → H1'26 61.02 亿 = +168.4%，而营收仅 +23.8%——存货增速是营收的 7.1 倍**，
> 与周转 83 → 201 天两条独立路径互证。**恰在这个半年，利润含金量只能等 9/30。**
> 年度代理：FY2025 OCF 108.65 亿 / 归母 127.76 亿 = 85.0%、capex 9.85 亿（占营收 2.7%，轻资产实证），**但明确不可外推至 H1'26**。
> 同时须说明证据等级：**H1'26 数字为多源转述互证**（2026 中期業績公告原文因 IP 限流未取到）；**H1'25 对照数字为港交所公告 PDF 一手原文**（A1 二次收工已成功下载并解析 2025 年中期業績公告 40 页原文，H1'25 的政府补助、汇兑、存货、现金三项拆分、分部与渠道数据均系一手）。**本档不谎称核过 H1'26 原表。** 完整清单见 [sources.md §12.2](sources.md)。

**买点（三条件，必须同时满足）**

   **现价 153.000 距第一档还有 −40.9%，距买点还有 −51.3%。**

   (b) 除 THE MONSTERS 与星星人外，**再有第三个 IP 半年营收突破 15 亿**（矩阵化不是一次性事件）；

> 单纯的价格下跌不构成买入理由——**跌下来的可能是价格，也可能是价值。**

**卖点（若持仓，四条任一触发）**
1. 存货周转天数 **>240 天**（当前 201，同期对照基数 83）——滞销转为实际减值。
2. 连续两个半年期**无任何单一 IP 半年营收新增放量到 15 亿**——矩阵化停摆、爆款空窗。
3. 中国内地同口径会员复购率**跌破 48%**（当前 51.6%）——需求底座塌陷的先行指标。
4. 管理层开始频繁切换「调整后」口径掩饰下滑，或出现大额增发 / 收购——诚信与资本配置红线。

### 11.1 lens 专项监控（命中三份逐条落地）

**x-growth（主）**
- **扩产达产证伪**：美洲门店 +34% vs 线下收入约 +20% → **单店产出方向性下滑**（幅度不可硬核，**「−35%」无源禁用**）。连续两期线下单店产出下滑即判达产失败。
- **终端兑底下修**（无 B 端具名客户，按 lens ② 降级）：中国内地会员半年净增（当前近 +1,000 万 / +13.6%），跌破 **+600 万** 判客户增长引擎熄火；会员复购率跌破 **48%**（当前 51.6%）。
- **增长质量恶化**：营收增速连续两期放缓**且**毛利率同步走弱——**本期已同时发生**（+184.7% → +23.76%、72.1% → 69.7%），需盯是否延续。毛利率跌破 **67%** 判定价权受损。
- **同业供给集中释放**：TOP TOY 2026Q1 +51.4%（**增速高于泡泡玛特国内 +47.3%**）、纽约时代广场首店、二次递表港交所；52TOYS 转 ToC。**真正的威胁不是份额被抢，而是整个潮玩品类需求周期同步回落。**

**x-dividend-value（辅）**
- **分红削减风险**：FY2026 末期股息（2027-03 宣派）——**股息是峰值盈利的函数**（FY2023 HK$0.2821 → FY2024 HK$0.8146 → FY2025 HK$2.3817），FY2026E 归母 105 亿 < FY2025 的 127.76 亿，末期息大概率同步下修。
- **当前 trailing 股息率 1.79%、2026 中期不派息、派付率 25.0%（低派息高留存）——不构成任何收益率支撑，不可作估值下界**（[valuation.md §9.6④](valuation.md)）。
- **股东回报按回购下限 20 亿元（≈23.4 亿 HKD，市值 1.15%）保守取值**，且**一次性 6 个月授权不可永续外推**。

**x-ai（仅识别）**
- 产品层与业绩层**均判【蹭概念】、零 AI 敞口**，**不入任何一档 owner earnings 基础**。
- **反向监控**：名创优品已设 AI 创新部并规划人形机器人 YOYO【软】——若「IP + AI 智能体化」跑出实质产品并获市场验证，泡泡玛特的「不参与」将从「省下 capex」变成「让出赛道」。
