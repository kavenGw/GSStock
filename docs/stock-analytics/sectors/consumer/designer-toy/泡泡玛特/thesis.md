## §6 核心新论点

### 6.1 本轮最有解释力的因果链：**不是海外扩张失败，是线上渠道崩塌**（双面写实）

旧档与卖方的主流归因是「海外扩张失败 / 单店产出大幅下滑 / 美洲开店为负 ROIC」。
**A1 的分渠道拆解把这条归因整体证伪了**，正确的机制是一条链：

```
2025 年 Labubu 月产能 1,000 万 → 5,000 万只（公司为兑现当期收入主动放量）
      ↓ 稀缺性被自己消耗
二级市场崩塌：3.0「前方高能」隐藏款「本我」原价 99 元 → 4,522 元（+44.7 倍，2025-06）→ 540 元（2025-12，−88%）；
              「坐坐派对」1,478 → 约 632 元（−57%）；部分款跌破官方价；黄牛 2025-12-31 公开暂缓收购（热搜第一）
      ↓ 转售套利空间消失 ⇒ 投机性囤货需求归零
海外【线上】渠道塌方：亚太线上 −39.8%、美洲线上 −45.6%、Shopee −62.1%
      ↓ 而同一个半年
海外【线下】门店收入增长：亚太 +16.2%、美洲约 +20%（门店 64 → 86 家）
```

**这条链同时解释了三件原本被分开归因的事**：海外收入转负、**存货同期 +168.4%**、周转 83 → 201 天
（为 5,000 万只月产能配置的渠道库存，在投机需求消失后无处可去）。

**两条定量支撑（均来自 A1 二次收工取得的 2025 年中期業績公告 PDF 原文，一手）**：
1. **海外线上占海外收入 45.8%**（H1'25 口径 25.61 / 55.93 亿）——**一个占海外近一半的渠道塌掉 40% 量级，正好解释海外整体 −11.1% 而线下仍双位数增长**。
   这条比任何定性表述都有力：它说明 −11.1% 不是「全面失速」，而是「一条腿被打断、另一条腿还在跑」。
2. **存货 H1'25 22.74 亿 → H1'26 61.02 亿 = +168.4%**，同期营收仅 +23.8%，**存货增速是营收的 7.1 倍**，与周转 83 → 201 天（+142%）**两条独立路径互证**。
   ⚠️ 媒体与旧档常用的「2025 年末 54.73 亿 → 61.02 亿 = +11.5%」是**跨季节对照，把问题缩小了整整一个数量级，本档全档禁用**。

#### 【空头侧】这是本轮对空头最有利的量化证据

线上 −40% 量级的整段塌陷，**第一次把「投机性需求占总需求的比重」量化出来了**——而且有了分母：**线上原本就占海外收入的 45.8%**。

**本轮最硬的单条负面证据是存货，不是收入**：**H1'25 22.74 亿 → H1'26 61.02 亿 = +168.4%**，营收仅 +23.8%，**存货增速是营收的 7.1 倍**。
**但必须把风险放对位置**：它现在是**资产负债表事件，不是利润表事件**——H1'25 存货跌价计提原文仅 **0.043 亿**，即便旧档「+430%」属实，H1'26 也只约 0.23 亿 = **归母的 0.45%**。
**旧档抓错了科目。** 真正的风险路径是：**这 61 亿货未来若被迫打折清理，才会在利润表上兑现**——所以它属于**前瞻性触发器**，也正是 bear 情景 30% 减值假设的来源，而非对已披露计提的外推。
线上正是转售投机的主要承接渠道（低摩擦、可批量、可秒杀），它整段消失而线下同店仍增长——
**这等于做了一次天然实验，分离出了投机需求与真实零售需求。**
旧档空头论点「海外从地理对冲反转为 **Labubu 敞口放大器**」因此不但成立，**而且机制被彻底坐实**：
COO 司德在业绩会承认，去年海外扩张主要由 Labubu 驱动，**大量新国际客户对公司其他角色几乎一无所知**【硬】。
**海外客户结构 = 单 IP 客户结构。**

#### 【多头侧】剥掉投机层后，真实零售需求仍在双位数扩张

**线下同店在增长，而且是双位数，且发生在跌幅最深的美洲。** 这说明**实体零售网络的海外复制能力没有被证伪，被证伪的只是线上炒作流量。**
这是旧档、A2 初稿、A3 初稿**三处共同的误判**，本轮全部撤回。

#### 【净判断】地板更结实了，天花板没抬高

- 线上塌掉的那部分收入**大概率不会回来**——它对应的是已经消失的套利空间，不是周期性走弱。
- 因此**不能用「线下增长 + 线上复原」两段相加**来推演恢复路径，只能靠线下单条腿把一个曾占 38% 收入的 IP 峰值填回来，**这需要很多年**。
- **对估值的含义：分子的「地板」更结实（bear 由 49.01 上修到 74.61），「天花板」基本没动（bull 164.10 → 171.17）。** 见 [valuation.md 变化清单](valuation.md)。

#### 必须同时写明的两条限制

1. **「美洲单店产出 −35%」无源，本档禁止引用。** 可确认的只有方向：美洲门店数 **+34%** 远超线下收入增幅（约 +20%），**单店产出必然显著下滑**；
   新店爬坡期属正常，但也可能是稀释。幅度不可硬核。
2. **分部 ROIC 无公开口径可验**——公司未披露美洲分部的资本开支、租金人力成本与分部经营利润，**不得断言正 ROIC 或负 ROIC**。

### 6.2 星星人：是补位为主、增量为辅，不是「叠加」

| IP | 2026H1 | 2025H1 | 同比 | 占比变化 |
|---|---|---|---|---|
| THE MONSTERS（含 LABUBU） | **44.54 亿** | 48.14 亿 | **−7.5%** | 34.7% → **26.0%** |
| **星星人** | **26.50 亿** | 3.89 亿 | **+580.6%** | → 15.4% |

**算术**：集团总增量 = 171.73 − 138.76 = **32.97 亿**；星星人贡献增量 = 26.50 − 3.89 = **22.61 亿**
→ **单一新 IP 扛起集团总增量的 68.6%**。

- **补位的证据**：最大 IP 占比从 34.7% 降至 26.0%，表面像「矩阵化降低单 IP 依赖」，
  **但这是用一个新爆款替换旧爆款，不是分散**。真正的矩阵化应是「无单一 IP 贡献增量 >30%」，当前是 **68%**。
  **依赖对象换了，依赖结构没变。** 二级市场同向佐证：2026-01 起星星人价格**反超 Labubu**——同一批消费者的预算与注意力在**转移**，不是新增。
- **增量的反驳点（必须保留）**：中国内地 **+47.3%** 说明基本盘有**真实增量**，「纯补位」是上界表述。
  **严格说法：以补位为主、增量为辅。**

### 6.3 矩阵化是**损失缓释**，不是**波动消除**

- 硬证据只到**分散度**这一层：6 个 IP 破 10 亿、11 个 IP 破亿【硬】。**它证明的是分散度，不证明各 IP 的周期不相关。**
- 实测反证：Labubu 走完 +44.7 倍 → −88% 的约 **18 个月**曲线；而**星星人在同一品类逻辑下已重复同样形态**——
  首日冲高近千元后腰斩，批次溢价 **3.2× / 6.8× / 10× / 14×** 剧烈跳动。**同机制驱动的 IP 高度相关，分散只能削峰、不能去波动。**
- **结论**：矩阵化把公司级衰减从 Beanie Babies 式**断崖**改造成三丽鸥式**多年下坡**——
  **这值得比 Beanie Babies 高的倍数，但不值得「平台股」溢价。** 这正是 base 倍数给 11.5x 而非 15x 的直接理由（见 [valuation.md §9.4](valuation.md)）。
- **反驳点**：若内容化（乐园 / 索尼影业电影）真跑通，IP 周期可被内容拉长、相关性才可能下降。**但该路径当前全部【缺】数字，不构成反驳。**

### 6.4 利润 miss 远大于营收 miss，差额主因是**非经营性汇兑**

| 指标 | 实际 H1'26 | 一致预期 | miss |
|---|---|---|---|
| 营收 | **171.73 亿（+23.76%）** | 199.8 亿 | **−14.0%** |
| 归母净利 | **50.38 亿（+10.14%）** | 66.4–66.7 亿 | **−24.4%** |
| 经调整净利 | 51.6 亿（+9.5%） | 66.7 亿 | −22.7% |

- 差额主因：**汇兑损失 RMB 7.20 亿**（2025H1 为收益 1.2 亿，**摆幅 −8.4 亿**），属非经营性。
- **剔汇兑后的干净归母 = 55.8~57.6 亿，干净同比 +25.3%~+29.3%，与营收 +23.76% 基本匹配。**
- 毛利率仅降 0.6ppt 至 **69.7%**；销售费用 **+23.1%** 与营收 +23.76% 同步，**费用率未失控**。
- **裁定：「经营性恶化」证据不足。真实恶化点在存货周转与海外线上，不在利润率。**
- **反驳点（空头必须拿到的）**：经调整净利（已剔汇兑口径）仍只有 **+9.5%**，且较市场预期低 22.7%——
  汇兑只能解释表观利润的**一部分**；且**归母 +10.14% < 营收 +23.76%**，说明增长开始需要费用去买，**增长质量拐点已是已发生事实，不是未来风险**。

### 6.5 管理层自行撤回指引：本轮最硬的单条增速证伪信号

王宁（2026-08-20 中期业绩会，全部【硬】）：
- 「今年**大概率无法完成**年初制定的 **20% 营收增长目标**。」
- 「今年有没有比去年业绩压力更大，我想肯定是更大的；**下半年会不会更大，我相信也会更大**。」
- 2026 是「**经营调整年**」，「坦白讲，今年我们的重心并非追求高速销售增长」。
- 自评 2025：「**一美遮百丑、问题很多的一年**。」
- 海外开店新原则：「**质量要远大于数量**」；欧洲重新审查全部计划门店、部分直接放弃，达不到要求「宁可等」。

**credibility 对照（管理层可信度的双面）**
- **正面（坦诚度高）**：愿意公开说「一美遮百丑」；Non-IFRS 只加回股份支付、**不剔除对自己有利的汇兑损失**（保守披露）。
- **负面（预测准确度低）**：年初给 20% 指引、8 个月后自行撤回；2025 年把 Labubu 月产能 1,000 万扩到 5,000 万只追逐当期收入、2026 又反过来踩刹车控量。
- **推论**：空头唯一能被反驳的那条逻辑——「2026 的 E 是公司**主动压低**的，不应作正常化基准」——
  要求投资者**接受管理层的意图陈述作为估值输入**，而同一位管理层刚刚承认上一年「一美遮百丑」。
  **本档不给这条辩护任何估值溢价，只等实测。**

### 6.6 股东回报的定性翻转：从「高分红」到**低派息高留存**（x-dividend-value lens）

| 项目 | 事实 |
|---|---|
| FY2025 末期股息 | **RMB 2.3817/股、总额约 31.94 亿**，2026-05-13 股东大会批准、**2026-05-28 派付**（现金流落在 H1'26 内，**不是 2026 上半年的分红决议**） |
| **2026 中期股息** | **董事会决定不派付**（2025 中期亦未派，公司仅年度末期派息） |
| trailing 股息率 | **1.79%**（DPS 2.744 HKD / 153.00）——**纯 trailing，本期分子为零，前瞻性为零** |
| ⚠️「2026 中期不派息」的正确读法 | **不是新增利空，是惯例延续。** 2025 年同期公告附注 9 有**一模一样的措辞**（H1'25 派付 10.83 亿 FY2024 末期息，同一份公告写明不派中期息；第三方库「已付股息 10.83 亿」与原文附注「1,083,288 千元」完全吻合）。**公司惯例就是只派年度末期息、中期从不派**，本档不得把它当作恶化信号 |
| **派付率** | **25.0%**（31.94 / FY2025 归母 127.76），含回购口径 **36.7%**。**「52%~75%」口径错配（分子全年、分母半年），已推翻** |
| 回购 | 2026-08-20 宣布 6 个月内 **RMB 20–50 亿**（**是人民币不是港元**），**全部注销**，占市值 1.15%–2.87%；**新授权下的执行情况【缺-检索失败】**（见下方双面必答①） |

**双面必答（lens 逐条）**
1. **是否可持续？**【支持】现金及等价物 124.4 亿 + 零银行借款 + 资产负债率 24.9%，20 亿下限回购完全由内生现金流覆盖，不是借债分红。
   【反驳】① **支付能力 ≠ 支付意愿，而且这一条要用两句话才说得完整**：
   **第一句——公司有真实的回购执行历史。** 2026 年 1–4 月累计回购约 **17.44 亿 HKD**（1 月约 3.48 亿；3/26–4/2 连续 6 个交易日约 13.97 亿，
   其中 **3/26 单日 5.99 亿**、**3/30 斥资 1.99 亿回购 134 万股、价区间 144.3–153.5 HKD**），并已注销 1,122 万股。**这不是空头支票公司。**
   **第二句——但这些全部发生在 08-20 新授权之前。** 08-20 宣布的 RMB 20–50 亿新授权窗口内，港交所《股份购回报告表》按规定应于回购次营业日披露，
   而本轮**未检索到任何一份，且港交所检索受限**（A1 扫描 hkexnews 编号空间触发 IP 限流、整站 403）——
   **故只能记为【缺-检索失败】，不得写成「零执行」结论，更不得把新回购写成估值下界支撑。**
   旁证（媒体零报道；09-01 起收盘价窄箱体、日均成交仅 7.7M 股，若真有 23–58 亿港元回购在跑难以不留量价痕迹）**倾向尚未执行，但仅是旁证**。
   **两句并读才是完整证据：公司在 3 月能一天砸 5.99 亿、在 144–153 的价区间大举买入，如今股价 153.000 落在同一区间，——**能力已被证明，意愿则要等新授权下首份《股份购回报告表》来回答。这是最易验证的言行一致性活体测试，也是本档的触发器写法。**
   ② 回报池是「上一财年利润」的函数，FY2026E 归母 105 亿 < FY2025 的 127.76 亿，**FY2027 的回报池会缩水**；③ 2027 年乐园二期 capex 启动将分流现金。
2. **是否在补偿增长缺失？** **是，且公司自己承认。** 管理层在业绩明显不及预期的**同一天**宣布大额回购——**这是防御性资本配置，不是价值股的稳态派息。**
3. **股息率高是否因股价暴跌（价值陷阱信号）？** **不适用**——本标的股息率只有 1.79% 且本期归零，**根本不构成收益率支撑**，谈不上「股息率被跌出来」。
   真正的价值陷阱信号在别处：**同一价格 ÷ 更低的 E ⇒ 估值被动扩张**（见 §8.2）。

## §7 AI / 概念潜力

**本标的无 subsector 专用 lens**——`references/lenses/` 现有 12 份板块专属 lens 覆盖金属、半导体、PCB-CCL、光纤光缆，
**无 designer-toy / 潮玩 / 消费 IP 类 lens**。本档命中的是横切三份：x-growth（主）、x-dividend-value（辅）、x-ai（仅识别）。

| 维度 | 判定 | 理由 |
|---|---|---|
| **AI 产品层** | **【蹭概念】** | 主营为潮玩 IP 设计、生产与零售，**未找到任何 AI 产品 / 在研 AI 品类的公开披露**【缺】 |
| **AI 业绩层** | **【蹭概念】** | **AI 相关营收 = 0**，公司从未把任何增长归因于 AI【缺】 |
| **AI 作为竞争威胁** | **【真敏感，但是反向】** | 名创优品已设 AI 创新部并规划人形机器人 YOYO【软】——若「IP + AI 智能体化」跑出实质产品，泡泡玛特的「不参与」将从「省下 capex」变成「让出赛道」。**这是风险项不是机会项**，落 [§11 监控](index.md) |

> **红线 5 执行**：产品层与业绩层**均为零敞口**，**不得进入 §9 任何一档的 owner earnings 基础**。
> 若未来出现 AI 玩具 / 智能陪伴品类（行业方向确实存在），需重新识别。**本轮不深挖。**

## §8 周期定位：周期顶，还是结构性新台阶？

### 8.1 判定：**这是周期顶之后的正常化下坡，不是结构性新台阶**——但下坡的形态是三丽鸥式而非 Beanie Babies 式

| 正向信号（支持「结构性台阶」） | 反向信号（支持「周期顶回落」） |
|---|---|
| 中国内地 +47.3%，基本盘加速 | 集团增速 +184.7% → **+23.8%**，一年降 161ppt；**Q2'26 单季约 −5%~−6%**【软-推算】 |
| 毛利率仅降 0.6ppt 至 69.7%，定价权未伤 | 归母 +10.14% **低于**营收 +23.76%，增长开始需要费用买 |
| 海外**线下**双位数增长，实体网络复制能力未被证伪 | 海外整体 **−11.1%**，2025 年的唯一发动机熄火 |
| 6 个十亿 IP / 11 个亿元 IP，分散度真实提升 | 单一新 IP 扛 **68%** 增量；THE MONSTERS **−7.5%** |
