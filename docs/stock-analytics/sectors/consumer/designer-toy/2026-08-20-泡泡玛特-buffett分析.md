## §0 结论摘要（倒金字塔）

**新评级：watch（维持，未翻转）。** 相对旧档 2026-06-20 的 watch，本次以**首份反映 Labubu 退潮的完整半年报**重审——旧档的「峰值盈利论」被证实，旧档的「平台接棒未证实」被**部分推翻**（Twinkle Twinkle 已跨越旧档自设的证伪线），旧档的「海外是地理对冲」被**推翻**（海外收入首次同比转负），三者相互抵销后评级维持 watch，但**安全边际从 −42~−48% 收窄到 −30.5%**，价格已明显更接近价值。

**期望内在价值 = HKD 106.90/股**（场景加权，穿越峰值正常化口径），对应**市值 HKD 1,423.6 亿**（÷13.31723 亿股）。

**三情景（概率/每股内在价值 HKD）一句话**：
- **Bear 30%｜HKD 49.01**：Q2 转负的非节奏性成分兑现为持续性退潮，THE MONSTERS 继续下滑而无等量接棒、海外线上不回补、存货跌价常态化 → 正常化 owner earnings 回落到 RMB 70 亿 × 8x（周期性/衰退型上沿）。
- **Base 55%｜HKD 122.88**：剔汇兑后经营与营收同步（+24.0%）这一事实成立、中国大陆 +47.3% 基本盘继续、海外在低位企稳但不再是引擎 → 正常化 owner earnings = H1'26「干净」归母年化 RMB 108 亿 × 13x（一般护城河 + 低增长的上沿）。
- **Bull 15%｜HKD 164.10**：IP 矩阵化被反复验证、海外从线上转线下重建成功、乐园/影视内容飞轮起步 → 正常化 owner earnings RMB 125 亿 × 15x（稳固护城河区间 15-20x 的**最下沿**）。**bull 门控三要素无一项为硬证据，故概率封顶 15%、倍数不给上半区。**

**安全边际（对 2026-08-20 收盘 153.70）**：(106.90 − 153.70)/153.70 = **−30.45%**。
**价格敏感度带**：即便次日向下跳空 −10%（138.33）安全边际仍为 **−22.72%**；跳空 −20%（122.96）仍为 **−13.06%**；**要出现正安全边际，价格需跌破 106.90，即较现价再跌 30.4%。**
**bull 压力测试**：最乐观的 bull 内在价值 164.10 相对现价仅 **+6.76%** —— 即便押注最乐观情景全部兑现，折价也只有 6.8%，远达不到「存在不确定性因素需 40-50% 折价」的纪律要求。

**一句话**：这是一门真正漂亮的生意（69.7% 毛利、29.3% 净利率、零银行借款、净现金 141.64 亿、8,244 万会员），本期财报也证明了平台能再造爆款；但它同时证明了每个爆款的经济价值在衰减，而当前价格在 base 倍数下**隐含的正常化利润是 RMB 135.1 亿——比公司历史上最高的 TTM 峰值 132.40 亿还要高**。好公司，不是好价格。

## §1 能力圈 & 本次重审触发 & 相对旧档变化清单

### 1.1 能力圈判定：边缘地带（与旧档一致，不上修）

商业模式在圈内、一句话讲得清：签约艺术家 → 孵化形象 IP → 盲盒/毛绒化高毛利零售 → 门店 + 机器人商店 + 线上 + 全球扩张 + 会员复购。但巴菲特铁律「10 年后会不会更强」在潮玩品类上天然难答——这是消费品里历史上最不耐久的品类（Beanie Babies 从 14 亿美元营收崩到接近零）。**本期财报给了这条铁律一次真实的压力测试，并给出了一个比旧档更微妙的答案（见 §6.1）：平台能造新爆款，但新爆款的半衰期在缩短。**

**反演检查（这笔投资可能怎么亏钱）**：
1. **正常化 E 下台阶而 P 不跟随** —— 现价对应的 PE 13.27x 分母是含 H2'25 峰值的 TTM 盈利；若 FY2026 归母落到 A1 测算的 112.9~126.1 亿，PE 被动抬到 13.9~15.7x，「便宜」蒸发。这是最大概率的亏损路径。
2. **爆款接力出现空窗** —— Twinkle Twinkle 这次接住了，但下一次不一定有；一个空窗半年就足以让营收与利润同时下台阶。
3. **存货 201 天转化为减值** —— 存货 61.02 亿、周转天数从 123 天飙到 201 天、当期跌价计提同比 +430%，而海外收入同期 −11.1%（备货理由与事实相悖），这是资产负债表上已经点亮的黄灯。

**时间尺度**：本档一律用 10 年持有视角评估，不回答「明天会不会跳空」——但因价格锚的特殊性（见免责），§9.6 给出价格敏感度带。

### 1.2 本次重审的 4 个新变量（相对旧档 2026-06-20）

1. **旧档 §12 局限 #1 已被补上**【硬】：旧档明写「2026 H1 半年报 8 月才出——本次重做时点尚无 H1 完整业绩，退潮对 H1 营收的实际拖累只能外推」。**本档正是补上这个缺口**：44 页公告原文提供了分地区、分渠道、分 IP、分品类、门店、会员、存货、现金流的全部拆分。旧档所有基于外推的判断，本档一律以公告原文替换。
2. **公司首次书面承认核心 IP 退潮**【硬】：公告原文 *"The popularity of the core IPs returns to normal levels and the general traffic and customer acquisition capabilities of online channels remain under development."* —— 这不是媒体转述，是公司在经审阅的公告里对美洲线上下滑的官方归因。
3. **海外收入首次同比转负**【硬】：海外合计 49.72 亿（−11.1%），占比从 40.3% 掉到 29.0%，崩塌 100% 发生在线上（海外线上 −44.0%），而海外线下 +20.8%（但门店同比增 105 家，单店产出大幅下滑）。
4. **Q2'26 单季营收已同比转负**【推算，确定性高】：由「Q1'26 官方 +75~80%」+「H1'26 官方 +23.8%」两个硬数字直接推出——**海外三大区 Q2'26 全部负增长是数学必然，对任何假设都不敏感**；集团口径 Q2'26 约 −5% ~ −18%，中枢 −11%。**这直接命中旧档写死的卖出触发器，本档必须裁定（见 §6.2）。**

### 2.3 跑道判定（相对旧档下修一档）

旧档：「地理空间是真实跑道、属中性偏正证据」。
**本档：跑道（物理渗透空间）是真的，但 2025 年那条陡峭的斜率是假的。**

理由是本期给出的一组极其锋利的对照：**美洲门店从 41 家（2025-06）增到 86 家（+110%），而美洲零售店收入只从 7.37 亿增到 9.03 亿（+22.5%）—— 单店产出大幅下滑。** 同期美洲线上 −45.6%。这说明海外的「渗透率提升」在 2025 年被单一 IP 的一次性流量 + 线上冲动消费透支了一部分：**门店可以继续开，但新开的门店产出远不及老店，跑道的坡度已经变缓。**

> **双面必答（成长 lens）——扩张是结构性需求支撑还是赌景气？** 最强反驳前置：**本期的开店是「赌景气」成分明显大于「结构性需求支撑」**。判据有三：(a) 海外门店同比净增 105 家而海外收入 −11.1%；(b) 存货周转从 123 天飙到 201 天、官方解释为「为海外市场扩张提前备货」，而海外收入同期是负的；(c) 租赁相关费用 +43.3%、销售人员从 6,219 增到 9,734 人（+56.5%），这些是**已经固化的成本台阶**。反面则是：中国大陆门店只净增 10 家而收入 +47.3%，说明中国区的增长**不靠开店**，是同店与线上驱动的高质量增长——这条把「赌景气」的指控限制在海外，而非全公司。

**剔除后的「真实」增速**【推算】：
```

```

**债务安全性最坏情景测试（营收 −30%）**：营收降至约 283 亿、毛利率退到 66% → 毛利约 187 亿；固定成本侧最刚性的是租赁（H1 年化约 21 亿）+ 员工（H1 年化约 16 亿）。即便净利率压到个位数，**公司仍有 141.64 亿净现金、零银行借款、24.9% 资产负债率**——**这是本案最没有争议的一项：财务上完全不存在生存风险，公司有充足时间穿越退潮。** 这也是 bear 情景不给到「周期性/衰退型 <8x」下沿的核心理由。

## §6 核心新论点

> 本节正面回答三个问题：① 「IP 矩阵化已被验证」与「单 IP 经济价值在衰减」如何同时成立；② Q2 已转负是否「非节奏性」；③ 市场在 PE 端与 PS/PB 端的互相矛盾定价，哪一端是对的。

### 6.1 论点一：**平台能造新爆款 ≠ 每个爆款的经济价值和持续时间不衰减**（本档灵魂）

旧档用的是「平台护城河 vs 爆款依赖」的二分法：要么平台能持续造爆款（多头），要么它只是运气好的单 IP 公司（空头）。**本期数据同时给出了两侧的硬证据，说明这个二分法本身是错的。**

**两组事实必须并置：**

| 支持「矩阵化已验证」 | 支持「单 IP 经济价值在衰减」 |
|---|---|
| Twinkle Twinkle 3.89 → **26.50 亿（+580.6%）**，多贡献 22.6 亿 | THE MONSTERS **−7.5%**，且是在史上最强曝光下 |
| 破亿艺术家 IP 从 8 个扩到 **11 个** | MOLLY **−33.6%**（20 周年） |
| CRYBABY/DIMOO/SKULLPANDA/HIRONO 全线 +27%~+47% | **手办品类 +0.3%**（剥离高基数因素后仍零增长） |
| 艺术家 IP 合计 **+25.0%**，占比 88.1%→89.0% | 其他 IP 衍生品 **−15.8%** |
| 会员 +986 万、同口径复购率 +0.8pp | 海外单店产出大幅下滑（门店 +110%、收入 +22.5%） |

**为什么两者能同时成立？** 因为它们描述的是**同一个飞轮的两个不同参数**：

1. **平台的「造爆款频率」没有下降** —— Molly（2016）→ SKULLPANDA/DIMOO（2020-21）→ Labubu（2024-25）→ Twinkle Twinkle（2026），孵化节奏甚至在加快，因为渠道（676 店 + 2,827 台机器人 + 8,244 万会员）本身就是一台放大器：**同一个新形象放在今天的渠道里，能比五年前更快、更大地起量。**
2. **但每个爆款的「峰值高度」与「峰值持续时间」在缩短** —— Labubu 的峰值高度是空前的（FY2025 单 IP 141.6 亿），但从爆发（2025 Q2）到财报级下滑（2026 H1）只用了约一年；MOLLY 从巅峰到 −33.6% 用了更长时间但同样在走。**渠道放大器是双向的：它让爆款起得更快，也让稀缺性被消耗得更快**——公司自己主动放量打黄牛（月产能拉到千万只级别）正是加速消耗的直接原因。

**经济含义（这才是估值口径上真正要紧的）**：
- 若「造爆款频率 ≥ 爆款衰减速度」，营收可以在震荡中维持甚至增长——这是 **base/bull 情景**。本期恰恰演示了一次成功的对冲（Twinkle Twinkle 填平 THE MONSTERS 缺口）。
- 若「衰减速度 > 造爆款频率」，就会出现空窗期，营收与利润同时下台阶——这是 **bear 情景**。
- **但即便在最好的情形下，这种模式的正常化利润率也应低于「一个长青 IP 稳态运营」的利润率**：因为它需要持续的新品投入、更高的营销/铺货费用、以及承担存货错配风险（本期存货周转 123→201 天就是错配的代价）。**这是 §9 把 base 倍数压在 13x 而非 15-18x 的核心理由——它不是一门「稳固护城河 + 3-5% 增长」的生意，它是一门「一般护城河 + 高波动」的生意。**

**最强反驳（前置，必须诚实）**：Twinkle Twinkle 的 26.50 亿有多少是「平台能力」、有多少是「Labubu 溢出的流量红利」？无法分离。公司 COO 司德 2026-05 的原话是「大批新晋用户对潮玩行业及品牌其他 IP 认知不足」——**如果新客不认其他 IP，那么 Twinkle Twinkle 的爆发更可能是中国大陆老客的内部轮动，而不是平台把海外新客成功转化。** 这条反驳与「海外收入 −11.1% 而中国大陆 +47.3%」的地理分布**完全一致**：矩阵化在中国大陆被验证了，在海外**没有**被验证。**本档采纳这条限定——§9 的 base 情景不假设海外矩阵化成功。**

### 6.2 论点二裁定：**Q2'26 单季转负，「非节奏性」成分占主导，旧档卖出触发器判定为已触发**

**事实条件（A1 裁定成立）**：
- **海外三大区 Q2'26 全部同比负增长是数学必然**，对任何假设都不敏感（由「Q1 增速为正 + H1 增速为负」直接推出）：美洲 −50% 以上、亚太 −25% 以上、欧洲亦转负。
- **中国大陆 Q2'26 从 Q1 的 +100~105% 骤降到 −8% ~ +11%。**
- **集团 Q2'26 营收同比转负，区间 −5% ~ −18%，中枢约 −11%**，确定性高（属【推算】，公司确无分季披露）。

**A1 明确把「是否非节奏性」的裁定移交给本档**（前件「单季营收同比转负」由 A1 判定成立；单季净利【缺】无法推算，故本档只裁定营收这一支）。

> ⚠️ **必须先说清一件事：这个裁定不能推迟。** A1 穷尽核查（中期公告 44 页 + FY2025 年度公告 48 页 + 2025 年年报 370 页 + 21 条公告）后确认，公司分部附注的时间维度**只有「六个月」一个粒度**，唯一的季度口径是自愿性的「第一季度最新业务状况」公告，**且只发 Q1、从不发 Q2/Q3**。**这不是偶发缺口而是固定披露体例——未来任何一期都不会有官方 Q2 数字。** 因此「等官方数据落定再判」在本案是一个**永不到来的条件**，必须在推算基础上决断。

**判定过程如下：**

**支持「节奏性（纯高基数）」的证据**：
1. **Q2'25 恰是 Labubu 全球爆发季**（第三代搪胶毛绒「Big into Energy」2025-04 全球发售），2025 Q1 海外 +475~480% 而 H1'25 海外增速更高，说明爆发主要落在 Q2 —— **这是一个极端到几乎不可比的基数。**
2. 海外的收缩几乎全部发生在**线上**（−44.0%），而海外线下同期 **+20.8%**、门店从 41 家增到 86 家 —— **供给侧仍在扩张**，属渠道结构性分化，不是全面需求塌方。
3. 公司主动去 fad 化（放量打黄牛）+ 主动收缩海外线上（官方口径：「线上渠道外部流量红利逐步消退，把业务从『规模扩张』转向『精细化运营』，平台整合聚焦更核心的渠道」）—— **部分收缩是自选动作。**

**支持「非节奏性（真实退潮）」的证据**：
1. **公司自己的书面归因是需求侧而非基数侧**：「核心 IP 的热度回归正常水平」——这是对**热度**的定性，不是对**基数**的解释。若纯属高基数，公司完全可以（也更愿意）写「上年同期基数较高」。
2. **手办品类 +0.3%** —— 手办不是 Labubu 毛绒的高基数品类，它在**正常基数**上仍近乎零增长。**这一条单独就足以说明退潮不限于 Labubu 的高基数区间。** 其他 IP 衍生品 −15.8% 同理。
3. **海外线下同店经济在恶化**：门店同比 +105 家（美洲 41→86，+110%）而美洲零售店收入仅 +22.5% —— **单店产出大幅下滑与基数无关**，是当期同店经济的直接恶化。
4. **资产负债表已经点亮黄灯**：存货周转 123 → **201 天**、存货跌价拨备余额 +43.3%、**当期计提同比 +430%**。存货是按需求预期备的，周转天数翻倍意味着**实际需求显著弱于公司自己的备货预期**——这是一个不受基数影响的绝对指标。
5. **官方对存货的解释与事实存在张力**：公司称「为海外市场扩张提前备货」，**但海外收入同期 −11.1%、海外三大区 Q2 全部深度负增长**。为一个正在萎缩的市场提前备货，只有两种解释：要么公司在 H1 初期仍误判海外会复苏（说明退潮超出管理层预期），要么这批货实际是常规备货而解释被美化。**无论哪种，都指向「需求弱于预期」，而不是「基数太高」。** 本档正面采用这一对质结论。
6. **中国大陆 Q2 的基数并不极端**：中国大陆 Q2'25 的基数远不像海外那样含 +475% 级爆发，而中国大陆 Q2'26 仍从 +100~105% 骤降到 −8% ~ +11%。

**裁定**：**两种成分都存在且无法用现有数据精确分离**（这一点必须诚实标注），**但「非节奏性」成分占主导**——判据是第 2、3、4、6 条，它们全部是**剥离了高基数因素之后仍然成立**的证据。

**对旧档卖出触发器的意义**：
- 旧档卖出线原文：「**单季营收或净利同比转负且非节奏性**」。**事实条件成立（A1 裁定）+ 非节奏性成立（本档裁定）→ 该触发器判定为「已触发」。**
- **但触发器的作用在本案是「阻断买入」而非「触发卖出」**：旧档评级为 watch（无持仓），故不存在卖出动作。它的实际后果是：**任何「等回调就买」的想法在这条触发器下失效**——买点必须重新按正常化 E 定价（§9），而不是按「跌够了就便宜」。
- **它也不足以把评级推到 exclude**，理由三条：(a) 中国大陆基本盘 +47.3% 仍在加速；(b) 剔汇兑后除税前 +24.0% 与营收同步，经营层面并未失速；(c) 净现金 141.64 亿 + 零银行借款给了公司充足的穿越时间。**「盈利下台阶」不等于「生意在腐烂」。**

### 6.3 论点三裁定：**PE 端与 PS/PB 端不是矛盾定价，而是「好生意 + 盈利正从峰值回落」的组合定价；PS/PB 端是对的，PE 端是分母幻觉**

**现象（A1 可比表）**：PE(TTM) 13.27x 已跌到可比组低端（仅高于名创 11.28、美泰 10.38），**但 PS 4.35x 与 PB 7.62x 仍是全组第二高**（仅次于三丽鸥的 7.18x / 8.92x）。

**裁定：这两端各自定价的是不同的东西，都没有错，错的是把它们放在一起读出「矛盾」。**

- **PS 4.35x / PB 7.62x 定价的是「资产与生意的质量」，而这个质量是真的**：69.7% 毛利率（全组第二，仅次三丽鸥 76.8%）、29.3% 净利率（**全组第一**）、零银行借款、141.64 亿净现金、8,244 万会员、676 家自营门店。**一门 29% 净利率的生意，PS 高于一门 8% 净利率的生意（迪士尼 1.87x、名创 1.01x）是完全正确的定价**——因为 PS × 净利率 = 1/PE，PS 高本就是高净利率的算术结果。
- **PE 13.27x 定价的是「盈利」，而这个分母是失真的**：TTM 归母 132.40 亿里含 H2'25 的 82.01 亿（占 FY2025 的 64.2%），那是 Labubu 全球爆发的绝对高点。**这个分母不是常态。**

**把分母换掉，「便宜」立刻消失**：

| 分母口径 | RMB 亿 | 对应 PE（@市值 RMB 1,756.29 亿） |
|---|---|---|
| TTM 归母（含 H2'25 峰值，**分母失真**） | 132.40 | **13.27x** |
| FY2026E 中性 + H2 无汇兑冲击（A1） | 126.07 | 13.93x |
| FY2026E 中性（A1） | 117.67 | **14.93x** |
| FY2026E 悲观（A1） | 112.92 | **15.55x** |
| **本档 base 正常化 owner earnings** | **108.00** | **16.26x** |
| **本档 bear 正常化 owner earnings** | **70.00** | **25.09x** |

> **一句话结论：「PE 13.27x 全组低端」是一个建立在峰值分母上的幻觉。按任何一个前瞻或正常化口径，泡泡玛特的 PE 都在 14–16x，即从「全组低端」回到「全组中位」——和孩之宝（16.66x）一个水平，而孩之宝的毛利率 63.8%、净利率 16.0%、增速个位数。**

**所以，这是估值底还是价值陷阱？**

**两个都不是，这是第三种情形。**
- 它不是**典型价值陷阱**——价值陷阱的定义是「生意本身在腐烂而报表尚未反映」。泡泡玛特的生意没有腐烂：剔汇兑后经营利润与营收同步增长、费用率改善、中国大陆加速、会员与同口径复购率改善、零负债。
- 它也不是**估值底**——因为按正常化 E，PE 就在 14–16x，谈不上底；而 PS 4.35x / PB 7.62x 更是明确的溢价定价。
- 它是**「一门好生意，盈利正在从一个不可重复的峰值往下走一个台阶，而价格只跌到了刚好反映『台阶存在』、还没跌到反映『台阶有多深』」**。市场已经把「不再是超级成长股」定价进去了（一年 −45.26%、PE 从 100x+ 杀到 13x），但还没有把「正常化利润是 108 亿而不是 132 亿」定价进去。

**这正是 §9 安全边际 −30.5% 的来源，也是评级维持 watch（而非 exclude、也非 core）的全部理由。**

### 6.4 论点四：海外角色反转 —— 从「地理对冲」到「Labubu 敞口的放大器」

旧档把「海外渗透是真跑道、美洲 +748.4%」列为核心多头支柱之一，并明确写「海外提供了 2022 时不具备的地理对冲」。**本期证据击穿了这条。**

| 事实 | 数值 |
|---|---|
| 海外合计 | **49.72 亿，−11.1%**（首次转负），占比 40.3% → **29.0%** |
| 海外线上 | 25.61 → **14.33 亿（−44.0%）**：Shopee −62.1%、美洲自营官网 −44.6%、亚太「其他线上」−58.2%、欧洲线上 −59.0% |
| 海外线下 | 26.45 → 31.94 亿（+20.8%），**但门店同比 +105 家，单店产出大幅下滑** |
| 港澳台零售店 | 7.58 → 6.62 亿（**−12.6%**）——**港澳台已随海外一起退潮** |
| 官方归因（2026-05 业绩会）【硬】 | 「新晋海外用户对潮玩 IP 认知不足，流量自然回落」；「大量新增海外员工业务积淀尚浅，导致销售回撤较大」 |

**判定：海外不是对冲，海外是放大器。** 管理层自己的归因把病因指向**获客质量**——2025 年的海外爆发有相当部分是 Labubu 引流带来的**低黏性新客**，热度退去后不复购。**这意味着海外的用户资产从来没有沉淀下来，退潮是一次「没有底座」的退潮。** 这是本档对旧档结构最实质的一处修正。

**双面必答（最强反驳前置）**：**海外线下 +20.8% 且门店从 571 家（2025-06）扩到 676 家的物理渗透没有任何倒退。** 公司主动放慢开店节奏、把海外从「爆款驱动」转向「品牌矩阵 + 渠道深耕」（司德，2026-05），是把增长引擎从「流量」换成「留存」的正确动作。**若 2027 年海外能在低位企稳并靠线下+会员重建，海外仍可能成为第二引擎——这正是 bull 情景的核心假设，也是它只有 15% 概率的原因：这个假设目前没有任何硬证据支持，只有管理层的定性表述。**

### 6.5 论点五：存货 201 天 —— 本期最刺眼的运营指标，且官方解释与事实存在张力

| 指标 | 2026-06-30 | 2025-12-31 | 2024-12-31 |
|---|---|---|---|
| 存货 | **RMB 61.02 亿** | 54.73 亿 | 15.24 亿 |
| **存货周转天数** | **201 天** | 123 天 | 102 天 |
| 跌价拨备余额 | 0.755 亿 | 0.527 亿（**+43.3%**） | — |
| 当期跌价计提 | 0.228 亿 | H1'25 为 0.043 亿（**+430%**） | — |

**官方解释**：*"mainly due to the inventory prepared in advance for overseas market expansion"*（为海外市场扩张提前备货）。

**对质**：海外收入本期 **−11.1%**、海外三大区 Q2'26 全部深度负增长。**为一个正在萎缩的市场提前备货，这个解释与事实存在张力。** 两种可能：(a) 公司在 H1 初期仍预期海外会复苏，实际退潮超出管理层自己的预期；(b) 这批货实际是常规备货，解释被美化。**无论哪种，都指向「实际需求弱于公司预期」。** 本档在 §6.2 的「非节奏性」裁定中已把这条作为核心判据之一。

**对偶的诚实（不能只说一半）**：
- 绝对额仍小：跌价拨备余额 0.755 亿相对 61.02 亿存货只有 1.24%，相对半年 50 亿的利润更是微不足道。
- **贸易应付 −51.3%** 与存货口径互证公司口径的一部分：2025 年末的集中大额备货高峰确实已结束。
- 品类结构变化本身会拉长周转：毛绒占比从 44.2% 升到 57.2%，毛绒的体积/SKU 数与备货周期天然大于手办。
- **但这些都不能解释 78 天的跳升**。且这是**连续第二年恶化**（102 → 123 → 201）。**本档把存货列为监控指标第一顺位（§11）。**

| 编号 | 论点 | 性质判定 | 用于 §9 |
|---|---|---|---|
| **P-1** | 平台造爆款频率未降，但单个爆款峰值高度与持续时间在缩短 | **结构性**（渠道放大器双向作用，不可逆） | base 倍数压在 13x 的核心理由 |

| **P-3** | PE 13.27x 是峰值分母幻觉，正常化后 14–16x | **算术事实** | 安全边际 −30.5% 的直接来源 |
| **P-4** | 海外从对冲反转为放大器，退潮无用户底座 | **结构性**（用户资产未沉淀） | base 不假设海外矩阵化成功 |

## §7 AI / 概念潜力

> **总判定：本案应从旧档的【蹭概念】进一步下修为「主动拒绝 AI」——泡泡玛特是本轮少见的、创始人公开表态拒绝 AI 化的消费标的。产品层 = 无（NONE）；业绩层 = 0（ZERO）。**

### 7.1 逐维度

**① AI 产品敞口**：截至 2026-08-20，未找到泡泡玛特发布或在研任何 AI 玩具 / AI 陪伴机器人 / AI 交互 IP 产品的公开证据。官方两次否认（跨 14 个月）：2025-06-09 对「进军 AI 玩具」传闻回应「没听说过」；后续公关部对同类传闻声明「目前真没这计划」。**未公开成立 AI 团队、未公开 AI 岗位招聘。**
→ **【蹭概念】**（严格说连蹭都没蹭——是主动拒绝）。理由：不存在任何可被称为 AI 的产品或研发线，谈不上敞口。

**② 创始人立场（本案最有信息量的一条）**：2025-11 周鸿祎当面建议王宁给产品加 AI（「能说会道、能唱歌，像智能音箱一样对话」），**王宁答「无用就是有用」**，明确拒绝。逻辑是怕未成熟技术损害 LABUBU 的品牌调性——在一门卖「情绪价值 + 收藏属性」的生意里，这个拒绝逻辑**可以自洽**。
→ **【蹭概念】**。理由：这是一个战略性的不参与决策，不是一个待兑现的概念。

**③ AI 终端市场的 TAM 与竞争格局（对本案属「未进入的相邻市场」，只作机会成本参照）**：中国 AI 玩具市场预计 2030 年突破 RMB 1,000 亿；全球 2034 年可能突破 USD 600 亿；2025 年 1–10 月国内线上 AI 玩具销售额 RMB 5.2 亿（+394.9%，基数极小）【软】。**两个口径不在同一统计边界，无法交叉验证；未找到权威机构对「AI 陪伴玩具」单列的 TAM【缺】。**
→ **【蹭概念】**。理由：泡泡玛特在该链节**没有份额、没有客户、没有认证**，TAM 再大也与它无关。

**④ 兑现节奏（放量时间表 / 在手订单 / 客户导入阶段）**：**不适用【缺】**——无产品即无时间表、无订单、无导入阶段。
→ **【蹭概念】**。

**⑤ 被抢跑风险（这是「主动拒绝」的真实代价）**：**名创优品**创始人叶国富明确「如何把 AI 和 IP 融合，是我们下一步的战略」，已**新设 AI 创新部**、开放相关岗位招聘、规划人形机器人「YOYO」；京东/字节/华为均在加码 AI 玩具赛道。
→ **【蹭概念】**（对泡泡玛特自身而言）。但**投研含义需要写清**：「蹭概念」意味着还有讲故事的**可选性**；「主动拒绝」意味着**既拿不到任何 AI 估值溢价、也不承担 AI capex 黑洞风险**，同时把「IP 智能体化」这一潜在跑道让给了名创优品等。**这是一个双向的、非对称程度不大的选择——本档不把它计为减分项，但把「名创等在 IP+AI 上跑出实质产品」列入 §11 监控。**

**⑥ 数字化第二曲线的最终结局（旧档需修正）**：旧档记自研潮玩手游《梦想家园》「2026-06 停服」，**需修正为**：2026-06-15 发布停运公告、2026-06-12 起关闭全平台充值与新用户注册、**2026-08-12 正式关服**（关服日在本次中报期之后 6 周）。财务代价：运营主体葩趣互娱 2024 年营收 RMB 2,150 万 / 净亏 4,770 万；2025 年营收骤降至 270 万 / 净亏扩大至 7,050 万；**两年累计亏损约 RMB 1.18–1.2 亿；截至 2025 年末总资产 3,660 万、总负债 1.56 亿、净资产 −1.19 亿（资不抵债）**。管理层复盘：「团队最初认为《梦想家园》是一款 80 分的产品，但市场上存在大量 100 分、120 分的产品。」
→ **【蹭概念】**。定性应从旧档的「收缩」改为**「已完成清算式退出」**。**正面读法**：管理层承认失败并果断止损，是资本配置纪律的正面证据；**负面读法**：这是泡泡玛特唯一一次严肃的数字化尝试，结果是资不抵债的清算——**它对「泡泡玛特能否构建内容飞轮」这个 §4 的核心差距问题，给出了一个负面答案。**

→ **【蹭概念】**。理由：属「用 AI 工具」而非「卖 AI 产品」，与旧档判断一致，不构成 AI 敞口。

### 7.2 双面必答（AI lens）

- **未兑现的概念是否进入了 §9 的 owner earnings 基础？** **没有，且结构性不可能有**——AI 敞口为零，§9 三情景的正常化 owner earnings **不含任何 AI 相关收入或溢价**，一分钱都没有。
- **AI 叙事是否已被市场充分定价（贵不贵）？** **本案不存在 AI 溢价可稀释「贵」的问题**——市场没有给泡泡玛特任何 AI 溢价。反过来说，**本案的「贵」（安全边际 −30.5%）完全来自 IP 平台溢价本身，不能用任何 AI 想象空间来辩护，也不需要用 AI 风险来加重。** 这一点上本案比多数标的干净。

| **Bear** | **8x** | 「周期性/衰退型 <8x」与「窄护城河 8-12x」的**交界上沿** | bear 假设 IP 被证明为 fad、营收进入下行，按框架本应 <8x。**给到 8x 而非 6-7x 的唯一理由是资产负债表**：净现金 141.64 亿占 bear 内在价值 560 亿的 25.3%，扣除净现金后隐含 EV/E 仅 **5.98x**——即在企业价值口径上已经是「衰退型」定价了。**不给更高**：因为 bear 的定义就是护城河被证伪 |
| **Base** | **13x** | 「一般护城河 + 低增长 10-15x」的**上沿** | **这是本档最需要诚实交代的一格。** 我**没有**给到 15–18x（稳固护城河区间），理由不是保守，是证据不支持：<br>① **它不是「稳固护城河」** —— 稳固护城河的定义是竞争优势可持续、需求可预测。本期的硬证据是核心 IP 在史上最强曝光下 −7.5%、最老 IP 在 20 周年 −33.6%、手办品类零增长。**一门需要每 18–24 个月重新造一个爆款才能维持体量的生意，不满足「可预测」。**<br>② **它不是「+3-5% 增长」** —— base 情景的定义就是「H2 无增长、正常化后持平」，增长中枢约 0%。<br>③ **可比校验**：13x 位于名创（11.28x，毛利率 44.7%、净利率 9.0%）与孩之宝（16.66x，毛利率 63.8%、净利率 16.0%）之间。泡泡玛特的毛利率 69.7%、净利率 29.3% **都优于孩之宝**，故不应低于名创；但它的盈利可预测性**明显差于**孩之宝（孩之宝的变形金刚/大富翁是数十年长青 IP），故不应给到孩之宝的 16.66x。**13x 是这两个约束的交集。**<br>④ **我没有给到 15x，不是我保守，是证据不支持** —— 要给 15x，需要至少一条「IP 长青性」的正面实证；本期给出的恰恰是 MOLLY 20 周年 −33.6% 这条反面实证 |
| **Bull** | **15x** | 「稳固护城河 + 3-5% 增长 15-20x」的**最下沿** | bull 的定义就是护城河升级为「稳固」，故进入 15-20x 区间是自洽的。**但只给最下沿 15x，因为成长持续性证据包三要素无一项为硬（§9.5）** —— 在没有任何硬证据的前提下，把倍数给到区间中上部（17-20x）等于用叙事定价。**同时坚决不给三丽鸥的 26.29x** —— 三丽鸥的 Hello Kitty 已长青 50 年，泡泡玛特最老的 MOLLY 在 20 周年是 −33.6%，两者不可类比 |

> **框架合规自检**：三档倍数 8 / 13 / 15 **全部落在 buffett 框架内**，无一档需要破框架才凑得出「像样」的每股价值 ✅。故不触发 playbook 的「隐含 ROE 回查 → PB 阶梯重排」路径（且 base 隐含 ROE 46.8% 极高，资产法本就不适用）。

### 9.5 bull 门控三要素逐条表（成长持续性证据包）

零售/IP 公司的「扩产」映射为**开店 + 供应链产能 + 品类扩张**；客户端为 to C 无具名大客户，按「终端兑底」处理，**会员数与复购率是客户增长的核心代理指标**。

| 要素 | 本案证据 | 判定 |
|---|---|---|
| **(a) 扩产达产确定性** | **已开出的产能是硬**：门店 630→**676 家**（美洲 64→86）、机器人商店 2,637→**2,827 台**、销售人员 6,219→9,734 人、capex +93.4%、使用权资产新增 13.74 亿。供应链侧越南约占总产能 10%（2 家工厂）、印尼产业园、泰国在建、2026 新增墨西哥/柬埔寨/印尼【软，且多为外协代工非自有资产】。<br>**但「达产」明确不确定**：美洲门店 +110% 而美洲零售店收入仅 +22.5%，**单店产出大幅下滑**；存货周转 123→201 天说明备出来的货没卖掉。<br>可验证 H2 节点：纽约时代广场 + 第五大道旗舰店 Q4 开业（媒体必报道，可验证性高）；司德承诺「美国 2026 年底门店超 100 家」——**但该承诺的进度无法精确核验**：公告只披露到大区粒度（美洲大区 H1 末 **86 家**），**国别口径不可得【缺】**，且既然美洲全大区 2025-12-31 才 64 家，业绩会所称的「美国 72 家」不可能是美国零售店数（冲突 C-9）。两个节点口径时点均为 **2026-03 年报业绩会，中报未重申** | **中（半硬）**：产能是硬的，达产不是 |
| **(b) 客户 capex / 出货能见度** | to C 无具名大客户，按终端兑底 + 会员代理指标：中国大陆会员 7,258→**8,244 万**（+986 万）、会员销售占中国大陆收入 **92.9%**、**同口径复购率 50.8%→51.6%（+0.8pp）**——**这是硬指标且方向正面**。<br>**但覆盖面不足**：**海外会员数公司从不单独披露【缺】**，而海外恰恰是本期崩塌的地方；且中国大陆会员半年新增从 FY2025 的 +1,346 万降到 +986 万，增速在放缓 | **中**：中国大陆硬、海外缺 |
| **(c) TAM 跑道** | Art Toy / Designer Toy 口径机构分歧达 **约 27 倍**（USD 18 亿 ~ 499.5 亿），无权威单列口径；**铁律：本案任何「TAM × 份额」倒推估值不可用**。仅能定性说：海外门店 221 家 vs 中国 455 家，物理跑道未到天花板 | **软** |

**门控结论**：**(a) 中 / (b) 中 / (c) 软 —— 三要素中硬证据数量为 0。** 按 playbook「三项里硬证据越少，bull 概率越要封顶（三项全软 → bull 概率 ≤ 20%）」，本案略优于「三项全软」但**仍无一项达到硬**，故：
- **bull 概率封顶 15%**（低于 20% 的软证据上限，因为其中 (c) 是明确的软）；
- **bull 倍数只给 15-20x 区间的最下沿 15x**；
- **base 情景不得脱离「无增长」中枢**（playbook 允许「三项全硬的结构性成长股 base 可用成长中枢」——本案不满足该准入条件，故 base 严格按 H1'26 干净利润 ×2、零增长处理）。

> **高增长不许稀释「贵」（红线 #8 的对偶面）**：本期营收 +23.8% 的绝对水平在全球消费品里仍属优秀，**但这不构成任何估值上修的理由**——因为 §6.2 已裁定 Q2 单季已转负，+23.8% 是 Q1 的 +75~80% 与 Q2 的 −11% 平均出来的，**它描述的是过去，不是未来的运行速率。**

### 10.2 买点 / 卖点阈值

**买点（三条件，必须同时满足）**：
1. **价格条件**：跌破 **HKD 90**（期望内在价值 106.90 的 −15% 折价上下）方进入观察性建仓区；**HKD 75 以下**（−30% 折价）才是「不确定性生意」纪律要求的完整安全边际。**现价 153.70 距第一档还有 −41%。**
2. **盈利分母落定**：至少看到 **FY2026 全年业绩（2027-03 披露）**或 2027 Q1 经营数据，确认正常化归母落在 105 亿以上（即 base 假设未被证伪）。
3. **单 IP 衰减被证伪或被抵销**：出现下列任一 —— (a) THE MONSTERS 半年营收恢复同比正增长；(b) 除 THE MONSTERS 与 Twinkle Twinkle 外，**再有第三个 IP 半年营收突破 20 亿**（即矩阵化不是一次性事件）；(c) **海外**（而不只是中国大陆）出现非 Labubu IP 的独立放量实证。

> **为什么买点不只是价格条件**：因为 §6.2 已裁定「单季转负且非节奏性」的卖出触发器已触发。在触发器状态下，单纯的价格下跌不构成买入理由——**跌下来的可能是价格，也可能是价值。**

**卖点（若持仓，四条任一触发）**：
1. **存货周转天数再上一台阶（>240 天）或跌价拨备余额占存货比 >3%**（当前 201 天 / 1.24%）——库存转化为实际减值。
2. **连续两个半年期出现「无任何单一 IP 半年营收 >15 亿的新增量」**——即矩阵化停摆、出现爆款空窗。
3. **中国大陆同口径复购率跌破 48%**（H1'26 为 51.6%，2022 失速时为 50.7%）——需求底座塌陷的先行指标。
4. **管理层开始频繁切换「调整后」口径掩饰下滑，或出现大额增发/收购**——诚信与资本配置的红线。
