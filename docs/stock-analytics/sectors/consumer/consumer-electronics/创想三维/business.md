# 创想三维 — §1 能力圈 · §2 市场规模 · §3 盈利能力 · §4 全球竞争力 · §5 护城河

## 1 · 能力圈 & 本次建档触发

**一句话生意模型**：深圳市创想三维科技股份有限公司设计并销售**消费级 3D 打印机（FDM/树脂）、3D 扫描仪与激光雕刻机及其耗材配件**，主要通过**亚马逊、TikTok 等第三方电商平台与自有独立站直接触达全球 C 端与小微 B 端用户**（DTC/电商 B2C，无 Top-N 具名大客户），2026H1 **75.9% 收入来自海外**（美洲 40.7% / 欧洲 24.9% / 其他 10.3%）。收入四条腿：整机 51.8%、扫描仪和雕刻机 20.0%、耗材 17.0%、配件及其他 11.1%。

**能力圈判定：边界区（可分析，但有两处结构性盲区）**。生意模型本身简单可解释（硬件 + 耗材 + 电商渠道），但：① **量价不可拆**——出货台数与 ASP **未找到公开证据**（三份披露文件均无），无法判断增长中量与价各自的贡献；② **分业务毛利率结构性永久不可得**——公司明示「并未根据其产品划分业务单位，且仅有一个可报告经营分部」，故「耗材是不是高毛利」这个决定护城河判断的关键问题**在公开信息下无法回答**。→ 这两处盲区决定了本档**不给精确的分部估值**，只给整体 PS 主锚（见 [§9](valuation.md)）。

**倒推三条亏钱路径（inversion）**：① 拓竹继续以更强产品在同价带压制，创想为守份额持续让利，毛利率与费用率同向恶化 → 结构性亏损；② Artec 案 2027-01 败诉，占收入 20% 的扫描雕刻腿在北美受阻；③ 2026-11-28 基石解禁 + 次新情绪溢价出清，估值向 SSYS/DDD 的 1.2–1.5x PS 收敛。

### 1.1 本次建档触发（首建档，无旧档）

本股在 `docs/stock-analytics/` 池内**此前无 buffett 档**。本轮建档的触发事件有三：

## 2 · 市场规模与跑道长度（`x-growth` lens 落点）

| 层级 | 口径 | 数字 | 分级 |
|---|---|---|---|
| **TAM（消费级 3D 打印整机）** | 全球市场规模 | 15 亿美元(2020) → 41 亿(2024) → 预测 169 亿(2029)，CAGR 约 33% | 【软·第三方预测】 |
| **装机与渗透** | 全球累计装机约 1,580 万台；中美欧约 8.6 亿户 → 家庭渗透率 **1.8%** | 【软】 |
| **行业当期动能** | 2026H1 中国消费级 3D 打印机**出口额 13.1 亿美元、+90.2%**（海关总署统计，公司公告转述） | 【硬·官方统计经公司转述】 |
| **邻接品类（扫描/雕刻）** | 同期「其他测量或检验用光学仪器」（含消费级 3D 扫描仪）出口额 12.7 亿美元 **+34.2%**；激光加工机床 11.9 亿美元 **+16.3%** | 【硬·同上】 |
| **SAM（公司可寻址）** | 公司口径全球第二大消费级 3D 打印公司；累计出货 **440 万台**（2020–2024）、官方口径 **620 万用户生态** | 【硬/软】 |
| **SOM（当前份额）** | 累计出货份额 **27.9%（2020–2024，第一）**；**单年出货 16.9%（2024，第二，拓竹 29%）**；**GMV 份额 11.2%（拓竹 42.7%）** | 【软】 |

**跑道长度的双面读法（lens 必答）**：
- **空间侧**：1.8% 家庭渗透率意味着跑道很长，TAM 未见顶——公司自身地区收入仍全线增长（美洲 5.296→6.624 亿、欧洲 3.727→4.041 亿）也是反证 TAM 见顶的证据。
- **坍缩侧**：**>70% 的入门级买家买完即弃**【软】，活跃装机可能不足 470 万台。→ **TAM 被高估的位置不在整机需求，而在「装机 = 耗材用户」的换算**（即 [§6 T1](thesis.md) 剃刀-刀片的转化率假设）。同时地区收入含**关税前置囤货的渠道压货成分，sell-in ≠ sell-through**。
- **份额侧（决定性的一条）**：跑道长不等于**这家公司**能跑。行业出口额 +90.2% 而公司整机 +0.1%——**行业增速 ≠ 公司论点**。SOM 的正确读数是「**份额正在从 27.9% 的累计第一向 11.2% 的 GMV 口径收敛**」。
- 【缺】**北美/欧洲装机增速的分区时序数据未找到公开证据**，故行业是否已在某些区域见顶无法直接验证。

→ **本期收入增量 1.852 亿元中，99.3% 与整机无关**（整机贡献 122 万）。**这是全档最重要的一个数字**：剃刀-刀片确在跑通，但**剃刀腿已停止增长**。非整机三条腿合计已占收入 **48.2%**（耗材 + 扫描雕刻 = 37.0%）。

**量价拆分：明确不可拆，不硬凑。** 出货台数与 ASP **未找到公开证据**——中期业绩公告、中期报告、盈利预警三份文件均未披露单位出货量或均价，且公司只有一个可报告分部。可得的**间接方向证据**（三条一致）：
1. 销售成本 **+19.1%** vs 收入 +12.9%（跑赢 620 bps），公司自述成本上升「主要归因于**销售数量增加**」→ 公司把成本增量首先归因于**量**；
2. 整机收入 +0.1% 而销量按公司口径在增加 → **整机 ASP 同比下行**（幅度不可量化）；
3. 行业出口额 +90.2% vs 公司整机 +0.1%，落差 90 个百分点。
→ **结论：三条替代证据一致指向「量增价跌 + 整机份额被侵蚀」，但精确的量价拆分公开信息不足以完成，本档不给拆分数字。**

### 3.4 增长质量：增长**不伴随**毛利改善 → 判定为「以利换份额」

| | 2026H1 | 2025H1 | 变动 |
|---|---:|---:|---|
| 毛利率 | 30.8% | 34.4% | **−360 bps** |
| 销售及营销费用率 | 18.71% | 16.33% | +238 bps |
| 一般及行政费用率 | 6.68% | 4.99% | +169 bps |
| 研发费用率 | 8.82% | 7.24% | +158 bps |
| **三费合计** | **34.21%** | 28.56% | **+565 bps** |
| **经营利润率** | **−5.32%** | +7.70% | **−1,302 bps** |

**−1,302 bps 的归因权重（本档的核心纠偏）**：毛利率 −360 bps（**28%**）+ 费用率 −565 bps（**43%**）+ 其他损益与其他收入合计 −377 bps（**29%**）。→ **费用失控对利润的伤害大于毛利率下滑。市场叙事聚焦毛利率，但数字上三费扩张才是最大单一杀手。**

费用明细【硬】：营销及广告 1.076 → **1.284 亿**；销售员工成本 5,550 → **7,180 万**；**支付予电商平台之佣金 3,760 → 5,660 万（+50.5%，占收入 3.48%）**，公司归因「主要受亚马逊及 TikTok 等平台业务增长带动」——**渠道税刚性上升，不随促销结束回落**；研发员工成本 8,280 万 → **1.105 亿**（研发团队 890 人，截至 6/30 已获授 957 项专利含 141 项发明专利、1,278 项申请、65 项版权、843 项注册商标）。行政费用增长主因为上市开支 + 股份支付（**这两项已在非 IFRS 中剔除**）。

**毛利率归因（公司口径，仅定性、无 bps 分解【硬】）**：① 「2025 年下半年度**策略性地**将新推出产品的定价利润率定于较以往产品率低的水平」；② 「促销及主动降价清理老旧系列产品」。

| 分解项 | 判定 |
|---|---|
| 毛利率总降幅 −360 bps | 【硬】 |
| 「让利 + 清库存」 | 公司把**全部 360 bps** 归于这两项，**不可再细分【缺】** |
| **关税** | **公司归因清单中完全未提关税** →【缺】，**不得写进毛利归因** |
| 汇率 | **不在毛利线上**——汇兑损失 3,540 万走「其他亏损/收益净额」【硬】 |
| **存货减值** | **中报未披露任何存货减值/撇减金额**【缺】，**不可假定存在** |

> **本轮最大的口径风险**：「旧库存清理」是**主动降价折价出清、打在毛利线上**，不是计提减值；且新品低毛利定价是公司自述的**「策略性」持续性价格策略**。**把毛利率下滑写成一次性事件是错误的。**

## 4 · 全球竞争力

| 2024 出货 / 份额 | 70 万台 / **16.9%（第二）** | 约 120 万台 / **29%（第一）** | 工业级为主，消费级基本退出 |
| **GMV 份额** | **11.2%** | **42.7%** | — |
| 2025 营收 | 31.27 亿 RMB | 超 100 亿 RMB（口径 93.7–94.7 亿）【软】 | SSYS 5.47 亿 USD（−3.1%）/ DDD 3.88 亿 USD（−6.2%） |

| 定位 | **被拉开的老二 / 跟随者** | 品类标准定义者 | 收缩中的老牌工业厂商 |

**vs 国际龙头的差距**：本行业的「国际龙头」已不是欧美厂商——**SSYS/DDD 收入负增长、双双亏损**，中国厂商占全球消费级出货 >90%（深圳「四天王」创想/拓竹/纵维立方/智能派合计约九成）。**真正的对手在同一个城市**。创想在全球出货量口径确实是前二，但在**价值口径（GMV 11.2%）只有龙头的四分之一**——这是全球竞争力的真实读数。

**细分龙头识别**：① **整机**：非龙头，且份额下滑（+0.1% vs 行业出口 +90.2%）；② **耗材**：无份额数据【缺】，但绝对额 2.766 亿、+48.3%，是公司自身增长最快的腿；③ **3D 扫描仪**：全球份额与分部毛利率**未找到公开证据【缺】**，夹在先临三维/思看（专业级、高毛利）与 Revopoint/xTool（低价）之间，**无明确技术或渠道独占位**；④ **激光雕刻**：+16.7% 与行业出口额 +16.3% 同步，属跟平。

## 5 · 核心优势 / 护城河

| 护城河来源 | 类型 | 强度 | 趋势 |
|---|---|---|---|
| 品牌心智（消费级 3D 打印入门认知） | 无形资产 | **中** | **承压** |
| 研发迭代速度（研发费率 8.82%、890 人团队、957 项已授权专利） | 无形资产 | **中** | 稳定 |
| **耗材复购（RFID + CFS 供料系统）** | 转换成本（候选） | **弱→中** | **拓宽中（未证实）** |
| 渠道 / DTC 数据资产（亚马逊 + TikTok + 独立站） | 成本优势 | **弱** | **承压** |
| 规模与供应链（累计出货 440 万台，深圳产业集群） | 成本优势 | **弱** | 稳定 |

**整体判定：弱→中，趋势承压。按本仓横向排序 `安克 ≥ 影石 > 创想`，本档不得给到「中强」及以上。**

**四条判据（相对兄弟档的定档理由）**：
1. **定价权验证器已经失守**。本仓把**毛利率当作品牌护城河的唯一可量化验证器**：安克维持 **45%**（未崩）；影石从 52.2% 降到 **45.2%**（已被本仓视为警讯，但仍在 45% 上方）；**创想 34.4% → 30.8% 且直接导致由盈转亏**——**三者中唯一让利已吞掉全部利润的一档**。
2. **技术差异化的独占性最弱**。影石有自研算法 + 自研芯片 + 337 胜诉专利组合；安克有 9.48% 研发占比支撑的迭代速度；创想的 FDM 消费级技术栈更接近开源生态（Marlin/Klipper 系）与成熟供应链，**未找到与影石专利胜诉同级别的独占性证据【缺】**，且自身正被 Artec 起诉（见 [§6 T5](thesis.md)）。
3. **竞争位势最差**。安克在充电类目自身是龙头；影石在全景是全球第一；**创想是老二，而龙头拓竹既更大又更赚钱（GMV 42.7%、净利率约 30%），并在主动降价**。
4. **转换成本接近零，耗材是唯一亮点但锁定是软的**。FDM 耗材市场高度通用（第三方 PLA/PETG 可互换），Creality 官方 wiki 明写**非 RFID 耗材可手动设置继续打印**——「无芯片则拒打」**未找到公开证据**。故耗材只能定「弱→中 / 拓宽中」，且**分业务毛利率结构性永久不可得**意味着这条护城河**在可预见的未来无法被公开数据证实**。

**buffett 的判据检验**：「需要不断重建的护城河终究不是护城河。」本股的品牌与份额需要**持续让利**来维持（新品即以低毛利定价），而让利已经吃掉全部利润——这不是在维护护城河，**是在用股东资本购买市场份额，且份额仍在丢**。

**管理层三维评估**：
- **诚信**：**未触一票否决线，但先验概率被显著调低**。正面：中报对毛利率下滑给出了明确且不回避的归因（自认「策略性地」定低毛利），未粉饰；负面：四项治理红旗（亏损年份派息 8,140 万后募资 13 亿港元、上市 40 天四位核心财务/信披高管同时辞任、董事长兼总经理自认偏离守则 C.2.1、招股书对 Artec 诉讼披露被质疑）——详见 [§6 T7](thesis.md)。
- **资本配置**：**待观察，当前信号偏负**。IPO 前在亏损年份派息、上市后 3 个月即公告拟投**约 5.5 亿 RMB** 建增材制造总部（≈当前年化 capex 的 25 倍），对 9.166 亿净现金是重大占用，**而公司当前的问题是费用率而非产能不足**。
- **所有者心态**：控股股东四人合计约 82%，持有**内资股**、与公司深度绑定，处置受非上市股份限制——绑定度高是正面；但集体控股 + 一人兼任董事长与总经理，制衡不足。
- **机构强制力（institutional imperative）警示：存在**。在毛利率已被让利吞噬的当口加码固定资产投入与营销投放，是典型的「同业都在扩、我们也要扩」行为模式。
