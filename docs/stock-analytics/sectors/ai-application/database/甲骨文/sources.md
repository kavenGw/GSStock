## 12.5 已知局限 —— 【缺】清单（**严禁补白**）

1. **OCI 单独毛利率**：**公司从未披露**。管理层在 FY27Q1 电话会明确**推迟至 2026-10 投资者日**，并拒绝给出前瞻数字。市面流传的 **28%** 与 **14%** 两个数**都无原文支撑**，本档一律不采信、不入档。旧档「AI 算力稳态毛利率 30–35%」因此**本期既不能证实也不能证伪**，按「无信息」处理。本档改用 Cloud & software 分部 margin（54.5%，−504bp）作唯一代理。
2. **OpenAI 合约的本期履约 / 付款状态**：8-K、10-Q **均未提及**，电话会全程**无任何客户集中度或 OpenAI 相关问答**。旧档假设「OpenAI 履约」本期**无法证实也无法证伪**，按「无信息」处理。**任何关于合约重谈 / 延期 / 缩量的说法本轮均未找到公开证据，不得写入。**
3. **NRR / 净收入留存**：Oracle 不披露。旧档「>110%」降级为估计值，不作论据。
4. **AI 基建 TAM 单一权威口径**：第三方分歧极大，本轮未取得可调和数字，**不代入估值**。
5. **服务器 PP&E 净值明细**：10-Q 未按设备类别拆分。[§9.5](valuation.md) 折旧敏感性所用基数 **$900 亿为估算**（按 FY26–27 capex 合计约 $1,450–1,500 亿 × 约 60% 服务器占比推算），结论应作数量级参考而非精确值。
6. **FY27 D&A**：[§9.3](valuation.md) 取 **$190 亿为估算**（A3 给区间 $180–220 亿），是本档三情景 EBITDA 的最大单一估算项，非披露值。
7. **10 年平均 ROIC**：本轮未取得可靠十年序列。仅给出 TTM 自算 **12.5%** 与下行趋势判断。
8. **研发资本化精确金额**：10-Q 未单列；可确认 Oracle 历来费用化且本季无会计变更披露。
9. **利用率 97.9%、GPU 续租溢价 20%、「新签合约绝大多数采用客户预付或 BYOH」**：均为**管理层自报口径，无第三方或财报附注坐实**，本档标【软】且**不进估值假设**。
10. **OpenAI 占 RPO 约一半**：多方来源（含 S&P）一致，但**非公司披露**，标【软】。
