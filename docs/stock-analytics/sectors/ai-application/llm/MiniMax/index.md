## 0. 结论摘要

**评级：watch（维持，不翻转）** —— 期望内在价值 **83.9 HKD/股**（约 293.0 亿 HKD），当前 **303.00 HKD / 1,058.18 亿 HKD**，**安全边际 −72.3%**（旧档 −53.7%）。

**第一段必须说的是那个组合：基本面转差与价格上涨同时发生。** 期望内在价值由旧档 117.4 下修至 83.9 HKD（−28.6%，三个来源：base 终局 EV/S 按 T2a 执行由 6x 下修至 4x、base 毛利率假设 45%→38%、**bull 概率按 T1c 与 T4a/T4b 两条下调闸执行由 20% 降至 10%**），**而股价同期从 253.80 涨到 303.00（+19.4%）**，安全边际两头恶化。更关键的是压力测试：**bull 单档安全边际由 +4.1% 转为 −12.3%——今天的价格已经高于本档最乐观情景的现值**，这是旧档没有出现过的状态。

### 多头侧：ARR 叙事没有被打回原形（本轮最重要的一条，先写）

**H1 会计收入 US$116.573M（+283.1%），单半年超过 FY2025 全年 US$79.04M**；年化 US$233.2M 与 2026-05 公司口径的 ARR 约 US$300M **大体自洽**。旧档最大的悬念是「中报会不会把 ARR 打回会计收入原形」——**答案是没有**：成长证据包 (a) 兑现确定性由「偏软」升为「**偏硬**」（升两档），**切 bear 闸（H1 < US$90M）未触发**，实际高出阈值 29.5%；**距 bull 上调闸 US$125M 仅差 6.7%，属「差一点」而非「不及格」**（记入下期复核清单，但按纪律不用于本期突破封顶）。同时，**收入端增长质量在本仓 AI 应用池里仍是独一份**——收入 +283.1% 的同时销售及分销开支**再降 17.9%**（连降两期）、销售费率 107.9% → **23.2%**，透支存量拉不出 +283%；**估值分母的分裂大幅收窄**（TTM PS 143.8x → **82.1x**，三口径跨度由 12.6 倍收敛到 **2.2 倍**），**旧档「不存在可辩护的中枢估值」本档予以撤回**；**「跃迁为 AI 平台公司」的叙事被公司报表从【蹭概念】推翻为【真敏感·业绩层】**（开放平台及企业服务 US$73.9M、+703.1%、占比 **63.4%**，FY2025 为 28.9%）。逐条论证见 [§6.2 / §6.3](thesis.md)。

### 空头侧：同等篇幅——毛利率崩塌，且崩塌的机制正是收入增长本身

**混合毛利率的真实序列是 12.1% → 33.7% → 17.9%**（1H2025 / 2H2025 反推 / 1H2026），**环比 −15.8pct，是腰斩不是回落**；**边际毛利率只有 6.5%**（增量收入 US$67.96M 只带来增量毛利 US$4.42M）。只写「17.9% 低于 FY2025 的 25.4%」会把这件事说轻，本档拒绝这种写法。**机制与增长同向**：低毛利的开放平台占比从 28.9% 冲到 63.4%，**收入越增长、混合毛利率越被拖低**（旧档记录的智谱模式）——**故「B 端占比提升 → 混合毛利率上行」这条 bull 前提本期被反向证据直接命中**，不得再进任何一档（两种解释的并列见 [§6.1](thesis.md)）。另有三条：**亏损加速快于增长**（经调整净亏 **US$293.0M / +111.2%**，月烧 **US$48.8M** = 旧档假设的 1.75 倍；亏损增量是毛利增量的 9.0 倍；毛利仅覆盖研发 **7.0%**，[§3](business.md)）；**技术位置由「名次落后」恶化为「分数断层」**（AA Index **v4.1.1** 下 M3 = **45** vs K3(max) = **60**，open weights **#8/107**；**引用纪律：AA 分数必须带版本号，「开源第一 / 全球第五」是 v4.1 之前口径、全档禁止沿用**，[§7.2](thesis.md)）；**重资产化已启动而旧档没有这一条**（PP&E **+47.7 倍**、非流动预付款 **+113.7 倍**，合计约 US$174M 已流出或锁定且未入损益表；[§9.1](valuation.md) 拒绝资产法的理由已重写）。

### 主论点的升级（重写而非改数）

旧档主 thesis 是「跃迁到软件成本结构……**至今没有任何证据**」。**本轮升级为：已有证据指向反方向**——旧档的状态是「不知道」，现在是「知道，且方向是坏的」，机制可辨识、可监控。

### 11.2 卖出标准逐条检查（Buffett 四条）

1. **价格严重高估？→ 是，且比旧档更严重。** 安全边际 −72.3%（旧档 −53.7%）、**bull 单档 −12.3%（旧档 +4.1%，已由正转负）**；TTM PS 82.1x 是港股 AI 同业（1.5–9.3x）的 9–55 倍、Palantir 前瞻 50.9x 的 1.6 倍、Anthropic 一级约 15x 的 5.5 倍。**这是评级的决定性因素。**
2. **护城河根本性破坏？→ 恶化，但仍未完成。** 旧档唯一仍成立的候选「成本效率」，其唯一可验证的表征是毛利率——**本期毛利率环比腰斩、边际 6.5%，这条候选被自己的报表直接命中**；技术位置恶化为 AA v4.1.1 下落后 15 分的分数断层。**尚未判「已破坏」**：需求侧真实拉动仍在（收入 +283.1%、B 端 +703.1%、销售费用连降两期）。逐类判定见 [§5](business.md)。
3. **管理层诚信问题？→ 否，不触发一票否决。** 未找到财务造假、监管处罚、关联方掏空的证据；公告**主动并列会计净亏（−US$358.0M）与经调整净亏（−US$293.0M）**；安永审阅。⚠️ 两条须观察的治理项（**均不构成诚信判定**）：① 闫俊杰兼任董事长与 CEO，偏离 CG Code C.2.1（p.10）；② **本期分部颗粒度倒退**（三线拆分合并为「AI 原生产品」单项），**且发生在毛利率崩塌的同一期**。
4. **有明显更好的机会？→ 是。** 金山办公（688111）已实现 86.6% 毛利、PS(年化) 16.3x，质地已验证。**与[智谱](related.md)相比，旧档「MiniMax 是更优的一个」本期降为「动摇」**（两侧证据与口径不对称说明见 [related.md](related.md)）。**但只判「动摇」不判「反转」**：智谱 2026 中报未刊发【缺】，横向财务口径无法同一时点对齐。

**制度性强制检查**：**有新情况但不扣分。** 无并购、无跨界扩张，IPO 募资约 90% 投向研发。新变化是重资产化（约 US$174M 转向自购设备与长期预付算力）：**判为产能保障而非帝国建设**（绝对额仅市值约 1.3%，方向与研发一致）。**但它推翻了旧档「纯租用算力、无 capex 黑洞」的定性**，已列入 §11.1 风险 5 阈值。
