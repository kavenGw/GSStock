## 1. 能力圈 & 本次重审触发

### 1.1 能力圈判定：**边界区域，商业模式可解释但终局不可预测**（维持旧档判定）

这门生意怎么赚钱，可以用一段话说清楚：**训练基座模型，然后从两个口子变现**——① 把模型能力打包成 API 卖给企业与开发者（开放平台及企业服务，1H2026 占 63.4%）；② 把模型做成自有 C 端产品收订阅与增值费（AI 原生产品：陪伴类 Talkie / 星野，视频类海螺 Hailuo，1H2026 占 36.6%）。成本端主要是算力（销售成本）与研发人员。

**可解释 ≠ 可预测。** 终局取决于两个至今无法回答的问题：**基座模型能力会不会商品化到没有定价权**（本期证据：M3 定价是 K3 的 1/10.5，是主动放弃定价权换份额）；**规模上来之后单位经济会不会改善**（本期证据：方向相反，边际毛利率 6.5%）。**故仍判边界区域，不进入核心圈。**

## 2. 市场规模与跑道

### 2.1 **旧档的估值分水岭已经失效，必须重写**

旧档 §2.1 的杀手锏是「**陪伴赛道的 TAM（Statista 2030 US$62 亿）可能小于它今天的市值**」。**这个分水岭本期失效，两条理由都必须写出：**

1. **公司主营结构已变**——陪伴不再是主线，AI 原生产品（含陪伴与视频）占比已降至 36.6% 且未单独拆分。用陪伴 TAM 框住整家公司的估值，在会计事实上已不成立。
2. **该 TAM 口径本身存在一个数量级的分歧**：Statista 口径 2030 年 **US$62 亿**；market.us 口径 2024 US$108 亿 → 2034 US$2,908 亿（CAGR 39.0%），**按此插值到 2030 约 US$550 亿，是前者的 8.9 倍**。**这不是「TAM 大」或「TAM 小」的问题，是「没有一个可用的 TAM」——单一引用不可辩护，本档两个口径并列。**

**替换后的分水岭：开放平台 / 企业 API 的 TAM vs 市值。** 可用口径：**中国独立模型厂商 API 池约 US$21 亿**（2026-07 链上/调用量推算，**【软】**）。当前市值 US$13,566M 是该池的 **6.5 倍**——**新分母同样是软证据，故本档不把它当作估值依据，只作为跑道量级的参照。**

### 3.2 毛利率：**真实序列是 12.1% → 33.7% → 17.9%**

完整算术与机制判读见 [§6.1（thesis.md）](thesis.md)。此处只固定三条数字纪律：

1. **写序列，不写「低于 FY2025 的 25.4%」** —— 后者把环比腰斩说成温和回落。
2. **环比 −15.8pct** 与 **边际毛利率 6.5%** 是本期两个必须并列出现的读数。
3. **B2B 分部毛利率的数学上限仅 28.2%**【软·自算】，网传的「开放平台毛利率 69.4%」对 1H2026 已失效，**全档不得引用**。

**绝对水平检验（旧档纪律沿用，读数更差）**：每 1 美元收入被算力吃掉 **0.821 美元**（旧档 0.746）。全期毛利 US$20.8M，而研发 US$296.9M ——**毛利覆盖研发的 7.0%**（旧档 8%）。**收入翻近 3 倍，覆盖率不升反降。** 按当前 17.9% 毛利率，费用（研发+销售+管理 = US$354.1M/半年）需要收入约 **US$1,978M/半年** 才能覆盖，是当前的 **17 倍**。

### 3.3 增长拆量价与增长质量（x-growth lens 必答）

**拆量价**：**这门生意的增长几乎全部是「量」**。

- **价**：**没有正贡献，甚至是负的**。M3 最低输入价 90 天 **−15%**（US$0.300 → 0.255/百万 token）；标准档官方牌价 US$0.60/$2.40 挂「永久 5 折」执行 US$0.30/$1.20。**至今无任何一次提价的公开证据。**
- **量**：CEO 唯一的量化表述是「**至 2026 年 7 月平台 Token 消耗量已增至 1 月的 20 倍**」。用户 >3 亿、企业及开发者 >100 万（公告口径【硬】）。
- **结论**：**收入 +283.1% = 量增 × 价跌**，且价跌是主动的（把 M3 定在同侪 1/10.5 换份额）。**这解释了为什么收入越增长、毛利率越低。**

**增长质量**：逐维度表与裁决见 [§6.3（thesis.md）](thesis.md)。一句话——**收入端是「有质量增长」的教科书样本（销售费用连降两期而收入 +283%、销售费率 107.9%→23.2%），成本端是「烧钱扩张」的教科书样本（毛利率环比腰斩、亏损 +111.2%、月烧 US$48.8M），而且是同一批数字。**

### 5.1 五类护城河逐项判定（重评旧档）

| 类型 | 判定 | 趋势 | 依据（本期更新） |
|---|---|---|---|
| 无形资产（品牌/专利） | **无** | — | 无品牌溢价证据；**本期反向新增**：多起知识产权侵权索赔诉讼被告，未计提拨备 |
| **成本优势** | **旧档判为唯一候选，本期被自己的报表命中** | **↓↓ 收窄** | 「成本只有 OpenAI 的 1%」「推理成本 2 个月降 >50%」在收入放大 3 倍的压力测试下**未转化为毛利率**：环比 −15.8pct、边际 6.5%。**产品层可能成立，业绩层证伪** |

### 5.2 开源策略：与智谱同构的双刃剑，**而本期证据显示 MiniMax 处境更差**

M3 承诺约 10 天内放权重（商业受限许可），H3 已于报告期后以 open weights 发布。**开源换生态、生态换调用量**这条路径本身成立（Token 消耗量 7 个月 20 倍是证据），**但它对定价权的压制在本轮无任何改善迹象**——**公司自己把 API 价定在同侪 1/10.5，这是主动放弃定价权换份额，不是被动被压。**

**定价权的三条证据（逐条标级，并说明为何不二次触发 §11 风险 3）**：

| 证据 | 强度 | 读法 |
|---|---|---|
| 腾讯云 2026-06-12 下调 M3 接入价 | **【软】** | **旧档建档（2026-08-05）前已发生、旧档正文已多处记录**，旧档「无定价权」的判定本就建立在它之上 |
| M3 最低输入价 90 天 US$0.300 → 0.255（**−15%**） | **【软】** | 来自第三方聚合站的**最低报价追踪（含渠道折扣）**，**不是公司公告的牌价下调** |
| **M3 定价 US$0.22/百万 token = Kimi K3(max) 的 1/10.5** | **【硬·AA 官网 v4.1.1】** | 见下方双面读法 |

> **本档判定：以上三条不足以二次触发 §11 风险 3（T3）。** T3 原文要求的是「任何一次**官方**降价，或云厂商**再次**下调接入价」——腾讯云那一次是「这一次」而非「再次」，用同一事件二次触发是**重复计数**；而【软】级的渠道折扣追踪够不上「官方降价」的门槛。**故 base 终局 EV/S 维持 4x，不叠加额外 1x 下修。** 但**方向上它们与「毛利率修复」这一 base 核心假设相反，已计入 base 毛利率由 45% 下修至 38%**（[§9.4/§9.6](valuation.md)）。
>
> **「1/10.5」这条必须双面写**：① **它是定价权缺失的直接体现**——同侪十分之一的单价，是主动放弃定价权换份额；② **它同时是 M3 真实的差异化**——单位智能的价格效率压倒性（US$0.22 vs US$2.31/百万 token），输出速度 137 vs 40 tok/s（**3.4 倍**），首 token 时延 1.35s vs 2.69s，上下文窗口 1M token。**「便宜且快」是可验证的真优势，但它同时正是毛利率上不去的直接原因——这两件事是同一枚硬币。** 而且**这些强项恰好全部落在 AA 指数之外**（[§7.2](thesis.md)），这解释了为什么「AA 45 分 vs K3 60 分」与「M3 在真实部署里有价格效率优势」可以同时成立，不是矛盾。

**与兄弟档[智谱](related.md)的关键差异**：智谱在同期拿到了**提价且量未降**的反证（GLM-5.1 提价 10%、Coding Plan +30%），**MiniMax 至今拿不出任何一次提价的证据**。这正是本档股权成本比智谱档高 1pct 的两项来源之一（另一项是毛利率，本轮差距由 15.6pct 扩大到 **23.1pct**）。

### 5.3 护城河综合判定：**当期不存在可定价的护城河**

**旧档的判定是「当期存在的只有成本效率一项，且它不可独立验证」。本期须更新为：那一项被自己的报表命中了。** 毛利率是成本效率唯一可验证的表征，而它环比腰斩。

> **但不能因此判为「护城河根本性破坏」**（[§11.1 卖出标准第 2 条](index.md)）：需求侧的真实拉动仍在（B 端 +703.1%、销售费用连降两期、企业开发者破百万），**这是一门有真实需求、但至今没有定价权的生意**。护城河的候选从「成本效率」转移到了「**规模与生态**」——而后者能否变成定价权，本期没有任何证据，且**判别它的钥匙（分部毛利率、客户集中度）连续两期未披露**。
