## 6. 核心新论点

本轮六条论点，逐条给出**受益/受损侧传导**、**周期性 vs 结构性二分判定**与**最强反驳前置**。

### 6.1 论点一：收入质量的事实基础发生了本轮最大的一次多头移动，但会计证据仍缺一环

**事实**：本地化部署（一次性项目制）占比 **73.7%（FY2025）→ 13.5%（1H2026）**，绝对额 **−20.5%**；开放平台及 API 占比 **15.2% → 86.5%**（8.25 亿 CNY，**+27.4 倍**）。公司称本地化是"战略性压缩调整"（重质轻量）。运营侧配套证据：企业及开发者用户 **>740 万**（较年初 +144%）、**付费日活 +603%**、前十大客户日均调用量 **+98%**、token 调用量较年初 **+40 倍以上**。

**传导（受益侧）**：旧档最有力的空头论点之一——"收入主体是一次性项目交付、前五大客户逐年完全不重合、客户零留存"——的**核心事实基础在 1H2026 已不成立**。收入主体已切换为月度经常性的 API 调用，其自然属性是随使用量线性、可重复、可预测。

**二分判定：结构性，不是周期性。** 这不是某个季度的验收节奏波动，是收入模型的置换，且置换方向不可逆（本地化业务被公司主动压缩）。

**最强反驳（前置，必须写）**：
> **"API 收入是订阅收入"这句话，本轮拿不到会计证据。** 判断 API 收入是否具备订阅属性的唯一会计凭据是**递延收入 / 合同负债余额**，而该科目 **1H2026 中报未见披露**（A1 C6 级别 1【缺】、A2 与 A3 均独立查证未获）。同时缺失的还有：**应收账款周转天数**（旧档 112 天，本轮无更新）、**前五大客户集中度**（FY2024 可比值 45.5%、单一最大客户 19.0%）、**在手订单**。
> 因此本档的表述边界是：**收入性质已实质改善，但订阅属性的会计证据仍缺。不得写成"已验证为订阅收入"。**
> 另一层反驳：付费日活 +603% 的口径截至 **2026-06-30**，**早于 2026-07-31 的 Coding Plan 提价**，因此它**不能**用来验证提价后的留存。提价后的需求侧反应要到 3Q2026 数据才可证伪，本轮**无法裁定**。

### 6.2 论点二（本档核心矛盾，必须成对写）：定价权在单位经济层已被证明存在，但尚不足以抵消 mix 稀释

**旧档表述「定价权只存在于卖得出去这一层、不存在于卖出去能不能赚钱这一层」方向成立但归因错了，本轮废弃该表述。**

**支持"能赚钱"的一面（硬）**：

| 证据 | 值 |
|---|---|
| 云端部署（API/MaaS）分部毛利率 | **−0.4%（1H2025）→ +24.6%（1H2026）**，转正，+25.0pct |
| 单位 token 推理成本 | 较年初 **−80%** |
| 每投入 1 元算力对应的 API 收入 | 同比 **+约 14 倍** |
| API 平均售价 | **+约 101%**（印证 2026-07-31 提价已落地） |
| 公司归因 | 调用规模扩大 + 定价上调 + 推理成本下降，三因并列 |

**支持"不赚钱"的一面（同样硬）**：

| 证据 | 值 |
|---|---|
| 混合毛利率序列 | 64.6%（2023）→ 56.3%（2024）→ 41.0%（FY2025）→ **26.4%（1H2026）**，四期单调下行 |
| 1H2026 单期降幅 | **−23.6pct**，且**逆着"H1 毛利率天然高于 H2"的季节性**（1H2025 50.0% vs H2 2025 37.8%）仍大幅下跌 |
| 亏损强度 | 经调整口径每收 1 元亏 **2.06 元**（旧档 FY2025 口径为 6.5 元，**须标年份**） |
| 研发 / 收入 | 21.31 / 9.539 = **2.23 倍** |
| 高毛利稳定器 | 已失去——本地化从 73.7% 掉到 13.5% |

**正确表述（本档采用）**：
> **定价权在单位经济层已被证明存在——云端分部毛利率转正至 24.6%、单位算力变现 +14 倍——但它被收入结构的爆炸性重构淹没了。集团毛利率从 41.0% 塌到 26.4% 是 mix 重构的结构稀释，不是单位成本恶化。真正的问题因此被换成了一个更难回答的：24.6% 的云端毛利率能否在 GLM-5.3 级别的算力密度下继续爬坡到覆盖 40 亿+/年的研发。**
> **云端毛利率的爬坡斜率是全案最关键的可证伪变量。**

**二分判定：结构稀释是结构性的（本地化不会回来），分部改善的可持续性未定。**

**最强反驳（前置）**：
> 云端毛利率 24.6% 的改善有一个尚未定价的逆风：**1GW 数据中心若为自建自有，其折旧将进入营业成本**。公司未披露 1GW 是自建、合作还是承租——**自建则毛利率爬坡面临折旧逆风，承租则算力自主叙事被削弱，二选一**（见 6.4）。另外，**GLM-5.3 API 定价与 GLM-5.2 持平（未再提价）**，上一轮的提价动能在 8 月停止，这对定价权叙事是中性偏负的边际信号。

### 6.3 论点三：ARR 从"最大估值杠杆"变成"全案首要风险"

**事实链**：
- 公司自述唯一 ARR 官方口径：**约 17 亿 CNY**（张鹏，2026-03-31 业绩会，"过去 12 个月提升 60 倍"）。
- 媒体传闻口径：**US$1bn**（36氪独家，2026-07-17）≈ 71 亿 CNY，与公司自述差 **4 倍**；**源报道自行标注**"WAIC 期间行业流传的测算数据、**RRR 口径（收入运行率）而非标准 SaaS ARR**、**尚未经官方财报公开确认**、**数据存在高估可能性**"。
- 中报口径：截至 2026-08-31 ARR **按月年化 US$1.6bn / 按末周年化 US$2.0bn** ≈ 114–143 亿 CNY。
- **同期 IFRS 口径 API 收入年化仅约 16.5 亿 CNY，裂口 6.5–8.7x**（A1 测 6.5–8.2x、A3 测 7–8.7x，取并集）。
- **中报未官方确认 US$1bn ARR**（A2 已说明查证范围：中报全部媒体转述稿与业绩会报道无一引用；属否定性断言）。

**传导（受损侧）**：旧档 forward PS 59x 的分母正是 ARR US$1bn（≈68 亿 CNY）。分母塌掉 → **forward 锚失效 → 唯一合法主锚只剩 PS(TTM) 320.7x**。这与旧档触发器 2a 写死的后果条款（"forward PS 锚失效"）完全一致——**触发器命中，且成因被独立加固**。

**二分判定：结构性（口径问题不会随周期消失）。**

**最强反驳（前置）**：
> ARR 的**方向**是可信的：US$0.1bn（2026-01）→ US$1.0bn（2026-07）→ US$1.6bn（2026-08 月化）。方向证实、绝对值证伪，是本档的完整表述。若下一期公司改按 IFRS 可审计口径披露 ARR 并与入账收入收敛，本条论点将被大幅削弱——这也正是 [index.md §11.2 风险 1](index.md) 的监控设计。

### 6.4 论点四：1GW 国产算力从"偏硬的扩产证据"退化为"数量级缺口"

**事实**：2026-07-21 宣布落地 1GW 级国产 AI 算力数据中心（全部国产 AI 芯片，定位 GLM 训练基地），同日完成收购中科加禾（中科院计算所编译实验室背景，异构算力编译栈）。已实现 **10 万级国产芯片规模化推理**（GLM-5.3-Flash 全部由国产卡承载）——这一条是中报硬披露，本轮由"叙事"升级为"已验证"。

**但**：投资总额 / 建设时间表 / 分期节奏 / 资金结构（自筹/银团/地方国资/租赁）/ 选址 / 芯片供应商名单 **全部【缺】**（A3 已查新浪 2026-07-23 深度稿、腾讯新闻、新京报、Digitimes、虎嗅；新浪记者明写就算力占比采访智谱"截至发稿未收到回复"）。

**本轮新增反向证据（重要）**：**1H2026 资本开支仅 3.90 亿 CNY**，而 1GW 级 AI 数据中心的行业 capex 量级通常在**数百亿 CNY**——**相差两个数量级**。且这 3.90 亿的主因是**收购北京红钻科技**带来的物业厂房设备，不是算力建设。三种可能的解释公司均未澄清：① 1GW 由合作方/地方国资建设、智谱仅承租算力（则属经营性支出，**不构成 bull 门控意义上的"自身扩产"**）；② 项目尚未实质开工；③ 分期极长。

**传导**：直接下调 [valuation.md §9.4](valuation.md) 门控要素 (a) 的强度（旧"偏硬但不可量化" → **弱-中**）。

**二分判定：暂不可判**——数据不足以区分结构性投入与叙事性宣布，这本身就是判定。

**与实体清单的关系**：B7（美国实体清单，2025-01-15 起，EAR §744.11 全项目 presumption of denial）与 1GW 全国产算力是**同一约束的两面**——1GW + 收购编译栈 = 对实体清单的结构性应对。**本档不把它们当作两条独立论据计。**

### 6.5 论点五：融资节奏已从"估值负项"升格为"商业模式的必要条件"

| 时点 | 事件 | 规模 |

| 2026-01-08 | 港股 IPO | 募 43 亿 HKD，定价 116.20 |
| 2026-06-01 | 董事会建议 A 股科创板上市 | 拟募 **150 亿 CNY**（基座大模型 120 / MaaS 平台 20 / 补流 10），发行占**发行后**总股本 **2%–8%**（909.88 万–3,876.9 万股） |

**12 个月三次股权融资，累计拟募 >500 亿 HKD 等值，而 1H2026 收入仅 9.539 亿 CNY——资金需求与收入量级相差近两个数量级。**

**本轮新事实（旧档没有，对触发器 5 有直接影响）**：**现价 1,195.00 HKD 已低于 2026-07-09 配售价 1,588 HKD 达 24.7%，配售投资者浮亏。** 在低于配售价近四分之一的位置再做股权融资，摊薄成本显著上升；A 股 150 亿募资的定价压力随之升高，且**发行区间上限 8% 已突破触发器 5 的 5% 摊薄阈值**——这是一个**已进入时间表、大概率命中的前瞻触发**，已事前登记进 [index.md §11.2 风险 3](index.md)。

**传导（受损侧）**：老股东面对的是持续的、不确定的稀释流。**这直接决定了 [valuation.md §9.5](valuation.md) 中 bear/base 采用 pro-forma 股本的口径选择。**

**最强反驳（前置，必须给管理层这一分）**：
> 配售择时是教科书级的资本配置——在 7/8 收盘 1,825（距峰值仅回撤 39%）启动加速簿记，以 1,588 定价、仅折让 12.99% 完成 313.75 亿 HKD，符合 Buffett"股价高于内在价值时发股"的原则，为股东换来了多年现金跑道。**融资节奏本身不构成对管理层诚信或能力的指控。**
> ⚠️ **【缺】**：2026-07 至 2026-09-01 期间是否已正式向上交所递交 A 股 IPO 申请 / 是否获受理，**未找到公开证据**（A2 已查上交所受理动态转述、新浪/21经济/证券时报/瑞财经专题、港交所公告转述）。**这是一个真实的"未找到"，不是"没有进展"的等价物。**

### 6.6 论点六：价格发现不是失效，是迟到但已启动

**旧档表述「万亿市值建立在 2.67% 自由流通盘上、价格发现机制本身失效」须改写。**

事实：
- 2026-07-08 首次解禁：11 家基石约 2,568 万股（约总股本 5.76%），解禁市值 >400 亿 HKD。当日低开 2.92%、盘中一度跌近 10%，**随后反弹涨近 15%**；近七成基石对应机构表态长期持有。自由流通盘由 <3% 扩至约 **9.7%**。
- **随后价格发现剧烈运作**：股价自 **2,980 HKD** 高点回撤逾七成（2026-07-30 单日 −16.55%）；**2026-08-18 单日 −17%，最低触及 1,000 HKD 关口**，成交额 >66 亿 HKD；**2026-08-14 卖空 88.52 万股 / 卖空成交 11.60 亿 HKD，双双创 2026-07-09 以来新高**。

**改写后的表述**：**价格发现已在补课，且补课已完成大部分——它不再是"机制失效"，而是"机制迟到但已启动"。** 这**削弱**了 B1 作为"未来还有一次崩塌"的预测力，但**不削弱**"当前估值仍由较薄流通盘与叙事共同定价"这一层。

**残余供给风险**：**2027-01-08 约 40% 待解禁**（旧档承袭数字，本轮**无法证实亦无法证伪**，A2 已查公司公告转述、财联社、新浪港股频道）。**反向纪律**：解禁当日的坚挺**不作为"已消化"的判据**——7/8 当日反弹近 15%，其后仍完成 −70% 重定价。

**口径警告**：腾讯行情 [70] 报"已上市流通股 241,094,605 股（占总股本 51.78%）"，这是**已上市 H 股口径，不是自由流通盘**，与旧档"自由流通盘 9.7%"（扣除基石/禁售后的实际可交易量）**不可混用**。8/31 的最新自由流通比例**【缺】**。

### 6.7 赛道级会计现象（裁定 §4.1 要求单独成段）：IFRS 与经调整亏损方向相反

| 口径 | 1H2025 | 1H2026 | 方向 |
|---|---|---|---|
| **IFRS 期内亏损** | −23.56 亿 CNY | **−20.71 亿 CNY** | **收窄 12.1%（看似改善）** |
| **经调整净亏损** | −17.52 亿 CNY | **−19.64 亿 CNY** | **扩大 12.1%（实为恶化）** |
| 两者差额（一次性项合计） | 6.04 亿 | **1.07 亿** | 一次性项几乎消失 |

**机理**：1H2025 的 IFRS 亏损含约 6.04 亿 CNY 一次性项，主要为**可转换可赎回优先股公允价值变动**——IPO 前优先股按 IFRS 列为**金融负债**，其公允价值上升即形成账面亏损（这同时是 IPO 前股东权益为 **−81.11 亿 CNY** 的成因，纯会计事件、非经营恶化）。2026-01-08 上市后优先股全部转为普通股，该项目消失；1H2026 一次性项仅剩 1.07 亿（估计为股份支付 + 汇兑 + 政府补助的净额，**明细【缺】**）。

**这是赛道级现象，不是个体特征**：[MiniMax](../MiniMax/index.md) 同期同样呈现 **IFRS 亏损收窄 11% / 经调整净亏损扩大 111.2%**，成因是同一个优先股转股机理。

> **结论：剔除一次性项后的可比口径是"经调整净亏损扩大 12.1%"。媒体标题普遍写的"亏损收窄 12.1%"是 IFRS 口径，具有误导性——它反映的是资本结构变化，不是经营改善。任何只引 IFRS 的分析都会系统性高估这批公司的经营改善程度。本档全档两口径并列。**

## 7. AI / 概念潜力（分维度，每维度打标）

> **敞口层级判定：业绩层，100%。** 全部收入来自大模型（开放平台及 API 8.25 亿 CNY 占 86.5%，本地化部署 1.29 亿占 13.5%），**无需论证"是否蹭概念"**。以下按维度深挖，非打标签。

### 7.1 维度一：模型能力与技术领先 —— 【真敏感】

- GLM-5.3（2026-08-14 发布，总参约 744B / 激活约 40B）：Artificial Analysis **综合智能指数 60 分，与 Kimi K3 并列开源模型第一**；Agentic 指数 **59 分**，14 模型对比中排第 2；对 DeepSeek V4-Pro 0813 的 Agentic 分差 **+9**，八项细分评测胜 7 项。Terminal Bench 3.0 由 4.6 → 28.3，DeepSWE v1.1 由 46.2 → 66.9。
- GLM-5.3-Flash（320B 总参 / 18B 激活 MoE，MIT 开源，GLM-5 系列首个原生多模态）：AA 57 分；2026-08-20 以匿名代号"Ox Alpha/牛来"登顶 OpenRouter 日榜，**单日逾 4 万亿 token，破平台历史纪录**；8/26 正式开源。
- 2026-08-19 GLM-5.3 API 正式上线，**定价与 GLM-5.2 持平**（未提价、未降价）。

**理由**：这是真业绩驱动的能力基础，且旧档触发器 4（技术领先被抹平）本轮**被明确证伪**。
**但领先的经济含义必须诚实标注**：2026-08-13 DeepSeek V4-Pro 上线，AA 53 分**追平 GLM-5.2**；智谱**次日**发 GLM-5.3 才拉开差距。**领先幅度以分计、领先时长以天/周计——这是跑步机，不是护城河。** 第三方横评的结论是**能力分域**而非单一冠军：Kimi-K3 领先代码生成与终端操作，DeepSeek-V4-Pro 领先业务流自动化，GLM-5.3 领先代码工程/安全。

### 7.2 维度二：变现兑现度 —— 【真敏感，但未证伪风险高】

- **产品层 → 业绩层已跨越**：API 收入 8.25 亿 CNY（+27.4 倍），占比 86.5%，且**分部毛利率转正 24.6%**。这不再是"有能力"，是"已贡献可量化营收"。
- **但兑现节奏 / 在手订单 / 客户导入阶段全部【缺】**：零具名客户、零合同负债、零订单簿。"前十大客户日均调用量 +98%"是**活跃度而非承诺量**。
**理由**：变现已发生且可量化（【真敏感】），但其**持续性没有任何前瞻性凭据**（未证伪风险高）。

### 7.3 维度三：算力自主度 —— 【真敏感】

10 万级国产芯片规模化推理已落地（GLM-5.3-Flash 全部由国产卡承载，中报硬披露），单位 token 推理成本较年初 −80%，云端毛利率转正的三大归因之一即为推理成本下降。**本轮由"叙事"升级为"已验证"。** 1GW 数据中心的投入规模仍【缺】（见 §6.4）。
**理由**：已有可量化的成本侧兑现证据，不是宣传口径。

### 7.4 维度四：订单能见度 —— 【蹭概念级披露】

ARR「按月年化 US$1.6bn / 按末周年化 US$2.0bn」的口径包装远大于实质合同：与 IFRS 入账 API 收入年化的裂口达 **6.5–8.7x**，公司自己给出两个版本已自认极值属性，且**中报未官方确认 US$1bn**。合同负债、在手订单、具名客户**全部为零披露**。
**理由**：这一维度上，公司交付的是口径而非承诺量——**是全档唯一一个被打【蹭概念】的维度，也正因如此它被列为首要风险。**

### 7.5 AI 叙事是否已被充分定价（x-ai lens 双面必答第二条）

**是，且仍严重超前定价。** PS(TTM) **320.7x** / 1H26 年化 PS **250.0x**，同口径下是 MiniMax（**58–59.6x**，A1/A3 两路独立测算，本档并列不择一）的约 **4.2–4.3 倍**、商汤（10x）的 25 倍；市值是 MiniMax（1,058–1,098 亿 HKD）的约 **5.07 倍**，而 1H2026 收入只比它多 21%。
**本档不用"AI 想象空间"稀释"价格太贵"**：[valuation.md](valuation.md) 中三档的 owner earnings 基础**全部来自实际入账收入**，ARR 与任何未兑现概念**一律未进入估值分母**（x-ai lens 双面必答第一条）。旧档"市场已把 bull 当 base 定价"的结论本轮**未被推翻**——反而因 bull 单档安全边际由 +2.8% 转为 **−27.9%** 而**加强**。

### 8.2 对冲后的结论

**定价范式已经切换，而智谱恰是板块里叙事最重、利润表最远的那一个。** 云端分部毛利率转正是它在这个新范式下**唯一的入场券**——它证明了这门生意在单位层面可以不亏钱。但入场券不是通行证：集团层面仍在扩大亏损（经调整 −19.64 亿，+12.1%），研发/收入 2.23 倍。

**这对当期不利，但它同时定义了本档的观察路径**：真正会让评级移动的不是股价，是[云端毛利率的爬坡斜率](index.md)——这是全案唯一一个"改善则整条 base 路径上移、恶化则直接切 bear"的单一变量。

### 8.3 增长的最强反驳前置（x-growth lens 双面必答，裁定 §6 明令不得省）

> **份额侧证伪：智谱可能正在被 Agent 普适化浪潮绕开。**
> - **MiniMax 月调用量约 6.9 万亿 token，为智谱 2.7 万亿的 2.6 倍。**
> - OpenClaw 类 Agent 工具榜霸榜的是 **Kimi、MiniMax、MiMo、Qwen**；GLM-5 仅"曾短暂登顶"。
> - 论点：智谱走精品/高价路线，**系统性错过普适 Agent 驱动的轻量高频增量红利**，调用量天花板低于大众化工具的日活规模。
>
> **与"GLM-5.3-Flash 破 OpenRouter 纪录"（8/20 单日逾 4 万亿 token）构成直接对立证据，本档并列而非择一**：8 月的破纪录是**开源免费 Flash 模型冲量**，与**高价旗舰 API 的变现分属两条曲线，冲量不自动等于 ARPU**，**不可互证**。

**第二条反驳（扩产侧）**：智谱的"扩产"（1GW）与同业是否在**一起扩**、未来是否产能过剩？本轮无法回答——1GW 的投资额与时间表【缺】，同业算力扩张的可比口径亦【缺】。**但可以确定的是：这不是赌行业景气式的扩产，因为它连 capex 都还没花出去**（1H26 仅 3.90 亿 CNY）。风险因此不在"过剩"，而在"承诺与执行的数量级缺口"。

**第三条反驳（国际化天花板）**：智谱自 2025-01-15 列入 BIS 实体清单，向其托管 API 发送受控技术构成需许可的出口而 BIS 推定拒绝——**这是国际化的结构性天花板**。对照：**MiniMax 1H2026 海外收入占 60.8%，智谱基本无此选项**。这是两家同赛道公司在成长天花板上的根本差异，**对智谱不利**，且本轮实体清单状态**无变化**（2026-08 后状态【缺】）。
