## 0. 结论摘要

**评级：watch（维持，不翻转）** —— 期望内在价值 **212.8 HKD/股**，现价 **1,195.00 HKD**，**安全边际 −82.2%**（旧档 374.6 HKD / −62.1%）。

| 情景 | 目标年 | 每股内在价值 | 概率 | 终局 PS | 一句话 |
|---|---|---|---|---|---|
| Bear | 2028E | **28.6 HKD** | **40%** | 4x | 触发器 2a 命中（H1 营收 9.539 亿，仅阈值 47.7%）；ARR 裂口证明 forward 锚失效；本地化退场后收入基数被打回真实量级；A 股 8% 上限发行摊薄落地 |
| Base | 2029E | **160.2 HKD** | **45%** | **9x（触发器 3 命中，由 12x 执行下修）** | API 月度经常性收入线性放量，FY2029E 收入 123 亿 CNY；云端毛利率爬坡但不足以覆盖 40 亿+/年研发；仍不盈利，按 PS 定价 |
| Bull | 2030E | **861.7 HKD** | **15%** | **18x（封顶，未放宽）** | 1GW 国产算力兑现推理成本继续下行，2030E 收入 350 亿 CNY，云端毛利率过 50%，首次实现经营性盈亏平衡 |

Σ概率 = 40% + 45% + 15% = **100%**｜期望值 = 0.40×28.6 + 0.45×160.2 + 0.15×861.7 = 11.44 + 72.09 + 129.26 = **212.79 → 212.8 HKD**（算术自检通过）。

**四句话结论**：

1. **多头这一轮拿到了真东西，必须先说。** 收入结构在半年内 180 度置换：本地化部署占比 73.7%→**13.5%**（绝对额 −20.5%），开放平台及 API 占比 15.2%→**86.5%**（8.25 亿 CNY，+27.4 倍）。**云端分部毛利率由 −0.4% 转正至 +24.6%**，单位 token 推理成本较年初 **−80%**，每投入 1 元算力对应 API 收入 **+14 倍**。旧档"收入是一次性项目交付、客户零留存"这条空头论点的**事实基础被推翻**（详见 [§6](thesis.md)）；旧档"定价权不存在于赚钱这一层"的表述也**必须废弃**——定价权在单位经济层已被证明存在。
2. **空头这一轮拿到的东西更硬，因为它打的是估值锚本身。** 旧档 forward PS 59x 的分母是 ARR US$1bn；本轮中报 ARR 升至 US$1.6bn（按月年化）/ US$2.0bn（按末周年化）≈ 114–143 亿 CNY，而**同期 IFRS 口径 API 收入年化仅约 16.5 亿 CNY，裂口 6.5–8.7x**（A1 测得 6.5–8.2x、A3 测得 7–8.7x，取并集）。这不是时滞（正常 SaaS 时滞倍数 1.2–1.5x），是口径不同。**ARR 已被本档逐出估值分母与 owner earnings 基础**，唯一合法主锚是 **PS(TTM，含 1H2026) = 320.7x**（分母 14.873 亿 CNY = FY2025 7.243 + 1H2026 9.539 − 1H2025 1.909）。
3. **亏损必须两口径并列，否则会得出方向相反的结论。** IFRS 期内亏损 −20.71 亿 CNY，**收窄 12.1%**；经调整净亏损 −19.64 亿 CNY，**扩大 12.1%**。差额来自一次性项由 1H2025 的 6.04 亿降至 1H2026 的 1.07 亿——成因是 IPO 后可转换可赎回优先股转普通股、公允价值变动项消失，**是资本结构变化，不是经营改善**。这是赛道级现象（MiniMax 同期 IFRS 收窄 11% / 经调整扩大 111.2%），只引 IFRS 的分析会系统性高估这批公司。
4. **最重要的一条：最乐观情景已经托不住现价了。** 旧档 bull 单档安全边际 +2.8%（勉强为正），本轮股价上涨 21%（987.50→1,195.00）叠加 base 支柱由 12x 下修至 9x、bull 门控三要素两项下调，**bull 单档安全边际转为 −27.9%**。即"把 2030 年 350 亿 CNY 收入 + 18x 终局 PS 这条最好的路完整走完，今天买入仍是亏的"。这是本轮评级不能松动的算术理由，与任何叙事无关。

## 10. 评级决策

### 10.1 期望内在价值 vs 实时市值

| 项 | 值 |

| **安全边际** | **(212.8 − 1,195.00) / 1,195.00 = −82.2%** |
| 确定性等级 | **低**（无法可靠估算的边缘：无盈利、无在手订单、无合同负债、主锚 PS 单一） |
| 按 buffett 框架所需折价 | 不确定性因素存在 → 40–50%；**低确定性 + 主锚单一 → 本档要求 40% 折价起** |

> 每股口径说明：bear/base 采用 A 股 8% 上限发行后的 pro-forma 股本 **506,112,054 股**（= 465,623,090 ÷ 0.92），bull 采用当期股本 **465,623,090 股**。理由与逐档论证见 [§9](valuation.md)，**不是照抄旧档**。

### 10.2 为什么仍是 watch 而不是 exclude

**四条同时成立才给 exclude，本档只满足两条：**

1. ✅ 价格无安全边际（−82.2%，且 bull 单档 −27.9%）。
2. ✅ 商业模式尚未证明能产生利润（经调整亏损仍在扩大）。
3. ❌ **护城河没有被破坏，反而在当期扩大**——GLM-5.3 在 Artificial Analysis 综合智能指数 60 分并列开源第一，对 DeepSeek V4-Pro 分差 **+9**，八项细分胜 7 项。旧档触发器 4 **被明确证伪**，这是本轮多头最硬的一条。
4. ❌ **管理层诚信无负面证据，且中报主动披露了对自己不利的数字**——毛利率 −23.6pct 与云端分部拆分都是主动给出的，未做美化。Buffett 的一票否决项**不触发**。

**判定：watch（观察，不建仓）**。它是一家生意质地正在真实改善、但价格把最好的十年提前定完的公司。**不翻转评级**；若持续跟踪中出现 §11 的降级触发，直接走 exclude。

### 10.3 买点 / 卖点阈值

| 阈值 | 值 | 说明 |
|---|---|---|
| **首次建仓价** | **≤ 128 HKD/股** | = 期望内在价值 212.8 × (1 − 40%)。**诚实披露：这较现价低 89.3%，实务上等价于"本轮不买"**，写出来是为了让下一轮有一个不可被叙事移动的算术参照，不是为了假装它可执行 |
| **加仓价** | 不设 | 无首仓即无加仓 |
| **观察转正的证据阈值**（比价格阈值更可操作） | 满足任意两条即重估：① 云端 API 分部毛利率 > 35%；② 披露合同负债/递延收入且余额 > 单季 API 收入；③ 出现具名大客户的多年期锁量合同；④ 单季经调整亏损绝对额环比收窄 | 这四条各自对应本档三条最脆弱假设的证伪路径 |
| **降级 exclude 触发** | PS(TTM) 仍 > 300x **且** 下一期 API 分部毛利率环比掉头向下 | 即"贵"与"单位经济改善中断"同时成立 |

### 10.4 相对旧档是否翻转

**不翻转**（旧 watch → 新 watch）。多空两侧同时向极端移动：收入质量与单位经济实质改善（多头），vs 估值支柱 ARR 塌掉、毛利率触发器命中、A 股摊薄在途（空头）。净结果是**安全边际由 −62.1% 恶化至 −82.2%**，评级枚举内无更差的观察档位，故维持 watch。逐项变化见 [valuation.md 末「相对旧档变化清单」](valuation.md)。

- **关联交易与客户集中度**：1H2026 关联交易附注、前五大客户集中度**均【缺】**（可比历史：FY2024 前五大 45.5%、单一最大客户 19.0%）。若后续披露显示前五大客户含股东方（美团/腾讯/蚂蚁/清华系），收入质量须重估。
