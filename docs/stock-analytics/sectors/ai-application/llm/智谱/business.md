### 1.2 能力圈判定：**边界区域，可解释但不可预测**（维持旧档判定）

**季节性回测（L25 纪律，必做）**：本公司毛利率存在"H1 高于 H2"的季节性（1H2025 50.0% vs H2 2025 37.8%，差 12.2pct），成因是本地化项目在 H2 集中验收、成本确认后置。**该偏置的方向对本轮裁决是"不利于命中"的**——季节性让 H1 毛利率天然偏高，而 1H2026 的 26.4% **同时低于** 1H2025 的 50.0%（−23.6pct）**和** H2 2025 的 37.8%（−11.4pct）。**逆着季节性方向仍大幅下跌，说明这不是日历效应而是真实结构变化，触发器 3 的判别力成立。**

**⚠️ 但「H1 占全年 26.4%」这个历史季节性参数本身已作废**——产生它的本地化年底验收业务已退场（占比降至 13.5%）。收入现由随调用量线性的 MaaS API 主导，FY2026 分布应显著更均匀，甚至因 ARR 在 Q3 陡升而**前低后高得更极端，但成因是增长曲线而非验收周期，与旧季节性完全不同源**。**[valuation.md §9.5](valuation.md) 因此改用分部重建法做 FY2026E 外推，不用该参数。**

### 3.3 增长拆量价与增长质量

**价**（2026 年内提价路径，累计约 +83%，【软】）：2026-02 代码订阅套餐 **+30%** → 2026-03 旗舰 API **+20%** → 2026-04-08 经 OpenRouter 的 GLM 系列 API **+10%** → 2026-07-30/31 GLM Coding Plan 改版为透明积分制（Pro 档涨幅 >150%、Max 档约 +61%，整体 30% 起）。
> **⚠️ 净提价幅度被旧档高估**：7/31 那次提价**同时配了老用户 V1/V2/团队版权益不变可按原价续订 + 7/31–8/15 新套餐年付 7 折 / 季付 8 折**——**这是带补偿的提价，不是纯粹的定价权行使。**
> 中报口径的兑现证据：**API 平均售价 +约 101%**。

**量**：1Q26 提价后调用量 **+400%**【软】；**token 调用量较年初 +40 倍以上**（截至 2026-08-31，中报口径）；**付费日活 +603%**；前十大客户日均调用量 **+98%**；企业及开发者用户 **>740 万**（较年初 +144%）。
> **口径切换警告**：旧档"9.2 倍"是 1Q26 单季拆解，本轮"+27.4 倍"是 1H26 分部收入同比，**二者不可混谈**。

**增长质量判定：高速、真实，单位经济已转正，但规模化盈利仍未证明。**

| 正面 | 负面 |
|---|---|
| 云端分部毛利率 −0.4% → +24.6% | 集团混合毛利率 41.0% → 26.4%（结构稀释） |
| 单位 token 推理成本较年初 −80% | 研发 21.31 亿 = 收入的 **2.23 倍** |
| 每元算力对应 API 收入 +14x | **经调整净亏损扩大 12.1%** |
| API 均价 +101% 而量 +40x（量价齐升） | 收入放大 5 倍而亏损仍在扩大 → **经营杠杆尚未跑赢研发军备竞赛** |

> ⚠️ **增长的低基数属性必须写出**：+399.7% 的分母是 1H2025 的 1.909 亿 CNY，增量几乎全部来自 API（+27.4 倍）——**这是从零起量的曲线，不可外推**。且高增长伴随毛利率 −23.6pct，含"用毛利买增长"的成分。

## 4. 全球竞争力

### 4.1 模型能力：国内第一梯队，全球开源第一梯队

- **GLM-5.3**：Artificial Analysis 综合智能指数 **60 分，与 Kimi K3 并列开源模型第一**；Agentic **59 分**，14 模型对比排第 2；对 DeepSeek V4-Pro 0813 分差 **+9**，八项细分胜 7 项。
- **GLM-5.3-Flash**：AA **57 分**，GLM-5 系列首个原生多模态，MIT 开源；2026-08-20 登顶 OpenRouter 日榜、**单日逾 4 万亿 token 破平台纪录**；定价约为 Claude Opus 4.8 的 **1/40**。
- 中国开源模型占 OpenRouter token 流量份额：2024 年底 **<2%** → 2026-04 **>45%**【软】。

**vs 国际龙头的差距**：闭源前沿（OpenAI / Anthropic / Google）仍在综合能力上领先；智谱的定位是**开源第一梯队 + 极致性价比**。**Anthropic / OpenAI 的 2026-08 一级市场估值本轮【缺】**（旧档的 Anthropic 20.5x 未能刷新），**不得用道听途说的一级估值给港股锚定**。

### 4.3 结构性天花板：美国实体清单

### 5.2 定价权的重评（本轮最重要的护城河判断变化）

**旧档判定："定价权只存在于能不能卖出去这一层、不存在于卖出去能不能赚钱这一层"——本轮废弃。**

**新判定**：**定价权在单位经济层已被证明存在**（云端分部毛利率 −0.4% → +24.6%、API 均价 +101% 而量 +40x、单位算力变现 +14x），**但尚不足以抵消 mix 稀释**（集团毛利率 41.0% → 26.4%）。**云端毛利率的爬坡斜率是全案最关键的可证伪变量。**

**两条必须并列的限定**：
1. **供给受限下的量价齐升不能单独证明定价权**——管理层在 2026-03-31 业绩会自承"最近确实存在算力供给的约束和瓶颈"，供不应求下的提价成功有产能不足的成分。
2. **7/31 提价是"带补偿的提价"**（老用户价格锁定 + 限时 7 折），且 **GLM-5.3 API 定价与 5.2 持平，提价动能在 8 月停止**。提价后的留存实证**【缺】**——中报"付费日活 +603%"口径截至 6/30，**早于 7/31 提价**，不能用来验证提价后留存。

**护城河总评：中等偏弱，趋势为"成本侧走阔、能力侧持平、黏性侧未改善"。** 未到"破坏"（[index.md §11.4](index.md) 卖出标准第 2 条判否），但也远不足以支撑 [valuation.md](valuation.md) 中超出 buffett 框架的终局倍数。
