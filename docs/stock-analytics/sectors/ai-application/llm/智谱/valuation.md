## 9.1 估值方法选择：为什么是 PS，为什么不是别的

| 方法 | 可用性 | 理由 |
|---|---|---|
| **PE** | **N/A** | IFRS 与经调整两口径均为大额亏损（−20.71 / −19.64 亿 CNY） |
| **PB / Altman Z** | **禁用** | IPO 前可转换可赎回优先股按 IFRS 列为**金融负债**，导致股东权益 −81.11 亿 CNY（旧档口径）；转股后金额**【缺】**、6/30 净资产**【缺】**。腾讯行情 [58]=20.93 亦不可用（分母失真），[50] 字段**不是 PB**。任何 PB 与 Altman Z 在本档一律不引用 |
| **DCF（利润折现）** | 不适用 | 无正 owner earnings，且首次盈亏平衡年份本身是三档之间的核心分歧变量 |
| **EV/Sales** | **不切换** | **净现金占市值比检验**：pro-forma 现金约 **269 亿 CNY = 313.8 亿 HKD**（= 6/30 报表现金【缺】 + 2026-07-09 配售净额 313.75 亿 HKD）。**为什么必须做 pro-forma 而不能直接读中期表：313.75 亿 HKD 的配售发生在 2026-06-30 之后，因此不在中期资产负债表内**——中期表上的现金余额天然不含这笔钱，直接引用会严重低估可用资金。该 pro-forma 现金占 5,564.196 亿 HKD 市值的 **5.6%**。兄弟档 [MiniMax](../MiniMax/index.md) 确立的口径是**净现金占市值 >15% 才切 EV/S**，5.6% 远未达标 → **保留 PS 主锚**，并在 §9.5 bear 档单独做现金地板检验 |
| **PS(TTM)** | **主锚** | 见 §9.2 |
| **RIM / 资产法主锚** | 不适用 | buffett-doc-spec §3 的准入判据是 bull<base + 资产法可托底；本档 bull>base 且为轻资产亏损软件型公司，两个条件均不满足（同 memory `rim-ironlaw-not-for-asset-light-software`） |

### 9.3 ARR 为什么被逐出估值分母

| 对照 | 数值（CNY） |
|---|---|
| 1H2026 **实际入账** 开放平台及 API 收入 | 8.25 亿（半年） |
| 线性年化 | **16.50 亿** |
| 公司 ARR US$1.6bn（按月年化）× 6.7439 | **107.90 亿** |
| 公司 ARR US$2.0bn（按末周年化）× 6.7439 | **134.88 亿** |
| **裂口倍数** | **6.5x – 8.7x**（A1 测得 6.5–8.2x、A3 测得 7–8.7x，**取并集区间并注明两路测算**） |

要让 ARR US$1.6bn 成立，8 月单月 MaaS 收入需 ≈ **9.0 亿 CNY** —— 相当于整个上半年全部收入（9.539 亿）的 **94% 在一个月内实现**。正常 SaaS 中 ARR 领先确认收入的时滞倍数约 **1.2–1.5x**（领先 1–2 个季度），**6.5–8.7x 不是时滞能解释的**。公司自己给出两个版本（月化 / 末周年化）已自认口径的极值属性。

**裁定：ARR 的增长方向可信，绝对水平不可信。ARR 严禁进入 PS 分母，严禁进入任何情景的 owner earnings 基础**（x-ai lens 双面必答第一条）。旧档把 ARR US$1bn（≈68 亿 CNY）当作最大估值杠杆的做法，本轮被中报实际入账数字事实性废除。

### 9.4 bull 门控三要素（红线 8，命中 x-growth lens 必算）

**强度裁定与概率取值分开写**：强度回答"证据变好没有"，概率回答"据此赋权多少"。

| 要素 | 本轮证据 | 强度裁定 | 相对旧档 |
|---|---|---|---|
| **(a) 算力扩产确定性** | 1GW 全国产 AI 算力数据中心「落地建设」【软，公司口头宣布，未见港交所自愿性公告编号】；**投资总额 / 建设时间表 / 资金结构 / 选址 / 芯片供应商名单全部【缺】**。**新增反向证据：1H2026 资本开支仅 3.90 亿 CNY，与 1GW 级数据中心通常数百亿 CNY 的行业量级差两个数量级**，且该 3.90 亿的主因是收购北京红钻科技带来的物业厂房设备，不是算力建设。三种解释（合作方/国资建设而智谱承租、尚未开工、分期极长）公司均未澄清 | **弱-中**（由旧档"偏硬但不可量化"**下调**） | ⬇️ |
| **(b) 客户 capex 能见度** | 具名客户 / 在手订单 / 合同负债**仍全部为零**。中报新增"前十大客户日均调用量 +98%"，但这是**活跃度而非承诺量**，且**不具名**。按 x-growth lens ②③ 只能降级到"终端兑底"，而终端兑底本身口径分歧扩大（见 (c)） | **弱**（维持） | ➡️ |
| **(c) TAM 跑道** | 口径分歧由旧档 3 倍**扩大到约 9 倍**：IDC「中国大模型训练与推理公有云」2025 = **79.4 亿 CNY** vs 艾媒「中国 AI 大模型」2026E = **738.57 亿 CNY**。对应智谱份额 **9.1%**（FY2025 收入 7.24 亿 / IDC 口径）vs **2.6%**（1H26 年化 19 亿 / 艾媒口径）——"已占近一成、天花板不远"与"渗透率个位数、空间巨大"完全反转。**两个口径必须并列，不得单选**。沙利文 2026 版口径**【缺】** | **弱-中**（由旧档"中"**下调**） | ⬇️ |

> **门控结论**：三要素**无一升级、其中两项下调**。按 buffett-doc-spec §3 与红线 8，**bull 概率封顶 20%、终局 PS 封顶 18x，维持且不得放宽**。本档在封顶之内进一步取 **15%**——**理由不是触发器 4**（触发器 4 已被明确证伪，技术面不构成 bull 下调依据），**而是门控要素 (a)(c) 本轮实质下调**：旧档给 20% 时 (a) 是"偏硬"、(c) 是"中"，现在两者都是"弱-中"，赋权理应随证据强度同向移动。

## 9.5 三情景构建

### 收入路径的重建起点（约束 1：不得从 ARR 68 亿起算）

旧档 base 的"2029E 收入 180 亿 CNY"起点是 ARR 68 亿 CNY，**该起点已作废**。新起点是**实际入账收入 1H2026 = 9.539 亿 CNY**。

**FY2026E 年化方法论**：
- ❌ 不用"H1 占全年 26.4%"外推（季节性成因是本地化年底集中验收，该业务已退场至 13.5%）。
- ✅ 用**分部重建**：本地化部署 1H26 = 1.29 亿，公司称主动"重质轻量"战略压缩，H2 假设 1.5–2.0 亿；API 为月度经常性、随调用量走，1H26 = 8.25 亿而 8 月单月已在 ARR 陡升区间，H2 假设 11–13 亿（**前低后高，但成因是增长曲线而非验收周期，与旧季节性完全不同源**）。
- → **FY2026E 收入区间 22–26 亿 CNY**，三档分别取 22 / 24 / 26 亿。

**bull 隐含 PE（约束 6，必须披露）**：bull 终局权益价值 6,300 亿 CNY ÷ 2030E 净利润 70 亿 CNY = **隐含 PE 90x**。
> **诚实披露**：90x PE 给一家 2030 年才刚刚做到 20% 净利率的公司，本身已远超 buffett 框架下任何倍数档位（周期/衰退型 <8×、窄护城河 8–12×、宽护城河成长股 20–30×）。这说明 **bull 档的 18x 终局 PS 不是保守假设，而是已经把一个极其乐观的终局提前定完**。之所以仍保留 18x 而不下修，是因为 18x 是门控封顶值、且下修会让"bull 也无安全边际"这个结论显得像是靠调参得来的——**本档宁可给多头最宽松的假设，让结论由算术而非选择产生**。

### bear 档现金地板检验（约束 7）

pro-forma 现金约 **269 亿 CNY**（= 6/30 报表现金【缺】 + 313.75 亿 HKD 配售净额 × 0.8572）。**再次强调：该配售发生在 2026-06-30 之后，不在中期资产负债表内，故必须以 pro-forma 形式构造，不得写成"期末现金"。**

| 步骤 | 值 |
|---|---|
| 今日 pro-forma 现金 | 269 亿 CNY |
| 至 2028-12-31（2.33 年）累计消耗（经营 −13.3 亿/半年 + capex，按约 38 亿 CNY/年，且 bear 档研发不减） | −88.5 亿 |
| 2028E 残余现金 | 180.5 亿 CNY |
| **烧钱公司折价 50%**（见下） | 90.3 亿 CNY |
| 折现回今日（÷1.3849） | 65.2 亿 CNY = **76.1 亿 HKD** |
| 每股（÷506,112,054） | **15.0 HKD** |

**现金地板 15.0 HKD < PS 法 bear 28.6 HKD → 现金地板不构成约束，bear 取 PS 法的 28.6 HKD。**

> **重申：烧钱公司不享有现金面值保护。** 一家每年净烧 38 亿 CNY、且烧钱强度随算力军备竞赛上升的公司，其账面现金对股东的意义是"距离下一次融资还有多久"，不是"清算能拿回多少"。市场从不给这种资产负债表以面值定价——旧档所引媒体口径"现金可维持约 1.9 年"用的是 2025 末 22.59 亿余额、未计 IPO 与配售，**严重低估续航，本档禁止引用**；但反过来，计入配售后续航超 5 年这一事实，也**只解除近期破产风险，不构成任何估值支撑**。
