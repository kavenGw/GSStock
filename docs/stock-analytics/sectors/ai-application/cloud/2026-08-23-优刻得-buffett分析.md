### 3.5 增长拆量价（成长 lens 必答）

**量【硬，但增量不来自新产能】**：

**价【缺】**：

### 3.6 增长质量 —— 增长是否伴随毛利改善？（成长 lens 必答）

**表面上是（毛利率 +3.40pct），实质上不是。** 三条量化：

**① 边际扣非利润率 ≈ 0.62%**
```
Q1 → Q2 收入增量 = 5.4290 − 4.3875 = +1.0415 亿（环比 +23.74%）
Q1 → Q2 扣非改善 = −810.73 − (−874.98) = +64.25 万
边际扣非利润率 = 64.25 万 / 1.0415 亿 = 0.62%
```
**收入环比增了近四分之一，扣非只改善 64 万。增量收入的边际盈利能力接近于零。**

**② 毛利首次覆盖期间费用，但只多 966 万**【推算-A2】
```
H1 毛利 2.7838 亿 − 期间费用 2.6871 亿 = +966 万元
```
这是一个真实的里程碑（旧档时点尚未达成），但缓冲厚度只有营收的 1%——**任何一个季度的毛利率回落 1pct 就会把它吃掉**（H1 毛利率每降 1pct ≈ 982 万）。

**③ 增长的一部分来自研发欠投**【硬】
研发费用 +1.14%（9,979.89 万）而营收 +24.09%；研发投入占营收比 **12.47% → 10.17%**；研发人员 344 人（+4.9%）但**人均薪酬 −6.9%**；博士 0 人、50 岁以上 0 人。研发**零资本化**（会计保守，正面）。**当"减亏"的一部分来自研发强度下降，这部分改善不可持续。**

### 3.7 ROIC / owner earnings —— 全为负，且边际回报有了硬数字

- **ROE**：2025 摊薄 −3.07%；2026H1 归母 +807.72 万 / 归母权益 24.6139 亿 = **+0.33%（半年度）**，年化约 0.66%，且 100% 来自非经常性；**扣非 ROE(H1) = −0.68%**。
- **ROIC 为负**（NOPAT 为负）。buffett 的 ROIC > WACC 条件**完全不成立**，且已连续六年不成立。
- **owner earnings 为负**：FCF(H1) = 0.6744 − 3.9069 = **−3.2325 亿**；2025FY FCF −4.6037 亿。维护性 capex 与成长性 capex 拆分【缺】，故 owner earnings 无法精确计算，方向明确为负。
- 🔴 **本轮首次拿到"边际 ROIC"的公司自报代理值：募投项目税后 IRR 8.49%、税后回收期 8.30 年（含建设期 3 年）、测算期 14 年、年均收入 3.0085 亿、年均毛利率 39.46%。**

> **这是本档最重要的一个数字。** 8.49% 的税后 IRR 意味着：这家公司把 18.17 亿资本投进它最核心的成长项目，能拿回来的边际回报是 8.49%。而它的股权成本（无分红、26 季扣非为负、资产负债率一年升 5.26pct、AB 股无制衡、Altman-Z 型财务弹性差）**不可能低于 12%**。**边际 ROIC < 股权成本 = 每投一块钱毁灭价值。** 更要命的是，8.49% 已经是公司自己在保荐机构核查下给出的**乐观-中性**值（按当前价外推、未假设涨价、AI 服务器利用率假设 90%、机柜托管稳定期 85%）——**若算力单价下行，IRR 会迅速跌破资金成本。**

### 5.3 管理层与治理透镜

**① 诚信维度（buffett 的一票否决项）—— 黄灯，本期未恶化**

旧档因"三期报表更正是在交易所问询语境下完成、且更正方向恰好让 2025 减亏更好看"把诚信从"未见问题"降为黄灯。**本期核查结果：合规勾选项全绿**——无新前期差错更正（权益变动表该行为空）、无新问询函、无非标意见、无处罚、无重大诉讼；独董更替系任期满 6 年常规轮换。**这是旧档 Top1 风险明确未触发。**

**仍在的减分项**：AI 相关收入连续两期（2026Q1、2026H1）只给"占比超过 40%"，**拒绝披露金额、口径定义与同比**——这是公司对市场最关心的一个指标持续给出不可验证表述。**这不构成不诚信，但它意味着最重要的成长指标无法被独立验证。**

**② AB 股绝对控制 —— 旧档的两口径之争已收敛【订正】**

旧档并列了"表决权 39.39%（无法复核）"与"推算 57.4%"两个口径。**本轮半年报原文给出确定答案**：季昕华/莫显峰/华琨持 A 类股 **97,688,245 股**（季昕华 50,831,173 / 莫显峰、华琨各 23,428,536），每股表决权 = B 类的 **5 倍**；**季昕华个人表决权 38.27%**；公司自述"对公司的经营管理以及对需要股东大会决议的事项具有**绝对控制权**"；特别表决权设立于 2019-03-17，**除非股东大会决议终止将持续、长期运行**。

保荐书按 2026-03-31 股本测算，定增后三人合计持股降至约 **14.81%**、表决权 **39.39%**（旧档 39.39% 的出处由此确认，是**定增后**口径而非当前口径）。

> **治理判定：在一家扣非连亏 26 季、正在向股东伸手要 15 亿的公司里，实控人以约 21% 的股本掌握绝对控制权，且该安排长期运行。这是治理减分项。** 但需双面：AB 股本身是科创板允许的合法安排，且实控人**未减持**（2026-05/07 董事王凯、曹宇合计减持约 8.25 万股 = 总股本 0.018%，噪音级）。

**③ 资本配置（一美元留存标准）—— 本轮首次可以量化，结论是不达标**

- **加分**：主动收缩低毛利业务换毛利率（营收 2021 年 29.01 亿 → 2024 年 15.03 亿，毛利率 3.36% → 18.86%）符合"宁要高质量的小生意"的纪律；乌兰察布 92.78% 利用率证明该笔重资产投入在利用率上兑现了。
- **减分（本轮量化）**：**募投项目税后 IRR 8.49%、回收期 8.30 年**。以任何合理的股权成本衡量，**每 1 元留存创造 <1 元市值** —— 这不再是"待验证"，而是**公司自己在保荐机构核查下算出来的数字**。而且三年资金缺口 26.28 亿 > 募资上限 15 亿（覆盖率 **57%**），差额仍需借款或二次融资。
- **股本变动**：总股本从 456,305,081 增至 **460,705,081 股**（+4,400,000 股，2026-06-11 公告），增量来自 2024 年限制性股票激励计划第二个归属期第一批次归属，**不是定增**。
- **分红**：上市（2020-01-20）以来**仅 2019 年度分红一次**（10 派 0.50 元，2020-08-18 除息），此后 **2020–2025 连续六个年度未分红**，半年报明确无分配预案 → **`dividend_yield = null`**。（现金流表"分配股利、利润或偿付利息支付的现金"421 万系利息支出，非股利。）

## §6 核心新论点（结构性 vs 周期性二分 + 最强反驳前置）

### 6.1 新论点

旧档的核心命题是"**生意确在变好、但证据质量在变坏**"。半年报到位后，这个命题的两端都需要修正，且**问题的性质迁移了**：

> **本档命题：优刻得的问题已从"账可不可信"迁移到"这门生意本身值不值这个价"。**
>
> 半年报同时证实了三件事：**营收在真加速**（Q2 +30.72%，近三年最快）、**旧档的会计/监管信用风险未再触发**（这是对空头最实质的反驳）、**以及——盈利转正是假的、毛利改善是会计的、扩产的边际回报只有 8.49%**。
>
> 一句话概括：**优刻得正在把一门公司自报税后 IRR 8.49% 的重资产电力/机柜生意，用 7.95 倍 PS 的软件式估值卖给市场；而这门生意里最赚钱的板块（IDC/AIDC，毛利率 43.61%），恰恰是客户集中度最高（前五 50.53%、单一 26.79%）、合同锁定度最低（RPO 占 TTM 营收 6.89%）的那一块。**

### 6.2 结构性 vs 周期性 vs 会计性 —— 三分判定

| 成分 | 判定 | 依据 |
|---|---|---|
| 收入加速（+24.09%，Q2 +30.72%） | **结构性为主** | 驱动来自境外节点扩张（19.83%）+ IDC/AIDC 结构升级 + 存量利用率爬坡（青浦 57.65%→65%）；三者都不是周期脉冲 |
| 综合毛利率 28.36% | **会计性为主** | 公司自报四项归因无一是涨价；折旧曲线 3.53→3.03→2.03→1.43 亿；GPU 折旧年限 4→5 年。**且 2027 反转** |
| 归母首次转正 | **一次性** | 非经常性损益 2,493.43 万 > 归母 807.72 万，四项无一与主业相关 |
| IDC/AIDC 板块 43.61% 毛利率 | **半结构性** | 区位电价 + 折旧未满额；需在 D 楼折旧满额后重测 |
| RPO 6.89% / 零订单公告 | **结构性（商业模式决定）** | 收入确认全部"按客户实际使用量和约定单价按月确认"——**业务模式本身不产生可披露的大单**。914 条公告零命中不是"公司不爱发公告" |
| 扣非 26 季连负 | **结构性** | 六年半，穿越了两轮行业周期 |
| 流动性收紧 | **结构性** | capex 3.91 亿 > OCF 0.67 亿 是重资产扩张期的必然，不是意外 |
| 算力供给过剩 | **结构性（行业级）** | 信通院：2025 年智算"用算"占比仅 **36.8%**，约七成空转；多源确认平均利用率不足 30% |

### 6.3 最强反驳前置（四条，含一条对空头的反驳 —— 双面纪律）

**反驳 1：「归母首次半年度转正，这就是拐点。」**
**不成立。** 非经常性损益 +2,493.43 万 > 归母 +807.72 万，四项构成（资产处置 731.98 万 / 应收减值转回 848.60 万 / 政府补助 498.87 万 / 金融资产公允价值 111.33 万）**无一与云或智算主业经营相关**。更硬的反证是边际数据：**Q2 收入环比 +23.74%，扣非只改善 64.25 万，边际扣非利润率 0.62%。** 收入加速没有换来扣非改善。扣非连负纪录延长至 **26 个季度**。

**反驳 2：「毛利率 28.36%、+3.40pct，说明 3/1 的涨价成功了、护城河在升级。」**
**被公司自己推翻。** 2026-07-29 经保荐机构与立信会计师核查的问询回复中，毛利率改善的四项归因**没有一项是涨价**，其中最重要的一项原话是"实际商业运行年限长于会计折旧计提年限"。折旧曲线 3.53→3.03→2.03→1.43 亿是公告级数据。**最硬的反向验证：Q2 是提价后第一个完整季度，云计算板块毛利率却从 Q1 的 25.45% 降到约 22.03%【推算】，综合毛利率环比 −1.78pct【硬】。** 而且这份折旧红利有明确的到期日——**D 楼年底投产后 2027 年起新折旧满额计提，公司自算募投项目 T2 新增折旧摊销 = 该项目净利润的 325.26%，峰值年新增折旧摊销 2.02 亿。刚省下的折旧会原样吐回去。**

**反驳 3：「vivo 具名 + 22,100 kW 意向订单（占 D 栋外售功率 >85%），客户能见度问题已经解决了。」**
**部分成立，但两个口径必须并列。**
- **意向口径【硬】**：D 栋意向售卖功率 22,100 kW ≈ 规划总功率 75%、外售功率 >85%，客户为"部分互联网和金融行业客户"（问询函 2026-043）；2026-06-16 与 vivo 签乌兰察布 D 座机柜专属预留协议——**这是上市以来第一个具名客户，旧档的"零具名客户"被推翻，我认可这个升级。**
- **合同口径【硬】**：**RPO 仅 1.3027 亿元 = TTM 营收的 6.89%**（2026 内 0.8226 / 2027 0.2969 / 2028 0.1832 亿，下半年可确认部分约等于半个月营收）；**合同负债 −2.7%、预收款项 −10.4%，双双不增反降**；半年报"其他重大合同 **不适用**"；vivo 协议**无金额、无期限**；**E 栋公司明确"尚未主动开展大规模客户锁定工作"**——募投一半产能消化零兑证。
> **裁定：客户能见度从【缺】升级到【软】，不能升到【硬】。** bull 概率据此从 15% 上调到 20%，但被 RPO 6.89% 封在 20%（§9.3）。

**反驳 4（对空头的反驳，双面纪律）：「这家公司会计有前科、应收有雷、资金链紧，早晚出事。」**
**本期这条路径明确未兑现，我据此下调了 bear 概率。**
- 半年报合规勾选项全绿：**无新前期差错更正、无新问询函、无非标意见、无处罚、无重大诉讼**；独董更替系任期满 6 年常规轮换。
- **海马云真金白银回款 588.41 万元**（此前按"预计无法收回"全额计提），单项计提范围余额 2.4919 亿 → 2.3482 亿，坏账准备净减 849 万。
- 应收原值/TTM 营收 从旧档同口径 37% 降至 **35.6%**。
- **两条传闻被更强地证伪**：33 亿采购新增四条硬反证（H1 capex 仅 3.91 亿、固定资产原值总额 38.37 亿、公告级 GPU 算力 11,740.82P 是"2.9 万 P"的 40%、公司 8/5 公告自查否认），**且"33 亿/3.7 万 P"与华策影视 2026-05-22 真实公告数字完全一致，极可能是张冠李戴**；智谱「5 万卡/20 亿」仍零一手来源，且智谱的"20 亿"是其自身 IPO 募投 MaaS 平台金额、与优刻得无关。
> **对冲**：3 年以上账龄敞口 1.01 亿→**1.34 亿（+32%）**、单项计提比例 70.81%→**71.53%**、德阳国创 2,402.09 万零回款、**1,055.07 万司法冻结**、短期借款 +327 倍。**尾部变薄了，但没有消失。bear 35% → 30%，不是 → 20%。**

### 6.4 结构性增量 vs 周期性补涨（成长 lens 必答的二分）

**扩产是结构性需求支撑，还是赌行业景气？—— 判定：两者兼有，但赌的成分被公司自己的 IRR 数字压住了。**

**支持"结构性需求支撑"的一侧**：乌兰察布机柜利用率 92.78%、GPU 利用率 91.29%、CPU **102.86%（无余量）**——**已有产能真的卖光了**，扩产不是无中生有；D 栋意向 22,100 kW（外售功率 >85%）；AI 相关收入占比 >40%；公告级算力 2024 末 8,301.23P → 2025 末 11,740.82P（+41.4%）。

**支持"赌行业景气"的一侧（最强反驳）**：
- **同业在一起扩**：VNET 未来 12 个月交付 297MW、GDS 66,405 ㎡；万国数据上半年新签 471MW。
- **行业整体已经过剩**：信通院——2025 年智算"**用算**"占比仅 **36.8%**，约七成空转；多源确认平均利用率不足 30%。
- **公司内部就有过剩样本**：**青浦利用率从 2024 年 85.43% 回落到 2025 末 57.65%**（闲置功率 42.35%），6/30 才回到约 65%；**青浦一期已延期至 2028-01-24、效益未达预期——这是本次定增被问询的第一个问题。**
- **公司自报的项目经济性就是"景气赌注"的定价**：税后 IRR 8.49%、回收期 8.30 年，且逐年收入是一条**先升后降的曲线**（T+2 1.83 亿 → T+4 峰值 4.70 亿 → T+7 4.49 亿 → T+9 2.62 亿 → T+14 0.58 亿，T+9 之后收入全部来自机柜托管）。**这条曲线本身就承认了 AI 服务器出租收入会在 T+9 后大幅衰减。**
- 反向信号【软】：高盛 2026-07-27 称受芯片供应偏紧，上半年 IDC 入驻慢于预期。

> **裁定：扩产有真实的需求支撑（乌兰察布确实卖光了），但支撑的强度只够撑起一个 IRR 8.49% 的项目——这不是结构性成长股的经济特征，是公用事业型资本开支的经济特征。** 因此 §9 中 D/E 栋**不按"AI 高成长期权"定价**，而按其自报的资本回报定价；bull 情景的上行来自估值倍数与收入规模，**不来自扩产项目的 NPV**（在合理 WACC 下它接近零甚至为负）。

### 7.1 AI 前景深挖（AI lens：判定为 AI 真驱动，故从"打标签"升级为前景深挖）

**TAM 增速**：见 §2.1，双口径并列（中商隐含 +13.7% vs IDC +132.1%，分母差 3.65 倍）。**结论：增速方向确定，量级极不确定；本档不使用任何单一 TAM 数字驱动估值。**

## §9 估值（场景加权）

### 9.1 方法与局限（必须明示，共七条）

**传统 owner earnings / PE 法完全失效**：TTM 归母 −0.4957 亿、TTM 扣非 −0.9023 亿、扣非连续 26 季为负、owner earnings 为负、ROIC 为负、PE(TTM) = −303.22 无意义。因此沿用 **PS / PB 混合法**。

**方法局限：**

1. **PS 对重资产云本就粗糙——它不反映盈利能力差异。** 这在本标的上尤其致命：**9 家可比中，优刻得是唯一 TTM 归母与 TTM 扣非双负的**（A 股五家可比全部 TTM 盈利）。**用 PS 给一家连续 26 季扣非为负的公司定价，等于把估值锚完全建在"未来会盈利"这个假设上。这不是技术细节，是本档估值方法论的根本弱点。**
2. **A 股 vs 港美股的 PS 有系统性市场分割偏差。** A 股 IDC 池中位 ≈ **7.6x**，港美股池中位 ≈ **2.06x**，**相差 3.7 倍**。优刻得 PS 7.95x 在 A 股池排 4/6（便宜于润泽 16.73x、数据港 13.92x），在港美股池是 GDS 的 2.21 倍、金山云的 3.91 倍、VNET 的 6.65 倍。**本档 base 取 5.0x = 介于两个池之间且偏港美股一侧，本身就是对"这个分割溢价能否维持"下的一个判断，而不是一个可验证的事实。**
3. **优刻得自身的算力单价 / ARPU / 每卡收入从未披露，是最大的单一不确定源。** 行业新卡跌、老卡涨并存，卡型结构又被监管掩码，**无法判断其实际租金单价方向**。公司自己做 14 年测算时按当前价外推、未假设涨价。
4. **定增未发行，摊薄未计入。** 三情景每股价值一律用当前总股本 **460,705,081 股**计算。若 ≤15 亿 / ≤4,500 万股定增落地，发行后 505,705,081 股、新股占发行后 8.90%、**对现有股东摊薄 9.77%**；同时公司获得约 15 亿现金（净资产增厚约 61%，PB 相应下降）。**两个方向部分对冲，本档不预先计入。**
5. 🔴 **市值锚不含半年报信息。** **2026-08-21 是周五收盘、半年报 2026-08-22（周六）披露 —— 32.63 元 / 150.33 亿市值不包含任何半年报内容，2026-08-24（周一）才是市场第一次对半年报定价。** 本档所有安全边际数字都是相对这个"未反应价"计算的：**若周一及之后股价因半年报上涨，安全边际会比 −31.1% 更差；若下跌，会改善。** 使用本档结论时必须先用最新价重算一遍。
6. **分板块无同比基数【缺】。** 公司本期重构业务分类且未提供 2025H1 重述对照，IDC/AIDC 板块 2.84 亿无同比，**无法判断该板块是加速还是自然爬坡**，故不能对该板块单独建增长模型。
7. **PS 历史分位【缺】**（数据源不支持），估值的纵向坐标只有 PB 一条腿。

**估值锚定基础**（全部为已兑现事实，未兑现的算力/意向/订单不进入）：
```
实时市值   = 32.63 元 × 460,705,081 股 = 150.3281 亿元（与东财 f116 分文不差 ✓）
TTM 营收   = 4.3609 + 4.7220 + 4.3875 + 5.4290 = 18.8994 亿元（25Q3+25Q4+26Q1+26Q2）
归母权益   = 24.6139 亿元（BVPS 5.3427，PB 校验 32.63 / 5.3427 = 6.107 ✓）
PS(TTM)    = 150.3281 / 18.8994 = 7.95x
PB         = 6.11x
```

### 9.5 隐含 ROE 交叉检验（红线 #4：诚实面对"贵"）

本标的是重资产 IDC，**资产法（PB）是合理的主锚候选**。按剩余收益（RIM）口径反查各档隐含的永续 ROE：

```
公允 PB = (ROE − g) / (r − g)   →   ROE_隐含 = PB × (r − g) + g
取 r = 12%（股权成本：无分红 + 26 季扣非为负 + 资产负债率一年 +5.26pct + AB 股无制衡 + 财务弹性差）
取 g = 3%（长期名义增长）
```

| 档位 | PB | **隐含永续 ROE** | 对照 |
|---|---|---|---|
| **当前市价** | **6.11x** | **58.0%** | 公司历史最好一年 ROE = **12.48%（2017）**；近六年全为负；2025 摊薄 −3.07% |
| bull | 7.68x | 72.1% | — |
| base | 3.84x | 37.6% | — |
| bear | 2.50x | 25.5% | — |
| **公司自报边际回报（募投税后 IRR）** | — | **8.49%** | → 公允 PB = (8.49−3)/(12−3) = **0.61x** |

> **这张表必须被诚实地读出来：本档三个情景——包括 bear——隐含的永续 ROE 全都远高于这家公司历史上任何一年做到过的水平。**
> **严格按公司自报的边际资本回报（税后 IRR 8.49%）做 RIM，公允 PB 只有 0.61x，对应市值 15.01 亿 / 每股 3.26 元。**

> **但它标出了下行空间的真实量级，并解释了为什么本档要求 35% 的安全边际而不是 20%（§10）。这一条按 buffett-doc-spec 的铁律，降格进 §10 压力测试，标「❌破框架」。**

## §10 评级决策

**期望内在价值 103.51 亿（每股 22.47 元） < 实时市值 150.33 亿（32.63 元） → 安全边际 −31.1% → 评级 watch（关注，不买入）。**

**是否翻转旧档：不翻转。** 旧档 watch，本档仍 watch。但**这不是"没变化"**：安全边际 −32.0% → −31.1%（几乎持平），bull 概率 15% → 20%，bear 概率 35% → 30%，base 倍数 5.5x → 5.0x。**分布的两个尾巴都往中间收了一点，中枢的定性变差了（毛利改善是会计的、扩产 IRR 只有 8.49%），价格的结论没变。**

### 10.1 为何是 watch 而非 exclude（对偶纪律，正面事实的应有认可）

- **旧档 Top1 风险（会计/监管信用二次事件）明确未触发**：无新差错更正、无新问询函、无非标、无处罚、无重大诉讼；**海马云真金白银回款 588.41 万**。这是本轮最实质的正面证据。

- **毛利首次覆盖期间费用**（+966 万）【推算-A2】，是真实的里程碑。
- 属科技类标的，反面对照有跟踪价值；价格已从年内高点回撤 38.15%。

### 10.2 为何也不能是 config / core

**边际资本回报 8.49% < 股权成本。** 一家把增量资本投进负 NPV 项目、且必须持续投（三年缺口 26.28 亿）的公司，**规模越大、价值毁灭越多**。这是 buffett 框架里最不能接受的一类生意（"一门需要不断投入资本才能维持的生意，是坏生意"）。

### 10.4 买点阈值（价格条件）

**要求安全边际 ≥ 35%**（buffett 分档中的"存在重大不确定因素 40–50%"与"一般优秀 30–40%"之间，取偏保守一侧）。

**为何是 35% 而不是兄弟档金山云的 20%**（五条差异，逐条对齐）：
1. 优刻得 TTM 归母与扣非**双负且扣非 26 季连负**；金山云规模是其 5.8 倍，且有小米/金山股东背景提供融资通道。

3. 优刻得有**会计差错更正 + 年报问询函前科**（诚信黄灯），金山云无。
4. 优刻得**三年资金缺口 26.28 亿 > 募资上限 15 亿（覆盖率 57%）**，且定增未落地、满额需要股价先涨。

**坦率说明**：14.60 元低于 52 周最低价 22.31 元、也低于年内最低收盘 26.58 元。**在当前的证据结构下，靠价格下跌走进买点是不现实的路径**——现实的路径是基本面兑证把内在价值抬上来。
