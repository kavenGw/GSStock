## 0 结论摘要

**评级：watch（好公司，当前价不买）—— 首次建档**

期望内在价值 **约 $342/股（≈ $2.54 万亿市值）**，主锚现价 **$426.40**（2026-07-30 06:36 EDT 盘前，含财报 +9.2%，市值 ~$3.168T），安全边际约 **−19.7%**。三情景围绕**唯一变量「FY27–FY29 自由现金流能否重新增长」**三分：

- **Bull 25%**（capex 在 FY27 见顶 → FCF 重新增长）：每股内在价值 **$442**——正常化 owner earnings 上修至 $18.5/股 × 23× + OpenAI/Anthropic 权益 SOTP $16/股。
- **Base 50%**（capex 高位平台期 → FCF 低速修复）：每股内在价值 **$358**——owner earnings $17.4/股 × 20× + SOTP $10/股。
- **Bear 25%**（需求 miss 或折旧集中释放 → FCF 继续零增长/转负）：每股内在价值 **$212**——owner earnings 因折旧充足性折让下修至 $14.8/股 × 14×（倍数向重资产基建靠拢）+ SOTP $5/股。

期望内在价值 = 442×0.25 + 358×0.50 + 212×0.25 = 110.5 + 179.0 + 53.0 = **$342.5/股**（取 **$342**）。算术自检：110.5+179+53=342.5 ✓；Σ概率 = 0.25+0.50+0.25 = 1.00 ✓。市值口径自检：$342.5 × 7.43B = $2.545T，vs $3.168T → −19.7% ✓（与每股口径一致）。

**一句话判断**：这是一家护城河**依然完好**（Commercial RPO $678B/+84%、久期 2.3 年、12 个月内确认约 $203B ≈ FY26 营收 61%——全行业最硬的客户能见度）却**资本回报已实质变质**的公司。FY22→FY26 净利润 +84%，FCF **+2.8%**（CAGR +0.7%）；FCF margin 32.9% → **20.2%**；ROIC 71.6% → **30.7%**。PE(TTM) 从 FY24 峰值 37.88× 杀到主锚 23.76×（正常化后 25.2×）确是十年低位，但**这个下杀（−42.6%）与 ROIC 下杀（−57%）量级相当——它更像对"轻资产软件 → 重资产基建混合体"的合理重定价，不是错杀**。真正的分歧不在 PE 分位，而在现金轨：P/FCF **47.3×**，隐含市场已在为「FY29 FCF 约 $132B（FY26 的两倍）」付钱。这个恢复未必不会发生，但它是**未被证明的**，而当前价没有留下证明失败时的余地。给 **watch**：不是不好，是不便宜。

## 1 能力圈 & 本次建档触发

### 能力圈判断：圈内（企业软件订阅）/ 边界（超大规模云基建资本周期）

一段话讲清怎么赚钱：**微软向全球企业卖三样东西——① 生产力订阅（Microsoft 365 / Dynamics / LinkedIn，按席位按月收费，Q4 占营收 42.0%）；② 云与 AI 基建（Azure 计算/存储/AI 服务，按消耗计费，Intelligent Cloud 占 43.7%）；③ 消费与 PC（Windows OEM / Xbox / 搜索广告，占 14.3% 且在萎缩）。跨分部口径的 Microsoft Cloud 单季 $59.3B，占总营收 65.9%。** 这套模式的经济本质是**企业 IT 预算的通道税**：一旦客户把身份目录（Entra）、文档协作（M365）、开发工具（GitHub/VS Code）、数据平台（Azure）绑在一起，迁移成本极高。这部分我看得懂。

**边界区**：Azure/AI 基建的资本周期——capex/营收已达 **34.9%**（FY22 为 12.0%），FY26 capex $115.9B（+80%），日历 2026 指引 ~$175B。判断这些资产 10 年后的经济寿命与回报率，需要对 GPU 迭代节奏、电力供给、模型推理成本曲线做预测，**这超出我能给出高置信度答案的范围**。我把这个诚实的不确定性直接翻译成三情景概率，而不是假装能解决它（见 §6 末、§9）。

1. **FY26 Q4 与 FY2026 全年实际数刚落地（2026-07-29 盘后，10-K 同步 filing）**：Azure 全年首破 $100B（+41%）、Q4 加速至 +43%、RPO 跳到 $678B（+84%）、FY27Q1 指引 ~+45% cc——**基本面在加速**，值得用实际数而非预期承做。
2. **估值被杀到十年低位**：PE(TTM) 21.76×（收盘锚）vs 10 年中位 ~32.56×（低约 33%）；PB 6.56× vs FY24 峰值 12.38×（−47%）；52 周 **−23.80%**。**估值与基本面方向完全背离**，必须回答这个背离是错杀还是重定价。
3. **商业模式变重，已跨过一个结构性门槛**：**Intelligent Cloud 首次成为第一大分部（43.7% > PBP 42.0%，FY27Q1 指引差距进一步扩大）**、Microsoft Cloud 占 65.9%、capex/营收 34.9%、ROIC 30.7%——这些是**基建特征而非轻资产软件特征**（本档 sector 归 `ai-application`/`cloud`，是本仓一级枚举内最贴近项；模式变重对护城河的影响见 §5）。
4. **两个新的会计/结构变量同时出现**：FY27 起数据中心与办公楼折旧年限 **15 → 25 年**；2026-04-27 OpenAI 协议重构使 **Azure 独家性与收入分成告终**。两者都直接影响正常化利润口径与倍数中枢。

### 跑道长度（成长 lens）

- **Copilot 是最长跑道**：付费席位 3000 万 / 商业席位 4.5 亿 = **~6.7% 渗透率**，且本季净增 1000 万（环比翻倍以上，20M → 30M+）。F500 中 >90% 在用（含试点）、>60% 已部署至少 1 万席位、Accenture 单家 74 万+ 席位。**天花板远未触及。**

- **约束不在天花板，在产能与电力**：公司连续多季自述 **"Demand continues to exceed available capacity"**【硬】。Azure +43% 是**供给上限而非需求上限**——这既是达产即变现的多头证据，也意味着**我们从未观察到不受供给约束的真实需求曲线**（见 §8）。

**拆量价**：本季增长**以量为主**——容量端 Q4 新增 ~1GW / 31 座 DC、全年 88 座；席位端 Copilot 20M → 30M+；消耗端 Foundry 年化用 1 万亿 token 的客户数同比 ×4。**价的证据只有间接的**：意大利 AGCM 2026-06-26 开始调查 M365 与 Copilot/Designer 捆绑相关的**涨价**（反证提价动作确实存在，但这是监管口径的推论，非公司披露）。**Copilot ARPU / 席位单价公司未披露【缺】——"席位加速是否伴随降价换量"无法证伪。** 本档不据此下任何结论。

**增长质量三层**：
1. **损益层：优秀。** 营收 CAGR 13.7%、利润 CAGR 16.4%，且营业利润率四年 **+4.7ppt**——增长伴随营业利润率**改善**而非稀释。这是 Buffett 看重的信号。
2. **毛利层：转折。** 毛利率 FY24 见顶后回落 1.9ppt，Microsoft Cloud 毛利率 65% 同比下降。**Azure/AI 的边际毛利结构性低于 Office/Windows**——收入越增长，混合毛利越被稀释。FY27 指引营业利润率"down less than a point"是**首次指引下滑**。
3. **现金与资本层：恶化。** FCF 四年 CAGR **+0.7%**、FCF margin −12.7ppt、ROIC −41ppt、净 PP&E ×3.85。**"+18% 营收伴随的是毛利率下降与 FCF 下滑"——这句话是本档的核心事实。**

**这就是本次建档的核心张力**：同一家公司，看损益表是加速的优质成长股，看现金流量表和资本回报是重资产周期股。

## 5 核心优势 / 护城河

| 护城河类型 | 强度 | 趋势 | 依据 |
|---|---|---|---|
| **切换成本**（身份/M365/Azure/GitHub 企业绑定） | **极强** | **稳定** | RPO $678B 已签合同、久期 2.3 年；企业 IT 栈迁移成本极高 |
| **企业分销**（4.5 亿商业席位 → Copilot 加载通道） | **极强** | **加宽（但被监管盯）** | Copilot 席位单季 +1000 万；F500 >90% 在用；意大利 AGCM/EU DMA 正针对捆绑 |
| **效率规模**（全球 DC + 自研 Maia/Cobalt） | 强 | **加宽（但由资本买来）** | 88 座 DC/年、~1GW/季、Maia 200 性能/美元 +30% |
| 无形资产/品牌（Windows/Office） | 强 | **窄化** | More Personal Computing −4%，Windows OEM −7%（FY27 指引 −high teens）、Xbox 内容 −10% |
| 网络效应（开发者/GitHub 5000 万 users） | 中-强 | 稳定 | 开发者生态；GitHub Copilot 为 users 非付费席位 |

### 商业模式从轻资产变重：对护城河是加宽还是稀释？—— 两者同时成立

**变重的事实【硬】**：Intelligent Cloud 首次成为第一大分部（43.7% vs PBP 42.0%，FY27Q1 指引 IC $41B vs PBP $36.9B 差距扩大）、Microsoft Cloud 占 65.9%、capex/营收 **34.9%**（FY22 12.0%）、净 PP&E 四年 ×3.85、ROIC 30.7%。这些是**基建特征，不是轻资产软件特征**。

**我的判定（分开两个层面，这是本节的关键）**：

- **竞争护城河：加宽。** 全球只有 3–4 家企业能持续年投 $175B 级 capex 并同时拥有 4.5 亿席位的分销通道。资本强度本身成了准入壁垒（Buffett 的 efficient scale）。新进入者不可能追上。
- **经济护城河：稀释。** Buffett 的护城河标准从来不是"别人进不来"，而是"**不需要不断投入巨额资本就能维持高回报**"（See's Candies vs 资本饥渴型生意的经典对立）。一条需要靠年投 $175B 才能守住的护城河，对所有者产生的回报**必然低于**一条靠品牌与代码守住的护城河——ROIC 从 71.6% 到 30.7% 就是这个稀释的定量结果。

**结论：微软的"生意"仍然极好（8 问 6 项全绿），但它已经不是同一门生意了。** 这不是护城河被摧毁，是护城河的**收费方式变贵了**。合理倍数中枢因此应下移——这是 §9 三档倍数（14×/20×/23×）低于软件股惯用中枢的根本理由。

## 6 核心新论点：AI capex 超级周期——护城河加宽，还是资本黑洞？

### 多头侧（最强证据，全为公司口径【硬】）

1. **Azure 在 $100B 基数上反加速**：Q4 **+43%**（Q3 +40%），FY26 全年 +41% 首破 $100B，FY27Q1 指引 **~+45% cc**。驱动为"efficiency gains across our CPU and GPU fleet" + "process improvements to enable earlier delivery of new capacity"——**是产能释放而非降价换量**。
2. **订单簿能见度全行业最强**：Commercial RPO **$678B/+84%**，加权期限 2.3 年，**12 个月内确认约 30% ≈ $203B**（本档自算），相当于 FY26 全年营收的 **61%**。这不是"预期"，是**已签合同义务**。
3. **对"OpenAI 独撑"最有力的反证**：公司明确 Q4 **$51B 环比增量"全部来自非大模型公司客户"**，**剔除 OpenAI 后 backlog 仍 +25%**，剔除 OpenAI 影响后 commercial bookings +18%。
4. **物理产能达产确定性高**：本季新增 **31 座数据中心**（五大洲）、全年累计 **88 座**、新增 **~1GW**（Q3 亦 ~1GW），Nadella 重申"on track to roughly double its overall capacity in just two years"。且**需求持续超过供给**——达产即变现，无空置风险。
5. **capex 有可逆性（下行保护）**：Q4 capex $41B（含 $5.6B 融资租赁）**低于**市场 $42.5B 预期；公司称 capex "heavily weighted toward short-lived assets (CPUs/GPUs)"、短寿命资产约占 **2/3**，若需求变化可 **"simply slow down that component"**，土地/建筑占比小且时点灵活。**这与 2025 年上半年的"租约取消"叙事不同**——那批报道（TD Cowen 200MW、SemiAnalysis 冻结 1.5GW）全部集中在 2025 上半年，规模占其总租赁电力（~20GW）**不到 2%**，且 **2026 年未复现**（相反是加速扩张）。空头若引用必须标明是旧闻。

### 空头侧（同等篇幅，最强反驳前置）

**(a) FCF 连续三年不增长——"利润在涨，现金在缩"【硬】**
FY23 $59.5B → FY24 $74.1B → FY25 $71.6B → FY26 **$67.0B（−6.5%）**；FCF margin FY22 32.9% → FY26 **20.2%**；Q4 单季 FCF $19.6B（**−23% YoY**）而净利 **+31%**。四年间净利润 +84%（$72.7B→$133.7B）而 FCF **+2.8%**（$65.1B→$67.0B）。**如果微软是一台现金机器，这台机器四年没有提速。** 且**公司没有给 FY27 FCF 指引【缺】**——核心变量无官方能见度，仅 Barclays 估 2026 年 −28%、2027 回升【软】。

**(b) ROIC 四年掉 41ppt——PE 下杀可能是合理重定价而非错杀【硬】**
ROIC 71.56% → **30.69%**（−57%），ROE 47.15% → 32.10%，净 PP&E $87.5B → $337.3B（×3.85）：**分母膨胀远快于分子**。**这一条我正面承认，不用"错杀"一笔带过**：一家 ROIC 30% 的重资产企业理应比 ROIC 70% 的轻资产软件企业享受**更低**倍数。量化对照——PE 自 FY24 峰值 37.88× 跌至主锚 23.76×（**−37.3%**）、跌至收盘锚 21.76×（**−42.6%**），而 ROIC 同期下杀 **−57%**。**下杀幅度小于资本回报下杀幅度，"十年最低分位"因此不能自动读成便宜。**

**(c) 会计口径连续放宽——事实【硬】与动机质疑【软】必须分开措辞**
- **事实【硬】**：FY27 起数据中心与办公楼折旧年限 **15 年 → 25 年**。历史第三次放宽（2020 服务器 3→4 年、2021 服务器与网络设备 4→6 年、2026 建筑 15→25 年）。折旧/净 PP&E 从 FY22 **16.5%** 降至 FY26 **11.4%**（MBI 更长口径：FY14-20 的 30–34% → FY24 ~15%，而计算机设备与软件占 gross PP&E 稳定在 40–45%，**mix shift 解释不通**【软】）。
- **公司口径【硬】**：Amy Hood "affects only the timing of future depreciation and is expected to have a **minimal benefit** to FY 2027 operating income"；更大影响在 capex——"more of our future data center leases will shift from finance leases to operating leases"，使日历 2026 capex 指引从 ~$190B 降至 **~$175B**（**纯分类效应，公司明确 "underlying investment plans remain unchanged"**）；变更**只针对建筑壳体，不涉及服务器/GPU**。
- **质疑【软】**：会计上可辩护（混凝土/电力/冷却基础设施用 25 年确有现实基础），但**时点可疑**——恰在 FCF 转弱、ROIC 腰斩、市场质疑盈利质量的当口放宽，且顺带把 capex 指引"下修"$15B，**在一个市场因 capex 上调而暴打 Alphabet 7% 的季度里，这个下修直接帮助了股价 +9%**。Michael Burry 关于"GPU 按 5–6 年折旧而 NVIDIA 年年换架构"的质疑（CNBC 2025-11-14）在此背景下无法被简单驳回。**定性结论：这不是造假，是在关键时点做出的有利于管理层的会计选择，且披露方式弱化了实质。据此对管理层"会计保守度"打折，但不升级为诚信质疑（8 问第 7 项仍判通过）。**

**(d) 表外义务膨胀【软·未直核原文】**
未起租租约承诺 **$329.1B**（上期 $196.6B，**+67%**）、Q4 新签数据中心租约 $130B+。⚠️ **此数据二手源（ZeroHedge）引 10-K，采证时 SEC 10-K 原文抓取 ECONNRESET 失败，本档未直核原文，等级【软】，不得升格。** 技术性论点是：15→25 年变更会让**更多未来租约从融资租赁转为经营租赁**，即**会计变更本身在把义务推向表外**——"future costs won't appear on balance sheets until payment begins"。

**(e) 股东回报空间被压缩【硬+自算】**：见 §3——FY26 $48.7B = FCF 的 **72.7%**，回购较 FY22 缩水 32%，净现金从 $51.3B 变薄至 $20.0B，而 FY27Q1 单季 capex >$50B。

**(f) 消费与 PC 端持续失血【硬】**：More Personal Computing Q4 **−4%**（占 14.3%），Windows OEM and Devices −7%（**FY27 指引下滑 high-teens**），Xbox content and services −10%。这块曾是稳定的 FCF 贡献者。

**(g) 市场情绪【软】**：MSFT 空头兴趣为 **2015 年 5 月以来最高**；同时 50 位分析师 42 Strong Buy / **0 卖出**、中位目标价 $540——**一致预期极度乐观本身构成风险**（UBS $510→$480、Mizuho $515→$490 已在 7 月中下旬下调，分化已开始）。

### OpenAI 关系：从"结构性资产"降级为"有条件资产 + 显性集中风险"

**2026-04-27 协议重构【硬】**：IP 授权转为**非排他**、**Azure 独家性已终止**（OpenAI 可上任意云，微软仅保留 "primary cloud partner"）、**云优先购买权 ROFR 取消**、**收入分成设上限/终止**。微软换到的是：IP 权利延至 **2032 年**且**涵盖 AGI 之后的模型**、AGI 定义权由 OpenAI 单方判定改为独立专家小组裁定。（注意：27% 持股 + $2500 亿 Azure 承诺 + IP 至 2032 出自 2025-10 营利化重组；非排他/取消 ROFR/收入分成设限出自 2026-04-27，**两次事件不同。**）

**这笔交换防住了尾部风险，但让出了上行捕获。** 更大的新增风险是集中度：公司 2026-01 自己披露 $625B RPO 中约 **45%（~$281B）系 OpenAI**；**Q4 未更新该百分比【缺】**，本档按"此后 OpenAI 部分未新增"**推算** Q4 占比降至 **~41%**（**推算，公司未更新披露**）。而 OpenAI 2026 年化营收目标仅 $20B+、单季亏约 $12B、2027 预期亏损扩至 $40B、IPO 推迟至 2027、长期算力承诺已从 $1.4 万亿**下调**至 2030 年约 $6000 亿【均软】。**$2500 亿 Azure 承诺与 OpenAI 偿付能力之间存在数量级鸿沟。**

**权益法损益必须纠正一个流行误读**：FY26 全年 OpenAI 对微软是**净贡献 +$5B / +$0.67 EPS**，不是拖累（Q1 −$3.1B/−$0.41 → Q2 +$7.6B/+$1.02 → Q3 −$14M → Q4 约 −$600M/−$0.07）。但**这 $5B 是估值重估收益，不是现金**。叠加 Anthropic Q4 +$3.2B/+$0.33，FY26 GAAP EPS $17.95 中约 **$1.00（5.6%）为非现金投资重估收益**——**做 owner earnings 必须剔除**（见 §9）。讽刺之处：微软 2025-11 投 Anthropic $5B（持股第三方估 **~1.4%**【软】，公司未披露比例，亦未明确是权益法还是公允价值计量【缺】），**单季重估获利 $3.2B ≈ 持股 27% 的 OpenAI 全年贡献**；而 Anthropic 同时承诺采购 $300 亿 Azure、微软自身对 Anthropic 支出近 $5 亿/年——**微软同时是股东、供应商与客户**，循环收入（round-tripping）质疑因此无法回避（最有力的反驳仍是 $51B 增量全来自非大模型客户 + 剔 OpenAI 后 +25%）。

### 结构性 vs 周期性二分判定（本档的裁决）

**我的裁决：营收端是结构性的，资本回报端是"结构性变重 + 周期性超额"的混合体——而后者的拆分比例目前无法确定。**

**判据**：
- **结构性的部分（高置信度）**：企业 AI 上云是范式迁移，RPO $678B 是已签合同而非景气预期；capex/营收从 12% 到 35% 不会回到 12%——**微软永久地变成了一家资本密集企业**（这部分是结构性的，ROIC 不会回到 71.6%）。
- **周期性的部分（低置信度）**：当前 capex 中包含一次性的产能追赶与**组件成本通胀**（Q4 capex 明确"including the impact from higher component pricing"【硬】；Meta 上调 capex 时亦归因 "higher component and data center costs"——**意味着 capex 数字被通胀虚增，实际产能增速低于 capex 增速**，这是对"capex → 产能 → 营收"传导链的折扣项）。若 capex 在 FY27 见顶并进入平台期，D&A 增速会在 2–3 年后趋平，FCF 可重新增长——**这是 bull 的全部依据**。

**证伪条件（写在这里以便未来回看）**：
- 若 **FY28 ROIC 回升至 35%+ 且 FY28 FCF > $95B**，则"投资期暂时下滑"成立 → bull 路径，base 应上修。
- 若 **FY28 ROIC 仍 ≤30% 且 FCF 仍 < $80B**，则"商业模式永久变重"成立 → 合理倍数中枢应永久下移至 14–16×，bear 权重上调。

**必须诚实收录的未解问题**：**ROIC 从 71.6% 到 30.7% 是"投资期暂时下滑"还是"商业模式永久变重"——目前双方都缺决定性证据。** 多头需证明 ROIC 会回升（capex 见顶 + AI 营收放量），空头只需证明重资产是新常态。我不假装能解决它。**这个不确定性的翻译方式是：base 权重 50%（不做方向性下注）、bull 与 bear 对称各 25%（承认双向都有实质可能），且三档的差异几乎全部来自 FCF 路径而非 PE 分位。** 这是本档估值结构的直接来源。

**对称赋权必须正面回应一个反驳**：ROIC 已**连续四年单向恶化**（71.6% → 51.6% → 43.1% → 37.2% → 30.7%），按趋势动量论，bear 理应重于 bull（如 30% / 20%）而非对称。我不这样赋权的理由有二：① 这四年的恶化是**主动投资决策**的会计结果（capex/营收 12% → 35%），而非需求或竞争地位恶化的结果——同期营收 +18%、RPO +84%、Azure 在 $100B 基数上反加速，**是分母扩张而非分子受损**，这与典型的"ROIC 趋势性恶化"（份额丢失、定价权流失）性质不同；② capex 具**可逆性**（公司称短寿命 CPU/GPU 占约 2/3、需求变化可 "simply slow down that component"【硬】），故趋势外推在此处的效力弱于对不可逆经营恶化的外推。**但这个反驳的力量是真实的，我给它一个明确的转化条件**：若 FY27 出现「capex 继续上台阶**而** Azure cc 增速同时回落至 35% 以下」——即分子受损与分母扩张同时发生——则趋势动量论成立，届时应把 bear 上调至 30%+、bull 压至 20%，期望内在价值随之下移约 $20–25/股。

## 7 AI / 概念潜力（已进业绩层，逐维度分产品层 vs 业绩层）

**总判定**：微软 AI 敞口**已明确进入业绩层**——AI 同时体现在①营收增速 ②订单簿 ③资本开支 ④毛利率（负面）四个可量化维度，且均有公司口径【硬】支撑。这是本次采证中确定性最高的结论之一。

| 维度 | 层级 | 量化证据 | 标签 |
|---|---|---|---|
| **Azure AI 基建** | **业绩层（硬兑现）** | Azure +43%、FY26 破 $100B、FY27Q1 指引 +45% cc、需求超供给 | **【真敏感】**——增速直接落在营收上，且是供给受限而非需求受限 |

| **GitHub Copilot** | 产品层 | **5000 万 users**（非 paid seats），无独立营收披露 | **【真敏感·产品层】**——分发规模真实，但货币化口径缺失，不进 §9 利润基础 |
| **Foundry 平台** | 业绩层（早期） | 年化消耗 1 万亿 token 的客户数同比 **×4** | **【真敏感·早期】**——消耗量是真需求信号，但无营收拆分，不单独估值 |

| 量子（Majorana） | 概念层 | 2026-06-24 *Nature* 刊文质疑方法论与能隙检测稳健性【软】 | **【蹭概念】**——无营收、可信度受损，零估值权重 |

### 三个不许编造的口径（采证明列为【缺】，本档如实写"公司未披露"）

1. **公司本季未披露 "AI 服务贡献 Azure 增速 X ppt"【缺】**——**本档不拆分 Azure +43% 中 AI 与传统云的占比**。历史曾有"16 points from AI services"但季度归属不明，不采信。
2. **Q4 未更新 AI 业务年化 run rate**——最近量化是 **FY26 Q3 的 $37B（+123%）【软】**，**本档不把它当 Q4 数字用**。
3. **Copilot ARPU / 席位单价未披露【缺】**——因此"席位加速是否伴随降价换量"（AlphaStreet 的 "shelfware risk" 质疑：>90% F500 在用但仅 6.7% 付费渗透）**无法证伪**，本档不给 Copilot 单独估值溢价。

**双面必答**：微软的 AI 是**产品层与业绩层双强的少数派**——它不是蹭概念，Azure 与 Copilot 已经把 AI 变成了营收与合同。**但 AI 同时是它毛利率下行与 FCF 塌陷的原因**（Microsoft Cloud 毛利率 65% 同比降，公司归因含 "continued investments in AI infrastructure"）。**本档绝不用"AI 想象空间"抬倍数，也不让未兑现的 AI 概念（GitHub Copilot 货币化、Foundry 营收、Maia 外部化、量子）进 §9 owner earnings 基础；OpenAI/Anthropic 的 $1.00 重估收益一律剔除、改作 SOTP 单列。**

## 8 周期定位

### 行业属性：非商品周期股，但深度绑定 AI 资本开支超级周期

微软不受铜/锂等商品期货驱动，但 Azure/AI 基建深度绑定**全球 AI capex 超级周期**（与英伟达同源需求侧、与谷歌同源竞争侧）。四大 CSP 2026 日历年 capex 合计第三方汇总 **~$725B（+77%）**（另有 $690B / ~$750B 口径，**机构分歧已标**【软】）——这是**行业级持续性的兑底证据，不是微软的具名客户 guidance**，且含成本通胀成分。

### 当前定位：结构性新台阶 vs 周期顶？正反对冲

| 维度 | 结构性新台阶（看多） | 周期顶 / 资本回报见顶（看空） |
|---|---|---|
| 估值位置 | PE(TTM) 21.76×（收盘）为十年最低区间，低于 10 年中位 29–33%；PB 6.56× 为五年最低（vs FY24 峰值 12.38×） | **P/FCF 47.3×（主锚）一点都不便宜**；正常化 PE 25.2×；EV/EBITDA 16.3×（主锚） |
| 基本面 | 营收 +18%、营业利润 +21%、EPS +32%、Azure 加速、RPO +84% | FCF −6.5%、FCF margin 20.2%、毛利率 FY24 见顶、MPC −4% |
| 资本回报 | 需求超供给 → 达产即变现 | **ROIC 71.6%→30.7%**，capex/营收 34.9%，回购被挤出 |
| 增速性质 | 供给受限 → 产能一放增速就在 | **真实需求曲线从未被观察到**：若两年后容量翻倍、供给不再是瓶颈，增速将首次暴露真实需求水平，那个数字可能远低于 43%【采证者推论·软】 |
| 会计 | 折旧年限变更仅针对建筑、公司自称对利润"minimal benefit" | 折旧/净 PP&E 降至 11.4%，会计变更把义务推向表外 |

**净判断：营收侧是结构性新台阶，资本回报侧更像"周期高点尚未验证"。** 因此 §9 的正常化 owner earnings **绝不取 FY26Q4 年化顶部**（$4.74×4 = **$18.96 non-GAAP 仅作上界参考，不直接采用**），三档全部低于该上界；同时因增长证据包三要素多为硬证据，base 允许适度脱离纯周期均值（用穿越周期成长中枢，而非 FY26 原地不动）。

## 9 估值（场景加权：双轨口径 + 正常化 owner earnings + 联营 SOTP 单列）

### 9.1 双轨口径——先把"便宜"和"贵"同时摆出来

**①损益轨（显示便宜）**，主锚 $426.40 / $3.168T：

| 指标 | 主锚（$426.40） | 收盘锚（$390.54） | 参照 |
|---|---|---|---|
| PE(TTM, GAAP EPS $17.95) | **23.76×** | 21.76× | 10 年中位 ~32.56× |
| **PE（正常化 EPS $16.95，剔 $1.00 重估收益）** | **25.16×** | 23.04× | — |
| Forward PE | ~21.8× | 19.9–20.1× | FY27 指引双位数增长 |
| EV/EBITDA（EBITDA = 营业利润 $155.2B + D&A $38.5B = $193.7B） | **16.25×** | 14.87× | FY24 峰值 25.42× |
| PB（BVPS $59.36） | 7.18× | 6.56× | FY24 峰值 12.38× |
| PS | ~9.55× | 8.74× | FY24 峰值 13.56× |

**②现金轨（显示不便宜）**：

| 指标 | 主锚 | 收盘锚 |
|---|---|---|
| **P/FCF（FCF FY26 = $67.0B）** | **$3.168T / $67.0B = 47.3×** | 43.3× |
| FCF/股 | **$9.02**（$67.0B / 7.43B） | 同 |
| **FCF 收益率** | **2.12%** | 2.31% |
| FCF margin | **20.19%** | 同 |
| ROIC | **30.69%** | 同 |
| 股息率 | 0.85% | 0.93% |

**两轨差额 = 市场对"capex 何时转化为 FCF"的定价。** 把这个差额量化成一句可检验的话：**按 24× P/FCF（三情景内部一致的现金轨倍数，见 §9.4）反算，主锚 $3.168T 隐含市场已在为「FY29 FCF ≈ $132B」付钱——是 FY26 实际 $67.0B 的 1.97 倍。** 这就是当前价格真正的假设，而非"PE 21.76 便宜"。**我采纳采证者的双轨建议，并把场景加权轴设为「FY27–FY29 FCF 能否重新增长」这一单一变量，不纠缠 PE 分位。**

### 9.2 正常化 owner earnings 口径（三步，全程 USD 每股）

**第一步：剔除非现金重估收益（联营铁律）。**
- Q4 离散收益 **+$0.27/股**（Anthropic +$0.33 被 OpenAI 权益法 −$0.07 部分抵消）→ 剔除。
- FY26 全年 GAAP EPS $17.95 中约 **$1.00（5.6%）** 为 OpenAI(+$0.67) + Anthropic(+$0.33) 非现金重估收益 → **剔除后 FY26 正常化 EPS ≈ $16.95**（对应主锚 PE **25.2×**、收盘锚 **23.0×**）。**三情景的利润基础一律用剔除后口径。**

**第二步：owner earnings = 正常化净利 + D&A − 维护性 capex − 营运资本增加。**
FY26 正常化净利 ≈ $126.3B（$133.7B − 约 $7.4B 重估收益），D&A $38.5B，capex（现金 PP&E）$115.9B。（**股数口径消歧**：聚合口径的 $7.4B 用 FY26 加权摊薄股数 ~7.451B 反推（$1.00 × 7.451B ≈ $7.45B），而每股口径全档统一用当前流通股 **7.43B**；故 $16.95 × 7.43B = $125.9B 与聚合 $126.3B 存在约 **0.3%** 的口径差，属加权 vs 期末股数差异，**不传导进三档每股估值**。）**关键判断是维护性 capex 取多少**：公司称近期 capex 约 **2/3 投向短寿命 CPU/GPU**（FY26 约 $77B）。按 4 年经济寿命对已建成的短寿命机队做稳态替换测算（FY24 ~$30B + FY25 ~$43B + FY26 ~$77B ≈ $150B，/4 ≈ **$37B/年**，本档粗算），**当前账面 D&A $38.5B 大致等于当期经济替换需求**——即 base 可接受"维护性 capex ≈ D&A"，capex 超出 D&A 的 $77B 视为增长性投入。**但机队正在陡增，替换需求会快速上升，而折旧年限被拉长会延后账面 D&A——这正是 bear 情景要打的"折旧充足性折让"。**

**第三步：三档取值（上界纪律）。** FY26Q4 non-GAAP EPS 年化 **$18.96 是上界参考，三档全部低于它**，且**不采用**。这是一条刻意的保守：一家 GAAP EPS $17.95 只转化出 **$9.02 现金**的公司，我拒绝把它两年后的一致预期利润直接资本化。**这条纪律的代价我在 §10 明算给出（约每股 $60–80），不藏起来。**（对照：卖方 forward EPS 约 $19.59，我的 base owner EPS $17.4 低约 11%——差额来自剔重估收益 + 折旧充足性折让。）

### 9.3 三情景（每档 = 主业 owner earnings × 倍数 + OpenAI/Anthropic SOTP）

**SOTP 铁律（联营独立单列 + 深度折价）**：OpenAI 27% 持股在 2025-10 重组时计价约 **$1350 亿**（$18.2/股），Anthropic 持股第三方估 **~1.4%**（**公司未披露比例与会计处理【缺】**，$350B 估值下约 $4.9B ≈ $0.66/股）。**折价理由（三重）**：① 私估波动极大且 OpenAI IPO 已推迟至 2027、无市场报价；② 流动性为零（无法在需要时变现）；③ 潜在税负 + 微软经济权利在 2026-04-27 后被削弱（非排他 IP、无 ROFR、收入分成设限），同一持股的**上行捕获能力已下降**。故给深度折价：**bear $5 / base $10 / bull $16 每股**（分析师判断，非市场报价）。**主业 owner earnings 已把这两笔重估收益剔干净，绝不双计。**

#### Bull（capex 在 FY27 见顶 → FY28-29 FCF 重新增长）—— 概率 25%

**假设**：capex 在 FY27 见顶转平台，短寿命资产替换节奏被 Maia 单位经济改善（性能/美元 +30%）与机队效率吸收；Azure 维持 40%+ 数个季度、Copilot 渗透率从 6.7% 上行、FY28 ROIC 回升至 35%+、FY28-29 FCF 重新增长至 $110–130B、FCF margin 修复至 26% 附近。
- 主业：正常化 owner EPS **$18.5**（< 上界 $18.96 ✓）× **23×**（宽护城河 + 现金转化修复 + ROIC 回升；仍非泡沫倍数）= **$425.5/股**
- SOTP：**$16/股**
- **合计 ≈ $442/股（≈ $3.284T）**

**赋权理由（bull 增长证据包门控，逐要素定级）**：
- (a) **扩产达产确定性 = 硬**：88 座 DC / ~1GW 新增 / capex 已实际支出 / 需求超供给。
- (b) **客户 capex 能见度 = 硬**：RPO $678B、剔 OpenAI 后 +25%、公司自身 FY27 指引（双位数营收与营业利润增长、Azure ~+45% cc）；四大 CSP 2026 capex ~$725B/+77% 为终端兑底 = **中**（第三方汇总、机构分歧 $690B/$725B/$750B、且含成本通胀）。
- (c) **TAM 跑道 = 中高**：Azure 份额 21–25% 距 AWS 5–8ppt（份额口径【软】）+ Copilot 渗透仅 6.7%（基数【软】）+ 公共云 2026 破 $1T。
- **三要素两硬一中，故 bull 可获 25% 而非封顶 20%。但这里必须讲清关键约束：扩产确定性高 ≠ 回报确定性高。** 微软的短板从来不是"能不能建成"（这是全行业最强的一项），而是"**建成后 ROIC / FCF 能否回来**"——而这一点**没有任何硬证据**（公司甚至未给 FY27 FCF 指引【缺】）。**因此我不因为 capex 是硬证据就给 bull 更高权重，25% 已是这套证据能支撑的上限。**

#### Base（capex 高位平台期 → FCF 低速修复）—— 概率 50%

**假设**：capex 在 FY27 维持高位（Q1 >$50B、日历 2026 ~$175B）后进入平台；营收增速从 +18% 逐步回落至中双位数；营业利润率按公司指引 FY27 "down less than a point" 后趋稳；ROIC 稳在 **30% 附近**（不回升也不继续崩）；FCF 从 $67B 低速修复至 FY29 约 $110B；毛利率因 Azure mix 继续微降；监管以行为救济收口。
- 主业：正常化 owner EPS **$17.4**（略高于 FY26 的 $16.95——双位数营业利润增长被上升的 D&A 与折旧充足性折让大部分抵消）× **20×**（宽护城河 + 全行业最强订单簿能见度，但被资本强度 + 现金转化率 50% 压制，故低于软件股惯用中枢）= **$348/股**
- SOTP：**$10/股**
- **合计 ≈ $358/股（≈ $2.660T，隐含 EV/EBITDA 13.6×）**

**赋权理由**：base 的每一项假设都有公司口径直接支撑（FY27 指引、capex 指引、需求超供给），且它对 §6 那个**未解的 ROIC 问题不做方向性下注**——这正是它该拿 50% 的理由。护城河未损 + 能见度极强使"缓慢修复"比"崩塌"或"快速修复"都更可能。

#### Bear（需求 miss 或折旧集中释放 → FCF 继续零增长/转负）—— 概率 25%

**假设**：① 两年容量翻倍后供给不再是瓶颈，真实需求水平暴露、Azure 增速快速回落；② 折旧集中释放（机队陡增 + 拉长年限的追赶效应），折旧年限争议被市场重新定价，倍数向重资产基建靠拢；③ OpenAI backlog 部分不可兑现（占 RPO ~41% 推算，OpenAI 单季亏 $12B、算力承诺已从 $1.4T 下调至 ~$600B）；④ FCF 继续零增长甚至转负、回购进一步收缩；⑤ Windows OEM 按指引 −high teens、Xbox 续跌。
- 主业：正常化 owner EPS **$14.8**（在 $16.95 基础上计入约 $2.2/股 的**折旧充足性折让**——相当于把年度折旧/维护性 capex 上调约 $16B、+42%，反映 GPU 经济寿命 1–3 年 vs 会计 5–6 年的错配）× **14×**（重资产基建倍数；仍高于 buffett 框架的窄护城河 8–12×，因为切换成本与企业分销护城河在 bear 情景下**依然存在**）= **$207.2/股**
- SOTP：**$5/股**（OpenAI 私估大幅缩水 + Anthropic 回撤）
- **合计 ≈ $212/股（≈ $1.575T，隐含 EV/EBITDA 8.0×）**

**赋权理由**：bear 的核心证据**不是假设，是正在发生的事实**——FCF 已经三年不增长、ROIC 已经掉 41ppt、回购已经被挤出、折旧年限已经再次放宽、空头兴趣已是 2015 年 5 月以来最高。故给 25%（不低于常规宽护城河股的 20%）。但护城河未损、RPO $678B 是已签合同、净现金仍 +$200 亿、公司有主动放慢短寿命 capex 的能力（"simply slow down that component"），深度崩塌概率不高，故不超 25%。

### 9.4 现金轨反算——三情景的内部一致性检查（本档最重要的一致性验证）

三档若真的只差在 FCF 路径上，那么用各档**自己相信的终局 FCF** 反算 P/FCF，三者应当落在同一区间：

| 情景 | 每股内在价值 | 隐含市值 | 该情景的终局 FCF（FY29） | 隐含 P/FCF |
|---|---|---|---|---|
| Bear | $212 | $1.575T | 维持 ~$65B（零增长） | **24.2×** |
| Base | $358 | $2.660T | 修复至 ~$110B | **24.2×** |
| Bull | $442 | $3.284T | 增长至 ~$130B | **25.3×** |
| **当前主锚** | **$426.40** | **$3.168T** | **隐含所需 ≈ $132B** | 24× |

**三档落在 24–25× P/FCF 的同一窄区间 ✓** ——这确认了三情景的差异确实**只来自 FCF 路径**，而不是我在偷偷改倍数。**而当前价 $426.40 隐含的所需 FY29 FCF 是 $132B——比 bull 情景的 $130B 还略高一点。** 换句话说：**市场当前定价已经略超我的 bull 情景所需的现金流恢复。** 这是"无安全边际"最有力的单一证据，也比任何 PE 分位讨论都更贴近争议本质。

### 9.5 期望内在价值、安全边际与压力测试

- **期望内在价值** = 442×0.25 + 358×0.50 + 212×0.25 = 110.5 + 179.0 + 53.0 = **$342.5/股**（取 **$342**，≈ $2.545T）。算术自检 ✓；Σ概率 = 1.00 ✓。
  - 口径消歧：frontmatter `valuation.base=358` 是 **Base 单情景**每股内在价值；决策锚用**三情景加权期望 $342**。
- **安全边际（主锚口径）** = ($342.5 − $426.40) / $426.40 = **−19.7%**（即现价较期望内在价值溢价约 24.5%）。市值口径 = ($2.545T − $3.168T)/$3.168T = **−19.7%** ✓ 两口径一致。
- **敏感性（收盘锚口径）**：若按 7/29 收盘 **$390.54** 计，安全边际 = ($342.5 − $390.54)/$390.54 = **−12.3%**——**仍为负**。即"财报后 +9.2% 是否回吐"改变的是负安全边际的深浅，**不改变"当前无安全边际"这一结论**。这是本档结论对时点风险的稳健性。
- **Bull 单独压力测试（关键）**：即便 bull 兑现 $442，相对主锚 $426.40 也仅 **+3.7%** 上行（相对收盘锚 $390.54 为 +13.2%）。**市场已把最乐观的 FCF 恢复路径基本定价完毕。**
- **Bear 下行测试**：若 bear 兑现 $212，相对主锚为 **−50.3%**。**风险回报结构严重偏下行（bull +3.7% vs bear −50.3%）。**

**估值净结论**：微软的 PE 处在十年最低分位是客观事实，我不抹掉它；但它**同时**是一家 P/FCF 47.3×、FCF 四年零增长、ROIC 腰斩的公司，两件事都是真的。把它们放在同一把尺子上量（现金轨反算），结论是清晰的：**当前价格要求的现金流恢复（FY29 FCF $132B）比我最乐观的情景所需的还多一点。** 这不是"贵得离谱"，是"没有余量"。

## 10 评级决策

| 决策要素 | 数值 |
|---|---|
| 期望内在价值 | **$342/股（≈ $2.545T）** |
| 主锚现价 / 市值（2026-07-30 盘前） | **$426.40 / $3.168T** |
| 收盘锚现价 / 市值（2026-07-29） | $390.54 / $2.90T |
| **安全边际（主锚）** | **约 −19.7%** |
| 安全边际（收盘锚敏感性） | 约 −12.3%（仍为负） |
| Bull 上行 | 仅 **+3.7%**（主锚）/ +13.2%（收盘锚） |
| Bear 下行 | **−50.3%**（主锚） |
| 确定性档位 | 营收端很高（RPO $678B）、**资本回报端低**（ROIC 走向未解）→ 要求折价 **20–30%** |
| **评级** | **watch（好公司，当前价不买）** |

**评级逻辑**：8 问过滤 6 项全绿（能力圈懂、十年更强、优势难复制、有提价权、债务安全、管理层诚信通过），**两项否集中在"利润转现金"与"价格"**。按 Buffett 折价标准，应在期望内在价值 $342 之下 20–30% 建仓。现价不仅无折价，反而溢价约 24.5%。给 **watch**——非 exclude（生意质地完全不支持排除：这是全球企业 IT 的通道税 + 最强订单簿）、非 config/core（价格不支持买入）。

**与谷歌档（2026-07-23，watch，安全边际 −18.4%）的对照**：两档评级相同但**路径相反且不是硬凑对称**。谷歌是"52 周 +80%、成长被充分定价"型的贵；微软是"52 周 −23.8%、估值已被杀到十年低位却仍无余量"型的贵——**后者更容易被误读为便宜**，这正是本档花最大篇幅做双轨估值的原因。若必须二选一，**微软的生意确定性（RPO 能见度、切换成本、股息+回购）优于谷歌，而谷歌的利润率扩张动能（Cloud margin 20.7%→35.6%）优于微软**；两者的安全边际都为负，都是"等回撤"而非"现在买"。

**买点 / 卖点阈值（美元每股，不因盘中波动失效）**：
- **进入正安全边际观察点**：现价 ≤ **~$342**（跌破期望内在价值，≈ −20% 于主锚）。
- **合格建仓点（20% 折价）**：现价 ≤ **~$274**（$342.5 × 0.8，≈ $2.04T 市值）。
- **强安全边际加仓点（30% 折价）**：现价 ≤ **~$240**（$342.5 × 0.7）。
- **触发重估的下行**：若跌至 bear 区 $212 附近**而 RPO 剔 OpenAI 后增速仍 >20% 且 FCF 已现修复拐点**，则属显著错杀，应上调 bull 权重。
- **当前 $426.40：观望，不追。** 等两件事之一：① 价格回撤到 $342 以下；② FY27 出现 FCF 重新增长的实证（H1 FY27 FCF 同比转正 + ROIC 环比回升），届时 base 的 owner EPS 与倍数都可上修，内在价值将向 bull 靠。

**多头算法的压力测试（把我保守纪律的代价明算出来，不藏）**：
若接受**把 FY28 一致预期口径 EPS ~$24（自 forward $19.59 按双位数增长两年推）按 21× 资本化**，得每股 **~$504**（+18% 于主锚）。**注意这里的倍数 21× 并未破 buffett 框架——分歧不在倍数，在利润基础。** 我拒绝采用的理由只有一条：**一家 GAAP EPS $17.95 只转化出 $9.02 自由现金的公司，用利润法资本化它两年后的利润，等于对"现金转化会回来"这件尚未被证明的事收取零风险溢价。** 这条纪律让我的期望内在价值比这个算法低约 **$162/股**——我认为这个代价值得付，但读者应当知道它的大小，并自行判断。（若采用该算法且 FY28 兑现，微软将是明显低估；这就是 bull 25% 权重所代表的可能性。）

**倍数是否破框架自检**：三档倍数 14× / 20× / 23× 全部落在 buffett 框架内（宽护城河 15–23× 区间，bear 的 14× 因资本强度下移但仍高于窄护城河 8–12×，理由是切换成本护城河在 bear 下仍存）。**无一档需要框架外倍数才凑得出"像样"的每股价值 → 无 ❌破框架项。** 隐含 ROE 交叉验证：base owner EPS $17.4 / BVPS $59.36 = **29.3% 隐含 ROE**（vs 实际 FY26 ROE 32.1%），bear $14.8/$59.36 = 24.9%，bull $18.5/$59.36 = 31.2%——三档隐含 ROE 均远高于股权成本（约 9–10%），公允 PB 显著高于 1×，利润法有效，无需退回资产法。且 bull > base > bear 单调 ✓。
