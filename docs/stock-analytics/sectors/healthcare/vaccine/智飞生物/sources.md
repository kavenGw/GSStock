## 12.3 已知局限（明写，不掩饰）

**A. 数据缺口（【缺】，本档中一律写成"未找到公开证据"，未作推测）**

1. 利拉鲁肽"达舒宸"上市后的**销售额、销售队伍规模、医院准入家数**——公司未披露。这直接导致"复用疫苗渠道推处方降糖药"的商业化能力**只能判为未获证**。
2. 智飞 **GLP-1 / 治疗线的收入与利润单独拆分**——半年报未按此口径披露。
3. 宸安司美格鲁肽的**预期获批时间、定价、产能爬坡计划、销售峰值指引**——均无。本档的 bull 期权估值因此是**框架性推演而非可核对测算**，不确定性最高的一块。
4. 宸安"年产能 3,000 万支"——仅见媒体转述增资公告，未见公司直接披露【软】。

6. 宸安司美格鲁肽**是否面临诺和诺德专利/工艺侵权诉讼**——未见披露。
7. 微卡、宜卡（结核 EC）为药品，不在疫苗批签发表内，**年报/中报未单独披露销量或收入**。

**B. 方法局限**

11. **一致预期不可作锚**：2026E/2027E/2028E 由第三方模型给出，样本极薄（6 个月无研报）；本档仅用其判断"三年不预期盈利"这一方向，不用其绝对值定价。历史上曾有机构给 2026 归母 **30 亿元**的预测，与 −12.52 亿元差异巨大，说明预期极度分歧且多数陈旧【软】。
12. **资产法的质量扣减比例是判断而非计算**：递延所得税资产 30%/70%/100%、应收 5%/10%/20%、开发支出 30%/50%/80% 等扣减率由本档设定，非公司披露；扣减方向有硬证据支撑（三年不预期盈利、95.93 亿元应收已质押、管线在审评期），但**具体幅度可辩论**，且期望值对其高度敏感——**量化敏感性**：若把 base 情景的递延所得税资产减记由 70% 放宽至 30%、应收账款扣减由 10% 放宽至 5%（即采用明显更宽容的一组假设），base 抬升至约 **4.31 元**、期望内在价值升至约 **4.12 元**、安全边际由 −73.1% 改善至 **−69.5%**。**结论方向不变（仍是深度负安全边际），改变的只是幅度**。审查与后续重做应优先挑战这组比例。
13. **三年经营现金消耗（−45/−30/−18 亿元）为情景假设**，锚定于一致预期累计 −26 亿元与剔除营运资本释放后的 −14 亿元/半年，非公司指引。
14. **EV/Sales 交叉验证的可比区间（3–5×）**为经验区间，未逐一列示可比公司，属方法性弱点；该验证只用于"资产法结论是否已足够保守"的方向性检查，未参与加权。
15. **前期会计差错更正削弱了 2020–2024 历史数据的可信度**——本档引用的三年指标已是追溯调整后口径，但"调整后是否即为最终"取决于是否再有更正（已列为监控项 T15）。
