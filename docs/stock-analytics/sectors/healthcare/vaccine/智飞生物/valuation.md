# 智飞生物 — §9 估值（场景加权）

> 价格锚（全档唯一）：**2026-09-08 收盘 13.51 元 / 总股本 23.938 亿股 / 总市值 323.40 亿元 / 账面 PB 2.15 / PE(TTM) −2.17 / EV ≈ 404 亿元**。[A1 §0]
> 业务前提见 [§1-§5](business.md)，论点前提见 [§6-§8](thesis.md)。

## 9.0 方法选择：为什么禁用 PE、为什么主锚是资产法

**（1）PE 主锚禁用。** TTM 归母 −149.25 亿元，PE(TTM) −2.17 无经济含义；且该分母几乎全部由 2025Q4 单季 −133.95 亿元的一次性减值贡献（2025 全年计提减值 141.28 亿元，其中代理 HPV 存货单项 127.66 亿元，占 94%）。**不得据 −2.17 推断当前亏损速率**——剔除减值后 2025 利润总额约 −33.4 亿元，2026H1 归母 −8.09 亿元且资产减值项为 **+1.906 亿元（转销/转回，正贡献）**，经营性亏损年化约 −16 亿元量级，远小于 TTM 数字暗示的失血速度。[A1 §1.2]

同时，第三方一致预期 2026E/2027E/2028E 归母为 **−12.52 / −10.88 / −2.62 亿元**，即**三年内不预期盈利**，任何正的 PE 倍数都无法落地。该一致预期本身还须打折：同花顺明示"过去 6 个月内尚未发布相应的研究报告"，样本极薄，**只能作为方向参考、不能作为估值锚**【软，可靠性低】。[A1 §7]

**（2）必须用 EV 口径。** 这不是净现金公司：货币资金 21.05 亿元（其中受限 2.00 亿元）vs 有息负债合计约 **101.82 亿元**（短借 3.03 + 一年内到期 26.92 + 长借 66.88 + 应付债券 5.00），**净有息负债 −80.77 亿元**。

> **EV = 323.40 + 80.77 ≈ 404 亿元**。本节所有对收入/资产的对比，凡用市值口径说过一遍的，一律在 EV 口径复述。[A1 §1.4、§5.5]

**（3）主锚取资产法（调整后净资产），EV/Sales 作交叉验证。**
资产法适用性判据：本标的资产负债表是**重存货 + 重应收的代理型**结构（应收账款账面 103.77 亿元占总资产 37.30%，存货 24.03 亿元，固定资产+在建 56.12 亿元），不是轻资产软件股，`buffett-doc-spec` §3 的"资产法主锚"准入成立（bull 情景本身也不依赖利润倍数，且三档单调 bear<base<bull，无框架失效症状）。

## 9.1 核心估值发现：账面 PB 2.15 是乐观读数

**PB 2.15 的分母 150.31 亿元（2026-06-30 归母净资产）必须做质量扣减。** 逐项：

| 科目（亿元） | 账面值 | 质量问题 | 证据 |
|---|---|---|---|
| 递延所得税资产 | **38.92** | 回收**完全依赖未来盈利**，而一致预期三年不盈利。若三年内确认无法回收，须全额或大部分转回，直接减记净资产 | A1 §1.4；一致预期 A1 §7 |
| 应收账款（账面价值） | **103.77** | 占总资产 37.30%；2025 末余额 134.46 亿元、已计提坏账 22.82 亿元（准备率 16.97%）；**其中 95.93 亿元已质押**给银行，不是可自由支配资产 | A1 §1.4 |
| 存货 | **24.03** | 已从 50.03 亿元半年降 26 亿元，但降的方式是"按减值后成本出货"；疫苗**效期是硬约束**，剩余批次仍有再计提风险 | A1 §1.4、§3 |
| 开发支出（资本化研发） | **21.48** | 管线未获批即归零；治疗线与 15 价肺炎均在审评期 | A1 §1.4 |
| 固定资产 + 在建工程 | **41.42 + 14.70** | 疫苗/生物药专用产线，非通用资产，处置变现折价大 | A1 §1.4 |
| 子公司股权 | — | **32.82 亿元已质押**（归母口径）；受限资产合计 **147.83 亿元** | A1 §1.4 |

**先给一个不需要任何主观扣减率的读数**：分母本身是自洽的（323.40 ÷ 150.31 = **2.151** ✅，腾讯 PB 用的正是 2026-06-30 归母净资产），问题不在分母算错，而在**分母的构成**——递延所得税资产占 **25.9%**、应收账款占 **69.0%**。
> **仅剔除递延所得税资产 38.92 亿元这一项，有形净资产即为约 111.4 亿元，对应 PB 由 2.15 升至 2.90。** 这一步不含任何本档设定的扣减率，是纯口径转换，**应作为最低限度的诚实读数写进 §0**。下文的扣减表是在此基础上再进一步。

> **受限资产 147.83 亿元 ≈ 归母净资产 150.31 亿元的 98%**。公司近乎把全部核心资产抵质押换取银行授信（2025 年获 102 亿元银团授信，控股股东蒋仁生以个人信用及家族资产**无偿担保**）。质押不直接减记账面值，但它意味着**这些资产的经济归属排在债权人优先序之后**，股东视角必须折价。

## 9.2 收入基线：2026H1 的 35.95 亿元代理收入必须扣水

2026H1 代理产品收入 **35.95 亿元**（占营收 89.34%），但同期：

- 默沙东**九价 HPV 批签发 = 0 支**（2024 全年 3,114 万支）；
- GSK **重组带状疱疹批签发 = 0 支**（2024 全年 377.6 万支）；
- 存货从 50.03 → 24.03 亿元，半年去化 26 亿元；
- 代理毛利率 **11.95%，同比 −47.17pct**（2025 全年 −0.49%）。

三条合起来只有一个解释：**这 35.95 亿元几乎全部是减值后存货的出清收入，是一次性的、不可持续的，不得线性外推。**[A1 §1.3、§3、§9.4]

**可持续收入基线重算（用于 2027 起）：**

| 组成 | 年化（亿元） | 依据 |
|---|---|---|
| 自主产品 | 7.6 | 2026H1 3.82 亿元 ×2；且方向仍为 **−24.94%**，不上调 |
| 代理产品（仍在销品种） | 12–18 | 五价轮状 2026H1 批签发 126.65 万支、进口 23 价肺炎 28.10 万支（同比 −52.89% / −50.86%）；按**推广服务商**而非包销商口径 |
| 其他 | 0.9 | 2026H1 其他 0.47 亿元 ×2 |
| **base 可持续收入** | **≈ 24** | |

> 对照：2023 年营收 529.64 亿元 → 2025 年 89.58 亿元 → 可持续基线约 24 亿元。这不是"下滑"，是**商业模式塌缩**。

### EV/Sales 交叉验证

- 当前 **EV 404 亿元 ÷ 可持续收入 24 亿元 = 16.8×**。一家收入结构性塌缩、整体毛利率 18.09%、三年不预期盈利的公司给到 16.8× EV/Sales，无法用任何可比口径辩护（健康期疫苗厂 3–6×，医药推广/流通服务商 0.5–1.5×）。
- 给合理区间 **3–5× EV/Sales** → EV 72–120 亿元 → 权益价值 = EV − 净有息负债 80.77 = **−8.8 至 +39.2 亿元** → 每股 **−0.37 至 1.64 元**。
- **交叉验证结论**：收入法给出的每股价值（0–1.64 元）**低于**下文资产法期望值 3.63 元。差异来源是资产法认了 150 亿元账面净资产的托底，而收入法直接被 80.77 亿元净有息负债吃掉。**取资产法为主锚（有实物资产与在产产线托底），但必须承认真实下界可能低于 bear 情景。** 这一点不做美化。

## 9.3 三情景设定与赋权

统一公式（三档同一套口径，避免重复扣减）：

```
每股内在价值 = [调整后净资产 − 未来三年经营现金消耗 + 融资注入
                + 自主疫苗业务持续经营溢价 + 代理业务残值 + 治疗线期权(归母 51%)]
               ÷ 摊薄后股本
```

> 口径说明：**现金消耗用现金口径而非会计亏损口径**，以免与 9.1 的减值扣减重复计算。2026H1 经营现金流 +19.74 亿元的来源是**存货去化 26.00 亿元（账面价值 50.03→24.03）+ 应收回收 7.88 亿元**，剔除营运资本释放后经营现金流约 −14 亿元/半年；同期筹资净流出 23.96 亿元，**现金及等价物净减少 6.39 亿元**。而存货账面价值只剩 24.03 亿元，**这个释放源正在枯竭**。
> **并且 2026H1 的 8.09 亿元亏损是纯经营性的**（同期资产减值为 +1.906 亿元正贡献，即转销 18.058 亿 > 计提 0.712 亿），**不能再用"减值性亏损"为其开脱**——该定性只对 2025 年成立。[A1 §1.4、§8bis C-3/C-6]

|---|---|---|---|
| 调整后净资产（9.1） | 49.82 | 85.92 | 118.99 |
| 三年经营现金消耗 | −45 | −30 | −18 |
| 股权融资注入 | +35（增发救急） | 0（债务展期+回款覆盖） | 0 |
| 自主疫苗持续经营溢价 | +8 | +16 | +28 |
| 代理业务残值 | 0 | +8 | +20 |

| **概率** | **30%** | **50%** | **20%** |

### 各档逻辑与赋权理由

**bear 1.74 元 / 30%** — 旧逻辑依旧：代理业务实质终结（九价 HPV 与带疱批签发连续为 0 是**已发生事实**而非预测），存货出清完成后收入断崖，递延所得税资产全额转回，自研管线不放量；三年烧现金 45 亿元而有息负债已 101.82 亿元、无加杠杆空间，被迫股权融资 35 亿元、摊薄 14.6%。
赋权 30% 的证据：批签发归零【硬】、代理毛利率 −47.17pct【硬】、回购承诺 1.5–3 亿元而截至 2026-08-31 实际执行 **0**【硬】、六年会计差错更正 + 深交所监管函【硬】、卖方覆盖真空【软】。见 [§6](thesis.md)、[§8](thesis.md)。

**base 3.34 元 / 50%** — 一轮完整出清后企稳、但不重估：按一致预期路径三年减亏至接近盈亏平衡（累计 −26 亿元，本档取 −30 亿元现金口径），存货去化完成、应收缓慢回收，代理退化为"推广服务商"但五价轮状/23 价肺炎仍贡献 12–18 亿元收入，自主产品止跌但不高增。**司美格鲁肽不进 base**（理由见下）。
赋权 50% 的证据：经营现金流在 **2025 四个季度及 2026H1 均为正**【硬】（但其来源是去库存与收账，不是盈利，故只支持"不猝死"、不支持"会改善"）；自主产品毛利率仍 72.80%【硬】；新协议取消基础采购金额、期限至 2028-12-31，短期不再有单方承担库存风险的隐患【硬】。见 [§8](thesis.md) 周期定位。

**bull 7.18 元 / 20%** — 换轨成功：司美格鲁肽（降糖）2027–2028 获批并放量、减重适应症申报获受理、15 价肺炎获批填首创卡位、默沙东采购恢复。

**bull 概率封顶 20% 的门控（`x-growth` 成长证据包，逐项标级）：**

- (a) **扩产达产确定性【缺】** —— 2025–2026 无新增产线/capex 扩产公告作为增长主叙事，公司口径是"去库存、促回款、降负债"，处**收缩/修复周期**而非扩张周期。宸安"年产能 3,000 万支"为【软，媒体转述增资公告】。须区分：**自研管线获批是审批期权，不等于产能兑现**。
- (b) **客户 capex / 出货能见度【软且方向为负】** —— 客户是各省疾控与基层接种点，不具名，按 `x-growth` ② **降级到终端市场兑底**：HPV 行业 2026Q1 批签发 27 批次 vs 2025 同期 45 批次【软】；智飞代理九价 2023 年 3,655 万支 → 2024 年 3,114 万支 → 2025 年 424 万支 → 2026H1 **0**【硬】。**终端在缩不在增，且新协议无任何锁定量**（按需动态滚动采购），能见度低于旧模式——不得用"独家代理权保留至 2028 年底"暗示收入锁定。
- (c) **TAM 跑道【软】** —— GLP-1 与 15 价肺炎的 TAM 确实大，但 GLP-1 赛道 **23 家在研**、已有多家报产且首家申报者被拒，原研已先行腰斩降价，跑道被同时拉长和压扁。

→ 三项**无一为【硬】**，按 `buffett-doc-spec` §3「三项全软 → bull ≤20%」封顶，取 **20%**。

**Σ概率 = 30% + 50% + 20% = 100%** ✅

### 司美格鲁肽为何只作 bull 期权、不进 base（三条并列）

1. **赛道拥挤、智飞至少是第 5 家申报者**：全赛道 **23 家在研**；**九源基因 2024-04-03 首家申报**（受理号 CXSS2400037，商品名吉优泰），**2025-01 该上市申请未获批准**；齐鲁制药、丽珠新北江、石药均已报产。智飞 2026-09-08 才获受理，比首家晚 **2 年 5 个月**。**这是红海，不是独家。**
2. **价格带在国产上市前已被打穿**：原研中国核心化合物专利 2026-03-20 到期前，诺和诺德已主动腰斩降价（司美中国区 2026Q1 销售同比 −22.5%、Wegovy −36%，省级平台降幅超 50%）。**国产上市即面对被打穿的价格带。**
3. **真正的门槛不是专利而是数据保护**：诺和诺德基于中瑞自贸协定，Ozempic 在华享有**至 2027 年 4 月的药品试验数据保护**【软，第一财经等多源】——专利到期 ≠ 类似药可立即上市，实际获批窗口受此约束。

另有两条独立减项：**公司自己在 2026-09-08 公告中写明"对公司近期业绩不会产生重大影响"**【硬】；**商业化能力未获证**——利拉鲁肽"达舒宸"2026-07-10 已获批，但其销售额、销售队伍规模、医院准入家数**均无公开披露**【缺】，"复用疫苗渠道推处方降糖药"目前只有公司与媒体说法。写作口径：**未获证，不是"具备"**。

**限定语纪律（彻底删除"首个"）**：智飞公告 2026-52 **全文没有出现"首个/首家"字样**，其原文是——
> "截至本公告披露日，经查询国家药品监督管理局网站，**国内暂无国产企业的司美格鲁肽注射液获批上市**；已获批的司美格鲁肽注射液为原研进口产品。"

引用**只能用这句原文**，且**必须同时披露九源（2024-04 申报、2025-01 被拒）、齐鲁、丽珠、石药等多家在审/被拒**，否则构成误导。"暂无国产获批"是**审评进度的描述，不是智飞的卡位优势**——恰恰相反，九源的被拒说明这条路本身就有失败先例。

## 9.4 期望内在价值、安全边际与压力测试

```
期望内在价值 = 1.74 × 30% + 3.34 × 50% + 7.18 × 20%
             = 0.522 + 1.670 + 1.436
             = 3.628  →  3.63 元/股
```

- **期望内在价值 3.63 元/股**，对应总市值 3.63 × 23.938 = **86.9 亿元**。
- **安全边际 =（86.9 − 323.40）÷ 323.40 = −73.1%**（对应确定性等级：**低**）。
- **EV 口径复述**：期望企业价值 = 86.9 + 80.77 = **167.7 亿元** vs 当前 EV **404 亿元** → EV 口径偏离 **−58.5%**。市值口径与 EV 口径都显著为负；净有息负债的存在意味着**市值口径其实还低估了"贵"的程度**。

**bull 单独压力测试**：即便 bull 全部兑现（7.18 元），相对 13.51 元仍有 **−46.9%** 的距离。也就是说——**司美格鲁肽获批、15 价肺炎获批、默沙东采购恢复三件事同时发生，当前股价依然贵近一半**。这是本档最硬的一句：不存在"用成长空间稀释贵"的余地（`x-growth` 双面必答第三问的直接回答）。

**买点**：确定性等级低（对应 40–50% 折价档），取 base 3.34 元 ×(1 − 45%) ≈ 1.84 元；按期望值 3.63 元 ×(1 − 45%) ≈ 2.00 元。**统一取买点 2.00 元/股**（对应总市值 47.9 亿元、EV 128.7 亿元）。当前价距该买点 **−85.2%**。
