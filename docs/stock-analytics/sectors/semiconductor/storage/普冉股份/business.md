# 普冉股份 — §1—§5 生意与财务

## §1 能力圈与本次重审触发

**能力圈：边界内，但长期精度低。** 公司以Fabless模式设计NOR、EEPROM、MCU/Driver与邻接产品，通过代工与封测供货；持51%的诺亚/SHM链条供应SLC NAND、eMMC、MCP，以工程、固件、认证、采购和渠道赚取利润，不拥有SHM晶圆制造厂。能解释收入与利润来源，尚不能精确预测分规格价格、上游量和2032后的续接条件。

三季报触发全量重估，并由旧平铺档迁为七文件。旧档exclude、期望50.51亿/33.97元；本轮exclude、109.56亿/73.68元。**评级相同不代表旧解释正确。** 本轮最重要的新事实是利润继续增长、大容量NOR已有交付、SHM二采购渠道有支出，同时母公司现金未跟上、合并口径匹配现金比已触发旧警戒。

反向思考的三条亏损路径：高价库存与上游成本追涨叠加产品降价；主供中断或量约束而替代制造源未完成客户认证；以长期成长价格买入有限期周期租金。十年竞争力判断保持谨慎，不把一季涨价当自主定价能力。

八问快筛：商业模式可解释；十年存续可能但供货续接未证实；护城河窄；脱离行业独立涨价5%—10%能力未证明；集团利润真实但现金分层偏弱；集团账面资金有缓冲而母公司需融资；未发现诚信一票否决；现价缺安全边际。定价权、现金和价格未通过，仍建档用于已有研究纠错与持续监控，不列入核心配置。

## §2 市场规模：按可服务产品拆跑道

本轮**未找到足以可靠计算最新分容量TAM/SAM/SOM的公开同口径数据**。旧档第三方全球NOR约30—44亿美元的宽分母，既有预测口径分歧也受本轮价格变化影响，不沿用为2026确定值；没有用全存储或AI服务器总市场冒充普冉SAM。公司公开排名只证明卡位，不反推出百分比。

|---|---|---|
| NOR 512Kbit—128Mbit中小容量 | SONOS低功耗/成本基础，消费、TWS/可穿戴、显示等；40nm 4—128Mbit系列为出货主力 | 分容量收入和份额缺；竞争密集，不能用全NOR份额当小容量SOM |
| NOR 256Mbit—1Gbit，含512Mbit—1Gbit | ETOX 55/50nm 4Mbit—1Gbit已量产；256Mbit—1Gbit已交付部分工控、通信、PC、服务器；4Xnm 4—256Mbit亦量产 | 商业覆盖已打通，金额/毛利/重复订单缺；扩SAM有事实，剩余天花板不可量化 |
| 汽车/工业NOR | SONOS、ETOX全容量已有AEC-Q100认证，ADAS/座舱可能提升代码存储需求 | 认证不等于车型设计赢单；ADAS收入、车载NOR单机价值及份额缺 |

| SHM SLC NAND、eMMC/MCP | 公司称2025全球SLC第三；H1独立SHM收入23.4597亿、Q3约20.39亿 | 排名非份额；NAND总TAM不是低容量2D利基SAM，受可采购量和技术替代约束 |
| MCU/VCM Driver等存储+ | 产品持续出货、客户复用可扩钱包份额 | 没有同口径分业务TAM和Q3金额，不能给远期市占目标 |

需求逐项量化边界：

- **AMOLED**：【软】Omdia 4-20预测2026手机AMOLED出货7.78亿片、同比−7%。手机/折叠/车载的分项增量、外置NOR每屏配套率及普冉单屏收入缺；显示驱动集成差异使“每屏必一颗NOR”不能当事实。
- **AI server/BMC/boot**：【软】TrendForce 8-03预计AI服务器出货近+31%、九大CSP capex+90%；9-14称AI机NOR用量为传统机3—5倍。缺普冉单机价值、具名客户订单和AI NOR可服务金额，两项不能直接相乘生成收入。
- **车规ADAS/座舱、工业、TWS/可穿戴**：已有产品/认证或交付，逐项外部最新市场增量与公司份额均缺，不拿整车或耳机总销量乘未经核实的配套数。

跑道结论：大容量、车规、工业和海外渠道拓展具备方向性空间；消费终端并非全面高增。提高长期估值需要“市场份额×单机价值×可靠订单”桥，当前还不能给到可靠天花板百分比。

### 3.3 量价与涨价弹性：只算可支持的部分

H1 NOR出货超过37亿颗、EEPROM超过8.7亿颗；MCU超过33亿颗为**产品推出以来累计**，不是H1销量。H1存储系列收入约12.84亿，混合NOR/EEPROM；12.84/(37+8.7)<0.281元/颗只是混合均值上界，**不是NOR ASP，也不是大容量ASP**。Q3公司明确量、价均同比上升，大容量提价与SHM高毛利拉升业绩；逐容量销量、ASP和毛利缺，不能定量分摊量增百分比。

按容量段的可复算弹性仅给**单位收入敏感性**：在销量不变、单位成本不变时，某段收入R、售价涨幅p，新增毛利=R×p；若该段原毛利率m、代工成本占成本c、代工涨幅f，则新增毛利约`R×p−R×(1−m)×c×f`。例如每1亿元段收入、涨价10%，最多新增毛利0.10亿；假设m=35%、c=70%、代工涨10%，则只增0.0545亿。这是压力算式，不是已实现业绩。

小容量≤128Mb消费级机构4Q预测+10%—20%；高容量≥256Mb机构2H预测+90%—110%，期间不同，不可直接比较弹性倍数。实际小容量/512Mb—1Gb收入R、m、c均缺，因此不编全公司净利增幅，也不因小容量标签给“纯弹性”。SHM的利基SLC/MLC和eMMC又是独立价格链；其正常化现金在[§9](valuation.md)拆分，不能套NOR毛利。

## §4 全球竞争力：排名有意义，不能替代议价权

公司援引研究称2025 NOR和EEPROM销售额全球第六、SHM SLC第三；百分比份额未披露。SONOS工程与中小容量成本、ETOX大容量覆盖、SHM海外客户和固件认证构成竞争基础。相对华邦、旺宏、国际IDM，差距仍在自有制造资源、长期规模供给、车规工业客户深度和全球多来源保障；相对兆易还有MCU生态差距。取得认证不等于客户无法换供。

## §5 核心优势、管理层与护城河

**窄护城河，强度中偏弱，产品覆盖拓宽但定价权未证实。** 成本/工艺工程和客户认证可延缓竞争，不能阻止代工方提价或同类设计替代；没有网络效应。SHM固件与认证的切换成本有价值，却受单一规模主供、合约期限和上游租金分配限制。周期涨价同时仍有弱品减值，说明产品异质性，不足以直接证明客户已经大量逃离，也不能当独立提价权证据。

管理层诚信：暂未发现公开事实触发否决；公司披露弱品减值、供给集中与期限风险，H1/Q3均未经审计，不能以“审计过利润”背书。资本配置：中等，收购剩余权益可能增厚，但高价回购和8亿保障金需用未来回报验证；不能凭无负面公告断言绝无减持。股东意识：有回购和激励，是否注销、累计摊薄与真实费用持续跟踪。机构惯性风险在涨价时追逐锁产和扩张，若再次新增大额承诺而现金不改善应扣分。

十年持有前提仍是可靠制造来源、持续产品迭代和现金回报，而非目前高毛利不变。窄护城河倍数纪律继续成立，旧低利润基数并不因此自动成立。
