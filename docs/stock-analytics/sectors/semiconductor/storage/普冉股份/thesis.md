# 普冉股份 — §6—§8 论点与周期

## §6 核心新论点：真实受益，长期租金仍待证明

**最强反驳先行：业务所有权转手不是产能销毁，大容量已交付也不是收入结构全面升级；有采购第二渠道不等于规模化第二制造源落地。** 三季报证明当前涨价利润继续兑现，不能由此推导永久高毛利，也不能因上游风险抹去未来几年的现金价值。

### 6.1 NOR独立供需引擎：退出、代工分配与工艺提效同看

NOR不是DRAM，HBM不会与NOR在同一条晶圆线任意切换。直接供给因素是成熟节点资源分配、原厂产品优先级、制程良率与客户认证。AI是终端需求及资本配置的间接驱动；把“HBM挤出”直接写成所有NOR/NAND永久缺货，缺少物理和经济桥梁。

| 参与者 | 可核事实与时间 | 对普冉的传导 | 最强反向约束 |
|---|---|---|---|
| Infineon/Cypress→华邦 | 【硬】2026-09-16宣布出售NOR/F-RAM业务，预计2027H2完成 | 汽车/工业客户与产品线重新整合 | 所有权转移并非停产，不能算永久退出供给 |
| Micron NOR | 【硬】官网仍有长供生命周期方案 | 老客户长供与专用品类仍存在 | 本轮未获“全部NOR退出”的逐SKU官方EOL清单，不能编统一退出日 |
| 旺宏 | 【硬】2026股东会文件披露新台币220亿capex与12英寸扩充、NOR/NAND双路线 | 一面迁移资源，一面可响应高价 | capex总额不等于同规格新增晶圆；回流时间及可用bits未披露 |
| 华邦/兆易 | 【软】9-14机构研究称制程迁移及有效产出恢复；【硬】华邦承接英飞凌业务 | 短期认证限制、长期bits/wafer增供 | 制程缩小即使wafer starts不增仍会增加bit供给，不能永久稀缺定价 |
| 中芯/华虹/力积电 | 【硬】本体8亿华虹锁产；中芯专题转录成熟线从LCD driver调往NOR | 锁产改善可获得量，转产增加行业供给 | 普冉采购价、配额与良率缺，无法量化涨价被代工分走多少；中芯问答本轮未独立取得原文 |

9-14 TrendForce按≥256Mb定义高容量，预测2H26再涨90%—110%；≤128Mb消费级涨速放慢，但4Q仍预计涨10%—20%。这是**机构不同期间预测**，不是普冉ASP，更不能将涨速放慢写成已跌。lens的≤256Mb/512Mb—2Gb分段与该机构≥256Mb门槛不同，256Mb处不能混算。两家同口径最新成交序列未取得。

需求也需双面：AI服务器的BMC/boot、retimer固件可能增加NOR用量，机构估AI服务器用量为传统机3—5倍，但未给普冉单机价值；AMOLED手机面板2026出货反预计−7%。车规AEC-Q100认证、工业与通信交付是真实进展，TWS/可穿戴、折叠、车载增量缺分客户金额。不能把所有需求一律上调，也不能凭“每屏一颗”生成订单。

判定：**有结构性产品升级和供给分配变化，当前盈利仍以周期价格租金为主。** 大容量交付使旧静态小容量判断失效；分容量收入、毛利和重复订单金额仍缺，暂不足上修为宽护城河。NOR占收入比例不透明，普冉是多业务混合弹性，不称NOR纯弹性。

### 6.2 SHM利基NAND：逐家核退出，不能把整个NAND当一个市场

| 原厂/竞争者 | 范围、时间与证据层级 | 意义与反驳 |
|---|---|---|
| Samsung | 【软】TrendForce 1-07称MLC于2025-03宣布EOL、2026-06末出货 | 仅特定MLC路线，非全部NAND；未取得面向所有客户的官方逐SKU全文，不认永久退出全部存储 |
| Kioxia | 【硬】3-15原厂TSOP PCN、4-10 ATP下游通知部分15nm MLC/24及32nm SLC末单9-30、交付可到2028 | LTB不是即刻断供，更不能以末单结束推断2027库存立即消失或释放 |
| SK hynix体系 | 【硬】SHM供应协议正常执行至2032-12；【软】研究称优先既有客户 | 出售经营资产不等于停止生产供应；协议有量安排也有周期定价，主供集中真实 |
| Micron NAND | 【软】机构称MLC以既有承诺为主、扩供意愿弱 | 未获全球SLC/MLC统一退出日的官方清单，不将所有低端NAND归零 |
| 旺宏 | 【软】机构认为可承接MLC缺口 | 是竞争反向力量；没有足以量化抵消全部缺口的同规格达产表 |
| 华邦 | 【硬】8-06官方Q2称24/32nm SLC贡献上升 | 收入增长混合涨价与数量，不能等同同幅新增产能 |

1-07机构预测2026全球MLC产能−41.7%是预测，不是实物清点。SLC/MLC指每cell位数，2D/3D是结构，不能互作同义词。7-13机构把2H26相对1H26 SLC涨幅预测上修至120%—170%；6-16原预测70%—75%是更早时点，**旧专题引用7-13并非错引**。SLC涨幅不能代替SHM全部eMMC/MCP的实现售价。

SHM有固件、工程、可靠性认证及海外渠道，2025全球SLC第三为公司援引研究的排名；它不拥有晶圆制造厂。低容量eMMC与利基SLC/MLC受益可观，但全球缺口转成公司份额还取决于可采购晶圆量、良率、单片价值与客户重认证。不能按IDM稀缺产线给价。

**供应链两端同时成立**：10-17注册稿新增H1经Unitrontech采购晶圆1892.03万元、占全部采购1.35%；同一文件仍称仅一家规模化供应的存储晶圆和控制器供应商。第二采购渠道有动作，底层第二制造源持续量产/客户验证/保障量仍未获公开证据。2032是现合同边界，续约和替代可设概率，不能直接说2033停业。采购按市场机制和季度定价框架，不支持“上游可任意收走全部利润”的确定断言，但追涨成本滞后仍会挤压利润。

判定：**比旧档更强的近端可提取现金，叠加仍脆弱的中长期供货权利。** 正常化不能退回旧评估低利润而忽略现实，也不能用当前净利率一路永续；在[估值](valuation.md)分开计量至2032和之后条件续存。

### 6.3 扩产与资本配置：保障供给要付资金代价

Fabless不虚构自有产线达产率。8亿华虹成都产能保障协议是【硬】供给确定性改善；节点、片数、季度付款、增量收入和达产曲线【缺】。它是赌需求与保障供给的共同安排，不是AI独家订单。若同业同时扩供，长期价格会回落；SHM合同池和本体华虹锁产不是同一池。

注册稿列博世、惠普、思科等终端覆盖，不等于这些公司直接向普冉下达可量化订单。客户capex能见度只能降级为终端市场兑底，不能把CSP资本开支直接映射成公司订单。已有批量出货计入正常化假设，未获证的增量不进确定利润。

剩余49%收购尚待注册，以约1.80%老股权益稀释换取新增49%链条归属，在本轮估值下有增厚可能；证券市价机会成本与全面摊薄不得双扣。8-31已回购122,880股、4999.41万元、均价406.85元，只占总股本0.0826%，不能抵消273.29万潜在新增股，也不能证明回购价低于内在价值。资本配置评分中等，需警惕为追逐涨价而加大资金承诺的机构惯性。

## §7 AI与概念潜力：产品能力和量化业绩分开

| 维度 | 市场、卡位、兑现与限制 | 结论 |
|---|---|---|
| 间接供给重排 | Q3管理层明确AI算力建设改善供给格局并推动提价；已体现在业绩，但租金需与原厂、代工共享 | **【真敏感】**：公司归因和实际利润同向，进入现有经营现金尺度，不另加一笔“AI利润” |
| 大容量server NOR/BMC/boot | 256Mb—1Gb已交付PC/通信/服务器，车规全容量有AEC-Q100；机构称AI机NOR用量3—5倍，普冉单机价值、设计份额、GPU/CSP具名订单和AI独立金额缺 | **【真敏感】**：已有商业产品与终端映射，尚未证明可量化AI业绩，估值不加AI溢价 |
| EEPROM/DDR5 SPD/TS | 重点客户已验证且量产，功能分别是参数存储/模组识别/温度监测；不能套NOR涨幅，AI收入与毛利未拆分 | **【真敏感】**：有交付而非纯研发，AI增量金额未证实，不另计增利 |
| AIoT MCU/Driver | 已持续出货，但AIoT销量不等于AI收入；缺专门AI订单、放量路线图和算力价值量 | **【蹭概念】**：若用该标签推导AI高倍数，超出已公开业绩证据 |
| HBM身份外推 | 普冉不是HBM销售商；HBM优先投资影响传统DRAM资源，传向利基存储还需多层验证 | **【蹭概念】**：不能把HBM盈利模式和估值直接移植给NOR/SHM |

前景尺度：【软】TrendForce 8-03将2026 AI服务器出货增速由28%上调近31%、九大CSP capex预计+90%；是终端兑底，不是具名客户锁单，也不是NOR可服务市场金额。旧群智370万台/+51.3%与此定义不同，不能平均成“共识”；本轮未取得第二家同口径更新及普冉AI SAM。增长不意味着价值无穷，现价仍较bull高近一倍，[§9](valuation.md)没有用想象空间填估值差。

## §8 周期定位：高景气继续、边际分化扩大

| 向上证据 | 对冲证据与判定 |
|---|---|
| Q3合并毛利55.15%，高于Q2 54.87%；母公司43.55%，高于Q2 41.54% | 财报尚未证明利润已见顶；绝对毛利已远超过去常态，不能直接永续 |
| SHM Q3收入约20.39亿，比核对后的Q2约16.0332亿增27.17% | 单季独立SHM净利/OCF仍缺，不能把收入增速改称净利增速；上年同期收入环比+18.69%仅季节观察 |
| 机构9-30仍预计4Q DRAM合约+10%—15%、NAND+15%—20% | 这是主流篮子预测，不是SHM低容量MLC成交；实时同规格现货/合约价差、渠道库存天数和稼动率均缺 |
| 大容量NOR交付、SLC/MLC供给重排支持近端 | 低容量涨速趋缓、TLC替代、竞争扩供与工艺提效反驳永久稀缺；NOR周期不套DRAM位置 |
| 前三季合并OCF16.02亿 | Q3 OCF/全部净利0.558触发预警，母公司前三季OCF负；应交税费和应收快速增长要求现金折价 |
| 存货周转155.75天较同期194.70天改善 | 集团并表改变结构；存货25.54亿、部分弱品新增计提扩大，不代表所有库存健康 |

当前可称**涨价高位延续、结构分化阶段**，不能证实精确周期顶日。NOR盘子、集中度和成熟代工响应不同于DRAM；SHM的利基NAND又不同于主流TLC/SSD。上调长期中枢需要分容量毛利、稳定二供和重复订单，价格仍上涨本身不足。

估值因此同时做两件事：提高正常化本体和近端现金基数，并为SHM供给与价格回归折价。高景气不被抹去，结构性重估也未获全硬证据。
