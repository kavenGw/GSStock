# 普冉股份 — §9 估值与相对旧档变化

## §9 场景加权估值：从零重建 SOTP

**结论：bear/base/bull 每股 23.62/77.50/139.21 元，概率 30%/50%/20%；期望 73.68 元，对现价 270.50 元安全边际 −72.76%。** 这是低确定性估算，不是短期目标价。全部金额除每股、股数外均为人民币亿元。模型比旧档明显上修，仍不足支持现价。

### 9.1 价格、起算日与口径

[原始来源与核验口径](sources.md)：2026-10-29 收盘 270.50 元×148,703,553 股＝402.243110865 亿元；按9月归母净资产39.990823亿元重算PB **10.0584×**，TTM归母PE **23.6145×**、扣非 **24.0482×**。接口PB12.03滞后于半年报，不采用。价格早于当晚三季报披露；10-30是报告落款日，不把10-29跌幅归因财报。

估值基准日为 **2026-09-30**，未来现金从 **2026Q4** 起算；与10-29价格比较的一个月时差不作虚假精调。前三季已赚利润不再加入未来现金流。它们留在资产负债表现金、应收、存货和其他净资产中；经营资产产生以下未来现金，不能再按账面总额加一次。现阶段可单独确认的可自由分配超额现金取0，相关保守性及上界见9.5。

现有51%和完成100%分开。三情景把经营状态和交易结果共同定义：bear含收购未完成；base/bull条件为交易完成并全转股。不存在“当前已持有100%”的事实断言。统一先算每股价值，再乘现有股本得老股东等值总价值，以该值与当前市值比较。

### 9.2 本体：先正常化，再保留近端超额现金

本体指剔除诺亚/SHM链条的经济业务，**不等于母公司单体**。Q3集团归母7.281573亿，若49%少数损益全部来自该链条，则调整后100%收益基数=4.502903÷49%=9.189599亿，本体敏感性残差=7.281573−51%×9.189599=**2.594878亿**。这是条件代理，不是SHM官方独立净利；H1三种利润口径已有差异。母公司Q3净利2.675986亿只作交叉观察。两者均说明旧base 3.2亿常态值需重建，却不能证明Q3×4永久成立。

以下都是**主观模型参数**，不是公司指引。正常化OE近似为 `(营收×毛利率−持续期间费用)×(1−税率)×现金兑现系数`；费用包含研发、股权激励、常态减值与融资成本，不把股份支付、存货损失机械加回。净财务收益不资本化。缺乏维持capex、分部营运资本桥，故系数同时覆盖D&A与维持capex差额、现金税和营运资本占用，**并非精确OE测量**。

基准营收42亿接近Q3剔SHM外部收入10.1136亿的四倍40.45亿，毛利36%低于母公司Q3 43.55%，全年OE6亿低于条件残差年化10.38亿；并非强迫收入回到旧27亿。bull营收50亿要求大容量与存储+持续放量，但40%毛利、9亿OE仍低于最新季度顶部代理。bear回落至35亿及32%毛利，体现价格与代工刚性。分业务收入和实际ASP未披露，这些桥的精度有限。

### 9.3 SHM链条：有限期现金与2032后条件续存

H1独立SHM净利10.00548亿是事实；Q3独立SHM净利、现金流未披露。调整后链条Q3收益基数9.18960亿只支持近端起点的敏感性。SHM无自有晶圆制造产能；现有主供合同至2032年12月、约定采购量约束与市场定价依然有效。第二采购渠道已有1892.03万元支出，不等于规模化第二制造源已认证。

采用**链条100%股权现金流代理**，已扣持续研发/工程、采购、营运资本和现金税后的FCFE，不另叠加SHM利润倍数。归母以前先对整个链条估值，再按51%或100%归属。

贴现12.4%（参考旧评估风险尺度，本轮仍属判断），t依次0.25至6.25。2032后不把“企业灭失”当事实：bear终值0；base假设**35%续存成功率×长期FCFE4亿×8倍**=11.2亿；bull **65%×8亿×12倍**=62.4亿，均在2032末再折现。4/8亿来自2032附近可提取能力圆整，不是合同续约承诺。三情景概率和情景内续存概率层次不同，后者只折价2033以后现金。

### 9.5 现金、压力测试与最脆弱参数

母公司财务净现金2.99853亿是**未扣**最低运营现金、租赁及保障金的上限；集团净现金22.83290亿含子公司和49%少数权益对应份额。集团应交税费4.08520亿，税款支付时点使当前OCF偏强；8亿保障协议的已付/未付余额不明。不能把22.83亿全加、乘51%、或以少数股东权益余额代替现金归属。

主表采用**已赚现金全部留作偿债、税款、营运与已承诺资金的保守情形，超额可分配现金=0**，没有说已赚利润消失。这使主表偏下界：如果其中确有闲置现金，则须按独立现金桥补回。独立归属不明之前，不伪造一个“净现金点数”。模型FCFE已经包含未来保障金与营运资本的兑现折价，不能再无条件扣全额8亿；主表也没有另扣4.085亿税款，避免把过去应交税和未来现金税重复相扣。
