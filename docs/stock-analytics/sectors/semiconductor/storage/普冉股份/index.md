## §10 评级决策

**维持exclude，不新增配置；已有仓位在长期价值框架下优先减仓评估。** 依据是正常化、股权归属与现金折价后价格仍过高，不是“公司没有增长”或“利润不真实”。内在价值区间比旧档上调明显，市值较旧锚下降42.05%，仍不足形成安全边际。模型细节、现金保守性的边界和同等经营条件下51%/100%股权桥均见[§9](valuation.md)。

以未圆整估值加权，期望109.5635亿；对402.2431亿市值安全边际−72.7619%。bull老股等值207.0134亿也只有当前市值约51.46%，单独安全边际−48.54%。现价隐含了比本轮bull更持久的高盈利或更强的供货与客户壁垒，需要新增事实支撑。

| 价格/事实门槛 | 行动 |
|---|---|
| 当前270.50元 | 不新买；持有者复核减仓与替代机会，不能以跌幅大代替估值 |
| 约73.68元，接近期望价值 | 进入价格观察，仍不足抵消供货、周期与现金不确定性 |
| 约44.21元以下，期望值六折 | 才讨论初始安全缓冲，同时重核现金和生意；不是自动买单 |
| 经营现金持续失配、主供中断且替代失败、诚信问题 | 独立于价格重新评估，诚信确证问题立即卖出 |
| 分容量结构、稳定二供、订单/现金出现硬进展 | 先上修现金参数，再决定评级，不通过抬AI倍数补缺口 |

卖出四条件逐项：

1. **价格严重高估：是。** 在本轮可辩护假设下，bull也低于现价，适用减仓评估；估值不是下个交易日跌幅预测。
2. **护城河被摧毁：未证实。** 产品范围与客户交付反而改善，制造源集中仍在；不把窄护城河写成完全无资产。
3. **管理层诚信问题：未发现足以否决的证据。** 不以未经审计利润冒充审计保证，也不以没有公告断言绝无减持。
4. **显著更好机会：有比较候选，尚不凭此自动换仓。** 同期同业扣非、金融收益、A/H口径和风险不同，旧“聚辰永无β”和“普冉PE最高”均不能沿用。[当期比较与治理](business.md)

静态股息率按每股0.12元/270.50元为0.0444%，圆整0.04%，无足够股息等待回报。最脆弱的估值判断是2027 SHM FCFE17亿及之后的回归路径；若利润转现金弱于模型，要直接下修，不用更高终值抵补。[现金与终值压力测试](valuation.md)
