# 长鑫科技 — §9 估值与相对旧档变化

## §9 场景加权估值

**期望内在价值6,086.68亿元、每股8.97元；对41.80元收盘价，安全边际−78.55%。** 三档每股3.60/8.86/17.28元，概率30%/50%/20%。这是对穿越周期现金能力的低置信度估算，不是短期目标价。正常化盈利已随实际经营与技术进展上修，不能再冻结旧5.79元。

### 9.1 起算日、股本和价格

金额除另注均为人民币亿元。2026-10-30收盘41.80元，腾讯16:14:38与新浪15:34:59快照一致；股本67,884,099,077股，即678.84099077亿股。价×股本=28,375.553414亿元，与接口28,375.55亿元一致。价格形成于当晚三季报公开之前，不能把当日跌幅解释为三季报的市场反馈。[来源与核验](sources.md)

9月归母权益2,568.7631亿元，BVPS3.78404元，重算PB11.0464倍；接口PB14.11倍分母滞后。TTM归母=2026前三季1,320.4005+2025全年18.7486−2025前三季负52.7997=1,391.9489亿元，PE20.3855倍。后两个历史数继承招股书基线。PB与PE描述当前资产和历史利润，不单独决定贵贱。

估值基准为9月末，未来现金从2026Q4起算；与10月末价格比较的一月差异不做虚假精调。前三季已赚的利润不再加进未来现金流。账面现金、IPO募资、应收存货及厂房不另按总额叠加；这些资产共同支撑未来收益，且含少数股东权利与必要再投资资金。

参数桥及最强反驳：

- **bear**：价格和毛利明显回落、国产替代维持但成本追赶受阻，营收1,800亿元约为前三季收入年化3,586.99亿元的一半；45%毛利并不是灾难底。归母份额60%略低于Q3实际61.17%，保留利润向少数权益较多的经营主体集中风险。8倍取窄护城河低端；若发生持续亏损或设备限制，实际价值可低于本档，没有净资产价格底。
- **base**：营收2,600亿元高于旧长鑫的历史规模，但低于当前高价运行率；55%毛利承认DDR5/LPDDR6和G5升级提高中枢，同时剔除89.53%毛利长期不变的假设。归母份额65%介于Q3的61.17%和9M的67.18%之间。510亿元OE高于旧base直接采用的396亿元利润，且已经扣再投资现金；10倍对应标准化存储产品的周期与竞争，而非软件股倍数。
- **bull**：营收3,400亿元仍低于9M年化，65%毛利需要产品升级与每晶圆产出提升持续兑现，68%归母份额需要经营利润组合改善。1,057.74亿元净利、890亿元OE均低于Q3归母年化2,177.39亿元；没有计入HBM收入。12倍已经给规模和技术追赶较高信用。若高景气成为长期新均衡，毛利与收入的回落假设会过保守，这是模型最重要的上行风险。

45%/55%/65%与89.53%的差距是**分析者对价格周期回落的判断**，不是本期财报证明未来必回落到该区间。G5量产支持正常化规模与产品中枢上修，但缺良率、全公司迁移比例及客户采购承诺，不能据此保证当前毛利永久化。维护capex高于D&A体现持续制程迁移负担；具体差额不是公司披露，需后续现金附注校准。

### 9.5 现金归属、反向估值与敏感性

没有另加“集团净现金”：9M现金等价物2,643.02亿元、金融资产684.57亿元中，少数权益、受限资金、贷款及其他负债、已签约资本支出和技术再投资均须核实。它们不是全部归母可分派盈余。该处理偏保守，**不等于现有现金价值为零**，而是不在缺少归属桥时给单独超额现金加项。假设未来核实可自由分派的归母超额现金另有500/1,000亿元，期望每股会升至9.70/10.44元，仍不足覆盖41.80元；这是假设敏感性，非已核实现金余额。

以12倍正常化OE覆盖当前市值，需每年归母OE2,364.63亿元，比Q3归母净利润年化2,177.39亿元仅高8.60%。因此旧“永续2,400亿等于顶部2.1倍”失效，必须撤回。问题在于**再投资后可分配现金能否在下行期仍保持该规模**，不能将本期归母净利润与长期OE当同一口径。扣除本模型未来超额现金后，该反向门槛会略低，仍显著高于本模型的正常化三档。

若保持bull OE890亿元并加其未来超额现金，覆盖现价需约30.70倍正常化OE，标记**❌破框架压力测试**，不纳入正式三档。若保持12倍，则需要约2,277.24亿元常态OE；不能靠把“AI”换成估值倍数来绕过这一现金要求。

三档正常化毛利同时提高5个百分点、其他利润桥参数不变，增量归母OE约45.90/71.83/98.26亿元；只计长期倍数部分，期望价值增加705.11亿元、每股增加1.04元。若未来现金路径不同时上修，额外OE会减少超常现金差额，净增值更低。最脆弱参数是正常化毛利和收入中枢，其次是少数权益经济份额及维护投入，非小数点汇率或PB历史分位。

有不确定因素，按期望价值50%—60%才进入重审，约**4.48—5.38元**、市值3,043.34—3,652.01亿元。该区间随基本面变化重算，不是价格到位即自动买入，也不预言市场会跌到这里。
