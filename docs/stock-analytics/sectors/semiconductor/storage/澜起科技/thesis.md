# 澜起科技 — §6–§8 核心论点、AI与周期

## §6 核心新论点：商业化已推进，技术成长与景气同时存在

**最强反驳前置**：Q3和Q4订单不能证明永久成长。客户可取消/延期、晶圆封测供给可能卡交付，高SBC比较基数也放大表观增速。上游颗粒厂可以调回部分供给；接口竞争者也在迭代。因此既撤回旧“2026只有金融收益、新品尚未起量”，也不把本季利润直接年化。

### 6.1 逐家公司与供给动机

|---|---|---|

这是**接口产品升级的结构性增量叠加服务器装机周期**，没有证据支持三强永久缺供。认证与交付链条比“国产替代空间”更有解释力：公司已是全球量产供应商，属于订单与产品实证；没有取得逐料号多年框架采购，不可把潜在空间全写成已锁收入。

### 6.3 颗粒供给不是接口芯片份额：storage lens逐项边界

1. **价格**：TrendForce 9/30预测Q4常规DRAM合约价环比+10%–15%、NAND+15%–20%，且消费承压【机构预测】；10/29同规格现货/合约成交价和机构间可比报价缺失。预测不能作已成交事实，更不能把颗粒涨价率代入澜起ASP。接口没有完整公开报价序列。
2. **三厂退出的范围/时间/可逆性**：三星10/29及SK海力士10/28业绩强调HBM、服务器DDR5/SSD；美光FY26 10-K仍列DDR4。未见三厂所有低端料号永久退出的官方日期及不可逆承诺。TrendForce 5/26关于美光Fab6接收旧产线、供长寿命需求的描述是迁移，不是重返全部消费市场。价格回升可使产线和产品组合调整，**退出可逆是永久缺口论的最强反驳**。
3. **利基份额传导**：澜起不生产DRAM/NAND颗粒，没有接盘颗粒缺口的产能，直接利基份额受益不适用。DDR4向DDR5迁移可提高接口价值，但涨价过猛/缺颗粒也会推迟模组装机。
4. **HBM挤出**：原厂优先高端和AI有官方支持；NVIDIA Rubin GPU的HBM、Vera CPU的SOCAMM LPDDR5X与DDR5 RDIMM用途不同。HBM扩张既可能挤出标准DRAM装机，也伴随CPU/Agent和互连需求增加；对澜起净收入/净利润量化【缺】，撤回旧“净负面已强化”。
5. **库存与减产**：三厂同口径库存天数/节点稼动率/减产进度、模组和澜起渠道sell-through均【缺】；不能据高端强景气宣布所有消费库存出清。复产、低端产能重启、合约价转跌均作为环境监控，不能单独决定澜起盈利。

三份历史行业事件的纠错均已承接：6/19涨价theme不再沿用旧120倍锚；8/2韩国出口theme中的H1毛利改69.3%，量端改善成立，HBM净负面待核；7/13华天利润质量theme中的募资致投资收益因果撤回，金融收益须据资产处置/重估分解。事件链接归[events](events.md)。

### 6.4 成长证据分层与供给约束

Fabless没有自建晶圆线的月产能/达产率模型，相关项目capex不能转算晶圆供给；9M购建长期资产4.0252亿元不等于新增芯片产能。扩产应核代工、封测可得性：【硬】已出货证明当前交付在运行；【缺】逐料号代工厂/节点、预付款对应月产能、锁产合同、封测优先级、报价转嫁幅度与时滞。因此产能紧时排位及涨价消化能力待核，不能因轻资产豁免。

客户层：【硬】公司披露内存接口下游有三星、SK海力士、美光；前两家自身业绩支持DDR5/AI需求，但没有逐家向澜起锁定长期采购。Retimer直接客户为服务器OEM/ODM，未具名订单金额。【硬】10/26在手订单增强Q4能见度，允许取消/延迟。【软】九大CSP capex及服务器出货为终端兑底，不是具名客户合同。

供给、订单、TAM三元素分级与概率落实于[§9](valuation.md)。结构性证据足以提高正常化中枢，尚不足以把bull提高为主情景；同业同时推进新代若集中放量，会造成价格与设计份额竞争。代工报价上升而客户不接受转嫁、渠道补货未转终端消耗，均可证伪高增长持续性。

## §7 AI与概念潜力：逐维度区分业绩与产品

| 维度 | TAM、竞争与兑现节奏 | 判定 |
|---|---|---|
| CPU/服务器DDR5接口 |Q3季报直接归因AI推理/Agent带动CPU与模组需求；互连收入20.47亿、量与结构改善已兑现，未披露AI专属收入比例 | **【真敏感】** 有业绩传导，不把全部互连收入标为AI收入 |
| MRCD/MDB与PCIe5 Retimer |H1与CKD/CXL合计四新品收入5.38亿元、同比+80.7%；公司已有出货。Rambus/MRDIMM、Astera/Retimer在竞争，单品贡献与份额未拆 | **【真敏感】** 已商业化组合支持收益，不能把组合收入都归AI或归单品 |
| 新代PCIe6、CXL3.2 |认证/送样、具名生态初验或试产成立；没有独立大规模利润。公司与国际龙头的量产阶段不同 | **【蹭概念】** 当作当期规模利润时证据不足；产品技术本身并非虚假 |
| CKD客户端 |高频PC CUDIMM/CSODIMM已有产品及商业化，需求主要为PC升级 | **【蹭概念】** 若全算AI服务器收入会错配；已有PC经营收入仍计主业 |
| Switch、PCIe7、DDR6 |工程计划或预研；未取得批量客户收入 | **【蹭概念】** 远期产品层，未进入OE增量 |
| HBM间接供给受益 |没有颗粒产能和HBM产品，也无公司量化净归因；双向机制见§6.3 | **【蹭概念】** 不能将HBM紧缺直接兑换澜起利润 |

终端前景【机构预测】：TrendForce 10/14预计2026 AI服务器出货+32.2%、2027近+36%，九大CSP capex2026年9570亿美元、2027年超1.5万亿美元。这是同一机构总量预测，未找到同定义独立机构完整交叉，不把不同月份上调当多个独立背书。整体服务器另有TrendForce 4月约+13%、IDC 10月约+12%；10/22服务器CPU颗数+31%属于另一量纲，收入涨54%也不是台数涨54%。终端增长率不能直接转换成RCD出货。

AI跑道来自高速接口内容量、子代迭代和内存互联，仍受架构路径、竞争认证、供给与客户预算约束。价格已给出高期待：GAAP53.01倍/扣非70.65倍、PB9.19倍；即便bull价值也低于现价。未兑现概念不进[§9](valuation.md)，不再另叠AI估值溢价。

## §8 周期定位：成长中枢上移，顶部仍未可知

正向信号是Q3收入与互连毛利环比提高、应收回落、CFO改善及Q4在手订单；2026“只靠一次性金融收益”的说法不能解释这些实绩。子代升级和多产品商业化具有结构性，base可高于历史简单均值。

反向信号是Q3扣非增速含2025高SBC低基数；毛利仍低于Q1，存货扩大、客户集中、终端capex高预期，客户备货与重复订单风险未被渠道数据排除。三厂高端需求旺、常规DRAM合约价仍被预测上涨，只能定位于**扩张与结构升级阶段，不能确认尚未到顶部**。价格和估值可能已提前反映未来多年代际升级；没有用“尚未见顶”解除正常化要求。

关键验证是Q4订单到收入/回款的转化、四新品逐项披露及子代毛利、下游内存是否影响装机。若外包供给正常而出货连续放慢、毛利下滑且库存天数增加，更像需求/竞争下行；若订单强、库存为委托加工且供给受限，则须分开看交付延迟。不能把颗粒涨价周期直接当澜起盈利周期。
