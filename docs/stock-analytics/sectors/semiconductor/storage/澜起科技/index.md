## §10 评级决策

### 10.1 为什么维持watch

经营改善及全球量产认证支持继续研究，价格项不通过，所以不升config/core。当前GAAP TTM PE53.01、扣非70.65、PB9.19；“比旧价便宜”不等于有安全边际。认证/技术优势仍有实证，未取得诚信或竞争地位根本损坏的定论，暂不exclude。能力圈处边界且可量化订单不等于多年锁定合同，参见[§1/§5](business.md)与[估值门控](valuation.md)。

**唯一买入讨论区为期望价值的50%–60%：345.30–414.36亿元、28.29–33.95元**，前提是论点未损坏、订单与现金桥重新核验。40%–50%价值折扣对应技术、周期与监管不确定性；纠正旧档以60%–70%期望值设买点的偏宽层级。PE35倍及PB20分位保留历史执行记录，均不作为另一套买点。新事实若改变OE、概率或现金，应先重估再改变买价。

**卖点/复审阈值**：价格高于bull83.16元已构成高估警报，不是机械指定清仓价；持仓者当前应重审回报预期和仓位。若无基本面变化，股价到期望值约56.58元仍没有所需折扣；不得把此前成本或历史高点当价值锚。基本面/诚信触发的退出独立于价格。

### 10.3 watch降级路径与长期复审

沿用旧路径A的执行记录：①正式卡特尔指控/认定且此后连续两季互连毛利低于65%；②原厂自研RCD量产或第四家通过平台/内存厂等认证并取得可查份额；③下一代首批认证名单落选；④管理层诚信实质问题。①本次程序及后续毛利因果缺证；②③缺足够证据；④未证实，均不得以“未找到”宣布风险解除。正式指控先触发法律及经营重估；不能等到毛利阈值才处理已证实诚信或永久损伤，也不能单凭指控推诚信有罪。

路径B：自8/8基准起连续六季度安全边际未收窄至−50%以内，2028Q1强制复审watch→exclude，不自动判生意变坏。本期仅约一季，观察时间未满；当前−66.08%仍在旧负向范围，未重置起算日。是否保留观察池届时依重估决定。

## §11 关键风险、监控与旧触发器复盘

### 11.1 风险Top 5

1. **价格包含较远增长，而利润中枢仍不确定。** 经营加速不能消化现价；风险归因由旧“过渡年/只有金融收益”改为高预期、竞争及周期波动。估值反向要求见[§9.5](valuation.md)。
2. **韩国调查及潜在客户/定价影响。** H1披露7/15办公室搜查；截至已核资料未找到更晚官方指控、处罚或结案，不等于解除。高毛利不推法律责任，撤回旧“调查反证护城河”；[来源与限界](sources.md)。
3. **技术架构、迭代和外包交付。** LPDDR/SOCAMM替代部分RDIMM、竞争者新代量产、代工与封测供给不足均可能削弱内容量或延迟交付；HBM对澜起净损益未量化。[产品分档与供给双面](thesis.md)。
4. **客户集中与库存真实性。** 2025最大客户29.7%、前五77.2%，Q3同口径未知；未有完整渠道sell-through。订单可取消，库存增长不能仅由“收入也增长”洗去。[现金与周转证据](business.md)。
5. **金融利润、资本配置和稀释。** 非经常收益比例历史命中旧阈值；扣非仍含利息/汇兑。SBC真实成本、现金闲置与回购价值待验，不凭减持/回购时点断诚信。[OE和可分配现金桥](valuation.md)。

### 11.4 新增可执行监控与最脆弱论点

以下为本次分析设定的预警阈值，未宣称公司承诺或当前已发生：

- Q4实际互连收入若低于原订单下限25亿元，核订单取消/递延、汇率与产能影响，并重估收入中枢；不能把25亿订单直接当业绩保证。若关键产品量产较公开节点延期超过两个季度，下调bull。
- 同口径滚动存货周转天数较上年扩大超过20天、连续两季恶化，或跌价损失占收入超过1%，追查渠道与品类；当前仅有9M简化周转约153.7天，缺上年同口径，不能伪造命中。CFO/归母滚动四季低于70%连续两期且应收转差时重审，兼看扣非与非经营现金分母。
- 如结构未变而互连毛利连续两季下降、从Q1 71.5%峰值回落超过5个百分点，拆竞争价格、代工与汇率。当前Q3较峰值低3.1个百分点，未达该新增幅度阈值；代工报价上调而售价未同步只作挤压信号，缺价表时记待核。
- 最大客户收入占比超过35%或前五超过85%时重审议价风险；当前只有2025的29.7%/77.2%，最新待核。代理收入转负需结合终端sell-through，代理占比本身也缺。
- 研发资本化率由零上升且费用率同步下行即核实；SBC单独披露并保留成本。当前研发全费用化；研发人数和人均薪酬缺完整同比，不以此豁免后续核查。
- AI专属收入未披露，无法设置可验证的独立占比阈值，先用四新品<15%/<40%组合预警但不把它们全叫AI。终端AI台数/CSP capex预测若同口径较前次下调超过10个百分点，或具名客户下调采购，即复审bull；整体服务器<8%旧阈值继续保留。
- DRAM/NAND同规格合约价环比转跌、三厂官方重启低端产能、同业新代集中量产时更新供给判断；澜起非颗粒厂，这些只触发机制重估，不直接套用颗粒盈利弹性。

**最脆弱论点自评**：base收入76亿元、综合毛利67%和20倍成立，依赖当前出货/结构改善转化为穿越周期的技术收益，而非一次客户备货；长期锁产和分项sell-through仍缺。Q4订单增强近期证据，尚未证明多年持续性。[§9](valuation.md)已展示税率、OE、倍数与金融资产敏感性，若商业化继续超预期可重估，若证据恶化则同步下修，不冻结今天参数。

分红监控沿用已核事实：中期股利2.4169亿元、单次收益率约0.119%；完整滚动年度股息率未核齐，frontmatter为null，不以低息对冲估值风险，详见[§3.4](business.md)。
