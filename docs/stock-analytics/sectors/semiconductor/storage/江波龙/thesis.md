# 江波龙 — §6—§8 论点、AI 与周期

## §6 核心新论点：结构升级与价格周期并存

### 6.1 先说最强反驳：有技术和客户，不代表本期利润可持续

江波龙已经超出“只有贴牌”的刻画：半年报披露企业级收入 21.40 亿元、UFS4.1规模出货以及主控累计生产超过2.8亿颗。但自研主控独立收入、企业级毛利、分产品现金回报均未披露。H1 综合毛利率 58.90% 中，多少来自售价上行、低成本批次和技术溢价尚无法分离。**技术进步是真实的，本期超额利润永久化尚未被证明。** 本档 base 给正常化现金收益30亿元，bull给65亿元且仅20%概率，已在[估值桥](valuation.md)体现这一区别。[半年报](https://static.cninfo.com.cn/finalpage/2026-08-11/1225467150.PDF)

与旧档比较，须同时修正两端：不能将一切增长说成库存红利，也不能接受“AI技术周期已经替代消费价格周期”的单向归因。用户预告若成立，Q3归母环比下滑，可能来自价差收敛，也可能受非经常损益、产品组合、费用和汇兑影响；Q2非经常归母约6.10亿使直接环比更需谨慎。Q3扣非和利润桥未知，不将其中任何一种解释写成定论。

### 6.2 供给侧逐家拆解：新厂、工艺升级、产品转配分别看

最强反方是企业SSD与AI需求持续吸收新增位元，使消费端宽松也不等于全行业崩价。相反，原厂有晶圆与工艺优势，扩产或产品回切仍可能挤压中游模组价差。下表仅使用原厂公开信息与机构原始预测，不沿用旧档“所有原厂同一时间全面扩产”的口径。

| 厂商 | 已核范围与时间 | 对供需的意义及反驳 |
|---|---|---|
| 三星 | 2026年8月FMS展示400层以上V10 BV-NAND，密度较V9约增58% | 【硬】产品路线图；不是当季新增晶圆量，不能直接推算2027过剩；三星HBM4扩产也不等于全部成熟DRAM停产 |
| SK海力士 | 8-07公告M17 NAND首个洁净室计划2028-12启用，投资19.1万亿韩元；Y2 DRAM计划2029-06 | 【硬】新厂时间较远，洁净室非满产；不能据此排除既有产线升级的近期位元增量 |
| 铠侠/闪迪 | 7-03 Kitakami Fab2开始第十代3D NAND生产 | 【硬】现有真实工艺产出，新增位元量未量化；对供给比远期规划更直接 |
| 铠侠 | 8-27 Fab3场地准备，目标FY2029投运，设备安排依市场与政府支持 | 【硬】有条件规划，不写无条件固定供给释放 |
| 美光 | 3-18材料称G9转换为2026 NAND位元增长主驱动，高性能Gen6数据中心SSD进入高量生产 | 【硬】工艺供给增长与高价值企业需求同步；不能全记作消费产能 |
| 长存 | 9-16 TrendForce公开摘要将中国产能列为消费NAND压力变量 | 【软】原厂逐季新增月产能、达产时间未核得，不填确定产量 |

原厂链接与日期见[§12产业证据](sources.md)。这些信息支持“供给约束会变化”，不支持精确宣布价格拐点。

**低端退出是否可逆**：美光6-24官方材料披露Virginia已开始1α DDR4生产，服务汽车、工业、医疗及航天国防，足以否定“全部DDR4永久退出”。三星/SK具体料号最后接单、交付时间的公开EOL文件本轮未找到，旧“续命至2026-12、无锡扩产”的细节不能继续当官方确认。经济性变化可能促使产品回切，实际速度受设备配置、认证与良率限制，不能说随时无成本重启。[美光材料第18页](https://investors.micron.com/static-files/2354ecda-77a0-4ddd-8462-a631eb491356)

**HBM挤出怎样传导**：HBM需要更多DRAM晶圆资源，可能压缩普通DRAM位元增速；DRAM与NAND不是直接互换的一套产线。NAND受企业SSD需求、层数转换和新厂共同驱动。对江波龙而言，资源转配既创造定制存储供应机会，也增加外购颗粒成本和额度不确定性。公司不拥有可直接承接退出份额的DRAM晶圆厂，未核得其可获取的具体缺口份额，不能把被让出的市场整体算进收入。

### 6.3 NAND不是AI错误品类，消费与企业分化更重要

TrendForce 7-21/7-30预测2027H2 NAND逐步转宽松，前提含层数升级扩位元和消费偏弱，并同时指出Agentic AI超预期可能吸收供给。9-16公开摘要进一步强调企业SSD、QLC及KV cache offload需求与消费疲弱的双轨走势；不能把付费报告未阅读部分当已知结论。[7-30原文](https://www.trendforce.com/presscenter/news/20260730-13158.html)、[9-16公开摘要](https://www.trendforce.com/research/download/RP260915MC)

9-30公开预测Q4普通DRAM合约价环比 **+10%—15%**、NAND **+15%—20%**，企业SSD是唯一涨幅加速品类，并预计2026企业SSD位元需求同比超过80%。这使旧档“NAND涨幅持续收敛至年底”的外推失效，但仍属机构预测，不是已实现价格或江波龙订单。[9-30预测](https://www.trendforce.com/presscenter/news/20260930-13258.html)

结构性部分是存储控制、固件和企业客户验证能力的积累；周期性部分是位元供需、售价与成本批次的错位。目前没有分业务毛利证据足以量化两者占比。供应商集中不能自动证明议价权恶化，可能也来自战略采购；但原厂掌握晶圆供给仍限制中游长期回报。

### 6.4 低价库存没有可验证的到期日

H1净库存257.77亿元、占总资产60.12%，证明风险敞口大，不证明全是高价货。公司没有披露可复算的成本层、数量及采购批次流转表，媒体“Q3末耗尽”缺少模型，撤销“硬时钟”。7-09媒体记录投资者问剩余低价库存时，公司仅称库存健康合理，既不是数量承诺，也不能当公司已确认耗尽。[第一财经记录](https://www.yicai.com/brief/103267661.html)

双面结论是：如果新采购成本追上旧售价而售价不再提高，利润会回落；如果价格继续上涨、采购条件改善或产品结构升级，超额利润也可能持续更久。需要同时观察毛利率、存货数量/账面值、跌价计提及经营现金流，不能用归母环降一个变量倒推出唯一原因。

### 6.5 成长与扩产：能力落地，订单和现金回报尚未锁定

公司6-30披露mSSD从2025年10月样品到2026年6月形成百万级月交付能力，并与联想、华硕开展合作，半年报披露在头部PC厂商规模商用。这是实际能力进展；但相关capex、产线利用率、实际销量、ASP和净增收入未单列。原文说明Gen4/Gen5 mSSD搭载联芸主控，故不能将其全部算自研SPU收益。[公司6-30原文](https://cn.longsys.com/about/news/14218.html)

客户证据要分层：联想/华硕是具名合作方，AMD/高通是技术合作方；并无各自对江波龙未来年度采购量承诺。2026H1未履约合同收入13.3021亿元预计年内确认，说明旧“任何订单数字都无”过强，却不能将此当2027长期企业级锁单。终端CSP资本开支增长只用作需求背景，不视作公司订单。

最强反驳是行业共同扩产、客户端库存和原厂资源配置导致实际出货低于能力。结构升级必须最终表现为周转改善、现金回收和可分辨的毛利优势；靠新融资维持高库存的增长不满足同一标准。新增中芯成熟制程涨价和长鑫LPDDR6专题没有江波龙专属成本节约、订单或采购额，只提供潜在供应选择权，不另抬估值。

## §7 AI与概念潜力：产品层和业绩层逐项判断

### 7.1 企业级SSD与RDIMM

H1企业级收入21.40亿元，同比增长208.80%，占公司营收8.884%，属于已兑现业绩。公司称进入部分头部互联网/服务器客户链，但这笔收入同时包含eSSD和RDIMM，不能全部命名为AI收入。最新全球NVMe企业SSD份额、AI专属收入和毛利未知；SATA细分排名也不能替代全球企业SSD总排名。相对国际原厂，公司仍缺晶圆制造和完整供给控制，需要靠定制、验证和交付争份额。

TAM方向由企业SSD位元需求增长和云端投入支撑，独立、同口径的可服务金额与当前份额未核得。没有精确份额就不写“还有多少倍天花板”。兑现节奏以企业级收入和占比逐期提高为准，机构需求不直接入账。**【真敏感】已有企业级收入兑现且终端与AI相关，但AI专属利润仍未拆分。**

### 7.2 端侧UFS、SPU和软件架构

搭载自研主控的5nm UFS4.1已量产及规模商用；车规UFS4.1仍在头部车企导入验证。主控累计超2.8亿颗为截至报告发布日累计生产，非半年出货或外售收入。高通9-23合作为参考设计现场演示，不是指定手机量产数量；AMD联合调优是性能测试，不是已实现利润。[公司高通合作披露](https://cn.longsys.com/about/news/16281.html)

公司7-02募投回复承认PCIe Gen6/Gen7、UFS5.0较全球领先厂商仍在追赶，商业化可能落后。技术进展与代际差距可以并存；未单列的软件收费或SPU独立利润不进入正常化基础。**【真敏感】产品与商用能力可核，但新增AI利润目前仍属待验证概念。**

### 7.3 AI挤出与直接HBM

间接受益机制是原厂资源倾向高价值市场、定制存储空缺和企业NAND需求；公司半年报将行业增长与AI/数据中心联系，提供管理层归因，但不能量化剥离技术与价格作用。**【真敏感】供需和产品需求存在传导，正面需求与采购成本冲击并存。**

将江波龙等同HBM晶圆制造受益者没有本轮产品或营收证据，不能拿HBM景气或高倍数直接外推。**【蹭概念】此标签针对“直接HBM制造敞口”的附会，不否定已披露企业存储业务。**

### 7.4 增长是否已经定价

TrendForce 10-14预测九大CSP 2026年capex为9570亿美元、同比106%，2027年超过1.5万亿美元，属于单一机构终端预测，未获第二家同口径交叉，绝非公司TAM或采购承诺。[机构发布页](https://www.trendforce.com/presscenter)

本档H价格仍比场景期望每股84.19港元高78.29%；需要可持续现金收益约49—59亿元才匹配10—12倍的定价。价格已要求比base更强的结构升级，AI方向正确不足以回答买价问题。[逆向估值](valuation.md)

## §8 周期定位：高价与需求分化阶段，尚不能宣告周期结束

|---|---|---|

| 未来供给 | 新建大厂洁净室释放时间较远，AI需求可能吸收增量 | 工艺升级和现有产线增位元可先发生；2027消费NAND宽松有机构预测支撑 |
