## §10 评级决策与价格纪律

### 10.1 为什么从exclude转watch

旧档把NAND品类本身、自研未量产和库存耗尽时点作为强否决，现有证据要求纠正。企业级NAND具备AI实际需求，自研UFS已商用，企业级收入占比提高，原厂新厂时间与工艺升级也不能合为“立即全面过剩”。这足以撤销质地一票否决，给予持续跟踪资格；还不足以证明宽护城河或穿越周期的高资本回报。[§6—§8逐条反驳](thesis.md)

旧档§10.2另规定“分部毛利证明自研溢价，且市值低于480亿元”才可翻案。两项当前均未满足：分部毛利仍缺，H等价市值为588.34亿元。本轮明确撤销这组条件作为取得观察资格的必要门槛；watch来自对旧论证的纠正，不代表旧门槛达成，也不解除买入所需的现金与价格验证。

旧期望价值225.58亿元，本轮现金桥后330亿元，上修46.29%；同时股价、股本和市场口径均变化。现H等价市值588.3448亿元人民币，比A口径1121.5645亿元低47.5425%，仍高于场景参考。A口径期望每股71.79元、对244元的安全边际−70.58%。不能把H折价本身当成低估，也不能称价值改善全来自价格下跌。[相对旧档变化清单](valuation.md)

### 10.2 观察、买点与估值卖点

- **目前**：保留观察，等待原始Q3公告与现金回收证据。H每股84.19港元是低置信度的期望参考，150.10港元高于它约78.29%；单独bull199.00港元有32.58%空间，但不是以100%概率能兑现的基准。
- **价格观察阈值**：按本档安全边际定义，H约60.14港元以下才有40%空间；若要求买价为价值六折，则约50.51港元。两种分母不同，不混称。由于现金模型尚未验证，跌到阈值本身不构成自动买入。
- **升级配置条件**：原始报表可解释利润、至少连续两季OCF转正且存货周转同比不再恶化、企业级维持增长并提供可辨别毛利或现金贡献。产品量产与现金回报须同时成立，再重算逐年等待期及估值；不能沿用静态买点。
- **估值过热复核点**：H超过bull参考199港元且没有新利润证据，应复核兑现或降低敞口的必要性。当前150.10虽未超过bull，也已高于期望值，已有持仓应结合仓位、成本与替代机会独立评估；本档不代替个体交易决策。

把bull提至15倍可得更高目标，但属于 **❌破框架**压力情景，不用于评级。base在融资后权益参考上仅约1.07倍PB，因为正常化现金回报不够支持高溢价；这是价格纪律，而非因股价下跌自动给估值抬倍数。[ROE/PB与逆向估值](valuation.md)

## §11 关键风险、监控指标与退出复核

### 11.1 关键风险Top4

1. **现金收益点估错误**：正常化30亿元base依赖利润率与营运资本回收假设。若真实利润仍高度依赖成本批次，企业级增长也不足以撑起现金中枢。最脆弱的是“结构升级可使毛利回落后仍有足够现金收益”，而非用户预告的同比数字。[现金桥](valuation.md)
2. **库存和资金链**：净存货257.77亿元、占资产60.12%，周转同比约增加180天；高绝对额借款与资本占用并存。后续募资增加弹性，但当前净债未披露。库存账面价值不是现金，外部募资不是经营收益。[压力测试](business.md)
3. **企业与消费分化下的竞争**：消费需求弱、原厂工艺扩位元可能压低顺价能力；另一方面AI需求可延长企业SSD紧缺。公司的受益大小取决于产品组合、认证与客户采购，不能只看行业总体涨跌。[供给侧双面](thesis.md)
4. **成长兑现与资本配置**：mSSD交付能力不等于满产，UFS与车规阶段不同；大规模融资、扩库存和新品研发能否提升每股现金价值尚待验证。定增限售期满及减持会影响交易供给，但不得用内部人动机替代业务分析。[治理和融资](business.md)

### 11.4 四项卖出原则逐项检查

1. **价格是否严重高于合理价值：按本档是。** H现价较期望参考高78.29%，即便采用未扣等待期的上界仍无安全边际；但bull存在更高价值，不能断言短期必跌。已有持仓应复核估值与仓位。
2. **护城河是否被根本摧毁：未证实。** 本轮相反确认了局部商业化进展；周期回落与永久竞争力受损是不同事情。
3. **管理层诚信是否出现否决项：本轮未发现足够证据。** 不把减持、发行倒挂或负现金流单独等同欺诈；若后续出现可核实的重大造假或侵占，再按诚信否决处理。
4. **是否已有显著更优机会：本轮未建立。** 同业行情快照与历史档不足以构成可立即替换的完整比较；持仓与机会成本未知，不擅自生成换仓指令。

这次重审的核心变化是撤销证据不足的否定，保留可核实的现金风险，并以价格约束决策。下一次最有价值的更新不是复述同比高增长，而是补齐原始Q3报告、库存成本与现金回收。[来源与局限](sources.md)
