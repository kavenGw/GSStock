## §0 结论摘要

**评级：Keep Watching（观察位）。相对旧档 `exclude` 上调一档，实际操作含义是不买、只跟踪。**

**先写最不利的一条，也是本档批判的支点——分母（利润）已经在历史包络之外。** 26Q2 存储分部单季毛利率 **53.86%**，比上一轮周期顶 2022 年的 36.85% 高 **17.0pct**；26Q2 综合毛利率 **57.12%**，比刚创十年新高的 26Q1（43.49%）又高 **13.6pct**；26H1 归母 **11.98 亿元 = 上轮周期顶全年（7.79 亿）的 1.54 倍**。**周期分位 100%——不是「高位」，是从未到过的位置。用任何倍数乘这个分母，都是在给周期顶利润估值。** 这与旧档「估值倍数极端（PE-TTM 144.83×）」不是同一条批判：那一条已被市场消化掉三分之二，**而这一条更硬、更难被行情反驳**（[thesis.md §8](thesis.md)）。

- **期望内在价值 ≈ 122.88 亿元人民币 / 27.76 港元每股**（场景加权，穿越周期正常化口径）。对 **H 口径 437.73 亿元（主）安全边际 −71.9%**；对 **A+H 合并 682.93 亿元（副）−82.0%**。**两者 10.1pct 差额 100% 来自 AH 折价 37.36%，不来自价值判断差异。**
- **Bull 单独压力测试**：即便 bull 100% 兑现（240 亿元 / 54.22 港元），对 H 口径仍 **−45.2%**、A+H 口径 **−64.9%**；bear 档对 H 口径 −89.0%。
- **Bear（34%）** 价格租金回吐 + 库存红利出清 + 代工报价补涨：**6.0 亿 × 8×** → **48 亿元 / 10.84 港元**。
- **Base（48%）** 一轮常规周期，但 HBM 挤出抬高周期底、车规/工业黏性抬高中枢：**12.0 亿 × 11×** → **132 亿元 / 29.82 港元**。
- **Bull（18%，门控封顶 20% 后取值）** 利基 DRAM 上结构性新台阶 + NOR 高容量段兑现：**20.0 亿 × 12×** → **240 亿元 / 54.22 港元**。

三档推导、赋权、bull 门控、隐含 ROE/PB 校验与 SOTP 上界压测见 [valuation.md §9](valuation.md)。

**倍数为什么必须回到框架内（旧档 11/15/18× 作废）**：「车规利基切换成本形成窄护城河溢价」这个理由**成立**，但它的终点是把倍数推到**窄护城河框架上限 12×，不是推到框架之上**——旧档把「该拿上限」误当成了「该破上限」。君正过不了 franchise 门槛（周期底 ROE 约 3%、峰谷比 >2×、护城河源自 30.08 亿元商誉的并购）。**车规溢价改体现在分子而非分母**；8×/11×/12× 与兆易、普冉、江波龙三份兄弟档完全对齐（[related.md](related.md)）。

**本轮唯一把天平往「更弱」压的重大变化**：招股书原文——**2025 年汽车应用收入仅 15.885 亿元（占 33.5%）≈ 2.2 亿美元**，旧档 BOM 拆解估的「7–9 亿美元」**高估 3.2–4.1 倍**，**且占比逐年下降 35.6%→35.4%→33.5%→33.0%(26Q1)**——它削弱的**正是旧档给 base 15× 溢价的唯一依据**。旧档「车规 SRAM #1 / DRAM #4 / NOR #4」与「SRAM 份额 23.9%」在招股书全文**未复现 → 降级为【未核到】**（[business.md §4](business.md)）。

**本轮真正变强的三条多头论据，不因维持结论而略去**（展开见 [thesis.md §6](thesis.md)）：
1. **NOR 品类站位正确、且与兄弟档形成分化**：半年报原文坐实君正 NOR 主力在 **512Mb / 1Gb 大容量段**（TrendForce 判 2H26 **再涨 60~65%** 的一侧），普冉自认基本盘在中小容量段（盘整且已计提跌价）。**但存储分部内收入拆分从未披露【缺】，量级无法定价，只能判「温和受益 + 站位正确」，不得升级为「纯弹性」。**
2. **基本面质量在改善而非恶化**：存货周转 **290.0 天（缩短 49.9 天、四年最低）**、应收周转 −4 天、OCF/归母 0.68 → **0.80**、OCF/营收 **24.2%（四年最高）**。**旧档触发器 #4「渠道压货/含金量下滑」被半年报证伪。**
3. **利润干净**：非经常性损益 **0.3134 亿元、占归母 2.62%**（半年报原文剥离），横比普冉 0.27% / **兆易 28.8%** / 聚辰 82.2%——**支持倍数取框架上沿的关键证据**（A2 的 2.46% 为半年报前推算，取 A1 的 2.62%）。

**AI 定性（`x-ai` 总裁定）：间接受益已在业绩层，直接受益全在产品层。** 「AI 虹吸 HBM 产能 → 通用 DRAM 缺口 → 合约价上行」由半年报**自己归因**并已量化为 11.98 亿元归母【真敏感·业绩层】；NOR 进 AI 服务器/光模块【真敏感但金额与客户全【缺】】；端侧 AI 计算芯片、3D DRAM、AI MCU、AI 研发提效【蹭概念】。**未兑现概念一律未进入 §9 的 owner earnings 基础**（逐维打标见 [thesis.md §7](thesis.md)）。

**一句话**：愿不愿意为一门**正常化归母 12.0 亿元**（base）的周期生意付 **437.73 亿元**（H）／**682.93 亿元**（A+H）——买的不是「业绩爆发」，而是一道「26Q2 那 53.86% 的存储毛利率里有多少是 AI 让渡的租金」的算术题；**而公司自己的答案写在分部数据里：唯一毛利率下滑的那个分部，恰恰是它最想讲的车规故事。**

### 为何从 exclude 上调到 watch（正面回答）

**上调依据不是「倍数压缩」。** PE-TTM 从 144.83× 压到 50.98× 的 −65% 中，**利润上升贡献 75.8%、股价下跌只贡献 24.2%**——**周期顶的低 PE 是估值陷阱，不是便宜；本档不因此上调评级。** 真正的四条依据：

1. **旧档 `exclude_reason` 的事实基础已部分不成立，不得原样搬运**：①「PE-TTM 144.83×」现为 50.98×（A）/ 49.82×（A+H）/ **31.94×（H）**；②「一致预期 ~8 亿 / 高 6 倍」现为 2027 **15.01 亿**（+88%）；③ 旧档最锋利的一刀「研报 PE 12-14X 与实时 PE-TTM 144.83x 直接矛盾」**已经钝了**——若 2027 真达 50 亿，A 口径隐含 14.0×、H 口径 8.8×，**算术上自洽**。**证伪落点须转移**为「**50 亿这个分子无任何机构背书，是最激进单家（申万宏源 2028 约 29.94 亿）的 1.67 倍、一致预期的 3.3 倍**」+「**周期顶的低 PE 是陷阱**」。
2. **口径切 H 后安全边际的绝对水平进入 watch 区间**：−71.9%（**H 口径**）vs 兆易 −82.7%（**A+H 合并口径**）watch、
   江波龙 −87.1%（**A 股口径**）exclude、普冉 −92.7%（**A 股口径**）exclude。
   > ⚠️ **四者口径不同，不可直接排名。** 同口径对照：**君正按 A+H 合并为 −82.0%，与兆易 −82.7% 基本打平**——
   > 「最不负」的 10.1pct 领先**全部来自 AH 折价 37.36% 的口径红利，非质地差异**，折价随纳入港股通收敛即消失

4. **题材即主业**，不触发「低质地非科技不建档」gating。

**因为价格，不因为生意。** 三档内在价值 10.84 / 29.82 / 54.22 港元**全部低于 H 股收盘价 98.90 港元**——当前**不存在任何可参与的价格区间**。买点 ≤19.43 港元距现价 −80.4%。**诚实标注：实操上等价于「不设买点、只保留观察」，不粉饰为「接近买点」。**另有三项负向变量在闭合前不支持更高评级：实控人方周期顶集中套现、并购弹药到位（§11 风险 3），以及存储分部内收入拆分从未披露致 NOR 站位**量级无法定价**（[sources.md §12.3](sources.md)）。

4. **有明显更好的机会？** 需在组合层比较；单档判断是**当前无需动用资金**。
