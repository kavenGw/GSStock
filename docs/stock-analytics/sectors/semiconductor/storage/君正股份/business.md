## §1 能力圈与本次更新

能力圈处于边界：能理解fabless设计、利基存储与车规认证带来的切换成本，但无法可靠预测多年存储价格。公司以ISSI存储、计算芯片及模拟互联获利；本次由2026三季报触发，重点核利润、现金和旧见顶假设。过去并购形成的商誉风险、车规客户结构与TAM基线沿用，不把短期涨价等同宽护城河。

关键假设是结构性规模提升能否延续、利润中枢能否高于旧基线、营运资本是否可回收、现金能否有效配置。三条主要损失路径为价格/毛利回落、库存与应收占用、并购损耗资金。公司旧称北京君正，自2026-08-13改简称。

> **【重大证伪】护城河覆盖的收入盘子只有旧档估算的四分之一。** 旧档记「车规相关营收 **7–9 亿美元（≈50–65 亿元）**，行业 BOM 拆解估算【软】」；招股书官方口径 **2025 年汽车应用收入 = 15.885 亿元 ≈ 2.2 亿美元**，**高估 3.2–4.1 倍**。**且汽车占比在本轮上行周期中不升反降**（35.6% → 35.4% → 33.5% → 33.0%），增量主要来自消费（计算芯片）与工业医疗。
> **含义**：护城河（车规切换成本）覆盖的收入盘子**只有 15.9 亿元（33.5%）**，其中真正「利基里的利基」（车规存储）13.4 亿元。**用车规护城河为 437.73 亿元（H 口径）／682.93 亿元（A+H）的市值背书，杠杆比旧档判断的还要弱得多。**

**跑道长度总判**：**SAM 看似不小，但护城河保护的只是车规这一薄切片，且该切片占比在收缩；市场规模不构成估值上修理由。** 增量只剩三条更慢的路径：① ASP（涨价，强周期、非永续）；② 车规/工业渗透深化（但占比在降）；③ NOR 品类结构上移（512Mb/1Gb，**但收入拆分【缺】，量级无法定价**）。

**邻接品类（`storage-nor-flash` lens 必查项）**：公司**无 AMOLED 驱动 NOR 敞口**（该段是普冉/兆易的地盘）；**2D NAND 仍在布局阶段**（半年报：「针对汽车、工业等领域对 2D NAND 不断增长的需求，公司加大对 2D NAND 的产品研发与资源布局」，无收入口径）；**EEPROM / DDR5 SPD 非君正主战场**（该链条对应聚辰股份，其 26H1 营收仅 +4.71%、扣非 −47.30%，是「EEPROM 这条线没有行业 β」的直接反例）。

### 3.3 增长质量与口径修正

应收12.3173亿，原始应收/前三季收入17.34%，不能直接与H1 23.6%比“改善”。统一为应收/[累计收入×12/月数]后，本期13.01%、H1约11.80%、2025Q3 10.23%，显示资金占用增加。旧28%阈值不可直接套Q3，后续监控见§11。

存货35.9943亿，年初29.7465亿、H1 31.4481亿；统一360天制周转=平均年初期末存货/累计成本×270=297.75天，H1同制288.44天、去年同期333.81天。环比略慢而同比改善，两面同时保留；旧约290天不作为精确可比基数。

合同负债年初1.0961→H1 0.62534→Q3 0.61577亿，连续两期下降触发旧M5a；环比仅−1.53%，公司解释预收转收入，不能单凭该项判断需求崩塌。去年同期0.72042亿，季节性不足以自动排除风险。

累计OCF/归母从去年同期199.56%降至72.48%，但OCF/营收从14.85%升至26.70%；单季OCF/营收从6.56%升至29.80%。利润跑得更快及营运资本占用均可能参与，不能只看净现比定性利润质量恶化。

### 3.4 资产负债与一次性项目

资产192.4997亿、归母权益174.8443亿、负债17.1892亿，负债率8.93%。现金等价物70.7511亿、交易性金融资产14.9041亿，扣租赁及一年内到期债务0.1350亿后85.5202亿；股票/理财不全是无风险现金。货币资金71.5934亿比现金等价物多0.8424亿，差额不默认自由现金。无短期/长期借款；收入下降30%的静态压力下，账面流动资源远高于现有有息债务，偿债安全较强，但不能保证库存及商誉价值不损失。

商誉30.0778亿未变，占资产15.63%，占比下降来自分母扩大，不是减值风险消失。季度未更新减值测试参数。资产减值0.9487亿（+68.09%），包含存货及开发支出，未拆项，不机械加回正常利润。累计非经常损益0.2131亿，占归母0.81%；Q3为−0.1003亿，解释扣非高于归母。非经常政府补助0.0288亿、金融投资项0.2371亿；其他收益0.0701亿不是同一科目。利息收入0.6871亿、财务费用−0.3356亿，汇兑未单列，不能把财务费用全当汇兑。

购建长期资产现金2.4163亿，OCF减该现金支出=16.5455亿，是粗FCF代理；维持性capex未拆，不能当精确owner earnings。投资支付37.0339亿含理财，不全是capex；办公楼意向金也不是并购。回购1.5001亿已完成、不注销。H股无完整年度派息记录，0.15元历史A股派息仅作未来同股派息代理，参考0.23%，不写为H实际股息率；自由现金足以覆盖历史分红规模，但未来分红取决于决策，须监控削减公告。

## §4 全球竞争力

**官方口径（招股书 2026-08-17 原文，2025 年收入口径，弗若斯特沙利文）**：

> - **利基型 DRAM：全球第七**，总部位于中国大陆的公司中**第二**
> - **SRAM：全球第二**，中国大陆公司中**第一**
> - **NOR Flash：全球第七**，中国大陆公司中**第三**
> - **IP-Cam SoC：全球第二**

**必须披露的口径冲突与降级**：

| 旧档表述 | 本轮裁决 |
|---|---|
| 利基 DRAM 全球 #6-7 / SRAM #2 / NOR #7 | **✅ 与招股书一致，证实** |
| **「车规 SRAM #1 / 利基 DRAM 车规 #4 / NOR 车规 #4」** | **⬇ 在 2026-08-17 招股书全文交叉检索 0 命中 → 降级为【未核到】，本档不得当硬证据引用** |
| **「SRAM 全球份额 23.9%」** | **⚠ 亦未在本次招股书正文命中【软】，且与第三方口径冲突** —— 第三方给的 SRAM 第一名 Infineon（含 Cypress）仅 **14.7%**、Renesas 12.8%、CR3 约 80%。**若 ISSI 真有 23.9%，它应该是第一而不是第二——两个口径不可能同时对。** 最可能的解释是招股书统计的是某个细分子市场（如异步/利基 SRAM，不含 MCU 内嵌与网络用高速 SRAM）。**本档不作裁决，但引用时必须标口径，且 2026 年是否被侵蚀无任何可比数据【缺】。** |

**竞争力的两侧**：
- **强的一侧**：ISSI 在车规利基存储是全球细分玩家，25 年 AEC-Q100 全谱积累（IS25LP/IS25WP 系列全线 AEC-Q100、−40~125°C，512Mb 与 1Gb 3.3V 车规 NOR 已在送样）；博世/大陆/电装/法雷奥等 Tier1 design-win【软·媒体转述，非招股书直接点名】。
- **弱的一侧**：**这与三星/美光的主流 DRAM / HBM / 高带宽 LPDDR5 竞争力不在一个量级**——竞争力是「利基里的强」，不是「行业里的强」。公司在高带宽 LPDDR5 / 3D DRAM 上落后（**3D DRAM 因 DRAM 产能紧张投片延后**，与 2026-05-26 IR 口径一致、延迟状态未改善），吃不到高算力域控 BOM。
- **国产替代侧的时限警告（本轮新证据，方向对君正有利）**：长鑫存储 LPDDR5 已获车规认证、月产能 29–30 万片，但**其车规/工业级产品仍在送样阶段，高温老化测试通过率约 80%、低于国际水平 98%**；且长鑫自有品牌 DDR4 自 2024 年底已停产、2026 计划彻底停产 DDR4【软】。→ **国产替代对 ISSI 车规位置的实质威胁在 2026 年内尚未形成**；**但这是一条时限警告——高温老化通过率是工程问题不是原理问题，车规利基 DRAM 的国产供给会在 2–3 年内出现。**

**地域与地缘敞口**：境外收入占比 **83.5%（26Q1）**（美国 8.4% / 中国台湾 7.5% / 日本 3.3% / 中国大陆 16.5%）；**境外资产 76.04 亿元，占净资产 55.90%**（半年报「是否存在重大减值风险：否」）。**对美直接销售不足总收入 2%**（招股书原文，因该部分产品主要由中国大陆晶圆厂生产）。

**代工结构（旧档表述被部分证伪，`storage-nor-flash` lens「代工依赖」必查项）**：
- **招股书全文 0 次出现「台积电」或「力积电」** → 旧档「代工重度依赖台积电/力积电」**无背书，降级为【软/未核到】**。
- 招股书原文（制裁及出口管制章节）：「于往绩记录期间，我们的常规晶圆代工安排**包括采购实体清单上的晶圆厂所制造的晶圆**」（法律顾问确认仅交付设计文件、不涉 EAR，无重大制裁风险）；关税章节确认代工是「**中国大陆 + 台湾地区 + 其他地区**」的多元结构。
- **【新硬证据】华虹无锡**：公告 2026-060——**2026-08-14 ISSI 向华虹半导体制造（无锡）有限公司出具《保证函》**，为 ISSI 开曼台湾分公司在华虹无锡**委托加工生产产品**的货款提供担保。→ 旧档「新增 3 家代工厂无官方源【软】」中**至少华虹无锡这一家获得公告级硬证据**，且是台湾分公司下单大陆产线（**产能与地缘双重腾挪**）。
- **仍【缺】**：君正的完整晶圆代工厂名单、各厂产能占比、NOR/DRAM 代工报价涨幅。ISSI serial NOR 为 **50nm 高性能工艺**【软·厂商发布稿】。

## §5 核心优势 / 护城河

**类型：切换成本（车规/工业利基存储）。强度：窄。趋势：稳定，但出现两条向下的力。**

**机制（真护城河的部分）**：车规存储 design-in 需走 PPAP（生产件批准程序），单颗切换平均 **18–24 个月**、**$50–150 万**认证成本，**10–15 年车型生命周期**；二代车型倾向沿用上代已验证 BOM → 正向滚雪球。**这是三家可比里唯一的「切换成本型」护城河**——兆易的天花板是长鑫的代工配额（护城河不在自己手里），普冉压在二线设计厂扎堆的中小容量 NOR 红海段。**这也是本档允许倍数取框架上沿、并把车规溢价体现在分子中枢上的唯一依据**（[valuation.md §9.2](valuation.md)）。

**为什么强度只判「窄」——四条**：
1. **覆盖面被官方口径证伪缩小**：护城河只覆盖车规薄切片（**15.885 亿元 / 33.5%，且占比逐年降**），不覆盖占营收大头的利基 DRAM commodity 段。
2. **切换成本 ≠ 锁价权**：IR 20260526 原话海外「**不再纯长协**」「保证价格一定弹性」——design-in 仍在，但**锁价权在弱化，客户在反向博弈**；KGD 缺货导致计算芯片**被动**调价（成本推动而非定价权）。**本轮无任何缓解证据。**
3. **护城河是并购来的，不是内生的**：30.0778 亿元商誉。buffett 框架对「高溢价并购形成的护城河」**打折而非加价**。
4. **本轮最赚钱的两条腿都不是护城河**：计算芯片 61.06% 毛利率来自 KGD 缺货提价 + 低价库存（一次性）；SRAM 需求来自「DRAM 严重缺货 → 客户以 HyperRAM/OctalRAM 替代 DRAM」（半年报原文，**缺货缓解可能削弱替代需求，设计导入留存程度未量化**）。**真正体现车规护城河的模拟互联分部，是唯一毛利率下滑（−1.28pct）、收入只增 10.59% 的分部。**

**趋势判断中必须写出的根部级长期反驳（旧档完全未涉及）**：
> **车规域控制器架构演进正在从根部侵蚀分立利基存储的单车用量。** 汽车电子架构正从「分布式 ECU + 小容量分立存储（SRAM/NOR）」向「域控制器 + 大容量池化 DRAM/LPDDR」演进，**2025 年车规级 LPDDR5 出货同比跳增 85%，原因正是 Tier-1 在域控制器里用池化 DRAM 替代分立 NOR**【软·第三方】。这条对君正的护城河叙事是**根部级的反驳**——它不攻击切换成本本身，而是让需要被切换的那颗芯片消失。**且君正在高带宽 LPDDR5 上恰恰是落后方（3D DRAM 投片延后）。**

**重评旧档「窄但真实」的判断：维持「窄但真实」，但覆盖面须显著下修，且新增一条长期结构性反驳。** 护城河不足以把 commodity 主体重估为 franchise，**更不能用来稀释「贵」**（[index.md §10](index.md)）。

> 「真正的 franchise（如 See's Candies）从不需要『涨价周期』才有超额毛利——它每年都有。」君正的模拟互联分部（最像 franchise 的那条腿）在这一轮涨价里毛利率是**下降**的，这本身就是判「窄」的最好证据。
> 附注：管理层 2026-05-26 IR 的「超额毛利率」表述，**在 2026 半年报全文未再出现**；半年报反而把毛利率下降列为风险第 (4) 条：「如未来需求下降、供应加大或市场竞争加剧，将可能出现产品毛利率下降的风险」。
