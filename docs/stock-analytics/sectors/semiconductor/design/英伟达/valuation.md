# 英伟达（NVDA）— §9 估值（场景加权）＋ 相对旧档变化清单

## §9 估值

### 9.1 方法与口径纪律声明

**主锚**：**2026-08-27 美东收盘 $227.98 / 股本 24.147B 股 / 市值 $5,505.03B**（价×股本自洽偏差 0.00%，已跑 quote_guard 断言，exit 0）。币种全程 **USD**，美股单一上市，无跨币种折算问题。

**owner earnings 口径（关键，且与兄弟档有一处刻意差异）**：

- **一律用 non-GAAP 净利/EPS**，不用 GAAP。理由是【硬】的：本季 GAAP 其他收益里含**股权证券投资净收益 Q2 $7.771B、H1 $23.707B**，分别占 GAAP 净利的 **13.0%** 与 **20.1%**。这既非经营性，又与被投企业估值（进而与 AI 叙事本身）高度同向，是典型的**顺周期虚增**。**这也是本季 GAAP EPS $2.46 反超 non-GAAP EPS $2.22 这一罕见倒挂的全部原因**——non-GAAP 已把它剔掉。若不剔，等于把「投出去的钱涨价」当成「卖芯片赚的钱」。
- 补充一层：这批持股中 **$36.9B 处于短期禁售期**（其中 $5.0B 锁至 2027 年 12 月），**浮盈当期无法变现**。
- **不照搬 [AMD 档](../2026-08-05-AMD-buffett分析.md) 的 ×0.83 系数**。AMD 档用 `owner earnings = 正常化 non-GAAP EPS × 0.83` 把股权激励计回股东成本；**NVDA 不能这么做，会重复扣除**——NVDA 自 FY27Q1 起 **non-GAAP 已不再剔除 SBC 且历史已重述**，SBC 占营收仅 **2.11%**（Q2 $2.027B）、H1 2.22%。即 NVDA 的 non-GAAP EPS 本身已经含了这笔股东成本，直接作 owner earnings 基数即可。

**不做 SOTP 的理由（显式声明）**：权益法投资（对「基础设施融资方」）仅 **$3.3B**，占市值 0.06%，不构成「重要联营/合营」。资产负债表上另有可交易股权证券 $42.783B 与非可交易证券 $51.157B（Note 6 口径非上市股权账面 $47.898B），合计近 $99B 的真实资产**本档不作正向 SOTP 加计**，理由三条：① 其中 $36.9B 禁售、无法变现；② 被投对象与本档正在估值的同一轮 AI 周期高度同向，单独加计等于把同一个论点算两遍；③ 保守起见接受这个**不对称**——下跌时它会通过公允价值变动打击报表（H1 已贡献 20.1% 的利润），上涨时本档不给它信用。

**禁用清单（逐条声明）**：

| 禁用项 | 理由 |
|---|---|
| **PEG** | 分母是单年约 70% 的超常增速，PEG 隐含「该增速可持续」，本股显然不可持续。第三方给的 0.38–0.39、自算 0.27 在本股上**信息含量接近零**，本档只在 §9.5 作「市场未按永续高增定价」的旁证提及一次，不作估值论据。 |
| **管理层 $3–4T TAM** | 利益相关方对自身产品的 TAM 自估，且与第三方（BofA 2030 年 $1.7T）口径差 2 倍以上。**不作估值输入。** |
| **把 $1T 可见度当 backlog** | 公司不披露 RPO/backlog；该数字经交叉验证 ≈ FY27+FY28 指引本身（FY27E 约 $400B + FY28E 约 $690B），**不是指引之外的增量**。 |
| **「目标份额 × TAM」反推**（与 AMD 档同纪律） | TAM 两口径差一个数量级，反推出的营收无判别力。 |
| **对 Street FY2028 共识再施加系统性折价** | **这是本档与 AMD 档的第二处刻意差异**，见 9.2。 |

### 9.2 FY2028 盈利分母的分歧：建模进三情景，不摊成宽买点带

**这是本轮估值最关键的一步。** AMD 档的做法是「对卖方一致预期系统性折价 17%（base）/42%（bear）」——**本档不能照抄**，原因是 NVDA 的 FY2028 一致预期本身是**财报前口径**：

| 口径 | FY2027 营收 / non-GAAP EPS | FY2028 营收 / non-GAAP EPS | forward PE |
|---|---|---|---|
| 卖方一致（stockanalysis，34 位分析师，"as of Aug 27, 2026"） | $409.0B / **$9.27** | 【缺·付费墙】 | **24.6×**（FY27） |
| 卖方一致（Yahoo，FY27 EPS 49 位 / FY28 EPS 51 位） | $397.01B / **$9.05** | $573.64B / **$13.13** | **25.2×**（FY27）／17.4×（FY28） |
| 管理层 +70% 指引推算（A1 自算） | — | 约 $688B / **$15.82** | 14.4×（FY28） |
| A1 自算（假设见其 §1.4） | 约 $404.6B / $9.13 | $688B / $15.82 | 25.0× / 14.4× |

- **FY2027 无分歧**：A1 自算 $9.13、A3 自算 $9.25 与一致预期 $9.05–9.27 收敛在 1.5% 以内。**直接用一致预期作锚，不额外折价。** 现价对应 forward PE **24.6×–25.2×**（227.98 ÷ 9.27 = 24.59；227.98 ÷ 9.05 = 25.19）。
- **FY2028 的 16–21% 差距不是乐观 vs 悲观，是「共识尚未更新」**：管理层 2026-08-26 才给出约 +70%（隐含约 $690B），Yahoo 共识 $573.64B 对应 +44.49%；第三方独立报道证实 Street 数为 **$573.5B**，与 Yahoo 吻合到 0.02%。**因此对 $13.13 再打折是双重折价**——它已经天然低于指引 17%。

**正确做法：把分歧建模进三情景的分母，而不是摊成一条宽买点带。**

| 情景 | 核心逻辑 | FY2028 non-GAAP EPS | FY2028 净利 | 正常化保留率 | 正常化 owner earnings | 倍数 | 每股内在价值 | 概率 |

| **base** | FY2028 落在 Street $13.13 与管理层推算 $15.82 之间的 **$14.20**（取值＝$13.13 + 40% × $2.69 的缺口）。**取值理由**：指引是 supply-constrained 口径、管理层对自己能出多少货有可见度，故缺口大部分应收敛；但保留 60% 缺口不认，对应两条具体保留——(i) CFO 明说内存涨价「headed even higher into next year」，72–73% 稳态本身已假设转嫁成功；(ii) 无 RPO/backlog 背书，指引仍是未经审计的前瞻陈述。此后 capex 转入更新周期、份额自 70% 降至 60–65%、盈利保留 70% | **$14.20** | $342.9B | **70%** | **$240.0B** | **20×** | **$199** | **45%** |

**股本口径**：三档均用 **24.147B 股**（当前在外流通股），**不给未来回购任何减股信用**。这对分子保守（FY28 实际加权股数大概率低于此），也使每股价值与今天的股本口径直接可比。

**取整说明（可复现性）**：精算分别为 $69.28 / $198.78 / $316.39，展示取整至 $69 / $199 / $316（漂移 <0.2%），加权按取整档计算。

**Σ 概率自检**：30% + 45% + 25% = **100%** ✅

**期望内在价值** = $69 × 0.30 + $199 × 0.45 + $316 × 0.25
= $20.70 + $89.55 + $79.00 = **$189.25 ≈ $189 / 股**

对应市值 = $189 × 24.147B = **$4,563.8B ≈ $4.56T**（bear / base / bull 分别约 $1.67T / $4.81T / $7.63T）。

#### 9.3.1 bull 封顶四条硬纪律——逐条落实说明

| 纪律 | 本档如何落实 |
|---|---|
| **① bull 每股价值 = bull 盈利 × 不高于 base 的倍数，绝对禁止倍数扩张** | bull 与 base **同为 20×**。bull 的全部上修落在**分母**（$240.0B → $382.0B，+59%），倍数一格未动。若 bull 用 25× 就会得到 $395/股——本档拒绝这个数字，因为它是叙事定价而非生意定价。 |
| **② bull 营收峰值不得超过第三方 TAM 口径的 50%** | bull 的 FY2028 营收即管理层指引推算的约 **$688B**，占 BofA 2030 年 TAM $1.7T 的 **40.5%**；bull 的 FY2029+ 正常化只假设盈利**保持**而非营收再上台阶，隐含营收峰值 ≤ 约 **$750B ＝ TAM 的 44%**，**低于 50% 上限**。 |
| **③ bull 不得同时使用「TAM 巨大」与「份额稳固」** | 本档 bull 的表述是：**TAM 继续扩张，而 NVDA 份额继续从约 70% 向 60% 侵蚀，两者相抵使营收在约 $690–750B 形成平台、盈利得以保持**。**没有**用「TAM 巨大」，也**没有**用「份额稳固」——用的是两者互相挤压后的净结果。 |
| **④ bull 权重 ≤ 30%** | 取 **25%**，低于上限。门控依据见下表。 |

**成长持续性证据包三要素门控（bull 赋权依据）**：

| 要素 | 硬度 | 依据 |
|---|---|---|
| (a) 扩产/产能锁定确定性 | **【硬】** ✅ | 供应与产能承诺单季 $119B → **$279B（+134%）**，10-Q Note 10 经审阅，**是公司自掏腰包的下注**，比任何口头可见度高一个证据等级。分年：FY27 剩余 $92B / FY28 $87B / FY29 $88B。上游同步售罄（memory 三家 2027 产能售罄、TSMC CoWoS 2027 前有效售罄）。 |
| (b) 客户 capex 能见度 | **【软】** ⚠️ | **无任何审计级在手订单（NVDA 不披露 RPO/backlog）【缺】**。可用的只有客户自身 capex 指引与第三方汇总，且 2027 年口径分歧显著（见 9.6）。唯一具名量化订单是电话会转述的「AWS 追加部署 200 万颗 GPU 至 FY2029 Q2」【软·AWS 未单独公告】。 |
| (c) TAM 跑道 | **【软·且偏短】** ⚠️ | 按最保守的第三方口径，FY2028 营收 $688B 已占 BofA 2030 TAM 的 **40.5%**；按管理层 $3–4T 口径则仅 17–23%，**但该口径已被本档禁用**。**保守口径下跑道只剩约 60%**，且与「份额已从约 90% 降到约 70%」叠加后构成天然天花板。 |

> **门控结论：一硬 + 两软 → bull 权重 25%**，低于 30% 上限。
> **与 AMD 档的横向可比说明**：AMD 档门控结论是「一项半硬、两项软」，bull 封顶 25%。NVDA 的 (a) **明显强于** AMD（AMD 的产能锁定无任何量化披露【缺】，NVDA 有 $279B 硬数字），但 NVDA 的 (c) **明显弱于** AMD 的判定方式——AMD 因 TAM 两口径差一个数量级而直接判「不可用」，NVDA 则有一个可用的保守口径，而该口径给出的答案是**跑道偏短**。两相抵消，**两档同落 25%，但落点的构成完全不同**。

**base 是否被增长拔高的交叉验证**：base 正常化 owner earnings $240.0B 对应 **TTM 剔浮盈净利 $167.27B 的 1.43 倍**。即 base 假设的是「从今天的干净利润再增长 43% 后永久停住」——**不是把 FY2028 的顶部当常态**（FY2028 净利 $342.9B 被打到 70%）。红线「拒绝用周期顶利润定价」逐条通过：三档正常化盈利 $139.4B / $240.0B / $382.0B，前两档均**低于** FY2028E 净利，bull 档等于但不超过。

### 9.4 正常化盈利敏感性（估值分歧的真正落点）

把估值分歧显式改写成「FY2028 之后盈利保留多少」的分歧，而不是「该给多少倍」的分歧：

| FY2028 之后正常化盈利（相对管理层口径 FY28E 净利 $382.0B） | 当前市值 $5,505B 对应的隐含正常化 PE |
|---|---|
| 100%（$382.0B，永续） | **14.4×** |
| 70%（$267.4B） | **20.6×** |
| 50%（$191.0B） | **28.8×** |
| 30%（$114.6B） | **48.0×** |

> **这张表就是本股的估值全貌。** 当前价对应：「FY2028 盈利只回撤 30% 且永久保持」＝ 20.6×（合理偏贵）；「腰斩」＝ 28.8×（明显贵）；「回撤 70%」＝ 48.0×（泡沫）。
> **风险不在倍数，在 FY2028 之后的盈利基数。**

### 9.5 安全边际

| 对照 | 安全边际 = (期望内在价值 − 现价) / 现价 |
|---|---|
| **收盘 $227.98（主锚）** | **(189 − 227.98) / 227.98 = −17.1%** |

**诚实面对「贵」的三条，不用护城河稀释**：

1. **−17.1% 是「贵」，不是「严重高估」**——现价是 base 内在价值 $199 的 **114.6%**。要达到 Buffett 的 30% 折价需回撤到 $139。
2. **bull 档单独压力测试（红线要求，但本股结论与兄弟档相反，必须诚实写出）**：bull $316 对现价 $227.98 是 **+38.6%**。**即现价并未贵过最乐观情景。** 这与 [AMD 档](../2026-08-05-AMD-buffett分析.md)（bull $310 仍较现价低 34.4%）、寒武纪档、海光档（bull 均低于现价）**结论相反**。不能把本档写成「贵过 bull」——那是抄兄弟档的措辞而不是算本股的数字。本股正确的表述是：**现价落在 base 与 bull 之间，无安全边际，但不构成泡沫溢价。**
3. **期望内在价值的自我校准**：$189 ÷ TTM 剔浮盈 EPS $6.86 = **27.6×** TTM PE（现价对应 33.2×）；÷ FY2027 一致预期 EPS $9.27 = **20.4×** forward PE（现价对应 24.6×）。即本档并非用苛刻倍数硬压——它给出的期望值仍对应一个**成长股档位**的倍数，只是比市价低 17%。
   - 旁证（**仅此一处提及，不作论据**）：PEG 第三方口径 0.38–0.39、自算 0.27。它唯一能说明的是**市场并未按永续高增定价**；它不能说明「便宜」，因为分母是单年 70% 的超常增速。

### 9.6 三处口径分歧的处理（不静默择一）

1. **2027 年超大规模厂 capex**：公开锚呈区间分布且**主体范围与发布方各不相同，不可互换**——**四家（Alphabet $284.8B / Amazon $256.5B / Microsoft $207.6B / Meta $185.6B）卖方一致 $934.5B**【软·MarketScreener 汇总，2026-08-05】；**Moody's 按六家口径（另含 Oracle、CoreWeave）预计"接近 $1 万亿"**【软·2026-05-18】；**Goldman $1.01T、JPMorgan 约 $1.0T、Morgan Stanley 约 $1.2T**【软】；**NVIDIA 管理层电话会引述的前五大合计约 $1.3T**【软·2026-08-26】。**取用为 $0.93T–$1.3T 区间**，上沿为管理层口径、下沿为四家卖方一致；**差额不能仅以「多一家」解释——即便六家口径也只到"接近 $1T"，$1.3T 位于所有已公开锚的上沿之外，说明该预测本身更激进。**
   - ⚠️ **与 A3 的冲突**：A3 §B-2 判「$934.5B 与 $1.3T 不自洽，写手不得并列引用」。**本档取 A1 校准补充②的裁定**（主体范围不同、应并列为区间并标口径上沿更激进），因为 A1 逐数溯源到了发布方与主体清单。
2. **GPU 租赁价格**：「B200 三周跌 30% 至 $4.22/GPU-hour」是 **2026-06 中旬读数**、发布于 2026-06-23、来源为加密媒体转载，**已过期且低质，不作任何裁定依据**。当期读数为 Silicon Data 标准化指数 **$5.45/GPU-hour**【软·页面无时戳，日期不可确认】与 AIMultiple 挂牌中位数 **$6.22/GPU-hour**（2026-08-25，区间 $3.75–$16.11）。**当前口径下 B200 租金较 6 月低点反而回升**。若保留该风险项只能作定性：neocloud 供给增加会压缩长尾报价（底价已见 $3.44–3.75），**但无法用当前指数证实「租金正在崩塌」**。
   - ⚠️ **与 A3 的冲突**：A3 §C-1 把 L1 写成「数据冲突」并保留「曾出现 −30% 急跌」。**本档取 A1 裁定**：该读数过期两个月且来源低质，不进正文风险论证。
3. **自研 ASIC 份额**：第三方估算存在两组并存口径——一处给「NVDA 按收入 70–75%、自研合计 15–20%」，另一处给「NVDA 80–85%（2023 年约 92%）」。**机构分歧显著，本档并列引用、不择一。** 另 TrendForce 按**出货台数**口径给 2026 年 ASIC 型 AI 服务器占比 **27.8%**（GPU 型 69.7%），**与收入口径、与旧档的「训练负载」口径三者不可互换**；按「训练负载」口径的 ASIC 份额**未找到任何机构统计【缺】**。

### 四、旧档结论的净变化

> 旧档结论：**「护城河真且仍在加宽，但已被定价为最乐观未来，缺乏安全边际」**。
>
> 本档结论：**前半句降为分层表述（长尾加宽 / 头部被绕开）；后半句的比例基准已完全失效**——旧档所称的「最乐观未来」（Blackwell+Rubin 双年 $1T 营收）已被**单一财年的指引追平**，因此「价格 ≈ 乐观情景 65%」这一比例结论不可平移。**评级维持 watch，但支撑评级的理由从「倍数太贵」换成了「兑现的代价第一次上了报表 + FY2028 之后的盈利基数无锚」。**
