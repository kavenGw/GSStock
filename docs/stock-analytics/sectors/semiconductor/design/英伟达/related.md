### 三条必须写明的口径纪律

1. **安全边际差 40 个百分点，不是标准放松，是分母变了。** 同板块三份近档（AMD −57.0%、寒武纪、海光）的安全边际都在深度负值区，本档只有 −17.1%。原因单一且可验证：**旧档写档时（2026-05-21）NVDA 市值 $3.3–3.5T、TTM PE 50×+，到 2026-08-27 股价 +57~66% 而 TTM GAAP 净利已达 $192.879B、FY2028 指引约 +70%——盈利跑得比股价更快，倍数被压缩到 TTM 28.8×、forward 24.6–25.2×。** 本档的 bull 权重（25%）、bull 倍数（与 base 同为 20×）、bull 营收上限（第三方 TAM 的 50%）全部按同一套门控执行，未对 NVDA 放松任何一条。

2. **bull 权重同为 25%，但门控的构成完全相反。** AMD 的 (a) 产能锁定**无任何量化披露【缺】**、(c) TAM 两口径差一个数量级而**判为不可用**；NVDA 的 (a) 有 $279B 硬数字（自掏腰包，证据等级最高），但 (c) **有一个可用的保守口径，而该口径给出的答案是跑道偏短**（FY2028 营收已占 BofA 2030 TAM 的 40.5%）。**一个是「不知道」，一个是「知道，且不够长」——两者落到同一个权重纯属巧合，不可互相援引。**

3. **兄弟档 note 里被本轮推翻的一处数字。** AMD 档（2026-08-05）与旧 NVDA 平铺档互指的 note 都写着「两档结论同构：护城河真但**已按最乐观未来定价**」。**「已按最乐观未来定价」这半句在 NVDA 侧已被本轮推翻**——旧档所称的最乐观情景（Blackwell + Rubin 双年 $1T 营收）已被**单一财年的指引追平**，且 bull $316 高于现价。AMD 侧该判断本轮**未被推翻**（其 bull 仍低于现价 34%）。**两档不再同构，反向链 note 应在 Phase C 据此更新。**
