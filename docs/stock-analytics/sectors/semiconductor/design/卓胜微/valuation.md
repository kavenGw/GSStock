## §9.1 三档正常化 owner earnings 推导（逐行列出）

### 假设的锚定逻辑（先说方法，再给数）

**营收基数**：不用 TTM 38.32 亿（含 2025 低谷），**不用 2021 峰值 46.34 亿**（一次性 5G 换机潮 + 缺芯涨价）。中性取 **42 亿**（2023–2025 三年均值 41.97 亿）；bear 36 亿（份额继续被侵蚀 + 终端 2027 年再 −1.1%）；bull 50 亿（L-PAMiD 放量 + 份额转移兑现，**已高于 2021 历史峰值**，是一个进取假设）。

**正常化毛利率**：**上限 42%，禁用 ≥46%。** 2023 年及以前的 46%–58% 是 **fabless 时代无折旧包袱**的毛利率，与当前重资产结构**不可比**——**把 2021 年 57.72% 当作正常化的任何估值都是错的**。

**研发费用——本模型最敏感的杠杆，三档必须各自写出费率与理由。**
关键的内在一致性：**三档的研发费率假设全部锚定在同一个刚性绝对额约 8.0 亿元上**（2026H1 研发投入 3.997 亿 × 2 = 7.99 亿；2025 全年 8.67 亿；749 名研发人员）。**费率的差异 100% 来自分母（营收）的差异，而不是靠假设公司会裁研发。** 这是本模型最重要的一条纪律：

| 情景 | 营收 | 研发费率 | 研发绝对额 | 与当前刚性绝对额（≈8.0 亿）对照 |
|---|---|---|---|---|
| bear | 36 亿 | **22%** | 7.92 亿 | ≈ 持平（费率被萎缩的分母被动抬高，与 2025 年 23.26% 的形成机制相同） |
| base | 42 亿 | **20%** | 8.40 亿 | ≈ 持平（略增，覆盖三代平台并行研发） |
| bull | 50 亿 | **16%** | 8.00 亿 | ≈ 持平（纯营收摊薄，不假设裁研发） |

**被拒绝的假设**：15% 费率（2023 年水平）在 42 亿营收下意味着研发绝对额降至 **6.30 亿、较当前减少 21%**——而 2025 年研发人员已减 16.5%（897 → 749 人），**再砍 21% 与「同时啃射频三代平台 + 光互联」的叙事直接冲突**。故 base **不采用 15%**。

**逐档假设理由**：

- **Bear（毛利率 18%）**：当前实际就是 16.39%（26Q2 单季 14.66%）。bear 即「产能利用率不再改善、价格战延续、折旧继续爬升」——毛利率停在 16–20% 区间中值。财务费用 −1.00 亿 = 2026H1 年化值（0.5094×2），即**不假设任何债务优化**。**归母为负 → 利润法在 bear 档失效**，该档改用资产法（§9.3）。
- **Base（毛利率 30%）**：回到 **2025H1 的 28.75%** 水平——即「产线爬坡完成、单位成本回到自制化启动前」，但**不回到 fabless 时代的高毛利**。财务费用 −0.60 亿：假设 34.62 亿募资的理财利息收入上升 + 部分短债偿还，净额由当前年化 1.02 亿改善至 0.60 亿（**这是一条上修假设，须显式披露**）。
- **Bull（毛利率 40%）**：回到 **2024 年的 39.49%**，需要 L-PAMiD 大规模放量 + 产能利用率打满同时兑现。**已是裁定允许的 38–42% 区间上沿附近，禁止再上修。**

**政府补助的敏感度（须披露）**：三档均计入经常性政府补助（公司在半年报中把「其他收益」中约 3,870 万界定为「与正常经营密切相关、持续影响」的经常性补助）。**若按最严口径全额剔除，base 正常化归母由 +1.53 亿降至 +0.85 亿**（营业利润 1.00 × 0.85）。本节采计入口径，但读者应知这一档的脆弱性。

### §9.1.1 bull 毛利率 40% 的隐含条件（一次量化压力测试）

**这一步是为了防止「毛利率回到 2024 年」被当成一句无成本的口号。**

- 稳态年折旧取 **11 亿**（10–12 亿中值）。bull 营收 50 亿、毛利率 40% → 营业成本 30 亿 → **扣除折旧后的非折旧营业成本 = 19 亿 = 营收的 38.0%**。
- 当前实测（2026H1 年化）：营收 36.19 亿、营业成本 30.26 亿，其中固定资产折旧 8.14 亿（**保守地假设全额计入营业成本**——若有部分计入研发费用，则下面这个比率会更高、对 bull 更不利）→ **非折旧营业成本 = 22.12 亿 = 营收的 61.1%**。
- **即 bull 要求「非折旧单位成本 ÷ 售价」从 61.1% 降到 38.0%，相对降幅 38%。** 这需要**ASP 上行 + 稼动率爬满 + 产品结构升级三者同时发生**，而其中稼动率与良率的数值**公司从不披露【缺】**。
- **这是 bull 概率封顶的第二个量化理由**（第一个是 §9.4 的证据包门控）。

## §9.2 倍数：内生倒推，不取同业中位数

**框架**：窄护城河 **8–12×**（本例护城河存疑，见 [business.md §5](business.md)），**bull 倍数不得超 12×**。

**内生倒推方法（不是拍脑袋，也不引用任何同业倍数作为断言）**：

1. **先定股权成本 r。** 判据：无股息（连续两期零分红、上市以来从未回购）、连续 6 个季度亏损、FCF 八期七负累计约 −46.5 亿、有息负债 28.98 亿且**利息保障倍数为负**、存货跌价准备率已达 21.3%、村田在德国 / UPC 的禁令诉讼构成尾部经营中断风险、无控股股东。**取 r = 12%**（`buffett-doc-spec` §3 对「高杠杆 / 无股息 / Altman Z 低」建议 ≥12% 的下限）。
2. **零增长永续下的公允 P/E = 1 / r = 1 / 12% = 8.33×。** 这个数**落在窄护城河框架 8–12× 的下沿**，无需破框架。
3. **引入增长会降低而不是抬高本例的公允倍数。** 带再投资的 Gordon 形式 P/E = (1 − g/ROE) / (r − g)：
   - base（隐含 ROE 1.18%，见 §9.3）：g 只要为正，g/ROE 立刻 >1 → 分子转负，**增长是价值毁灭的**。
   - bull（隐含 ROE 6.37%）、g = 2%（≈ 射频前端 TAM CAGR 2.15%）：P/E = (1 − 2/6.37) / (12% − 2%) = **6.86×**，**低于零增长下的 8.33×**。
   - **结论：当 ROE 低于股权成本时，增长越快毁灭越多。因此本档三档倍数一律取零增长下的 8.33×，不因「成长性」上修——这正是红线 8「看增长但不被增长拔高」的本例形态。**

**三档倍数（全部内生、全部落在框架内）**：

| 情景 | 倍数 | 来源 | 是否破框架 |
|---|---|---|---|
| Bear | — | 正常化归母为负，**利润法在该档不可用** | — |
| Base | **8.33×** | 1 / r（r = 12%），零增长永续 | ✅ 框架内（8–12×），**无「❌破框架」** |
| Bull | **8.33×** | 同上；带 g = 2% 的形式给出更低的 6.86×，未采用（取较高者对 bull 有利） | ✅ 框架内，**且远低于 12× 的上限** |

## §9.3 隐含 ROE、Gordon 校验与「利润法是否整体失效」的判定

### 第一步：三档隐含 ROE

**隐含 ROE = 该档正常化 owner earnings ÷ 归母净资产 129.49 亿**（分母为 2026-06-30 实际值，与价格无关）：

| 情景 | 正常化归母 | **隐含 ROE** | vs 股权成本 12% |
|---|---|---|---|
| Bear | −4.05 亿 | **负** | ❌ 远低于 |
| Base | +1.53 亿 | **1.18%** | ❌ 低 10.8pp |
| Bull | +8.25 亿 | **6.37%** | ❌ 低 5.6pp |

> **三档中没有任何一档的隐含 ROE 达到股权成本。** 这一条本身就已决定了估值的形状：**按 `buffett-doc-spec` §3，「隐含 ROE 低于股权成本 → 公允 PB 在 1× 附近或以下」。**

### 第二步：Gordon 校验（r = 12%，g = 0）

**Gordon 公允 PB = ROE / r**：

| 情景 | 隐含 ROE | **Gordon 公允 PB** | 对应公司价值 |
|---|---|---|---|
| Bear | 负 | **≤ 0** | 利润法给不出正值 |
| Base | 1.18% | **0.098×** | 12.7 亿 |
| Bull | 6.37% | **0.531×** | 68.8 亿 |

### 第三步：失效判定（`buffett-doc-spec` §3 的交叉验证条款）

**判据**：若按框架内倍数算出的 base 每股价值低于「净现金 / 股」，即为利润法整体失效的信号。

- **净现金 = 49.40 亿（货币资金 22.539 + 交易性金融资产 26.861）− 有息负债 28.98 亿 = +20.42 亿**
- **每股净现金 = 20.42 亿 ÷ 574,986,986 股 = 3.5514 元/股**
- **base 利润法价值 = 1.53 亿 × 8.33× = 12.7 亿 → 每股 2.22 元**

> **2.22 元/股 < 3.5514 元/股 → 判据命中。**

**并列的第二、第三条佐证**：
- bear 档正常化归母为负，**利润法在该档根本给不出非负值**（`buffett-doc-spec` 明令 bear 不得给负值）。
- 三档利润法价值（bear N/A / base 12.7 亿 / bull 68.8 亿）**全部低于账面归母净资产 129.49 亿**，其中 base 仅为账面净资产的 **9.8%**。

### 第四步：结论与改锚

> **利润法整体失效。按 `buffett-doc-spec` §3，本档三档改以【资产法】为主锚、【利润法】降为验证。**

**须同时诚实标注的两点**：
1. **本档的倍数并未破框架**——内生倒推的 8.33× 落在窄护城河 8–12× 之内，**无一档需标「❌破框架」**。失效的原因不是倍数不够用，而是**正常化盈利本身太小**：base 1.53 亿的正常化归母，无论乘以框架内的哪个倍数（8× 给 12.2 亿、12× 给 18.4 亿），都低于公司账上趴着的 20.42 亿净现金。
2. **改锚不是为了把数字做大**——恰恰相反，改锚后的结论仍是负安全边际（见 §9.6）。改锚只是承认一个事实：**这家公司当前的价值主要不在它的盈利能力里，而在它的资产负债表里。**

> **第三个可直接读出的角度**：市值 449.18 亿 − 金融资产 49.40 亿（货币资金 22.539 + 交易性金融资产 26.861）= **399.78 亿**，即市场为「94 亿产线 + 品牌 + 客户关系 + 技术平台」支付了 399.78 亿，对应 **81.30 亿账面产能资产的 4.92 倍**。**这个倍数是否合理，就是本档的核心判断题**（§9.4 的分块资产法给出的答案是：bear 0.30× / base 0.60× / bull 1.00×）。
> 本档的处理方式：**不把 PB 分位当作估值输入，只把它当作「市场情绪位置」的参照**；估值主锚是 §9.4 的**分块资产法**（对产能资产逐档给折价），它天然规避了「把 34.62 亿闲置现金按经营资产计价」这个陷阱——净金融资产 20.42 亿在三档中都按 100% 单独计，不参与折价，也不被当成产能。

> ⚠️ **另一处第三方数据陷阱**（写档与后续复盘均须注意）：百度估值接口（akshare `stock_zh_valuation_baidu`）的 PB 分母在半年报披露后可能仍停在 **2025 年末净资产 98.72 亿**，直接取其"最新值"会**高估 PB 约 33%**。腾讯 [46] / 东财 f167 已更新至半年报口径。

## §9.9 本节的诚实声明（红线 4：诚实面对「贵」）

1. **不用「护城河上修」稀释「价格太贵」**：本档已判定护城河**只在 sub-3GHz 成立**，且垂直整合的成本优势**至今无任何报表读数支持**（自产比例最高的模组毛利率反而最低）。
2. **不用「成长空间 / AI 想象空间」稀释估值结论**：bull 增长证据包三要素无一「硬且有利」；光互联收入为 0 且被门控在「首笔可辨认营收披露之后」；AI 对本公司当期是**成本端负变量**。
3. **不用「剔除一次性因素后其实还行」软化结论**：非经常性损益合计仅 **−14.85 万元**，存货跌价被公司**自标「具有可持续性」**。
4. **不回避改锚的难看结论**：利润法失效不是技术性瑕疵，它的经济含义是——**按盈利能力定价，这家公司值不了它的账面净资产**；本档给出的每一分内在价值都是在为资产付钱。
5. **不为了差异化而拔高或压低评级**：三情景算完是什么就是什么，评级由 §9.8 的安全边际算术决定，见 [index.md §10](index.md)。
