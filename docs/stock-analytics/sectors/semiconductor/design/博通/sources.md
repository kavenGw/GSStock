## §12.8 已知局限（方法层）

1. **Q3 10-Q 未出**是本档最大的方法性局限——分部经营利润、Q3 RPO、Q3 债务表三项只能用 Q2 10-Q 或电话会转述替代，已逐条标注。**Q3 10-Q 提交后应做一次差量更新**，重点核对：Q3 RPO 是否较 1,646 亿变动、XPV 担保附注、分部经营利润原文。
2. **三情景的利润率假设（43%/46%/47%）是本档主观性最强的一处**——它建立在「毛利率下行趋势延续、经营杠杆对冲能力递减」这一判断上，若 Q4 实际毛利率高于指引的 73%，三档利润率应上修，期望内在价值随之上调。
3. **本档未对 FY2028 做任何建模**（2,300 亿指引无第三方验证），仅通过 bull 情景的 FY2027 全额兑现间接反映其可信度。若后续出现第三方对 FY28 的验证性预测，bull 的倍数纪律（锁 18×）应重新审视——**但重审的方向应是提高 bull 概率，而非放开倍数**。
4. **市场背离的解释（[thesis.md §8.3](thesis.md)）是假设不是断言**，本档给出四条候选并标注了各自强度，未做单一归因。
