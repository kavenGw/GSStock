## §10 评级决策

### 10.1 评级：**watch**（维持），否决理由从"三重背离"扩容为"四重背离 + 两处旧档证伪"

| 项 | 旧档（2026-08-13） | 本档（2026-09-22） |
|---|---|---|

| PE(TTM) / PB / PS | 211.6x / 26.20x / 36.9x | **189.39x / 23.45x / 33.04x** |
| 期望内在价值 | 519 亿（每股 22.33 元） | **416.58 亿（每股 17.92 元）** |
| 安全边际 | −92.2%（bull 单测 −79.3%） | **−93.0%（bull 单测 −82.3%）** |
| 会计 ROIC | 18.6% | **16.5%（15.4%~17.8%）** |
| 否决理由 | 贵 + 增长质量三重背离 + 卡位被证伪 + 地缘二元 + 供应链不可验证 | 上述全部 **+ "零有息负债"证伪 + 关联依赖加速恶化 + 扩产资金缓冲耗尽 + H2 无任何公开科目可佐证** |

**为何维持 watch 而非降为 exclude**：这是一家真实的国产算力龙头——会计 ROIC 16.5% 优于多数 A 股半导体
设计公司、净现金仍为正、经营杠杆真实兑现、营运效率同口径改善 33%、研发资本化率连降两年至 4.35%、
H1 落在自愿预告上沿。**问题在价格与增长质量，不在生意本身的正当性。** 与寒武纪档同判 watch。

**为何不因"跌了 10.5%"上调**：本轮下跌既非基本面利空驱动（区间内无业绩下修、无处罚、无新减持、无实体
清单变动、无 BIS 新规），也非盈利上修驱动（2026E 一致预期仅 −0.8%）——**它是纯粹的杀估值**，而内在价值
下修另有其因（见 §0 末）。**价格下跌与价值下修同时发生时，折让不会自动变大**；何况 256.00 本身还含一次
未被官方材料证实的题材脉冲。

### 10.2 卖出标准逐项排查（持有者视角）

1. **价格严重高估？** ✅ **是**——256.00 元 vs 期望内在价值每股 17.92 元，**溢价 13.3 倍**；
   即使对最乐观的 bull 每股 45.22 元，仍**溢价 4.7 倍**。明确的减仓信号。
2. **基本面护城河被破坏？** ⚠️ **正在被侵蚀（本轮再添两条）**——毛利率阶梯下行累计 −14.23pct 且**溢价已归零**
   （55.21% vs 寒武纪 55.25%，而寒武纪归母已反超）；运营商主战场 ARM 65.01%；
   **中国移动 AI 超节点集采整体锁给昇腾、海光 DCU 零份额**（关掉的是入口）；x86 授权被订正为
   **按营收 5% 抽成的活租约**而非自有资产。巴菲特"护城河收窄"四信号全部命中。
3. **管理层诚信问题？** ❌ 否——无诉讼、无处罚、无非标意见、无违规担保。
   **但披露克制与系统性非 GAAP 口径引导需持续观察**（"扣股份支付后 +82.30%"被基数效应放大，
   2026Q1 调研只报 +74.86% 而 GAAP 为 +35.82%）。**这是观察项，不是否决项。**
4. **出现明显更好的机会？** ⚠️ 视组合而定——中科曙光 PE 51.21x / PB 5.37，持有海光 27.96%，权益市值
   1,663.71 亿 > 其自身总市值 1,238.82 亿（**折价 25.5%**，较旧档 29.4% 收窄）。**本档未对其独立承做。**

**持有结论**：业务在扩张、质量在打折、价格远脱离基本面——**减仓至观察性头寸**，余下仓位当作对
"政策窗口延续 + DCU 拿到具名入口"两个事件的期权，而非价值持仓。
