## §0 结论摘要

**评级：Keep Watching（观察位，非可参与档）。生意通过 Buffett 八问的七问，第八问「价格是否合理」不通过，且差距不是十几个点而是数倍。**

**先写最不利的一条：分歧不在倍数，在利润。** 卖方 2026E 归母 **59.18–93.12 亿**（26 家，跨度 1.57 倍，**全部 pre-report、无一家看过这份半年报**）。本档按季节性分离法（营收 H1 占比两年偏离仅 0.42pct 可外推；利润偏离 8.46pct 必须改走同比路径，失真源是 25Q4 归母仅 3.917 亿）得 **2026E 扣非 54–63 亿、中枢 58 亿**，落在卖方区间**下沿**。上沿 93.12 亿隐含 H2 归母同比 **+157%**（H1 实际 +5.05%），**算术上不成立，不作 bull 依据**。

- **Bear（35%）46 亿 × 18× → 828 亿 → 114.10 元/股**：存储腿 2028 前后转弱、成熟制程继续退、"商务优惠"固化为不可逆压价。
- **Base（45%）58 亿 × 26× → 1,508 亿 → 207.80 元/股**：**零增长外推**——2026–2030 营收从 488 亿爬到 535 亿的增量被毛利率下移与 18%+ 研发投入吃掉，即 2025 年"10 年首次增收不增利"模式延续。
- **Bull（20%，门控封顶）65 亿 × 34× → 2,210 亿 → 304.54 元/股**：存储 capex 延伸到 2028 + 低国产化品类（离子注入/涂胶显影/量测约 12%）兑现 + 毛利率止跌。
- **绝不取顶部年化**：26H1 扣非年化 = 66.82 亿，**46 < 58 < 65 < 66.82** ✓。
- **期望内在价值 = 0.35×828 + 0.45×1,508 + 0.20×2,210 = 1,410.40 亿元 = 194.35 元/股**（Σ概率 100%，算术自洽）。**安全边际（pre-report）= −72.3%**，市值是期望内在价值的 **3.60 倍**。
- **08-26 盘中已回填（09:44:03，post-report，`quote_guard` 通过、价×股本偏差 0.00%）**：现价 **681.57 元** ／ 市值 **4,946.08 亿元** ／ 安全边际 **−71.48%** ／ 报表 PE-TTM **87.02** ／ 扣非 PE-TTM **90.00** ／ PB **12.20** ／ PS-TTM **11.40** ／ 股息率 **0.1118%**（公式见 [valuation.md 末「价格派生量清单」](valuation.md)）。
- **市场对这份半年报的首日反应已可观测**：08-26 低开 **671.30（−4.15%）**、09:44:03 报 **681.57（−2.69%）**，日内区间 669.01–689.22。**方向与本档判读一致——利润失速被定价**。安全边际由 pre-report 的 **−72.3%** 收窄到 **−71.5%**，**收窄 0.8pct 全部来自价格下跌，内在价值一分未动**；量级不变、评级不变。买点与触发器全部以**绝对价格/绝对指标**表述，不依赖"价格不动"。

**必须并列的正面事实（缺一即失真）**：①**利润质量是 A 股 semicap 里最干净的一份**——扣非/归母 **99.13%**，非经常仅 0.293 亿且公允价值变动是 **−0.205 亿负贡献**；按扣非口径 **92.5×** 比中微 **159.6×** 便宜 42%、比拓荆 **180.8×** 便宜 49%（[valuation.md §9.4](valuation.md)）。②四条领先指标同向转强，**与兄弟档拓荆方向相反**（[thesis.md §6.3](thesis.md)）。③**D2W 混合键合"已实现产业化应用"，进度领先拓荆**（键科 26H1 营收仅 28.34 万元）。

**一句话**：愿不愿意为一门**正常化扣非 58 亿、且未来五年大概率还是 58 亿**的生意付 5,082 亿（08-25 收盘）／ **4,946 亿（08-26 盘中）**——那是 **87.6 倍 ／ 85.3 倍**，是国际 semicap 中枢 48.20 倍的 **1.82 ／ 1.77 倍**，而它的净利率只有人家的四成到五成半。**跌了一天，倍数还是这个量级。**

**卖出标准逐条检查**：① **价格严重高估？** **是**——**以下三个数均为 2026-08-25 收盘 pre-report 口径，08-26 开盘后须按 §0 与 [valuation.md §9.4 / 末尾价格派生量清单](valuation.md) 的同名占位一并重算，本句不单独回填**：安全边际 **−72.3%**、PE 近三年分位 **94.4%**、PB **94.2%**（5 年 PE 分位 73.5% 失真须弃用，判据见 [valuation.md §9.4](valuation.md)）。② **护城河被摧毁？** **否，但在被消耗**——覆盖度与准入壁垒完好，但公司在**两处独立位置**承认价格让步（风险提示"成熟制程设备同质化竞争、产品价格存在下行压力"＋毛利率归因"为部分大批量采购客户提供了一定的商务优惠"）＝**宽度未变、深度在浅**（[business.md §5](business.md)）。③ **管理层诚信问题？** **否**——股份支付仅 991.48 万（归母 0.29%）、研发资本化率**同比降** 0.99pct 至 27.76%（会计在收紧）、非经常仅 0.87%。三项观察项（非红旗）：存货跌价计提比例 0.7370%→**0.5477%**、分红率 10.00% 低于公司自援的 20% 门槛、"累计分红占利润分配总额 100%"是合规口径**不等于高分红**。④ **有明显更好的机会？** 组合层自比；单档判断是**当前无需动用资金**。
