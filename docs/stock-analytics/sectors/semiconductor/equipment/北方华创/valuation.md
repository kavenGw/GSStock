### (2) 三档正常化扣非归母

**顶部年化自检（红线 3）**：26H1 扣非 33.4072 × 2 = **66.82 亿** = 顶部年化。**bear 46 < base 58 < bull 65 < 66.82** ✓ 三档全部低于顶部年化。
### (4) 主动披露：base 与 bull 高于公司历史最高年度扣非

**① 事实（不等读者自己发现）**：公司历史最高年度扣非是 **2024 年的 55.70 亿**（2023 年 35.81 / 2025 年 53.36 / TTM 54.96）。本档三档与它的关系是——
**bear 46 亿低于峰值 17.4%**；**base 58 亿高于峰值 4.1%**（`58/55.70−1`）、并高于 2025 年的 53.36 亿 **8.7%**；**bull 65 亿高于峰值 16.7%**。
即**三档中有两档（base、bull）高于公司历史最高年度扣非**，这一点在此明写。

**② 为何不触发红线 3（"绝不取财报顶部年化"）**：
- **判据一 · 顶部年化对照**：红线 3 禁的是把**财报顶部年化**当常态。本档的顶部年化是 26H1 扣非年化 **66.82 亿**，**base 58 亿比它低 13.2%**、bull 65 亿比它低 2.7%、bear 46 亿低 31.2%——**三档全部低于顶部年化，红线 3 未被触发**。
- **判据二 · 隐含净利率方向（更强的一条）**：2026E 营收中枢 **488 亿** vs **2024 年公司总营收 300.75 亿**（年报重述口径；原披露口径 298.38 亿）＝ **+62.3%**；而 base 扣非 58 亿 vs 2024 扣非 55.70 亿仅 **+4.1%**。⇒ **隐含扣非净利率由 2024 年的 18.52%（55.70/300.75）降到 11.89%（58/488），下移 6.63pct、相对降 35.8%**。**营收涨六成、利润只涨四个点——这在方向上属保守，与"用周期顶利润定价"正相反。**（base 情景自身口径为 535 亿 × 10.8%，净利率更低，结论同向。）
- **判据三 · base 的性质**：**base 不是增长外推，是本档按季节性分离法算出的 2026 当年中枢**（营收 H1 占比两年偏离 0.42pct 可外推 → 488 亿；利润偏离 8.46pct 改走同比路径 → 26H2 扣非 +15% → 全年 58.2 亿）。它属"当年即达到"而非"未来才达到"。

**③ 敏感性：若把 base 压到 55 亿（即不超过 2024 峰值）**

```
bear  46 × 18 =   828.0 亿   （不变）
base  55 × 26 = 1,430.0 亿   （原 58 × 26 = 1,508.0 亿）
bull  65 × 34 = 2,210.0 亿   （不变）
期望内在价值 = 0.35×828.0 + 0.45×1,430.0 + 0.20×2,210.0
             = 289.80 + 643.50 + 442.00
             = 1,375.30 亿元
每股         = 1,375.30 / 7.256892 = 189.52 元
安全边际     = (1,375.30 − 5,082.73) / 5,082.73 = −72.94%
```
对照本档 base=58 的 **1,410.40 亿 / 194.35 元 / −72.25%**：**期望内在价值降 2.49%，安全边际由 −72.25% 走到 −72.94%（恶化 0.69pct）**；买点档位亦不变（base 每股由 207.80 降到 `1,430.0/7.256892 = 197.05` 元，×60% = **118.2 元**，仍落在本档 ≤125 / ≤114 元这一区间内）。
⇒ **量级不变、评级不变（仍为 watch）。**

## §9.3 概率赋权与 bull 增长证据包门控

| 情景 | 概率 | 赋权理由（引 §6/§8 证据） |
|---|---|---|
| **Bear** | **35%** | 引 [thesis.md §8](thesis.md)：**单腿站立**——成熟制程腿半年断 −23.25%、光伏腿公司自述"仍处于周期调整阶段，下游扩产需求整体偏弱，行业竞争持续加剧"，全靠存储腿 +56.43%。DRAM/NAND 是标准品，2028 年国内存储产能集中释放遭遇周期下行 → capex 骤停，而设备收入滞后 → **冲击晚到但更陡**（存货 305 亿、合同负债 53 亿会先后失血）。叠加公司在两处独立位置承认价格让步 |
| **Base** | **45%** | 引 [thesis.md §6.3](thesis.md)：四条领先指标同向转强（合同负债 26Q2 环比 +26.6%、存货周转 526.62→440.42 天、应收 +8.8% << 营收 +24.9%、OCF +37.74 亿），与兄弟档拓荆的"三条同向转弱"方向完全相反；且内生增速 +19.58% 仍在两位数。但**拐点只有一个季度，是"信号"不是"趋势"**，故不足以支撑 base 之上 |
| **Bull** | **20%（门控封顶）** | 见下三要素 |

**bull 增长证据包三要素（`buffett-doc-spec` §3 门控，逐项标【硬/软/缺】）**

| 要素 | 判定 | 证据 |

## §9.7 双面必答（两份命中 lens 的强制回应，估值侧）

**(x-ai) 未兑现的概念不许进 owner earnings 基础。** 四项 AI 直连产品——**混合键合（W2W/D2W）/ 高端 TSV 电镀 / 面板级封装 Descum / 数据中心元器件**——**全部零营收披露**，管理层 2026-05-15 IR 自述"预计 2-3 年后会逐步形成订单并实现销售收入"（= **2028-2029**）。⇒ **bear 与 base 的正常化利润中，这四项贡献严格为 0**；仅在 bull 的 570 亿营收中枢里保留期权，且**期权价值受硬 TAM 约束**：键合设备 Gartner 口径全球 **2029 年仅 10.46 亿美元 ≈ 74.8 亿元 ≈ 北方华创 2025 年营收的 19%**——**全球全拿也不构成第二增长曲线**。（另一口径 Yole 后道封装设备总盘 2025 年 69 → 2030 年 92 亿美元、CAGR 5.8%，与 Gartner 键合 CAGR 24% 的"体感差 4 倍"来自口径边界不同，**不得混用**。）

**(x-ai) AI 叙事是否已被充分定价——是，而且定价用的是一个正在被证伪的增长假设。** PE 近三年 94.4 分位（中位 41.14 的 2.17 倍）、PB 94.2 分位（中位 7.34 的 1.71 倍），而扣非增速处近四年最低。**PEG 视角：92.49× 扣非 PE 对 +5.02% 的扣非增速；即便用市场期待的 25%–30% 中期复合增速，PEG 也在 3.1–3.7。** 本档不使用"AI 想象空间"稀释"贵"——§9.4 的市值反推表把这件事量化成了一个可证伪的净利率命题。

**(x-growth) 高增长是否已被 price-in——是，且 price-in 的是内生增速的两倍。** 报表 +24.90% 里 **5.32pct 是买来的**（芯源微并表增量 8.587 亿），**内生 +19.58%**，为上市以来首次跌破 20%；而市值反推出的要求是扣非做到 105.5 亿（2026E 中枢的 1.82 倍）。**增长再好也要算安全边际——本档算出来是 −72.3%。**

**(x-growth) 扩产是结构性需求支撑还是赌行业景气——公司自己几乎不扩产，它赌的是下游扩产。** 结构性的一半是国产替代（政策与安全驱动，与半导体周期弱相关）——**真实，但空间已过半程**（§9.3c）；周期性的一半是存储扩产——长鑫上海一期 2027 初/二期 2028 初、长存三期 + 后续两厂**都在同一窗口投产**，**DRAM/NAND 是标准品，产能集中释放 = 价格战**，这是 bear 的核心路径。
