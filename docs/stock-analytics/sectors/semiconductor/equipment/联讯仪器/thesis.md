# 联讯仪器 — §6–§8 核心论点与周期

## §6 核心论点：真实成长与客户资本开支周期并存

### 6.1 高速互联测试已形成经营基础

**最强反驳在于设备订单可能前置透支后续需求。** 联讯卖的是验证、制造和测试能力，收入并不直接按存量网络流量持续收费。客户扩产暂停、提高旧机利用率或延后验收，会使设备销售先于终端出货转弱。

正面证据同样明确：官方H1 p17披露65GHz采样示波器、120GBaud时钟恢复、1.6Tbps误码分析及光模块测试仪向多家用户量产供货；10/23经营公告称800G/1.6T核心仪器是当年交付主力，在手订单储备较充足。[S2/S7](sources.md) Q3营收25.1235亿元、扣非13.7221亿元，方向与这些业务进展相符；续跑已取得官方三季报并与用户文件逐字节核对一致。[S1](sources.md)

传导链为：AI数据中心投资→高速光模块/光芯片扩产及速率升级→测试工位和精度要求提高→仪器交付或设备验收→确认收入→收款。每个环节都有时滞，不能把终端增长百分比直接变成联讯订单增长百分比。

收入增长兼有结构性与周期性：技术升级、国产替代和海外客户导入可能抬高穿越周期中枢；同时扩产、备货、验收和费用摊薄也会制造峰值。模型保留前者、压回后者，见[正常化参数桥](valuation.md)。

### 6.2 客户需求有具名证据，不能等同采购份额

H1 p20覆盖客户名单包括中际旭创、新易盛、天孚通信、源杰科技、Lumentum、Coherent、Broadcom等；p31前五大客户收入8.70197亿元、占56.83%。**覆盖名单不是Top5实名对应，也不披露对联讯的下一季订单。**

| 客户或终端 | 可核事实 | 证据等级与传导边界 |
|---|---|---|
| Coherent | FY26 Datacenter & Communications收入52.75亿美元、同比40%；全年购置PPE11.02909亿美元，FY25为4.40836亿美元 | 客户官方年报【硬】，但资本支出涉及多业务，不能全归光模块或联讯设备采购 |
| Lumentum | FY26Q4收入10.063亿美元，下一季FY27Q1收入指引12.25–12.75亿美元 | 官方业绩与指引【硬】，不是向联讯的采购承诺 |
| 中际旭创、新易盛等国内客户 | 公司披露客户覆盖关系 | 覆盖【硬】；本轮未取得对联讯具名采购额/分配份额【缺】 |
| 光模块终端 | 多家机构预测高速模块增长，季度调查显示需求强 | 机构原始预测/调查【硬】，只是终端兑底，非订单锁定 |

来源为[S2/S10–S14](sources.md)。客户增长是必要支撑，却不足以消除集中度风险。下游零部件短缺还可能延缓客户扩产和付款，联讯也可能面对客户同时要求降价与延长账期。

### 6.3 扩产有资金，2029募投尚未成为当前产能

H1 p68–69披露IPO净募资19.070802亿元，累计使用2.062129亿元。五项募投的预计可用日均为**2029/04**：[S2](sources.md)

| 项目 | 计划投资亿元 | H1累计投入亿元 | H1投资进度 |
|---|---:|---:|---:|
| 下一代光通信测试设备 | 5.127922 | 0.487717 | 9.51% |
| 车规芯片测试设备 | 1.988527 | 0.584243 | 29.38% |
| 存储芯片测试设备 | 3.854737 | 0.346670 | 8.99% |
| 数字测试仪器 | 3.040053 | 0.643499 | 21.17% |
| 研发中心及制造基地 | 3.103189 | 尚未投入 | 原表为“－” |

10/23公告称扩充正常、符合预期，证明工作在推进，不等于量化达产率。2026Q3爆发不能归功于五项2029募投全部达产；现有场地效率、外协和产品结构可能解释部分增长，但各自贡献未拆分。

**反驳面**：订单充足可能支持合理再投资，也可能让公司和同业在景气高点同时扩建。未披露设计产能台数、爬坡曲线、对应收入与锁定合同；不能将项目预算乘自设周转率变成确定利润。募投预算还包含研发产业化支出，不能全部当固定资产capex后又与研发费用重复扣减。

### 6.4 技术护城河仍须跨代验证

成熟光互联仪器和功率器件设备已有量产交付，WAT取得批量订单；CPO OE系统通过用户验证并实现收入。存储/HBM仍处验证阶段，国产替代进展应分品类判断。[S2 p17–18](sources.md)

Keysight、Anritsu仍有224G/1.6T具体产品供给，不存在本轮可确认的“海外退出”。公司“全球第二家推出全部核心仪器”是产品组合推出口径，不能推导只有两家竞争者或全球份额第二。国产化可能扩大机会，出口管制也可能约束关键上游器件、客户扩产与海外交付；本轮未取得具体断供或全面自主可控证据。

首台验证与重复购买是不同闸门。现有量产交付支持商业化，然而重复订单比例、验证机转量产机比例、装机台数、服务收入占比均未披露，不能提前认定存在稳定的装机服务年金。

### 6.5 管理层与资本配置：未见诚信否决，继续核结果

H1为容诚标准无保留意见，披露无非经营性资金占用、无违规担保；这些是治理正面基线，不代表所有采购定价均已独立证明公允。[S2 p2/59–64](sources.md)

H1向思诺威和合晶诺的关联采购/服务合计**0.441397亿元**，当期关联销售为零；Q3关联明细未披露。采购不是关联收入循环的证据，也不能写“无关联交易”。应持续检查技术服务成果、价格可比性与采购依赖。[S2 p205–206](sources.md)

与Aehr的中国专利侵权案一审驳回原告请求，但双方上诉及相关专利行政争议仍须跟踪，不能写终局风险已消除。[S2 p61–62/208](sources.md)

管理层诚信暂未发现可核实的一票否决事项；资本配置能力尚缺完整周期记录。创始团队持股与经营责任相联是正面因素，但送转不创造价值，高研发与多品类扩张也不能自动证明每一元留存都有高回报。机构惯性风险在于为追赶热门赛道同时扩多个验证周期很长的品类；目前是需监控的动机风险，尚无证据认定已发生利益输送或失控并购。

## §7 AI与新产品：按兑现阶段逐项判断

| 维度 | 截至本轮可核阶段 | 估值处理与标签 |
|---|---|---|
| 800G/1.6T光模块测试 | 核心仪器量产供货，2026交付主力；未单列AI专属收入 | 属于已有业绩基础，不能声称AI营收占比100%。**【真敏感】**：需求已传到交付和经营 |
| 光芯片老化、KGD、硅光晶圆测试 | 成熟产品出货及客户覆盖增长 | 进入已有主业经营，不额外再加一份AI利润。**【真敏感】**：对应已发生的光互联扩产 |
| CPO/NPO OE芯片KGD | H1已通过用户验证并实现收入，金额未单列 | 不能写零收入，也不能按完整CPO市场虚增利润。**【真敏感】**：已有商业兑现，量级未知 |
| 2.4T/3.2T | 公司称新一代方案满足眼图需求，自研采样保持芯片流片；H2计划向头部用户送样 | 验证、量产订单和独立收入未闭合，不另计增量OE。**【真敏感】**：主业相关的产品研发层 |
| 高速DRAM测试 | ASIC/PE流片、ETS工程验证通过，整机验证中 | 工程验证不能当量产验收；不照搬国际ATE利润。**【真敏感】**：研发/验证层，未计新增盈利 |
| HBM KGD | 客户送样验证推进 | 无规模量产收入证据，不进基准增量利润。**【真敏感】**：有实际研发活动，兑现待证 |
| 光电混合ATE | 初步技术预研、拟启动项目 | 不计当前利润或单独终值。**【蹭概念】**：仅指估值尚未兑现，不断言研发虚假 |
| 功率器件与WAT的AI延伸 | 本体产品/订单真实，AI终端用途比例未拆 | 本体收入可以存在，不能全算AI贡献。**【蹭概念】**：对其AI盈利标签暂缺量化证明 |

产品状态以[S2/S7](sources.md)为依据。公司原文已把高速互联增长归因AI数据中心需求，因此不是泛化“蹭AI”；但本轮未找到“AI挤出海外厂商产能导致联讯涨价”的间接供给证据，不另设该论点。

下一步机会来自速率升级提高测量难度、测试环节向上游延伸和海外导入。反向约束是并行通道和单机效率提高、旧设备升级、不同光电架构路线竞争。终端TAM与增长分歧见[§2](business.md)，在手订单未量化、SAM和份额缺口限制Bull赋权。现价对增长的支付要求见[§9.6](valuation.md)，真实AI暴露本身不足以证明股价便宜。

## §8 周期定位：上行已兑现，持续时间未知

| 正面信号 | 反向信号及局限 |
|---|---|
| 高端仪器量产，Q3收入和扣非大幅增长，毛利率提高 | 净利率和费用摊薄处高位，不能据一年表现判断永久经济特许权 |
| 合同负债由H1的6.4907亿元增至Q3的9.2413亿元，环增42.38% | 预收也有履约义务；无分部、交付期限及取消率，不能等同不可撤销订单总额 |
| Coherent等客户扩产、Lumentum指引、机构高速光互联预测向上 | 客户capex可能前置，设备订单领先终端，利用率提高可削弱新增设备弹性 |
| 高增长和高附加值产品结构改善支持中枢上移 | Q3现金/归母67.61%低于去年同季81.93%，应收和备货需占资 |

裁定为**结构性成长叠加设备资本开支上行，尚不能定位确定见顶时点**。合同负债与收入当前同向增加，未出现本轮可证实的订单先行崩塌；也无法据缺少总订单数据断言未来数季增长已锁定。本土存储、晶圆厂招标和稼动率在本股可及品类上的量化映射不足，不拿泛半导体景气指数替代本股客户订单。

后验采用组合指标：连续季度合同负债下行并伴客户指引转弱、同季毛利和收入减速、应收/发出商品账龄恶化，再下修正常化能力。新代际的H2送样窗和募投2029/04窗分别处理；尚未到期不能提前判违约。[监控与行动](index.md)
