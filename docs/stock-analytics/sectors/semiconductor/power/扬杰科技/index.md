## 10 评级决策

**相对旧档（2026-06-25）一句话**：价格 132.99 → **101.69 元**（−23.5%）、PE/PB 52.72/7.50 → **38.69/5.51**、期望内在价值 84.4 → **72.81 元**、安全边际 −36.5% → **−28.4%**、bull 压测 −8.6% → **+5.2%**、买点 62 → **52.30 元**、评级 **watch 不翻转**。逐条对账（32 项，旧 → 新 → 依据）见 [valuation.md 相对旧档变化清单](valuation.md)。

**为什么利润在上修、内在价值反而下调（84.4 → 72.81）？** 因为**倍数下调幅度超过了利润上修幅度**——本档把三档倍数从旧档的 25/37/44x 重锚到公司自身 5Y PE 分布的 22/29/38x（旧档 base 37x 约等于自身 PE 的 72 分位，是把"合理"锚在历史高位区）。利润端 base 13 → 14.0 亿、bull 15 → 15.3 亿是上修的，倍数端下调更多，净结果下移。**这不是对基本面转空，是承认旧档倍数给得太松。** 逐档推导与全部对账见 [§9 与相对旧档变化清单](valuation.md)。

**诚实面对"贵"（红线 4）** —— 拒绝两条稀释话术：

1. **"同业里 PE 最低"≠ 便宜**。华润微 91.49 / 士兰微 131.55 / 东微 72.99 的高 PE 是**分母塌陷**（2025 净利率 5.02% / 1.06% / 2.70%，均在周期底），不是有效对照。换 PB：扬杰 5.51 是这组**第二高**（仅次新洁能 5.96，高于华润微 3.60 / 士兰微 5.00 / 斯达 3.42 / 捷捷 3.97 / 东微 3.01）。真实位置是「**盈利兑现度最高因而 PE 最低，市场也为此给了最高的 PB 溢价之一**」。
2. **本档的 −28.4% 是"利润法框架内"的结果，不是跨框架下界**。按严格剩余收益（RIM）口径（r=11%、g=6%），公允 PB ≈1.59x、每股约 29.4 元，隐含安全边际约 **−71%**。本档不采用 RIM 作主锚（bull > base，利润法未失效，不触发改锚判据），但这条局限必须让只读本页的读者看到 —— 完整论证见 [valuation.md §9.5](valuation.md)。
3. **成长叙事不进估值，跌幅本身也不算便宜**。AI 只有增速没有基数、公司亲口排除 GPU/CPU/CPO 核心供电、AI 募投锚定单价最低的小信号品类 → **三档中 AI 的 owner earnings 贡献一律按 0**（[§7](thesis.md)）。价格自旧档锚先涨到 157.23（6/30）再崩到 79.98（8/3）再反弹至今，两个月内单日振幅 ≥8% 出现 9 次，是高换手投机盘定价形态；PE/PB 双双仍在近 3 年 95.5 分位。

**买点 / 观察点 / 上修条件**：

- **买点 52.30 元**（base 74.72 × 70%，要求 30% 安全边际；对应市值 ≈284 亿、TTM PE ≈19.9x、PB ≈2.84x）——对应"确定性一般、周期属性未消"档的折让。现价是买点的 1.94 倍。
- **第一观察点 78.87 元**（TTM PE 回到 30x）——comps 七方横评"PE 回到 30x 附近再看"的兑现价位，是"重新做功课"而非"直接买"的触发。**8/3 低点 79.98 元已几乎触及过该位**，并非遥不可及。
- **允许上修 base 的硬条件（非叙事）**：① Q3 单季归母 YoY ≥+25% 且毛利率环比修复至 36%+（证明涨价传导）；② SiC 或 AI 数据中心**营收绝对金额首次单列**且毛利率不低于公司均值；③ 欧盟移除或诉讼胜诉、2027-03-16 悬崖解除；④ 收现比回到 ≥0.9。**满足两条可上调 base 概率与倍数，满足三条重估评级。**
- **若已持有**：见 §11。当前估值下不构成新建仓理由；bull 情景上行仅 +5.2%，风险收益不对称。
