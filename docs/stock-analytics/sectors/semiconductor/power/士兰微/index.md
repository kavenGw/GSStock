## 0 结论摘要

**评级：watch（观察）—— 相对旧档不翻转。** 价格端「太贵」缓解一部分（安全边际 −27.9% → **−21.4%**），基本面端却新增四条旧档未查的裂缝，两者**相互抵消而非其中一方胜出**——这是评级不动的原因。

**期望内在价值 469 亿元 / 每股 28.21 元**｜**安全边际 −21.4%**（vs 市值 597.24 亿）｜**bull 单独压测仅 +8.8%**｜**买点 20.15 元**（base × 70%，市值 ≈ 335 亿）—— **现价 35.89 元是买点的 1.78 倍。**

|------|------|--------|------|---------|----------|------|

> 加权期望 **469.45 亿 / 28.21 元**（≠ base 单一情景）。Σ概率 = 35% + 45% + 20% = 100%。三档全部低于 2021 周期顶（归母 15.18 亿 / 净利率 21.10%）。

**一句话结论**：这轮涨价是**「供给挤出」而非「需求拉动」**——量的紧张来自 AI 抢走成熟制程产能，而它的核心终端（汽车/工业/光伏）被中芯 CEO、英飞凌分部数据、中汽协与光伏协会**三个互不相干的口径同时描述为下行**（[§6.1](thesis.md)）。传导机制没坏（华润微自称毛利率同比提升、7/1 那轮 15% 根本没进 H1 报表），但弹性被 **13.93 亿刚性折旧**吞噬，验证点后移到 **2026Q3** 而非已被证伪。更硬的是利润成色：**H1 归母 +96% 里 37.40% 是一个 3.425 亿量级资产项制造的浮盈**，Q2 单季扣非同比 −4.5%、环比 −25.1%，归母能高于合并净利则因**少数股东全年替它吸收了 2.60 亿亏损**。定价上 PS 4.40x 看似便宜，实则是**低毛利率的会计后果**（[§9.0.1](valuation.md)）。维持 watch。
