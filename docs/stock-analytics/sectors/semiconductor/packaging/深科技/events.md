# 深科技（000021）事件回写

> 本文件承接被本轮重做取代的两份旧档的残值结论，并作为后续 stock-research 模式 3（新闻/事件影响）的回写落点。
> 主档见 [index.md](index.md)。

## 承接一：26Q1 季报点评（2026-04-30，Phase C 删除）

原档 `quarterly/26q1/2026-04-30-深科技-26Q1季报点评.md`，结论 **「不投（Don't Buy）；已持有者维持观察」**。

**其核心指控与本轮的对账**：

| 26Q1 点评的指控 | 本轮（26H1）裁定 |
|---|---|
| 扣非与净利润背离 1 亿，**41% 的利润来自非经常性损益**，盈利质量同比下降 | **已修复** —— 26H1 非经常仅 0.3917 亿、占归母 **7.21%**，扣非/归母 92.79%；26Q2 单季扣非 3.615 亿 > 归母 3.013 亿（非经常为负） |
| **经营性现金流崩溃** —— 每股从 25Q1 的 0.43 暴跌到 26Q1 的 0.07，「利润是账面的，现金没回来」 | **证实且严重恶化** —— 26H1 每股仅 0.0749（Q2 单季只增 0.0024 元/股，绝对额 379 万元），现金转化率 21.69%、TTM 34.7%。**该点评是这条主线的起点，本轮把它从「单季扰动」升级为「已确认的趋势」，并已触发 [§11.2](index.md) 监控指标** |
| 应收账款周转天数 102.59 天、环比反弹 | 26H1 96.25 天（25H1 90.59），**与存货周转天数 79.74 天（25H1 69.28）同步拉长**，方向未改善 |
| 毛利率从 25Q4 的 21.89% 滑回 17.07%，未跟上江波龙的「史诗级毛利跳升」 | **已修复** —— 26Q2 单季 **20.37%**、H1 **18.88%（+3.13pp）**。**但该点评对「为什么跟不上」的结构性解释完全正确**：封测代工不享受存储现货涨价红利（合同价 + 加工费模式），26Q2 合约价 +58~63% 而存储分部收入只 +1.83% 是它的直接印证 |
| **核心判断**：封测代工「周期保护」的代价是长期 ROIC 永远爬不过门槛 | **本轮完全承接并强化** —— 五年加权 ROE 区间 6.06%~9.09%，从未接近 15% 优质门槛，也从未接近 12% 股权成本。这是本档 [§9.2](valuation.md) 把合理 PB 排在 0.45~1.08 的根本依据 |
| 「这家公司唯一定价的事情，是定自己的电费报销标准 —— 这不是 franchise，这是 commodity」 | **本轮裁定该判断是对的，旧 buffett 档推翻它是错的**（详见承接二） |

**残值结论**：26Q1 点评的**方法论与商业模式判断经受住了本轮检验**，唯二被证伪的是两个**可修复的读数问题**
（非经常占比、单季毛利率）——而它们恰恰是最容易随季度波动的项。**它对结构（无定价权、ROIC 爬不过门槛、
现金流质量）的判断，四个月后被半年报逐条坐实。**

## 承接二：旧 buffett 平铺档（2026-06-08，Phase C 删除）

原档 `sectors/semiconductor/packaging/2026-06-08-深科技-buffett分析.md`，评级 **watch**，
期望内在价值 543 亿、安全边际 −7.2%。

**watch 的成立过程（2026-05 至 06-08）**：旧档在 26Q1 点评的「不投」之上做了一次翻转，理由是 5 月出现四项
「重大新变量」——HBM3 量产良率 98.2%（追平三星）、国内唯一通过英伟达认证、HBM 占比 30% 且毛利率 39%、
14.7 亿扩产 2027 投产。旧档把**前三项全部标为【硬】证据**，据此判定「商业模式从 commodity 向 franchise 升级」，
AI 敞口从「蹭概念」升级为「**业绩层真敏感**」，护城河从「无」改判为「HBM 封测有技术壁垒」，
bull 情景给到 18–20 亿净利 × 20–25x PE。但同时诚实地保留了「PE 50x 已定价、ROE 8.67% 低于优质标准」的顾虑，
故只给 watch 而非 core/config，并设「毛利率是否结构性抬升」为**第一验证项**，明确交给 8 月中报裁决。

**watch 的瓦解过程（2026-06-30 至 08-30）**：

| 时点 | 事件 | 作用 |
|---|---|---|
| **2026-06-30** | 股价半月 +57.64% 后，公司发布《股票交易异常波动公告》：「HBM 技术尚处于研发阶段，**预计短期内不会产生相关销售收入和利润**」，并把「供货英伟达、封装良率对标国际一线」定性为**无官方披露依据的题材炒作** | **旧档第一根支柱被公司本人推倒**。该公告晚于旧档 conviction_date 22 天 —— 建档时该证据尚不存在 |
| 2026-07 | TrendForce 3Q26 DRAM 合约价涨幅从 +58~63% 收窄至 +13~18%，明写减速原因是**买方支付意愿见顶** | 周期定位从「中段」改判「后段」 |
| 2026-07-14 | 长电 H1 预增 63~102%，靠 mix 升级把扣非净利率拉到 4.8%~6.8% | 旧档记为「正面样本」，本轮改判为**对深科技不利的对照** |
| **2026-08-26** | **26H1 半年报**：毛利率 18.88%（第一验证项**读数通过**）；但 HBM 全文仅 1 次且指行业原厂、英伟达 0 次、存储分部整体仅占营收 25.83%（**「HBM 占比 30%」算术上不可能**）；经营现金流 −91.90%；营收增量 100% 来自 GM 11.90% 的 EMS；在建工程仅 2570 万、较年初 −4.3% | **第二根支柱立住了但没承重，且归因被证伪。同时暴露旧档完全未覆盖的增长结构问题** |
| 2026-08-30 | 本档重做，评级 **watch → exclude** | 期望内在价值 543 亿 → **88.35 亿**，安全边际 −7.2% → **−85.0%** |

**残值结论（最应被记住的一条）**：旧档的失误**不在于结论**，而在于**证据分级**。
把东方财富财富号与门户转述标为【硬】，让一个建立在传闻上的结论看起来有支撑；
真正的一手材料（公司公告、定期报告）在 22 天后把这些传闻逐条否掉。
**证据分级错误比结论错误更危险 —— 因为它会让错误的结论看起来有支撑。**

同时必须公平记下：**旧档并未被本轮全面推翻**。它设的第一验证项（毛利率是否结构性抬升）**设对了**，
只是它没料到答案会是「毛利率抬了、归因错了、利润没跟上」；它保留的两条顾虑（PE 50x 已定价、ROE 低于优质标准）
在本轮**全部成立并被放大**。
