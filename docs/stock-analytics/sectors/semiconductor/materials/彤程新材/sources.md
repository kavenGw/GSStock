### quote_guard 断言与 `--allow-preopen` 的披露

```
python scripts/quote_guard.py --code sh603650 --price 72.25 --volume 361469 \
  --ts "2026-09-17 16:14:44" --shares 616069636 --market-cap 44511031201 --allow-preopen

```

**必须披露的守卫口径**：不加 `--allow-preopen` 会被拒（"时戳 16:14:44 不在 A 连续交易时段内"）。
该断言是为**盘中锚**设计的，对**盘后结算快照**不适用。本轮锚是**收盘价**，依据四条：
① 时戳 16:14:44 在 15:00 收盘之后，属当日终盘结算数据；② 成交额 25.94 亿、换手 5.87%，
非零成交、非集合竞价挂单；③ 东方财富独立源给出完全相同的价/量/额/市值；
④ **市值自洽校验独立通过**（72.25 × 616,069,636 = 44,511,031,201，偏差 0.00%）。
→ `--allow-preopen` 只豁免"非交易时段"一条，**成交量与市值自洽照查且均已通过**。
