## 12.5 已知局限

1. **PB/PE 分位数的样本限制**：百度股市通历史序列为**约双周采样（599 点）**，非日频。5 年 PB 分位 98.1% 已**饱和无分辨力**
   （旧档 18.80 与当前 19.45 同报 98.1 分位），故本档主标尺改用「相对 5 年中位倍数 5.64x」。
2. **中证口径与腾讯/百度口径不同源**：公告 2026-050 的 PB 17.24 为中证指数口径，与本档 19.45（归母权益口径）不可直接比较。
3. **SOTP 的循环依赖**：本档约三分之一价值来自兄弟档 `2026-08-14-生益电子-buffett分析.md` 的三档估值，
   **本档全盘接受未作独立复核**——这是有意的分工（避免两档对同一标的给出两套数字），但读者须知这层依赖。
   兄弟档若偏高/偏低，本档同向偏高/偏低；且两档共享「拒绝用周期顶利润定价」的同一原则，
   **若该原则本身错了（本轮景气真是结构性新台阶），两档会同向同幅度低估**——这是本档最大的**系统性**误差来源。
4. **正常化营收/净利率的分档是主观判断**：两条独立路径只在 **bear 档**交叉收敛（27.5 / 28.88 / 27.8 亿），
   base 与 bull 是对「本轮涨价保住多少」的分档假设，路径一无法独立给出。已在 [valuation.md §9.2](valuation.md) 明写。
5. **母体/子公司利润拆分比例（82% / 18%）是推算**，依据是 26H1 实测的 21.4% 与生益电子历史盈利波动更大这一定性判断。
6. **A2/A3 与 A1 的数字冲突**已在 [valuation.md §9.7-D](valuation.md) 逐条列出并一律取 A1，其中**东莞企石新厂一期投产时点**
   （A2/A3 及裁定 §5 的 2027-09 vs A1 一手公告的 2028）是本轮最重要的一处，已显式标注并说明其对论点的影响方向。
