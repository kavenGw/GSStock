## §9.1 正常化利润：两侧压力各走一遍

**先明确红线**：正常化利润取**穿越周期均值**，**绝不把 H1 年化（28.87 × 2 = 57.7 亿）、7 月单月年化（11 × 12 = 132 亿）或 FY26E 峰值（77–95 亿 / 花旗 96.07 亿）当常态。**

### (iii) 新中枢的推导（两条独立路径，交叉收敛）

**路径 1 —— 穿越周期八年窗口均值（含两个峰值 + 一个已实现谷底）**

```
实际已发生（HKD 亿）：
  FY21  67.82  ← 上一轮周期顶
  FY22  19.09
  FY23   9.07  ← 上一轮周期底（自 FY21 −86.6%）
  FY24  13.26
  FY25  24.42
  → FY21–FY25 五年均值 = 133.66 / 5 = 26.73

加入本轮（推断，非披露）：
  FY26E  85    ← H1 实际 28.87 + H2 56（月均 9.3 亿：低于 7 月的 11，高于 H1 的 4.81）
                 对照：瑞银 66.54（隐含 H2 月均 6.3）/ A1 情景 77–95 / 花旗 96.07
  FY27E  55    ← 韶关布线 2026Q3 已投产、清远 2027H1、南沙 2027Q3 陆续压价，
                 但 2027 全年仍在高位平台（美银口径：上行周期持续至 2027）
  FY28E  20    ← 巨石 3.21 亿米（2027 底–2028 初）+ 建滔自身 10.5 亿米全部到位，
                 行业供给 +17.4% 集中释放（C14 已闭合）

  → FY21–FY28E 八年均值 = 293.66 / 8 = 36.71  ≈  HKD 36.7 亿
```

**路径 2 —— 正常化营收 × 正常化净利率（独立构造）**

```
正常化营收 ≈ 204 亿（FY25 实绩）
              × 1.25（量：H1'26 实测 +14%、月均破 1,000 万张，叠加萍乡 CCL 110 万张/月、
                       纱 18→25 万吨、布 3.23 亿米新增；取 +25%，低于满产名义值）
              × 1.22（价：穿越周期中枢价高于 FY25 均价；FY25 成交于 FR-4 70→130 区间，
                       取 +22%，远低于当前 260+ 隐含的 +270%）
            ≈ HKD 311 亿

正常化净利率 ≈ 11.0%
   历史锚：FY23 谷底 5.5% ｜ FY24 7.2% ｜ FY25 12.0%（24.42/204）｜ H1'26 实际 19.37%
   → 四点算术均值 = (5.5 + 7.2 + 12.0 + 19.37) / 4 = 11.02%
   → **相对旧档的两处口径变动，须同时记账**：
     ① 旧档第四个锚用的是「H1'26 推断 16.9–17.6%，取中 17.25%」，**实际是 19.37%** → 均值上抬
     ② 旧档的 D3（铜箔层过剩）是「为何不高于 FY25 的 12.2%」的定性理由，**该理由已随 A5 撤回而失效**
     → 但**不自动回到旧档更早的 12.5–13%**：D2（34.6% 利润是价格租金，且该层供给增幅已锁定）

       （**注意 D1 不参与此处的净利率推导**——扩张期 FCF 为负是资金去向问题，

     → 净结果 11.0%（旧档 10.5%，上修 0.5pp），**远小于单看 A5 撤回应有的幅度**

正常化净利 ≈ 311 × 11.0% ≈ HKD 34.2 亿
```

> ### **两条独立路径给出 36.7 亿 与 34.2 亿 → 收敛。本档取 base 正常化净利 = HKD 35 亿。**
>
> **取值说明**：两路径算术平均为 (36.71 + 34.2) / 2 = **35.46 亿**，本档取 **35 亿**是**向下的保守取整，不是算术平均**（低 1.3%）。理由：八年窗口的 FY26E–FY28E 三年是推断值而非实绩，阻尼后仍带外推成分；营收法的 34.2 亿全部锚在已实现的历史净利率区间上，**证据强度更高**，故取值向低的一侧靠。
>
> **红线 3 自检**：35 亿 = FY25 实绩 24.42 亿的 1.43 倍、FY26E 取值 85 亿的 **41%**、A1 上沿情景 95 亿的 **37%**、花旗 FY26E 96.07 亿的 **36%**、H1 年化 57.7 亿的 **61%**、7 月单月年化 132 亿的 **27%**。**三档正常化利润（24 / 35 / 55 亿）全部低于任何一个峰值口径 ✅ 穿越周期。**
>
> **敏感性带（八年窗口是阻尼估计量）**：令 FY26E / FY27E / FY28E 在 **77–95 / 40–75 / 12–35** 亿内摆动（覆盖从"H2 即回落"到"高位平台延续到 2028"的全部合理路径），八年均值落在 **32.6 – 42.4 亿** → base 每股 **10.3 – 13.5**，期望内在价值 **11.2 – 12.7**，安全边际 **−65.4% ~ −69.6%**。**评级在整条带上都不翻转（现价始终是期望值的 2.9–3.3 倍）。**

### (iv) **周期超额现金：旧档 base +15 亿 → 本档三档统一为 0**（本档最大的单项下修）

**旧档做法**：base 按 FCF 口径给 +15 亿（bear +4 / bull +26）。

> ### **归零的理由不是"利润不含金"，而是"现金全部投进了产能"。**
>
> 周期超额现金的定义就是 **OCF − CapEx − 股息**之后**还能留下的钱**。26H1 的实测是：**CapEx 从约 4 亿暴增到约 18 亿（×4.5）**，加上 16.8 亿证券投资与派息，FCF 转负、缺口由净负债 +29.6 亿补上。
> **所以周期内没有超额现金可供留存——不是因为利润不含金（净现比判据已被证明对本公司不具判别力，见 [§3.3](business.md)），而是因为公司选择把峰值现金流投进产能扩张。**
>
> **而这恰恰与本档核心新论点闭合**：它投出去的产能，**正是将来压垮峰值价格的那批**（韶关 9,500 万米布线 2026Q3 全面投产，建滔 + 巨石合计 +17.4%，[§6.1](thesis.md)）。
> **同一笔钱，在现金流量表上是"超额现金归零"，在供需表上是"未来价格的掘墓人"。**

**按本档三档利润路径重算现金留存**【推算】（系数：CapEx FY26 40 亿 / FY27 45 亿——四线同时在建：南沙 1.5 亿米 + 清远 7,800 万米布 + 清远 2.1 万吨铜箔 + 萍乡 CCL 一期；OCF 按全年口径取净利的 **FY26 各档 0.65–0.67x、FY27 各档 0.90–0.91x**，**已按季节性用全年而非半年口径**；**各档实际隐含系数**：FY26 bear 50/77 = **0.65x**、base 57/85 = **0.67x**、bull 64/95 = **0.67x**；FY27 bear 32/35 = **0.91x**、base 50/55 = **0.91x**、bull 81/90 = **0.90x**（FY27 系数高于 FY26，反映价格走平年营运资金占用释放，与旧档「价格走平年取 1.1x」同向但更保守）；股息按各档实际派息率 30%）：

## §9.2 合理 PE：8–12x（commodity + 成本护城河），三档取值与"本可上调却不上调"的记账

| 业务特征 | 适用 PE | 建滔符合？ |
|---|---|---|
| 宽护城河（定价权）+ 轻资产 | 20–25x | ❌ 无独立定价权（挂牌 +183% vs 实现 +36.5%）；重资产（FY26 capex ~40 亿） |
| 稳固护城河 + 中等增长 | 15–20x | ❌ 跑道主要是价格；技术护城河从未拥有（中报 M6/M8/M9、英伟达、服务器各 0 次） |
| **成本护城河 + commodity + 强周期** | **8–12x** | ✅ **最符合** |

| 情景 | PE | 理由 |
|---|---|---|
| **Bear** | **8x** | 周期下行时市场只肯给 commodity 谷底倍数（上一轮 FY23 净利 9.07 亿即实证） |
| **Base** | **10x（维持，不上调至 11x）** | **本可上调的三条理由**：①U1 A5 撤回——最大成本层（42.1%）的紧缺红利并未消失，四层一体化的截留效力恢复到接近全链条；②U2 量增被证实 +14.0%（与生益 +14.24% 几乎一致，说明**行业量增约 +14%**，建滔并非"只卖更贵的板"）；③U4 上游层利润首次被量化（10 亿 / 34.6%）。**为什么不上调**：①**D2**——34.6% 的利润来自一个价格处于历史极值、而供给增幅已由公司自己公告锁定的环节；②**D1**——扩张期 FCF 为负、靠净负债 +29.6 亿支撑，**且这不是暂时的**：南沙/清远/萍乡/铜箔四线同时在建，CapEx 强度将延续到 2027；③**D3 资本配置**——FCF 为负时净买入 16.8 亿证券已亏 2.69 亿；④**D4**——挂牌 +183.49% 对实现 +36.5% 的定价权缺口。**⚠️ 本档明确不把"净现比 0.25x"列为不上调的理由**（该判据对本公司不具判别力，见 [§3.3](business.md)）。**两侧抵消 → 维持 10x，显式记账。** |

**倍数破框架自检**：三档（8/10/12x）**全部在 8–12x 框架内，无一破框** ✅。

## §9.5 **正面对峙：本档的 12x 框架 vs 市场对整个 CCL 板块的定价**

**这是本轮最难处理的一条，不能回避、也不能靠"市场错了"一句带过。**

### (i) 事实：建滔是整个 CCL 板块估值最低的标的

|---|---|---|

| 生益科技 600183.SH | 57.98x | 16.28x |
| 台光电 2383.TW | ≈107–114x | ≈37–40x |
| 南亚新材 688519.SH | 174.12x | 22.84x |
| 金安国纪 002636.SZ | 89.37x | 11.50x |

旧档以「commodity 合理 PE 上限 12x」为锚给出 exclude。**表面看，本档的框架与市场对整个板块的定价差了一个量级。**（⚠️ 旧档记的"PE-TTM 37.60x"实为静态 PE，真实 PE-TTM 更低——这个纠错**加重**而非减轻了本节的对峙难度。）

### (ii) 分解：这个分歧的 84.3% 不在倍数，在分母

@36.800 的隐含倍数阶梯（**须原样呈现整条阶梯，不许选一个**）：

| 分母口径 | EPS (HKD) | @36.800 的 P/E |
|---|---|---|
| PE-TTM（FY25 24.42 + 26H1 28.866 − 25H1 9.333 = 43.95 亿） | 1.3947 | **26.39x** |
| **本档 base 正常化（35 亿）** | 1.1106 | **33.1x** ← 市场在为本档的正常化利润付 33.1 倍 |
| 26H1 年化（0.920 × 2） | 1.840 | **20.00x** |
| 瑞银 FY26E 66.54 亿 | 2.111 | **17.43x** |
| 花旗 FY26E 96.07 亿 | 3.048 | **12.07x** |
| 花旗 FY28E 195.23 亿 | 6.195 | **5.94x**（花旗 TP 130 ≈ **21.0x FY28E**） |

**对数分解**——本档 base 估值（35 亿 × 10x = 350 亿）与市场最便宜读数（96.07 亿 × 12.07x = 1,159.73 亿）的 **3.31 倍**差距：

```
分母比 = 96.07 / 35   = 2.744   →  ln = 1.0096
倍数比 = 12.07 / 10   = 1.207   →  ln = 0.1881
合计                    3.313   →  ln = 1.1978   （2.744 × 1.207 = 3.312 ✅ 自洽）

分母贡献 = 1.0096 / 1.1978 = 84.3%
倍数贡献 = 0.1881 / 1.1978 = 15.7%
```

> ### **结论：本档与市场的分歧，84.3% 是「96 亿是不是新常态」，只有 15.7% 是「CCL 厂该给几倍」。**
>
> **这直接回答了控制者的对峙题**：**「若 12x 是对的，则整个板块都错得离谱」这个推论本身是错的** —— 因为市场根本没有在正常化利润上给 58x。生益 57.98x TTM 的分母同样是半个周期的 trailing 利润（其 26H1 归母 32.87 亿年化 = 65.7 亿 → 市值 3,012 亿 = **45.8x 峰值年化**）；台光电 ~110x 同理。**市场付的是「峰值 × 中等倍数」，本档付的是「正常化 × 中等倍数」。两边的倍数其实相差约 20%。**
>
> **所以真正的问题从来不是"12x 还是 25x"，而是："FY26 的 85–96 亿，是新台阶还是周期顶？"** 这也正是卖方一致预期跨度 5.1 倍的唯一来源（§9.6）。

### (iii) 本档选哪一边、为什么、以及若选错会怎样

**本档选"周期顶"一侧（正常化分母），四条理由，全部是硬事实或已闭合的定量证据：**

1. **供给增幅有数字、有日期、且第一批是标的自己的**（D2 / C14 闭合）：+17.4% 行业供给落在 2026Q3–2028Q1，韶关 9,500 万米就在下个季度。旧档因"幅度不可量化"而不敢重仓这条论据，本轮该理由已不成立。
2. **34.6% 的纯利来自价格处于历史极值的一层**（7628 年内 +118~165%）。转移型利润（上游向下游收租，母公司 0148 收入 +35% 而纯利仅 +5% 是直接证据）的持续性远弱于创造型利润。
3. **垂直整合的现金代价是结构性的、不会随周期好转而消失**（[§5.2](business.md)）：生益靠应付票据 +81.51%、应付账款 +53.28% 向上游转嫁 **46.39 亿元**营运资金；建滔上游即自身、无外部供应商可转嫁，应付类仅增 **9.30 亿港元**，43.25 亿占用**全部自扛**。**这不是盈利质量问题，是商业模式的现金特征**——它意味着每一轮扩张都必须靠资产负债表融资，因而周期顶部的估值不该拿到"能自我造血的成长股"的倍数。
4. **上一轮的实证振幅是 −86.6%**（FY21 67.82 → FY23 9.07 亿）；股价侧 2026-06-25 的 107.20 → 07-31 的 28.56，**五周 −73.4%**。这个分布的左尾极重。

**若本档选错（即市场对、短缺确属结构性并活到 2028），会怎样 —— 诚实列出：**

- **代价是错过一次重估**：花旗 TP 130 相对现价 36.800 是 **+253%**。这是本档可能付出的最大机会成本，写在这里，不辩解。
- **但即便完全按"市场对"的口径重算，现价仍不便宜**：结构性情景 = 本档 bull（正常化 55 亿 × 12x = **HKD 20.9**）。现价是 bull 的 **1.76 倍**。
- **要让 36.800 成为"公允"，需要同时满足两件事**：正常化利润 ≈ **60 亿**（1,159.73 / 19.3x）**且**给到 **~19.3x** 的 franchise 倍数。而 19.3x 需要一条护城河，**建滔的一手披露不支持**：中报全文 **M6/M8/M9 = 0 次、英伟达 = 0 次、服务器 = 0 次**；高端 CCL 占比 ≥30% 目标连续两份法定报告零兑现；高端特殊 CCL 份额 2.3% 仅有【软·二手】来源；无任何第三方具名客户 ≥10%。
- **一句话**：**本档可能错在"周期顶什么时候到"，但要错到"现价合理"，需要同时错在利润和倍数两件事上。**

## §9.7 交叉验证：两个独立方法 + 母子折价

**验证 A —— 周期峰值利润 5–8x 启发式**（用 A1 的 FY26E 情景区间，不用花旗 96.07 亿）

|---|---|---|---|
| FY26E 下沿 **77 亿**（H2 月均降至 8 亿） | HKD **12.22** | HKD **14.66** | HKD **19.55** |
| FY26E 上沿 **95 亿**（H2 维持 7 月的 11 亿/月） | HKD **15.07** | HKD **18.09** | HKD **24.12** |

→ 区间 **HKD 12.2 – 24.1**。**⚠️ 上沿 24.1 须打折读**：8x 用在**峰值**利润上本身就超出框架（8–12x 是给正常化利润的）；把 24.1 当内在价值，等于假设峰值即永久。

**验证 B —— PB / 隐含 ROE 交叉验证**

| 口径 | BVPS | PB @36.800 |
|---|---|---|
| H1'26 实际权益（183.37 亿） | **HKD 5.82** | **6.32x** |

- 剩余收益模型（g = 0）：公允 PB = ROE / Ke = 15.7 / 12 = **1.31x**
- （g = 2%）：公允 PB = (15.7% − 2%) / (12% − 2%) = **1.37x**
- 上沿给垂直整合的成本地位加权 → 合理 PB **1.3 – 2.0x**
  - 按 BVPS 5.82 → **HKD 7.6 – 11.6**
  - 按 FY26 末 BVPS 7.07 → **HKD 9.2 – 14.1**

→ 区间 **HKD 7.6 – 14.1**

> **本档对这一整块的正面回应（不回避）**：旧档为周期转向设的六条可观测阈值，到今天**没有一条触发，且多数在反方向走**。**这是本档看空立场最强的反证。**
>
> **为何仍维持 exclude**：
> 1. **这六条全部是同步或滞后指标**——价格、涨价函、交期、配额、当期利润率，都是"周期正在发生"的读数，**没有一条能提前看到拐点**。旧档设它们是对的（它们便宜、可观测），但**它们不触发不等于拐点远**。
> 2. **本档新增的两条证据是前瞻的**：①**供给日程表**（+17.4%，2026Q3–2028Q1，第一批是建滔自己的韶关布线）——这是**已公告、有日期、不可撤销**的；②**现金**（净现比 0.25x、FCF 转负）——它记录的是当期利润的**质量**，而不是当期价格的**水平**。
> 3. **估值的分歧不在这六条上**：§9.5 已算出，本档与市场 3.31 倍的差距有 **84.3% 在分母**。六条阈值不触发只说明**当前分母（FY26 85–96 亿）是真的**——本档从未质疑这一点，本档 base 已按 FY26E 85 亿计入八年窗口。**分歧在于它是不是常态。**
> 4. **诚实的代价陈述**：若这六条在 2027 年仍全部不触发，本档就是错的，且错的量级见 §9.5(iii)。
