# 宏和科技 — §9 估值（场景加权）+ 相对旧档变化清单

> 结论摘要与评级决策见 [index.md](index.md)；论点与周期定位见 [thesis.md](thesis.md)；盈利能力拆解见 [business.md](business.md)。

## §9.1 估值框架的选择与被排除项

**主锚：正常化单米毛利 × 正常化销量（自下而上）。**

被显式排除的口径：

| 被排除口径 | 排除理由 |
|---|---|
| **2026E PE**（卖方口径 402x，对应 2026E 归母 6.01 亿） | 周期材料股在价格抛物线段的 forward PE 无判别力。26H1 单半年归母 3.795 亿 = 过去七年归母合计（5.796 亿）的 **65.5%**；把这样的 E 乘以任何倍数都是双重放大。 |
| **当期 PE-TTM / 静态 PE** | 254.8x / 623.5x，分母是周期顶 E；且 5y 分位不可给数（2023 亏损、2024 归母近零）。 |
| **PB / 资产法作主锚** | 极薄布 know-how 与客户认证不在账面（全球极薄+超薄布市占 20.5%、2024 年低介电认证通过），纯 PB 会系统性低估；且黄石宏和注册资本两年内 7 亿→24 亿的多轮增资令净资产口径不稳。**仅用作 bear 地板。** |
| **DCF** | 三档正常化利润跨度达 3 倍、扩产达产时点全部为【缺】，永续假设不可辩护。 |

**正常化毛利率分两段加权**（裁定口径）：

- **E 玻璃纤维布段**：长期常态毛利率 **10–20%**。锚点是 2023 年周期底 8.83% 与 2019–2021 年 35.88–37.73%（彼时高性能布收入占比仅 2.05%，即那时的综合毛利率就近似纯 E 布毛利率）。取中枢 15%。
- **高端布段（Low Dk / Low CTE / 极薄超薄）**：**35–45%**，锚用公司自述「高端极薄/超薄布最近一年平均毛利率 **44%**」（定增问询回复，2024-07~2025-06 口径）。**不采用 26H1 特种布 67.49% 的单季极值**——该值处在报价抛物线段，且 2026Q1 产业口径尚称「LDK/LCT 特种布尚未明显涨价」，说明高端布是长约/年度定价，涨价滞后于现货，跌价时同样滞后。
> **必答：为什么高端段敢给 44%，而公司历史最好年份的综合毛利率只有 37.73%（2020 年）、七年均值只有 28.84%？**
> 因为两者不是同一层级的指标。**44% 是分品毛利率**（公司自述「高端极薄/超薄布最近一年对外销售平均毛利率」，2024-07~2025-06 口径），**37.73% / 28.84% 是全公司综合毛利率**；而在 2019–2021 年，高性能布收入占比**推断不足 2%**（**【软·外推，非直接读数】**：直接证据只到 2023 年的 **2.05%**、1,353.70 万元；2019–2021 年公司未作分品类披露，本档由「2022 年高性能布销量 11.91 万米仅为 2023 年 51.78 万米的约 23%」+「高端认证 2024 年才完成」两条趋势线倒推——认证节点与销量爬坡曲线同向指向更早年份份额更低，但该值本身是外推），**那时的综合毛利率近似等于纯 E 布毛利率**，其中根本不含今天这个高端段。同期公司披露的其他分品毛利率佐证 44% 并不激进：2025H1 低介电布 **55.63%**、低 CTE 布 **65.60%**（对外销售口径）——**44% 已是公司自己给出的高端段最低一档**，且取自非极值期。
> **加权后的正常化毛利率 26.0%，低于七年均值 28.84%**（[§9.2 base](#base--50365-元股)），因此整体中枢**不需要**「显著高于历史」的独立理由；抬升只体现在结构（高端布占比 2.05% → 34%）而非水平上。同时明示：单米毛利 26H1 的 **7.084 元/米**、26Q2 的 **8.812 元/米** 相对 2025 全年约 1.7 元/米涨了约 4 倍，**两者都是周期顶部读数，本档三档均未采用**（base 单米毛利仅 2.39 元/米）。

- 权重按当前收入结构 **65/35**（26H1 实际 E 布 64.5% / 特种布 34.0% / 电子纱外售 1.1%）。

**正常化中枢必须能解释 2023 年谷底**：2023 年营收 6.6115 亿、归母 **−0.6309 亿**、扣非 −0.8608 亿、毛利率 **8.83%**、经营现金流 −0.9775 亿。当时公司几乎全部收入是普通 E 布（高性能布收入仅 1,353.70 万元、占比 2.05%），产能利用率仍超 90% 却毛利率 8.83% → **在低端环节宏和没有任何定价权**。任何中枢假设都必须承认这一点。bear 情景即显式回到该状态附近。

**倍数区间 20–30x**：周期材料 + 已验证的高端细分卡位。给到 30x 已隐含「特种布结构性抬升可持续」这一乐观假设；超过 35x 须由已锁定订单或已落地产能支撑，当前两者皆【缺】。

## §9.2 三情景推导

共同参数：总股本 **904,586,445 股**；正常化期间费用参考 26H1 实际（销售 597.0 万 + 管理 9,354.5 万 + 研发 6,226.9 万 + 财务 2,383.3 万 = **1.856 亿/半年**，年化 3.71 亿）与 2025 全年约 1.9 亿之间取值，反映规模扩大 + 有息负债 19.17 亿带来的利息负担；所得税率按高新技术企业 15%；政府补助按 26H1 实际 756.7 万年化取 0.15 亿。

### bear · 30%｜2.68 元/股

| 项 | 值 |
|---|---|
| 正常化销量 | 1.80 亿米 |
| E 布 ASP / 毛利率 | 4.50 元/米 ／ **8%**（回到 2023 谷底附近） |
| 特种布销量占比 / ASP / 毛利率 | 5% ／ 55 元/米 ／ 30% |
| 混合 ASP | 0.95×4.50 + 0.05×55 = **7.03 元/米**；收入 12.65 亿 |
| 毛利 | E 段 7.70 亿×8% = 0.62 亿；特种段 4.95 亿×30% = 1.49 亿 → 合计 **2.10 亿**（毛利率 16.6%） |
| 期间费用 | 2.60 亿 → **营业利润 −0.50 亿**，利润法失效 |
| **改用资产法地板** | 归母权益 29.4933 亿 − 尚未产生收益的在建投入（在建工程 0.5955 + 设备预付 4.7033 = 5.30 亿）= **有效净资产 24.2 亿**；给 **1.0x PB** |
| **估值** | 24.2 亿 → **2.68 元/股** |

PB 1.0x 的依据：bear 情景下隐含 ROE ≤0，按 buffett-doc-spec §3「隐含 ROE 低于股权成本 → 公允 PB 在 1× 附近」。参照 5y PB 低点 2.96x 属景气中段读数，不适用于假设的谷底状态。

**赋权理由 30%**：供给增量约 +22% 已由公司自己的定增文件披露且拐点恰落在 66% 收入的 E 布段（[§8](thesis.md)）；公司 2023 年刚在同一门生意上亏过一次；且宏和在 E 布段无成本优势（纱不自给 vs 巨石全一体化）。

### base · 50%｜3.65 元/股

| 项 | 值 |
|---|---|
| 正常化销量 | 1.85 亿米（介于 26H1 年化 1.734 亿米与 24FY 2.088 亿米之间；苍溪已终止、黄石无时点，**不预设放量**） |
| E 布 ASP / 毛利率 | 6.00 元/米（景气中位 5.5–6.5 取中）／ **15%** |
| 特种布销量占比 / ASP / 毛利率 | 5% ／ 70 元/米 ／ **44%**（公司自述非极值期高端均值） |
| 混合 ASP | 0.95×6.00 + 0.05×70 = **9.20 元/米**；收入 **17.02 亿** |
| 收入结构自检 | E 段 5.70/9.20 = **62%**、特种段 38% → 与裁定要求的 65/35 权重一致 ✅ |
| 加权正常化毛利率 | 0.62×15% + 0.38×44% = **26.0%** |
| 单米毛利 | 9.20 × 26.0% = **2.39 元/米**（vs 26H1 实际 7.084 元/米、Q2 8.812 元/米） |
| 毛利总额 | 1.85 亿米 × 2.39 = **4.42 亿** |
| 期间费用 / 补助 / 税 | −2.80 亿 ／ +0.15 亿 ／ ×85% |
| **正常化归母** | **1.50 亿** |
| 倍数 | **22x** |
| **估值** | 33.0 亿 → **3.65 元/股** |

**隐含 ROE 回查（buffett-doc-spec §3 要求）**：base 隐含 ROE = 1.50 / 29.4933 = **5.1%**，显著低于本标的风险对应的股权成本（有息负债 19.17 亿、股息率 0.049%、2023 年曾亏损 → ≥12%）。按框架，公允 PB 应在 1× 附近；本档 base 对应 PB = 33.0 / 24.2 = **1.36x**，即 22x 倍数已经**偏向多头**（它给了高端布占比抬升一份未由 ROE 兑现的溢价）。此处不下修，但明确披露：**base 是三档中最偏多的一档，不是保守档**。若严格按 ROE 一致的 1.0x PB，base 将降至 24.2 亿 / 2.68 元/股（与 bear 重合）。

> **⚠️ 部分破框架（显式标注）**：本档 base 未字面执行 buffett-doc-spec §3 的「PB 阶梯重排」动作，属**有意保留的偏离**——机械重排会使 base = bear = 2.68 元/股，反而违反 spec 自身「bear < base < bull」的三档要求。故改为「保留 22x + 完整披露隐含 ROE 诊断 + 给出 1.0x PB 替代值」的处理，偏离范围仅限倍数一项，不影响 bear/bull 与期望值算法。

**赋权理由 50%**：该中枢同时解释了 2023 年谷底（E 布无定价权）与 2019–2021 年 1.04–1.24 亿的利润平台，并承认高端布收入占比从 <2% 升至 34% 带来的真实抬升（1.50 亿 > 七年平均 0.828 亿）。它不需要任何未兑现的扩产或未披露的客户。

**该档内部存在一处须点明的张力**：base 的**输入假设是三档中最保守的一侧**（正常化销量取 1.85 亿米、低于 24FY 的 2.088 亿米；毛利率加权 26.0%、低于七年均值 28.84%；不给扩产与高端认证任何赋权），而**倍数一侧却是偏多的**（22x 对应 PB 1.36x，高于隐含 ROE 5.1% 所支持的约 1.0x）。两侧方向相反，净效果是 base 大体落在合理区间但**并非"保守档"**——真正的下行保护来自 bear 的 30% 权重，而不是来自 base 本身。

| 项 | 值 |
|---|---|
| 正常化销量 | 1.95 亿米 |
| E 布 ASP / 毛利率 | 6.50 元/米 ／ **20%**（E 布段毛利率上限） |
| 特种布销量占比 / ASP / 毛利率 | **9%**（当前反推 3–7%）／ 78 元/米 ／ **45%**（高端段上限） |
| 混合 ASP | 0.91×6.50 + 0.09×78 = **12.94 元/米**；收入 **25.22 亿** |
| 毛利 | E 段 11.53 亿×20% = 2.31 亿；特种段 13.69 亿×45% = 6.16 亿 → **8.47 亿**（毛利率 33.6%） |
| 期间费用 / 补助 / 税 | −3.40 亿 ／ +0.15 亿 ／ ×85% |
| **正常化归母** | **4.44 亿** |
| 倍数 | **28x** |
| **估值** | 124.3 亿 → **13.74 元/股** |

**bull 证据包门控（x-growth lens 必算）**：

| 要素 | 判定 | 依据 |
|---|---|---|
| (a) 扩产达产确定性 | **【缺】且被公司自身行为否定** | 景气顶终止苍溪 6 亿元/7,200 万米项目并退地；80 亿黄石产业园无产能指标、无建设期、无达产时点；公司 2026-06-17 自述「产能投放节奏以及最终是否可以实施落地仍存在较大不确定性」，且依赖尚未完成的 H 股发行 + 银行融资 |
| (b) 客户 capex / 出货能见度 | **【缺】** | 无具名客户披露（半年报仅列应收前五合计 3.6738 亿元，未具名）；无在手订单金额、无长协锁定量、无客户 capex 指引引用。仅能降级到终端兑底（AI 服务器需求，【软】第三方口径） |
| (c) TAM 跑道 | **【软】** | 沙利文口径全球特种电子布市场 2025 年仅 6.23 亿美元（约 45 亿人民币），而宏和 26H1 单半年特种布收入已 3.57 亿人民币 —— 口径可比性公司未说明，**不可直接套用**；第三方低介电布需求 2025 年约 1 亿米、低 CTE 约 1,500 万米。整个全球高端布收入池是百亿人民币量级 |

**三项无一为【硬】→ 按 buffett-doc-spec §3 门控，bull 概率封顶 20%，倍数不得超 30x。** 本档取 20% / 28x，与建滔积层板 08-25 档 bull 压至 20% 的处理一致。

**bull 单独压力测试**：bull 隐含 ROE = 4.44 / 29.4933 = **15.1%**，PB = 124.3 / 24.2 = **5.1x**。即 bull 已经隐含「宏和从一家七年平均 ROE 5.5% 的公司，永久变成 15% ROE 的高端材料商」。**即便这一整套假设全部兑现，13.74 元仍距 139.17 元现价 −90.1%。** 这是本档最重要的一条压力测试结论：**不是「贵一点」，是「即使最乐观情景全中，仍需下跌 90%」。**

### 敏感性变量 s：特种布销量占比（不得取定值当事实）

公司**确认未披露分品类销量**（A1 穷尽四条路径：主要经营数据公告「主要产品」列只有一行合并值；半年报全文「销售量/销量/产销/万米」仅 2 处命中且全为定性句、零数字；附注五 61(2) 只有收入与成本两列、无数量列；本期半年报**没有**「主要产品产销量情况表」）。因此特种布销量占比 **s 是假设，不是事实**，本档作敏感性变量处理。

**约束等式**（由 26H1 硬数据反推，E 布收入 6.76276 亿 / 特种布收入 3.56526 亿 / 电子布总销量 8,668.89 万米）：

| s | 隐含 E 布 ASP（元/米） | 隐含特种布 ASP（元/米） | 特种布/E 布价格倍数 |
|---|---|---|---|
| 3% | 8.04 | 137.09 | **17.1x** |
| **5%（本档 base 采用）** | 8.21 | 82.25 | **10.0x** |
| 7% | 8.39 | 58.75 | **7.0x** |
| 10% | 8.67 | 41.13 | 4.7x |
| 20% | 9.75 | 20.56 | 2.1x |

**读法与风险**：A2/A3 由第三方定价（一代低介电约 60 元/米、二代约 120 元/米）反推出的 s = 3–7% 区间，隐含特种布售价是 E 布的 **7–17 倍**；该倍数需要独立的实际市场价差证据支撑，**否则真值可能更靠近 10–20%**。本档 base 取 s = 5%（落在 A2/A3 区间中部）、bull 取 s = 9%，并对 base 跑 s 敏感性：

| base 变体 | 正常化特种布 ASP | 正常化归母 | 估值（22x） | 每股 | 对应期望内在价值 | 安全边际 |
|---|---|---|---|---|---|---|
| s = 5%（**主用**） | 70 元/米 | 1.50 亿 | 33.0 亿 | **3.65 元** | **5.38 元** | **−96.1%** |
| s = 10% | 45 元/米 | 2.14 亿 | 47.0 亿 | 5.19 元 | 6.15 元 | −95.6% |
| s = 20% | 22 元/米 | 1.92 亿 | 42.3 亿 | 4.68 元 | 5.90 元 | −95.8% |

（s 变体中 E 布正常化 ASP 与两段毛利率不变，仅调整 mix；bear/bull 权重与取值不变。）

> **变体中特种布 ASP 的取法（补推导）**：45 / 22 元/米**不是**独立测算值，而是把上方约束等式表（26H1 历史反推口径）在 s=10% / 20% 处的隐含值 41.13 / 20.56 元/米，按 base 的正常化口径**平移取整**得到（同 s=5% 处 82.25 → base 取 70 的处理方式，即正常化值系统性低于周期顶反推值）。它保持了「s 越高 → 单价越低」这一约束等式的内在关系，但属**近似平移而非重新推导**，精度到量级而非小数位。因结论对 s 不敏感（区间仅 5.38–6.15 元/股），该近似不影响评级。

**结论：期望内在价值对 s 的敏感区间为 5.38 – 6.15 元/股，安全边际 −96.1% ~ −95.6%——评级结论对 s 的取值不敏感。** 本档正文一律以 s = 5% 的 5.38 元/股为口径，但**不把 s 当作已知事实**；分品类销量若在 H 股招股书正式版中披露，即构成重新承做触发（[§11](index.md)）。

### 期望内在价值与安全边际

| 情景 | 每股（元） | 概率 | 加权贡献 |
|---|---|---|---|
| bear | 2.68 | 30% | 0.804 |
| base | 3.65 | 50% | 1.825 |
| bull | 13.74 | 20% | 2.748 |
| **合计** | — | **100%** ✅ | **5.377 → 5.38 元/股** |

- **期望内在价值总额** = 5.377 × 904,586,445 = **48.64 亿元**
- **实时市值**（2026-08-28 收盘，quote_guard EXIT=0）= **1,258.91 亿元**
- **安全边际 = (48.64 − 1,258.91) / 1,258.91 = −96.14% → −96.1%**

确定性等级：**低**（三项 bull 要素全部【缺/软】、产能绝对数与客户名单均未披露）→ 按 buffett 框架属「无法可靠估算」的边缘，所需折价 40–50%；即便按 40% 折价，买点约 3.2 元/股。
