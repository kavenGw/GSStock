- 旧点评定性：「**收入端首次失速，但毛利率改善撑住了净利**——典型的『以利润换体面』季度，
  需要看 Q2 收入能否恢复正增长以判断是周期回调还是结构性问题。」
- 旧点评评级：**观察（不变）**；买点 < 73 元（PE 35x 试探）/ < 59 元（PE 30x 建仓），前置条件为 Q2 营收转正。
- 旧点评另记：26Q1 扣非 +5.91%、**财务费用 +449%**。

**该问题在本轮已有答案**【硬·A1 §2】：
- **Q2 营收转正且强劲**：26Q2 单季 25.4023 亿、**+16.78%**，26H1 **+5.12%** —— 旧点评的前置条件**已满足**。
- **但答案是「以利润换体面」的升级版**：26Q2 毛利率 **28.81%、同比塌 5.22pp**，扣非仅 +4.87%；
  26H1 扣非 **+0.68%**、毛利率 **29.87%（四期最低）**。
  **即：Q1 是「收入失速、毛利率撑住」，Q2 起变成「收入回来、毛利率塌了」。**
- **财务费用 +449% 已证伪并反转**（26Q1 **−61.4%**、26H1 **−58.48%**），但原因是华飞 8.498 亿股权融资还债，
  **属一次性资本结构事件，不是经营改善**。
- **旧点评买点 59–73 元在本轮被大幅下移**：新档三档每股内在价值 bear 13.03 / base 19.33 / bull 28.37 元，
  期望值 18.62 元。旧买点口径基于「整体 PE 30–35x × 归母」，与本档的 SOTP + 资产法主锚不可直接比较，**以新档为准**。
