## §0 结论摘要

**评级：exclude（不买，且当前价位主动回避）。维持旧档评级，但否决理由结构整体重写。**

- **期望内在价值 ≈ 88.6 亿元（每股 18.62 元）**，对当前市值 652.878 亿 → **安全边际 −86.4%**。
- **三情景各一句**（口径与算式见 [valuation.md §9.4](valuation.md)）：
  - **bear 62 亿（每股 13.03 元）/ 40%** —— 传导继续以 +8% 斜率滞后、毛利率下行不止、2028–2030 供给释放窗口提前显形；
  - **base 92 亿（每股 19.33 元）/ 40%** —— 稼动率由 59.31% 爬到 70% 一档，前驱体量增 8–12%，LNG 补回但不加速；
  - **bull 135 亿（每股 28.37 元）/ 20%（封顶）** —— 2027H2 存储线按公司口径「明显提升」+ 两基地 2027 年底接近满产。
- **核心矛盾（三层，展开见 [thesis.md §6](thesis.md)）**：
  1. **传导滞后被延长了半年，而且这次连遮羞布都没有了**：半导体分部 26H1 **+8.31%**（2025 全年 +8.01%，同一斜率），
     LNG 所在化学材料 **−1.30%**。旧档说「引擎是 LNG 不是半导体」——**现在是两个引擎同时钝化**，
     H1 的 +5.12% 靠毛利率仅 **16.13%**（同比 −7.10pp）的「其他电子材料」+24.51% 顶上，属**降质增长**。
  2. **收入回升的同时盈利能力系统性下移**：26H1 毛利率 **29.87%（四期最低）**、26Q2 单季 **28.81%（同比 −5.22pp）**；
     **扣非归母仅 +0.68%**，归母 +7.29% 的绝大部分来自非经常性损益（政府补助 2,533 万 + 公允价值 1,671 万）。
     **经营性利润基本零增长。** 旧档唯一的护城河正面信号（前驱体毛利率 +3.66pct）本期翻转为 **−1.45pct**。
  3. **估值分母错配 + 兑现窗口与定价窗口错位**：真半导体前驱体仅占总营收约 **25%**（FY2025 21.11/86.11），
     市场却按纯半导体材料股给 PE(扣非) **68.19x** / PB **8.16x**；而公司 2026-09-08 调研自陈
     「新增产能**明年下半年**才明显提升」，放量窗口在 **2027H2**，恰与其自己预告的
     **行业新增产能 2028–2030 集中释放**的价格下行窗口重叠。

> **先把旧档的两处过时表述纠正掉**（否则新档带事实错误发布）：
> ① **「26Q1 营收转负」已修复**——26Q2 **+16.78%**、H1 +5.12%，**本档不得再用此论据**；
> ② **「真实增长引擎是 LNG」已反转**——化学材料 **−1.30%**、合同负债 **−52.9%**，改写为「两条腿同时钝化」。
>
> 倒金字塔一句话：**营收回来了，定价权没回来。** 在 memory 市场 +302% 的半年里全线毛利率下滑，
> 就是这门生意此刻最诚实的体检报告——好平台、真受益（长期）、坏价格，而且比三个月前更坏。

**与兄弟档的差异化（举证责任，不得偷懒复制）**：同 subsector 四只兄弟档全部 exclude 且否决理由全是「价格」而非「生意」。
其中**华特气体档的核心判据在雅克身上反读**：雅克 2022 主营 42.59 亿 → 2025 86.11 亿，**CAGR ≈ +26.4%，五家中最优**。
**雅克的病不是「长期没增长」，而是「增长的来源与市场付费的叙事不一致，且价格跑在前面」**——
那条贡献历史 CAGR 的 LNG 腿 26H1 已转负。逐条对照见 [thesis.md §6.4](thesis.md) 与 [valuation.md §9.5](valuation.md)。

## §10 评级决策

### §10.1 判定

```
期望内在价值 88.6 亿  vs  实时市值 652.878 亿（盘中锚）
安全边际 = (88.6 − 652.878) / 652.878 = −86.4%   →   exclude
```

**估值方法为何与旧档不同**（诚实标注，避免被误读为基本面崩塌）：旧档用**整体单一倍数** 18x/28x/35x 乘整体利润，
而本标的最贵分部（前驱体，44.79% 毛利）与最便宜分部（显示光刻胶，16.72% 毛利）体量接近——
**单一 PE 必然是用最贵分部的倍数乘最便宜分部的利润**。本轮改 SOTP 后，
对称破框架测试判定**利润法整体失效**（bull 降回框架内 140.8 亿 < base 181 亿），
按 `buffett-doc-spec` §3 铁律改以**资产法（RIM/PB 阶梯）为主锚**。
三步桥接（概率重排 −25.7 / 方法变更 −174.3 / 华飞摊薄 −6.7）见 [valuation.md §9.4.5](valuation.md)。
**本轮下修中没有一分来自「基本面变差」的判断**——若沿用旧档口径，结论会是「安全边际约 −55%」，方向一样、幅度更轻。

### §10.3 买入 / 卖出阈值

- **Buffett 安全边际分档**：本案属「存在不确定因素」（传导滞后 + 认证门控 + 商誉 20.25 亿占归母净资产 25.32%
  + 40% 负债率契约 + 2029 前股本摊薄），应要求 **40–50% 折让**。
- **合理买点市值 ≈ 88.6 × (1 − 40%~50%) = 44–53 亿**，对应股价 **9.3–11.2 元**。
- **宽松观察讨论区**：市值 < **62 亿**（= EV × 0.7，恰为 bear 档值），对应股价 **< 13.03 元**。
- **诚实说明**：这些阈值意味着**本标的在可见区间内不会进入射程**。
  **exclude 在此处是终局判断，不是「等回调再买」的委婉说法**——若未来评级要翻转，触发它的应是
  §11 监控指标第 3 / 4 条出现实质反转（扣非脱离零增长 + 稼动率脱离 59.31%），而不是股价下跌本身。
- **卖出阈值（针对已持仓者）**：**当前价位本身即应减持**——现价高于 bull 内在价值 4.8 倍、
  高于全部 27 份研报中仅有的 2 个目标价（较最高 110.89 溢价 **+23.71%**）。硬触发见 §11。

## §11 关键风险 Top 5 + 监控指标 / 卖出触发器

### §11.1 关键风险

1. **【估值/行为·最大】叙事退潮与分母重估**：市场按「纯半导体材料龙头」定价，而真前驱体仅占营收约 25%。
   **PB 从 95.5 分位回到 5 年中位 4.27x 即为 −47.7%**，且这一步不需要基本面恶化，只需要认知修正。
   同时 27 份研报全「买入」却仅 2 份给价、**2026-05-10 后 4 个月无人再给价**——卖方在情绪上跟随、在定价上退出。
2. **【结构性】盈利能力持续下移**：26H1 综合毛利率 −1.95pp、26Q2 单季 −5.22pp、扣非 **+0.68%**、营业成本增速 > 收入增速。
   若新产能 2027 年转固而稼动率未爬起来，折旧 + 低毛利结构双杀，扣非可能由零增长转负增长。
3. **【时序·结构性】放量窗口与行业供给释放窗口重叠**：公司自陈存储线 2027H2 放量、两基地 2027 年底接近满产，
   而行业新增产能 **2028–2030 集中释放**（亦为公司口径）。**这是结构性问题，不是执行问题。**
4. **【资本结构·新增】三项连锁负债**：① **合并资产负债率 ≤40% 的隐性契约**（FY2025 已 42.60%、25H1 40.55%，
   突破即触发投资人回售/延续权，实质限制债务融资能力）；② **2029-03 前以发行股份回购华飞 45.94% 的摊薄**
   （投后 18.498 亿对应 2026 目标 3,000 万净利即 61.7x PE，而**华飞 26H1 净利仅 1,116 万、不足目标的 37.2%**）；
   ③ 少数股东权益已占所有者权益合计 **29.7%**，制造 PB 口径陷阱（见下）。
5. **【财务】商誉与汇率**：商誉 **20.2537 亿 = 归母净资产 25.32%**（UP Chemical 收购遗留），
   **26H1 减值测试结论【缺】**；韩国子公司利润含汇兑成分，**26H1 汇兑损益金额中报未披露【缺】**。

> **⚠️ PB 口径陷阱（本标的最易踩，引用前必读）**：26H1 少数股东权益 **33.85 亿，占所有者权益合计 113.85 亿的 29.7%**
> （华飞引入 8.498 亿外部投资人所致）。误用「所有者权益合计」作分母，**PB 会从 8.16 压到 5.73，凭空造出 29.7% 的估值折扣**。
> 市值只归属母公司股东，分母必须同口径剔除少数股东权益。任何看多/看空方引用「雅克 PB 才 5.7 倍」均属口径错误。
> 详见 [valuation.md §9.0.3](valuation.md)（含 A3 的 PB 6.00 为何判定为计算错误）。

| 10 | **一致预期是否被下修** | 2026E 归母 **13.30 亿（11 家）**，隐含 26H2 同比 **+61.0%**；另一路 13.91 亿（6 家）隐含 +74% | 中报后券商若不下修 → 说明卖方模型未吸收中报；若下修 → 「动态 PE 49.09x / 35x」的看多测算失效 |
| 11 | **商誉减值与安全环保尾部** | 商誉 20.2537 亿（归母净资产 25.32%）；5 家主体在环境信息披露名单；滨海雅克「其他产品尚未正式生产」 | 减值预告 / 处罚停产 / 资质受限 |
| 12 | **LDS 收入确认瓶颈是否解除** | 26H1 **−8.77%**，公司称订单在手、卡在阀门供应与装机验收 | 2026 年报未见追补 → 「认证=业绩」假设再添反例 |

### §11.3 卖出触发器（硬阈值）

- **立即减持（已触发）**：当前价高于 bull 内在价值、高于全部券商目标价 23.71%、PB 处 5 年 95.5% 分位。
- **加速减持**：26Q3 单季扣非归母同比**转负**（指标 3）；或电子分部毛利率**跌破 30%**（指标 2）。
- **结构性卖出**：合并资产负债率**重新越过 40%**（指标 5）；或商誉**减值预告**（指标 11）；
  或 2027 年报显示两基地**仍未接近满产**（指标 4，公司承诺节点被 miss）。
- **旧档触发器复盘**：旧档「资产负债率突破 50%」**阈值口径已作废**（真正的硬线是 40% 契约线）；
  旧档「前驱体毛利率连续两期下滑 >3pct」**已亮黄灯**（26H1 −1.45pct，未达 3pct 但方向已反）；
  旧档「商誉减值预告」**未触发**，敞口仍在。
