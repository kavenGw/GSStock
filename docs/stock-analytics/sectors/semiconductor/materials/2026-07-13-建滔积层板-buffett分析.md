### 2.2 跑道长度的结构性拆解（本节是全档最关键的定性判断之一）

一个成长故事需要一条跑道。建滔的跑道在哪里？只有两个可能的方向，**两条都是死路**：

**方向 A —— 在存量刚性 CCL 市场继续拿份额。**
已经是 14.7%、全球第一、连续 20 年。在一个 CR5 约 59% 的成熟大宗市场里，从第一的位置再抢份额，唯一的手段是**降价**。**份额跑道 ≈ 0，且任何份额增长都以毛利率为代价。**

**方向 B —— 在增量的 AI 高端 CCL 市场取得位置。**
份额 **2.3%**，排名第 8。M6 仍在验证，M8 才刚从送样进入小批量，**M9 仍处预研、尚未通过英伟达/华为认证**。而对手生益的 M8 已通过英伟达 GB300 认证、AI 服务器 CCL 份额 **>30%**。产业演进路径明确：H100 用 M7 → GB200 用 M8 → **2026 年 M9 级大规模放量**。
产业分析给出的判断一针见血：*"当 AI 服务器主战场还在 M6–M8 区间时，建滔是垂直一体化的王者；但当 CCL 等级被推到 M8–M9、M9–M10 时，这些高端等级所需的原材料建滔尚未形成垂直一体化布局，也未能打入核心客户的供应商认证体系。"*

> **即：AI 向更高等级演进的方向，恰恰是建滔的相对劣势方向。它不是在爬一条上升的跑道，而是站在一条正在被高端化绕过的跑道上。**

**⚠️ 数据缺口 C4**：AI 服务器 CCL 的 **TAM 绝对规模**未取得可引用的第三方数字（TrendForce/Prismark 均未检索到）。**因此本档不对 AI 高端市场做任何绝对金额的假设**，只用相对量化（AI 服务器 CCL 用量 = 普通服务器的 5–7 倍）作为需求方向的定性支撑。

### 2.3 那么，建滔的"跑道"到底是什么？

**是价格，不是数量。**

**价格跑道有到期日。** 机构一致口径：CCL 上行周期**保守预计延续至 2027 上半年**【软】；供应紧张局面**预计 2027 下半年才逐步缓解**【软】。

> **§2 结论**：这门生意的天花板不在份额（已是龙头），不在技术（高端无位置），而在**价格周期的长度**。给一个有明确到期日的价格周期以成长股估值，是范畴错误。

### 3.2 增长拆解：量 vs 价（**本档最重要的一张表**）

| 维度 | FY25 增速 | 相对营收的弹性 |
|---|---|---|
| 营业额 | **+10%** | 1.0x（基准） |
| 毛利 | +21.7% | 2.2x |
| **基本纯利** | **+85%** | **8.5x** |

**营收只涨 10%，净利涨 85%。这不是成长，这是经营杠杆。**

- 营收 +10% 中，**销量与价格的贡献未被公司拆分披露**，但公司自身在 2026-02 的 FY25 盈喜中明确归因于"**产品价格显著上升**，销量较 2024 年同期有所增加"——**价在前，量在后**。
- 从算术上：营收 +10% 而毛利率 +1.9ppt、净利率 +5.0ppt → **利润增长几乎全部来自单位价差的扩张，而非规模的扩张。**

> **这一条是全档估值逻辑的基石**：一个把 10% 的营收增长放大成 85% 的利润增长的经营杠杆，**在下行时是完全对称的**。FY22→FY23 净利从 1.91B 跌到 0.91B（**-52%**）——正是同一台杠杆反向运转的实证。

## §5 核心优势 / 护城河

### 5.1 护城河的真实来源：>85% 成本自供的四层垂直一体化【硬】

| 原材料 | 占 CCL 成本 | 建滔自产产能 |
|---|---|---|
| 铜箔 | **42.1%** | 11 万吨/年 |
| 环氧树脂 | **26.1%** | 15 万吨/年 |
| 电子玻纤布 | **19.1%** | 7–8 亿米/年 |
| **合计** | **>85%** | **全球屈指可数的四层（铜箔–树脂–电子布–CCL）全打通厂商** |

**这是真的，而且是全档唯一站得住的护城河论据。** 我要在这里**明确上修旧档的判断**：旧档称之为"窄护城河"，这**低估了它**。在一个大宗行业里，能自供 85% 成本的玩家不是"窄护城河"——这是 commodity 行业里**罕见地宽**的成本护城河。

**它的经济学机制（"利润截留"）**：当 AI 需求把上游（电子布、铜箔、树脂）全面推向紧缺时——
- 对**同业**（生益、南亚、EMC 等外购原料的厂商）：这是**成本打击**，毛利被上游吃掉
- 对**建滔**：这是**利润的层级截留**——上游涨价的利润不流出公司，而是在内部各层级被逐级留存

实证：电子布年内**第五轮**提价、均价 **7.4 元/米**、较 2025Q3 低点 **+100%**；台湾富乔 7-1 起 E-glass 电子布 **+30%**、Low DK2 **+15%**；PPE 树脂面临**断供风险**。**这些对全行业是成本，对建滔是内部转移定价。**

### 5.2 五类护城河检验

| 护城河类型 | 建滔状态 | 评估 |
|---|---|---|
| 无形资产 / 品牌 | **无** | CCL 是 ingredient 业务，下游认性能与价格，不认品牌 |
| **成本优势** | **是（核心，且被旧档低估）** | **>85% 成本自供 + 全球规模第一 + 中国成本基地。评级：中等偏强（在 commodity 行业里属最强梯队）** |
| 转换成本 | **弱** | PCB 厂可同时认证多家 CCL，切换周期 6–12 个月 |
| 网络效应 | **无** | — |
| 高效规模 | **弱** | 全球 7+ 玩家，CR5 仅 59% |

**护城河趋势判定**：
- **成本护城河：稳定 / 略微加宽**（韶关玻纤 2026H2、连州铜箔 2027 年中投产，自供层级进一步夯实）【硬】
- **技术护城河：持续变窄**（高端从 M6→M8→M9 演进，建滔在每一级都落后一到两个身位）【软】

### 5.3 Franchise vs Commodity 测试（Buffett 1991 三条）

> Franchise 需同时满足：(1) 客户需要/渴望；(2) **客户认为无相近替代品**；(3) 不受价格管制。

| 条件 | 建滔 | 判定 |
|---|---|---|
| (1) 客户需要 | ✅ CCL 是 PCB 的必需基材 | 通过 |
| (2) **无相近替代品** | ❌ **生益、南亚、台光电、EMC、联茂都做 FR-4。客户现在拿不到货，不是因为只有建滔能做，而是因为全行业都缺。** | **不通过** |
| (3) 不受价格管制 | ✅ | 通过 |

**关键的诚实**：建滔在半年内涨价 6 次、累计 >50%，客户全盘接受了。这看起来像定价权。**但它不是。** 客户接受，是因为**全行业同步涨价**（生益 +5–15%、富乔电子布 +30%、招商证券料 7 月 PCB 全品类 +20–30%），且**物理性缺货**（订单排满、交期拉长至 2–3 个月、实施限购）。

> ### **短缺不是特许经营权。**
>
> 特许经营权是"别人也有货，客户还是买我的，还愿意付溢价"。短缺是"所有人都没货，客户只好接受任何价格"。**前者在周期底部依然存在；后者在供给恢复的那一天蒸发。**
>
> **判定：Commodity（大宗）业务，具备强成本优势，但不具备独立定价权。** 这个判定，直接锁死了估值倍数的上限。

### 5.4 护城河的正确用法（本节的估值含义）

一条**成本**护城河和一条**定价**护城河，在估值上的作用截然不同：

- **定价护城河**（可口可乐）→ 可以支撑 **20–25x** 的倍数，因为它能穿越周期持续获取超额利润
- **成本护城河**（建滔）→ 只能支撑一个**相对于同业的倍数溢价**（比如同业 8x，它值 10–12x），因为它决定的是**"谁在寒冬里活下来、谁在繁荣里赚更多"**，而不是**"利润水平永远更高"**

> **成本护城河抬高的是正常化利润的地板，不是天花板。** 这正是本档 §9 把正常化中枢从 1.65B 上修到 3.2B、同时把 PE 上限锁在 12x 的全部理由。

## §6 核心新论点：本轮盈利爆发的机制拆解

### 6.1 机制链条（自下而上，逐环标证据级别）

```
AI 服务器需求爆发（用量 = 普通服务器 5–7 倍）【软，相对量化】
    ↓
上游全面紧缺：电子玻纤布（+100% vs 25Q3 低点）/ 铜箔 / 环氧树脂（PPE 面临断供）【硬】
    ↓
上游成本暴涨 → 全行业 CCL 厂被迫提价 → 常规 FR-4 一年 +330%（70 → 300+ 元/张）【硬】
    ↓
建滔 >85% 成本自供 → 上游涨价的利润不流出，在内部四个层级逐级截留【硬（机制）】
    ↓
经营杠杆放大：营收 +10% → 毛利 +21.7% → 净利 +85%（FY25 实证）【硬】
    ↓
FY26E 净利 5.07B（一致）～ 9.607B（花旗）= FY25 的 2.1～3.9 倍【软】
```

### 6.2 结构性 vs 周期性：**必做的二分判定**

| 要素 | 结构性（穿越周期存续） | 周期性（会回归） |
|---|---|---|
| >85% 成本自供、四层垂直一体化 | ✅【硬】 | |
| 刚性 CCL 14.7% 份额、连续 20 年第一 | ✅【硬】 | |
| 韶关玻纤（7 万吨纱 + 9600 万米布）2026H2、连州铜箔 2.1 万吨 2027 年中 | ✅【硬】 | |
| AI 带来的 CCL 需求量台阶（AI 服务器用量 5–7 倍） | ✅（方向）【软】 | |
| **FR-4 价格 +330%** | | ❌【硬】 |
| **"利润截留"的价差幅度** | | ❌【硬机制，周期性幅度】 |
| **净利率 7.2% → 12.2% → ~24%（FY26E）** | | ❌【软】 |
| **股息（FY21 1.50 → FY23 0.16 → FY25 0.68）** | | ❌【硬】 |
| **FY25 增长 100% 来自价格、0% 来自销量** | | ❌【硬】 |

> ### **二分判定：资产是结构性的，盈利水平是周期性的。**
>
> 建滔真的建成了一套罕见的四层一体化资产，这套资产在未来十年都会存在，并且会让它在每一轮周期里都比同业赚得多、在每一轮寒冬里都比同业活得久。**这值得把正常化利润中枢往上修——而且要修得实在。**
>
> **但它不改变一件事：这套资产赚的钱，是一个"价差"。而价差，是大宗商品世界里最周期的东西。**

### 6.3 **最强反驳前置：如果多头是对的呢？**（红线 6 —— 我必须先把敌人的枪擦亮）

**多头最强的论证是这样的**（我认为这是唯一值得认真对待的反方论点）：

> "你说这是周期，但你没看懂：**这一轮上游紧缺是 AI 驱动的、结构性的、多年期的**。电子布、铜箔、树脂的产能扩张需要 2 年以上，而 AI 需求在加速。所以'利润截留'的价差不是一个季度的事，是 3–5 年的事。在这 3–5 年里，建滔是**全球唯一**能吃到全部四层利润的玩家。花旗的 FY26E 9.6B / FY27E 14.3B 不是周期顶，是**新的常态**。你用 3.2B 做正常化中枢，会像旧档用 1.65B 一样被打脸。"

**这个论点有力量。它必须被逐条正面回答，而不是被"commodity 就该 8-12x"的口号敷衍过去。**

---

**反驳 (a) —— 价差是大宗世界里最周期的东西，没有之一。**

一个价差是两个价格的**差**。两个价格都是周期性的，它们的差是**双重周期性的**。建滔的一体化让它**捕获**这个价差，但**不创造**这个价差。价差由「上游紧缺程度」单方面决定，而建滔对上游的紧缺程度**毫无控制力**。

**更致命的是**：**建滔自己就是那个正在杀死自己价差的供给。** 韶关玻纤项目（7 万吨玻纤纱 + **9600 万米玻纤布**）**2026H2 投产**——建滔现有电子布产能 7–8 亿米/年，这一笔就加 **12–14%**。连州高端铜箔 2.1 万吨 **2027 年中**投产——现有 11 万吨，加 **19%**。

> **多头把扩产当成"确定的成长"（G1，证据【硬】）。但在一门靠短缺赚钱的生意里，扩产就是短缺的解药。** 建滔正在用 145 亿的资本开支，亲手拆掉支撑它 FY26 盈利的那根柱子。**这不是矛盾，这是大宗商品的第一定律：高价格治愈高价格。**

---

**反驳 (b) —— 传导链条的终点尚未被验证，而链条中段已经在冒烟。**

媒体明确记录了传导矛盾：**"原材料暴涨 — CCL 缺货 — 终端无法完全转嫁"**，**PCB 板块因此走弱**。谁最终为 FR-4 从 70 涨到 300 买单？这个问题**至今没有答案**。

更值得警惕的是当前需求的成分。业内引述：*"原物料堆在库房里，下个月就能升值，客户不接受涨价，我们不接单也能赚库存升值的利润"*——**部分 PCB 厂已经拒绝接单，转而囤货。**

> **一部分正在推高 CCL 价格的"需求"，不是终端消费，是 PCB 厂的库存投机。** 投机性库存需求在价格转向的那一刻会**反向变成供给**（去库存），这是大宗商品最凶残的加速器。**当我们看不到终端买单方，却看到中间商在囤货时，我们看到的不是繁荣的开始，是繁荣的末段。**

---

**反驳 (c) —— 供给侧能见度为零，而这恰恰是不能做多的理由。**（缺口 C3）

本次采证**未能取得**生益 / 台光电 / 南亚 / EMC / Fulltech 的 **2027 年产能投放规模与时点**的任何量化数据。只有定性口径："紧张局面预计要到 **2027 下半年**才逐步缓解"。

> **这里必须极度诚实：数据缺失不等于产能不存在，它等于"我不知道"。** 而在 FR-4 从 70 涨到 300 元/张的当下，地球上每一个 CCL 厂、每一个玻纤厂、每一个铜箔厂都在扩产——这是经济学的确定性，即使我拿不到数字。
>
> **在一门大宗生意里，用"我看不到供给"来支撑多头论点，是把无知当成安全边际。** 正确的做法恰恰相反：**看不到供给，就不能给 bull 情景高权重。**（这直接构成 §9.4 的 bull 概率门控。）

**反驳 (d) —— 最了解这个价差的人，已经卖了 145 亿。**

母公司建滔集团在 06-17 以 **11.5% 的折价**配售 1.55 亿股 @ **HKD 76.0**；4 名董事在 06-24/26 减持 236.45 万股，执行董事张国平的成交价是 **HKD 93.71**。年内累计套现约 **HKD 145 亿**（详见 §8.3）。

> **如果"利润截留"真的是一个 3–5 年的结构性红利，那么全世界最清楚这一点的人——拥有这四层产能、每天看着内部转移价格的人——为什么要在 76 块折价 11.5% 急售？**
>
> 花旗自己在 07-07 的报告里把 "Hallgain（母公司持股平台）减持" 列为股价下跌的**三大原因之一**。一份给出 130 目标价的报告，同时承认最大股东在卖。**这个内部矛盾，花旗没有解释，我也无法替它解释。**

### 6.4 §6 净判定

多头论点的**机制**是对的（利润截留真实存在，且被旧档严重低估），**幅度和持续性**是错的（价差会回归，且建滔自己的扩产正在加速这一回归）。

> **结论：把正常化中枢从 1.65B 上修到 3.2B（+94%）——因为资产是真的。**
> **但拒绝把 9.6B 当作常态——因为价差不是。**

## §7 AI / 概念潜力：逐维度打标

| 维度 | 判定 | 理由 |
|---|---|---|
| **常规 FR-4 涨价（占营收绝对主体）** | **【真敏感 —— 但是间接的商品周期溢出】** | AI 需求 → 上游全面紧缺 → FR-4 提价 → 一体化厂商截留。**这是建滔全部盈利爆发的来源，机制真实【硬】。但它是"AI 引发的大宗周期"，不是"AI 技术卡位"。它的估值属性是周期股，不是成长股。** |
| **AI 玻纤布（Low DK 电子布）** | **【真敏感 —— 但规模很小】** | 花旗口径：占建滔**总毛利** **6.9%（2026E）** → 17.4%（2028E）【软，卖方】。**当期不足 7%。这是目前唯一可量化的 AI 直接业绩敞口，而它太小，撑不起任何估值溢价。** |
| **铜箔 / 环氧树脂自供** | **【真敏感（成本端）】** | AI 拉动的铜箔/树脂紧缺，对建滔是内部利润，对同业是成本。**机制真实【硬】，但同样是周期性价差。** |
| **高速 CCL（M6 / M8 / M9）卡位** | **【蹭概念】** | **高端特殊 CCL 全球份额仅 2.3%（第 8 位）**；M6 仍在验证；M8 才从送样进入小批量（26Q3–Q4）；**M9 仍处预研，未通过任何客户认证**。对照生益：M8 已过英伟达 GB300 认证、AI 服务器 CCL 份额 >30%。**建滔在 AI 高速 CCL 上没有位置，把它当作 AI 高速 CCL 标的是错配。** |
| **PCB 中板 / CPO 高速互联** | **【蹭概念 —— 且是负敞口】** | 建滔不生产这些。Kyber NVL144 因**PCB 中板工艺瓶颈**延期至 2028，反而通过"CCL 增量 -8~16%"**打击**建滔。**这个维度对建滔只有下行，没有上行。** |

### §7 核心判定

> **建滔的盈利爆发，是 AI 需求引发的商品周期溢出效应，不是 AI 技术卡位的兑现。**
>
> 三个数字锁死这个判断：**高端特殊 CCL 份额 2.3%**（不是玩家）、**M9 未认证**（不在牌桌）、**AI 玻纤布占总毛利 6.9%**（业绩层敞口不足 7%）。
>
> **估值含义（红线 7）**：AI 概念**不进入 §9 的 owner earnings 基础**。§9 的正常化利润完全建立在 (i) 已兑现的一体化成本优势、(ii) 已投产/有明确时点的产能、(iii) 穿越周期的 CCL 需求量台阶之上。**M8/M9 若在未来兑现，是 bull 情景之上的免费期权，不是 base 情景的假设。**

## §8 周期定位

### 8.1 价格周期：在哪个阶段？

| 观察 | 读数 | 周期含义 |
|---|---|---|
| FR-4 价格 | 70 → 300+（一年 **+330%**），**6 月单月 +100%** | **加速段 / blow-off 形态** —— 大宗商品最陡的一段通常在末段 |
| 建滔涨价函 | 年内 **6 封**，7-1 单次最大 | 加速 |
| 交期 / 库存 | 排满、交期 2–3 个月、**实施限购**；M7/M8/M9 **零库存断货** | 极度紧缺 = 周期顶部区的典型特征 |
| 机构一致口径 | 上行周期"保守延续至 **2027H1**"；紧张"**2027H2** 才缓解" | **时间上已过大半** |
| **同业 2027 产能** | **【缺口 C3 —— 无任何公开数据】** | **供给侧能见度为零 → 无法量化见顶时点** |

**定性判定：上行周期的末段（加速期），但见顶的确切时点无法量化——因为供给侧数据缺失。**

### 8.2 估值周期：三个 PE 口径，读出三个不同的故事

| 口径 | 数值 @53.35 | 读法 |
|---|---|---|
| PE-TTM（FY25 净利 2.44B） | **68.8x** | 看起来极贵——但对周期股，trailing PE 在利润起飞前必然高，**信息量有限** |
| Forward PE（市场一致 FY26E ~5.07B） | **33.1x** | 仍然贵 |
| **Forward PE（花旗 FY26E 9.607B）** | **17.5x** | ← **这才是多头真正的论据，也是必须正面击穿的数字** |

> **"只有 17.5 倍，不贵啊？"——这是全案最需要想清楚的一句话。**
>
> 对一门**成长**生意，17.5x 确实不贵。但对一门**周期**生意，**17.5x 是付在周期峰值利润上的**。周期股估值的第一原则（Lynch 早已说透）：**周期股在 PE 看起来最低的时候最贵**，因为分母是峰值利润。经典的周期顶部纪律是：**对峰值 EPS 只付 5–8 倍**。
>
> 按此启发式：花旗峰值 9.607B × 6–8x = **57.6B – 76.9B** = **HKD 18.3 – 24.4/股**。现价 53.35 是它的 **2.2–2.9 倍**。
>
> **即便完全接受花旗最激进的盈利预测、并且承认它就是峰值，这只股票依然贵一倍以上。**（此为 §9 的独立交叉验证。）

**母公司持股：从 ~74%（旧档口径）降至 61.70%。**

**三层解读**：

3. **治理判定（Buffett Q7 一票否决检查）**：**不构成诚信问题**——减持合法、及时披露、用途明确。**但构成极严重的负面择时与信号证据。** 我不用它一票否决，我用它给 bear 情景加权。

### 8.4 事件二分：假利空 vs 真利空

| 事件 | 日期 | 判定 | 依据 |
|---|---|---|---|
| **英伟达"压价 PCB 10%"** | 06-23/24 | ❌ **假利空（已被官方辟谣）** | 英伟达官方回应：**仅对新批次/新客户个别议价，未实施硬性统一降价目标**。行业澄清：所谓"降价"实为成熟产品 **8–12% 的正常年降**。**情绪性杀跌，非基本面恶化。**【硬】 |

> **但**：它精准命中了**花旗 FY27E 142.75 亿 / FY28E 195.23 亿的外推**，也就是多头故事里"这不是周期、这是新常态"的那部分。**它杀的不是当期利润，是"周期能延长到 2028"的信念。** 这正是本档 bull 情景**不采用花旗 FY27/28 外推**的直接理由。

### 8.5 §8 综合定位

> **盈利的顶大概率还在前面（FY26H2 – FY27H1）；股价的顶大概率已经过去（107.20，06-23）。**
>
> **这种背离对周期股是常态，不是异常。** 股票在利润最好的消息传出之前见顶，因为市场定价的是**下一个转折**，而不是**这一个季度**。旧档在 91.85 判 exclude 时，恰好站对了这条规律的一边——即使它的算术是错的。

## §9 估值（场景加权）

### 9.1 正常化利润：**为什么必须上修，以及上修到哪里**

**先说旧档错在哪里。** 旧档取 FY22–25 四年均值 **HKD 1.65B** 作正常化基准。这个数字的问题不是"太保守"，而是**它对应的是一个已经不存在的公司**：
- 那四年里，韶关玻纤（+9600 万米电子布）和连州铜箔（+2.1 万吨）**都还没投产**
- 那四年里，AI 服务器对 CCL 的需求量台阶（用量 5–7 倍）**还没出现**
- 那四年里，上游电子布/铜箔/树脂**没有进入结构性紧缺**，"利润截留"机制**没有被激活到当前强度**

**用一个不含这些变化的均值去定价一个已经发生这些变化的公司，是系统性低估。这是旧档 exclude 结论虽然方向正确、但完全没有决策价值（内在价值 5.4，永远买不到）的根本原因。**

**上修的三个论据（每条回指 §5 / §6 的证据）**：

| # | 论据 | 证据 | 量化影响 |
|---|---|---|---|
| **U1** | **产能扩张夯实自供层级**（§5.1、§6.2） | 韶关玻纤 7 万吨纱 + **9600 万米布**（现有 7–8 亿米，**+12~14%**）2026H2 投产；连州铜箔 **2.1 万吨**（现有 11 万吨，**+19%**）2027 年中投产【**硬，有具体时点**】 | 自供覆盖的绝对利润基数抬升 **~10–20%** |
| **U2** | **一体化的相对成本优势在周期中枢持续兑现**（§5.1、§5.4） | >85% 成本自供、四层全打通，全球屈指可数【硬】 | 穿越周期的**净利率中枢**高于外购型同业，且在寒冬里不会跌到同业的水平 |
| **U3** | **AI 抬升了 CCL 需求量的地板**（§2.2、§7） | AI 服务器 CCL 用量 = 普通服务器 **5–7 倍**【软】；建滔以 14.7% 刚性份额自动承接量的增长 | **正常化营收基数**从 FY25 的 20.4B 抬升至 **~24–26B** |

**正常化利润的量化推导（base）**：

```
正常化营收基数  ≈ HKD 25B
   （FY25 实绩 20.4B + 韶关/连州产能贡献 + AI 驱动的 CCL 需求量台阶 [U1+U3]）

正常化净利率    ≈ 12.5–13%
   历史区间锚定：FY23 谷底 ~5–6%  ｜ FY24 7.2%  ｜ FY25 12.2%  ｜ FY26E 峰值 ~24%（花旗口径）
   → 穿越周期中枢取 12.5–13%，即"略好于 FY25"（FY25 是一个正常偏好的年份，非峰值）
   → 理由：一体化的成本护城河 [U2] 让建滔的周期中枢净利率高于外购型同业

正常化净利      ≈ 25B × 12.8%  ≈  HKD 3.2B      ← base 情景中枢
                （对照旧档 1.65B：+94%）
```

> **这个 3.2B 就是本档的"锚"。它比旧档高 94%，因为公司真的变好了。它比花旗的 FY26E 低 67%，因为价差会回归。红线 1（不许用周期顶利润定价）与红线 2（不许沿用失效的旧基准）在这里同时被满足。**

### 9.2 合理 PE：8–12x（成本护城河 commodity）

| 业务特征 | 适用 PE | 建滔符合？ |
|---|---|---|
| 宽护城河（定价权）+ 轻资产 | 20–25x | ❌ Franchise 测试第 (2) 条不通过（§5.3） |
| 稳固护城河 + 中等增长 | 15–20x | ❌ 无独立定价权；跑道是价格不是量（§2.3） |
| **成本护城河 + commodity + 强周期** | **8–12x** | ✅ **最符合** |

**在 8–12x 之内如何取值**（这是成本护城河唯一能兑现的地方，§5.4）：
- **Bear 8x** —— 周期下行时市场只肯给 commodity 谷底倍数
- **Base 10x** —— 给一体化的相对优势一个溢价（外购型同业约 8x）
- **Bull 12x** —— commodity 顶格，反映最强的成本地位

### 9.3 三情景（含周期存留现金）

**为什么要单独计入"周期存留现金"**：无论周期何时见顶，FY26（乃至 FY27）赚到的巨额利润是**真金白银**，按 ~50% 常规派息率（§3.6），另一半会**永久留存在资产负债表上**。这部分不该被"正常化利润 × PE"的框架抹掉——它是**已经赚到的、不会随周期蒸发的价值**。（当前股东权益 16.42B，BVPS 5.21。）

| 情景 | 假设（一句话） | 正常化净利 | PE | 核心价值 | + 周期存留现金 | 内在价值（市值） | **每股** | 概率 | 赋权理由 |
|---|---|---|---|---|---|---|---|---|---|
| **Bear** | 周期在 2027H1 如机构一致预期见顶；同业 + 建滔自身扩产（韶关 2026H2）压垮短缺；FR-4 从 300 回吐至 120–150；价差坍塌；PCB 厂投机库存反向去化 | **2.2B** | **8x** | 17.6B | **+2.5B**（FY26 按一致预期 5.07B、~50% 留存） | **20.1B** | **HKD 6.4** | **35%** | **供给侧能见度为零（C3）+ 内部人套现 145 亿 + 建滔自己的扩产正在杀死自己的价差 + 一部分需求是 PCB 厂囤货（§6.3 a/b/d）——这些不是尾部风险，是主线剧本，必须给足权重** |
| **Base** | 繁荣延续约两年（FY26 兑现**市场一致预期** ~5.07B，FY27 高位回落）后回归；正常化中枢按 U1/U2/U3 上修至 3.2B | **3.2B** | **10x** | 32.0B | **+5.0B**（FY26–27 累计留存） | **37.0B** | **HKD 11.7** | **45%** | **最高权重。它同时接受了"公司真的变好了"（中枢 +94%）与"价差会回归"（不是 9.6B）两个已被证据支持的事实，且盈利假设锚在市场一致预期而非卖方单一口径** |
| **Bull** | **花旗 FY26E 9.607B 大致兑现**；上游紧缺延续至 2028；M8 转量产、AI 玻纤布毛利占比爬向 17.4%；正常化中枢**结构性抬升**至 5.0B | **5.0B** | **12x** | 60.0B | **+8.8B**（FY26 9.6B + FY27 **平台化 8.0B**，~50% 留存） | **68.8B** | **HKD 21.8** | **20%（封顶）** | **见 §9.4 门控。且此处刻意 _不_ 采用花旗 FY27E 14.275B / FY28E 19.523B 的加速外推——那正是 Kyber 延期砍掉 8–16% CCL 增量的年份（§8.4）。bull 情景取"FY27 平台化 8.0B"，是 bull，不是幻想** |

**Σ 概率 = 35% + 45% + 20% = 100%** ✅

**期望内在价值** = 6.4 × 0.35 + 11.7 × 0.45 + 21.8 × 0.20
= 2.240 + 5.265 + 4.360 = **HKD 11.87 ≈ HKD 11.9/股**（对应市值 ~HKD 37.4B）✅ **算术自检通过**

### 9.4 **Bull 概率门控：成长证据包三要素**（红线 4）

在给 bull 任何权重之前，必须先检验支撑它的三根柱子：

| 要素 | 分级 | 证据 | 判定 |
|---|---|---|---|
| **(a) 扩产达产确定性** | **【硬 —— 有具体时点】** | 韶关玻纤 2026H2；连州铜箔 2027 年中；泰国持续增产；母公司 145 亿明确投向 PCB 扩产 | ✅ **通过** |
| **(b) 客户 capex 能见度（具名）** | **【缺 —— 缺口 C5】** | **未取得任何具名 PCB 大厂（胜宏 / 沪电 / 深南等）的 capex 或出货 guidance。** 客户增长只能**降级到终端兑底**（AI 服务器 CCL 用量 5–7 倍；北美 CSP capex）——**这是终端市场总量兑底，不是具名客户订单兑现** | ❌ **缺失** |
| **(c) TAM 跑道** | **【弱】** | 刚性 CCL 已是 **14.7% 全球第一**（份额跑道 ≈ 0，见 §2.2）；AI 高端特殊 CCL 份额仅 **2.3%**（增量市场无位置）；AI 服务器 CCL 的 **TAM 绝对规模【缺】**（C4） | ❌ **薄弱** |

> ### **门控推理**
>
> 三要素中，**(b) 完全缺失、(c) 明确薄弱，只有 (a) 成立。**
>
> **一个只有产能、没有客户能见度、没有跑道的成长故事，不配拿高权重。** 产能本身不是需求——在 commodity 里，产能恰恰是**供给**（见 §6.3 反驳 a：建滔自己的韶关扩产就在杀死自己的价差）。
>
> **因此：bull 概率封顶 20%，不得再高。** 并且在 bull 内部，我进一步**拒绝采用花旗的 FY27/28 加速外推**（14.275B / 19.523B），改用"FY27 平台化 8.0B"——因为那两年正是 Kyber 延期砍掉 CCL 增量 8–16% 的年份，而花旗的模型显然没有把自己 07-06 之后的这条新闻消化进去（它 07-07 反而上调了）。
>
> **对偶的诚实**：bear 拿 **35%** 的高权重，同样来自证据——供给侧能见度为零（C3）不是"未知的中性"，在大宗商品里它是**看空的理由**（§6.3 c）。

### 9.5 **交叉验证：两个独立方法**（避免单一框架自证）

**验证 A —— 周期峰值利润启发式**（§8.2）
经典周期纪律：**对峰值 EPS 只付 5–8 倍**。

| 峰值口径 | 6x | 8x |
|---|---|---|
| 花旗 FY26E **9.607B** | HKD **18.3**/股 | HKD **24.4**/股 |
| 市场一致 FY26E **~5.07B** | HKD **9.7**/股 | HKD **12.9**/股 |

→ **区间 HKD 9.7 – 24.4。现价 53.35 是其 2.2 – 5.5 倍。**

**验证 B —— PB 交叉验证**
当前 BVPS **5.21**，PB **10.24x**。即便把 FY26 的利润全部计入账面（一致预期 5.07B → 约 +1.6/股；花旗 9.6B → 约 +3.0/股），FY26 末 BVPS 也只有 **6.8 – 8.2**，届时 PB 仍为 **6.5 – 7.9x**。
一门 ROE 15.39%、重资产的 commodity 制造业，合理 PB 约 **1.5 – 2.5x** → **HKD 9.0 – 16.8/股**（按当前 BVPS 5.21 折算：7.8 – 13.0；按 FY26 末账面 6.8–8.2 折算：10.2 – 20.5，取中段）。

**三法汇总**：

| 方法 | 区间 / 中枢 |
|---|---|
| **场景加权（主）** | **HKD 11.9** |
| 峰值利润 6–8x | HKD 9.7 – 24.4 |
| PB 1.5–2.5x | HKD 9.0 – 16.8 |
| **收敛区间** | **HKD ~10 – 20** |
| **现价** | **HKD 53.35** |

> **三个互相独立的方法，全部落在 HKD 10–20。现价是这个区间上沿的 2.7 倍、中枢的 4.5 倍。这不是一个"估值方法选错了"的问题。**

### 9.6 **安全边际 —— 诚实面对"贵"**（红线 5）

| 对照基准 | 每股价值 | 现价 53.35 相对倍数 | 高估幅度 |
|---|---|---|---|
| **期望内在价值** | **HKD 11.9** | **4.49x** | **-77.7%** |
| Base 情景 | HKD 11.7 | 4.56x | -78.1% |
| **Bull 情景（最乐观）** | **HKD 21.8** | **2.44x** | **-59.1%** |

**Bull 情景压力测试（红线 5 要求）**：
> **即便花旗全对、即便上游紧缺延续到 2028、即便 M8 转量产、即便正常化中枢真的能站上 5.0B、即便给 commodity 顶格的 12x —— 内在价值也只有 HKD 21.8。现价仍是它的 2.44 倍。**
>
> **反推现价隐含了什么**：要让 HKD 53.35（市值 168.13B）在 12x 下成立，需要**正常化净利 HKD 14.0B**。那是 FY25 的 **5.7 倍**，比花旗最激进的 **FY27E（14.275B）** 只差 2%——**换言之，市场当前的价格，等于假设花旗的 FY27 峰值利润是永久的常态，并且再给 12 倍。**

> ### 我拒绝用任何理由稀释这个结论。
>
> 我在 §5 上修了它的护城河（从"窄"改成"commodity 行业里罕见地宽"）。
> 我在 §9.1 把它的正常化中枢上修了 **94%**（1.65B → 3.2B）。
> 我在 §9.3 额外加计了周期存留现金。
> 我在 §7 承认它的 AI 玻纤布敞口是**真敏感**。
>
> **做完这一切，它还是贵 77.7%。**
>
> **护城河上修不能稀释"价格太贵"。AI 想象空间不能稀释"价格太贵"。跌了 50% 更不能稀释"价格太贵"。** 一个从 107.20 跌到 53.35 的价格，唯一改变的事实是：它从"贵 5 倍"变成了"贵 4.5 倍"。

> **⚠️ 本档是给 1888 建档。本附录仅作"若要暴露于 CCL 主题，1888 是不是最优载体"的讨论，不构成对 0148 的建档或推荐。**

| 项目 | 数值（2026-07-13 10:57 盘中） |
|---|---|
| 1888 现价 / 市值 | HKD 53.35 / **168.13B** |
| **0148 现价 / 市值** | HKD 63.00（**-14.29%**）/ **70.67B** |
| **0148 所持 1888 股权市值** | 19.44 亿股 × 53.35 = **HKD 103.71B** |
| **0148 市值 ÷ 其持有的 1888 股权市值** | 70.67 / 103.71 = **0.681** |
| **→ 控股折价** | **-31.9%** |
| **0148 PE-TTM** | **16.06x** vs 1888 的 **68.8x** |

**读法**：**0148 的整个市值，只相当于它所持 1888 股份价值的 68.1%。** 市场对 0148 自有的 PCB、化工、地产等全部业务给了**负估值**。

**若必须暴露于 CCL 涨价主题**，0148 在算术上严格占优：**同一份 1888 敞口打 68 折，外加 PCB / 化工 / 地产业务白送，且 PE 仅 16.06x。**

**但三点必须写清楚，否则这个"发现"是危险的**：
1. **折价并非无理由**：0148 有自身的**债务负担与地产敞口**，这是控股折价长期存在且**可能永不收敛**的合理原因。这不是市场的错误定价，可能是对风险的正确定价。（关联交易占比 / 客户集中度**无公开数据**——缺口 C8。）
2. **折价不保护周期**：0148 今日同步 **-14.29%**（1888 -15.05%）。**折价对抗的是"公司层面的估值错配"，不是"行业层面的周期回落"。** 一门顶部周期生意打 68 折，仍然是一门顶部周期生意。
3. **本档对 1888 的 exclude 判定与此无关**：即便 0148 更便宜，也不能反过来使 1888 变得便宜。**"有更差的选择"从来不是买入的理由。**（这一点已计入 §10.5 卖出标准第 4 条：存在明显更好的机会。）

> 但请注意我说的是'最后一个饿死'，不是'永远不会饿'。
>
> 它赚的是一个**价差**。价差不是特许经营权。可口可乐即使在所有人都能买到可乐的年份里，依然可以比对手多卖三毛钱——那是特许经营权。建滔现在可以随便涨价，是因为**全世界都没货**。等货有了呢？而最讽刺的是——**它自己正在盖那座工厂。韶关那 9600 万米玻纤布，明年下半年就投产了。它在用自己的资本开支，亲手结束自己的暴利。**
>
> 至于'AI'——我看了它的数字：高端 CCL 的全球份额是 **2.3%**，最高等级的 M9 连认证都没过，而所有人挂在嘴边的 AI 玻纤布，占它总毛利的 **6.9%**。**你付的是 AI 的价钱，买的是 FR-4 的生意。**
>
> 现在说价格。我把它的正常化利润从 16.5 亿上调到 32 亿——上调了 94%，因为公司确实变好了；我还额外加上了这轮繁荣会存下来的现金。做完这一切，我算出来它值大概 **12 块**。它今天卖 **53 块 3 毛 5**。
>
> 它从 107 跌到 53，跌掉了一半。有人会说：'跌一半了，总该便宜了吧？'——**从一个泡沫价上跌一半，只是从贵 5 倍变成贵 4.5 倍。** 用前高做锚，是周期股杀死投资者最常用的那把刀。
>
> 最后一件事，也是最重要的一件事。**六月十七号，控股股东在 76 块，打了 11.5% 的折扣，急着卖掉 1.55 亿股。一个星期后，四位董事在 93 块 7 毛 1 卖了。他们今年一共套现了一百四十五个亿。**
>
> 这些人每天早上醒来，看的就是铜箔厂到覆铜板厂之间的内部转移价格。他们比花旗清楚，比我清楚，比市场上任何人都清楚这个价差还能挣多久。**而他们在卖。**
>
> 花旗给了 130 的目标价，然后在同一份报告里，把'大股东减持'列为股价下跌的三大原因之一。**这份报告自己都没能说服自己。**
>
> **我的答案是：不买。不是因为它是家坏公司——它是家好公司。是因为好公司加上坏价格，等于坏投资。**
>
> 我把买点写在这里：**7 块钱以下我会认真看，9 块 5 以下可以谈。** 如果它跌到 25 块以下，而且盈喜真的很强、同业还没扩产，我会把卷宗重新打开——**但那也只是重新开始看，不是买。**
>
> 在此之前，我什么也不做。**在周期的顶部，什么也不做，是一项被严重低估的技能。**」
