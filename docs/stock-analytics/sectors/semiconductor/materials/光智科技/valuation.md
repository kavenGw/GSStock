## §9.1 主锚方法判定：利润法重新准入（base/bull），bear 仍走资产法

旧档（2026-08-17）以资产法为三档主锚，原因是穿越周期的正常化扣非为负（2021–2025 五年扣非均值 −0.90 亿元），利润法给不出正数。本轮事实变了：

| 检验 | 旧档 | 本轮 | 判定 |
|---|---|---|---|
| TTM 扣非（25Q4–26Q3） | 2026Q1 年化 0.61 亿 | **0.927 亿**（−0.255 + 0.154 + 0.176 + 0.853） | 由负转正 |
| 9M 扣非 | — | **1.182 亿**（2021–2025 连亏序列终止） | 正 |
| 五年扣非均值 | −0.90 亿 | 仍 −0.90 亿（历史不变） | 穿越周期仍负 |
| 利润法 bull 降到框架内倍数后是否 < base | 是（旧档症状） | **否**（bull 16.47 元 ≫ base 4.05 元） | 不触发「改资产法主锚」铁律 |

处理：**base / bull 用利润法（正常化 owner earnings × 框架内倍数）**；**bear 的正常化利润 ≈ 0，利润法无解，仍按资产法 PB 定价**。这与兄弟档云南锗业的「bear 资产法 + base/bull 利润法」混合口径一致。每档都回查隐含 ROE 与 12% 股权成本的关系（§9.3 末列）。

**股权成本 12%（下限，不下调）**：旧口径净有息负债 17.49 亿元 = 归母 2.25 倍；宽口径再加 6.40 亿元长期应付款（滁州琅琊国资 5.137 亿明股实债，7 年回购、朱世会无限连带；售后回租 4.086 亿，扣一年内到期 2.421 亿）后为 23.89 亿元 = 归母 3.07 倍；零分红且依法不能分（合并未分配利润 −2.075 亿）；子公司刑事判决 + 两次监管处罚记录。12% 是对公司有利的取值。

## §9.5 期望内在价值与安全边际（算术自检）

```
期望内在价值 = 2.24 × 30% + 4.05 × 50% + 16.47 × 20%
            = 0.672 + 2.025 + 3.294
            = 5.991 元/股 → 5.99 元/股
概率校验：30% + 50% + 20% = 100% ✓
期望市值 = 5.991 × 1.39158 亿股 = 8.34 亿元（市值是其 32.5 倍）
安全边际 = (5.99 − 194.99) / 194.99 = −96.9%      【LOI 公告前锚 2026-11-06 收盘】
bull 单独压测 = (16.47 − 194.99) / 194.99 = −91.6%   （市价是 bull 的 11.8 倍）
```

期望值较旧档 4.52 元上调 33%（扣非转正让 base 从资产法 0.81× PB 回到利润法、bull 概率 +5pct），而锚价较旧档 256.00 元下跌 23.8%——两者相向而行，安全边际只从 −98.2% 收窄到 −96.9%。

### §9.5.1 base 双系数敏感性带（红外扣非口径 × 现金转化）

base 占期望值的 34%（2.025 / 5.991），而它依赖两个判断值：红外扣非取 0.70 亿、现金转化取 0.70。逐项放开（bear / bull 不变，先锐存量腿均为 0.106 亿）：

| base 设定 | base 每股 | 期望内在价值 | 安全边际 |
|---|---|---|---|
| 红外 0.70 亿 × 现金转化 0.50（Q3 式转化持续） | 2.90 元 | 5.42 元 | −97.2% |
| 红外 0.659 亿（H1 年化，干净口径）× 0.70 | 3.85 元 | 5.89 元 | −97.0% |
| **红外 0.70 亿 × 0.70（本档采用）** | **4.05 元** | **5.99 元** | **−96.9%** |
| 红外 0.70 亿 × 1.00（不打现金折扣） | 5.79 元 | 6.86 元 | −96.5% |
| **不打折**：红外取 9M 年化 1.576 亿、现金转化 1.00 | 12.09 元 | 10.01 元 | **−94.9%** |

**结论对这两个系数不敏感**：把两个折扣全部拿掉（且红外按 9M 年化，已接近 Q3 混口径的上沿），安全边际仍是 −94.9%。0.70 亿的红外口径与 H1 干净年化 0.659 亿只差 0.04 亿，打折依据主要靠后者，而不是"TTM 打 25%"这个拍数。
