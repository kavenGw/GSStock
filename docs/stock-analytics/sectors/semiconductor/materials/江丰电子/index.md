# 江丰电子（300666）— 2026Q3 重审

## §0 · 结论摘要

**评级watch，当前价不买入。** 期望内在价值**18.20元/股、50.2247亿元**；对2026-10-29 13:35:15盘中**163.69元、451.74亿元**，安全边际为**−88.88%**。报价不是收盘价，总股本275,971,083股。三档每股价值**8.69/18.83/30.88元**；模型反映保守现金与资本回报假设，不能当精确目标价。[完整估值、SOTP与敏感性](valuation.md)

- bear **30%**：延期、原料与利用率冲击令扩张无法充分转成股东现金。
- base **50%**：Q3改善延续，存量客户与零部件支撑增长，但不把季度高点或新品试制当常态。
- bull **20%**：既有产品份额提升和爬坡改善兑现；达产、公司锁单与SAM证据仍缺，限制赋权。[论点与成长门控](thesis.md)

Q3扣非与OCF恢复真实，旧“零部件修复仅叙事、凯德未交割”须纠正；技术认证壁垒也仍成立。较旧档约89元估值的大幅下修，主要含**现金口径、经济回报倍数和折现的方法修订**，不能解释成最新财报让业务价值暴跌。逐步贡献和旧假设逐条更新已列于[变化桥与清单](valuation.md)。

## §10 · 评级决策：看增长，也要求价格与现金回报

本次仍为watch，理由是持续经营与认证价值值得跟踪、尚无诚信否决证据，但股东现金回报未充分验证且现价过高，不能升级config/core。现归母TTM PE49.65倍、扣非TTM90.20倍、PB5.96倍；低于部分同业并不等于绝对便宜。财报窗口、归属、现金和可比局限见[§3/§4](business.md)、[§9](valuation.md)。

**买点条件**：按本模型18.1993元期望值与安全边际=(价值−买价)/买价，要求≥40%时观察价不高于**13.00元**；同时须确认增长非一次性、现金条件满足且偿债/融资压力可控。价值参数若更新，应同步重算门槛，价格到达不构成自动买入。当前分析无法获得足够精度，不以单一估值数字替代经营验证。[参数及误差带](valuation.md)

**旧PE<35倍条件保留**：新归母TTM对应约115.38元/318.42亿元，目前未触发；若另看扣非TTM的35倍约63.52元，应标作补充口径，不能倒改旧规则的分母。两者仅估值复核条件，不是独立现金估值通过。旧40—47元固定买点不机械沿用。

即使把旧2028年15亿元利润直接当现金收益、给35倍高成长估值并按12%折现，约148.70元；再给最乐观投资SOTP也约153.72元，仍低于现价。这是明显超出本股当前已证经济回报的压力测试，不能进入主情景；20—25倍也不是对所有宽护城河成长企业一概禁止。[高倍数压力与反向要求](valuation.md)

四项卖出条件逐条核对：

|条件|本次判断|决策含义|
|---|---|---|
|价格严重超过内在价值|**是**，主模型与宽松压力测试均缺安全边际|不新增；已有持仓需按组合、税费和替代机会评估兑现价值，持仓未知，不给固定减仓比例|
|基本护城河被根本破坏|**未证实**，客户认证与批量业务仍存在|不把价格下跌或单季波动当护城河永久毁损；观察技术与经济回报分化|
|管理诚信问题|**未触否决线**，但关联采购、更正与平台归属需核验|若出现财务造假、严重欺骗或利益输送硬证，立即退出投资论点|
