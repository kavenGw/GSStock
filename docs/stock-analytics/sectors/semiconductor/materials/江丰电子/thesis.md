# 江丰电子 — §6–§8 论点与周期

## §6 · 核心新论点：增长已发生，收益归属与达产仍须兑现

**最强反驳前置**：客户景气与国产替代不会自动变成股东现金。江丰扩产延期，JX也在韩国扩产；同业一起增加供给，认证可能保护在位国际厂商。客户双供与让价可换份额却损伤回报，不能把“认证难”直接等同“可以持续提价”。

### 逐项传导与反证

|主体/论点|已核证据与传导|反驳与判定|
|---|---|---|
|江丰靶材|H1收入16.7074亿元、同比26.08%，毛利31.77%；具名台积电、中芯国际、SK海力士客户，公司称先进节点产品已批量应用|认证沉淀是结构性；具体客户—料号—节点采购量、独供份额与先进节点收入均缺，不宣称全面替代或唯一3nm。成本传导/补库存仍有周期性|
|精密零部件|H1收入6.4504亿元、同比40.59%，毛利23.97%，修复已有报表支持|同比毛利仅+0.32pct；不能以2025全年14.88%制造同比+9.09pct。新设备配套与更换需求并存，份额扩张与景气贡献缺量化拆分|

|JX|7/23官方宣布韩国加工扩产约40亿日元，FY2027下半年分期投运，加工能力较FY2025约翻倍；10/28宣布日本残靶回收设备投资|既验证先进存储需求，也增加竞争与原料保障；加工能力不是全球成品总产能翻倍。直接反驳“国际供应商全面退场”|

来源：[S1/S2/S5/S9](sources.md)。国产替代属于结构性机会，金属涨价与补库存属于周期因素；已实现增长中两者各占多少未披露，不能二选一硬判为纯周期或不可逆新台阶。

表据更正H1 p26—27。投入比例不是物理完工率或达产率。韩国最新拟用募集资金2.56亿元，不机械沿旧3.5亿元额度；位于龟尾，纠正旧“牙山”。现有惠州/武汉显示靶材项目可用后仍须认证且效益未达预期，是公司自身“建成≠赚钱”的反例。[S2/S10](sources.md)

替代进度按三档回应：**量产供货**已有靶材业务和公司先进节点批量应用自述，H1靶材总收入16.7074亿元，但不能把总额等同先进节点收入；**认证未放量**的各新客户/料号名单与对应收入【缺】；**送样/试制**ESC首枚试制下线仅有9/30媒体转述，未获本次客户验收原件，收入体量【缺】，不当成已量产。三档收入不能编造填满矩阵。

### 成长证据包：具名客户先行，订单传导另核

- 扩产达产确定性：建设与资金【硬】，已延期【硬】，完整达产/爬坡/增量收入【缺】。
- 客户能见度：台积电10/15官方维持2026 capex 600—640亿美元；SK海力士10/28官方称2027—2028超过一半产能签长协、HBM4和服务器产品增长，均为客户层【硬】。江丰对应采购金额/份额/锁单【缺】，不把客户长协写成江丰长协。中芯最新稼动率与采购金额本次【缺】；三星是韩国基地目标客户，未核到锁定订单。[S11](sources.md)
- TAM跑道：同年同地域、半导体细分SAM与江丰收入分子【缺】，不能用旧25%份额推算剩余75%空间。

因此bull概率20%，不是把全部产线与全部AI市场同时满产。现价451.74亿元已要求远超现扣非的持续现金收益，成长没有消除价格约束，详见[§9](valuation.md)。

## §7 · AI与概念：产品能力到股东利润的距离

|维度|产品/业绩证据、竞争与节奏|判断|
|---|---|---|
|先进逻辑与存储靶材|有先进节点批量应用、具名全球客户，工艺步骤与晶圆投片增长可增加耗材需求；JX同样在HBM链扩产。AI/HBM专属收入、订单、江丰份额及放量时间表【缺】|【真敏感】产品确在相关工艺链，收入方向敏感；AI增厚尚不能单独量化，不称纯AI业绩股|
|精密零部件|H1增长已兑现，但AI设备配套/存量更换各占比缺；不能把6.4504亿元都称AI收入|【真敏感】随设备和运行需求传导，但AI归因无量化硬桥|
|ESC新品|仅软证试制下线，募投可用2028-06-30不等于客户验收；无可核收入、在手订单与毛利|【蹭概念】若宣传AI利润已兑现即越界；技术期权保留，不进入已实现OE基础|
|AI挤占海外产能形成独占缺口|未见江丰财报/CEO具体归因或实际转单数量；JX扩产是反证|【蹭概念】缺已发生供给缺口证据，不构造套利利润|

AI终端TAM不能替代材料SAM。Gartner 2026Q2资本开支展望、WSTS春季半导体预测均为官方站可核的**机构预测【软】**：前者看AI投入且提示周期暂停，后者统计全半导体销售额，统计口径不同，无法做同口径分歧比较；AI靶材专属TAM与机构分歧【缺】。不把宏观金额写进江丰收入预测。[S12](sources.md)

兑现监测应从“首枚、认证”升到实际量产客户数、验收、收入和收款。尚未披露AI收入占比，不能设一个假基线再称跌破；一旦首次披露，以同口径同比转负或占比较初始基线下降≥5pct作为复核假设。当前估值不另计ESC或AI/HBM专属未兑现利润，亦不因AI标签提高合理倍数。

## §8 · 周期定位：改善期，尚非已证穿越周期新台阶

正面：Q3扣非2.2733亿元、同比94.23%，OCF5.5112亿元、综合毛利31.93%；Q3收入环比+20.68%，扣非环比+182.11%，已明显恢复。反面：Q2毛利27.79%、现金转换43.42%曾触线，H1靶材毛利同比下降1.49pct，存货与应收增加；一次性、并表/出表、原料和预收款均干扰表面增长。FY25 Q4综合毛利22.76%也提示季节性与结构扰动，不能拿Q1或Q3单季外推。

靶材首先跟随晶圆厂**实际稼动率、投片与工艺耗用**，设备capex只是前导；零部件同时跟随新设备和存量更换，二者周期相位不同。主要客户当期稼动率及江丰订单弹性缺同口径数据，不预设固定时滞。

压力情景明确是分析假设：售价不变、出货下降20%，基期收入R、毛利率m，固定成本F不变时，新毛利率=m−0.25F/R；若F/R=10%/20%/30%，毛利率分别下降2.5/5.0/7.5pct。Q3 31.93%据此可降至29.43%/26.93%/24.43%，跨旧28/25线；F未披露，这不是公司精确成本预测。单独新增折旧若相当收入1%/3%，毛利率约受压1/3pct。原料涨价若未及时转嫁则更差，转嫁时滞、锁价和年降条款均【缺】。因此不确认已经周期见顶，也不确认利润永续上台阶；以后续现金与资本回报证伪。[监控与旧触发对账](index.md)
