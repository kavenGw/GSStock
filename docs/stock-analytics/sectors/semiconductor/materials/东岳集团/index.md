## 0 · 结论摘要

**评级：watch（不买，但已从"远远不买"进入"值得盯"）。相对旧档（2026-06-09 watch）——基本面结论明确上修，估值/动作结论不翻转。**

### 10.2 旧档买点条件「两个前置条件已成其一」的裁定（必答）

旧档设的买入触发是二选一：① **PB < 1.5x**；② 生益/沪电/深南年报或投关**具名披露**东岳为 PTFE 供应商。

- **条件①：已达成**。PB（归母口径）= 202.34 亿 RMB ÷ 152.157 亿 RMB 归母权益 = **1.33x**（腾讯 1.32x 交叉一致）。达成路径是**股价跌**（−42.6%）而非账面值涨（归母权益仅 +5.83%）。
- **条件②：未达成**。A2/A3 分头检索生益科技、南亚新材、华正新材、中英科技四家 2026 中报与投关，**无一家具名其 M10 PTFE 树脂来源**；反向还出现指向昊华/晨光院「国内唯一通过英伟达 M10 认证」的软证据（详见 [§7](thesis.md)）。
- **本档裁定：PB<1.5x 这条触发器本身设错了，降格而非执行。** 理由有三：① 它是**估值便宜度的代理指标**，而本档已能直接算安全边际（−36.9%），代理指标与直接测算冲突时以直接测算为准；② 1.33x PB 对应的隐含定价并不便宜——按本档 base 情景，公允 PB 仅 **0.96x**（见 [§9](valuation.md) 隐含 ROE 阶梯），1.33x 仍高出 39%；③ PB 阈值对周期股天然失真，账面净资产里含着 2025–2026 周期顶留存收益，**周期顶的 PB 分母本身是虚高的**。
- **处理方式**：把 PB<1.5x 从"买入触发器"**降格为"进入观察窗口的必要非充分条件"**——它已经做了它该做的事（把这只股从"不必再看"拉回"每季度复核"），但不构成买入信号。买点改由期望内在价值折让直接裁决（见 10.3）。条件②保留为唯一的 **bull 上调硬触发**。

### 10.3 买点 / 卖点阈值

- **买入触发（估值腿）**：市值回落至 **104–119 亿 HKD**（**每股 6.0–6.9 HKD**）——对期望内在价值 149.0 亿取 30% 折让为 104.3 亿；对 base 单档 170.6 亿取 30% 折让为 119.4 亿。周期股 + 少数股东漏损 + 无稳定股息 → 按 buffett 安全边际阶梯属"存在不确定性因素"档，30–40% 折让是下限而非上限。
- **买入触发（逻辑腿，可替代估值腿部分折让）**：任一 CCL 厂（生益/南亚/华正/中英）在年报、投关或供应商大会中**首次具名**东岳为其 M10 PTFE 树脂来源【硬】→ bull 概率可自 20% 上调、bull 定义可重写，届时重算。**这是唯一能上调 bull 的硬触发。**
- **不追的理由（对未持仓）**：现价 13.620 HKD 已高于 base 每股 9.85，接近 bull 每股 14.14。买在现价 = 押注 bull 情景兑现且不要任何折让。

### 10.4 为何不做 SOTP（对齐昊华档口径的显式说明）

同板块的[昊华科技](../昊华科技/index.md)（2026-08-29 重做）以 SOTP 而非单一 PE 作主锚，理由是四分部合理倍数跨度过大（周期化工 10–15x vs 半导体材料 60–100x）。**东岳不适用**：
1. **倍数跨度小**：制冷剂、含氟高分子、有机硅三条腿在本档均判为**周期化工属性**（含氟高分子的增长归因是"提价 + 锂电/高端需求回暖"，不是 AI 订单——见 [§7](thesis.md)），合理倍数跨度 8–13x，做 SOTP 与整体法结果差异在噪声内。
2. **方向性声明（这样处理偏保守）**：整体法把东岳硅材那 44.40% 权益隐含地当作「不为东岳集团股东创造独立价值」——因为本档全程用归母口径，少数股东那部分利润已被剔除，而其对应的**权益市值并未作为资产单列回来**。若做 SOTP 把该权益按东岳硅材市值×持股折现回来，base 内在价值会**高于**本档的 170.6 亿。**即本档的不拆分是一个方向明确的保守处理，可能低估 base，不可能高估。** 之所以仍不拆：中期业绩公告**不含分部资产负债表**（须待 9 月底中期报告全文），SOTP 的分部资本回报无法计算，只能拿分部业绩配倍数——那等价于加权整体法。
3. **主锚选择**：本档主锚是 **PE（归母口径）× 正常化利润**，以 **PB / 隐含 ROE 阶梯**作交叉验证（两条路径在 base 档给出 170.6 亿 vs 隐含 PB 0.96x，互洽）。

### 10.5 卖出标准逐项检查

1. **价格严重高估？** —— **是（对内在价值而言）**。期望值 149.0 亿对市值 236.0 亿，−36.9%；bull 245.0 亿仅 +3.8%。但强度较旧档（bull 都 −34.5%）**明显减弱**：现在 bull 已能覆盖现价。
2. **基本面护城河被破坏？** —— **否，且部分加宽**。配额牌照未松动（2027 征求意见稿零削减 = 存量份额锁定）；一体化程度首次量化坐实（制冷剂分部 28% 收益内供 PTFE）。见 [§5](business.md)。
3. **管理层诚信问题？** —— **否，但治理评级下调**。无诚信红旗（2026-07-09 盈喜"超过 31%"对实际 +31.80%，预告精度高，是正面信号）；但董事长张建宏兼任主席与行政总裁、公司明确披露不遵守企管守则 A.2.1（中报 p.27），直接+间接持股仅 15.35%，联营公司未来材料第三次科创板 IPO 于 2026-06-30 撤回（问询涉实控人变更真实性与隐形关联质疑【软】），无回购反有 3.28 亿 HKD 信托减持。**护城河表"民营家族治理"由中-高下调至中**（见 [§5](business.md)）。
4. **存在显著更好机会？** —— **可能**。买配额主线 A 股[巨化](../2026-05-08-巨化股份-buffett分析.md)三代份额更大（37.7%）；买 AI-PTFE 则[昊华科技](../昊华科技/index.md)在市场共识中是第一顺位。
