# 东岳集团 — §1 能力圈 / §2 市场规模 / §3 盈利能力 / §4 全球竞争力 / §5 护城河

## 1 · 能力圈 & 本次重审触发

**边界区，偏内圈**（较旧档持平，但确定性提升——本轮拿到了旧档全部【缺项】的硬数）。

**一段话说清怎么赚钱**：东岳在山东淄博建了一条从**萤石 → 氢氟酸 → 单体 → 下游产品**的完整氟硅化工链。利润主引擎是**含氟制冷剂**（R22/R32/R125/R134a）——这门生意的本质是**政府发牌照**：蒙特利尔议定书/基加利修正案把每家企业每年能生产多少吨制冷剂用配额锁死，东岳拿到 R22 全国第一、R32 全国第二的配额，所以它**卖不了更多，只能卖更贵**。第二条腿是**含氟高分子**（PTFE/PVDF/FKM），第三条腿是**有机硅**（通过控股 44.40% 的东岳硅材），另有二氯甲烷及烧碱、含氟功能膜（PEM）。**一体化的价值本轮首次被量化**：制冷剂分部约 **28%** 的总收益是内供给含氟高分子做原料（R22→TFE→PTFE），即它自己的配额产品同时是自己下游的原料。

**本次重审触发**：
1. **H1 2026 中期业绩公告（2026-08-20）**——旧档的**三条核心负面假设被逐条证伪**（制冷剂接近顶 / 含氟高分子下滑 / 有机硅亏损），且旧档全部财务【缺项】（PB / ROE / 资产负债率 / OCF / FCF / capex / 投产表 / 回购）**全部补齐**。
2. **股价形态质变**——自 2026-06-23 高点 **23.74 HKD** 回撤 **−42.6%** 至 13.620，**旧档买点条件之一 PB<1.5x 首次达成（1.33x）**。
3. **政策面证伪**——2027 年度配额征求意见稿（2026-08-24）确认三代**零削减**，旧档"2026 收官年后进削减期"的紧缺加速叙事不成立（详见 [§6](thesis.md)）。
4. **汇率口径失效**——CNY→HKD 由旧档的 ×1.08 变为 **×1.1663**（+8.0%），所有 HKD 计价内在价值须重算。
5. **旧档硬伤**——CGF218H/K 牌号归属错误（实为昊华科技/中昊晨光院），须删（详见 [§7](thesis.md)）。

**inversion（亏钱路径，四条——第四条为本轮新增）**：
1. **制冷剂价格见顶回落** → 周期顶利润不可持续。（旧档已有，**未推进**：价格 Q3 仍在涨。）
2. **PTFE-M10 远期期权落空**（路线赛马输给 M9+Q 布或南亚方案 / 被昊华截胡）→ 题材溢价蒸发。（旧档已有，**未推进也未兑现**，但**被稀释**——供应商扩至三家 + 国内三强并列。）
3. **港股流动性折价长期压制估值**，"业绩兑现股价不动"。（旧档已有，**已实质发生**：中报创新高而股价自高点 −42.6%。）
4. **【新增】原料成本吞噬配额提价红利**——萤石 2026-08 突破十年天花板 3,250–3,800 元/吨，制冷剂售价创十年新高的半年里分部业绩只 +20.99%（三条腿最慢）。**这是 H1 已经在发生、而旧档三条路径都没覆盖的真实亏损机制。**
5. **【新增·口径型】少数股东漏损**——弹性最大的有机硅由控股 44.40% 的东岳硅材承载，本期利润增量的 **57.1%** 不归你。"第二引擎越好、漏损越大"是一条结构性而非周期性的亏损路径。

**诚实声明（本轮仍存的【缺】项）**：商誉减值 1.595 亿的分部/子公司归属；2027 年度配额正式方案与 R22 内用配额逐项数字；R125 连续现货价格序列；东岳作为 M10 PTFE 具名供应商的任何硬证据；H1 2026 完整现金流量表与分部资产（须待 9 月底中期报告全文）；FY2024 年末归母权益（故 FY2025 完整年度 ROE 不给点值）；**各分部销量（吨）——公司从不披露，故量价拆解只能定性**。完整清单见 [§12](sources.md)。

| 业务线 | 东岳地位 | TAM / 跑道 | 天花板性质 |
|---|---|---|---|
| **制冷剂（HFC/HCFC 配额）** | R22 配额全国 **#1**（2026 年度 4.30 万吨）/ R32 **#2**（山东东岳绿冷 56,312 吨 ÷ 全国 281,520 吨 = **20.00%**，首位浙江衢化 99,456 吨）/ 三代合计 #4（10.2%） | **配额硬锁产量，量无增长空间**；三代 2024–2028 基线冻结、2029 首削 10%；二代 R22 生产配额 2026 再削 3,000 吨 | **硬天花板**——靠价不靠量。**且 2027 起连"收紧推价"这个变量也被冻结** |

**跑道长度判定**：东岳的增长本质是**价格弹性而非内生量增长**。制冷剂作为占分部业绩 **63.2%** 的利润主引擎，是配额硬天花板——量已到顶，只能靠价；而 2027 配额征求意见稿把"配额收紧推价"这一变量也冻结到 2029。**H1 2026 的 R32 扩产 4.9 万吨/年已投产——⚠️ 新增的是产能不是配额**，配额锁死内用产量，新产能主要指向出口配额与替代/检修弹性，公告原文只说"为本集团应对制冷剂未来市场变化提供了有力的保障"，**未给任何量增指引，不得据此推"量增逻辑成立"**。距天花板：行业 CR3≈66%、6 家三代配额合计 91.2%，寡头格局已成型，份额增量空间小。

### 3.3 增长拆量价与增长质量（x-growth lens 落点）

**旧档"增长全部来自价、不来自量"→ 部分证伪，须改写为**：

> **「利润弹性仍主要来自价——管理层对三个分部的归因（p.20–22）全部是价格，无一提销量；但收入端已由近零增长转为 +7.99%。」**

判据：① 收入 +7.99%（对比 FY2025 的 +1.2%、FY2024 的 −2.15%），三大主力分部收入齐涨 +10.35% / +12.69% / +12.06%，剔除二氯甲烷及烧碱 −26.82% 的拖累后为 **+11.7%**——"营收近零增长"这半句**已不成立**；② 收入增速仍**远低于**毛利增速（+37.93%）与分部业绩增速（+38.51%）——"增量利润来自价"这半句**仍成立**；③ **各分部销量（吨）公司从不披露【缺】**，量价拆解只能靠管理层归因定性 + 收入/溢利率反推，**无法给出量的硬数**。

**增长质量**：毛利率 29.11% → **37.18%（+8.07pct，创历史高）**，增长伴随毛利改善 → 属"有质量的增长"而非烧钱扩张。**但质量的来源是价差扩张而非规模效应或产品结构升级**（管理层归因全是价格），而配额锁量意味着**价一回落即反向**。**H1 的 +31.80% 不得年化外推**——它是价格弹性不是产能弹性。

- **2026 中期不派息是惯例延续，不是新增负面**——2025 中期同为「無」，东岳历来只派末期息。**不得写成"净利 +31.8% 却一分不派"的指控。**
- **顺周期派息，非稳定高息品种**：股息随景气同向大幅波动（0.14 → 0.34 → 0.10 → 0.10 → 0.30），**无平滑迹象、无最低派息承诺【缺】**。交叉验证：券商 2022–2024 年股息预测为 0.66 / 0.79 / 0.80 HKD，而 **2024 实际仅派 0.10 HKD（预测的 1/8）**——连专业机构对东岳派息能力的外推都被现实证伪。
- **派息覆盖**：FY2025 派息总额 4.70 亿 RMB 对 OCF 37.06 亿 / 归母 16.42 亿，覆盖充裕（28.6%），**可持续性无问题**——问题不在能不能派，在愿不愿意平滑地派。
- **回购：无**【已核实】。反而有全资子公司作为受托人在二级市场**出售 22,266,000 股（原僱员购股权计划持股，该计划 2024-09-27 已终止），代价约 3.28 亿 HKD**（p.27）。
- **股东回报率 = 股息率 2.20%（0.30 ÷ 13.620，TTM）+ 回购 0% = 2.20%**，**低于港股无风险利率与恒指平均，在高股息价值股判据上不达标**。
- **双面必答 · 可持续性**：0.30 HKD 对应 28.6% 派息率，但**分母是周期顶利润**。若制冷剂价格回中枢，同样派息率会让绝对股息回落至 0.10–0.15 HKD 量级（= 2023/2024 实际水平），按现价股息率降至 **0.6%–0.9%**。**现在这个 2.20% 是周期顶的数字，是股息率的上界而不是中枢。**
- **双面必答 · 价值陷阱信号**：**不适用**。股息率不高不是因为削减分红，而是因为股价此前大涨（年内仍 +29.5%）。这是"贵"的信号而非"陷阱"的信号。
- **结论：股息价值型买入理由不成立，明确否决。**

## 4 · 全球竞争力

- **制冷剂（配额特许）**：R22 生产配额 2026 年度 **4.30 万吨居全国 #1**（巨化 3.81 / 梅兰 3.02 / 阿科玛 0.86 / 三美 0.77），R22 产能 ~22 万吨为**全球最高**；R32 配额 **56,312 吨 / 全国 20.00% / #2**（首位浙江衢化 99,456 吨，旧档记 20.09%，误差 0.09pct，**证实**）；三代 HFC 合计 7.64 万吨 / 10.2% / **#4**（巨化 37.7% / 三美 15.7% / 中化蓝天 13.7% / 东岳 10.2%）。2026 年度三代整体仅增发 3,000 吨 R245fa + 50 吨 R41，其余品种与 2025 持平，品种间可调整比例合计不超 30%。【硬·生态环境部方案 + 国信点评】
- **PTFE（国产替代）**：东岳是国产 PTFE 龙头（产能 5.5 万吨，2023 市占 ~23.7% / #1）。**但高端电子级仍由科慕/大金/AGC/苏威主导，未见任一退出或让位的证据**（其在电子级 PTFE 的具体份额与 2026 扩产计划**未找到公开量化数据【缺】**）。**⚠️ 旧档"东岳已开发 CGF218H/K 高端牌号对标大金/科慕"是硬伤——该牌号归属昊华科技（中昊晨光院）**，剔除后东岳在电子级高纯上的可查证据只剩"通用产能大 + 一个超高纯提质项目"。国内同业昊华（4.8 万吨/年，被指国内唯一过 M10 认证）、巨化、永和、新宙邦均已在电子级 PTFE 语境下被点名；**东岳+昊华+巨化合计约占中国 PTFE 产能 57%**——赛道不独占。
- **有机硅**：东岳硅材 60 万吨单体，全球前十 / 中国第四。
- **研发投入**：H1 研发成本 **4.245 亿 RMB（+14.98%），占收入 5.27%**；期末专利 478 项（本期新增 12 项）；研发团队 645 人，博硕占 46.67%。
- **横向对比**：相对[巨化](../2026-05-08-巨化股份-buffett分析.md)（三代配额份额最大 37.7%、A 股估值高），东岳是"R22 第一 + PTFE 一体化最深"的差异化形态；相对[昊华科技](../昊华科技/index.md)（央企多分部拼盘、SOTP 定价），东岳是民营家族、三条腿都是周期化工属性、更适合整体法定价（见 [§10.4](index.md)）；相对[东阳光](../../../materials/aluminum-foil/2026-07-12-东阳光-buffett分析.md)（配额仅 6.6% 却被 AIDC 叙事推至 PE 157–958x），东岳的题材溢价已随 −42.6% 回撤被大部分挤出。

## 5 · 核心优势 / 护城河（重评旧档判断）

| 类型 | 强度 | 趋势 | 说明（vs 旧档） |
|---|---|---|---|
| **政府授予特许（HFC/HCFC 配额）** | **强** | **稳定**（旧档判"稳定"，维持但理由改写） | 配额制 = 事实牌照，新进入者无份，东岳 R22 #1 / R32 #2 / 三代 #4。**理由改写**：旧档的"稳定"建立在"配额加速收紧"上，本轮 2027 征求意见稿确认三代**冻结至 2029** → 护城河的**宽度不变（份额锁定）但增速归零**（不再有配额收紧带来的额外挤压红利） |
| **一体化规模（萤石→氢氟酸→单体→PTFE/PVDF/FKM/有机硅全链）** | **中-强** | **稳定** | **本轮首次拿到硬证据**：制冷剂分部约 **28%** 总收益内供含氟高分子做原料。旧档判"中-强"属推断，现已坐实。**但反面也随之显形**：一体化的上游起点是**外购萤石**，萤石破十年天花板时一体化并不能护住毛利 |
| **PTFE 客户认证壁垒（高端电子级）** | **中 → 中-弱** | **widening 但更慢、且位次靠后**（旧档"中 / widening"，**本轮下调**） | 三条下调理由：① 旧档支撑该评级的 CGF218H/K 牌号**归属错误**，剔除后产品层证据更弱；② **PTFE 树脂不是高频 CCL 链的瓶颈**——瓶颈在 Q 布（2026 全球缺口 300 万米）、高端铜箔（HRP4）、PTFE 板压合/孔金属化良率，东岳即使入链也处在**议价能力最弱的一环**；③ 国内昊华被指"唯一过 M10 认证"，**市场共识第一顺位不是东岳** |
| **民营家族治理** | **中-高 → 中** | **下调** | 下调依据：① 董事长张建宏**兼任主席与行政总裁**，中报 p.27 明确披露**不遵守企业管治守则 A.2.1 条**；② 直接+间接持股仅 **15.35%**，"家族控股"表述需校准；③ 联营的未来材料 **2026-06-30 撤回科创板 IPO、上交所终止审核**（2020/2023/2025 三度冲刺失败），此前问询涉**实控人变更真实性**与"新增大客户负责人与东岳集团高管同名"的隐形关联质疑【软】；④ **无回购，反有 3.28 亿 HKD 信托减持**。**保留的正面**：2026-07-09 盈喜预告"超过 31%"对实际 **+31.80%**，预告精度高；错峰扩产纪律仍好于国资同行 |
| **品牌 / 转换成本** | 弱 | — | 大宗化工品定价 |

**moat 综合判断**：**配额给底（强）+ 一体化规模（中-强）是当下真实的护城河，且一体化本轮由推断升级为硬数**；PTFE 客户认证壁垒**由"widening 的 franchise 苗头"下调为"位次靠后、且不在瓶颈环节的潜在通道"**。按 Buffett 1991 franchise 三要素，制冷剂受配额"产量管制 + 政策性价格底"约束，是**带 franchise 壳的 commodity**；高端 PTFE 理论上有 franchise 潜质，但前提是"真拿到订单"——本轮该前提**比旧档更远**。

**业务模式：Hybrid（commodity 主体 + 配额壳），高端 PTFE 苗头较旧档减弱。**

**制度性强制（institutional imperative）警示**：**存在但强度低**。R32 扩产 4.9 万吨/年投产、新立项拟投超 10 亿元 RMB（无明细无时点），是在配额锁量的环境下扩产能——但公司自己曾因"PVDF 及通用 PTFE 供需失衡"把未动用募资从**扩产改投提质**，这是纪律的正面证据。管理层"未来展望"定调偏谨慎（原文「複雜多變的市場仍需謹慎對待」「下半年市場環境存在諸多不確定性」），**没有在业绩创高的半年里给出上调式指引**——这在周期股里是稀缺的克制。
