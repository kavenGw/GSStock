# 东岳集团 — §9 估值（场景加权）+ 相对旧档变化清单

## 9 · 估值（场景加权）

### 9.0 口径声明（三条，违反即结果不可比）

1. **币种**：财报 RMB、市值/估值 HKD。场景加权**前**先把正常化利润按 **CNY→HKD ×1.1663** 折到 HKD，三档 / 期望值 / 安全边际全程 HKD。汇率锚：2026-09-02 09:50 HKT，新浪 fx_shkdcny 0.857471，USDCNY 6.7234 ÷ USDHKD 7.8414 = 0.857419 反算一致【硬·双源交叉】。**旧档 ×1.08 作废，本档无任何 ×1.08 派生数。**
2. **归母口径**：全部正常化利润为**归属母公司股东**口径。本期利润增量的 **57.1%** 被非控股股东分走（存量口径 37.1%，H1 2025 为 26.3%），弹性最大的有机硅由控股 **44.40%** 的东岳硅材承载。用期内溢利（+54.61%）会系统性高估股东回报。PE 亦为归母口径 **10.7x**（第三方报价源腾讯 10.61 / stockanalysis 10.52 用的是**含少数股东**口径，两个口径都对但差 18%）。
3. **不做 SOTP，用整体 PE 主锚 + PB/隐含 ROE 交叉验证**——理由见 [§10.4](index.md)（倍数跨度小、分部资产未披露、两条路径互洽）。

### 9.2.1 三档概率是怎么定的（本轮独立赋权，不沿用旧档）

旧档赋权为 bear 30% / base 50% / bull 20%。**本轮三档权重逐个重新论证，其中 bear 由 30% 上调至 40%、base 由 50% 下调至 40%、bull 维持 20%。**

- **bear 40%（上调 10pct）** —— 本轮新增了**四条同时在场的下行信号**，且没有一条在旧档的赋权依据里：① **下游需求走弱**：2026-08 家用空调排产 1,073 万台，同比 **−16.7%**，直指 H2 制冷剂出货；② **成本端**：萤石 2026-08 突破十年天花板 3,250–3,800 元/吨，H1 已在制冷剂分部显形（售价创十年新高而分部业绩仅 +20.99%，是三条腿最慢）；③ **已有一条腿进入下行段**：二氯甲烷及烧碱分部业绩 **−72.11%**、收入 −26.82%；④ **利润转现质量劣化**：应收 91–180 日档 **+181%**、减值计提 +327%，而收入仅 +7.99%。bear 情景（8.5 亿 = 回 2024 量级 + 有机硅重回微亏）在这四条同时兑现时是**完全可达的**，不是尾部。**旧档 30% 是在只有"制冷剂价格可能见顶"一条下行论据时定的；四条信号对一条论据，权重必须上调。**
- **base 40%（下调 10pct）** —— 让出的 10pct 全部给 bear，而**不动 bull**。理由是这四条信号**只压制下行侧**：它们让"利润回中枢甚至更低"更可能，但不改变"再上一个台阶"的可能性（那取决于配额平台期的价格锚定与有机硅剪刀差延续，与空调排产/萤石/应收无关）。base 自身的支撑未被削弱——隐含 ROE 8.7% ≈ 实际中枢 8.0%（见 9.5），仍是三档中最有实证支撑的一档。
- **bull 20%（维持）** —— 权重由**两条独立门控**共同封顶，且两条都与上述下行信号无关：① 成长证据包 **4/15 弱档**（见 9.4）；② 隐含 ROE 11.5% 需较实际中枢提升 **44%** 且要求可持续（见 9.5）。同板块[昊华科技](../昊华科技/index.md)以同一纪律封顶 20%（"周期顶利润 × 成长股倍数是双重乐观"），本档保持一致。**bull 不因股价 −42.6% 而上调，也不因下行信号增多而下调。**

**赋权变动对结论的影响**：期望内在价值由（按旧权重算的）158.1 亿降至 **149.0 亿**，安全边际由 −33.0% 走扩至 **−36.9%**——**方向是让"不买"更成立而非更勉强**，故此项调整不存在为迁就结论而反推的空间。

### 9.3 倍数框架自检（不破框架）

buffett 倍数框架：周期/衰退型 <8x、窄护城河 8–12x。本档 **bear 8x / base 11x / bull 12x 全部落在框架内**，无一档需要降格进压力测试。

- **bear 8x**：周期底利润配周期股下沿倍数 + 港股流动性折价。
- **base 11x**：配额牌照（[§5](business.md) 判"强·稳定"）+ 一体化规模（"中-强"）给的中枢溢价，已扣港股折价。**反向敏感性**：base 倍数降至 10x → base 155.1 亿、期望值 142.8 亿、安全边际 **−39.5%**，**更负，强化不买结论**；升至 12x → base 186.1 亿、期望值 155.2 亿、安全边际 **−34.3%**，**仍为负**。倍数在 10–12x 区间摆动都不改变结论，11x 是诚实取值而非托估值。
- **bull 12x**：框架上沿。**不给 13x**——13x 需要成长股属性，而成长证据包评分 4/15（弱，见 9.4），给不出。

### 9.3.1 base 正常化利润 13.3 亿的反向敏感性（本档最承重的一个假设）

倍数已在 9.3 做过反压，**正常化利润本身也必须做**——13.3 亿是全档最主观、最承重的取值，仅交代方法不足以说明它经得起反压。

四年样本里 2023/2024 是配额收紧**前**的低谷、2025/2026E 是收紧**后**的高位，取均值等于假设未来在两端之间摆动。**这个假设可能错在哪**：若 2027 起的配额冻结平台把 R32 价格锚在 6 万元/吨以上而非回落（[§6 论点一](thesis.md) 的多头面：配额冻结 = 存量份额被永久锁定、CR3≈66% 寡头挺价真实），则"中枢"应更靠近 2025 的 **16.42 亿**而非 13.3 亿——**base 被低估约 23%**。

| 若 base 正常化利润取 | base 内在价值 | 期望内在价值 | 安全边际 |
|---|---|---|---|
| 13.3 亿（本档取值） | 170.6 亿 | **149.0 亿** | **−36.9%** |
| 16.42 亿（= 2025 实际，冻结平台锚住价格） | 210.6 亿 | **165.0 亿** | **−30.1%** |

**结论不翻转，但张力必须记名**：即便按最有利于多头的正常化基数（2025 实际值，已是本档愿意接受的上限——再往上就是 2026E 的 21.5 亿，触犯穿越周期铁律），安全边际仍为 **−30.1%**，未进入买入区间。**但要诚实说明：13.3 亿唯一的辩护是"四年均值仍显著低于顶部年化"这条纪律，而纪律不等于正确**——没有任何硬证据能证明中枢就是 13.3 而不是 16.4。这条是本档最脆弱的一环，其证伪路径已挂在 [§11](index.md) 风险 #1（2027 配额正式方案）与 #2（制冷剂分部溢利率 <44%）上。

### 9.4 bull 门控（x-growth lens 三要素证据包）

| 要素 | 证据 | 判定 |
|---|---|---|
| ① 标的自身扩产达产确定性 | R32 扩产 **4.9 万吨/年已投产**（中报 p.15–18）——**⚠️ 新增的是产能不是配额**，配额锁死内用产量，公告原文只说"为应对未来市场变化提供保障"，**未给任何量增指引**；新立项拟投超 10 亿元但无明细无时点；未动用募资改投「PTFE 超高纯品质提升项目」= **提质不提量** | **【软】** |
| ② 客户 capex 能见度 | 具名：**零**——无任何 CCL 厂具名东岳为 M10 PTFE 树脂来源；生益/南亚/华正/中英四家 2026 中报与投关均无。终端兑底：制冷剂端客户为空调/汽车厂高度分散，只能兑总量（**2026-08 家用空调排产 1,073 万台，同比 −16.7%**，方向为负）；AI 端可兑到 AI 服务器出货但**该端当前营收占比为 0** | **【缺】** |

**合计 4/15（弱档）→ bull 概率封顶 20%**，与同板块[昊华科技](../昊华科技/index.md)保持一致纪律（"周期顶利润 × 成长股倍数是双重乐观"）。**bull 定义写死为「制冷剂价格周期再上台阶 + 有机硅反转延续」，明确禁用 AI/M10 重估**——AI 通道在数学上撑不起重估（上界 7.1 亿元收入，占 143.55 亿营收 <5%）。**AI-PTFE 的任何收入不进入本节 owner earnings 基础。**

### 9.5 隐含 ROE 自检（对齐昊华档的第二条赋权依据）

归母权益 152.157 亿 RMB（静态，未计入未来留存；这一简化会略微高估远期隐含 ROE，方向保守）。

| 情景 | 隐含 ROE | vs 实际 ROE 中枢 |
|---|---|---|
| bear 8.5 亿 | **5.6%** | 低于中枢 30% |
| base 13.3 亿 | **8.7%** | **与中枢基本持平（+9%）** |
| bull 17.5 亿 | **11.5%** | 需较中枢**提升 44%** |

**实际 ROE 中枢**：2023 ≈5.5%、2024 ≈6.2%、2025 ≈12.1%（均为归母/归母权益近似），**三年中枢 ≈ 8.0%**；H1 2026 年化 **13.88%**（周期高位读数，不作中枢）。

- **base 隐含 ROE 8.7% ≈ 实际中枢 8.0%** → base 赋权 40%（见 9.2.1）有支撑，不是乐观外推；它仍是三档中实证支撑最强的一档，本轮下调 10pct 是把权重让给 bear，不是因 base 自身被削弱。
- **bull 隐含 ROE 11.5% 需较中枢提升 44%**，且要求这个高 ROE **可持续**（否则不配 12x）。而 H1 的 13.88% 是价格弹性驱动、配额锁量意味着价一回落即反向 → **44% 的持续性提升缺乏支撑，这是 bull 只给 20% 的第二条独立依据**（第一条是 9.4 的证据包 4/15）。
- **公允 PB 交叉验证**：股权成本按周期股 + 无稳定股息 + 少数股东漏损取 **11–12%**。base 隐含 ROE 8.7% **低于股权成本** → 公允 PB 应在 **1x 以下**。本档 base 隐含 PB **0.96x**，与之一致。**现价 PB 1.33x 高出公允 PB 39%** —— 这是与利润法完全独立的第二条"贵"的证据。

### 9.6 bull 压力测试

bull 内在价值 245.0 亿 HKD 对实时市值 236.0 亿 HKD → 安全边际 **+3.8%**。

**解读**：与旧档（bull 190 亿对市值 290 亿，−34.5%）相比这是实质变化——**现价已不再高于所有情景**。但 +3.8% 不是安全边际，是"最乐观情景下刚好公允"。买在现价 = 押注 bull 兑现（20% 概率）且不要任何折让。**按 buffett 安全边际阶梯，"存在不确定性因素"档需要 40–50% 折让；本档给 30% 已是下限。**

### 9.7 最强反方：卖方一致预期（必须正面处理）

| 口径 | 数字 | 来源 |
|---|---|---|
| 一致预期 2026E EPS | **1.44 RMB**（→ 归母约 **24.9 亿 RMB**） | stockanalysis，5 家覆盖，截至 2026-08【软】 |
| 一致目标价均值 / 中位 / 区间 | **20.28 / 19.13 / 15.00–27.88 HKD** | 同上；隐含较现价 **+49%** |
| 最新单家 | 华泰证券 2026-08-25 买入，目标价 **21.67 HKD** | 【软】 |
| 一致评级 | Strong Buy（覆盖家数由 2025-12 的 8 家降至 5 家，属收敛而非下调） | 同上 |
| 本档 2026E 中枢 | **21.5 亿 RMB** | [§9.1](valuation.md) |
| 本档 base 正常化 | **13.3 亿 RMB** | 四年均值 |

**分歧的本质，逐层拆开**：

1. **第一层分歧（2026E 本身）：H2 隐含季节比 1.42（卖方）vs 1.108（2025 实测）。** 卖方 24.9 亿 − H1 实际 10.27 亿 = H2 需做 **14.63 亿**，即 H2/H1 = **1.42**。而 2025 年实测季节比是 **1.108**（FY2025 16.42 亿，H1 7.792 亿）。
   **为何不采纳 1.42**：① **没有独立证据**——要 H2 环比 +42% 需要制冷剂价格再上一个台阶或销量放大，但配额锁量、且 2026-08 家用空调排产同比 **−16.7%**，H2 出货方向为负；② **管理层自己没有给上调式指引**——中报"未来展望"原文是「雖然本集團在上半年業績有較大增長，但**複雜多變的市場仍需謹慎對待**」「下半年市場環境存在諸多不確定性」；③ **成本端已在吞噬**——萤石 2026-08 突破十年天花板 3,250–3,800 元/吨，H1 已经出现"制冷剂售价创十年新高、分部业绩只 +20.99%（增速三条腿最慢）"的传导衰减；④ **1.42 是外推而 1.108 是实测**，在无独立证据时取实测是纪律而非保守。
   **诚实反方**：H2 确有上行动能——Q3 R32 长协较 Q2 已实涨 2,900 元/吨（已落地事实）、有机硅同比基数仍极低、且**未检索到中报后任何一家卖方的正式下调研报**【缺】。若 H2 真做到 14.63 亿，本档 2026E 中枢 21.5 亿会显得保守约 16%。
2. **第二层分歧（更重要）：2026E 该不该当正常化基数。** 即便卖方 24.9 亿全部兑现，**那仍是配额高位利润而非穿越周期中枢**。本档 base 13.3 亿是四年均值——把 2026E 上修到 24.9 亿，四年均值也只从 13.3 升到 **14.15 亿**（+6.4%），base 内在价值升至 181.5 亿、期望值升至 **153.3 亿**（= 0.40×79.3 + 0.40×181.5 + 0.20×245.0 = 31.72 + 72.60 + 49.00）、安全边际 **−35.0%**。**结论不翻转。**
3. **第三层：目标价 20.28 HKD 隐含什么。** 20.28 × 17.327 = **351.4 亿 HKD** = 301.3 亿 RMB。对 24.9 亿归母 = PE 12.1x（看似不贵）；但对本档 base 13.3 亿 = PE **22.7x**，对应隐含 PB **1.98x** / 隐含 ROE 需 8.7% 而付 2x 账面 —— **对一个 ROE 中枢 8% 的周期股，这是明显的高估**。**分歧不在算术，在"周期顶利润是不是新常态"这一个假设上**：卖方隐含"配额把高利润锁成永久态"，本档隐含"配额锁量不锁价，价格弹性双向，且 2027 征求意见稿已确认配额收紧引擎关停至 2029"。本档选后者，并把"24.9 亿兑现且常态化"折进 bull 的 20% 概率而非作为基准。
