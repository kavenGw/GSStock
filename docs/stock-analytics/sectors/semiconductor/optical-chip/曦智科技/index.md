## §0 结论摘要

**评级：`exclude`（不进入 buy 讨论）。期望内在价值 83.73 HKD/股，对 2026-09-03 收盘 372.20 HKD 的安全边际 −77.5%。**

- **这不是一家假公司，但它是一个被提前十倍支付的价格。** 收入 100% 来自 AI 算力场景，光跃 LightSphere X 已在数千卡国产 GPU 集群商业部署，2026H1 收入 7,978 万元、毛利率 65.8% —— AI 敞口是**【真敏感】**而非蹭概念（[§7](thesis.md)）。但总市值 350.01 亿 HKD ＝ 299.95 亿元 RMB 对应 **PS_TTM 181.4x / EV-Sales_TTM 164.3x / PB 10.19x**，PE 不适用（18C「-P」未商业化公司，持续亏损）。
- **bull（15%）210.07 HKD**：2025Q4 那批订单之外持续拿到新单，FY2027 收入 6.0 亿元、给 25x PS。三情景中唯一一档要求「订单可重复」被证实。
- **base（45%）85.37 HKD**：FY2027 收入 3.2 亿元、15x PS —— 已隐含 2026→2027 收入近乎翻倍，并不苛刻。
- **bear（40%）34.50 HKD**：H2 收入环比大幅回落坐实单批订单假说，FY2027 收入 1.3 亿元、6x PS，价值主要由净现金构成。
- **bull 权重压到本仓下限档 15%** 的理由：`x-growth` 成长证据包三件套中，扩产达产【不适用·Fabless】、客户 capex 能见度【缺·客户全匿名且终端市场无第三方口径】，只剩 TAM 跑道【软】—— 按 `buffett-doc-spec` §3 门控，三项无一为【硬】即须封顶。算式与逐档口径见 [§9](valuation.md)。

**一句话**：技术是真的，收入是小的，客户是换血的，补助是填坑的，价格是四倍的。

## §10 评级决策

### 10.1 期望内在价值 vs 实时市值

| 项目 | 数值 |
|---|---|
| 2026-09-03 收盘价 | **372.20 HKD**（+11.705%，成交 343,271 股 = 前一日 4.0 倍） |
| 总股本 | 94,037,377 股（H 股 76,850,576 + 内资股 17,186,801） |
| 总市值 | **350.01 亿 HKD = 299.95 亿元 RMB**（HKD/CNY 0.857；**内资股按 H 股同价计**，口径披露见 [§9](valuation.md)） |
| 期望内在价值 | **83.73 HKD/股 = 78.72 亿 HKD = 67.46 亿元 RMB** |
| **安全边际** | **(83.73 − 372.20) / 372.20 = −77.5%** |

期望内在价值本身仍隐含 **PS_TTM 40.8x / EV-Sales_TTM 23.7x** —— 即本档的"公允价"按本仓 optical 兄弟档标准（中际旭创、新易盛盈利同业 PE_TTM 53–70x、PS 十倍级）依然是慷慨的一侧，**不存在"估得太狠"的解释空间**。

### 10.2 评级落定

`exclude`，不是 `watch`。三条并列理由：

1. **安全边际 −77.5%，超过本仓既有 exclude 门槛**（铂力特 −57.7% 判 exclude；博通 −39.8%、创想三维 −29.7% 判 watch）。按同一把尺，−77.5% 只能落 exclude。
2. **核心增长开关不可验证**：中报未披露在手订单/剩余履约义务（A1、A3 双路确认【缺】），2025Q4 那批 8,730 万元订单与 2026H1 收入 7,978 万元在量级与时序上高度吻合（[§6](thesis.md)）。这不是"论点偏弱"，而是**论点无法被证实也无法被证伪** —— 巴菲特框架下属于"无法可靠估计"，对应"不投资"而非"折价买入"。
3. **价格发现质量低**：自由流通盘 **6,889,905 股 = 总股本 7.33%、H 股 8.97%**（IPO 15,864,480 股含绿鞋 − 基石 8,974,575 股）。52 周区间 228.40–1,050.00（4.6 倍）。2026-09-03 单日 +11.70%、4 倍量，**遍查无任何公开催化剂且非板块 beta**（当日恒科 −1.08%、中际旭创 −1.14%、新易盛 −0.50%）——【缺】，本档不为其编造理由。**并须纠正一个易犯误判：这波上涨与半年报无关 —— 半年报 8/21 盘后发布，8/24 市场给出的答案是 −6.64%。**

### 10.3 买点 / 卖点阈值

- **买点闸（框架内）**：确定性层级为"无法可靠估计"，本应对应"不投资"。若强行按"不确定性因素存在"档给 50% 折扣，买点 = 83.73 × 50% ≈ **41.9 HKD**，而**现金每股下界仅 35.10 HKD**（净现金 28.28 亿元 RMB ÷ 94,037,377 股）—— 买点闸与清算下界几乎重合，意味着**在可辩护的框架内本标的几乎不存在买入区间**。这条分歧必须诚实写出，而不是靠抬倍数造一个买点。
- **重估触发（向上）**：FY2026 年报披露在手订单/剩余履约义务且金额 ≥ 2 亿元，或前五大客户中出现具名头部云厂/GPU 厂并连续两期复购 → 客户能见度这一格由空转实，bull 权重可从 15% 上修，届时重算。
- **卖出触发**：见 §11 第 1、5、7 条。
- **相对旧档是否翻转**：不适用（首建档，仓内无 01879 历史档，无旧档结论可对照）。

## §11 关键风险 Top 5 + 监控指标 / 卖出触发器

### 11.1 关键风险 Top 5

1. **单批订单风险（头号）**：2026H1 收入极可能就是 2025Q4 那批 8,730 万元匿名采购订单的交付，招股章程明写该批订单"预期于 2026 年全部履行"—— **2027 年收入需要全新订单支撑**，而在手订单未披露。
2. **客户基盘无复购**：前四大客户占 **77.6%**，2025H1 的四家 10%+ 客户在 2026H1 **全部退出名单**，最大客户 2025 年占 40.6% 且匿名。客户名单一年换血一遍。
3. **政府补助掩盖经营恶化**：剔除补助后可比经营亏损同比扩大 **49.4%**（186.7M → 278.9M），而管理层强调的经调整净亏损仅 +12%（131.4M → 147.1M），差额全由补助从 52.8M 跳到 120.6M（+128%）填平（[§3/§6](business.md)）。
4. **供给冲击**：2026-10-28 基石解禁 8,974,575 股 = 总股本 9.54%、H 股 11.68%，**约为当前自由流通盘 6,889,905 股的 1.30 倍**，按 9/3 成交量相当于 26 个交易日的全部成交，距今约 8 周。
5. **平台方与体系内玩家挤压**：海外 Broadcom / NVIDIA / Google Apollo 已封闭 scale-up 光互连，公司**无任何海外收入披露【缺】**；国内华为昇腾超节点自研光互连，属"客户即对手"结构。

> **现金不是风险点**，此处不铺陈：净现金 28.28 亿元，FCF 口径月烧 3,910 万元，**跑道 73 个月（6.1 年）**，烧钱翻倍仍有 3 年。
