## 0 结论摘要

**评级watch（维持）**。2026Q3收入8.29428亿、扣非归母1.33015亿，同比+106.45%/+208.08%、环比+37.05%/+39.07%，AI高速器件归因仍在。TTM扣非升至3.19676亿。

本次实质修复旧采证：**补贴重复扣除、遗漏10.81725亿H2履约义务、误把1–2月生产周期当订单久期、漏取现金资本开支**。成长证据包由“全软”改为分层：已兑现无源产能及H2合同覆盖为硬，后续投资收益、具名跨年合同和TAM尚不全硬。收入/净利率三档上调，概率25/55/20→20/60/20，净利润PE统一股权口径、不再额外扣净债；估值26.95→34.38亿。推导与纠错贡献见[§9](valuation.md)。

Q3没有分部、PAM-4阶段、米兰损益与募投效益更新，最后产品基线仍属H1，**缺披露不构成年度证伪触发**。前三季FCF−3.18352亿、Q3−0.66629亿，利润转现金仍待验证。安捷讯已审核通过但注册交割未完成，承诺改为2026–2027累计扣非3.41亿，不入基础。

行情严格守卫**实际exit 1**：脚本排除15:00历史收盘；多源核验及股本市值算术一致，但不能声称guard通过，见[§12](sources.md)。

### 10.2 watch维持：估值上修但仍无配置空间

相对9月档，市值753.25→514.70733亿、TTM归母2.73199→3.52053亿，价格与盈利共同消化估值；内在价值26.95→34.38亿。不能沿用旧“只有倍数扩张、升级只能靠跌价”的绝对断言，未来经营和护城河证据同样可能改变价值。
