# 光库科技 — §1 能力圈与重审触发 / §2 市场规模 / §3 盈利能力 / §4 全球竞争力 / §5 护城河

## 1 能力圈 & 本次重审触发

### 1.1 能力圈判定：边界内

**一句话商业模式**：光库是**光通信上游器件厂商**——用自有的芯片制程与封装产线（IDM），把铌酸锂晶体和微光学元件做成调制器、光纤阵列（FAU/MT-FAU）、MPO/MTP 连接件、隔离器/环形器与光纤激光器件，卖给光模块厂与光通信设备商，赚取器件加工与技术设计的价差。

**旧档的能力圈描述需要修正一处**：旧档写"光库是国内唯一、全球第三的铌酸锂调制器 IDM 厂商……赚取技术溢价"。这个描述在**能力**层面成立，但在**收入**层面不成立——它今天的钱主要不是这么赚的。**准确的商业模式描述是两句话**：

1. **今天赚钱的**：AI 数据中心用的**无源微光学连接件**（FAU、CPO/NPO 用保偏光纤阵列、MPO/MTP），H1 收入 6.018 亿、+115.04%；
2. **尚需独立业绩验证的**：**薄膜铌酸锂（TFLN）调制器芯片**——H1承载主体光库米兰营收640.58万、净亏5,926.43万；该主体损益不等于PAM-4产品收入，Q3未给单独更新，不能断言当前贡献为零。

理解这门生意需要能分清这两句话；能分清，则在圈内。

### 1.2 本次财报差量更新触发（2026-11-01）

2026Q3正式报告显示单季收入8.29428亿、归母1.42293亿、扣非1.33015亿，收入/扣非同比+106.45%/+208.08%、环比+37.05%/+39.07%；AI数据中心及高速器件需求归因仍在。TTM扣非升至3.19676亿，10月30日历史收盘市值514.70733亿、归母PE146.20x。本次更新经营兑现、估值与全部监控状态。

同时回读H1附注，发现旧档**补贴重复剔除、遗漏10.81725亿履约义务、误把1–2月生产周期当订单久期、误称未披露现金资本开支**，均在相关正文实改。Q3没有产品/地区、产销、米兰及TFLN效益表，以下分部与项目判断的最后可核基线仍是2026H1，不将旧数据写成当季事实。2026-10-23安捷讯审核通过、未完成注册交割；承诺条款见[§9](valuation.md)。

### 2.2 跑道长度：**不可判定**，必须明写

x-growth lens 要求给"当前渗透率距天花板多远"。本档**给不出这个数字**，且拒绝编造：

- **TFLN 细分**：光库该业务收入公司从未披露 → 分子不存在 → 渗透率**不可算**。
- **光模块整体**：2029 全球 373 亿美元是**模块**口径，而光库卖的是**器件**；器件价值量占模块的比例公司未披露 → 分子分母不可通约 → 渗透率**不可判定**。
- **唯一可靠的跑道信号是物理产能**：光通讯器件产能已从 3.1M 件/半年提至 6.2M 件/半年，且仍 **99.48% 满产**。

> **跑道能否延长，取决于下一轮扩产能否落地——而下一轮扩产（铌酸锂募投）恰恰是延期且累计亏损的那个。** 这是本档对"跑道"这一问最诚实的回答。

### 2.3 §2 与估值的连接：自反性

把 SAM 这个数字和市值放在一起看，就是 [§9.5①](valuation.md) 那条论据的来源：**公司自己援引的 TFLN 全球 2029 年销售额（约 53 亿人民币），只有10月30日市值（514.70733亿）的约10.3%。**

### 3.4 毛利率的结构性成因拆解（optical lens）

1. **单位成本 −10.87%**——规模效应/良率，**结构性、可持续**；
2. **单价 +8.08%**——供需紧张，**周期性、可反噬**（合同定价保护条款未披露，见§3.6）；
3. **国内 +12.93pct / 国外 −0.62pct 的分化**——改善集中在占收入 42.98% 的国内业务；
4. **减值与补贴近似对冲**：资产减值 −750.36 万（存货跌价，占利润总额 −4.39%）、信用减值 −1,435.14 万（应收坏账，−8.39%），合计吃掉利润总额 12.78%；其他收益+2,046.11万内含政府补助1,880.20万，已列非经常损益并在扣非中扣除。**旧档把其他收益全额再剔一次构成重复扣减**，现按[§9.1](valuation.md)纠正；不机械加回真实经营减值。

> **口径提示（optical lens 横比纪律）**：光库为 IDM（自有芯片制程 + 封装），其毛利率**不可与纯封装/纯代工同行直接横比**——与该 lens 中"一体化口径毛利率不可与外购光棒同行横比"同理。
>
> **季节性偏置回测**：综合毛利率 2025H1 30.92% vs 2025 全年 34.66%，存在系统性 **H1 低于全年约 3.74pct** 的偏置。但 2026H1 的 38.77% 距 28% 阈值有 10.77pct 空间，加回偏置只会更高 → **偏置不改变裁决方向，该指标可用于半年口径裁决**。

### 3.5 ROIC / 增长质量 / 现金转化

**Q3更新**：前三季OCF−1.30415亿、OCF/归母−44.86%；单季OCF+0.31002亿、净现比21.79%，同比2025Q3的+0.54323亿反而下降42.93%。回款边际恢复，但尚未转成足额自由现金。H1/9M现金资本开支为0.90306/1.87937亿，Q3差分0.97631亿，9M/Q3 FCF为−3.18352/−0.66629亿。**现金资本开支是现金流表已披露值，旧“未披露、用4.08亿投资额代理”撤销**；仅维护/成长拆分仍缺。

Q3同旧科目负债代理=短借10.01502+一年内到期非流动负债2.96026+长借2.32840=15.30368亿，/归母权益24.02584亿=63.70%（2025Q3同口径40.46%）；一年内到期项目可能含非借款，另有租赁负债0.64421亿，不冒充精确银行债务。货币资金13.34169亿，净债代理1.96199亿；现金等价物8.48451亿，二者差4.85718亿用途待核，不能全称受限或可自由支配。

Q3末应收+存货14.98685亿，按滚动Q2+Q3收入为104.47%，同期117.09%；9M收入分母则80.53%/85.98%，**不能与H1六个月分母122.6%直接比较**。C2窗口修订见[§11](index.md)。预付1.1709亿、较年初+626.27%，库存/应收较年初+71.93%/+68.57%，属备料和营运资金占用，未足以推断造假或坏账爆发。

前三季研发费用同比+39.65%，低于营收86.41%的一半，但这不是总研发投入口径；B6保留H1既有警示、Q3待核。Q3汇兑+其他财务费用代理1,506.64万不等于单项汇兑损失，C4待核。

**以下为H1历史基线**：

- 加权平均 ROE **6.65%**（半年口径），年化粗估约 13%——**尚未达到 buffett 框架 15% 的门槛**，且这是在景气高点、毛利率创新高的半年。
- 扣非占归母比重 **88.6%**（2025H1 为 80.1%）→ **利润质量同比改善**。
- **但现金转化严重恶化**：净现比 **−1.09**；应收 7.177 亿（+37.90%）+ 存货 5.473 亿（+51.44%）合计 12.65 亿 = H1 营收的 **122.6%**；预付款项 9,593.66 万（**+495.05%**，前五名占 81.11%）。
- **杠杆抬升**：有息负债合计约 **12.79 亿**（短借 7.204 亿 +89.86%、长借 4.505 亿、一年内到期 1.075 亿），对应归母净资产 22.574 亿 → **有息负债/净资产由年初 39.7% 升至 56.7%**；财务费用 2,858 万（**+983.75%**，含汇兑损失 2,824 万）。
- **研发投入 9,986.88 万，仅 +18.05%**（营收 +72.91%），研发费用率由 14.18% 降至 9.68%。

> **现金流表述纪律**：光库经营现金流季节性极强（2025 全年 2.3125 亿中 Q4 独占 1.6645 亿，H1 仅占全年 4.5%）。**"H1 现金流为负"的绝对值不能用于裁决经营质量**；必须走**同口径同比**：2026H1 −1.614 亿 vs 2025H1 +0.105 亿，同口径恶化 **−1.719 亿**——**这一条是真实恶化**。详见 [§6.5](thesis.md)。

### 3.6 合同能见度：纠正旧生产周期推断

H1 P129明确已签未履约或未完全履约合同对应收入 **1,081,725,193.41元（10.81725亿）**，预计全在2026H2确认。旧“无剩余履约义务披露”属于采证遗漏；P12“平均生产周期1–2个月”不能推为订单久期。合同负债710.60万、占H1收入0.69%只说明预收模式，不能推导订单少或零保护。

这项附注**提高H2合同能见度**，但缺具名客户、价格保护、产品/TFLN占比与跨年订单信息；不能把10.81725亿全归TFLN，亦不能用其减Q3收入推当前剩余订单。保留价格压力敏感性，删除“无合同缓冲、1–2季度完整传导”的确定断言，见[§9.6(a)](valuation.md)。

### 3.7 供应链位置：铌酸锂晶圆**外购**（optical lens「光棒自给率」的类比问项）

半年报全文**未出现"8 英寸""12 英寸""铌酸锂晶圆"等自供表述**——**未找到公司自产铌酸锂衬底的证据**【缺】。（外部流传的"12 英寸 TFLN 晶圆"检索指向的是**天通股份**，不是光库。）

> **含义**：光库在 TFLN 环节吃的是"芯片设计 + 制程 + 封装"的加工与设计价差，**衬底外购**——与 optical lens 中"外购光棒者两头受挤"的风险结构同型。上游涨价或供给受限时**缺乏对冲**。

## 5 核心优势 / 护城河

### 5.1 重评旧档判断

**旧档：技术壁垒强 · 拓宽中（基于 TFLN IDM 稀缺性）。本档：窄 · 由技术型窄向制造型窄漂移。**

理由不是"TFLN 不行"，而是**护城河的归属必须跟着收入走**：

| 判据 | 事实 | 对护城河的含义 |
|---|---|---|
| 已兑现收入的来源 | 无源微光学连接件（加华微捷 H1 营收 2.373 亿、净利 3,329 万）+ 体材料 LN + 光纤激光器件 | 这些环节的**技术门槛与替代难度显著低于 TFLN IDM**；竞争者包括天孚、太辰光，以及**它正在花 16.4 亿收购的安捷讯本身** |
| TFLN IDM 的稀缺性 | 技术能力存在，但**未见PAM-4独立量化业绩证据**（光库米兰H1营收640.58万、净亏5,926.43万，不能据其整体收入判断PAM-4收入；募投累计效益−2,986.60万，Q3未更新细分） | 稀缺性在账面上还不是护城河，是**期权** |
| 定价权 | ASP +8.08%、毛利率 +12.89pct | 有，但**国外（占 57%）毛利率零改善**说明定价权在海外增量上不成立；且**39% 的毛利率在无源器件同业中并非独有的超额水平**，更可能是行业景气普涨 |
| 切换成本 | 客户验证周期 6–12 个月（旧档口径，本轮无新证据） | H1履约义务10.81725亿提供H2合同覆盖；但客户验证周期为旧口径，长期锁价及替换成本货币化程度未披露 |
| 成本优势 | 单位成本 −10.87% | **真实**，是本轮护城河中最扎实的一块（规模效应 + 良率） |
| 技术领先的再投资 | **研发投入仅 +18.05% vs 营收 +72.91%** | **反向信号**：在竞争窗口前移的同一年没有加码研发 |

### 5.2 五类护城河逐项判定

| 类型 | 判定 | 依据 |
|---|---|---|
| 无形资产（技术/专利/认证） | **中，趋势持平偏弱** | TFLN 能力真实且稀缺，但未变现；研发投入增速掉队；HyperLight 代差未拉开 |
| 成本优势 | **中，趋势向好** | 单位成本 −10.87%、满产 99.48%、IDM 一体化 |
| 转换成本 | **弱—中，趋势持平** | H2合同覆盖已证实，跨年锁价/客户替换成本仍缺，不能由生产周期推订单久期 |
| 网络效应 | **无** | — |
| 有效规模 | **弱** | 无源器件环节同业众多且都在扩产 |

> **综合：窄护城河（narrow），趋势持平。** 对应倍数框架 **8–12x**（[§9.2](valuation.md)），与同 subsector 兄弟档光迅科技（2026-08-20 判"窄"→8–12x）同框架。
