## 4. 口径与纪律声明

1. **价格锚为 2026-09-07 午间盘中价（12:05:30），非收盘价**；全部以 880.11 元为分母的派生数须收盘后回填（清单见 [valuation.md](valuation.md) 末节）。
2. **A+H 口径**：跟踪主体 = A 股 300308.SZ，市值 = A 股价 × **总股本 1,177,909,641 股**；H 股仅作溢价观察项。若改用 H 股口径则 PE_TTM 56.2 / PB 28.8——**两套口径择一贯穿，本档选 A 股口径，禁止混用**。
3. **正常化利润以扣非为基础**，**汇兑损失 5.62 亿不作一次性剔除**；**H1×2 = 273.02 亿（扣非年化 261.84 亿）为顶部年化，仅作上限参照，不作 Base 基础**。
4. **未兑现代际（3.2T / NPO / XPO / CPO / OCS）2026H1 收入贡献为零，不进 owner earnings 基础**，仅在 Bull 单列并注明「2027 年前无收入贡献」。
5. **「控股股东高位套现 53 亿」框架已整体撤回**（A2 校准闭合节）：减持交易全部发生在 2026-01 之前，旧档建档日 2026-07-02 之后无任何一笔；「53 亿」是媒体用 2026-07-30 收盘价 864 元反算的**名义市值**，非实际套现额；持股 17.99%→16.53% 的降幅同时含 H 股摊薄 + 股权激励行权 + 二级减持三项，不可全归因减持；**2026 年内无新披露的减持计划或进展公告**。故**不写入 thesis**，仅作 [events.md](events.md) 背景注脚。
