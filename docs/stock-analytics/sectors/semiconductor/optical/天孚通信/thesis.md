# 天孚通信 — §6—§8 论点、AI兑现与周期

## §6 核心论点：盈利台阶已提高，现金与跨代适配决定持续性

### 6.1 需求与供给改善正在转化为利润

**最强反驳先列出：需求旺盛不等于天孚能按期交货，利润增长也不等于现金同步可分配。**2026H1有源光器件收入同比下降19.57%，公司解释个别核心物料短缺限制提产；Q3归母同比增长55.30%、环比增长23.47%，10月28日交流记录称有源和无源同步增产、核心物料供给明显缓解。这支持盈利基础上移，但本期未披露分产品出货与订单金额，无法把Q3增量精确拆成1.6T或CPO贡献。[财务S1—S3、交流S5](sources.md)

泰国项目2026年3月量产、江西二期投用，支持供应能力扩张；苏州新总部及工厂预计2027年陆续投用仍是前瞻安排。设施节点【硬】与产品级达产率、客户认证后有效产能、增量利润【缺】必须区分。前三季购建长期资产支出4.9102亿元，无法拆到各项目及维护/成长用途。结构性需求升级成立，同业扩产、客户议价和新厂爬坡使过剩风险仍在。

Fabrinet在2025年销售占比63.31%、前五89.73%有年报具名支持，但直接代工客户不等于单一终端云厂。未取得足以映射为天孚保底采购的客户capex/锁单合同，本轮仅以公开终端预测及公司订单口径作需求佐证，不能将“客户集中”当作“增长确定”。

### 6.2 毛利改善不能用单一产品占比解释

H1无源收入增长77.40%、毛利率71.90%，有源收入下降19.57%、毛利率47.03%。Q2/Q3综合毛利率分别64.66%/65.05%，明显高于旧档50%—54%的基准假设。**被财报证伪的是旧档将有源占比上升与毛利必然下滑绑定的当期推导，不是取消未来结构变化风险。**

10月28日交流第4问以Q3有源占比提升为背景，管理层将毛利稳定归因于自动化、良率、工艺和产品设计改善。H1的同比下降与Q3的占比提升属于不同期间，可以同时成立；Q3没有分部表，不能自行算出每项措施的利润贡献。

### 6.3 技术竞争真实，全面替代论点需要收窄

康宁GlassBridge具备玻璃波导与被动对准等技术路径，官网同时将其定位为FAU方案的补充选择；2026年3月产品册已存在，6月24日会议并非首次公开技术。未取得头部客户量产替换天孚、天孚相关收入下降或已丢单的公开证据。技术可行性不能直接推导成天孚护城河已毁。[康宁原文S11](sources.md)

反面也不能忽略：新连接架构可能减少某些分立器件或改变单端口价值分配；自动化设备可降低竞争者进入门槛。但购买FAU整线不等于已掌握良率、工艺配方和客户认证，天孚自身同样使用自动化。旧主题中的“公司H就是Fabrinet”未证实，不进入事实基线。

因此Bear保留“技术适配失败/客户转供”的条件路径，Base不预设已经发生。CPO对天孚同时存在新增连接需求和价值分配变化两面，不能简单套用纯可插拔模块厂的替代逻辑。

### 6.4 现金回收是本轮最需要跟踪的约束

Q3净现比0.524，低于上年同季1.300；应收、库存较H1末分别增长33.95%、37.16%，高于单季收入环比28.41%。管理层称库存包括CPO等关键原料战略储备，但未披露每批库龄和对应订单覆盖；合同负债增长提供部分客户预付款支持，不能据此确认全部库存可回收。

利润增速优于现金增速仍可与高速成长并存。判别点在未来交付、周转、减值及现金释放，而不是看到库存增加就认定需求崩塌，也不是看到“战略”二字就豁免现金折扣。[现金表与季节性回测](business.md)

AI需求不是通过“大厂退出、挤出利基产能”间接传导，本公司是高速互连器件直接参与方。终端规模与版本见[§2](business.md)：机构预测是需求方向证据，天孚SAM与份额缺失，不能将模块市场总量直接资本化。公司在工艺制造及全球交付有卡位；关键激光料依赖、直接客户集中及国际连接方案竞争仍在。

当前价格对应67.56倍归母TTM、约128.50倍实际TTM简化FCF。市场已经要求未来盈利与现金规模显著扩大，不能用“CPO想象空间”代替[§9](valuation.md)的现金收益桥。

## §8 周期定位与可证伪路径

**定位：AI需求和产品升级驱动的盈利新台阶，叠加高预期与再投资压力；尚不足以证明永续高增长或行业见顶。**

| 正向证据 | 对应约束 |
|---|---|
| Q3收入同比31.50%、利润同比55.30%，较Q2加速 | 单季高毛利不可永续外推，季度分部及ASP未披露 |
| 核心料供给改善，泰国/江西产能兑现 | 未来量产良率、订单覆盖及投资回报仍缺 |
| CPO已交付、2027提量有管理层口径 | NPO仍验证，远期规模并未锁定 |
| 低有息负债与净现金提供抗压空间 | 净现比下降，应收/备货/扩产消耗可分配现金 |

本轮不再把H1低于同业的增长排名作为天孚持续减速或丢份额的证明，也不把股价当日大跌当作业务已证伪。可证伪路径按[§11](index.md)执行：客户和技术实际转供、连续单季现金转化低于旧阈值、连续毛利失守及扩产节点落空。激励目标强烈但不构成锁单，具体口径见[估值](valuation.md)。
