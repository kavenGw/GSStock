# 天孚通信 — §1—§5 商业模式与财务

## §1 能力圈与本次重审

天孚通信向光模块、光互连设备及制造平台提供无源器件、有源封装和光引擎，价值来自精密加工、工艺整合、联合研发、量产良率与交付。AI数据中心需求已形成收入，下一代架构能否持续保留其器件价值仍需验证。能力圈判定为**边界区**：可以核实财务及交付阶段，不能可靠预判每一种耦合技术最终份额。

本轮由2026三季报触发，将7月单文件档迁为七文件。重点改动是盈利基础、毛利结构、现金回收和证据等级：前三季扣非已超过旧档所谓19.7亿元上限；旧1.6T出货数字实际属于卖方预测；GlassBridge技术存在，但全面替代天孚的推导没有客户失单证据。价格与完整模型见[估值](valuation.md)。

三条主要亏损路径：①客户或产品代际变化使高利润不能延续；②应收、库存和扩产持续吞噬现金；③即使公司增长，买入价格已提前计入过多成果。未来十年应持续跟踪认证与工艺优势能否跨代保留，不能按某一季度高毛利作永久判断。

| 快筛 | 本轮结论 |
|---|---|
| 商业模式可解释 | 是，器件/封装/光引擎研发制造与销售 |
| 十年耐久性 | 未证实，技术路线与客户设计持续变化 |
| 护城河 | 窄，工艺、交付与认证壁垒存在；无永久垄断证据 |
| 定价权 | 未取得普遍提价5%—10%仍不流失客户的证据 |
| 盈利现金化 | 有现金生成，但Q3转化走弱，需复评 |
| 债务安全 | 低有息债提供缓冲，定存/受限资金不能全当即期现金 |
| 管理层诚信 | 本轮未发现足以否决的证据；继续核披露和执行 |
| 价格 | 缺安全边际，保持观察 |

## §2 市场规模、跑道和份额边界

天孚服务的是光互连器件与封装环节，**下游光模块TAM不能直接当公司TAM**。各产品统计范围不同，未取得足以计算全公司SAM、分产品SOM和剩余渗透空间的统一数据，本档不编造全球份额。

| 业务/市场 | 可核市场信息 | 对天孚的意义及缺口 |
|---|---|---|
| 无源光器件 | 半年报显示实际业务强增长 | 光纤连接/耦合/隔离等需要随速率演进；细分TAM、公司份额分母【缺】 |
| 有源封装/光引擎 | 800G/1.6T规模交付方向已获公司材料支持 | 有源提产受核心料制约；不能用全模块市场规模直接推公司收入 |
| 以太网光模块终端 | LightCounting **2026年7月版预测**2026增长73%、2031市场800亿美元 | 机构公开预测、非实绩，且非截至10月最新已独核预测；只作终端需求佐证 |
| AI专用光模块终端 | TrendForce **2026年4月版预测**2026约260亿美元、较2025约165亿美元增长逾57% | 与前项定义/时期不同，不能拼接；其同时指出激光器及制造约束 |
| NPO/CPO | LightCounting 2026年5月版模型假设2030—2031年10%—15%的scale-up互连迁移 | 属预测假设，非当期渗透率；单端口器件价值分配仍可能变动 |

10月媒体曾转述更高的LightCounting预测，本轮未取得原机构完整更新，不作为硬数字。跑道方向来自速率升级与数据中心互连，收益捕获取决于设计定点、客户认证和材料供应；没有分产品份额就不能断言公司距离天花板还有多少倍空间。[机构原文S13—S15](sources.md)

金额单位亿元。Q2由H1减Q1，Q3现金流由前三季减H1；2026报告均未经审计。原始口径、页码及算式保存在A1底稿，公开来源见[S1—S4](sources.md)。

Q3营收环比增长28.41%、归母增长23.47%，经营现金流环比下降43.69%。前三季扣非同比增长44.26%，Q3扣非同比增长55.78%，非经常性损益分别仅0.1863亿元、0.0061亿元，利润增长主要来自经营。

2025与2026前三季均呈增长，但本轮未重建足够长的同口径营收/净利序列，**长期CAGR和十年平均ROIC未计算**，不能以一年高增长替代长期质量。前三季加权ROE为32.51%（报告值，非全年）；低杠杆和高利润率解释其回报优势，现金占款使会计回报与股东可提取收益不同。净现金较多也使扣现金ROIC对现金分类敏感，本轮不报虚假精确ROIC。

年初以来应收/存货分别增长73.33%/178.65%，这是时点余额变化；与收入同期同比不是相同时间口径。公司称战略备货包含CPO等关键料，合同负债由年末1.6056亿元增至3.6631亿元，提供一定预收支持；订单覆盖、库龄和后续周转仍未量化。

前三季购建长期资产支出4.9102亿元、简化FCF9.7083亿元；TTM购建6.0026亿元、FCF13.8561亿元。Q3单季FCF约2.7829亿元。H1折旧摊销约1.0379亿元，维护与成长capex未拆。[§9](valuation.md)明确列出估计桥及敏感性，不能把20.8346亿元前三季归母当作可全部分配的现金。

前三季信用减值净损失0.4449亿元、资产减值净损失0.2811亿元；Q3差分约0.2648/0.1775亿元。净损失不等于总计提上界，无法证明没有转回或准备已充分。前三季财务费用0.6175亿元，公司归因汇兑损失增加，但累计汇兑单项未拆；H1汇兑损失0.8585亿元不直接移用到前三季。经营减值及经常性汇率风险不为美化利润一律加回。

### 3.4 资金安全与资本配置

9月末资产82.4495亿元、负债16.5850亿元、归母权益65.7980亿元，资产负债率20.12%；借款和债券项目为空，含一年内到期部分的租赁负债约0.0323亿元。货币资金26.5930亿元中，现金及现金等价物仅9.3943亿元，其余涉及定存/受限等分类；交易性金融资产1.8004亿元。**现金及现金等价物包含在货币资金内，不能重复相加。**

营收下滑30%的压力情形下，低有息债、存量资金与经营回款提供生存缓冲；9.3943亿元现金及现金等价物不能独立覆盖16.3304亿元全部流动负债，仍需定存到期及应收回款。结论是债务风险较低，不能据此宣称无流动性风险。

2026年已实施的2025末期分红折算转增后每股0.50元，加2026中期0.50元，合计每现股本1.00元；按163.23元计算 **0.613%**。这是已实施现金回报口径，不是未来股息承诺。最新已核股本1,090,825,093股由10月24日回购公告及行情交叉支持；本档采用A股口径，不加入未核实收到的H股募资。

10月24日公告拟以1—1.5亿元自有资金回购注销，价格上限350元、尚需股东会通过，不能写已经完成；上限也不是公允价值。10月26日拟投入产业基金0.3亿元，占认缴96.77%、拟不并表，收益尚未兑现。10月授予227.69万股限制性股票约占现股本0.2087%，未归属部分不计入已发行股本，未来摊薄和费用需要跟踪。[S8—S10](sources.md)

管理层评价：诚信未发现否决证据；执行力受益于产能与成本控制，现金转化需后验；资本配置偏中性，注销回购方向与是否以合理价格执行应分开。激励目标有长期导向，也可能提高追逐规模的压力，尚无充分证据认定已发生盲目多元化。

## §4 全球竞争力与客户结构

公司材料支持其全球交付及800G/1.6T产品参与能力，不能据此断言独占全球市场。精密加工、联合研发、产线良率与认证是已观察到的竞争来源；未取得统一可复核的全球份额，旧“全球龙头”标签不转化为数值溢价。与上游激光器厂相比，公司对关键料仍有依赖；与国际连接方案提供商相比，需持续适配不同封装架构。

2025年报具名Fabrinet销售32.6884亿元、占63.31%，前五89.73%，是重要集中风险。2026H1/Q3未更新可比比例，不能说已改善或已经砍单。Fabrinet作为制造平台也可能对应多个终端客户，不能把直接客户占比等同单一云厂暴露。

同赛道参考：10月29日11:30供应商行情显示中际旭创、新易盛PE-TTM分别34.10/24.77倍，天孚67.56倍；同行财报TTM基线未全部独立复算，中际两地价格口径亦不同，仅提示价格要求差异，不构成换仓或便宜判断。结构性同行比较见[关联文档](related.md)。

## §5 护城河：窄、稳定但需持续维护

| 来源 | 支持证据 | 可复制或侵蚀因素 |
|---|---|---|
| 工艺知识与量产经验 | 多类器件平台、良率/设计/自动化改善；高毛利实际兑现 | 代际更迭、设备扩散和上游新方案要求持续研发 |
| 客户认证与协同开发 | 高速产品规模交付及长期大客户关系 | 客户集中导致议价/转供风险，未证明永久排他 |
| 全球生产交付 | 泰国量产、国内基地协同 | 新产能爬坡与地缘政策影响，海外厂址不自动免疫实体限制 |

判定为**窄护城河、目前未见根本损毁，趋势仍需验证**。毛利提升支持当前竞争力，却不能直接证明未来十年的独立定价权；不具网络效应，也没有排除替代方案的证据。Base使用12倍正常化现金收益与该判断一致；Bull提升至20倍，须对应跨代适配、产能效率和现金化一起验证后的稳固平台优势，而非仅凭行业热度升级。
