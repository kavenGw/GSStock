# 光迅科技 — §6–§8 论点与周期

## §6 核心新论点：利润台阶出现，资本回收尚未完成

### 6.1 盈利弹性应获得承认

最强反驳是净利率改善有研发费用和财务费用确认节奏贡献，且只有一季，不能把全部改善归于产品结构。即便如此，Q3收入同比+54.27%、扣非+121.06%、毛利率25.51%，足以推翻“规模扩大永远没有经营杠杆”的旧绝对说法。应把它改为“单季盈利杠杆初现，跨周期保持能力待验证”。[财务拆解](business.md)

受益传导为终端互联需求→高速光器件/模块销售→毛利增加→费用增速较慢→净利润增长；尚缺按速率出货、ASP及芯片自供率，不能将此链条每一环都视为已量化。结构性产品升级与周期性供需偏紧可能并存。

### 6.2 备货可以合理，持续负现金仍有成本

最强多头证据是收入、合同负债及应付账款同时增长，说明库存不必全是滞销。最强反驳是预收并非不可取消订单，应付只是延后付款，均不保证库存可回款。Q3库存121.10亿元、单季CFO−6.45亿元；上年同季现金为正，不能以季节性自动豁免。

本轮不认定利润造假，也不认定库存没有风险。应验证备料能否依次转为产成品、交付、应收及现金。旧按期初计提率推算的2.95亿元只是一项历史机械敏感性，既不是当前应计未计损失，也不是管理层保证可按成本回收的证据；季度缺库龄分类必须承认。

### 6.3 IDM有价值，价值取决于经济回报

公司具备芯片、器件、模块协同及InP/GaAs/硅光等平台，是客观技术储备；认证与工艺积累能降低交付风险。反面是客户可多源采购，技术代际快，垂直整合增加固定资产与研发负担。高端芯片自供率、200G EML商业良率、全成本优势缺少公开量化证据，不能由“IDM”自动推导宽护城河。

### 6.4 扩产：硬的是计划与已投入，收入兑现仍有条件

H1主募投项目拟使用20.738355亿元，已投入1.976388亿元、9.53%，预定可使用2028-07-31。4月注册稿设计新增高速光模块年产499.2万只，属于设计产能。另有自筹激光芯片扩产计划1.8亿元、年产能200万→2400万只，是独立项目，不能与募投混成同一条已达产产线。[S7、S8](sources.md)

结构性受益需要高速互联持续升级且公司拿到客户订单；反驳是竞争者同步扩产可能使ASP与产能利用率下降。公司未披露可验证的产线季度爬坡曲线、良率和具名远期订单，不能把设备支出直接资本化成确定利润。政府媒体采访所述Q4高速产能目标是未来口径，未取得验收证据，不与募投新增设计产能相加。

### 6.5 政策风险按实际覆盖判断

FCC26-50组件终规已经形成，但只针对Covered List相关生产主体的逻辑组件与新授权范围，未在该规则中一概扩至所有受foreign-adversary控制的企业，已授权设备不追溯。S.5548针对联邦关键系统采购光模块的立法仍是提案。两者不可拼成“中国光模块全面禁运”。[S9、S10](sources.md)

反面同样成立：范围有限不等于风险消失，后续扩围或客户合规偏好仍可能影响新增业务；也不能把其他企业被列名等同本公司被覆盖。公司北美数通收入子集【缺】，不使用境外总收入替代北美敞口。触发重估的应是明确覆盖本公司、产品或客户供应链的正式条款及实际受影响收入。

## §7 AI与概念潜力：产品、验证、收入分层

| 维度 | 当前证据及兑现阶段 | 判断 |
|---|---|---|
| AI高速数通互联 | 半年报确认需求传导，800G出货占比提升、1.6T具备批量交付能力；未给按速率收入、订单金额及纯AI利润 | 【真敏感】产品与终端需求有实证，专属财务贡献不可量化 |
| 国内CSP的NPO | 2026-03-17官网披露3.2T硅光NPO完成国内头部CSP系统验证，强于实验室样机；无可辨认量产收入 | 【真敏感】客户系统验证真实，仍不得直接加入OE |
| XPO/CPO及更高速路线 | 9月ECOC披露12.8T XPO实测、6.4T NPO方案和400G/lane展示；未给批量毛利 | 【真敏感】属于相关技术储备，当前只是产品层敞口 |
| OCS与DCI | 官网展示320×320 OCS、800G ZR Lite城域DCI产品，未披露独立财务金额 | 【真敏感】潜在新应用可跟踪，未兑现收入不另加估值 |
| “国际厂商退出带来确定转单” | 未找到公司正式披露的对应转单金额或不可逆退出证据 | 【蹭概念】以该说法解释确定未来利润缺乏证据 |

“数据与接入”同时包含数通、PON及无线接入，不能用其H1增速+16.01%代表纯AI数通增速，更不能用它反证Q3增长并非AI驱动；反向声称全部增长来自AI也没有证据。Q3未披露产品及地区拆分，保留未知。

AI未来跑道使用终端市场兑底：[TrendForce](sources.md)预测2026年AI专用光收发器260亿美元、较2025年165亿美元增长超过57%；[LightCounting](sources.md)对800G端口增长及1.6T起量给出乐观预测。机构统计范围及收入/端口单位不同，不合并成一个确定TAM，更不将公司数通份额4.7%直接乘AI专用TAM。客户匿名，终端CSP资本开支与公司采购合同无法一一对应，未来订单能见度仍不足。

技术替代有双面：NPO/CPO可减少功耗并重分配可插拔模块价值量；公司主动布局降低路线缺席风险，但新架构收入未证实足以补偿旧架构损失。LightCounting对2030–2031年scale-up互联10–15%转向NPO/CPO的判断是预测情景，不能写成确定渗透率。

## §8 周期定位与关键假设

判为**扩张期中的结构升级候选，尚非已证明的永久盈利新台阶**。正面是收入与毛利同比改善、利润弹性出现、客户预收上升、扩产已有投入；反面是库存及负现金、同行同步扩产、产品代际变化和未来客户锁单证据缺失。没有证据断言行业已经见顶，也不能断言利润率永久保持Q3高位。

估值依赖四项可证伪假设：一是高速需求仍可支持正常化收入高于旧业务规模；二是净利率不会全部回落，但低于Q3峰值；三是扩张期营运资金占用会收敛，不能永久保持当前失血；四是技术与政策变化没有使现有客户认证和产品能力大幅失效。最脆弱的是第三项，若现金迟迟不能转正，正常化OE15亿元的base需要向下重做。[场景和概率](valuation.md)
