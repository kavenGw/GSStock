# 源杰科技 — §9 估值与相对旧档变化

## §9 估值：盈利基数上修，估值倍数纠错

**估值时点为2026-10-30收盘，688.99元；总股本124,500,377股，市值857.7951亿元。** 10月31日为周六。每股价值和利润均为人民币，无汇率换算。股本来自Q3报告第9页，收盘价由腾讯和Yahoo历史行情交叉，quote_guard通过；详见[来源](sources.md)。

### 9.1 从会计利润到正常化所有者收益

前三季扣非归母9.2392亿元，Q3单季4.0947亿元，其简单年化16.3790亿元仅为顶部参照，**不作为任何一档正常化利润**。前三季经营现金8.6281亿元、全部购建长期资产现金10.5277亿元，FCF为−1.8995亿元；实际维护/成长capex、折旧及必要营运资本桥未充分拆分，不能声称已精算本期owner earnings（OE）。

以下是分析者对需求、毛利、维护投入与营运资金的联合情景假设，不是公司盈利指引，也不是已实现自由现金流：

| 情景 | 正常化年度OE | 占Q3扣非顶部年化 | 盈利与现金约束 |
|---|---:|---:|---|
| Bear | 3.5亿元 | 21.37% | 供给释放、客户重排使紧缺溢价消退，保留成熟产品业务，但毛利与现金回报大幅归一化 |
| Base | 8亿元 | 48.84% | 承认CW结构性新台阶，高于旧4.5亿元；对当前高毛利、预收款回款及新增维护/营运资本需求折价 |
| Bull | 12亿元 | 73.26% | 成熟CW及已批量产品持续放量，规模优势保留；仍预留再投资和毛利回落，不添加200G/CPO新品独立利润 |

OE公式是净利＋折旧摊销−维护capex−必要营运资金增加。因分项缺失，上表综合折扣只能作为区间判断，不是假精确的逐项现金桥。增长capex不是永久维护支出，不能将55亿元级项目总计划全扣OE，再因扩产重复打相同折扣；本模型同时不将尚未达产的新园区利润计入，也不额外分配现有净现金。

### 9.2 主业与投资资产分开计价

Q3长期股权投资2.2710847969亿元＋其他权益工具1.2349781137亿元＋其他非流动金融资产0.2980240022亿元＝**3.8040869128亿元**。其中重要联营为观新光源基金。以扣非归母近似主业起点，已剥离非经常性投资重估，**不能再扣一次约0.967亿元投资非经常收益**。合并利润表投资收益与非经常表穿透金额不同，不能混用。

上述投资资产按账面70%计值，合计**2.6628608390亿元**，统一加至三档主业价值。30%折扣为分析者对非上市流动性和估值回撤的假设，不是市场报价。这里已是公司持有资产账面额，不再乘一次基金持股比例。现金等价物扣保守债务约2.6670亿元，因运营与扩产需求未知，**不再额外加净现金**，避免假设其全部可分配。

### 9.4 倍数与成长证据包

11/20/25倍分别对应竞争回归、较强技术与客户验证壁垒、乐观持续成长。20倍已要求成长兑现、资本回报不明显恶化；25倍是宽护城河参考上沿的乐观情景，**不是已证明公司拥有永久宽护城河**。旧35/55倍超出本轮可辩护主锚，予以纠错。兄弟档中际旭创16/26/29倍、Lumentum18/26/34倍仅作口径约束，产品和资本结构不同，不据此直接给源杰溢价。

| 成长证据 | 已有支持 | 未闭合约束 |
|---|---|---|
| 扩产 | 二期工程与新园区计划【硬，公司公告】；管理层预计分别支持2027/2028产能 | 形成产能不等于满产，良率曲线、产能消化及确定增量收入【缺】 |
| 客户能见度 | 管理层称未来两年需求能见度高【硬，定性预期】；终端光模块增长【软，机构预测】 | 具名不可取消订单、价格、客户指引与源杰份额配对【缺】 |
| TAM跑道 | AI高速互联升级与CW外部光源架构有依据 | 细分CW可服务市场、当期份额与可获订单【缺】，光模块总TAM不可直接套用 |

因此不能只凭单季爆发把Bull权重提高。假设长期需求、毛利或再投资回报改变，应重算整套模型，不能靠抬倍数填补价值差。

### 9.5 旧倍数压力测试与买点

仅为区分盈利上修与方法纠错，保留旧12/35/55倍、采用新3.5/8/12亿元OE和新25/55/20%概率，再加同一投资权益，期望值约**240.29元/股**，仍低于688.99元。此为**❌破框架的旧倍数压力测试，不作为主锚或买点**；旧Bull55倍尤其缺乏可持续回报支持。

不确定性较高，要求期望值至少40%折价，对应研究买区约**≤77元/股**（128.7449×60%＝77.2469）。约**130元/股**只是重新完整审查的参考线，仍需同步更新利润、资本需求与风险；不以历史价格自动触发买入。现价无新增买入依据。
