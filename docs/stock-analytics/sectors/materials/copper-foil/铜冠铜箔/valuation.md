# 铜冠铜箔 — §9 估值（场景加权）+ 相对旧档变化清单

## 9. 估值（场景加权）

### 9.1 正常化口径（禁用 H1 年化）

**H1 年化 4.30 亿元（归母 2.1488 亿 × 2）是周期顶读数，位于本档正常化区间上界之外，不得作为 base。** 理由：① 铜价 2026-08-05 逼近 14,125 美元/吨历史高位，营收含不属于公司的铜价水分；② 加工费处上行中段但顶部风险落在 2027 年；③ 本期利润含存货跌价转回 388.55 万元 + 信用减值转回 1,431.70 万元（合计约 +1,820 万元），中报自标「是否具有可持续性：**否**」。

**正常化营收**：不沿用旧档「80–100 亿元」（该区间含铜价历史新高水分）。改按 **销量 7.2–7.6 万吨 × 正常化铜价 + 加工费** 口径 → **70–85 亿元**。（对照：H1 营收 40.21 亿 × 2 = 80.4 亿；若铜价回归近三年中枢约 −20~25%，同等销量下营收落至 65–75 亿。）

**正常化综合毛利率**：旧档 5–7% 被中报证伪为偏保守（26H1 实际 **8.42%**、26Q1 8.79%、26Q2 8.11%，连续两季高于旧上限），上修至 **6.5–8.5%**。上修依据是**不可逆的产品组合改善**——高频高速基板用铜箔占 PCB 铜箔产量由 >30% 升至 **>50%**，PCB 箔分部毛利率 5.56% → 11.60%（+6.04pct），而非单纯的加工费周期。下界 6.5% 对应加工费回落至 2025 年水平，上界 8.5% 对应加工费仅温和回落。

**正常化净利：2.7–4.2 亿元，中枢 3.5 亿元。**

```
中枢测算：营收 78 亿 × 毛利率 7.5% = 5.85 亿毛利
        − 年化期间费用约 2.1 亿（H1：销售 0.035 + 管理 0.182 + 财务 0.241 + 研发 0.556 = 1.014 亿）
        − 所得税（高新 15%）
        ≈ 3.2 亿  → 计入少量政府补助等常态项，取中枢 3.5 亿
上界：营收 85 亿 × 毛利率 8.5% → 约 4.2 亿
下界：营收 70 亿 × 毛利率 6.5% → 约 2.7 亿
```

**口径冲突处理（三路数字冲突一律取 A1）**：A3 §1.1 的中报硬数字与 A1 一致。A2/A3 记载的披露日「2026-08-26」为落库日，**本档统一以巨潮原文 2026-08-27 为准**（公告编号 2026-048）。A3 §1.7 的行情快照（107.82 元 / 893.84 亿 / PB 15.93x / PE-TTM 368x）为 2026-08-26 收盘，**已被 A1 §五的 2026-08-27 收盘锚（114.53 元 / 949.47 亿 / PB 16.93x / PE-TTM 391x）取代**，全档安全边际一律对 **949.47 亿** 计算；A3 §4.3 基于 893.84 亿得出的「−88%~−90%」相应作废。A3 §1.6 的股息率 0.056% 亦按 107.82 元计；`dividend_yield` 字段按全档唯一锚重算为 **0.000524**（每股 0.06 元 ÷ 114.53 元 = 0.0524%，中期口径；年化两次约 0.105%）。

**敏感性披露 · 若铜价不回落（正常化铜价假设的反向情景）**：本档正常化营收 70–85 亿的核心主观输入是「铜价回归近三年中枢约 −20~25%」。若铜价长期驻留 13,000–14,000 美元/吨而不回落，同等销量下正常化营收应上修至 **80–90 亿元**，base 正常化净利中枢升至约 **4 亿元**，base 内在价值升至约 **80 亿元**（4 亿 × 20x），期望内在价值升至约 **68 亿元**，安全边际约 **−92.8%**。

> 该反向情景**不改三情景主表**（§9.3 仍以 70–85 亿营收口径为准），仅用于暴露正常化铜价假设的敏感度。结论方向不受影响：即便铜价维持历史高位这一对多头最有利的假设成立，安全边际仍在 −93% 附近，评级不变。原因是铜价对本标的是**透传项**——它抬高营收却不改变加工费，对利润的贡献远小于对营收的贡献（见 [§3.3](business.md)）。

### 9.2 合理倍数与隐含 ROE 检验

**合理 PE 区间：15–25x（中枢 20x）。** 定性依据：大宗加工业 + 存量产能 + 销量近零增长 + capex 归零 + 经营性现金流为负 + 加工费高位不可外推 → **不适用成长股倍数**；上界 25x 已计入 HVLP 国产替代的稀缺性溢价与 TAM 跑道。

> **关于 TAM 跑道被两处引用是否构成重复计价**：不构成。两处的作用逻辑相互独立——**bull 概率门控**问的是「bull 情景**是否可能发生**」，其判据是扩产达产确定性与客户 capex 能见度**是否被证伪**（本档两项分别为证伪与降级，故概率封顶 10%）；**倍数上浮**问的是「bull 一旦发生，**该给多少倍**」，其判据是届时盈利中枢的可延续性与稀缺性。TAM 跑道在前一处只提供「不为零」的下限（若连 TAM 都不成立，bull 概率应归零而非 10%），在后一处提供倍数上沿。前者未因 TAM 通过而提高概率——概率恰恰是被另外两项**压到封顶值**的。

**为何高于兄弟档嘉元科技的 12–18x**（同 copper-foil，见 [related.md](related.md)）——三条可核验差异：

1. **产品结构**：嘉元主业为锂电铜箔（周期底、微利），铜冠 PCB 铜箔占营收 62.3%、贡献毛利 **85.9%**，且其中高频高速已占产量 >50%；铜冠的盈利中枢挂在 PCB/HVLP 而非锂电。
2. **HVLP 稀缺性**：铜冠 HVLP1-4 全系列已批量供货、RTF 铜箔内资企业产销第一、实现规模化出口【硬】；嘉元无同等级 HVLP 量产地位。
3. **TAM 跑道**：高频高速覆铜板与高端铜箔国产化率不足 20%【硬，公司引用】，替代空间是铜冠倍数上沿的唯一支撑（也是其成长证据包中**唯一通过**的一项）。

> **诚实边界（不得省略）**：上述三条只支撑「铜冠 > 嘉元」的**相对**排序，**不支撑绝对倍数的合理性**。绝对合理性由下面的隐含 ROE 检验裁决。

**隐含 ROE 检验（buffett-doc-spec §3 铁律）**：

- 正常化 ROE = 3.5 亿 ÷ 归母净资产 56.10 亿 = **6.24%**，**低于本标的应有的股权成本**（实质无分红、经营现金流为负、加工费高位不可外推 → 应取 ≥10%）。
- 由 PE 反解隐含 PB：bear 15x × 4.81%（2.7/56.1）= **0.72x**；base 20x × 6.24% = **1.25x**；bull 25x × 7.49%（4.2/56.1）= **1.87x**。三档满足 bear < base < bull，利润法未失效，**不触发改资产法主锚**。
- **因此 A3 §4.3 建议的「合理 PB 1.5–2.5x」与其自身建议的 PE 15–25x 内部不自洽**（PB 上界 2.5x 对应 PE 33x）。本档**以 PE 法为主锚**，PB 法仅作交叉验证并采用上述由 PE 反解的隐含 PB 阶梯；A3 的 84–140 亿 PB 法区间**不进入加权**。
- **框架内下界披露**：按 buffett 倍数框架，周期/衰退型应 <8×、窄护城河 8–12×。本档 15–25x **已在框架之外**，逐档标记 **❌破框架**。若严格按框架内 8–12x，base 内在价值仅 **28–42 亿元**（中枢 35 亿），安全边际将为 **−96.3%**。本档保留 15–25x 是对 HVLP 稀缺性与 TAM 跑道的**最大让步**；读者应知：该让步已使估值结论系统性偏向多头一侧，而结论仍是 watch。

### 9.4 期望内在价值与安全边际

```
期望内在价值 = 105 亿 × 10% + 70 亿 × 50% + 40.5 亿 × 40%
            = 10.5 + 35.0 + 16.2
            = 61.7 亿元

每股 = 61.7 亿 ÷ 8.29 亿股 = 7.44 元
```

```
安全边际 = (61.7 − 949.47) / 949.47 = −887.77 / 949.47 = −93.5%
```

**bull 单情景压力测试**（与兄弟档嘉元科技同法）：

```
bull 压力测试 = (105 − 949.47) / 949.47 = −88.9%
```

即**假定本档最乐观情景 100% 兑现**（加工费维持 20–25 万元/吨、份额不失、高频高速占比继续爬升，且给到破框架的 25x），现价仍高估约 **8.0 倍**。安全边际的负值不来自情景概率的保守，而来自价格本身。

**与横向锚的距离**：铜冠 PB 16.93x vs 德福科技 11.99x、中一科技 3.49x、嘉元科技 2.19x（腾讯口径 2026-08-26 快照，仅作排序参考）。铜箔行业估值分化的解释变量是 HVLP/高频高速敞口比例——而恰恰是这一敞口，公司**未给出营收口径披露**。

**与兄弟档嘉元科技的一致性**：嘉元安全边际 −85.5%、bull 压力测试 −71.7%、评级 watch；铜冠 −93.5% / bull −88.9%、评级 watch。两档同法、同结论方向，铜冠更极端。
