## §0 结论摘要（倒金字塔）

**评级：exclude（回避）。相对旧档评级未翻转，但翻转的是全部理由。** 旧档写的是"资源稀缺但根本不赚钱的高估概念股"；本档写的是"**一个已经发生的真拐点，配上一个与之相差 32 倍的价格**"。

- **期望内在价值**：三情景概率加权 **19.60 亿元 / 每股 3.00 元**（bear 33% / base 45% / bull 22%）。
- **三情景一句话**（完整推导见 [valuation.md §9](valuation.md)）：
  - **bear（33%）**：锗价复刻 2025 剧本回落 + InP 过剩窗口提前 → 正常化归母 ≈ 0，**利润法无解**，以资产法 PB 0.9× 定价 → **13.81 亿元 / 每股 2.11 元**。
  - **base（45%）**：锗主业穿越周期归一化 + InP 成为真实第二主业但不爆发 → 正常化归母 **1.00 亿元**（隐含 ROE 6.5%），PB 1.2× → **18.42 亿元 / 每股 2.82 元**。
  - **bull（22%）**：45 万片按期达产 + 合同按上限履约 + 锗价向现货靠拢 → 正常化归母 **2.53 亿元**（隐含 ROE 16.5%），PB 2.0×（隐含 PE 12.1×，仍在窄护城河框架内）→ **30.70 亿元 / 每股 4.70 元**。
- **安全边际**：对收盘锚市值 650.90 亿元，(19.60 − 650.90)/650.90 = **−97.0%**【收盘锚 2026-08-28】。**bull 单独压力测试 −95.3%**——即便最乐观情景全部兑现，市价仍是内在价值的 21.2 倍。
- **一句话**：26Q2 是这家公司有记录以来最强的单季（扣非 6,205.66 万元），InP 已经独立盈利（鑫耀单体净利 5,705.74 万元 = 合并净利的 74.7%）——**这些都是真的**。但同一个半年里经营活动现金流 −1.568 亿元、自由现金流 −2.747 亿元、**全口径带息债务 16.41 亿元（净有息负债 = 归母净资产的 79.7%）**；营收增长 100% 来自销量、价格是 −2.55 亿元的净拖累；三条 AI/航天/军工需求叙事里有两条在业绩层是负增长。**拐点为真不等于价格为真：PB 42.41× 要成立，需要一个 343% 的可持续 ROE。**

### 10.3 为什么是 exclude 而不是 watch

buffett 框架下 watch 的含义是"好生意，等价格回到合理区"。本标的**两个前提都不成立**：

1. **生意质量尚未达门槛**。base 情景的正常化归母 1.00 亿元对应隐含 ROE **6.5%**，仍低于其自身风险对应的 12% 股权成本——**在最可能的情景里，这门生意仍在毁灭而非创造股东价值**。bear 情景更直接：正常化归母 ≈ 0，利润法给不出任何数字，只能用资产法托底。26H1 加权 ROE 4.96% 是历史最好的半年，但 [L25] 回测已证该公司 H1 不可外推全年（24H1 毛利率 14.69%→全年 28.48%；25H1 23.98%→全年 21.12%，两个方向的反例都有），**4.96% 不可简单年化为约 10%**。
2. **价差不是"回落"级别，是量级级别**。安全边际 −97.0%，市价 = 期望内在价值的 **33.2 倍**。watch 适用于折价 20–50% 的等待，不适用于 32 倍的差距。

**"拐点只有一个季度的证据"**是本次不给 watch 的第三条理由：公司把「其他收益 1,079.85 万元（与资产相关的政府补助）」**主动界定为经常性损益并留在扣非之内**；用同一口径剔除后，26Q1 扣非**接近 0 甚至微负**，26Q2 才是真正的经营性拐点。**目前"拐点"的样本量 = 1 个季度**（详见 [business.md §3](business.md)）。

| 4 | **利润不变现金 + 杠杆抬升**（替换旧档恒为真的"经营现金流转负"） | 现金流量表、附注「带息债务」披露（**全口径，含长期应付款**）、资产负债率、受限资金、应收账款增速 vs 营收增速 | 资产负债率 **>65%**（当前 59.06%），**或**全口径带息债务自 **16.41 亿元**再增 30% 以上（**即超 21.3 亿元**），**或**净有息负债/归母净资产自 **79.7%** 升破 **100%**，**或**应收账款增速连续两期超营收增速 **15pct 以上**（当前 +55.2% vs +38.21%，超 17pct，已在触发边缘） | 资产负债率序列 2022 38.31% → 2024 52.53% → 26H1 59.06%，**是连续变量不是常真布尔量**。⚠️ **口径纪律：只看「短期借款+长期借款+一年内到期」的银行类小计（11.48 亿）会漏掉 4.93 亿长期应付款，把风险画像从 79.7% 误读成 47.6%——必须用半年报 P122 的带息债务全口径** |

### 11.3 补充观察项（不设硬阈值，但每期必看）

- **出口管制二元窗口**：商务部 2025 年第 72 号公告暂停 2024 年第 46 号第二款，**有效期至 2026-11-27（距今 3 个月）**。届满后延长 / 恢复 / 永久取消三种处置对本股**方向不同号**——公司境外收入仅 1,062 万元（占 1.45%、同比 −58.45%，FY2024 曾占 17.62%），**几乎不出口，吃不到国内外价差溢价**；"恢复禁令"压制的是公司自身出口通道，"取消禁令"压制的是国内锗价。**任何把该窗口当单边利多或单边利空的写法都是错的。**
- **筹码结构（回撤缓冲缺失）**：陆股通本期**减持 17,053,241 股、期末仅余 5,752,006 股（0.88%）**；章建平新进 6,659,800 股（1.02%，第 4 大股东，国泰海通**信用担保账户**），王萍 / 葛贵兰 / 金澹资产添利七期等多名自然人与私募亦走**融资融券信用账户**；控股股东临沧飞翔冶炼质押 **3,550 万股（占其持股 39.6%）**。→ **外资撤离 + 筹码游资化 + 两融杠杆化**。触发观察：控股股东质押比例 >50%，或信用担保账户合计持股占比继续上升。
- **股东回报机制缺位**：半年报「市值管理制度 / 估值提升计划 / 质量回报双提升方案」**三项披露均为否**，无回购、无股权激励、半年度不派现。股息率 0.010% 意味着**下行时无任何现金回报缓冲**——这是 commodity + 概念高估股最危险的组合。
- **公司自愿披露口径的不可核性（写给下一轮）**：良率（半年报与两次 IR 一致只给"国内领先、国际先进水平"）、客户名单（合法豁免）、自有矿锗自给率（两份定期报告均未披露）、前五大客户集中度（半年报无该表）——**这四项一律不得再进入任何触发器**，否则重蹈旧档触发器 4 的覆辙。

### 11.4 卖出准则逐条检查（若已持有）

1. **价格严重高估？** 是。安全边际 −97.0%，bull 压测 −95.3%，PB 42.41×，发行人本人三次公告自认高估。
2. **护城河根本性摧毁？** 否，但需重新定性：最像护城河的锗资源禀赋**从未转化为超额回报**（五年均 ROE +0.43%），InP 是暂时技术领先而非结构壁垒（详见 [business.md §5](business.md)）。
3. **管理层诚信问题？** **否，且方向为正**——公司在股价高位主动三次发布风险提示、自认非理性炒作、如实披露境外收入腰斩与三条产品线负增长、明确拒绝对良率给数字而非编造数字。**这是本档少见的加分项**（详见 [business.md §5](business.md)）。
4. **有显著更好的机会？** 是。同为出口管制小金属 + price-taker 的兄弟档在可比框架下均有更低的估值分位。
