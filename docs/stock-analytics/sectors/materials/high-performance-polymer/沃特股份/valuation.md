# 沃特股份 — §9 估值（场景加权）

## §9.1 估值方法选择：主锚 = 资产法（PB），利润法作交叉验证

**本 subsector 首建档，无兄弟档口径可参照。**本节确立的口径供后续 `high-performance-polymer` 档继承。

### 9.1.1 TTM 分母口径（供继承）

公司收入与利润**明显下半年偏重**：2025 年 H2 归母净利 4,598.92 万元 = H1（1,840.80 万元）的 **2.50 倍**，H2 营收 11.46 亿 = H1（9.064 亿）的 1.26 倍。**因此 26H1 的任何指标一律不得 ×2 年化**，分母统一走滚动法：

```
TTM 归母净利 = 26H1 2,742.57 万 + 2025 全年 6,439.72 万 − 25H1 1,840.80 万 = 7,341.48 万元
TTM 扣非归母 = 26H1 2,009.23 万 + 2025 全年 3,859.91 万 − 25H1 1,230.05 万 = 4,639.09 万元
TTM 营业收入 = 26H1 10.698 亿 + 2025 全年 20.52 亿 − 25H1 9.064 亿 = 22.15 亿元
```

### 9.1.2 当前倍数（锚：2026-08-31 收盘 29.04 元 / 总市值 76.43 亿元）

| 分母 | 值 | 倍数 |
|---|---|---|
| TTM 归母净利 | 7,341.48 万元 | **PE-TTM = 104.1×** |
| TTM 扣非归母 | 4,639.09 万元 | **扣非 PE-TTM = 164.8×** |

> **【估算】标注说明**：EV/EBITDA 因 2025 全年折旧摊销明细【缺】、以 26H1 EBITDA（1.175 亿元）×2 近似；因下半年收入偏重，真实值或落在 **30–36×** 区间。净债务 = 短借 6.4146 亿 + 长借 3.9439 亿 − 货币资金 2.2251 亿 = **8.13 亿元**。

### 9.1.3 为什么 PE 不能作主锚

**不是因为公司亏损，而是因为利润基数太小、构成太脏。**

1. **基数过小 → 假精确**：TTM 归母 7,341 万元，2023 年一度只有 **590 万元**。分母在千万量级时，任何一笔政府补助或公允价值变动都能让 PE 跳动几十倍，倍数**不具辨识力**。
2. **构成脏**：26H1 非经常性损益 733.34 万元占归母净利 **26.7%**（政府补助 640.45 万 + 金融资产浮盈 265.68 万）；2025 全年该比例达 **40%**。扣非口径下 PE 直接从 104.1× 变成 164.8×。
3. **owner earnings 口径下可能为负**：

```
owner earnings = 归母净利 + D&A − 维持性 capex − 营运资本增加
26H1：2,742.57 万 + 6,597.86 万 − (维持性 capex ≈ D&A) − ΔWC
ΔWC（应收 + 存货，半年）= (63,660.60 + 61,663.33) − (60,209.21 + 58,032.45) = 7,082.27 万元
→ 若维持性 capex ≈ D&A，则 owner earnings ≈ 2,742.57 − 7,082.27 = −4,339.70 万元
```

固定资产账面 11.17 亿元、26H1 环比**下降** 4,102 万元（D&A > 新增），说明维持性 capex 确实不高于 D&A；但**应收 6.37 亿 + 存货 6.17 亿 = 12.53 亿元、占总资产 33.8%、占当前市值 16.4%，且两项占比均较年初上升**——利润正被营运资本吸走。**owner earnings 接近零甚至为负，利润法在本股整体失效。**

**→ 按 `buffett-doc-spec` §3「利润法整体失效 → 三档改以资产法为主锚、利润法作验证」执行。**

> **触发路径说明**：spec §3 该条款的字面描述是「bull 降回框架内倍数后出现 bull < base → 利润法整体失效」。**本档走的是另一条独立触发路径——owner earnings 为负导致利润法在源头即无法成立**，三档全程保持 bear < base < bull，**未出现倒挂**。两条路径指向同一处置（改资产法主锚），但触发条件不同，此处显式区分以免后续档误读为「本档出现过 bull<base」。本股是重资产材料企业（固定资产 11.17 亿 + 在建工程 3.77 亿 = 归母净资产的 80.5%），**不属于该条款排除的轻资产软件股**，准入成立：bear 的资产托底真实存在（商誉仅占净资产 1.85%、无爆雷、无年度亏损、资产负债率 48.11%）。

## §9.2 隐含 ROE 阶梯（PB 主锚的定量基础）

股权成本 **r = 12%**，依据（`buffett-doc-spec` §3「高杠杆 / 无股息 ≥12%」）：有息负债 10.36 亿 vs 货币资金 2.23 亿；财务费用 2,097 万 ≈ 扣非净利 2,009 万（1.04 倍）；股息率仅 0.26%；三大控制人质押 19.88% / 37.56% / 42.14%；当日换手 31.39%、年内振幅 −48%→+73%。

永续无增长 RIM 简化：**公允 PB = ROE ÷ r**。

| ROE 情形 | 数值 | 收益能力口径公允 PB | 对应每股 |
|---|---|---|---|
| 5 年（2021–2025）均值 | **2.58%** | 0.215× | 1.51 元 |
| 2025 峰值 | **3.56%** | 0.297× | 2.09 元 |
| base 假设（修复） | 5.5% | 0.458× | 3.22 元 |
| bull 假设（回到 2019–2020 水平） | 8.5% | 0.708× | 4.98 元 |

**这个阶梯的结论是刺眼但必须写出的**：即便在 bull 假设下，纯收益能力口径的公允 PB 也只有 **0.71×**，远低于当前 4.12×。三档若照此定，每股价值区间是 1.51–4.98 元——**理论正确但完全脱离任何可观察的交易区间**（本股历史 PB 底部在 2.2× 附近：52 周低点 15.50 元 = PB 2.20×，年内低点 16.81 元 = PB 2.39×）。

**故本档在 RIM 之上叠加资产重置托底**：净资产 18.53 亿中，固定资产 11.17 亿 + 在建工程 3.77 亿是真实、在产、可重置的产能资产（LCP 2 万吨树脂、特种尼龙 1 万吨、PEEK 一期 500 吨、PTFE 制品线），商誉仅 3,430 万（1.85%），应收存货虽大但账龄结构未见异常、26H1 资产减值计提 509.60 万元规模可控。**按 `buffett-doc-spec` §3「隐含 ROE 低于股权成本 → 公允 PB 在 1× 附近」，bear 锚定 PB 1.00×。**

**三档的锚定方式并不相同，如实写明（不粉饰为统一方法）**：

| 档 | PB | 锚定方式 |
|---|---|---|
| bear | 1.00× | **RIM（0.215–0.297×）+ 资产重置托底上调**——唯一真正沿用本节 RIM 阶梯的一档 |
| base | 1.60× | **由同业倍数锚定**（隐含 PE 29× 落在改性塑料同业 23–43× 中枢，见 §9.3），**RIM 的 0.458× 作为下界参照而非取值** |
| bull | 2.60× | **由同业倍数锚定**（= 改性塑料同业上沿 2.25× + 特种材料溢价，低于概念端 3.6–6.4×），**RIM 的 0.708× 作为下界参照而非取值** |

**为什么 base/bull 弃用 RIM 取值**：永续无增长 RIM 假设 g=0，对一个营收仍在 +18% 增长、且 base/bull 的全部逻辑正是「ROE 从当前水平修复」的标的，g=0 会系统性低估——RIM 在本档的正确用法是给出**下界**（说明「即便如此，公允 PB 也远低于当前 4.12×」），而不是直接充当 base/bull 的取值。三档保持 bear < base < bull。

**本档不使用任何超出框架的倍数，无「❌破框架」行。**

## §9.3 三情景

### bear 40% — 每股 7.04 元 / 市值 18.53 亿元 / PB 1.00×

**情景描述**：PTFE-PCB 收入停在 400 万/半年这个量级（年化 800 万），M10 材料体系或未定案 PTFE 复合、或定案而沃特未进认证名单；市场把标签从「AI 高频材料」撕回「改性塑料 + 特种材料平台」，按账面净资产定价。ROE 停在 2.5–3.5%（= 过去 5 年的实际区间）。

**赋权理由（40%，最高）**：本轮**几乎全部硬证据都指向这一侧**——① 公司自己在异动公告中把 PCB 用收入拆到 0.37% 并自述「不会对经营业绩产生重大影响」（[§6](thesis.md)）；② 综合毛利率十四年锁在 15–19%、特种材料占比升到 54.08% 而毛利率无结构性抬升（[§3](business.md)）；③ 十年利润零增长（2025 归母 6,439.72 万 ≈ 2020 年 6,474.30 万 ≈ 2015 年 6,323.02 万，而同期营收扩张 3.5 倍）；④ 募投产能三年只投 39.39%、半年投 395.88 万、1.4 亿募资拿去理财（[§8](thesis.md)）。**这些不是预测，是已发生的事实。**

**交叉验证**：EV/Sales = (18.53 + 8.13) ÷ 22.15 = **1.20×**，对一家毛利率 16.84%、TTM 净利率 3.31% 的材料公司属合理下沿而非清算价。

**必须正面回应的一个矛盾：PB 1.00× 低于本股有记录以来的最低交易 PB。**
本股历史交易 PB 底部在 **2.2×** 附近（52 周低点 15.50 元 = PB 2.20×；年内低点 16.81 元 = PB 2.39×），且 **2023 年 ROE 史上最差（0.43%）时，市场也没有把它打到 1.00×**。本档 bear 仍取 1.00×，理由是：

1. **1.00× 是收益能力口径的公允值，不是对交易价格的预测。**它由 RIM（0.215–0.297×）上调至资产重置托底得来，回答的是「这些资产按其产生的回报值多少」，而**不是**「市场最悲观时会报什么价」。这两个问题的答案在本股上长期不一致。
2. **「交易 PB 长期高于公允 PB」这件事本身，就是本档『贵』这一结论的组成部分**，不是对本档方法的反驳。如果市场从不按公允价定价这只股票，那正说明它长期含有一块与基本面无关的溢价——把历史交易底部当作估值下限，等于把这块溢价当成永久地板写进模型。
3. **可辩护性上界（诚实标注）**：若读者认为估值应锚定于可观察的交易区间而非公允值，**bear 按历史交易 PB 下沿 2.2× 计约为每股 15.5 元**，此时期望内在价值升至约 14.02 元 / 36.89 亿元（= 40.80×0.40 + 29.64×0.45 + 48.19×0.15），安全边际由 −63.4% 收窄为 **−51.7%**——**方向仍为负，评级与买点结论不变**。本档保留 1.00× 与 40% 权重，同时把这个区间摆给读者。

### base 45% — 每股 11.26 元 / 市值 29.64 亿元 / PB 1.60×

**情景描述**：PTFE-CCL 不兑现，但公司**已经确定在做的事**兑现——重庆 LCP 2 万吨树脂产能爬坡（26H1 报告已确认「产线有效运行、出货量较快增长」）、沃特华本半导体上海第二工厂 2026H2 投产放量（公司自认「接近产能满产」）、有息负债继续压降（26H1 已还 2.19 亿、短期借款占总资产比降 4.47pct）。ROE 从 2025 年 3.56% 修复到 **5.5%** 左右——即回到 **2021 年（5.57%）** 的水平，不是历史新高。

**赋权理由（45%）**：LCP 是**唯一被半年报单独点名「较快增长」的品类**，且是全司净利率最高的资产（江苏沃特特种材料 10.55%）；半导体装备件是**唯一被公司自己确认为「批量 + 接近满产」**的高价值方向。这两条都是【硬】，与 PTFE 的【软/缺】形成鲜明对比。但**特种材料毛利率同比 −0.13pct 说明规模效应尚未出现**，故只给「修复到 2021 年水平」而不是「结构性抬升」。

**交叉验证（利润法）**：base ROE 5.5% × 归母净资产 18.53 亿 = **正常化归母净利 1.02 亿元**（口径澄清，**不回避一个不利的对比**：该值高于 TTM 的 7,341 万，**也高于 26H1×2 的 5,485 万（为其 1.86 倍）**——它并不比任何一种年化口径都低。它**不违反红线 3「拒绝用周期顶利润定价」的理由不是数值更小，而是它根本不来自年化外推这条路径**：1.02 亿 = base 假设 ROE 5.5% × 归母净资产 18.53 亿，是一条独立于当期利润的资产回报路径；而 **5.5% 是本公司 2021 年已经实现过的 ROE（5.57%），不是历史峰值**（2015 年 26.06% / 2016 年 16.77%），更不是把景气高点年化。换言之，这个正常化利润的可辩护性来自「回到自己五年前的正常水平」，而非「把最好的半年乘以二」）。29.64 亿 ÷ 1.02 亿 = **隐含 PE 29×**，落在改性塑料同业 23–43× 区间中枢（南京聚隆 23.33 / 金发 30.06 / 普利特 42.92）。EV/Sales = (29.64 + 8.13) ÷ 22.15 = **1.71×**。**两条交叉验证都支持 1.60× PB 不是苛刻数字。**

### bull 15%（封顶）— 每股 18.31 元 / 市值 48.19 亿元 / PB 2.60×

**情景描述**：M10（碳氢 + PTFE 复合体系）落地，且沃特经覆铜板厂间接进入供应链；PTFE-PCB 年收入从 800 万跃至 **2–3 亿元**（即当前量级的 25–37 倍）；同时 LCP 薄膜从「中央预算内核心技术攻关项目通过验收」转为量产订单。ROE 回到 **8.5%**，即 2019 年（7.55%）/ 2020 年（7.99%）的水平之上——**仍低于 2015–2016 年的 26.06% / 16.77%，未取历史顶部**。

**赋权理由（15%，封顶）**：按 `buffett-doc-spec` §3 成长证据包三要素门控逐项标记：

| 要素 | 证据 | 判级 |
|---|---|---|
| (a) 扩产达产确定性 | 公司**从未披露 PTFE 薄膜产能数字**（半年报对 LCP 2 万吨、特种尼龙 1 万吨、PAEK 1000 吨、PEEK 一期 500 吨、聚砜 1 万吨**全部给了数字，唯独 PTFE 章节零数字**）；唯一硬线索是附注 P124 抵押借款条款中浙江科赛「年产 8,000 吨高性能新材料及 5G 通讯、半导体装备项目」，属**在建**、非电子级薄膜专项；4.5 万吨募投项目仅 39.39%、延至 2027-08 | **【软偏缺】** |
| (b) 客户 capex / 出货能见度 | 半年报与 2026 年三份投资者关系记录表**均无任何 PCB 客户名**；公司 2026-05-27 已澄清**未获英伟达直接认证、未直供**；无锁定订单金额 | **【缺】** |
| (c) TAM 跑道 | M9→M10 单机柜 PTFE 价值量 3,000–4,000 美元 → 1.2–1.6 万美元（3–5 倍）、2027–2030 年 PTFE 需求年均 +30%——**单一券商口径经财富号转述，未找到第二家机构可交叉验证**；且该数字是全链条 PTFE 口径（含树脂），不等于薄膜环节 TAM，更不等于沃特可得份额。**M10 量产时间表本身【缺】** | **【软】** |

**三要素无一为【硬】，两项【缺/软偏缺】** → 按「三项全软 → bull 概率 ≤20%」封顶，考虑 (b) 实为【缺】（比「软」更弱），**取 15%**。

**bull 单独压力测试（红线 4）**：即便 bull 全部兑现，每股 18.31 元仍比现价 29.04 元低 **36.9%**。**换言之——把市场最乐观的故事完整、无折扣地实现一遍，今天买入仍要亏三成七。**这是本档对「贵」最直接的回答，不用「AI 想象空间」稀释。

**bull 情景的倍数纪律**：PB 2.60× = 改性塑料同业上沿（普利特 2.25×）+ 特种材料溢价，**低于**概念端 PB 3.6–6.4×（泛亚微透 3.61 / 中英科技 6.42），也低于氟化工龙头巨化 4.96×。EV/Sales = (48.19 + 8.13) ÷ 22.15 = **2.54×**。**未破框架。**

## §9.4 期望内在价值与安全边际

```
Σ概率 = 40% + 45% + 15% = 100% ✓

期望每股内在价值 = 7.04 × 0.40 + 11.26 × 0.45 + 18.31 × 0.15
                 = 2.8160 + 5.0670 + 2.7465
                 = 10.6295 ≈ 10.63 元/股

期望市值 = 10.63 × 263,203,565 股 = 27.98 亿元
（分档校验：18.53×0.40 + 29.64×0.45 + 48.19×0.15 = 7.412 + 13.338 + 7.229 = 27.98 亿元 ✓）

安全边际 = (27.98 − 76.43) ÷ 76.43 = −63.4%
```

**确定性档位「低」**（`buffett` 框架要求 40–50% 折扣）。当前不仅没有折扣，还有 **173% 的溢价**（76.43 ÷ 27.98 = 2.73 倍）。

**锚点加严说明**：29.04 元是**涨停收盘价**、当日换手 31.39%、三连板触发异动公告，**不是平静价**。若改以年内低点 16.81 元（2026-07-20）为锚，市值 44.25 亿元，安全边际 = (27.98 − 44.25) ÷ 44.25 = **−36.8%**——**方向不变，仍为负**。即本档结论不依赖于「今天恰好是情绪高点」这一条。
