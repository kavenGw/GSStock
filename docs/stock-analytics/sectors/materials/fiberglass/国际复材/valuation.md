# 国际复材 — §9 估值（场景加权）

> 承接 [§6-§8 论点与周期](thesis.md)，结论落 [§0/§10/§11](index.md)。
> **本节所有市值 / 股本 / PE / PB 只用一组锚**：收盘 31.00 元、总股本 **3,770,878,048 股**、总市值 **1,168.97 亿元**、PE-TTM **171.69x**、扣非 PE-TTM **189.5x**、PB **13.35**、H1 年化 PE **91.4x**（2026-08-31 收盘后，腾讯行情 + 半年报五源交叉，见 [§12](sources.md)）。

## 9.1 owner earnings 口径与两处折扣

```
Owner Earnings = 归母净利 + D&A − 维护性 capex − 营运资本增加
```

- **D&A 与维护性 capex 相互抵消**。半年报未单独披露 D&A【缺】；固定资产 146.09 亿元占总资产 60.71%，玻纤池窑典型 8–10 年一次冷修、行业折旧年限 10–15 年，**冷修支出即维护性 capex 且与折旧同量级**。故本档按「D&A ≈ 维护性 capex」处理，不做加计——这对多头是中性偏保守而非苛刻的处理。
- **营运资本变动很小**：应收 26.24 亿（年初 25.67 亿）、存货 18.77 亿（年初 18.94 亿），周转天数双双改善（存货 94.42 天、应收 94.11 天，均优于 2025Q2）。
- **现金转化折扣 0.93**：26H1 经营现金流 5.933 亿 / 归母 6.397 亿 = **0.93**。本档把这个比值直接作为归母 → owner earnings 的折扣系数，用以吸收营运资本与票据到期的真实占用。
- **不做的两件事**：① 不加回 1.99 亿财务费用（虽然公司归因汇兑、方向上压低了利润，但汇兑在会计上计入经常性损益，且公司已开始套保，本档按"经常项"处理）；② 不加回 4,191 万减值（其中存货跌价 3,991 万，在涨价周期里计提存货跌价本身值得留意，不予加回）。

> **红线 3 自检**：三档正常化归母（4.5 / 8.0 / 11.5 亿）**全部低于 H1 年化 12.79 亿**这一顶部口径，bull 亦低于。
>
> **年化口径限定（全档统一）**：「H1 年化 12.79 亿 / PE 91.4x」出自公司《摊薄即期回报公告》的**测算假设**，公司在该公告中声明其不构成盈利预测，并在 2026-08-20 投资者关系活动中**明确表示不披露全年经营目标**。本档只把它当作"最乐观的可辩护上界"用于红线 3 的封顶自检，**不作为任何一档的预期值**。

## 9.2 一个必须先回答的问题：为什么本档以 PB 阶梯为主锚

**先把适用条件说准确**：`buffett-doc-spec` §3「倍数被迫破框架」条款的触发症状是「bull 降回框架内倍数后出现 bull < base」，**本档并未出现该症状**——纯利润法下三档单调递增（0.89 / 2.37 / 3.41 元/股）。我是**主动**跑了隐含 ROE 回查，而不是被症状逼出来的；下面是扩大适用该条款的理由，如实写清以便复核：三档倍数虽都在框架内，但**利润法给出的每股价值全部低于账面净资产**（bear PB 0.38、base PB 1.02），这与「倍数破框架」是同一个病根的两种表现——**正常化盈利配不上净资产规模**，只不过本档的症状出现在 PB 一侧而非倍数一侧。

隐含 ROE 回查（分母用 26H1 归母净资产 87.535 亿，定增未落地故不摊厚）：

| 情景 | 正常化归母 | 隐含 ROE | RIM 公允 PB（r=12%、g=2.5%） |
|---|---|---|---|
| bear | 4.5 亿 | **5.1%** | 0.27 |
| base | 8.0 亿 | **9.1%** | 0.69 |
| bull | 11.5 亿 | **13.1%** | 1.12 |

**股权成本取 12% 的依据**：资产负债率 62.09%、净有息负债 103.3 亿 = 归母净资产 1.18 倍、股息率 0.065%（实质无股息）、创业板高波动。三档隐含 ROE 中有两档低于股权成本 → **公允 PB 在 1× 附近甚至以下**：**这家公司正常化的盈利能力配不上它的净资产规模**（重资产 + 薄利润）。

但纯 RIM 结果（bear PB 0.27）低于任何可观察的市场底：近 5 年 PB 区间下沿 **1.34**，且该值出现在 2024 年**巨亏 3.54 亿**的年份。玻纤产线是可用重资产（固定资产 146 亿刚由在建工程转固 11.73 亿、无大额商誉），清算/重置价值真实存在。故本档做法是：

> **每档取「资产法（PB 阶梯）与 利润法（框架内倍数）的较高者」**——即在两条独立路径上都给多头以最大善意。这样得出的安全边际若仍为深度负值，结论就不依赖于口径选择。

利润法倍数一律限定在 buffett 框架内：周期/衰退型 <8×、窄护城河 8–12×。**本档 bull 取 12×（窄护城河上沿），任何超出的倍数一律降格进 [§10](index.md) 压力测试并标 ❌破框架**，不进正式估值。

## 9.3 三情景

### bear（30%）—— 旧逻辑依旧：它还是一只重资产周期品

- **逻辑**：2027 供给悬崖兑现（行业已公告约 6.6 亿米/年电子布新增，绝大部分落 2027），常规 7628 布价格从当前约 10 元/米回落；粗纱维持底部震荡（当前 3,600–3,650 元/吨，自底部仅 +15~18%）；本次募投项目 41.95 亿固定资产带来的**年新增折旧 2.8–4.2 亿【测算】**开始上身；高阶料号占比未能显著提升。
- **正常化归母 4.5 亿元**。锚是穿越周期均值：2021–2025 归母 10.97 / 11.44 / 5.455 / **−3.539** / 2.725 亿，五年算术均值 **5.41 亿**；在此基础上扣新增折旧、加回 F16 细纱线的规模效应，取 4.5 亿。
- **owner earnings = 4.5 × 0.93 = 4.19 亿**。
- **利润法**：4.19 × 8x（周期型上沿）= **33.5 亿元**（PB 0.38）。
- **资产法**：归母净资产 87.535 亿 × **PB 1.0** = **87.5 亿元**。取 1.0 而非历史底 1.34，是因为 bear 情景下 ROE 5.1% 远低于股权成本，RIM 指向 PB<1；1.0 是"不低于账面"的下限约束。
- **取较高者 → 87.5 亿元 / 2.32 元/股**。
- **赋权 30% 的理由**：2027 供给窗口是**已公告的、可数的**产能（[§8](thesis.md)），公司投产期 2027-06 与之精确重合；且玻纤上一轮同类情形有实证（2022-06→2024-02 缠绕直接纱累跌 48.7%、2023 年行业利润总额 −51.4%）。这不是尾部假设，是基准情形的对立面，给三成。

### base（50%）—— 一轮常规周期，电子端升级部分留存

- **逻辑**：两条结构性成分留存下来——① LDK 二代已进入多家头部 CCL 厂稳定批量供货【硬】（**兑现量级未披露【缺】**，公司对占比提问仅答"已占有一定比重"）；② **F16 电子细纱线 2025-12 点火带来的单位成本台阶**【硬，公司把它列为 H1 增长三因素之首】。电子级收入占比按 H1 分品类销量一手数据重算为 **21%–31%、中枢约 26%**【测算，见 [§6.1](thesis.md)】。但 2027 新增产能把常规布价格压回，高阶溢价随国产供给到位而收敛；粗纱温和修复不构成第二引擎（[§6](thesis.md) 已判定"双击不成立、是电子端单击"）。
- **正常化归母 8.0 亿元**。约为 H1 年化 12.79 亿的 **63%**、历史峰值 11.44 亿的 70%，高于五年均值 5.41 亿。**高出周期均值的这 2.6 亿，主要由 F16 新线的单位成本下降承担，而不是由 LDK 二代的收入承担**——理由是：成本台阶是内生的、不随价格回落消失，而 LDK 二代的贡献量级公司拒绝披露，无法量化。这是本档在证据最薄处所做的最重要一次保守选择。
- **owner earnings = 8.0 × 0.93 = 7.44 亿**。
- **利润法**：7.44 × 12x（窄护城河上沿，理由见 [§5](business.md)：护城河判定为"窄且趋势向好但未固化"）= **89.3 亿元**（PB 1.02）。
- **资产法**：87.535 × **PB 1.3** ≈ **113.8 亿元**（1.3 ≈ 近 5 年 PB 底 1.34，且此时盈利明显优于该底部对应的 2024 亏损年）。
- **取较高者 → 113.8 亿元 / 3.02 元/股**。
- **赋权 50% 的理由**：这是"景气真实但不永久"的中间情形，与 [§8](thesis.md) 的周期定位判定（电子端上行中后段、粗纱底部、两者背离）直接对应。

### bull（20%）—— 结构性重估，但受证据包门控封顶

- **逻辑**：2,513 万米高频高速布项目按 LDK 一/二代高阶料号如期达产（单位米投资 12.02 元的档次定位兑现），LDK 二代月出货沿产业预期路径爬坡，电子级收入占比升至 40% 以上，公司从"周期玻纤厂 + 电子期权"重定位为"电子级玻纤纱布一体供应商"。
- **正常化归母 11.5 亿元**——刻意设在历史峰值 11.44 亿（2022）附近、且**低于 H1 年化 12.79 亿**，遵守红线 3。
- **owner earnings = 11.5 × 0.93 = 10.70 亿**。
- **利润法**：10.70 × **12x** = **128.4 亿元**（PB 1.47）。
- **资产法**：RIM 隐含 PB 1.12 → 98 亿，低于利润法。
- **取较高者 → 128.4 亿元 / 3.41 元/股**。

**bull 增长证据包门控（x-growth 强制）**：

| 要素 | 内容 | 判级 |
|---|---|---|
| (a) 扩产达产确定性 | 定增 50 亿**仅完成董事会**（2026-08-31），尚需国资批复 → 股东会 → 深交所 → 证监会注册；三个募投项目均"已备案、环评办理中"；项目 1 工期 2025-12~2027-06，项目 2/3 建设期**未披露**；**且公司自述仅购置 1 台国产织机待调试、「高端产能短期释放有限」**——设备是比审批更硬的约束；项目 1 税后 IRR 仅 13.76%、回收期 7.91 年，为三个建设项目中最低 | **【软】** |
| (b) 客户 capex / 出货能见度 | 具名客户（生益科技、台光、斗山）**均无对本公司的采购量 guidance**；只能降级到终端兑底：AI 服务器 CCL 需求 2026 +151%、2027 +110%（券商预测口径，非客户 guidance） | **【缺】具名 /【软】终端** |
| (c) TAM 跑道 | 高端电子布日系占 70%–90%，国产替代空间在方向上确实很大；但**公司自身市占率无任何官方或权威第三方数据**，且分层供需口径互相矛盾（一代需求 1,500 万米/月 vs 全行业供给 550–600 万米/月，数量级不自洽） | **【软】** |

→ 三项分别为【软】/【缺+软】/【软】，**无一项为硬**。按 spec「三项全软 → bull 概率 ≤20%」封顶，取 **20%**（给到上限而非更低，是因为 LDK 二代"已进入多家头部 CCL 厂稳定批量供货"是一条公司一手【硬】证据，它支撑的是 base 的下限，也是 bull 唯一的硬立足点）。

**bull 不得假设 2027 集中投产对价格无影响（硬约束）**：本档 bull 的 11.5 亿正常化归母**已经内含了价格回落**——它对应的不是 2026 下半年的现货价格延续，而是"量增 + 结构升级抵消部分跌价"后的水平。若按 2026 年 8 月的现货价格线性外推，bull 会得到 20 亿以上的归母，本档**明确拒绝**该路径。

**bull 压力上探（❌破框架，仅供参考，不进期望值）**：若给 15x（超出窄护城河 8–12× 框架），10.70 × 15 = 160.5 亿 = 4.26 元/股，安全边际仍为 **−86.3%**。

## 9.4 期望内在价值与安全边际

| 情景 | 每股 | 总额 | 概率 | 加权 |
|---|---|---|---|---|
| bear | 2.32 元 | 87.5 亿 | 30% | 0.696 |
| base | 3.02 元 | 113.8 亿 | 50% | 1.510 |
| bull | 3.41 元 | 128.4 亿 | 20% | 0.682 |
| **合计** | | | **100%** | **2.888 → 2.89 元/股** |

- 总额校验：0.30×87.5 + 0.50×113.8 + 0.20×128.4 = 26.25 + 56.90 + 25.68 = **108.83 亿元**；108.83 ÷ 37.7088 亿股 = **2.886 元** ✓ 与逐股加权一致。
- **安全边际 = (108.83 − 1,168.97) / 1,168.97 = −90.7%。**

**反向核对（最有力的一句）**：按框架内 12x 倒推，1,168.97 亿元市值需要正常化 owner earnings **97.4 亿元**，对应正常化归母约 **104.7 亿元**——是公司历史峰值 11.44 亿的 **9.2 倍**、H1 年化 12.79 亿的 **8.2 倍**、26H1 全部营收 49.64 亿的 2.1 倍。**没有任何一条可辩护的路径能到达这个数字。**

**定增对估值的双面影响（必须并列）**：若 50 亿足额落地，净资产 87.5 → 137.5 亿、BPS 2.32 → 3.34 元、PB 13.35 → 约 **9.28**；按现价 31.00 元发行只需 1.613 亿股，**摊薄仅约 4.11%**（按发行股数上限 342,692,882 股则为 8.33%）——即摊薄很轻而摊厚很实，定增是当前极高 PB 的部分解药。**但这改变的是分母不是分子**：三档正常化归母不会因为账上多 50 亿现金而提升（募投产能要到 2027 年之后才贡献），故本档三档估值**未计入定增**，只把它写进本条披露与 [§10](index.md) 的 PB 讨论。

## 9.6 相对旧档变化清单

**不适用——本轮为首建档（2026-08-31），`docs/stock-analytics/` 池内此前无国际复材（301526）的任何 buffett 档，无旧档口径可对账，亦无旧档 §11 触发器需要复盘。**

需要与池内既有档对齐的一处口径差异，记于此以便 Phase C 与后续轮次追溯：08-15 theme 档以「电子纱进价 +229.2% > 电子布售价 +147.6%」论证瓶颈租金落在纱端，该论证链已被 2026-08-30 宏和重做档**部分撤回**（分母不同不可比）。本档的立场：**结论方向仍然成立，但改由本股自身的一手结构证据承担**——它自产电子纱、纱布一体、且部分以纱价直接外售（2023H1 细纱外售占收入 6.0%），这是"站在收租一侧"的直接证据，不依赖那组不可比的价格比值。详见 [§6](thesis.md) 与 [related.md](related.md)。
