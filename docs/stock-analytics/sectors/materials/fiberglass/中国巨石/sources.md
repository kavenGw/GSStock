## §12.4 已知局限（「缺」本身即结论的项已标注）

1. **分产品收入 / 毛利率 / 均价（粗纱 vs 电子纱 vs 电子布）公司完全未披露【缺】。** 公司只有一个经营分部，半年报全文无分产品毛利率表（grep「分产品」「分行业」「毛利率」0 命中）。**因此本档所有毛利率均为整体口径**；[§3.3](business.md) 的量价拆分（量 +8.3pct / 价与结构 +13.0pct / 单位成本 −3.44%）为 **A1 自算的【测算】，不是公司披露**。
2. **2026-08-21 业绩说明会问答全文，多轮检索未获【缺】。** 已尝试 WebFetch `https://ir.p5w.net/c/600176` 与多轮中英文检索。**后果是：管理层对下半年的指引、订单能见度、产能利用率、涨价函执行情况，本轮全部无法取证。** 且半年报正文本身**不含任何前瞻性指引**（「报告期内公司经营情况的重大变化……□适用 √不适用」）。**这是本轮最大的单一取证缺口**——本档的所有前瞻判断因此只能建立在公告出来的产能与公司自估 IRR 上，而不能建立在管理层表态上。
3. **粗纱内部结构（风电 / 热塑 / 汽车 / 建材）的收入或销量占比未披露【缺】。** 因此「风电/汽车/热塑同步复苏」**既不能证成也不能证伪**，本档不使用该论点支撑任何情景。
4. **能源（天然气/电）、纯碱、叶腊石的采购单价与单耗未披露【缺】。** 半年报仅定性风险提示。故成本护城河的量化只能依赖第三方倒算（【软】）。
5. **有息负债只能给区间 130–150 亿（中枢 140 亿）、两侧无法收敛【缺点估计】。** 筹资活动负债变动表含应付股利/利息，资产负债表侧「其他流动负债」含非债项。本档不给点估计。
6. **AI 高端料号（Low-Dk 一代/二代、Q 布）的产能规划、客户认证节点、送样进度【缺】。** 公司口径为「未形成订单及收入」，此外无任何公开进展披露。**注意：这里的「缺」本身就是结论——若已有实质进展，2026-051 异动公告与 2026 半年报都是必须披露的场合，两次都没有。**
7. **电子布/电子纱业务的客户名单与集中度【缺】。** 中英文检索未获任何具名 CCL 客户（生益科技/南亚新材/建滔）对巨石采购量的披露。这直接导致 [§9.3](valuation.md) bull 证据包要素 (b) 只能判【缺】并降级到终端兑底。
8. **产能利用率、成品库存天数、在手订单/长协锁定量【缺】。** 仅有「行业电子布库存基本不到一周」的景气指标【软】，非公司订单能见度。
9. **淮安 3.9 亿米线的达产率/稼动率爬坡量化进度【缺】。**
10. **AI 相关收入的公司口径拆分【缺】** —— 公司从未按此维度披露，**这个数字在公司层面不存在**，不可编。
11. **巨石 vs 海外（OC / NEG / Jushi USA / 埃及基地）的吨成本对照【缺】；自有叶腊石矿储量与自给率、对吨成本的贡献【缺】。** 故本档不使用「全球成本最低」的表述，只使用可证的国内对照。
12. **中国建材集团层面的减持记录、历次定增明细、关联交易金额与占比【缺】；埃及、美国南卡基地的分基地盈利【缺】**（年报仅披露基地布局，未见分部利润）。
13. **上一轮周期股价高低点的复权点位【缺】**，故 [§8](thesis.md) 的历史类比只用**盈利峰谷比**（−63.0%）而不用股价比。
14. **全行业 2026–2027 电子布/电子纱产能逐条明细表（时点 + 规模 + 资本开支）【缺】**，本轮为分散来源拼接，**不得当作完整供给表使用**。
15. **长海股份 / 山东玻纤 / 宏和科技的 26H1 业绩明细【缺】**（本轮未取），[§9.4](valuation.md) 的同业表仅取同时点行情，不含 EPS 对照。
16. **腾讯 52 周高/低字段（47.52 / 20.73）与日 K（77.20 / 14.21）严重不符**，口径不明，**本轮弃用腾讯 52 周字段，一律采日 K**。
17. **半年报未经审计**（第八节「审计报告 □适用 √不适用」）；年报审计机构为中审众环。
18. **本档的所有 lens 借跑说明**：`pcb-ccl.md` 按板块映射表严格不命中（materials/fiberglass），系按上下游传导借跑，其中 PCB/CCL/载板厂商自身属性条目已在 [§7.4](thesis.md) 逐条标注为不适用。
