# 山东黄金 — §9 估值（场景加权）

> 币种统一：跟踪主体是 H 股，**估值全程先在 CNY 口径完成（财报币种），最后一次性按 HKD/CNY = 0.859029 折到 HKD**。三档、期望值、安全边际全部同币种。汇率为控制者复核 open.er-api（2026-09-03）与 A1 的 Frankfurter 0.85706 双源交叉后取值。
> **A3 全文使用的 HKD/CNY 1.0929（方向反了）与 USD/CNY 7.15 已作废**，其 §1.2/§1.3/§1.5 的隐含金价、正常化归母、安全边际一律以本节重算值替代；A3 的非汇率内容（成本曲线、储采比、资产法准入、股息、成长、买点逻辑、监控指标）仍然有效并被本档采用。

## 9.1 分母选择：为什么主锚是收益法

**主锚 = 正常化归母净利 × 周期倍数。** `buffett-doc-spec` §3「改资产法主锚」的两条准入**全部不满足**：

| 准入条件 | 山东黄金实况 | 判定 |
|---|---|---|
| ① bull < base | bull 73.7 亿 **>** base 54.7 亿（周期股正常形态：金价与产量同向乐观） | ❌ 不满足 |
| ② 资产法能托底 | 资源法硬地板 ≈ 6.7 元/股（A 股），在现价下方 −73%~−82% | ❌ 不满足（是压力不是托底） |

→ **严禁改资产法主锚**；资源法/资产法仅作 bear 之下的极端地板参照，不进主估值链条。资源法细节：EV/权益资源量 $450/oz、EV/权益储量 $1,177/oz，为同业常见区间（$50–150 / $150–400）上限的约 3 倍 —— **「山东黄金资源多所以便宜」在数字上不成立**（【软·A3 §3.3】，同业区间为行业通行口径，非一手报告）。

**四个候选分母全部被否，回归基点取 FY2025**：

| 候选 | 数值 | 为何不用 |
|---|---|---|
| 2026H1 归母 35.43 亿 | 年化 70.86 亿 | 「**顶价格 + 塌产量**」的畸形组合：自产金实现价 1,029.98 元/克（含 1 月 $5,598/oz 极值），而矿产金只有 19.10 吨（年化 38.2 吨）。两端都不可外推 |
| 公司 pro-forma 40.72 亿（+45.01%） | — | 公司一边把东海证券 7.05 亿公允价值损失排除在非经常性损益之外（称「与正常经营业务直接相关」，半年报 p.8），一边在主表注释里把它加回来讲 +45.01%（p.7）——**两套口径互斥**。可用于估值的是 **35.43 亿 / +26.17%**（A1 §A4 裁决） |
| TTM 归母 54.74 亿 | — | 2025H2 低金价与 2026H1 顶金价的**算术混合**，不是中枢 |
| **FY2025 归母 47.39 亿** | @ 上海金约 750 元/克、矿产金 48.89 吨 | ✅ **回归基点**：最接近可用的完整周期年度观测点 |

| | Bear | Base | Bull |
|---|---|---|---|
| **概率** | **40%** | **45%** | **15%** |
| 金价 USD/oz | $3,100 | $3,800 | $4,300 |
| **隐含上海金 元/克** | **671.4** | **823.0** | **931.3** |
| 矿产金产量 | 46 吨 | 50 吨 | 52 吨 |
| 情景逻辑 | Fed 维持鹰派 + 强美元 + 地缘溢价消退，回到 2024 年中枢；产量仅温和恢复 | 央行购金结构性支撑 + 实际利率正常化，落在 6/24 低点（$3,968）与 bear 之间；产量恢复但不达 49 吨指引 | 金价维持**现价不打折**；Namdini 满产 + Osino 2027H1 投产带来产量爬坡 |

**汇率自洽校验（本节的正确性证明）**：按 USD/CNY = 6.7365 折算，现货 $4,469.52 → **968.0 元/克**，与 A1 从上金所取到的 Au9999 实盘 **967.00 元/克**吻合（偏差 0.1%）。**这反证 A3 使用的 7.15 是错的** —— 7.15 会推出 1,027 元/克，与实盘差 6.2%。（换算式：元/克 = USD/oz × 6.7365 ÷ 31.1035。）

**概率赋权理由（比 A3 的 35/45/20 更严，两条理由）**：
1. **产量侧的上行证据最弱且已被前瞻性证伪**：H1 19.10 吨（−22.70%）对 ≥49 吨指引只完成 39.0%，H2 需环比 +56.5%。**卖方 57.4 吨（天风）/ 62 吨 / 2027 突破 70 吨的预测需要 H2 环比 +100%，物理上不可能，本档点名拒绝采信。**（见 [§6/§8](thesis.md)）
2. **bull 的金价假设 = 现价**，属「不给金价任何折扣」的最宽容设定，不配 20% 权重。金价是公司零定价权的外生变量，把外生变量的当前值当作长期中枢，本身就是估值中最不该给高概率的假设。

Σ概率 = 40% + 45% + 15% = **100%** ✓

## 9.3 正常化归母推导

敏感度由 FY2025 与 2026H1 两个观测点反解（已扣除少数股东、所得税、永续债利息、财务费用）【软·推导，A3 §1.3】：
**金价每 ±100 元/克 → 归母 ±13 亿；矿产金每 ±1 吨 → 归母 ±2.5 亿；深部开采成本上行三档均 −5 亿。**

| 金价调整 vs 750 元/克 | −10.22 | +9.49 | +23.57 |

### ⛔ 铁律自检与例外披露（不掩盖）

| 检查 | 结果 |
|---|---|
| bear 24.9 < TTM 54.74 | ✓ |
| base 54.7 ≈ TTM 54.74 | ✓ **勉强满足，且须注明这是巧合而非构造** —— base 是由「金价 823 元/克 + 50 吨」独立推出的，与 TTM 撞在一起纯属数字巧合 |
| **bull 73.7 > TTM 54.74（+34.6%）** | ⚠️ **触发 `buffett-doc-spec` 铁律冲突** |

**本档对铁律冲突的处理（显式例外披露，不压数）**：

1. **为什么保留 73.7 而不压到 ≤ TTM**：山东黄金的 **TTM 不是周期顶** —— H1 年化 70.86 亿 **>** TTM 54.74 亿，TTM 被 2025H2 的低金价拉低。紫金档「三档全部 ≤ TTM」的形式化检查在此**不能机械照搬**。若强行把 bull 压到 54.74 亿，会造出 bull ≈ base 的畸形分布，比例外披露更不诚实。
2. **bull 超 TTM 的部分 100% 来自产量爬坡假设**（52 吨 = Namdini 满产 + Osino 投产），**不来自金价上修**（bull 金价 = 现价，未上修）。
3. **自动作废条款**：**若 2026 全年矿产金产量 < 45 吨，bull 情景自动作废**，期望内在价值按 bear/base 两档重排（bear 47%、base 53% → 期望市值 ≈ 424 亿 CNY ≈ 9.20 CNY ≈ **10.71 HKD**，安全边际恶化至 −60.0%）。对应监控点 [index.md §11 T1/T2](index.md)。

**隐含 ROE 回查（防止倍数破框架）**：base 情景隐含 ROE = 54.7 ÷ 471.37 = **11.6%**，bear 5.3%，bull 15.6%。11.6% 略高于该风险等级（61.90% 负债率 + 永续债 + 股息 < 1.3%）对应的 ~12% 股权成本下限，故 base 的公允 PB 应在 1.2–1.3x 附近 —— 本档 base 每股 13.052 CNY ÷ BVPS 10.226 CNY = **1.28x**，与隐含 ROE 自洽，**倍数未破 buffett 框架**（周期/衰退型 <8×、窄护城河 8–12×，本档 9/11/13x 中 bull 的 13x 已在窄护城河区间上沿，故只给 15% 权重）。

## 9.8 估值局限（诚实边界）

1. **敏感度系数为反解值**：金价 ±100 元/克 → ±13 亿、产量 ±1 吨 → ±2.5 亿，由 FY2025 与 2026H1 两个观测点反解，**只有两个观测点，属【软·推导】**，不是公司披露的弹性表。若实际税率、少数股东占比、套保头寸变化，系数会漂移。
2. **AISC【缺】使成本假设无法交叉验证**：「深部开采成本上行 −5 亿/年」是基于主力矿千米深部化的定性推断落到的数字，公司既不披露 AISC 也不披露分矿山成本，该项**无法被公开数据证伪或证实**。
3. **套保头寸【缺】**：若公司存在规模化黄金套保，bull 情景的金价弹性会被削弱，实际 bull 应低于 73.7 亿。本档未量化此项，属**已知的向下偏误**。
4. **储量口径为 2024 年报**：资源量 2,635.84 吨 / 储量 973.15 吨，且存在「储量平均品位 1.72 g/t < 资源量品位 2.35 g/t」的异常（可能因纳入 Namdini 低品位露天矿），标【软·口径存疑】。2025 年报储量表未取到。
5. **估值分位【缺】**：山金自身 PE/PB 十年历史分位与同板块横向分位未找到可引用的公开数据，本档的「贵」由绝对口径（隐含 ROE vs 股权成本、有形 PB 横比）判定，不依赖分位。
