2. **AISC 372.63 元/克** → 该值为 **FY2025 旧口径**；26H1 实测 **481.45 元/克（+35.46%）**（半年报）。
3. **Wassa AISC $1,972/oz** → 同为 FY2025 口径；26H1 实测 **$2,693.21/oz（+50.62%）**（半年报）。
4. **H 定增发行价 30.19 港元** → **29.82 港元**（2026-05-20 调整公告）。
5. **26Q1 年化作估值分母（EPS 2.08 / 归母 39.5 亿）** → **Q2 单季归母 7.4405 亿、环比 −24.71%**，Q1 年化法失效（Q2 = 半年报正式数 − 一季报正式数，核算值）。
