### 9.2 定价铁律：低 PE 是周期顶信号，不是便宜

- TTM 归母 = 2025 全年 71.302 + 2026H1 86.318 − 2025H1 41.745 = **115.88 亿元**，TTM EPS 3.346 CNY。
- **这是公司有史以来最高的 12 个月滚动利润**，为 2017–2025 九年归母均值 **45.6 亿的 2.54 倍**。
- PE 从旧档 23.09x（A）降到 13.71x（A）/ 9.36x（H）：其中**约三分之二来自分母膨胀，只有约三分之一来自股价下跌**。旧档自己立的铁律是"71 亿周期顶利润不能作分母"，**现在的分母比那个被拒绝的数字还高 62.5%**。
- 2026H1 顶部年化：归母 **172.6 亿** / 扣非 **151.1 亿**。**三档正常化利润必须全部低于此。**
- **一次性项必须剥离**：H1 归母 86.32 亿含非经常性损益净 **+10.756 亿**（主要为非流动资产处置 +11.13 亿），可比口径是**扣非 75.56 亿（+73.73%）**；归母 +106.77% 中约 33pp 来自一次性项与上年基数的方向反转。

### 9.3 铜价场景（与洛钼同源）+ 江铜独有的观测锚

采用与洛阳钼业档同源的三档铜价：**bear $8,000 / base $9,500 / bull $11,000 每吨（LME 3M）**。

**江铜独有的交叉验证（洛钼档没有）**：中报 P11 硬数据"2026H1 LME 三个月均价 **$13,137/吨**，较 2025 年均价上涨约 **39%**" → 反推 **2025 年 LME 3M 均价 ≈ $9,451/t**。

> **$9,451 ≈ base 情景假设的 $9,500（差 0.5%）。**
> 这意味着江铜的 base 情景**不需要弹性外推** —— 可以直接以「2025 年实际实现业绩（归母 71.30 亿）」作观测起点做结构调整。**观测值优于模型值**，这是本档在方法论上相对洛钼档的一个优势。

**⚠ 必须显式披露的偏离：base 的 $9,500/t 不是"中枢"，它比十年中枢高约 17%。**

LME 3M 十年均价为 **$8,140.5/t**，base 假设 $9,500/t **高出 16.7%**；bear $8,000/t 反而略低于十年中枢（−1.7%）；bull $11,000/t 高出 35.1%。**默认 $9,500 就是穿越周期中枢是错的。** 仍采用该三档的两条理由：

1. **跨档可比性优先**：与兄弟档洛阳钼业（2026-09-03）同源，否则两档结论无法横比，同板块会出现两套铜价假设。
2. **江铜独有的观测锚**：$9,500 ≈ 2025 年实际实现均价 $9,451，使 base 有**实际业绩对照**（71.30 亿），观测值优于模型值——这是采用它的真正理由，不是因为它是长期中枢。

**这条偏离的方向是偏多的**（base 铜价高于十年中枢 17% → 正常化利润偏高 → 内在价值偏高 → 安全边际偏乐观）。**若把 base 改用十年中枢 $8,140.5/t**，按扣非弹性 1.89x 从 2025 实现业绩折算，base 归母约 **62 亿**（71.30 × (1 − 13.9% × 1.89) + 结构调整项 +9 亿），×10x ÷ 34.6273 亿股 = 每股约 17.9 CNY ≈ **20.9 HKD**，期望内在价值降至约 **21.9 HKD**、H 股安全边际约 **−40.1%**。**结论方向不变（仍深度为负、仍 watch），但读者须知本档采用的是偏乐观的一侧。**

**口径注解**：洛钼对铜价是**单向多头**；江铜是**双向**（矿端多头 β + TC/RC 空头对冲）。故同一铜价场景下，江铜的下行利润回吐应打折——这已体现在 bear 档的 TC 修复对冲项里。

### 9.5 bull 增长证据包门控（x-growth）

| 要素 | 裁定 | 证据 |

| (a) 扩产达产确定性 | **软** | 武山三期、城门山铜钼分离已竣工投产【硬】，但中报**未给新增产能吨数**【缺】；自有矿 H1 10.00 万吨 vs 全年指引"约 20 万吨"，年产能未见跳升 |

| 情景 | 概率 | EPS(CNY) | 倍数 | 每股内在价值(CNY) | **每股内在价值(HKD)** | 赋权理由 |

| **bull** | **20%** | 3.03 | 11x | 33.33 | **38.95** | 增长证据包三项全非硬（§9.5），按门控**封顶 20%**；依赖铜价中枢结构性上移 + HVLP-3 放量两个未证事实。引 [thesis.md §7](thesis.md) |

**算术自检**：Σ概率 = 35% + 45% + 20% = **100%** ✓

**期望内在价值** = 0.35 × 13.46 + 0.45 × 26.99 + 0.20 × 38.95 = 4.71 + 12.15 + 7.79 = **24.65 HKD/股**

**H 股安全边际** = (24.65 − 36.58) / 36.58 = **−32.6%**
**A 股口径对照** = IV 24.65 ÷ 1.1686 = **21.09 CNY** vs 45.86 → **−54.0%**
**bull 单独压力测试** = (38.95 − 36.58) / 36.58 = **+6.5%**

> **汇率口径**：采 **CNY/HKD = 1.1686**（2026-09-04）。旧档的 1.159 与兄弟档洛阳钼业的 1.16412 **均已作废**，全档所有派生数（三档每股、期望内在价值、安全边际、股息率、AH 折价、FQM 敏感性）一律按 1.1686 统一重算，不保留任何按作废汇率计算的残值。

**PB 交叉验证**：base 每股内在价值 23.10 CNY ÷ BVPS 25.308 = **隐含 PB 0.91x**。冶炼/营运资产在周期中枢给 PB <1x 是合理的（A 股 PB 近 5 年区间下沿 0.71x）。当前 H 股 PB **1.237x**，距 base 隐含 PB 还有 **−26%** 空间，与安全边际 −32.6% 方向一致、量级自洽 ✓。
**⚠ 禁令**：**PB 不与洛阳钼业横比**。洛钼 H 股 PB 3.28x 是矿权资产口径（账面严重低于经济价值），江铜 1.237x 是冶炼/营运资产口径（账面 ≈ 重置价值），**不同量纲**。

**PB 双口径并列（必须两面同写）**：

### 9.8 财务费用缺口敏感性（单列，不扣减主锚）

**缺口是真实的**：base 以 2025 年实现业绩 71.30 亿作观测锚，而**那张资产负债表是 SolGold 并表前、短期借款仅 558.23 亿的**。2026H1 短期借款已翻倍至 **1,204.89 亿**、长期借款 66.39 → 126.73 亿，新增融资成本**结构性地不在 base 的利润基础里**。同期**财务费用 5.63 → 9.85 亿（+75.10%）**，增量 **4.22 亿**，年化约 **8 亿**。

**归因必须收窄，故不计入主锚**：
