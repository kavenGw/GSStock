该 theme 的结论大部分已被 2026 年半年报正式数取代并写入 [business.md §3](business.md) 与 [thesis.md §8](thesis.md)。以下为**仍有效、且未被新档正文覆盖的残值结论**，承接进本档：

1. **预告 → 实际的兑现对账（该 theme 唯一的一手事件价值）**：2026-07-08 业绩预告区间为归母 **75.5–85.0 亿元（+80.86%~+103.61%）**，2026-08-25 实际披露 **86.32 亿（+106.77%）**，**超预告上限**。该 theme 当时的判断"高增速部分含 2025H1 低基数效应，不宜线性外推为质地跃升"**在本轮被完整证实**——扣非口径仅 +73.73%，且一次性损益净 +10.756 亿。
2. **该 theme 当时的核心裁定"验证收入端、不改评级"成立并沿用**：预增只动收入/利润端，未动定价权、未拓护城河。本轮维持 watch，理由链条与之一致但更强（见 [index.md §10](index.md)）。
3. **板块级读数的相对排序仍有效（新档正文未覆盖，故在此承接）**：同一铜价驱动下，池内标的的受益强度排序为 **纯矿企（紫金 core / 洛钼 watch）> 自有矿+副产型（北方铜业 watch）> 冶炼+副产型（江铜、铜陵有色 watch）> 纯冶炼（云南铜业，判"无影响"——是加工费受害股而非铜价受益股）**；下游铜箔加工（铜冠铜箔 301217 / 嘉元科技 688388）由加工费而非铜价驱动，铜价上行对其为**中性偏空**（原料成本，pass-through）；中国铝业（601600）隔金属、判无影响。**该排序在本轮中报后未被推翻**，江铜仍处"冶炼+副产型"档位，且因境内自给率由 ~9% 降至 **7.9%**、更靠近纯冶炼一端。
4. **Section 232 关税口径的残值提醒**：该 theme 指出"232 关税推升的是 **COMEX 溢价**，不是全球铜价的永久上移"。本轮以硬数据落实了这一点——同日（2026-09-04）COMEX $14,699/t 对 LME 3M $14,371.5/t 溢价仅 **+2.28%**，且中报 P12 确认 2026-04 美国把计税基数改为整件产品货值后 COMEX-LME 价差维持高位。**当前铜价含政策套利成分，不是纯需求，这条构成 [thesis.md §8](thesis.md) 周期顶判断的一部分。**
5. **该 theme 的一处口径已被本轮推翻，不再沿用**：其正文写江铜"自给率 ~20%"，与旧档 ~9%、本轮 **7.9%** 均不符——该数字疑为把"自有矿年产 20 万吨"误当成了百分比。**以中报原文口径为准：自有矿 10.00 万吨 ÷ 阴极铜 126.04 万吨 = 7.9%。**
