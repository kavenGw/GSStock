## §0 结论摘要（倒金字塔）

**看（Watch），不买 —— 北铜这半年赚的钱是真的，但赚钱的三根柱子全换了位置，而市场仍在按旧柱子（自有矿）和峰值 ROE 给它定价。**

**三支柱变化（本轮相对旧档最大的改写，机制见 [§1/§3](business.md)）：**

1. **自给率降口径**：半年报硬口径 **13.4%**（自产铜精矿含铜 4.3 万吨/年 ÷ 阴极铜产能 32 万吨/年）。旧档并列的"券商冶炼口径 33%"本轮**作废**，全档不再使用；由此旧档"矿端受益 1/3 + 外购受损 2/3"的权重描述**全面失效，改为约 13% : 87%**。
2. **贵金属支柱已塌**：毛利率 2025 全年 17.48% → 2026H1 **10.77%**，**已低于阴极铜的 12.05%**；毛利占比 32.02% → **19.36%**（营收占比反升至 22.88%）。管理层明示"增加金精矿采购比例" ⇒ 贵金属是**第二条外购加工线，不是资源敞口**。旧档"高毛利贵金属副产是隐藏暗桩"这一支柱**判为已塌**。
3. **硫酸接棒**：营收占比仅 2.22%，毛利率 **82.79%（+47.29pp）**，贡献 H1 毛利增量 16.09 亿中的 **3.63 亿（22.5%）**，是第二大边际驱动。旧档 theme 判硫酸"量级中偏低"，**本档正式证伪**。

**期望内在价值 ≈ 101 亿（5.32 元/股）**，三情景加权；对现价市值 273.33 亿**安全边际 −63%**。即便 bull（172 亿 / 9.03 元）安全边际也 **−37%**。

- **bear 约 60 亿 / 3.15 元，概率 30%**：铜价回落 → 深度为负的 TC（2026-08 周均 −86.33 美元/干吨）对 87% 外购线立刻裸露 + 83.83 亿存货（占总资产 39.93%）跌价放大 + QP 公允价值 +4.36 亿对称反转，三重会计放大器同时作用。
- **base 约 98 亿 / 5.15 元，概率 50%**：只是一轮常规周期，穿越周期归一化利润 8.2 亿（2020–2025 年度归母 + TTM 七点均 8.19 亿），给商品档上沿 12x。
- **bull 约 172 亿 / 9.03 元，概率 20%（封顶）**：铜价中枢结构性上移 + 硫酸中枢不回落 + 胡家峪注入落地（自给率 13.4%→约 15.7%）。成长证据包三项全【软/缺】，按 `buffett-doc-spec` §3 门控 bull 概率封顶 20%。

**两个 PE 必须并列看（这是本档反周期顶定价的核心表达）**：

| 口径 | 分母 | PE | 读法 |
|---|---|---|---|
| 峰值 | H2 与 H1 持平的年化约 25 亿 | **≈10.9x** | "看起来便宜" |
| 穿越周期 | 七点均归一化 8.19 亿 | **≈33.4x** | 真实定价 |

差 **3.1 倍**。周期调整 PE 从旧档同口径的 40.4x 降到 33.4x，**下降全部来自分母上修（6.73→8.19 亿），不是股价跌**（14.29→14.35）。

**PB 的诚实读数**：PB 3.46，按 PB=ROE/r（r=10%）反推**隐含永续 ROE ≈ 34.6%**，**恰好等于当前 H1 年化的峰值 ROE 水平** —— 教科书式的周期顶定价形态。同业分组后，冶炼组（江铜 1.81 / 铜陵 2.25 / 云铜 2.21）中枢约 2.1、矿业组（紫金 4.65 / 洛钼 4.41 / 西矿 4.12）中枢约 4.4，**北铜被按接近矿业股定价，而其自给率只有 13.4%**。

**AI 铜箔：从"基本证伪"升级为"已证伪"**（见 [§7](thesis.md)）。反证锚：真 AI 铜箔标的铜冠铜箔 PB 14.91 vs 北铜 3.46 —— 北铜的 PB 溢价不来自 AI，而来自被高估的"自有矿"叙事。

**非分红价值股（排除性结论）**：股息率仅 0.98%，H1 赚 13.96 亿仍明示不派中期息。不构成股息支撑，**不得用分红率给估值托底**。

## §10 评级决策

### 期望内在价值 vs 实时市值

| 项 | 值 |
|---|---|
| 期望内在价值 | **101 亿 / 5.32 元/股** |
| 实时市值（2026-09-04 收盘） | **273.33 亿 / 14.35 元** |
| **安全边际** | **−63%** |
| bull 情景安全边际 | −37% |
| 隐含 PB（期望值口径） | 101 / 79.05 = **1.28x** |

（三情景构造、概率赋权理由与 PB 交叉锚见 [§9](valuation.md)。）

### 评级：watch（维持，但理由已换）

旧档的 watch 建立在"质地最优（矿+金）但 PB 板块最贵"上；本档的 watch 建立在**"质地确有改善（现金流转正、有息负债下降、阴极铜价差跳升）但支柱结构比旧档认知的更脆弱，且价格仍按周期顶 ROE 定价"**上。评级未翻转，**归因已被完全替换**。

**为什么不是 exclude**：① 治理无硬伤，2026 年内无股权摊薄、无高对价注入发生、有息负债从 67.66 亿降至 64.18 亿；② 经营现金流从 −8.78 亿转正到 +10.75 亿，是质量层面的真改善；③ 连续三年分红且绝对额递增（1.77→2.10→2.67 亿）；④ 铜矿峪深部 86.96 万吨铜金属量在上市公司自有采矿权范围内、无需集团注入，资源接续有实质保障（虽只延长服务年限、不提高自给率）。这不是一家应当从池子里划掉的公司，是一家价格不对的公司。

**为什么不是 config/core**：安全边际 −63%，且 bull 情景仍 −37%。按 Buffett 的确定性分层，商品型周期股属"存在不确定性因素"档，需 40–50% 折扣才可买；当前不是折扣，是 2.7 倍溢价。

### 买点 / 卖点阈值

| 阈值 | 值 | 依据 |
|---|---|---|
| **观察进入区** | 市值 ≤ 198 亿（**PB ≤ 2.5**，约 10.40 元） | 同业自给率插值给出的相对定价上界；此价以上一律 watch |
| **可讨论买点** | 市值 ≤ 103 亿（**PB ≤ 1.3**，约 5.40 元） | base 内在价值 98 亿 + 少量容差；对应穿越周期 PE ≈12.6x |
| **建仓** | 市值 ≤ 78 亿（PB ≤ 1.0，约 4.10 元） | 对 base 有 20% 折扣，且资产法托底 |
| **卖点（若持有）** | PB > 3.5，或 铜价见顶回落 + 单季存货跌价 > 5 亿同时出现 | 周期顶 de-rate 双确认 |

**相对旧档是否翻转**：评级未翻转（watch → watch），但**期望内在价值从 96 亿上修到 101 亿（+5%）**，安全边际从 −65% 收窄到 −63% —— 上修幅度远小于归一化利润的上修幅度（6.73→8.19 亿，+22%），原因是 base 倍数从旧档口径收敛到框架内 12x，且 bull 概率被成长证据包门控封在 20%。

### 旧档误判的正面处理（不事后合理化）

旧档 2026-06-02 判"周期顶、安全边际 −65%"后三个月：**股价 14.29 → 14.35（基本持平），而盈利翻倍**（TTM 归母从约 10.4 亿升至 17.00 亿）。同期铜价 YTD **+47.57%**、2026-08 创历史新高；金价从跌破 4000 回到 4,472.92（9-04）。

**诚实结论：结论方向上没亏钱（不买没错过上涨），但"周期顶"判早了三个月，且核心归因（矿 + 金双引擎）被证伪。** 旧档 §11 五条触发器**无一触发**，其中两条的价格前提**反向大幅走强**。这不是"我们对了"，是"我们用了后来被证伪的理由，得到了一个碰巧不亏的结果"。本档把归因换成"冶炼价差 + 硫酸"后，周期顶的判断依据从"价格已高"改为"**PB 隐含永续 ROE = 峰值 ROE**"这一可证伪的定价形态 —— 若后续 ROE 能在 25% 以上维持两年以上，本档的 base 概率赋权即被证伪，须重估。

## §11 关键风险 Top 5 + 监控指标 / 卖出触发器

### 风险 1｜周期顶定价被证实（最大风险）
PB 3.46 隐含永续 ROE 34.6% = 当前峰值 ROE 水平。铜价距历史高点仅 −1.1%、TC 仍深度为负（8 月边际回升但方向未定）、库存小幅累库。一旦铜价回落，**估值与盈利同时下杀**（戴维斯双杀）。
- **监控**：LME 铜跌破 13,000 美元/吨（较当前约 −9.5%）→ 触发估值重估；跌破 11,700（2026H1 下沿）→ bear 情景启动。
- **卖出触发器**：铜价连续两月环比转跌 + PB 仍 > 3.0。

### 风险 2｜存货跌价 + QP 公允价值的双向会计放大器
存货 83.83 亿占总资产 **39.93%**；H1 在铜价创新高的半年里已计提 **8.74 亿**存货跌价（上年同期仅 0.823 亿，10.6 倍放大），这是负 TC 的会计显影。同时 QP 公允价值变动 **+4.362 亿**（占利润总额 23.49%）在铜价下行时**对称转负**。
- **监控**：单季存货跌价计提 > 5 亿，或存货占总资产 > 45% → 盈利质量红灯；公允价值变动损益转负。
- **卖出触发器**：连续两个季度存货跌价 > 5 亿。

### 风险 3｜硫酸暴利回吐（22.5% 的毛利增量来源）
毛利率 82.79% 是价格暴涨下的极端读数，硫酸完全外生（硫磺进口成本 + 农化/镍冶炼需求驱动），2026-07-22 云南 98% 冶炼酸到厂 1,630–1,710 元/吨，**已自 4 月 2,100 元峰值回落约 20%**。
- **监控**：中国铜冶炼酸指数或云南 98% 冶炼酸到厂价跌回 1,000 元/吨以下（2026 年初水平）→ 抽走约 22.5% 的毛利增量来源。
- **卖出触发器**：硫酸价格跌破 1,200 元/吨且阴极铜毛利率同步回落至 10% 以下。

### 风险 4｜负 TC 结构性单边利空 + 2027 长单
2026 年度长单 TC/RC = **0 美元/干吨**。现货 2026 年内序列【软】：Q1 月均 −46.88 / −50.99 / −62.63 → 2026-05-15 周均 **−103.62**（旧档引用值）→ **2026-07-17 当周 −146.15（年内最深）** → **2026-08 Mysteel 干净铜精矿周均 −86.33（最新可得读数）**。即：**深度为负，但 8 月已边际回升、脱离最深位，方向未定**。本轮利润暴增**不是 TC 改善带来的**；对 87% 外购线，深度负 TC 仍是结构性单边利空。
- **监控**：2026-11/12 敲定的 **2027 年度长单 TC** —— 签在 0 以上则冶炼模型改善；继续为负则存货减值压力延续。
- **方向提醒**：现货 TC 向 0 修复是**利多外购线（87% 产能）、利空"自有矿溢价"叙事**，与直觉相反，勿写反。

### 风险 5｜铜箔叙事作废 + 集团高对价注入
募投项目半年仅推进 2.73pp（27.41%→30.14%），本期投入 391 万，9.51 亿募资中 3.5 亿临时补流 + 2.9 亿补流；**须预期二次延期**，2026-12-31 达产目标判为不可能。另一侧，胡家峪注入对价完全未知，股价/铜价越高**高对价注入风险越大**。
- **监控**：2026Q4 是否发布第二次延期公告（若发布，"铜箔转型"叙事正式作废）；铜带及压延铜箔毛利率（当前 −1.91%）连续两个报告期仍为负 → 该分部按清算价值处理；胡家峪安全生产许可证进度（承诺权证齐全后 24 个月内启动注入）。
- **卖出触发器**：在铜箔仍亏损时公告新增大额股权融资，或以显著高于同类资产估值的对价注入集团矿权。

### 补充监控（分红与产量，季度看）
- **中期分红**：H1 赚 13.96 亿仍不派中期息。若 2026 年度分红率维持 33–34%（对应约 8 亿），股息率约 2.9% —— 届时才具备分红讨论价值。分红率较前三年均值下降超 5pp 或公告削减 → 派息能力预警。
- **阴极铜产量与稼动率**：H1 15.98 万吨（年化近满产）。若在 TC 深度为负时仍不减产，须追问单位冶炼现金成本；若开始减产 → 规模摊薄失效、固定成本压力显现。
- **贵金属价格**：现货金跌破 3,900 美元/盎司、银跌破 55 美元/盎司（2026H1 下沿）→ 贵金属分部毛利率进一步下滑（已从 17.48% 降至 10.77%）。

| 4 | PB > 3 且铜价/金价见顶回落 → de-rate | **未触发**：PB 3.46 仍 >3，但价格未见顶回落。**注意 PB 从 3.58 降到 3.46 是净资产增厚所致，不是股价回调** |
| 5 | 铜箔亏损时仍大规模扩产融资 或 集团高对价注入 | **未触发**：2026 年内无新增股权融资，筹资现金流仅 +0.08 亿，有息负债下降 3.5 亿 |

**五条无一触发** —— 触发器本身设计得过于依赖"价格回落"这一单一前提，这是旧档方法论上的缺陷。本档新增的风险 1（PB 隐含 ROE = 峰值 ROE）与风险 2（存货/QP 双向放大器）是**不依赖价格方向即可观测**的形态指标，用以补上这个缺口。
