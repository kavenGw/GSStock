# 北方铜业 — §9 估值（场景加权）

> 行情锚：2026-09-04 收盘 14.35 元 / 市值 **273.33 亿** / 总股本 19.047 亿股 / PE(TTM) 16.08 / PB 3.46。
> 归母净资产 79.05 亿、BVPS 4.15 元（2026H1 末）。全档人民币口径，无跨币种问题（纯 A 股，无 H 股）。

## 9.1 归一化 owner earnings 中枢

| 口径 | 计算 | 结果 |
|---|---|---|
| 旧档（2020–2025 六年均） | (6.19+8.37+5.55+6.21+6.13+7.91)/6 | 6.73 亿 |
| **本档主用（2020–2025 + TTM 七点均）** | (6.19+8.37+5.55+6.21+6.13+7.91+**17.00**)/7 | **8.19 亿 → 取 8.2 亿** |
| 参照上界（以对称剥离后 20.32 亿替代 TTM） | 七点均 | 8.66 亿（仅 bull 引用） |

**为什么主锚取 8.2 亿而不是 8.66 亿**：8.66 亿把"对称剥离后的可比**上界**"（20.32 亿）当作第七点，等于用可比上界充当中枢，过于乐观。8.2 亿保留 TTM 账面 17.00 亿，已把 2026 的极值权重自然稀释到 1/7。

**两个 PE 并列（与 [index.md §0](index.md) 同源，未重算、未换分母）**：

| 口径 | 分母 | PE |
|---|---|---|
| 峰值 | H2 与 H1 持平的年化约 25 亿 | **≈10.9x** |
| 穿越周期 | 七点均归一化 8.19 亿 | **≈33.4x** |

差 **3.1 倍** —— 任何只写其一的估值都是误导。

**为什么绝不用峰值年化**：若 H2 与 H1 持平，2026 全年归母约 25 亿。这是"铜价历史新高 + 硫酸价格暴涨 + 白银 YTD 翻倍 + QP 公允价值顺风"四重顺周期叠加的产物，取它做常态即违反"正常化利润绝不取财报顶部年化"。

**QP 公允价值变动 +4.362 亿不进 owner earnings**：它是采购及销售延迟定价条款在铜价单边上行下的按市值重估，是纯铜价方向性敞口，铜价掉头即对称反转为损失。公司在非经常性损益表中标注"是"（可持续），本档不采纳该判断。

## 9.2 盈利质量：三档口径并列（禁止只写一档、禁止用扣非冒充"已剥离"）

同一张 2026H1 利润表里方向相反的两项**并存而非互斥**：

| 口径 | 2026H1 归母 | 含义 |
|---|---|---|
| **账面** | **13.96 亿** | 报表值 |
| **剔 QP**（税后约 3.28 亿，按实际税率 24.8%） | **约 10.68 亿** | 经营口径**下界** |
| **对称剥离**（A1 口径①：QP +4.362 与减值 −8.743 等一次性项税后净额 +3.32 亿） | **约 17.28 亿** | 可比**上界** |

- **会计扣非 13.81 亿几乎未剥离这两项**（vs 归母 13.96 亿仅差 0.15 亿）：存货跌价与套保均被认定为经常性经营损益。**严禁把扣非当作"已剥离口径"使用。**
- **存货跌价 −8.743 亿也不是"一次性"**：它是负 TC 与高价存货的会计显影（外购铜精矿含负加工费的入库成本 > 可变现净值）。存货 83.83 亿占总资产 39.93%，铜价回落即放大 —— 这条直接写进 bear 传导链。
- 反向事实须并置：13.96 亿是**已被 8.74 亿减值压低**后的数字，经营层面的赚钱能力比账面更强 —— 这对 bear 情景不利。**此条仅作利润质量披露，不作为任何情景的倍数依据**（bear 倍数的依据见 §9.5，来自护城河分类而非利润质量）。

## 9.3 三情景构造

| 情景 | 正常化 owner earnings | 倍数 | 内在价值 | 每股 | 隐含 PB | 概率 |
|---|---|---|---|---|---|---|
| **bear** | **5.5 亿**（周期底，≈2022 年 5.55 亿） | 11x | **60 亿** | **3.15 元** | 0.76x | **30%** |
| **base** | **8.2 亿**（七点均归一化） | 12x（商品档上沿） | **98 亿** | **5.15 元** | 1.24x | **50%** |
| **bull** | **11.5 亿**（结构性中枢，>8.66 亿参照上界，仍远低于峰值年化 25 亿） | 15x | **172 亿** | **9.03 元** | 2.18x | **20%** |

**期望内在价值 = 60×30% + 98×50% + 172×20% = 18.0 + 49.0 + 34.4 = 101.4 ≈ 101 亿 = 5.32 元/股**
Σ概率 = 30% + 50% + 20% = **100%** ✓
**安全边际 = (101 − 273.33) / 273.33 = −63.0%**；bull 单档安全边际 = (172 − 273.33)/273.33 = **−37.1%**。

### 概率赋权理由（每档一句，引 §6/§8 证据）

- **bear 30%**：深度负 TC 对 87% 外购线是**结构性单边利空**（长单 0；现货 2026-08 周均 −86.33，虽较 7 月中 −146.15 边际回升，仍深度为负、方向未定），本轮利润暴增不是 TC 改善带来的（[§6](thesis.md)）；铜价距历史高点仅 −1.1%、库存已现小幅累库（[§8](thesis.md)），一旦回落，存货跌价 + QP 反转 + 矿端红利收缩三重会计放大器同向作用。给到 30% 而非更高，是因为经营现金流已转正、有息负债在降、公司未参与 CSPT 减产而近满产，短期不存在生存问题。
- **base 50%**：北铜的盈利函数被证实**几乎全部由外生价格驱动**（阴极铜价差 + 硫酸价 + 金银价），量的空间已封顶（阴极铜 15.98 万吨对 32 万吨产能年化近满产），没有任何自主的中枢上移机制（[§6](thesis.md)）；因此"只是一轮常规周期、终将回归穿越周期中枢"是最可辩护的默认路径。
- **bull 20%（封顶，不可再高）**：按 `buffett-doc-spec` §3 成长证据包三要素门控 —— (a) **扩产达产确定性【软→近乎缺】**（募投半年推进 2.73pp、本期投 391 万、募资超半数挪去补流）；(b) **客户 capex/出货能见度【缺】**（无具名客户、无订单证据、无 HVLP 送样）；(c) **TAM 跑道【软】**（铜的长期需求叙事成立，但北铜无份额扩张路径，量已封顶）。三项无一为【硬】，**bull 概率封顶 20%**。胡家峪注入即便全额落地，自给率也只从 13.4% 到约 15.7%（集团胡家峪 + 篦子沟合计年产铜精矿含铜仅 7,000–8,000 吨），**不是质变**，只作定性加分、不上调概率。

### bull 压力测试（红线 4：不用"护城河上修"稀释"价格太贵"）

即便同时假设：铜价中枢结构性上移到 14,000 美元/吨以上并长期维持、硫酸中枢锁在 1,600 元/吨以上、胡家峪注入落地、铜箔扭亏 —— 内在价值 172 亿仍比现价市值 273.33 亿低 **37%**。**没有任何一个可辩护的乐观情景能支撑当前价格。** 要让 bull 追平现价，需要正常化利润 18.2 亿（≈ 对称剥离后的 H1 年化 17.28×2 的一半再上修）配 15x，即**把周期顶盈利当常态** —— 这正是本档拒绝做的事。

## 9.4 PB 交叉锚（旧档 ≤1.3x → 本轮 2.2–2.5 带，须说明为何上调）

**同业分组【A3】**：

| 组 | 标的（PB） | 中枢 |
|---|---|---|
| 冶炼组 | 江铜 1.81 / 铜陵 2.25 / 云铜 2.21 | ≈**2.1** |
| 矿业组 | 紫金 4.65 / 洛钼 4.41 / 西矿 4.12 | ≈**4.4** |
| **北铜** | **3.46** | 被按**接近矿业股**定价 |

按自给率线性插值（冶炼组 PB 2.1 对应自给率约 5–10%，矿业组 PB 4.4 对应 70%+），北铜 13.4% 的合理位置在 **PB 2.2–2.5**。

**为何从旧档的 ≤1.3x 上调到 2.2–2.5 带**（不静默替换）：① 旧档的 1.3x 是**绝对内在价值口径**（利润法反推），而本轮的 2.2–2.5 是**相对定价口径**（同业分组插值），两者本就不是同一把尺；② 相对口径本身也确有上移依据 —— 同业冶炼组 PB 中枢已升到 2.1（旧档时更低），且北铜相对纯冶炼厂多了 13.4% 自给率与 82.79% 毛利率的硫酸暴利，值一个小幅溢价。

**两把尺给出的数不同，必须并置而非二选一：**
- **相对定价口径（上界）**：PB 2.2–2.5 × 79.05 亿 = **174–198 亿**。含义是"就算按市场同业分组给最宽容的相对估值，北铜也只值 174–198 亿"，仍比现价 273.33 亿低 **27–36%**。
- **绝对价值口径（本档主锚）**：穿越周期 ROE = 8.2 / 79.05 = **10.4%**，r 取 10% → 公允 PB ≈ **1.04x** ≈ 82 亿。本档 base 给到 98 亿（PB 1.24）已略高于这条绝对线，是对硫酸/自给率的一点让步。

**两把尺方向完全一致（都指向"贵"），只是幅度不同。** 本档取绝对口径为主锚、相对口径为"观察进入区"阈值（PB ≤2.5 才值得开始看），见 [§10 买卖点](index.md)。

**当前 PB 的反推读数（原样保留 A3 裁定）**：PB = ROE/r，PB 3.46 × 10% = **隐含永续 ROE ≈ 34.6%**，**恰好等于当前 H1 年化的峰值 ROE 水平**。市场正在把周期顶 ROE 当永续 ROE 定价 —— 这是周期股估值最经典的错误形态，在北铜身上是完整教科书版本。

**ROE 季节性纪律**：H1 摊薄 ROE 17.66% / 加权 18.66%，**严禁与 2025 全年 11.65% 直接比较**（H1 占全年 90%（2024）/64%（2025），偏置明显）。跨期比较须用年化区间 **19.6%–27.6%（中值约 23%）** 并标注口径。毛利率无季节偏置，12.72% 可直接跨期比。

## 9.5 倍数框架自检（spec §3「倍数被迫破框架」条款）

- **倍数依据一律来自护城河分类，不来自利润质量。** 北铜护城河判定为**窄且在收窄**（[§5](business.md)），对应 buffett 周期/窄护城河倍数桶 **8–12x**：bear 11x、base 12x 均落在桶内（base 取桶上沿，因 base 已是穿越周期归一化利润）；**bull 15x 越出该桶**，标注 **❌破框架**，故 bull 仅作压力测试上界使用，不用于买点推导。
- bear 取 11x 而非桶下沿 8x，理由是**分类层面的**：北铜属周期型但非衰退型 —— 现款现货无应收风险、资产负债率 62.36% 且在降、连续三年分红，不满足 8x 桶下沿对应的"财务承压/清算折价"特征。与 2026H1 的利润质量无关。
- 隐含 ROE 回查：bear 5.5/79.05 = 6.96%、base 8.2/79.05 = 10.4%、bull 11.5/79.05 = 14.5%，单调递增，与 PB 阶梯 0.76 / 1.24 / 2.18 方向一致，**无 bull < base 反转**，利润法整体有效，无须切换资产法主锚。
- 资产法交叉验证：净资产 79.05 亿，bear 60 亿对应 PB 0.76x —— A 股铜冶炼股周期底部 PB 落在 0.7–1.0 有历史支撑，bear 未低于合理清算区间。

## 9.6 SOTP / 联营检查

无重要联营/合营需要单独 SOTP 拆分；投资收益 −0.0289 亿（现金流量套期无效部分），量级可忽略。压延铜箔/铜带分部**以负值进入估值**（H1 毛利 −0.22 亿、募投项目累计实现收益 −2.86 亿），**不给期权价值**（[§7](thesis.md) 判【蹭概念】）。
