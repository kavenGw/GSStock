## 12.5 已知局限

1. **行情为收盘价而非盘中实时**（2026-08-24 收盘 66.76 元，当日 −2.03%）。所有安全边际按此计算，价格变动会线性改变结论的量级但不改变方向（现价需下跌 82.6% 才触及期望内在价值）。
2. **矿端价格函数是两点定标的线性外推**，必然穿过两个观测点；其可靠性完全依赖"产量与单位成本不变"假设，且在 P < 20 万元/标吨时不适用。副产品（钼/铋/萤石/锡）价格若与钨价背离会带来误差。方法学限定已在 [valuation.md §9.2](valuation.md) 逐条写明。
3. **金洲的正常化利润是本档最主观的一格**（bear 3.6 / base 5.5 / bull 9.0 亿）。因【缺】1–5 全部未闭合，这三个数字无法用公开数据校准，只能锚在"2025 实绩 3.62"与"H1 年化 8.63"两端之间。**若公司未来单独披露金洲分季度或 AI 专用占比，本档估值需立即重估。**
4. **本档定稿于 2026-08-28 业绩说明会之前**，且**截至采证未见半年报后的新研报**。这两个时点都已列入 [index.md §11](index.md) 的复核触发器。
5. **本档采用整体法为主锚，SOTP 仅作交叉验证**（理由见 [valuation.md §9.1](valuation.md)）。若读者更信 SOTP 路径，请连同 §9.6 的互斥性一起读——两条路径不能同时使用。
6. 追溯重述存在内部不一致（2025H1 归母 +3,524 万元但扣非未变），用 2025H1 扣非作同比基数时须知。

> **本文档不构成投资建议。** 所有估值为在特定假设下的场景推演，钨价、金洲盈利、扩产达产三个核心变量中至少两个存在未闭合的信息缺口。
