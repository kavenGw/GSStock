## §9 估值（场景加权）

### 9.0 主锚裁定：为什么不用合并 PE

**主锚 = 「自产金分部重估 + 外购金近零计价」的分部加总（SOTP）。** 五条理由：

1. **合并 PE 的分母被外购金污染**：FY2025 外购金贡献 78.86% 收入但仅 15.42% 主营利润，且其利润随吞吐量剧烈摆动（26Q1 毛利 1.40 亿 → 26Q2 0.41 亿），合并 EPS 失去均值回复性。
2. **TTM 归母 8.87 亿中 26Q1 独占 58.8%**，而 Q1 同时受益于历史最高季均金价（4,863 $/oz）与外购金吞吐峰值，两者均不可持续。
3. **自产金侧存在稳定的建模基石**（实现价/市场价折价率两年稳定在 63.8%–66.1%、单位成本两年稳定在 178.0–183.6 元/克），可靠性远高于合并口径。
4. **外购金 ROIC 约 5.1%**，接近资金成本，权益贡献应按净营运资金清算价计而非盈利倍数计。
5. **分部加总天然暴露净负债 41.65 亿**，而合并 PE 会把它隐藏。

合并口径仍完整列出并作交叉验证（§9.5），但不作主锚。

### 9.1 建模基石与算式【硬推导】

`自产金毛利 = 产量(吨) × 1,000,000 × [市场金价(元/克) × 65% − 单位成本(元/克)]`

| 参数 | FY2024 | FY2025 | FY2026E 用值 | 分级 |
|---|---|---|---|---|
| 自产金实现价 / 市场金价 | 63.8% | 66.1% | **65%** | 硬推导（自产金分部收入含金精矿与焙砂，按含金量折价销售） |
| 单位成本（COGS 口径） | 178.0 元/克 | 183.6 元/克 | **195–215 元/克**（美盛爬坡抬升） | 硬推导 |
| 自产矿产金产量 | 约 1.08 吨 | 2.66 吨 | 见情景 | 软 |
| 金价换算系数 | — | — | **0.21628 元/克 per $/oz** | 硬（2026-09-04 双源自洽，偏差 0.11%） |

**口径冲突记录**：民生证券给的 FY2025 单位开采成本 256 元/克与硬推的 183.6 元/克相差 72 元/克，**两者不可混用**——本档一律用硬推的 183.6 元/克作基准，256 元/克作保守上界（差额可能是运输、权益金或摊销的更宽口径）。**公司不披露 AISC【缺】**，故无法给行业可比的全维持成本，成本曲线位次不作为竞争优势写入本档。

**26H1 自产金约 1.49 吨是反解值不是披露值**：由 26H1 黄金产品毛利 8.13 亿 = 自产金 × 64.13% + 外购金 × 1.94% 解出，产量口径交叉验证偏差 4.1%。**该反解依赖「外购金毛利率仍为 1.94%」与「自产金毛利率仍为 64.13%」两个取自 FY2025 年报的假设，若 26H1 自产金毛利率因美盛爬坡而低于 64.13%，反解产量会被低估。凡引用该数字处均须随附此脆弱性说明。** 独立佐证：按季再解得 26Q1 约 1.15 吨、26Q2 约 0.26 吨，与卡特巴阿苏 26Q2 有 73.6% 天数处于停产状态相互印证——两条互不依赖的证据指向同一结论。

### 9.3 分部加总测算（本档主锚，独立重算）

费用分摊法：公司只披露分部毛利，不披露分部费用与税【缺】。按毛利贡献比例分摊全公司期间费用与减值，所得税率取 26H1 实际 **21.2%**。

**base 情景（自产金 3.1 吨）**

| 步骤 | 值 |
|---|---|
| 自产金毛利 = 3.1 × 1,000,000 × 427.6 | **13.26 亿** |
| 外购金毛利 | 2.70 亿 |
| 锰及其他毛利（**因百源丰停产 60 天且电解锰技改减值，自 A1 原值 4.8 亿下修 25%**） | 3.60 亿 |
| 全公司毛利 | 19.56 亿 |
| 期间费用 + 减值（部分转回 **0.35–0.50 亿**——上限受硬会计约束：Q2 单季 0.8751 亿中仅存货跌价 0.5912 亿可转回，固定资产减值 0.2066 亿**一经计提不得转回**，再扣不随金价回的硅锰部分，正面贡献比全额转回低约三成） | −7.00 亿 |
| 自产金分摊费用 = 7.00 × 13.26/19.56 | −4.74 亿 |
| 自产金税前 8.52 亿 → 税后（×0.788） | **6.71 亿** |
| 锰系分摊费用 = 7.00 × 3.60/19.56 = 1.29 亿 → 税前 2.31 → 税后 | **1.82 亿** |

| 分部 | 税后利润 | 倍数 | 权益价值 |
|---|---|---|---|
| 自产金 | 6.71 亿 | **17.5×** | 117.4 亿 |
| 锰系 | 1.82 亿 | **9×** | 16.4 亿 |
| 外购金 | 0.76 亿 | **不给盈利倍数** | 5.0 亿（投入资本约 15 亿的清算折价） |
| 减：净负债 | — | — | **−41.65 亿** |
| **合计** | | | **97.2 亿 → 每股 10.67 元** |

> **与控制者自算校验值的对账**：控制者给出 96.4 亿 / 每股 10.58 元，本档独立重算得 97.2 亿 / 10.67 元，**偏离 0.8%，远在 15% 阈值内，无分歧需说明**。（A1 §12f 示例的「约 126 亿」用的是自产金 3.4 吨口径，与它自己最终采用的 base 3.1 吨不一致，本档以 3.1 吨为准，故低于该示例值，是口径差异不是算错。）

**bear 情景（自产金 2.90 吨，金价 3,750）**

自产金毛利 9.05 亿 / 外购金 2.5 亿 / 锰及其他 3.0 亿（百源丰停产不复产 + 硅锰实质停产 + 电解锰技改减值，三者同指向锰业务恶化，非独立事件）→ 全公司毛利 14.55 亿；费用+减值 8.00 亿（含续提）。自产金分摊 4.98 → 税前 4.07 → 税后 **3.21 亿 × 12× = 38.5 亿**；锰系税后 1.06 亿 × 7× = 7.4 亿；外购金在金价下行中减值敞口显性化，**权益贡献取 0**；减净负债 41.65 亿。

**分部加总法得权益价值仅 4.25 亿（每股 0.47 元）。这是 41.65 亿净负债在低谷盈利上的杠杆效应，数学上正确但作为内在价值不可直接采用**——一家拥有 110.8 吨资源量、有形净资产 47.64 亿的在产金矿，其清算/重置价值不会接近于零。故 bear 改以**资产法托底**：bear 情景下全公司税后约 4.77 亿 → 隐含 ROE = 4.77/51.39 = **9.28%**，对股权成本 13%（高杠杆 + 无实质股息 + 运营不稳定）→ 公允 PB = 0.71× → 51.39 × 0.71 = **36.5 亿 → 每股 4.01 元**。**bear 取两法较高者 4.01 元。**

**bull 情景（自产金 3.25 吨，金价 5,200）**

自产金毛利 17.26 亿 / 外购金 2.9 亿 / 锰及其他 4.5 亿（Q4 复产）→ 全公司毛利 24.66 亿；费用+减值 6.30 亿（减值转回，**上限受 0.5912 亿的存货跌价部分约束，见下**）。自产金分摊 4.41 → 税前 12.85 → 税后 **10.13 亿 × 20× = 202.6 亿**；锰系税后 2.64 亿 × 10× = 26.4 亿；外购金取清算上界 10 亿；减净负债 41.65 亿 → **197.4 亿 → 每股 21.67 元**。

### 9.4 倍数的框架内自检：隐含 ROE 回查【规格 §3 必做】

自产金给 15–20× 已超出 Buffett 框架对周期/衰退型（<8×）与窄护城河（8–12×）的常规区间，故按规格要求**回查隐含 ROE 而非直接抬倍数**：

| 情景 | 全公司正常化税后 | 隐含 ROE（÷归母净资产 51.39 亿） | 股权成本 | RIM 公允 PB | RIM 权益价值 | SOTP 隐含 PB |
|---|---|---|---|---|---|---|
| bear | 4.77 亿 | 9.28% | 13% | 0.71× | 36.5 亿 | — |
| base | 9.29 亿 | **18.1%** | 13% | (18.1−3)/(13−3) = **1.51×**（g=3%） | 77.6 亿 | **1.89×** |
| bull | 13.53 亿 | 26.3% | 13% | (26.3−5)/(13−5) = 2.66×（g=5%） | 136.7 亿 | 3.84× |

**必须诚实写明的一条：SOTP 在每一档都比 RIM 更慷慨**（base 1.89× vs 1.51×；bull 3.84× vs 2.66×）。本档按控制者裁定以 SOTP 为主锚，即采用了**偏乐观的一侧**；若改用 RIM 口径，期望内在价值将从 9.66 元降至 7.69 元（36.5×40% + 77.6×45% + 136.7×15% = 70.03 亿）、安全边际从 −67.8% 恶化至 −74.4%。**两条路径的结论方向一致，评级不因口径切换而改变**——这正是本档结论稳健性的来源。另需注意，base 隐含 ROE 18.1% 是在金价接近历史高位时取得的，穿越周期的正常化 ROE 应更低，故 1.51× 的公允 PB 本身也偏松。

倍数取值的支撑：自产金 17.5×（base）取板块可比 PE 中位 23.4× 打约 25% 折——折价理由是储量口径缺失、目标严重落后、非计划停产反复；bear 降至 12×、bull 升至 20×，**三档均落在"窄护城河 8–12× / 优质周期 ≤20×"的框架边界内，无 ❌破框架项**。锰系 7–10×（周期性工业金属、无成长性、硅锰已停产）。

### 9.6 加权与安全边际

| 情景 | 每股内在价值 | 概率 | 赋权理由 |
|---|---|---|---|
| bear | 4.01 元 | **40%** | 停产是重复模式而非一次性（四年四次，[§11](index.md) 有时间线），且金价 26Q3 至今季均 4,252.6 已较 26Q2 季均再降 5.79%，bear 的两个触发条件都在现实轨道上 |
| base | 10.67 元 | **45%** | 金价横盘 + 黄金端 H2 恢复但不满产（介于控制者给定的扰动档 2.90 吨与满产档 3.25 吨之间），是对 26H1 已发生事实的最小外推 |
| bull | 21.67 元 | **15%** | **x-growth 三要素门控**：(a) 扩产达产确定性【软】且有「进度慢于规划」反证、(b) 客户/终端能见度【硬】（黄金天然满足，央行连续 16 年净买入、2026Q2 净购 289 吨同比 +62%）、(c) TAM 跑道【软/缺】（储量口径缺失）。**只硬过一条，且是天然满足的那条**；叠加自产金 run-rate 1.49 吨与主力矿停产 99 天两项反向硬证据，按规格「三项全软 → ≤20%」再加严至 **15%** |

**期望内在价值 = 4.01×40% + 10.67×45% + 21.67×15% = 9.66 元/股 = 87.98 亿元。**
**安全边际 = (87.98 − 273.30) / 273.30 = −67.8%。Σ概率 = 100%。**

**bull 单独压力测试**：197.4 亿对现市值仍 **−27.8%**。最乐观情景也无安全边际。

## 首建档说明（本档为 2026-09-06 首次建档，无旧档可对照）

全仓此前无西部黄金分析档，故不写"相对旧档变化清单"，改记本轮相对**市场通行认知**被纠正的七处，供后续重估对账：

1. **"营收 135 亿的中型矿企"→ 错**。FY2025 外购金收入 106.99 亿占 78.86%、毛利率 1.94%，真实矿业收入体量仅约 15–20 亿。**营收不可用于同业对标。**
2. **"整体毛利率 9.59% 说明成本劣势"→ 反了**。自产金毛利率 64.13% 属行业上游水平，整体毛利率必须与外购金占比合读，单看会得出完全相反的结论。
3. **"产量 16.92 吨"→ 口径错**。那是含外购冶炼的商品金，**不可与紫金/山东/赤峰的矿产金并列**；可比口径是自产矿产金 FY2025 仅 **2.66 吨**。
4. **"非金业务是铁矿"→ 证伪**。非金业务是**锰系与铍，不含铁矿**，占收入 5.66%（26H1）。
5. **"资产注入长期落空"→ 推翻**。2025-08 已完成交割，新疆有色 2021 年同业竞争承诺函在先、定价成本封顶，四年内兑现。**真正落空的是并购标的的盈利承诺**（蒙新天霸完成率 6.08%）。
6. **"Q2 塌方是金价下跌引发存货跌价"→ 不完整**。主因是**主力矿停产 99 天**（26Q2 有 73.6% 天数停产），减值是次因且其中 2,065.65 万是不可转回的固定资产减值。
7. **"同花顺 F10 股息率 9.59%"→ 错误值**，真值 **0.52%**（疑与 26H1 毛利率 9.59% 字段串位）。**注意 26H1 销售毛利率恰为 9.59% 纯属巧合，该毛利率数据正确、是本档全部分部推导的输入，不得删。** 另需严防西部矿业（601168）2026H1 营收 394.43 亿 / 净利 41.69 亿被数据站错配给本股，**本股真值为营收 110.43 亿 / 归母 5.47 亿**。
