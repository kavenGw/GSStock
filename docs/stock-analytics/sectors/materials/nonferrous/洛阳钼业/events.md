# 洛阳钼业（03993）事件回写

## 承接：26Q1 季报点评（2026-04-29，被本轮中报取代）

原档 `quarterly/26q1/2026-04-29-洛阳钼业-26Q1季报点评.md` 的结论在 2026 中报后大部分被更新，以下为**仍有效的残值结论**，承接进本档：

1. **同业现金质量对照仍成立**：26Q1 洛钼每股 OCF +0.53 元、OCF/净利 ≈ 147%，同期中金黄金（600489）每股 OCF −0.45 元、OCF/净利为负——同为"央企 + 金属周期 + 价格上行"，报表肌理完全不同。**洛钼在"金属涨价时正常出货、把利润变成现金"这一项上长期优于同业**，这条判断在 2026H1（OCF/净利 101.1%）仍成立，只是缓冲已由 138.5% 收窄至 101.1%（见 index.md §11 触发器 T5a）。
2. **"不是矿业里最优秀的那一档"仍成立**：26Q1 横向表中紫金矿业 ROE 10.35% / 毛利率 36.33% / 每股 OCF 1.05 全面优于洛钼（9.06% / 22.88% / 0.53）。2026 中报后洛钼 ROE 升至 18.29%（半年加权），但同业估值横向（business.md §4）显示其相对紫金仍无估值折价——"若必须暴露在金属周期主题，紫金是更好选择"的相对排序未被推翻。
3. **"别拿单季 EPS 年化算 PE"的纪律仍成立且更重要**：26Q1 单季 EPS 0.36 年化后 PE 仅 13.3x 的错觉，在 2026H1（EPS 0.76、Q2 单季净利 83.92 亿创历史新高）会放大成更极端的低 PE 错觉（H 股 PE-TTM 10.73x）。**周期股低 PE 是顶部信号不是便宜**，见 thesis.md §8。
4. **26Q1 五项假设中，两项已在本轮被推翻或改口径**：
   - "假设 4：C1 cash cost 维持全球第一四分位" —— 公司**从未披露 C1**，26Q1 点评用毛利率反推并写成了硬结论，属越界。本轮已改为**毛利率替代口径裁决**并显式标注（index.md §11 触发器 T5b）。
   - "假设 5：无摊薄性激进并购" —— **已失守**：2026-01 巴西四座金矿 10.15 亿美元并购（40 天完成交割）+ 12 亿美元零息可转债（转股价 28.03 HKD），投资现金流 −140.25 亿。
   - "假设 2：钴价从低位见底回升" —— 价格侧成立（+94.22%），**但被配额制切断变现**：H1 钴销量 −87.60%、收入 −44.87%、库存 168,397 吨。
5. **26Q1 的监控指标口径变更**：其"资本开支/折旧倍数 >1.5x"因半年报未披露折旧摊销而**无法按原口径裁决**，本轮改以在建工程同比（+107.54%）替代；其"净利对铜价弹性 ≈ 1.5x"已被中报回算修正为 **2.2x**。
6. **26Q1 的"触发买入研究"三条件（铜价回成本曲线 75 分位 + PB <1.5x + 正 FCF）本轮完整沿用**，当前 1/3 满足（仅正 FCF），闸门关闭。

> 该季报的整体定性（"A 级的财报 + C+ 的商业模式"）在 2026 中报后依然适用，且中报把两侧都推到了更极端：财报更好（净利 +86.27%、ROE 18.29%），商业模式的弱点也更清楚（钴卖不出去、刚果金占毛利 74.1%、公司自己靠锁单避险）。
