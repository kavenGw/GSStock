# 洛阳钼业 — §9 估值（场景加权）+ 相对旧档变化清单

## §9 估值（场景加权，H 口径 HKD）

### 9.0 口径声明

- **跟踪主体**：洛钼 A+H 分别注册、不可互转（非 ADR/HK fungible），H 股对 A 股折价 **25.3%**（自算复核：A 18.46 CNY × 1.16412 = 21.49 HKD；H 16.06 / 21.49 − 1 = −25.3%）。按"A+H 取估值更低一侧"铁律，以 **H 股（03993，HKD）** 为跟踪主体。
- **汇率**：**1 CNY = 1.16412 HKD**（2026-09-03，open.er-api.com）。**旧档所用 ×1.08 已作废**，本档不含任何 1.08 派生值。每档先算 A 股 CNY 每股内在价值，再 × 1.16412 折 HKD。
- **实时锚（2026-09-02 收盘，quote_guard 两条 exit 0、市值自洽偏差 0.00%）**：A 18.46 CNY / PB 4.39x / PE-TTM 14.2x / 总市值 3,949.39 亿元；H 16.060 HKD / PB 3.28x（CNY 口径）/ PE-TTM 10.73x。总股本 21,394,310,176 股，每股归母净资产 **4.205 CNY**（899.63 亿 ÷ 213.943 亿股）。
- **无重要联营/合营需 SOTP 拆分**：投资收益 7.86 亿元占利润总额 3.1%，未达重大性阈值，不单独拆分。IXM 为全资并表贸易平台，按主业口径合并处理（其毛利率 2.06%，对估值贡献接近于零，见 9.2）。

### 9.1 正常化 EPS 推导（旧档三档全部作废，本节为重新推导）

**为什么旧档基数必须整体重来**：旧档取"3 年中枢（2023–25）EPS = (0.38+0.63+0.95)/3 ≈ 0.65 CNY"，并据此给 bear 0.45 / base 0.60 / bull 0.80。2026H1 单半年 EPS 已达 **0.76**，TTM EPS **1.299**——**连旧档 bull 档 0.80 都低于 H1 单期年化的 1.52**。旧档基数至少低估 50%，期望内在价值 A 7.09 / H 7.66 不可再用。

**但纪律不变：正常化利润绝不取周期顶年化。** 2026H1 归母净利 161.52 亿、Q2 单季 83.92 亿创历史新高，对应铜均价 $13,083.97/t、钴 $25.56/lb、APT +363.79%、金 +57.15% 的**多金属同步周期顶**。H1 年化 323.04 亿 / EPS ≈ 1.51 只作弹性推导的起点，**三档正常化 EPS 全部显著低于它**。

**两法交叉推导：**

**方法 A — 金属价回归 × 净利弹性**

净利/铜价弹性 **2.2x**（口径：归母净利同比 +86.27% ÷ LME 铜均价同比 +38.73%，A1 中报回算；旧档 1.5x 已作废）。弹性来自高经营杠杆 + 多金属同涨共振，下行时同向放大。

| 情景 | 正常化铜价 | vs H1 均价 $13,084 | 净利回吐（×2.2） | 顶部年化 323 亿 → 正常化净利 | 产量/结构调整 | 正常化 EPS（CNY） |
|---|---|---|---|---|---|---|
| Bear | $8,000/t（成本曲线 75 分位上沿） | −38.9% | −85.6% | ≈ 46 亿 | 黄金/钼/钨部分对冲，+ 铜量增 → 上修至 ≈ 75 亿 | **0.35** |
| Base | $9,500/t（10 年中枢上沿 + 成本抬升） | −27.4% | −60.3% | ≈ 128 亿 | KFM 二期 + 黄金放量，产量中枢较 H1 年化 +15% → ≈ 147 亿 | **0.65** |
| Bull | $11,000/t（结构性上移，仍低于现价 $14,353） | −15.9% | −35.0% | ≈ 210 亿 | KFM 二期 +10 万吨铜达产 + 黄金 20 吨产能 → ≈ 214 亿 | **1.00** |

**方法 B — 正常化 ROE × 每股净资产（交叉验证 base）**

H1 加权 ROE 18.29%（半年口径，年化量级 ≈ 36%）显著高于穿越周期水平；矿业股穿越周期正常化 ROE 取 **12–13%**。正常化时点（2027–2029）每股归母净资产按当前 4.205 CNY 以留存增厚推至约 **5.0 CNY** → 正常化 EPS = 5.0 × 12.5% ≈ **0.63 CNY**。

**两法收敛于 base 0.63–0.65 → 取 0.65 CNY。** 三档 EPS（0.35 / 0.65 / 1.00）全部低于 H1 年化 1.51 与 TTM 1.299，符合"绝不取顶部年化"铁律。

**bull 档 RIM 交叉验证（防止用倍数偷渡估值）**：bull 情景隐含 ROE = 1.00 ÷ 约 5.5 CNY（bull 时点每股净资产）≈ **18.2%**；股权成本按海外资源 + 单一司法辖区风险取 **12%**，永续增长 g = 3% → 公允 PB ≈ (18.2−3)/(12−3) = **1.69x** → 每股 ≈ 9.3 CNY，低于 12.00 CNY。**说明 bull 的 12.00 CNY 已是乐观上界而非中性值**，本档保留 12x 但在此显式披露：若按 RIM 取值，bull 将降至约 9.3 CNY / 10.8 HKD，期望内在价值随之降至约 6.0 CNY / 7.0 HKD，**结论方向不变、安全边际更负**。

**概率自检：40% + 35% + 25% = 100% ✓**

### 9.4 期望内在价值与安全边际

- **H 口径期望内在价值** = 3.26×0.40 + 8.32×0.35 + 13.97×0.25 = 1.304 + 2.912 + 3.4925 = **7.71 HKD**
- **A 口径对照** = 2.80×0.40 + 7.15×0.35 + 12.00×0.25 = 1.120 + 2.5025 + 3.000 = **6.62 CNY**（交叉核对：6.62 × 1.16412 = 7.71 ✓ 同币种自洽）

| 口径 | 期望内在价值 | 实时市值锚 | **安全边际** |
|---|---|---|---|
| **H（跟踪主体）** | 7.71 HKD | 16.060 HKD | **−52.0%** |
| A（对照） | 6.62 CNY | 18.46 CNY | −64.1% |

**Bull 单独压力测试（H 口径）**：13.97 / 16.06 − 1 = **−13.0%**。**即便"铜中枢上移 + KFM 二期达产 + 黄金 20 吨"三件事全部兑现、bull 情景独立成立，对标现价仍无安全垫。** 若再叠加 9.2 的 RIM 校正（bull → 10.8 HKD），压力测试值降至 −32.8%。

### 9.5 诚实面对"贵"（红线 4）

- **PB 才是矿业股的标尺**：H 股 PB **3.28x**（CNY 口径）/ A 股 **4.39x**，周期股合理区间是 PB 1–1.5x，买点闸设在 <1.5x——**当前距买点差 2.2–2.9 倍**。
- **低 PE 不是便宜**：H 股 PE-TTM **10.73x** 是全可比表最低（紫金 H 12.22x、五矿资源 13.93x、江铜 A 13.91x），但**分母是周期顶利润**（Q2 单季创历史新高、铜价约为 10 年中枢 1.9 倍）。周期股低 PE 是顶部信号而非折价，这是本轮最容易犯的错。
- **不用"护城河上修"或"成长空间"稀释价格（红线 8 的对偶）**：本轮基本面确实极强（ROE 18.29%、扣非/归母 96.6%、正 FCF 114.75 亿、净有息负债 ≤ 75.19 亿 = 权益的 ≤6.9%），估值也确实下杀（A 股 PB 5.18x → 4.39x）。**这两件事都被诚实计入——它们让 base 的正常化 EPS 从旧档 0.60 上修到 0.65、bull 从 0.80 上修到 1.00，期望内在价值从 7.66 HKD 略升到 7.71 HKD。但期望内在价值上修 0.7% 追不上"仍是现价的 48%"这个事实。**
- **相对同业无折价**：A 股 PE-TTM 14.2x 与紫金 A 12.95x、江铜 13.91x、五矿资源 13.93x 同区间；PB 4.39x 与紫金 4.59x、西部矿业 4.21x 相当。**唯一真折价来自 A/H 价差（25.3%），不是来自行业定价。**
