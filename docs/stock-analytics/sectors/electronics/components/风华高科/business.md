## §1 能力圈 & 本次重审触发

### 能力圈：边界地带，偏圈内

生意模型本身极易理解：生产 MLCC（片式多层陶瓷电容）及片式电阻、电感等被动元件，按「颗」卖货，价格由行业供需周期决定——**一句话能讲清**。

难的不是看懂生意，而是预测两件事：①下一轮 MLCC 涨价周期的时点与幅度；②风华能否真正从中低端突破日韩（村田 / 三星电机 / 太阳诱电 / TDK）把持的高端壁垒。**这两点都落在「可靠估计之外」。**
**本轮的进展**：中报对第②点给出了迄今最直接的读数——在最有利的价格环境下主营毛利率只有 17.31%，公司自己也在中报风险章节承认「产能规模及技术水平与国际先进同行仍然有差距」【硬】。第②点的不确定性**没有减少，但方向更清楚了**。

### TAM / SAM / SOM

| 新兴敞口 | 汽车电子 + AI + 储能 + 低空经济**合计** | **<15% 营收** | 【硬】公司公告 |

### 跑道结论（`x-growth` lens 落点）

**名义跑道极长，但风华跑不动它。** 国产替代空间在数字上巨大（本土高端自给率 <20%），但：
1. 公司在中报与异动公告中**自认**「高端产品在**技术水平、产能规模以及产品良率**上与日韩领先同行仍存在差距」【硬】；
2. 技术代差可量化：日韩顶尖介质层 <0.5μm、堆叠 >1500 层（另一口径 1000+ 层），风华公开资料约 **300–500 层**、国内主流 1μm【软】——**差一个量级的介质层厚度不是靠扩产能补的**；
3. 上游卡脖子：高纯超细镍粉「几乎 100% 依赖日本住友金属矿山与东邦钛工业」【软】；
4. **最关键**：唯一的高端 MLCC 产能项目已结项、二期已终止（§3.5）——**渗透率提升缺少产能载体**。

### 3.2 涨价传导：本轮最重要的一节

| 口径 | 2026H1 毛利率 | 同比 |
|---|---|---|
| 分行业 · 电子元器件制造业（= **综合**） | **18.76%** | **+0.81pct** |
| 分产品 · 电子元器件及电子材料（**主营**，占收入 98.19%） | **17.31%** | +0.66pct |
| 分产品 · 其他业务（占收入 1.81%） | 97.58% | +2.01pct |
| 分地区 · 境内（95.77%） | 18.62% | +0.85pct |
| 分地区 · 境外（4.23%，1.48 亿） | 21.89% | −0.22pct |

**⚠️ 口径警告（触发器设计的根源）**：综合毛利率 18.76% 被占收入仅 1.81%、毛利率 97.58% 的「其他业务」（0.632 亿收入 / 0.015 亿成本）**拉高约 1.45pct**。**真正的主营产品毛利率是 17.31%。** 任何裁决毛利率触发器的场合都必须写明用的是哪一个（本档钉死口径见 [§11](index.md)）。

**结论**：营业成本 +25.03% 几乎追平营收 +26.28%，毛利率只挪 0.81pct → **涨价基本被上游（银 / 铜 / 镍 / 锡）成本吃掉**。公司自述归因见中报现金流章节与风险章节【硬】。
→ **+74.01% 的利润增长来自薄毛利上的经营杠杆（56.39 亿固定资产被产量摊薄）+ 低基数，不是价差扩张。** 这是全档最重要的单一发现，已写入 [§0](index.md) 与 [§9.0 前提 1](valuation.md)。

**L25 季节性回测**：本公司 Q2 毛利率天然高于 Q1（2025 年 17.49% → 18.33%，**+0.84pct 季节性正偏置**）。2026 年为 16.78% → 20.27%（+3.49pct），**扣除季节性后真实改善约 +2.65pct**；同比口径 26Q2 vs 25Q2 为 **+1.94pct**。→ Q2 改善**是真实经营改善**，但幅度按 +1.9~2.7pct 理解，不能按 +3.5pct 外推。

### 3.4 利润质量：旧档「依赖补贴」必须收敛，但不能一笔勾销

2026H1 非经常性损益合计**仅 269.4 万元**（占归母 **0.93%**），扣非/归母 **99.07%**——**报表层面利润质量是近年最干净的一次**，旧档「扣非长期显著低于报表 / 依赖政府补贴」在本期**明确被证伪**。

**但公司把以下项目自行界定为「经常性损益」（中报 P.7 明列）**：

| 项目 | 金额 |
|---|---|
| 先进制造业企业增值税加计抵减 | 1,237.66 万 |
| 与资产相关的政府补助摊销 | 2,538.40 万 |
| 代扣个税手续费返还 | 56.90 万 |
| 稳岗补贴 | 4.35 万 |
| **合计** | **3,837.31 万（税前）**，占归母 **13.2%** |

另：利润表「其他收益」3,900.0 万（占利润总额 12.26%，主要为与日常经营活动相关的政府补助）；「投资收益」3,102.6 万（占利润总额 9.75%，参股公司投资收益 + 债权投资利息）。

**可比口径（严格）**：报表扣非 2.876 亿 − 上述 3,837 万（按 15% 高企税率税后约 3,262 万，未考虑少数股东，偏保守）≈ **半年归母 2.55 亿**（半年净利率 7.29%）；若再剔除非主营的投资收益 3,103 万，主业口径约 **2.29 亿**。

**裁定（旧档表述的替代文本）**：**低谷年依赖补贴与非经常项，景气年被经营利润摊薄；补贴依赖是周期低谷期特征而非常态结构。** 但政策性贡献仍占归母约 **11%–13%**，**不是「不依赖补贴」，只是补贴占比被高增的利润稀释了。**

| 2024 / 2023 分红率 | 51.0% / 33.1%（总额 1.7212 亿 / 0.5737 亿）；**近三年均值约 41.5%** | 【硬】 |
| **当前股息率** | **0.185%**（每股 0.10 元 ÷ 54.11 元） | 自算 |
| 中期分红 | 2026 半年度**不派现、不送股、不转增** | 【硬】 |
| 回购 | 952.28 万股（占总股本 0.82%），**2026-08-19 全部注销** | 【硬】 |
| 派息能力 | 26H1 经营现金流 1.611 亿 vs 上年度分红 1.147 亿，覆盖尚可，但**现金流同比 −55.64%**，覆盖率快速恶化 | 【硬】 |

**双面必答（简版）**
- **高分红是否可持续？** 分红率 40.5% 稳定，但**绝对额极小**；股息率 0.185% 在任何价值框架下都不构成回报来源。
- **股息率高是否价值陷阱？** **反向问题**——股息率被 220% 的涨幅稀释到几乎为零，这本身就是「**已从价值股区间彻底离开**」的读数。
- **⚠️ 口径陷阱**：公告里的「最近三个会计年度累计现金分红 3.4425 亿 / 三年平均净利 2.647 亿 = **130%**」是**监管合规披露口径，不是分红率**；真实年度分红率是 **40.50%**。二者不得混用。
- `valuation.dividend_yield` 填 **0.18（%）**，口径为最新年度每股股息 0.10 元 ÷ 2026-08-27 收盘 54.11 元。

## §5 护城河：类型、强度、趋势

| 护城河类型 | 判定 | 依据 |
|---|---|---|
| 无形资产（品牌 / 专利） | **无** | 电容是标准件，无品牌溢价；专利未构成排他 |
| 成本优势 | **弱且本轮被证否** | 若有成本优势，涨价周期应放大价差；实际毛利率仅 +0.81pct，且上游镍粉近乎 100% 依赖日本 |
| 转换成本 | **无** | 下游随时可换供应商（认证成本存在但远低于日韩高端料号） |
| 网络效应 | **无** | —— |
| 有效规模 | **无** | 行业玩家众多，CR5 集中在日韩，国内厂商同质竞争 |

**强度：弱 / 接近无。趋势：本轮由「中性偏弱」下调为「明确弱」。**

**旧档判断的重评**：旧档写「毛利率十年腰斩就是护城河不存在的判决书」（41.67%@2018 → 17.75%@2025）。本轮给出了**更强的一条判决**：
> **不是「毛利率跌下来了」，而是「在最有利的环境下也涨不回去」。** 行业史诗级缺货 + 公司连发两封涨价函 + 产销量创历史新高，主营毛利率只有 17.31%，最好的单季 20.27%，距旧档设的观察线 25% 还差 4.7pct。**周期底的低毛利可以用周期解释，周期顶的低毛利只能用竞争力解释。**

**商业模式：commodity（大宗商品型）。** 提价 10% 测试：客户会立刻流向村田 / 三环 / 其他国产同行——标准的商品生意。

**管理层三维评估**
- **诚信：正面（本轮上调）。** 两次主动发公告否认英伟达传闻、董事会自述股价「非理性炒作」、回购股份选择注销——三件事都指向诚信正面。**未见造假迹象。**
- **资本配置：本轮由「平庸」改判为「审慎但被动」。** 终止二期、结项募投、8.47 亿节余补流、回购注销，都是**理性的收缩**，比景气期盲目扩产好；但同时说明公司自己也不认为这轮景气值得押新产能。祥和项目年化投资回报率约 **3.0%**，是历史资本配置质量的直接读数。
- **主人翁心态：弱（未变）。** 国资任命制（广晟控股 23.59%，质押 7,853.40 万股）；**无股权激励、无员工持股**（中报明确「不适用」）；报告期高管持续变动（副总裁 4/20 离任、董秘 7/25 辞职由董事长代行、8/6 新聘副总裁）。**管理层与股东利益绑定机制依然为零。**
- **国资的正面论据不成立**：**【缺】**未找到 2026 年国资专项注资、定增、产业基金导入或政府资本开支支持的公开证据。**不得据此写「国资带来产业资源支持」**；旧档的治理折价判断维持。

**机构强制力警示：本轮方向反转。** 旧档写「重资产扩产是行业军备竞赛式的从众扩张」；中报证明**本轮公司未参与军备竞赛，反而退出**。这既解除了一条风险（不会因自身扩产制造过剩），也抽掉了成长叙事的载体——完整的双面拆解见 [§8.5](thesis.md)。
