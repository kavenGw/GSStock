## §12.5 已知局限与【缺】清单（明确未找到公开证据，不得编造）

1. **分产品产销量 / 产能利用率**：中报**无产销量表** → 通信线缆与高速线的量价拆分**全部为推算**，依赖「非铜单位成本持平 + 分部内品类结构稳定」假设。本档给出的「隐含销量 +13%~+20%」是**一组自洽解，不是唯一解**；另一组同样能拟合的解是「销量增更多但单位毛利额被压缩」。
2. **高速通信线的分部毛利率**：公司**从不单独披露**（只披露到「通信线缆」大类）→ 本档 2025FY ≈36.6% / 2026H1 ≈28.6% 为**反解值、非披露值**，区间取决于对「其余线缆毛利率 8%–15%」的假设。
3. **挤出机台数**：中报仅称「已全部到货」，**未给台数** → 旧档「年中 30 台」达成与否**无公开证据**；卖方口径「2026Q1 末 23 台」与投关口径「2026-05 已 16 台」互不一致，**旧档该数字来源本身不可靠**。本档据此**废弃台数阈值**并改用可持续观测的替代指标（[index.md §11](index.md) M3）。
4. **安费诺 / 立讯 / 英伟达绑定关系**：2026 中报（A 股 216 页 + H 股 56 页）**零次提及**三家中任何一家 → K9 前半与旧 T3 前半**无法刷新**。「224G 产能 80% 被安费诺包圆」最新可考仍是 **2025Q2 媒体转述**【软】，**不得作为 2026 年现状陈述**。
5. **全球高速铜缆市占率**：中报**未提任何市占率数字** → 「全球第二、约 25%」停在 2024 口径【软】，本轮既未证实也未证伪。
6. **高速通信线的铜价联动 / 调价条款**：公司**未披露**。
7. **2026H2 及以后的在手订单能见度**：**未找到**——中报无在手订单金额、无排产期限；旧档「订单排至 2026」为 2025 年口径，**降级为过期证据**。
8. **高速铜缆的定量降价幅度 / 报价指数 / 客户压价函件**：**未找到**（中英文关键词已检索：价格战/降价/产能过剩/224G 供给/price cut/copper cable pricing；范围含东财、新浪、财联社、观研、头豹、中国线缆网、Amphenol IR、LightCounting 转述、DIGITIMES）→ 压价只能三角推断，**不能给出定量幅度**。
