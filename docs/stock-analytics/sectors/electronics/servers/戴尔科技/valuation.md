## §9.1 先否掉不适用的口径

| 口径 | 适用性 | 理由 |
|---|---|---|
| **PS** | ❌ **禁用** | 净利率 8.8%（GAAP，Q2）、毛利率 19–21% 的硬件商，PS 无信息量。当前 PS @$466.53 = 1.99x（TTM 营收 $151.2B）或 1.57x（FY27 指引 $192B）——看起来"便宜"纯属低毛利错觉。**本档不出现任何以 PS 为依据的估值论证。** |
| **PB / 资产法** | ❌ **失效，且不许改主锚** | 股东权益 **−$1,427M**（2026-07-31，8-K 原表），PB 无定义。`buffett-doc-spec` §3「改资产法主锚」的准入条件是「bull < base + 资产法托底」，Dell 两条都不满足（bull $302.72 > base $214.37；净资产为负无从托底）→ **保留利润法主锚合规**。 |
| **forward PE** | ⚠️ **可算，但不作主锚** | 分母是**双重周期顶盈利**（AI capex 顶 × 内存短缺租金顶）。列为「市场在定价什么」的披露项，见 [index.md §10.3](index.md)。 |
| **正常化盈利 × 倍数** | ✅ **主锚** | 见 §9.3。Dell 在 FY27 变得**更周期、不是更结构**（利润 ≈ AI capex 强度 × 内存短缺强度），正常化法比 forward PE **更该用而非更不该用**。旧档的方法没错，错的是参数。 |
| **EV/EBIT** | ✅ **交叉验证锚** | 见 §9.2。负权益下市值口径易被质疑，EV/EBIT 是自然的交叉锚。 |

## §9.2 EV 的正确口径 —— **EV ≈ 市值，绝不能加账面净债务 $22.9B**

| 项 | 数值（$M） | 口径 |
|---|---|---|
| 账面总债务（短期 8,481 + 长期 25,985） | 34,466 | 8-K【硬】 |
| 减：现金及等价物 | (11,569) | 8-K【硬】 |
| = **账面净债务** | **22,897** | **❌ 不可用于 EV** |
| Q2 DFS owned assets（融资应收 20,430 + 经营租赁设备约 3,230） | 约 23,660 | 【推算】 |
| Q2 DFS related debt（按公司自陈 7:1 公式外推，Q1 实测吻合度 0.875 = 7/8） | 约 20,700 | 【推算·Q2 10-Q 未发布】 |
| **Q2 core debt** | 约 **13,900** | 【推算】 |
| 现金及投资（现金 11,569 + 长期投资 2,679） | **14,248** | 8-K【硬】，与 CFO 口述 "$14.2 billion in cash and investments" **精确吻合** |
| **核心净债务** | 约 **−350（净现金）** | 【推算】 |

**理由**：DFS related debt 是**客户融资业务的对应负债**，有等额生息资产（融资应收 + 租赁设备）对冲，且 10-Q 原文明写"the credit holders have **no recourse to Dell Technologies**"。把它当公司杠杆加进 EV，会高估 EV 约 8%。交叉验证：管理层电话会自述 **core leverage 0.8x**，若 core debt 约 $13.9B 则隐含 core EBITDA 约 $17.4B，与 H1 non-GAAP 经营利润 $10.16B + D&A 的量级一致。

→ **EV @$466.53 ≈ $301.1B；EV @$425.00 ≈ $274.3B。**

| EBIT 口径 | EBIT | EV/EBIT @$466.53 | EV/EBIT @$425.00 |
|---|---|---|---|
| FY27 指引隐含（**周期顶**）：non-GAAP EPS $25.50 × ~650M ÷ 0.8 + 利息 $1.2B | 约 **$21.9B** | **13.8x** | 12.5x |
| 本档 base 正常化 | **$14.03B** | **21.5x** | 19.6x |
| 本档 bear 正常化 | $11.63B | 25.9x | 23.6x |
| 本档 bull 正常化 | $17.50B | 17.2x | 15.7x |

> **这张表就是「forward PE 不贵」这句话的解毒剂**：同一个 EV，按周期顶 EBIT 是 13.8x、按正常化 EBIT 是 21.5x，**差 56%**。这 56% 是「分母有多顶」的量化读数，不是估值方法的分歧。**本档明令禁止用「forward PE 18.3x / EV/EBIT 13.8x 看起来不贵」来稀释「盈利本身处在双重周期顶」这一事实。**

## §9.3 三情景参数与算术

**共同口径**：正常化营收 $155–175B（**FY27 指引 $192B 是周期峰值，不可直接用**；FY26 实际 $113B 是 AI 放量前的旧基数，backlog $95B 与企业刷新周期不会一次清零，故也不退回 $113B）。经营利润率 **7.5%–10%**（上沿自 A2 初判的 11% **下修至 10%**，理由：A1 桥表证明 +649bps 全部来自非 AI 的周期租金，且 H1 毛利率同比 −30bps 证明半年维度无结构性扩张；唯一确认的结构性改善是 opex 效率与存储自有 IP 占比）。倍数 **12–15x，坚决不上调**。利息约 $1.2B、税率 20%、股数 646.14M。

| 步骤（$M，除每股外） | **bear** | **base** | **bull** |
|---|---|---|---|
| 正常化营收 | 155,000 | 165,000 | 175,000 |
| 正常化经营利润率 | 7.5% | 8.5% | 10.0% |
| = 正常化经营利润（EBIT） | 11,625 | 14,025 | 17,500 |
| − 利息 | (1,200) | (1,200) | (1,200) |
| = 税前利润 | 10,425 | 12,825 | 16,300 |
| × (1 − 20%) = 正常化净利 | **8,340** | **10,260** | **13,040** |
| × 倍数 | **12x** | **13.5x** | **15x** |
| = 内在市值 | **100,080** | **138,510** | **195,600** |
| ÷ 646.14M 股 = **每股内在价值** | **$154.89** | **$214.37** | **$302.72** |
| 隐含正常化 EPS | $12.91 | $15.88 | $20.18 |
| 隐含 PE（自检，须等于倍数） | 12.0x ✅ | 13.5x ✅ | 15.0x ✅ |

**三档均低于顶部年化**（红线 3 自检）：Q2 单季 non-GAAP EPS $7.04 年化 = $28.16；FY27 指引 $25.50。**bull 的正常化 EPS $20.18 = FY27 指引的 79%**，bear 为 51%。**无一档取周期顶年化。**

### 概率赋权（Σ = 100%，逐档挂理由）

**bear 35%** —— 依据 [§6.3](thesis.md)（中间层的最强反驳）与 [§8](thesis.md)（周期定位）：
① 集成是**低壁垒环节**，ODM（广达/纬创/鸿海）不需要"扩产"就能抢单，产能弹性极高；Dell 当前的高利润率**没有产能壁垒保护**，上游一旦解绑、配额不再稀缺，价格竞争会在 1–2 个季度内把 ISG 利润率打回原形。
② A3 建模的**情景 D**（AI 完全不减速、仅内存正常化）本身就有 EPS −22~−29% / 股价 −29~−45% 的下行 —— **下行不需要 AI 叙事破灭就能兑现**，这是把 bear 权重给到 35% 而非 25% 的直接理由。
③ H1 毛利率同比 **−30bps**、真实 FCF **±0%**：半年维度上，这家公司还没有证明它比一年前更赚钱。

**base 45%** —— 依据 [§6.1 归因桥表](thesis.md) 与 [§3](business.md)：
① backlog $95B ÷ FY27 AI 指引 $74B ≈ **15 个月覆盖**，是【硬】的公司披露在手订单，为收入提供真实缓冲；
② opex 降至营收 **8%**（42 年最低，费用 +22% vs 收入 +58%）与存储自有 IP 占比提升是**部分结构性**的改善 —— 但 opex 率一半也是分母暴涨带来的，营收回落时会同步反弹，故只给"部分"；
③ 但 H1 毛利率同比 −30bps 证明**半年维度并无结构性扩张**，因此 base 的 8.5% 只比 FY26 全年基数（non-GAAP 经营利润率约 7.4%–7.7%）高约 1pt，不脱离穿越周期中枢。

**bull 20%（门控封顶）** —— `buffett-doc-spec` §3「bull 增长证据包门控」逐项：

| 要素 | 判定 | 依据 |
|---|---|---|
| (a) 扩产达产确定性 | **【不适用 / 缺】** | Dell 是**轻资产集成商**，无晶圆厂式扩产；瓶颈不在自建产能而在**上游配额**（GPU/DRAM/CPU/HDD）。公司**从不给 capex 指引**（8-K 与电话会均无），H1 capex 实数 $2,202M（+77%）只能事后取。**此支柱对本标的整体不适用，不能空着，明写"不适用"。** |
| (b) 客户 capex / 出货能见度 | **【软·仅终端兑底】** | ①具名客户【缺】—— Dell 不披露具名 AI 大客户；②降级到终端总量：Top-9 CSP capex $886.7B（2026）→ 约 $1.3T（2027，+50%）、IDC 全球服务器市场 $647.0B → $930.6B、TrendForce AI 服务器出货量 +~31%，**全部【软·第三方机构口径】**；③已锁定 vs 意向：$95B backlog 与 $60.9B 订单是**公司披露的在手订单**【硬】，但**取消条款、定价是否可重议、客户信用构成均未披露**【缺】，且 Dell 已明确告知大客户"未来价格无法保证"——名义金额的可比性弱于固定价订单。 |
| (c) TAM 跑道 | **【缺·口径不可比】** | 第三方 AI 服务器 TAM（$157B）与 Dell 单家 FY27 AI 收入指引 $74B 相比得出表观份额 47%，**明显口径不可比**（Dell 口径含整机柜、含转售 GPU 全额）。**本轮禁止用"份额"论证卡位**，渗透率标【缺】。 |

> **三要素为「缺 / 软 / 缺」，无一为硬** → 按门控规则 bull 概率封顶，取 **20%**。同时 bull 的倍数仍取框架内上沿 15x（未破框架），符合「增量边际利润率低于存量 → 不具备倍数扩张资格」的裁定。

### bull 情景单独压力测试（沿用联想档方法论①）

**假设 bull 100% 兑现**（正常化营收 $175B、经营利润率 10%、15x 全部成立）：

| 对照价 | bull 内在价值 | 安全边际 |
|---|---|---|
| @$466.53 | $302.72 | **−35.1%** |
| @$425.00 | $302.72 | **−28.8%** |

> **压测结论**：把最乐观的一档单独拿出来当成确定事实，现价仍溢价 35%。**没有任何一个情景能把 $466.53 论证成便宜。** 这条压测的意义在于：它把"安全边际为负"从"取决于概率赋权"降级为"与概率赋权无关"——即便有人认为我的 bear 35% 过于悲观，结论不变。

### 交叉验证：思科口径的 FCF 收益率（**披露，不作买点依据**）

兄弟档思科的买点口径是 **FCF 收益率 >3.5%**。若对 Dell 同法：H1 真实 FCF $4,104M 年化约 **$8.2B**（**必须用真实 FCF，不是调整后 FCF $11,314M**）→ 3.5% 收益率对应市值 $234.3B / 每股 **$362.6**，**远高于本档买点 $148–150**。
**为何不采用**：$8.2B 年化本身就是**周期顶的真实 FCF**（H1 零增长，但基数已在高位，且这个"零增长"是在收入 +71% 的条件下达成的）；思科的 FCF 是穿越周期稳定的（毛利率 64%+、FCF 全额回购分红）。**把周期顶 FCF 直接年化再套收益率阈值，等于犯了本档反复警告的同一个错误。** 故仅作披露，不作依据。
