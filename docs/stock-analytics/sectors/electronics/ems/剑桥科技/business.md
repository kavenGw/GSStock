## §1 能力圈 & 本次重审触发

### 1.1 为何现在重做

**旧档结论的承接**：旧档评级 `watch`、"真兑现 + 全额透支"的骨干判断**本轮全部保留**；结构错配论点**弱化一档**（§6.1），减持论点**下调一档**（§5），并新增"利润与现金分道扬镳"为本轮最强证伪（[thesis.md §6.2](thesis.md)）。旧档一处硬错误（完全稀释股本）已纠正，见 [valuation.md 变化清单 A1](valuation.md)。

### 1.2 能力圈判定：**边界地带，可分析但需扣分**

一句话商业模式：**替海外电信运营商与网络设备商做宽带接入终端与无线网关的 ODM/JDM 代工（2025 年 65.2% 收入），同时用同一套精密制造能力切入 AI 数据中心 800G/1.6T 高速光模块（34.7% 收入）**。前者是看得懂的低毛利代工生意（毛利率 14~19%、客户主导设计与年降）；后者是技术代际两年一换代的高波动生意，且**核心料（硅光引擎 / CW 光源 / 3nm DSP）全部外购、公司自述不具备自我替代能力**。

**扣分项（本轮未解除，反而更突出）**：2026H1 **分产品收入与毛利率未披露**【缺】、分地区收入未披露【缺】、前五大客户集中度未披露【缺】、光模块出货量与 ASP 从未披露【缺】、存货跌价准备余额【缺】。**占公司全部估值弹性的那块业务，其单位经济性无法被外部验证**——这是真实的能力圈边界，不是措辞谦虚。旧档把"分业务毛利率披露"列为翻转触发器之一，**本轮该触发器仍为【缺】，未转硬。**

### 1.3 逆向思考：这笔投资亏钱的三条路径

1. **1.6T 再次滑期 / 份额被 CR2 锁死** → 高增长业务增速回落，65% 的零增长基本盘暴露 → 81 倍 PE（H 股口径）无处安放。**该路径已部分兑现过一次**（2026Q1 大量发货的承诺落空，见 [thesis.md §7.2](thesis.md)）。
2. **存货减值**：存货 **31.97 亿**——**÷TTM 归母 4.7066 亿 = 6.79 倍**（与旧档 9.0 倍同族口径）、**÷H1 归母 3.28 亿 = 9.75 倍**，两口径不得混用；周转天数 **267.82 天**。**减值 1% ≈ 侵蚀 TTM 归母 6.8%；减值 15% 足以抹平一年多的利润。** 而 H1 资产减值损失仅 311.98 万，**大幅计提尚未发生**。
3. **现金链 + 摊薄双杀**：半年经营净流出 11.13 亿 + capex 6.85 亿 + 产业基金 8 亿 = 26 亿量级的现金消耗，对应期末货币资金 34.44 亿（年初 47.91 亿）；一年股本摊薄 37.4%，激励再摊薄 4.42%。**若经营现金流不转正，下一轮股权融资几乎是必然，摊薄会继续。**

### 1.4 时间尺度

以"持有 10 年"视角看：13 年财务序列里加权 ROE 只有 2014（17.59%）、2015（27.88%）两年超过 15%，且发生在 2017 年上市**之前**；**上市后 9 个完整年度加权 ROE 从未达到 10%**，区间 −19.56% ~ 9.37%，简单平均约 3.5%。**2026H1 加权 ROE 4.32% / 摊薄 3.50%，较 2025H1 的 5.10% / 5.05% 双双下降**——在利润创历史同期最好的半年里，资本回报率反而下降（分母被股权融资撑大）。**十年视角下这不是一家复利机器。**

### 2.2 剑桥的渗透率与剩余空间（成长 lens · 跑道长度）

- **全球份额约 1.0%**：2025 年高速光模块 16.75 亿元 ≈ 2.36 亿美元（按 7.15 汇率）÷ 238 亿美元 = **约 1.0%**，全球光模块收入榜**排第 10**（中国厂商中位列光迅、华工正源、索尔思之后）。**本轮无份额更新证据【缺】，沿用旧档口径。**
- **对照**：中际旭创 2025 年光模块收入 53.33 亿美元（份额 28%–30%）、新易盛 35 亿美元（15%–18%）——**规模差 15–20 倍**。
- **1.6T 环节**：由中际旭创约 80% + 新易盛约 20% 瓜分【软-媒体估算，本轮无更新、无第三方证实】。剑桥截至 2026-09 仍是"**预计今年下半年量产**"（见 [thesis.md §7.2](thesis.md) 的滑期链）。

**跑道长度的双面判定**：
- **正面**：1% 的渗透率意味着理论跑道极长，且**产能而非需求是近期约束**——350 万支满负荷（2026-05-18 调研）+ 在建工程较 2025 年末 **+106.8% 至 9.47 亿** + 目标年内 ≥600 万只（**【软-待核】，未在公司公告或投资者关系记录中核到出处**），三方互证，与终端 8,300 亿美元 capex 相印证。
- **反面（必须前置）**：**1% 份额的跑道，走法是从旭创/新易盛/Coherent 手里抢，不是顺势渗透**。在 1.6T 这个 CR2 近乎垄断的环节，这是自上而下的攻坚。且**"产能是约束"这句话的有效期，就是份额窗口的有效期**——一线厂扩产完成，窗口就收窄（详见 [thesis.md §8.5](thesis.md)）。**跑道长 ≠ 能走。**

### 2.3 宽带 ODM / 无线侧的跑道：基本没有

2025 年电信宽带 ODM 营收 **19.92 亿（占 41.31%）、同比 −1.98%**；无线网络与边缘计算 **11.54 亿（占 23.92%）、+2.51%**。**这两块合计 65.2% 的收入在 2025 年的合计增长约等于零。** 公司整体 32.07% 的营收增长几乎全部由光模块贡献。**2026H1 无分业务披露【缺】，无法更新。**

### 3.2 增长拆量价与增长质量

**量价拆解：无法完成，如实标注。** 公司从未披露光模块出货支数与 ASP【缺】，2026H1 亦无分产品量价，因此**不可判定**：H1 光模块收入增长中量/价各占多少、毛利率提升有多少来自 1.6T 结构切换、多少被 800G 降价抵消。唯一可用的是公司自述归因："订单增加 + 发货及时 + **产品结构切换**推动毛利率提升"——**明确未提价格上涨**【硬-公司口径】。据此判定为**量 + 结构驱动，非价格驱动**。

**本轮新增的唯一 ASP 量化**：2026-09-04 投资者关系记录，**800G 单价 300~380 美元、平均约 350 美元，且"年降幅度不大"**【硬-公司口径，**无独立佐证**】。与之相悖的产业调研口径见 [thesis.md §8.1](thesis.md)，两条并存不做二选一。

**增长质量的二分判定（正反必须并置）**：

- ✅ **损益表侧：增长伴随毛利改善为真。** 综合毛利率 20.99%（2024）→ 22.31%（2025）→ 29.33%（26Q1）→ **30.77%（26H1）**，**Q2 单季约 32.0%**。这不是烧钱铺量。
- ❌ **现金流侧：增长质量被证伪，且比旧档所知更严重。** 经营现金流**连续第 6 个季度为负**（断点在 2024Q4 的 **+1.57 亿**）；2026H1 **−11.13 亿**（2025 全年 −4.71 亿的 2.4 倍），**Q2 单季 −8.94 亿为公司历史最差**。三年累计现金转化率 **−103%**（旧档口径 +44.6%），远低于 buffett 框架 >90% 的门槛。详见 [thesis.md §6.2](thesis.md)。

> **⚠️ 增速本身也在放缓**：2026Q2 营收同比约 **+24.3%**，较 Q1 的 **+43.98% 接近腰斩**。**利润增速远高于收入增速，弹性来源是毛利率/结构而非规模——而规模本身已在减速。** 这是本轮"未被叙事覆盖"的一条新事实。

4. **可比经营性口径（回加汇兑、扣少数股东补贴、扣其他收益、按 15% 正常化税率）≈ 3.88 亿 / 净利率 14.3%**【推算，非公司披露】。仍高于公司历史最高年度净利率（4.65%，2015 年），但已落回毛利率约束之内。**这是 [valuation.md §9](valuation.md) 正常化的起点。**

### 3.5 owner earnings 估算

```
Owner Earnings = 净利润 + D&A − 维持性 capex − 营运资本增加
```
2026H1：归母 3.28 亿，而经营现金流（已含 D&A 与营运资本变动）为 **−11.13 亿**，再扣 capex 6.85 亿 → **2026H1 真实 owner earnings 为大幅负值**。2025 全年同样为负（经营现金流 −4.7065 亿）。

|---|---|---|
| 净利润 | +2.74 亿 | +2.23 亿 |
| 固定资产折旧 | +1.07 亿 | +1.48 亿 |
| 无形资产 + 长期待摊摊销 | +0.75 亿 | +1.37 亿 |
| **存货的减少**（负数＝存货增加占用） | **−8.21 亿** | −7.32 亿 |
| **经营性应收项目的减少**（负数＝应收增加占用） | **−14.16 亿** | −9.87 亿 |
| **经营性应付项目的增加** | **+4.56 亿** | +5.72 亿 |
| **营运资本净吞噬（三项合计）** | **−17.81 亿** | −11.47 亿 |
| **经营活动现金流量净额** | **−11.13 亿** | −4.71 亿 |

**三条结论**：

1. **−11.13 亿全部由营运资本造成**——净吞噬 17.81 亿，被净利润 + 折旧摊销的 4.56 亿部分抵回。**不是利润造假，是利润没有变成现金。**
2. **最大单一吞噬项是经营性应收 −14.16 亿，超过存货侧的 −8.21 亿**。而应收账款账面仅增 6.21 亿（19.98 → 26.19 亿），差额主要来自**预付款项由 1.69 亿激增至 5.58 亿（+3.89 亿）**——**公司在向上游大额预付**，与"H 股募资约 80% 用于核心元器件备货"的口径一致。应付侧仅增 4.56 亿（应付账款 17.80 → 24.12 亿），**未能对冲**。
3. **直接法互证**：销售商品收到现金 **29.11 亿** vs 购买商品支付现金 **39.23 亿**，单这一对差额即 **−10.12 亿** ✅；间接法 −11.13 亿 ＝ 直接法 −11.13 亿 ＝ 每股经营现金流 −3.02 元 × 368,250,373 股，**三向自洽**。

> **必须显式并置的一处对比**：**本期新增押在元器件上的现金 ＝ 预付款项增加 3.89 亿 + 存货占用 8.21 亿 ＝ 12.10 亿，而 2026H1 资产减值损失只计提了 311.98 万元** —— **押注是计提的 388 倍**。若把存量也算上，预付余额 5.58 亿 + 存货余额 31.97 亿 ＝ 37.55 亿敞口对应同一笔 312 万计提。**敞口在扩大，计提尚未发生**（[index.md §11 风险 2](index.md)）。
>
> **这意味着**：本轮失血不是一次性的时点错配，而是「**营收 +32.92% 需要营运资本 +17.81 亿去支撑**」的结构。增速越快，失血越多。

**→ 直接后果**：不能把报告净利当 owner earnings 用。[valuation.md §9.2](valuation.md) 对三档正常化扣非归母统一施加现金转化系数（**0.45 / 0.60 / 0.80**，较旧档全面下调），并在 §9.6 给"不打折"敏感性对照。
