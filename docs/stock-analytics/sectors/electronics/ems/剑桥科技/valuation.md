## 9.2 正常化 owner earnings 的构造（三步）

**第一步：正常化扣非归母 —— 必须从可比经营性口径起步，不得用 3.28 亿归母外推全年。**

2026H1 报表归母 3.28 亿里有 **约 1.32 亿（占 40%）来自三项非可持续来源**（拆解见 [business.md §3](business.md)）：

| 项目 | 金额 | 性质 |
|---|---|---|
| 少数股东损益 **−5,380.92 万** 补贴归母 | +0.54 亿 | 归母 3.28 亿 > 合并净利 2.74 亿，差额全部由少数股东承担亏损 |
| **有效税率 0.19%**（所得税仅 52.72 万） | +0.41 亿 | 税率正常化至 15% 即减少归母约 0.41 亿 |
| 其他收益（政府补助等）4,692 万 | +0.37 亿 | 同比多贡献 0.37 亿 |
| **合计** | **≈ 1.32 亿 ＝ H1 归母的 40%** | **三项均非可持续经营性来源** |

反方向的一项：H1 财务费用 1.99 亿（2025H1 仅 0.073 亿），含**汇兑损失约 2.02 亿**（预告口径，与结构化财务费用净增 1.92 亿勾稽闭合）。**但汇兑不予剔除**——它是公司自选资本结构（募资以港元留存）造成的，真实计入归母、真实进入 PE 分母，且敞口在扩大，不是可随手回加的一次性项。

> **A1 的可比经营性口径（本档正常化的起点）**：回加汇兑、扣少数股东补贴、扣其他收益、按 15% 正常化税率 → **2026H1 约 3.88 亿 / 净利率 14.3%**【推算，非公司披露】。全年 run-rate 约 7.8 亿，**这是本轮景气 + 一次性毛利率台阶的顶部区域**。**bear 4.0 亿与 base 6.5 亿均低于它，符合"不取顶部年化"；bull 10.0 亿高于它 28%，其可容许性单独论证见 [thesis.md §8.3](thesis.md)——bull 不是"把 2026 的顶部利润率外推"，而是"利润率自尖顶回落、但收入规模跨一个台阶"。**

**第二步：现金转化系数 —— 本轮必须下调。**

| 口径 | 旧档 | **本轮** |
|---|---|---|
| 三年累计现金转化率 | 2023–2025 累计经营现金流 +2.34 亿 ÷ 累计归母 5.25 亿 = **+44.6%** | 2023–2026H1 累计经营现金流 **−8.80 亿** ÷ 累计归母 **8.53 亿** = **−103%** |
| 系数 | 0.55 / 0.70 / 0.85 | **0.45 / 0.60 / 0.80** |

依据：2026H1 经营现金流 **−11.13 亿**（2025H1 −1.90 亿，恶化 9.23 亿），**Q2 单季 −8.94 亿为公司历史最差单季**，**连续第 6 个季度为负**（断点在 2024Q4 的 **+1.57 亿**）。A1 已做季节性偏置校验（同口径 H1 序列 2024 +3.30 / 2025 −1.90 / **2026 −11.13** 亿），证明不是日历效应。构成拆解见 [business.md §3.5](business.md)：**−11.13 亿全部由营运资本造成**（净吞噬 17.81 亿），其中**经营性应收占用 −14.16 亿是最大单项**，且**预付 + 存货合计 12.10 亿现金已押在元器件上，而 H1 资产减值损失仅计提 311.98 万元**。**报告净利与可分配现金之间的裂口比旧档所设的任何情景都大，且这不是一次性时点错配而是"营收 +32.92% 需要营运资本 +17.81 亿去支撑"的结构——系数必须跟着下调。**

**第三步：SOTP 分部倍数 —— 不得整体套光模块可比 PE。**

这是本股最容易犯的估值错误。**65.1% 的营收来自毛利率约 15.8% 的代工资产**——**该值为 2025 年报分部数据加权推算**：(19.92×14.01% + 11.54×19.00%) ÷ 31.46 = **15.84%**（与整体反推 (48.23×22.31% − 16.75×34.49%) ÷ 31.48 ≈ 15.8% 互证）。**2026H1 公司未披露分部数据，此值不得写成 2026H1 口径。**客户主导设计、无自有 IP、年降为惯例、汇率敞口大——属应给 **10–12 倍 PE** 的制造代工资产，与光模块业务不可同倍数估值。故三情景**均按两部分分别定倍数后加总**。

| | **A 部 · EMS/ODM 代工基本盘** | **B 部 · 高速光模块** |
|---|---|---|
| 正常化收入锚 | 约 32 亿（2025 年 31.46 亿，近三年增速 ≈ 0：宽带 −1.98% / 无线 +2.51%） | 2025 年 16.75 亿；2026H1 【缺】未披露，A2 推算约 12 亿 /【软】 |
| 正常化净利率 | 2.8%（对应毛利率 15.84% 的代工口径，**2025 年报分部加权**） | 按分部盈利能力，随情景变化 |
| 正常化扣非归母 | 0.90 亿（三档不变——**这块业务本就没有情景弹性**） | bear 3.10 / base 5.60 / bull 9.10 亿 |
| 倍数 | bear 8× / base **10×** / bull 12× | bear 10× / base **15×** / bull 21× |

**倍数自我约束校验**：以 base 正常化扣非合计 6.50 亿计，H 股单边口径 forward PE = 381.01/6.50 = **58.6×**、真实 A+H 口径 = 708.51/6.50 = **109.0×**；三档分部倍数（8~21×）**全部远低于两者**，也远低于隐含 PE_TTM（H 股 81.0 / A 股 174.05）。倍数框架依据 [business.md §5](business.md) 的"窄护城河 8–12×"，B 部 base 给到 15× 已是对结构升级的额外让步。

## 9.4 赋权理由（每档挂证据，并说明为何相对旧档调整）

**旧档为 bear 40% / base 40% / bull 20%。本轮调整为 45% / 38% / 17%，三条理由，每条都是本轮新增的硬事实：**

1. **现金流恶化的量级超出旧档任何情景**（→ bear +5pct）。旧档 bear 只预期"经营现金流持续为负"，实际 H1 烧掉 **11.13 亿 ＝ 2025 全年 −4.71 亿的 2.4 倍**，Q2 单季 −8.94 亿为历史最差；三年累计现金转化率由 +44.6% 翻转为 **−103%**。这不是"增长期的正常营运资本占用"，是**利润与现金的方向性背离**。
2. **收入增速已在放缓**（→ base −2pct）。2026Q2 营收 14.18 亿、同比 **+24.3%**，较 Q1 的 **+43.98% 接近腰斩**（A2 推算，与 A1 营收硬数一致）。base 情景赖以成立的"光模块占比持续爬升"仍在，但**爬升的速度证据在变弱**。
3. **1.6T 时间表第三次改口，已构成一次公开失约**（→ bull −3pct）。2025-11-13「预计 2026Q1 大量发货」→ 2026-03/05「小批量供货、无时间表」→ 2026-09-04「预计今年下半年量产」，**约 3 个季度失约**，公司自述原因是核心硅光引擎交付延迟（详见 [thesis.md §7.2](thesis.md)）。**bull 的核心假设正是这条路线图，路线图已 miss 过一次，赋权必须计提失约折扣。**

**bear 45%**：挂 [thesis.md §6.3](thesis.md)（管理层自设 2026–2028 累计 12.21 亿，H1 已完成全年目标 97.9%，隐含 2027–2028 相对 2026 不增长）、[business.md §3.3](business.md)（上市后 9 年加权 ROE 从未破 10%，2026H1 加权 4.32% / 摊薄 3.50% **同比双双下降**）、[thesis.md §8.2](thesis.md)（2026 年 7 月一个月内已实际发生过 −50.4% / H 股 −61.4%）。**这不是尾部情景，是公司自己签字的路径。**

**base 38%**：挂 [thesis.md §7.1](thesis.md)（AI 兑现为真且管理层在法定公告中直接归因）、[business.md §3](business.md)（毛利率 22.01%→30.77%、Q2 单季约 32.0% 为报表级硬证据）、[business.md §2](business.md)（终端兑底强：九大 CSP 2026 capex 约 8,300 亿美元 /+79%）。正常化 6.50 亿介于 2026 可比经营性全年 run-rate（约 7.8 亿）与 2025 实际扣非（2.59 亿）之间，**符合"不取顶部年化"**。

**bull 17%（已按成长证据包门控封顶）**：

| 门控要素 | 本轮判级 | 依据（相对旧档的变化） |
|---|---|---|
| (a) 扩产达产确定性 | **【软】**（旧档【软/近乎全空】，本轮**略有改善**） | capex 金额首次转硬：H1 购建固定资产等支付现金 **6.85 亿（+110% yoy）**、在建工程 9.47 亿（半年 +107%）；产能目标首次量化：350 万支满负荷 → **年内力争 ≥600 万只**（2026-08-25 业绩说明会转述，**本轮未在公司公告或投资者关系记录中核到出处 →【软-待核】**）。**但分项目投向、达产爬坡曲线、"新增 X 万支对应 Y 亿营收"口径仍全【缺】。** |

## 9.5 资产法交叉验证（RIM，防"倍数破框架"坑）

> **【自设参数声明】**：股权成本 `Ke = 11%` 与永续增长率 `g`（bear 1.5% / base 3.0% / bull 4.0%）**均为本档自设**，三份采证 evidence 中没有任何股权成本或永续增长率的公开口径，**不属【硬】或【软】证据**。该组参数**仅用于对 §9.3 做交叉验证，不进入官方加权计算**。

调整后净资产：93.32 亿（已扣中期分红）− 商誉 0.99 亿 − 存货减值假设 15%（31.97×15% = 4.80 亿）− 应收追加坏账 10%（26.19×10% = 2.62 亿）= **约 84.91 亿**。

| 情景 | 隐含 ROE | g | RIM 公允 PB | 资产法内在价值 | 利润法内在价值 | **本档取值** |
|---|---|---|---|---|---|---|
| bear | 4.00 / 84.91 = **4.71%** | 1.5% | 0.34 | **28.7 亿** | 17.2 亿 | **23.0 亿**（两法收敛中值） |
| base | 6.50 / 93.32 = **6.97%** | 3.0% | 0.50 | 46.3 亿 | **55.8 亿** | **55.8 亿**（利润法，比资产法宽容 21%） |
| bull | 10.00 / 93.32 = **10.72%** | 4.0% | 0.96 | 89.6 亿 | **161.5 亿** | **161.5 亿**（利润法，比资产法宽容 80%） |

三条结论：
1. **bear 档两法方向相反且量级接近**（利润法 17.2 / 资产法 28.7），互为上下界，取中值 23.0 亿而非任一单法。
2. **base 与 bull 均由利润法给出且高于资产法** → **不存在"倍数被迫破框架"的坑**（症状是 bull < base，或某档只有抬倍数才凑得出数字）。三档单调递增，B 部最高倍数 21× 仍在成长股框架内。本档的 base/bull 是对多头的**让步**而非苛刻。
3. **净现金仍不作 bear 的硬底**：H1 末货币资金 34.44 亿，高于 bear 的 23.0 亿。但该现金**不可分配**——招股书明确约 80% 用于核心元器件备货，H1 已实际烧掉 11.13 亿经营现金 + 6.85 亿 capex，且以港元持有、半年产生 2.02 亿汇兑损失，是**负 carry 资产**；**2026-07-24 又拿 8 亿去做 7 年期非上市股权投资**（见 [thesis.md §6.4](thesis.md)）。在 bear 世界里它会被转化为需要减值的存货，而非可返还股东的现金。
