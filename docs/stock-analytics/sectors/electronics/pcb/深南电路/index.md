结构升级仍有硬兑现：**H1**封装基板36.67亿、营收占比23.97%、毛利31.35%、贡献毛利增量44.4%，维持历史事实；Q3未披露分部毛利/收入，不能用综合毛利替代PCB34%或载板26%阈值。公司IR确认AI加速卡、服务器、交换机、光模块需求及产品结构、基地爬坡改善。H1数据中心PCB收入突破20亿约为总营收下限13.1%，不是总AI占比上限或在手订单；应收分布不能证明没有大客户。FC-BGA已具备26层及以下批量生产能力，实际24–26层出货/验收/收入仍缺。
