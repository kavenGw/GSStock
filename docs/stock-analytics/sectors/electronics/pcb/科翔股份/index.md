## §0 结论摘要

**评级：exclude（首建档即排除，不进 watch）。**

**期望内在价值 20.46 亿元（4.70 元/股），对实时市值 401.99 亿元，安全边际 −94.9%。**
**买点 3.51 元**（base 的 30% 折价，距现价 −96.2%）——实操上等价于**不设买点**。

三情景（资产法主锚，PB 阶梯；详细推导见 [§9](valuation.md)）：

| 情景 | 内在价值 | 每股 | 隐含 PB | 概率 | 一句话 |
|---|---|---|---|---|---|
| bear | 13.0 亿 | **2.99 元** | 0.72x | **40%** | CCL 涨价在 26Q3 兑现挤压、主业毛利率仍为负，全年再亏 1.5–2.0 亿，净资产缩至约 16.3 亿，市场按 0.8x 破净给价 |
| base | 21.8 亿 | **5.01 元** | 1.20x | **45%** | 主业在 2027–2028 前后勉强过盈亏平衡线，正常化 ROE 仍显著低于 12% 股权成本，公允 PB 只能在 1x 附近小幅上浮 |
| bull | 36.3 亿 | **8.34 元** | 2.00x | **15%** | 高阶 HDI 工艺磨合收敛 + 陶瓷基板真导入 AI 服务器，净利率回到上市前后 4.10% 水平（对应正常化归母 1.66 亿），给成长溢价 22x |

Σ概率 = 40% + 45% + 15% = **100%** ✓
期望值自检：2.99×0.40 + 5.01×0.45 + 8.34×0.15 = 1.196 + 2.255 + 1.251 = **4.702 ≈ 4.70 元/股** ✓
总额口径：13.0×0.40 + 21.8×0.45 + 36.3×0.15 = 5.20 + 9.81 + 5.45 = **20.46 亿** ✓

**为什么不是利润法**：TTM 归母 −2.51 亿（= 2025 全年 −2.4633 + 26H1 −0.6638 − 25H1 −0.6203），
PE-TTM = −160.4（与腾讯字段 −160.36 交叉一致），静态 / H1 年化 PE 同为负 —— **PE 在任何口径下无定义**。
改用正常化利润法试算：上市以来 2016–2022 七年（唯一连续盈利段）合计归母 4.552 亿 / 合计营收 110.93 亿 =
**正常化净利率 4.10%**，套 TTM 营收 40.43 亿 → 正常化归母 **1.66 亿**；给 buffett 框架内窄护城河下沿 12x
（科翔实为 no moat，12x 已是宽容）→ **19.9 亿**，**低于资产法 base 的 21.8 亿** —— 即出现规格 §3 描述的
「bull 降回框架内倍数后 bull < base」症状，判定**利润法整体失效**，三档改以资产法为主锚、利润法作验证。
准入判据两条均成立：① bull 36.3 亿 < 现价 401.99 亿；② 归母净资产 18.13 亿是重资产 PCB 制造商的真实托底
（固定资产 26.43 亿 + 在建工程 2.66 亿），**不适用「轻资产软件股不套 RIM 铁律」的例外**。

**三情景概率一句话赋权理由**（证据见 [§6](thesis.md)/[§8](thesis.md)）：
- **bear 40%**：空 1（主业毛利率 −1.39%）与空 5（估值脱锚）均为【硬】证实；空 3（CCL 挤压）虽未决但方向已由两家子公司的
  「成本涨幅高于售价涨幅」「传导存在时间差」原文坐实，26Q3 是裁决点。给最高单项权重。
- **base 45%**：多 4（Q2 单季亏损环比收窄 72%）与多 2（工艺平台确有硬指标）成立，收入连续 10 年增长（2016–2025 CAGR 16.5%），
  公司不会消失；但扭亏无时间表，故 base 只承认「过盈亏平衡」，不承认盈利能力回归。
- **bull 15%**：成长证据包三要素 —— 扩产达产确定性【软】（进度 2.12%、2027-07-31 才可用）、
  客户 capex 能见度【**缺**】（无具名 AI 客户、无锁定订单、合同负债仅 1,210 万占总资产 0.17%）、
  TAM 跑道【硬】（服务器 PCB 2024–2029 CAGR 11.6%，Prismark）但**自身渗透率无数据【缺】**。
  按门控「三项全软 → ≤20%」，本例有一项为【缺】比全软更弱，**封顶 20% 后取 15%**。

### 10.2 反向解：现价需要什么条件才成立

按框架上沿 20x 倒推，现价 401.99 亿隐含**正常化归母 20.1 亿**，相当于 TTM 营收 40.43 亿的
**49.7% 净利率** —— PCB 行业最优秀公司的净利率量级是 15–20%，49.7% 不是「乐观」而是**不可能**。

**极限压力测试**（给科翔行业最优的假设，全部按对多头最有利取值）：假设主业毛利率一步到位修到沪电级别、
净利率给行业最优 20%，TTM 营收 40.43 亿 → 归母 8.09 亿，配框架上沿 20x → **161.7 亿**，
**仍比现价低 59.8%**。即：**即使把科翔当成沪电来估，现价也贵六成**。这条不进三档加权，只作现价的证伪测试。

### 10.3 为什么是 exclude 而不是 watch

同 subsector 已建档兄弟的位次（口径见 [related.md](related.md)）：

| 标的 | 盈利 | PE-TTM | 主业毛利率 | 安全边际 | 评级 |

| 生益电子 688183 | 是 | 47.31 | 25% 量级 | −68% | watch |
| 一博科技 | 是 | — | — | −62.5% | watch |
| **科翔股份 300903** | **否（连亏 3.5 年）** | **无定义** | **−1.39%** | **−94.9%** | **exclude** |

三只兄弟档是「**盈利但贵**」，科翔是「**亏损且更贵**」——**低一个质地层级、高一个估值层级**。

落点只能是 **exclude**。沿用一博科技档的板块收口句式：**三档中最乐观的一档（36.3 亿）都撑不起今天 401.99 亿的价**。

## §11 关键风险 Top 5 + 监控指标 / 卖出触发器

> 论证过程见 [§6 核心新论点](thesis.md) 与 [§3 盈利能力](business.md)，此处只列结论与硬阈值。
> 首建档，无旧档触发器可复盘。

### 风险 1｜主业 PCB 制造毛利率为负，且整体毛利率是结构性错觉【最高优先级】

26H1 分产品：PCB 制造收入 19.06 亿 / 成本 19.32 亿 → 毛利率 **−1.39%**（毛亏 2,640 万）；
「其他业务」收入 2.23 亿 / 成本 878 万 → 毛利率 **96.06%**（毛利 2.14 亿）。
勾稽自洽：−0.2640 + 2.1433 = 1.8793 亿 = 整体毛利 ✓，整体毛利率 8.83%。
**即其他业务贡献了 114% 的毛利，主业倒贴 14%。**

**两口径矛盾必须并列披露**：分地区口径（内销 19.80 亿 / 毛利率 9.07%，外销 1.49 亿 / 5.67%）**隐含 PCB 正毛利**，
与分产品口径的 −1.39% 直接冲突。**公司未对两表做任何勾稽说明**。本档采分产品口径（附注 38 独立交叉验证：
主营收入 19.082 亿 / 成本 19.344 亿 → 主营毛利 −2,621 万），同时明示该矛盾存在。
且无论采哪个口径，期间费用（销售 0.33 + 管理 0.78 + 财务 0.33 + 研发 1.11 = **2.55 亿**）> 整体毛利 **1.88 亿**，
主业不盈利的结论不变。

**「其他业务」2.23 亿的构成，半年报全文只字未提**（附注 38 的「市场或客户类型 / 合同类型 / 销售渠道」分类行全部空白）；
上年同期同样存在（1.70 亿收入、成本 489 万、毛利率 97.1%）故非一次性事项，但**性质、可持续性、是否涉关联方均未获证【缺】**。
这是本档**首要存疑项**。

- **监控**：定期报告「PCB 制造」分产品毛利率。**2026 年报若仍 < 0%** → 转型证伪；连续 3 个报告期 < 0% → 结构性缺陷坐实。转正确认阈值 **> 3%**。
- **监控**：主营毛利 / 合并毛利之比（当前 **−14%**）。2026 年报若仍 < 30% → 盈利质量证伪。
- **监控**：「其他业务收入」若继续 > 营收 10% 且仍不披露构成 → 视为披露质量缺陷，估值额外折价。

### 风险 2｜CCL / 铜箔 / 玻纤涨价的挤压尚未在报表兑现——26Q3 单季毛利率是裁决点【唯一未决论点】

上游：建滔积层板 2025-02 起本轮涨价，年内 7 次涨价函、6/16 单轮 +15%、全年累计超 50%；花旗研报指
**8 月 CCL 含税现货价或再上调 10%–15%**【软】。电子布 8 月三大系列均价环比 +17%~18%、年内累计 +118%~165%。
> **口径纠正**：坊间「9 月 CCL 再涨 5–10%」**无一手证据【缺】**，本档不引用，按花旗口径的 8 月 10–15% 写。

已发生的传导实证【硬】：江西科翔自述「成本涨幅高于售价涨幅」；智恩电子自述「成本向客户端的传导存在时间差，
当期售价未能充分覆盖成本增幅」；唯一传导成功的赣州科翔靠「**前期备料缓冲**」——一次性库存红利，不可持续。
公司称已「与 CCL 等上游厂商建立稳定的价格联动机制」，但从子公司实际毛利表现看该机制未抵消成本冲击。

**本档不提前定性**：26Q3 单季毛利率是裁决点。若 26Q3 分产品 PCB 毛利率仍为负或环比走弱，则「主业负毛利」+
「涨价挤压」联合成立，bear 概率应上调。

- **监控**：建滔涨价函频次/幅度 vs 科翔单季 PCB 分部毛利率。上游继续涨而科翔分部毛利率不升 → 定价权缺失坐实（当前已是此状态）。
- **监控**：存货跌价准备计提（当前 1,611 万，+72.38%）连续两期增长 → 结构性呆滞而非周期性。

### 风险 3｜偿债与流动性：营运资金 −9.16 亿，货币资金覆盖不了短期有息负债

| 指标 | 值 |
|---|---|
| 流动比率 / 速动比率 | **0.810 / 0.663** |
| 营运资金 | **−9.16 亿元** |
| 资产负债率 | **75.05%**（负债 54.79 亿 / 总资产 73.00 亿） |
| 货币资金 / 短期有息负债 | 9.471 / 16.354 = **0.579**；**扣受限后 0.475** |
| 净有息负债 | **8.89 亿**（有息负债 18.36 亿，未计构成未披露的长期应付款 2.25 亿） |
| 受限资产 | **10.10 亿**，含固定资产 6.906 亿抵质押、货币资金 1.696 亿、应收 0.730 亿；另**赣州科翔一厂土地房产 2,311 万元涉诉查封冻结** |
| 自由现金流（26H1） | **−0.671 亿**（经营 0.949 − capex 1.620） |

**不得用「H1 经营现金流为正」论证造血能力**：Q1 系统性为负（2024/2025/2026 Q1 每股经营现金流 −0.331/−0.032/−0.133），
H1 转正是营运资金季节性；且 26H1 的 0.949 亿**同比 −19.12%**，在收入 +17.88% 时反向走弱。
H1 现金净增 4.08 亿**全部来自筹资**（定增 2.77 亿 + 借款净增），经营端不能覆盖 capex。
