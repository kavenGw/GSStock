**其他方法论局限**：
1. **PB 历史分位为推算值【软】**：由 BPS 序列 + 前复权股价序列推得历史区间约 1.5–3.5x，
   非第三方直接披露口径；但「当前 22.17x 为上市以来最高」这一**定性**结论在任何合理口径下都成立
   （当前约为历史区间上沿的 6–8 倍）。
2. **2016–2022 年度数据为【软·第三方数据库】**（东方财富 RPT_LICO_FN_CPD），
   仅 2025 全年与 2026H1 经公告原文独立核对。§3.3 的十年序列据此，结论（毛利率与 ROE 单调下滑）
   在量级上稳健，个别年份小数位可能有出入。
3. **26Q2 单季为 H1 减 Q1 推算**（Q1 数经异动公告 2026-048 原文复述确认），非公司直接披露。
4. **资产法主锚的固有局限**：PB 阶梯给出的是**清算/重置视角的下界**，不是持续经营价值；
   若公司主业在 2027 后真正扭亏并进入正 ROE 通道，资产法会系统性低估。
   本档已通过 bull 档（PB 2.00x / 隐含 ROE 9.2%，且与利润法 36.5 亿收敛）为此留出空间。
