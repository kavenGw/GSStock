## 12.6 已知局限【缺】——未找到公开证据，不得编造

| 缺失项 | 对结论的影响 |
|---|---|
| **AI 服务器 / 算力 PCB 的独立营收金额与占比** | 无法量化 AI 敞口 → **bull 概率封顶 25% 的第一理由**；26H1 中报 `AI服务器`/`算力` 共 24 次全为定性无金额 |
| **英伟达 GB300 的公司具名证实或否认** | 维持【蹭概念】，零权重期权；公司在异动公告中的「不涉及热点概念事项」是**隐性否认**而非具名否认 |
| **26H1 前五大客户销售额与具名客户** | 半年报不强制披露；只能用应收口径 50.18% 代理，无法评估单一客户砍单杀伤 |
| **方正在高端 HDI / AI PCB 的全球或国内份额** | **无法计算渗透率 → 跑道长度不可测**，bull 无法用「天花板还有多远」赋权 |
| **是否具备 78 层 M9 级正交背板能力** | 无法判断能否分享 Rubin 价值量增量 → 只能做「赛道错配·双向中性」处理 |
| **珠海基地试产/达产时间表的公司公告口径** | 仅有媒体时间表，达产节奏不可锁定 |
| **泰国基地单独营收/产能口径** | 海外营收 +147.6% 无法归因到泰国具体贡献 |
| **2026 全年业绩指引** | 公司未给 → 全年归母只能给区间 6.4~15.7 亿 |
| **销量与 ASP 的具体拆分** | 只能从「营收 +72.89% 伴随毛利率 +10.29pct」间接判断量价齐升 |
| **毛利改善中自身 alpha 与行业 β 的拆分** | 公司未拆分 → 护城河判定只能维持「弱」 |
| **订单周期（旧档「1–3 月」）的最新公司口径** | 在手订单能见度只能定为【软·终端兑底】 |
| **券商正式研报覆盖与目标价** | 检索无卖方首次覆盖 → 无第三方估值锚可交叉 |
| **6 月以来主力资金流向的权威延续数据** | 无法更新旧档「主力净流出」判断 |
| **PE/PB 历史分位失真** | 序列含 2019–2022 巨亏年份，PE 出现负值与极端值，中位数与分位数失真；**仅 PB 分位 93.8% 相对可信**，故本档以 PB 绝对值对标同业而非依赖历史分位 |
