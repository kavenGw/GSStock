## 0. 结论摘要

**评级：`watch`（维持，未翻转）。期望内在价值 201.41 亿元 / 每股 4.71 元；对 619.27 亿市值安全边际 −67.5%。当前价不可买。**

**旧档 → 本轮**：期望内在价值 123 亿 → **201.41 亿（+64%）**，每股 2.87 → **4.71 元**，安全边际 −78% → **−67.5%**。**数字全面上修，方向未变**：业绩真兑现让张力大幅缓解，但**没有反转结论**。

**三情景各一句**（详见 [valuation.md](valuation.md) §9.2；三档正常化利润全部低于顶部年化，Σ概率 = 100%）：

| 情景 | 一句话 | 正常化归母 × 倍数 | 内在价值 / 每股 | 概率 |
|---|---|---|---|---|
| **Bear** | 高端占比提升停滞 → CCL 成本传导失效，2026H2–2027 行业产能集中释放价格战，二线高端良率 miss，毛利回落至 26–27% | 7.0 亿 × 15x | **105 亿 / 2.46 元** | **33%** |
| **Base** | 珠海爬坡兑现、重庆/泰国部分投产，毛利中枢回吐至 28–30%，AI 归因仍不可独立验证 | 11.0 亿 × 20x | **220 亿 / 5.15 元** | **42%** |
| **Bull** | 行业缺口延续至 2027 + 高端占比继续提升 + 三基地按计划爬坡三条同时成立的**好年景**（**GB300 零权重，不入基数**），再计 12% 现金含量折价 | 13.0 亿 × 26x − 12% | **297.44 亿 / 6.96 元** | **25%** |

**一句话论点**：这是 A 股 PCB 里少见的**真实困境反转**——26H1 扣非 5.5644 亿占归母 97.0%、毛利率六季从 21.91% 单调爬到 26Q2 的 33.48%、境外占比 25.2%→36.12% 且境外毛利率高 6.12pct，旧档三条空头论点（5 年营收零增长 / 毛利仅 1 季顶部 / 毛利落后沪电 6.5pct）被结论性推翻；**但市场为它付的价格（PB 11.80、分位 93.8%）把周期景气窗口里的定价权当成了永久能力**，而护城河证据仍全缺、AI 营收 0 披露、GB300 已触发证伪分支、26Q2 单季现金含量塌陷至 0.13x、扩产靠债务使自由现金流连续两个半年度为负。**尊重这家公司，和愿意在这个价格上买它，是两码事。**

**三条最不能忽略的新事实**（旧档全未覆盖）：
1. **H1 累计 OCF/归母 0.89x 与 26Q2 单季 ≈0.13x 同时为真**——后者被前者掩盖，是本轮最强反证（[thesis.md](thesis.md) §6.2）。
2. **董事长与法定代表人当前空缺**，陈宏良两个月内分两步交出总裁与全部董事职务，新总裁郑雷为财务/投行背景、非 PCB 技术出身（[thesis.md](thesis.md) §6.7）。
3. **26H1 自由现金流 −6.01 亿**（25H1 −5.17 亿，**同口径同比恶化，非季节性**），有息负债 24.77 亿、资产负债率 53.59%（[thesis.md](thesis.md) §6.3）。

## 10. 评级决策

### 10.1 期望内在价值 vs 实时市值

| 项 | 值 |
|---|---|
| 期望内在价值 | **201.41 亿元 / 每股 4.71 元** |
| 实时市值（盘中锚） | **619.27 亿元 / 14.49 元** |
| **安全边际** | **−67.5%** |
| 对应 PB / PE（TTM） / PS（TTM） | 期望值 **3.84x / 23.1x / 3.13x** vs 现价 **11.80 / 70.92 / 9.63** |
| bull 全兑现（297.44 亿）对现价 | **−52.0%**（不计折价的 338 亿仍 −45.4%） |
| 框架内下界压力测试 | 103.68 亿 / 2.43 元 / −83.3% |

> **决定性判断：bull 全兑现也不足以支撑当前市值。** 旧档此结论下 bull 仅为市值的 43%，本轮基数整体上修后升至 **48.0%**——张力有所缓解，**但未反转**。这是评级维持 `watch` 而非上调的核心算术。

### 10.2 评级：`watch`（相对旧档**未翻转**）

**为什么不是 `exclude`**：基本面是真的。毛利率六季单调、扣非占比 97.0%、26Q2 单季归母 3.4194 亿、境外结构升级、无商誉、重整后表内干净、公司在股价异动时主动泼冷水自曝 PE/PB——**没有任何诚信否决项**，也没有触发旧档的「彻底规避」条件。这家公司值得继续跟踪。

**为什么不是 `config`/`core`**：安全边际 −67.5%，且要求的确定性折扣本就应在 **40–50% 档**（存在不确定性因素：护城河无证据、AI 归因不可验证、治理空窗、负 FCF）。买入需要的不是「便宜一点」，而是价格腰斩再腰斩。

**诚实面对「贵」（红线 4）**：本档**未用「护城河上修」或「AI 想象空间」稀释价格问题**——三档估值中 AI 成分只以「高端产能达产 + 海外结构」的已量化形式进入，未兑现概念权重为零；bull 概率上调的 3pct 完全由经营斜率解释。而现价 PB **11.80 高于公司自己 8-08 风险提示时列示的 11.27**，说明**AI 叙事的定价程度不降反升**。

### 10.3 买点 / 卖点阈值

**买点须用新净资产 52.4847 亿重算**（旧档 PB 2.7–3.3x 按当时约 48 亿计，对应 130–160 亿；同一 PB 区间在新净资产下已是 142–173 亿，沿用旧数会系统性偏低）。

| 档位 | 阈值 | 含义 |
|---|---|---|
| **重估观察区**（启动深度复核，非买入） | 市值 ≤ **180 亿**（每股 **4.21 元**，PB 3.43x）**且** 26Q3 单季 OCF/归母 ≥ 0.5x | 回到期望内在价值 89% 以下且现金含量红线解除，才值得重开估值 |
| **买入区（40% 安全边际）** | 市值 ≤ **120.85 亿**（每股 **2.83 元**，PB 2.30x） | 对应「存在不确定性因素」档的 40% 折扣。**需现价再跌约 80%——实务上等同于本轮不可买** |
| **上调评级的替代路径**（不靠跌价） | 见 §11 三条「重估触发器」全部满足 | 若基本面继续超预期兑现，内在价值上移也可缩小缺口 |

**卖点（若已持有）**：见 §11「卖出触发器」。**四条卖出准则逐项检查**：
1. **价格严重高估？** ✅ **是**——安全边际 −67.5%，PB 分位 93.8%，bull 全兑现仍 −52.0%。
2. **护城河根本性破坏？** ❌ 否——护城河本就弱（窄护城河下沿），但趋势在拓宽而非收窄。
3. **管理层诚信问题？** ❌ 否——无违规、无诉讼、主动做估值风险提示。**但治理连续性存疑**（董事长/法代空缺），列为观察项而非否决项。
4. **有明显更好的机会？** ✅ **是**——同板块沪电股份 PE-TTM 43.44x 且客户能见度具名可查、生益电子体量大 57% 而估值倍数更低，**在同一条 AI-PCB 链上有更便宜且更可验证的选择**。

### 概念风险（单列，不占 Top 5 名额）

**GB300 二值裁决已触发证伪分支**（双硬证：中报 `英伟达`/`GB300` 命中 0 次；2026-08-07 异动公告「不涉及热点概念事项」+ 控股股东函询）。**升级条件仅两类**：公司公告，或英伟达官方供应链确认。**自媒体/研报转述一律不升级。** 该概念在本档估值中**权重为零**，因此它证伪不会造成内在价值下修——但它若被市场进一步 price-in，会让安全边际继续恶化。

### 每季必查清单

1. **单季 OCF/归母**（一号红线，阈值 0.5x）与自由现金流是否仍为负；
2. **单季毛利率**是否守住（峰值参照 33.48%，证伪线 <22% 连续 2 季）+ **境外收入占比**（26H1 36.12%）是否同步；
3. **AI 服务器 / 高多层板营收是否首次独立披露**——**若 2026 年报仍不拆分 → bull 封顶下调**；
4. **前五大客户占比**（定增口径已 36.89%→51.92% 单边上升；应收口径 50.18%）是否继续上升而**仍不具名**；
5. **扩产进度**：珠海（已投 24.2%）/ 重庆（36.9%）/ 泰国（70.2%）达产率是否 miss，公司是否给出公告口径的时间表；
6. **CCL/铜箔/电子布价格**与公司提价节奏是否背离（毛利见顶前瞻信号）；反之价格见顶回落而方正未同步降价 → 短期利好、中期需求信号转弱；
7. **治理**：董事长/法代补选进度、新增辞任；
8. **定增**：2026-12-04 批文到期前是否发行。

### 卖出触发器（若已持有）

- 单季 OCF/归母**连续两季 <0.5x**（增长质量证伪）；
- 单季毛利率**连续两季回落**且境外占比同步下滑（传导失效确认）；
- 2026 年报 AI/高多层收入**仍不拆分** + 前五大集中度继续上升且不具名（信息不透明恶化）；
- 珠海/重庆达产时间表出现**公告级推迟**，或定增批文到期未发行且未重新申报；
- **任何新增董监高辞任**，或董事长补选拖过 2026Q4；
- 资产负债率突破 56% 或经营现金流转负。

### 重估触发器（上调评级的正向路径）

三条**全部满足**才重开评级（AND 条件，缺一不可）：① 26Q3 与 26Q4 单季 OCF/归母**均 ≥0.8x** 且自由现金流转正或缺口显著收窄；② **AI/高多层板营收首次独立披露且占比可验证**（这是把 (b) 客户能见度从「弱」抬起来的唯一路径）；③ 董事长/法定代表人补选完成且珠海基地达产获**公司公告口径**确认。
