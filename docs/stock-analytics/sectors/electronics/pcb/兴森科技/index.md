**2026-10-29 财报更新已订正两处旧悲观事实，本轮复核一致**：集团单季及累计均已转盈；H1 的 4,094.86 万元本来就是净计提，

- **bear（35%，42.9911 亿/2.53 元）**：广州主体 H1 亏损、FCBGA 规模商业回报待验证；分析压力减值

   **9998.62万元**并完成，拟用于激励/员工持股，不当作注销。旧“现价高于31.09元上限”撤销。
3. 8 亿补流还贷可缓解融资压力，但未发行前不消除 **65%/70亿元**已触发状态。
   [valuation.md §9.8](valuation.md) 以现价×80%作敏感性（非实际底价），募足摊薄约 **9.0257%**，
   满股数上限 **23.08%**；满额股数现金情形 base每股 **5.36元**，不纳入主估值。

**股东本位**：实控人邱醒亚持股 13.79%（满额定增后 10.61%），2025 年 8–9 月减持 996.39 万股、

（**已了结的程序违规，非财务造假，本档不据此启动诚信一票否决，但记入监控**）。
FCBGA 员工持股平台未分配份额 5,256 万元不再分配、公司 0 元受让 1 亿元实缴义务，
**激励机制实质失败**。2025年度每股派 **0.03元**（2026-05-28除权），本次锚下静态股息率 **0.1038%**；一次分红不等于持续分红能力已验证。

1. **价格严重高估？** —— **是。** PE-TTM **111.11x**、PB **8.80x**，期望 **68.7696亿**对市值

### §10.5 什么会让本档翻转为 watch

不是股价下跌（下跌只改善安全边际、不改变质地），而是以下**任意两条同时出现**：

- IC封装基板分部毛利率连续两期站稳正值，**且**出现FCBGA批量/量产表述：**小批量生产已于2026-05-08确认，文字部分已满足**，但连续盈利仍待分部披露；小批量本身不证明稳定商业回报；
- 广州兴森国资股东退出方案签约落地，13 亿元回购义务由外部承接方消化；
- 剔除增值税留抵退税后的 OCF 转正，且全年 FCF 缺口收窄至 −3 亿元以内；
- 出现**公司公告级**的具名大客户量产订单（华为昇腾传闻若被公告确认即属此列）。
