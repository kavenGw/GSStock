## §9.1 正常化利润：纠正减值符号，纳入 Q3 实质改善

**10/29已据26Q3财报订正旧口径，本轮复核一致**：26H1 的 4,094.86 万元是信用与资产减值**净计提**，已经减少利润；
旧档写成“净冲回”再从归母扣除是符号错误和重复扣减。H1 信用减值损失 −1,888.64 万元、资产减值损失
−2,206.22 万元合计 −4,094.86 万元，与计提公告逐元对平。减值不能被整体归为非经常损益。
因此撤销旧“1.1051 − 0.4095 − 0.0904 = 0.6052 亿元、年化 1.21 亿元”的洗后桥；
资产处置收益 H1 904.43 万元已包含于披露的非经常项，采用扣非基准后亦不再重复扣。

**正常化归母沿用10/29更新的 2.5 / 5.0 / 8.0 亿元【分析者假设，非公司指引】**：

## §9.4 隐含 ROE 检验：保留资产法主锚的条件

26Q3 归母净资产 **55.8157979639 亿元**，BVPS **3.28391 元**。杠杆率升至 **68.80%**、
有息负债含租赁 **77.4271 亿元**，FCF 缺口较大，股权成本仍取 **12%【分析假设】**；
虽有每股 0.03 元分红，现锚股息率仅 **0.1038%**，不降低这一风险假设。

| 情景 | owner earnings | 隐含 ROE | 距 12% 股权成本 |
|---|---:|---:|---:|
| bear | 1.50 亿 | **2.69%** | −9.31pp |
| base | 3.00 亿 | **5.37%** | −6.63pp |
| bull | 4.80 亿 | **8.60%** | −3.40pp |

盈利基数上修后，三档 OE 隐含 ROE 仍低于股权成本，资产法主锚、利润法验证的适用方法未变。
利润法自身顺序为 12 < 36 < 57.6 亿元；**不存在“同法 bull < base”的失效症状**，
不能拿利润法 bull 与资产法 base 跨方法比较充当这一症状。
固定资产 **62.2196 亿** + 在建工程 **16.3768 亿** = **78.5964 亿**，占总资产 **184.7855 亿**的 **42.53%**，
仍是重资产制造业，不适用轻资产软件例外。

**方法敏感性**：60% 系数下，正常化归母需 **11.1632 亿元**才能使 OE / 当前净资产达到 12%；
若系数改善至 80%，临界归母为 **8.3724 亿元**。后续持续盈利与现金质量均改善时应重审主锚，
资产法并非永久有效。历史深南 H1 ROE 12.43%、沪电 17.38% 的对照仍保留为 2026-09-07 研究基线。
