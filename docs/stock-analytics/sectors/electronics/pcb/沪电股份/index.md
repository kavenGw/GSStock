## §0 结论摘要

**评级watch，当前回避。期望内在价值1,039.7亿元（53.85元/股），安全边际−42.8%；买点≤40.60元。** 对比2026-08-25的827.4亿元 / 43.00元 / −62.4% / 32.00元，盈利基数主动上修、价格也下降，差距明显收窄，尚未形成安全边际。

**利润继续加速，同时现金确有改善。** 9M收入232.2544亿元（+71.88%）、归母56.2194亿元（+106.87%）；Q3收入95.3601亿元、归母26.9858亿元、扣非26.7966亿元（占归母99.30%），整体毛利**44.0238%**、归母净利率28.2989%，均超过Q2的41.2786% / 22.4912%。Q3 OCF15.5317亿元、OCF/归母0.57555，较Q2的6.3967亿元 / 0.38047改善；季度FCF **−1.2183亿元**，净有息债由H1 **37.6076降至28.7251亿元**。泰国9M累计已转盈。

**现金条款仍需执行。** 9M OCF27.0385亿元同比−6.61%，OCF/归母0.48095、FCF−25.7315亿元，存货期末法141.97天。累计Q1/H1/9M的0.41142 / 0.39362 / 0.48095，**本轮首次满足连续3报告期<0.6x**；库存>120天是H1已触发、本轮持续。S1/T1亦为中报既有触发，不算Q3新触发。25Q2/Q3单季0.73488/0.77092也会命中旧T1<0.8规则，故其特异性弱；25年累计三个同期均>1，26年累计<0.6提供更强独立证据。[现金质量与回测](business.md)

- **Bear 30%**：价格竞争、扩产折旧及营运资金负担压低回报；正常化owner earnings **35亿元×13=455亿元，23.57元/股**。
- **Base 50%**：Q3已兑现的盈利台阶进入穿越周期中枢，但留出一个下行年；**56亿元×20=1,120亿元，58.01元/股**。
- **Bull 20%**：换代延续、扩产部分按期兑现；**66亿元×26=1,716亿元，88.89元/股**，仍比94.11元低5.6%。扩产、具名客户能见度、TAM三项尚无足够新硬证，概率不抬。

三档均低于9M机械年化74.9593亿元及分析者FY26外推79–83亿元；**全年外推不等于正常化利润、也不是公司指引**。会计中枢与owner earnings折价桥、旧base算术错误见[valuation.md §9.1–9.2](valuation.md)。

最近量化业务基线仍是**26H1交换机/路由71.39亿元、AI/HPC18.28亿元**，交换机吃掉数通增量76.6%。10/20管理层仍称交换机为最强应用、1.6T批量出货，定性支持主变量；Q3没有新分部数据，不能据整体44.02%推出PCB/汽车毛利。旧「稼动率红利彻底耗尽」改为高基数约束且仍有技改挖潜；旧「2027 capex必降速至35%」降为风险情景。[论点更新](thesis.md)

### 10.2 现金触发器与利润改善的裁定

**触发器要求回避 / 本档裁定维持回避，二者一致。** Q3盈利、季度FCF和净债均改善，足以把base从44上修到56亿元；不能再写现金「比Q1更差」或安全边际「继续走阔」。但累计现金转化仍低、库存天数升高，改善尚不足解除规则；价格亦高于bull价值。按规则执行，与正常化基数上修可同时成立。

### 10.3 标签为什么仍是watch而不是exclude

exclude的语义是质地/治理否决。历史ROE六年均21.21%、2021周期底15.85%、从未亏损，22层以上全球第一14.9%、数据中心PCB第一10.2%（2025招股书口径），公司主动披露竞争与项目IRR下降，诚信项无新红旗。**适价仍愿研究持有，故保留watch；现金与估值限制当前参与。**

### 10.4 与兄弟档的一致性

中报时的生益电子、生益科技watch、建滔积层板exclude均为**2026-08历史比较**，本轮不更新同业财报与行情。沪电的差异仍是周期底盈利与技术壁垒较好，代价是扩产和备货吸现。自身TTM滚动至67.2663亿元，不能继续拿旧50.629亿元与新价比较；不把同业旧倍数当本轮低估证据。
