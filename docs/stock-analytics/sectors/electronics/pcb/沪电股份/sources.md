## §12.4 采证方法与口径冲突处置

- **cninfo 的 `hisAnnouncement/query` POST 接口本轮返回 `totalRecordNum=0`**（接口侧问题，非公司未披露），A1 改用东财公告 API + 公告正文 API 取到中报全文 274,739 字符。**中报的关键词扫描结论（无「Rubin」「CPO」「78 层」「试产」，数据通讯段落无「调价/涨价/提价」）建立在该全文扫描之上。**
- **三路证据冲突一律取 A1 并显式标注**，逐条清单见 [valuation.md「D. A2/A3 与 A1 的数字冲突」](valuation.md)。**唯一一处不取 A1 的是"客户集中度的差异化含义"**——A1「变化 3」判「多客户分散是相对胜宏的实质差异化」时未独立核胜宏、沿用了旧档未验证的「胜宏单客户>50%」，本档采 A2 的 2025 年报同口径实测。该条属定性推论而非硬数字。
- **单机 PCB 价值量两套口径不自洽，必须并列不可择一**：口径一 Rubin VR200 NVL144 单机柜 PCB 约 **$116,700**（vs GB300 $35,100，+233%）；口径二 单 GPU PCB **$880**（+113%）、单柜 72 GPU 约 45.6 万元人民币。$116,700 ≈ 83 万元 vs 45.6 万元，**差 1.8 倍**（推测口径一含 Midplane/ConnectX/BlueField 等全部约 100 块板）。**本档不采用任一口径进入估值。**
- **已弃用的不可信口径**：网上流传「交换机 PCB 市场 73/95 亿元 vs AI 服务器 PCB 市场 379/689 亿元」——沪电一家 26H1 交换机收入就有 71.39 亿，不可能只占一个 95 亿元的全球市场。**引用时须避开。**
- **生益电子 26Q2 单季毛利率环比 −1.54pct**：A3 明确未能独立核实，公开口径本身分歧（26H1 综合 29.24% vs 21 世纪经济报道 34.31%「上市以来最好半年度」）。**本档正文只用 A1 可比表的 34.31% 半年口径**，「Q2 环比 −1.54pct」标为兄弟档口径【软】、未独立核实。
- **存货周转天数两个口径都列**：A1 期末余额口径 26H1 **130.3 天**（25H1 101.8 天）；A3/招股书平均余额口径 87 → 100 天（至 26Q1）。**监控阈值用期末口径的 120 天。**
