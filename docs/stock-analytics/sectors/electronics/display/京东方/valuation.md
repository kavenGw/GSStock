### 口径基础

**为什么主锚是 PB 而不是利润法**：面板是重资产 + 重研发 + 强周期生意，owner earnings 对单一年份失真严重（2021 顶归母 259.61 亿、2023 底 25.47 亿，相差 10 倍），符合 `buffett-doc-spec` §3「周期行业用历史盈利能力法 + 资产法锚」的准入。同板块兄弟档（TCL 科技）通行口径亦为 PB 主锚。

**正常化利润一律用扣非，不用归母**：2026H1 归母 52.48 亿中 22.39 亿为非经常性（占 42.7%），用归母会系统性高估中枢。H1 扣非 30.08 亿、年化 60.17 亿属**周期修复顶部**，穿越周期取中枢而非年化值（红线 3）。

**玻璃基板量产红利不进任何情景的 owner earnings 基础**——公司口径量产评估已后移至 2028Q2、自认良率未达量产水平、具名客户/订单/量产时点/营收四项全【缺】（见 [§6/§7](thesis.md)）。

### 三情景（控制者裁定值，倍数与概率不得自改）

| 情景 | 正常化扣非 | PB 倍数（近五年分位） | 内在价值 | 每股 | 概率 |
|---|---|---|---|---|---|
| **bull** | ~75 亿（面板去周期化 + 8.6 代线中尺寸 OLED 兑现 + MLED 延续高增） | **1.90x**（近五年约 p90，未及 max 2.39） | 1,331.36 × 1.90 = **2,529.6 亿** | **6.83 元** | **20%** |
| **base** | ~55 亿（穿越周期中枢，**非 H1 年化的 60.17 亿**） | **1.30x**（近五年 p75–80） | 1,331.36 × 1.30 = **1,730.8 亿** | **4.67 元** | **47%** |
| **bear** | ~30 亿（周期回落 + 8.6 代线折旧压顶 + 存储涨价挤压产业链） | **1.00x**（近五年下沿，上方 min 0.98） | 1,331.36 × 1.00 = **1,331.4 亿** | **3.59 元** | **33%** |

**概率自检：20% + 47% + 33% = 100% ✓**

**每档赋权理由（引 §6/§8 证据）**：
- **bull 20%（封顶 ≤25%，较旧档 22% 下调 2pct）**：`x-growth` 增长三要素证据包中**仅「扩产达产」为【硬】**（8.6 代线 2026-06-17 点亮量产、630 亿投资、3.2 万片/月）；**「客户能见度」【缺】**（玻璃基仅「部分国内客户 PoC」无具名，OLED 客户未具名，英伟达经公司否认）；**「TAM 跑道」【软】**（LCD 已全球第一、跑道在价格不在渗透；玻璃基卡位落后）。三要素两软一硬，证据包不支持上修。下调 2pct 的依据是**周期前视镜转跌**（7 月价格见顶、8 月普降 1–3 美金、TV 出货环比 −25.6%）+ **增长质量恶化**（非经常占归母 42.7%、营收仅 +1.83%、经营现金流零增长）。
- **base 47%**：LCD 双寡头格局因 LGD 退出而强化【硬】，主业尚能维持量缩价稳（显示器件毛利率 +0.34pct），但收入 −3.20%、H2 价格下行是基准情形。1.30x 已在近五年 p75–80，即已给出高于历史中位的溢价。
- **bear 33%**：8.6 代线 315.91 亿转固后年折旧增量 30–45 亿，叠加存储涨价挤压产业链（公司自述新增风险），扣非回落至 30 亿量级并非尾部情形。1.00x 是近五年下沿而非破净（min 0.98）。

### 期望内在价值与安全边际

```
期望内在价值 = 2,529.6 × 0.20 + 1,730.8 × 0.47 + 1,331.4 × 0.33
             = 505.9 + 813.5 + 439.4
             = 1,758.8 亿元  →  每股 4.75 元
```

**安全边际 = (1,758.8 − 2,193.02) / 2,193.02 = −19.8%**（旧档 −4.2%，**显著恶化**）。

**bull 单独压力测试**：(2,529.6 − 2,193.02) / 2,193.02 = **+15.3%** —— 即便最乐观情景完全成立，仍**不足周期股所需的 30–40% 折扣**（06-valuation：存在不确定因素的生意需 40–50% 折扣）。旧档同口径为 +19.2%，本轮更薄。base + bear 概率合计 **80%** 下均无安全边际。

### 倍数是否破框架（`buffett-doc-spec` §3 自检）

三档 PB 1.00 / 1.30 / 1.90 均落在**近五年真实区间 0.98–2.39 内**，bear < base < bull 单调，无一档需要跳出周期股框架去凑数字，不触发「破框架回查隐含 ROE」条款。作为交叉验证：base 隐含 ROE = 55 / 1,331.36 ≈ **4.1%**，bull 隐含 ROE ≈ **5.6%** —— **两者都远低于本标的应有的股权成本（高杠杆重资产、股息率不足 1%，≥10% 量级）**。这正是给不出高 PB 的根本原因，也说明「PB 1.647x / 93 分位」在基本面上缺乏支撑。**加权 ROE 实际值 3.82%（2026H1）与此一致。**

### 资产法托底是否成立（x-dividend-value lens 必答）

**不成立。** 面板产线专用性极强、二手残值低，账面净资产中含大量待折旧产线（固定资产 1,743.12 亿 + 在建工程 589.25 亿，受限资产 1,075.92 亿、其中固定资产 875.25 亿已抵押用于借款），清算价值显著低于账面。近五年 PB 最低 0.98、曾短暂破净，**当前 1.647x 距破净仍有约 39% 下跌空间 → 破净不构成当前价位的托底**。

### 诚实面对「贵」（红线 4）

- PE 27.91x 是周期股口径失真值，三个 PE 口径（27.91 / 36.4 / 20.9）差异达 75%，**任一都不足以定价**。
- PB 1.647x 处近五年 **93.32 分位**、为中位 1.19x 的 1.38 倍，是本轮最硬的估值事实。
- 股价自 2026-06-01 的 5.54 元涨至 8-28 的 5.92 元（+6.9%），同期基本面唯一硬兑现是 8.6 代线量产（OLED 产能，非 AI 收入），而玻璃基量产时点后移至 2028Q2 —— **概念溢价在证据边际变差的情况下继续扩张**。
- 不用「AI 想象空间 / 玻璃基期权 / 护城河上修」稀释「价格太贵」。同样地，也不用「周期股就该低估」掩盖生意本身的真实改善（供给侧格局确实强化）——所以评级是 watch 而非 exclude。
