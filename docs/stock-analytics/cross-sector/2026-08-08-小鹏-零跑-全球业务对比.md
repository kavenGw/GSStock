## Conclusion

**全球业务这一项，零跑在"量"上赢小鹏 3 倍多，但赢的是别人的渠道；小鹏在"资产"上赢零跑，但赢的是没有规模的资产。**

**两家的出海故事都进不了估值——因为两家都不披露分地区毛利率。**（两档各自的【缺】项在本次采证中仍未被填上。）

结论对两份个股档的评级**均无改变**：零跑维持 Exclude，小鹏维持 Watch。

## 2 模式差异：借船出海 vs 自己造船

**这是两家全球业务最本质、也是唯一真正结构性的区别。**

### 零跑 = Stellantis 合资通道（Leapmotor International）

| 维度 | 事实 | 判断 |
|---|---|---|
| 渠道 | 与 Stellantis 合资，整合其产品/制造/渠道资源，40+ 国 ~950 网点 | **半年破 10 万台的唯一解释** |
| 自建成本 | 近乎为零——用的是 Stellantis 存量经销体系 | 资本效率极高 |
| 研发本地化 | 2026-03 德国首个海外研发中心 | 增量正面 |
| 控制权 | **不在自己手里** | 见下 |

**代价：这是一条"借来的护城河"**——零跑档 §5 的判断在 H1 数据下**依然成立，而且被一次实证强化过**：

- **波兰工厂已因政治因素停产**——海外布局的政治敏感度已经兑现过一次风险
- Stellantis 自身经营承压，**资源分配的优先级不由零跑决定**
- 合作条款、渠道分成、区域配额，零跑都不是定价方

> "A moat you rent is not a moat." — 借来的渠道在顺风时是加速器，在逆风时是一个你无法投票的董事会席位。

### 小鹏 = 自建渠道 + 自控产能

| 基地 | 状态 | 定位 |
|---|---|---|
| **奥地利 麦格纳格拉茨** | **G6 / G9 已量产** | 欧洲本地化，规避关税 |
| **印尼工厂** | 2026-05-22 完成 **90.1% 股权收购** | **首个在东南亚实现制造端控股的中国新势力** |
| **马来西亚 马六甲** | 2026-06 投产 | 右舵 G6，供英/爱/东南亚右舵市场 |
| 大众欧洲工厂 | **洽购中**【软】 | 若成，欧洲产能量级跃升 |

**小鹏的本地化进度实际领先零跑**：欧洲代工已在量产，而零跑要到 **Q4 才开始 CKD**。

**代价**：自建慢、重，且**当前产能是负担不是资产**——小鹏 1–7 月国内仅交付 20.4 万辆，产能利用率严重不足（小鹏档 §1 已把"扩产确定性"从 bull 支撑里剔除）。

### 裁决

| 视角 | 更优的一方 | 理由 |
|---|---|---|
| **三年视角** | **零跑** | 量已经跑出来了，小鹏的还没有 |
| **十年视角** | **小鹏** | 资产在自己名下，渠道与产能都可控；零跑单点依赖一个自身承压的伙伴 |

**Buffett 框架下的落点**：零跑买到的是**速度**，小鹏买到的是**控制权**。护城河只认后者——但小鹏那条自有的护城河**目前还没有规模去填满它**。两家在全球业务上，一个有量没有护城河，一个有护城河雏形没有量。

## 3 关税与本地化时间轴（决定出海赚不赚钱）

欧盟对中国产纯电的**加征税率 30.7%**（20.7% 反补贴 + 10% 标准关税）——这是压在两家欧洲毛利率上的同一块石头。

| 时点 | 零跑 | 小鹏 |
|---|---|---|
| 至今 | **欧洲销量全额承担 30.7% 关税** | 奥地利产 G6/G9 **已本地化，规避关税** |
| 2026Q4 | 西班牙萨拉戈萨 **CKD 投产**（B10/B05），OTS 首台试制车已下线，10 月商业化量产 | — |
| 2026H2 | — | 马来西亚（右舵）、印尼产能爬坡 |

**这一栏是本档对零跑最不利的发现**：零跑 H1 那 10 万台海外销量里，欧洲部分**基本是在满额关税下卖出去的**。它的"欧洲爆发"是一个**尚未验证过盈利性的爆发**——放量在前，本地化在后。

反过来，小鹏欧洲量小，但**卖出去的每一台的关税结构比零跑干净**。

## 4 价格带：一个向下复制，一个向上对冲

| | 零跑 | 小鹏 |
|---|---|---|
| 海外主力 | **B10**（性价比，B 系列） | G6 / G9 / X9；L03 欧洲 **40,740 USD** |
| 打法 | 靠低价打进意大利细分冠军、德国销量榜首 | 欧洲 **4 万欧元以上高端纯电中国品牌第一** |
| 与国内的关系 | **国内"性价比换量"逻辑的复制粘贴** | **对冲国内 ASP 下沉的唯一通道** |

**小鹏在这一栏明确占优，且这个优势有具体的算术意义**：MONA L03 国内 12.38–15.68 万，欧洲 40,740 USD。小鹏档 §6c 识别的核心风险是"L03 每多卖一辆就把均价往下拽"（Q1 单车均价 17.5 万，汽车毛利率仅 12.1%，缓冲极薄）——**海外定价是这个风险唯一的对冲盘**。

零跑没有这个对冲：它把国内那门无定价权的生意，原封不动搬到了一个带 30.7% 关税的市场里。

## 5 出海到底赚不赚钱（本档最有决定性的一节）

**两家均【缺】分地区毛利率披露。** 但可以用两组反向证据做二分：

| | 零跑 2026Q1 | 小鹏 2026Q1 |
|---|---|---|
| 海外占比 | **37.1%**（当季创新高） | ~15%（4 月首破月销 6000） |
| 综合毛利率 | **9.4%（从 14.5% 暴跌 5.1pp）** | **20.6%（同比 +5.0pp，创新高）** |
| 整车毛利率 | **~7%** | 12.1% |
| 单季损益 | **亏 3.9 亿** | 亏 17.8 亿（研发 +46.8% 所致，非毛利端） |
| 管理层对海外的归因 | 未提及海外对毛利率的贡献 | **明确把"高速增长的国际化收入"列为毛利率稳健的原因之一**【软，定性无量化】 |

**读法**：

> **同一个季度，海外占比更高的那家毛利率在崩，海外占比更低的那家毛利率在改善。**

这不能证明"小鹏出海赚钱"（管理层归因是定性的、且毛利率改善也可归因于技术服务收入），**但足以证伪"零跑出海带来了毛利率溢价"**——一个海外占比冲到 37% 的季度，整车毛利率掉到 7%，海外至少**没有托住**毛利。结合 §3 的关税时间轴，最自然的解释是：**零跑的欧洲量是用满额关税下的薄利换来的。**

**估值纪律（两档一致）**：在拿到分地区毛利率之前，**出海不进入任何一家的 owner earnings 基础**，只能作为定性支撑。小鹏档 §4.3 已明写这条纪律，本档确认它同样适用于零跑。

## 7 Buffett 视角的合并裁决

| 维度 | 零跑 | 小鹏 | 更优 |
|---|---|---|---|
| 海外绝对规模 | ~10 万台 / H1 | 3.16 万台 / H1 | **零跑（3.2x）** |
| 海外增速 | 半年超去年全年 | +68.9% | **零跑** |
| 渠道所有权 | 借 Stellantis | 自建 | **小鹏** |
| 海外制造资产 | 1 处（Q4 才投产） | 3 处（已量产/已控股） | **小鹏** |
| 关税结构 | 满额 30.7% | 部分已规避 | **小鹏** |
| 价格带 / ASP 效应 | 向下复制 | 向上对冲 | **小鹏** |
| 海外盈利性 | 反向证据不利 | 定性归因正面 | **小鹏（弱证据）** |
| 目标兑现 | 超额 | 未达 | **零跑** |

**综合**：零跑赢在 2 项（都是"量"），小鹏赢在 5 项（都是"质"与"结构"），目标兑现零跑再加 1 项。

**但这个比分不能直接翻译成投资结论**，因为它遗漏了两家共同的问题——**全球业务在两家的估值里都还只是一个免费期权**：

- 零跑：海外占比 37% 的季度整车毛利率 7%，**海外没有改变 commodity 生意的本质**
- 小鹏：海外 3.16 万台对 739.4 亿的正常化营收基数**影响有限**，且毛利率贡献未量化

> "A horse that can count to ten is a remarkable horse, not a remarkable mathematician."（1989 年致股东信，零跑档已引用）
>
> 出海增速本身就是一匹"能数到十的马"。**它是不是好生意，取决于卖出去的每一台车赚不赚钱——而这两家都没告诉我们。**

## 9 监控指标

**共同的那一项（最重要）**：

- **任一家首次披露分地区毛利率 / 海外分部盈利** → 出海第一次具备进估值的资格，两档都需重算

**小鹏**：

- **2026-08-24 Q2 财报**：国际收入占比是否兑现"二季度起超 20%"、是否给出海外毛利率量化贡献
- 大众欧洲工厂收购是否落地（落地则欧洲产能量级跃升，属 bull 增量证据）
- 海外月销能否站稳 6,000+ 并向 30–40% 占比目标推进

**零跑**：

- **Q4 西班牙萨拉戈萨 CKD 是否按期投产**（延期 = 2027 年欧洲仍全额扛关税）
- **投产后欧洲毛利率是否回升**——这是"海外爆发"能否转化为利润的唯一验证点
- Stellantis 持股/合作条款是否生变、是否再现波兰式的政治停产
- 海外占比继续上行而整车毛利率不回升 → **反向确认海外是薄利换量**，Exclude 理由进一步夯实

**局限（必须诚实列出）**：

1. **两家均未披露分地区毛利率**——本档 §5 的核心判断建立在"综合毛利率 + 海外占比"的联合推断上，**不是直接证据**

4. **两家 H1 财报均未发**，本档财务侧全部停在 Q1，Q2 可能改变结论
5. **零跑个股档（2026-06-04）的估值未因本档重算**——本档只推进其 §6.1 的海外事实口径，三情景加权与 Exclude 结论沿用旧档
