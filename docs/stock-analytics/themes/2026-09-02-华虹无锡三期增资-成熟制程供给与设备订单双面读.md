## 0. 事件核实

**结论：确认属实（公司公告级，置信度高）；但项目本身非增量信息，增量在出资结构。**

- 公司公告口径已由智通财经转述并核对：标的公司增资后**注册资本 41.7 亿美元**，其中**华虹宏力出资 10.425 亿美元 + 上海华虹宏力出资 10.842 亿美元 = 21.267 亿美元**（约 51.0%），增资后标的仍为控股子公司；余下**约 49%（约 20.4 亿美元）由无锡锡虹国芯二期、华芯鼎新、国开新型政策性金融工具承担**【硬·公司公告转述】。
- 项目非新披露：无锡华虹三期已于 **2026 年初启动招标**，本次为股本注资落地【软·媒体】。故「新建 5.5 万片/月 12 英寸线」这条对市场**已部分 priced in**，真正的增量信息是**外部资本承担近半股本**以及**股本规模确认到 41.7 亿美元**。
- 未获披露【缺】：具体工艺节点、通线/达产时间表、各外部方分项出资额、总投资额（41.7 亿美元为注册资本非总投资；对照华虹制造无锡 FAB9 项目总投资 67 亿美元口径）。**本档不据此推算设备采购金额**。
- 出资方性质：华芯鼎新（北京）股权投资基金 2024-12-31 成立、出资总额 930.93 亿元，大基金三期占比 >99.9%【硬】。即本次为**大基金三期 + 地方国资 + 政策性金融工具**的组合注资，是国家级产能意志的直接体现，而非市场化项目融资。

## 2. 逐标的传导分析

### 2.0 华虹宏力（01347.HK / 688347.SH）— 本体，转模式 1 承做

本档不重估本体，只记两条对旧 thesis 的读数：①**利好侧**——外部方承担约 49% 股本，上市公司现金压力小于全额自建；②**利空侧（更重）**——旧档（2026-08-14，watch，安全边际 −76.2%）两条核心判断**均被本事件强化**：一是「折旧是阶梯而非单峰」，三期在 9C 折旧高峰（26Q2 折旧 YoY +30.0% 已快于营收 +26.8%）之上再叠一级，2028+ 又一轮爬坡；二是「归母利润高增很大程度是少数股东替上市公司股东吃亏损的会计结果」——**再引入约 49% 少数股东做新厂，等于把三期爬坡期亏损同样外置**，归母仍将好看，而上市公司股东对新增产能的实际权益被摊薄。⇒ 维持 watch 方向，**本体估值/评级重估请转模式 1**。

### 2.1 北方华创（002371）— 中性偏多 / 高 · 本档最强 read-across

- **旧 thesis（2026-08-26 首建档，watch）**：市场在为 2028 年 124–166 亿的扣非付约 30 倍，本档 base 认为 2026–2030 扣非横盘在 58 亿附近——分歧不在倍数，在利润。
- **改变了哪个变量**：该档 `thesis.md` §8 明确把「华虹资本开支规划大部分支出将集中于**今明两年**」（26Q2 capex 3.566 亿美元、利用率 102.8%）列为判定「foundry/成熟制程 capex **2026-2027 高位、2028 落**」的**第二根支柱**（第一根是中芯的平台期）。三期 41.7 亿美元股本落地 + 大基金三期背书，把华虹成熟制程 capex 的可见性**推到 2028 及以后**，这根支柱明显松动。而北方华创档与市场的全部分歧恰恰落在 2028 年的利润水平。
- **双面**：利好侧——成熟制程这条腿的下游 capex 悬崖被延后，base「58 亿横盘」的下沿更稳；风险侧——① 本次只确认股本、**未确认设备采购金额与节奏**【缺】，该档 §12 已把「华虹 capex 指引」列为缺证项，本事件**同样不得用来补金额**；② 该档 26H1 东北及华北营收 −23.25% 的实证仍在，一个新项目不改已发生的区域下滑；③ 前一份 theme（2026-08-21 中芯业绩说明会）已被该档裁为「动摇·中」（中芯 capex 平台期），本事件方向相反，两者相抵后是**分歧缩小而非结论翻转**。
- **结论**：不改 watch（分歧在利润不在方向，价格未变），但**「2028 落」这一空方论据的强度下降**，events.md 记「动摇·中」。

### 2.2 拓荆科技（688072）— 利好 / 中

- **旧 thesis（2026-08-22，watch）**：国产薄膜沉积唯一产业化龙头，26H1 腔体 +12%、收入 +49% 的量价双轮证明份额替代与结构升级是真的。
- **改变了哪个变量**：**收入端的订单能见度**。5.5 万片/月 12 英寸特色工艺线的 PECVD/ALD 腔体需求是确定性增量，且华虹是国产设备验证最充分的成熟制程客户之一。
- **双面**：利好侧——把量价双轮的「量」从 26H1 已实现的一次性数据延展成 2027-2029 的可见管线；风险侧——特色工艺线的薄膜层数与先进制程不可同日而语，**单价与腔体密度均低于逻辑/存储先进节点**，对结构升级（高端产品占比）这条更值钱的腿**没有帮助**，甚至稀释产品结构。
- **结论**：强化旧 thesis 的「量」侧，不改 watch（估值仍是主要矛盾）。

### 2.3 至纯科技（603690）— 利好 / 中 · 时间窗最近

- **旧 thesis（2026-06-28，watch）**：本质是晶圆厂高纯工艺系统集成商（特气 48.8%/化学品 30%+/洁净室国内第一，合计占收入 80%），湿法清洗仅 10% 且属国产二三梯队——困境反转命题而非成长设备股。
- **改变了哪个变量**：**新建 12 英寸厂的高纯工艺系统与洁净室是全厂最早签约、最早确认收入的一环**（先于工艺设备招标）。这是本档唯一一只传导时间窗可能落在**季度内**的标的。
- **双面**：利好侧——直接命中它占收入 80% 的主业而非只有 10% 的清洗设备，是罕见的「利好打在基本盘上」；风险侧——系统集成是**低毛利、重垫资**生意，新订单同时意味着应收与存货占用上升，对困境反转所需的**现金流修复反而可能是拖累**；且该业务竞争充分，不构成定价权。
- **结论**：强化困境反转的订单侧，不解决盈利质量矛盾，维持 watch。

### 2.4 芯源微（688037）— 利好 / 中

- **旧 thesis（2026-09-01 首建档，watch）**：市场付的是「北方华创平台 + CoWoS/HBM 临时键合」这两个尚未在报表出现一分钱的期权，而不是 21.36 亿营收对应的现金流。
- **改变了哪个变量**：**基本盘（前道涂胶显影/单片清洗）的订单**，而非市场在付钱的那两个期权。这是一条被市场忽视的「实」利好。
- **双面**：利好侧——成熟制程国产前道涂显是它份额最扎实的战场；风险侧——正因为利好落在基本盘而非期权上，**它不改变该档的核心指控**（PB 26.52 / PS 34.95 处三年 96%+ 分位、安全边际 −95.5%，是被期权而非基本盘定价的）；基本盘多接几个亿订单，对这个价格没有意义。
- **结论**：强化基本盘、不动估值结论，维持 watch。

### 2.5 士兰微（600460）— 中性偏空 / 中

- **旧 thesis（2026-08-23 深度重做，watch）**：本轮涨价是「AI 抢走成熟制程产能」的**供给挤出**而非需求拉动；涨价弹性真实但被 13.93 亿刚性折旧与 320 亿扩产吞噬，验证点后移至 2026Q3。
- **改变了哪个变量**：**供给端的中期解药落地**。该档已引机构口径「供给紧张窗口给到 2027H1（8 吋产能 2026 −2.4%、2027H1 仍为负）」；华虹三期 5.5 万片/月 12 英寸特色工艺（BCD/功率与士兰微 12 吋线正面重叠）把 2028+ 的供给补上，**为该档的窗口有限性提供了一条独立于机构预测的产业侧证据**。
- **双面**：利空侧——涨价窗口封顶更确定，「扩产赌景气」的风险上升；名义利好侧——供给增加也可解读为下游需求被产业侧确认为真实。但该档已实证 2026Q2 单季扣非同比 −4.5%、环比 −25.1%，**兑现尚未开始**，这一侧目前拿不到证据。
- **结论**：**强化**该档触发器 #4（2026Q3 扣非不转正即降级）的紧迫性，不改 watch，本事件不构成即时降级理由。

### 2.6 中芯国际（00981.HK）— 中性偏空 / 中

- **旧 thesis（2026-08-27，watch）**：大陆成熟制程代工龙头，26H1 营收 +19.4%、归母 +9%，半年报后判「两侧同时收窄、中枢下移」，安全边际 −65.5%。
- **改变了哪个变量**：**2028+ 的同业供给**。华虹三期与中芯在 BCD/eNVM/PMIC 等特色工艺上部分重叠，是大陆成熟制程池子里的新增竞争产能，且由大基金三期背书意味着**不受商业回报约束的供给**——这是成熟制程最典型的价格结构性压制来源。
- **双面**：利空侧——远期 ASP 压制；缓和侧——中芯自身 capex 已在平台期（2026 指引与 2025 大致持平 ≈81 亿美元），它不是这轮扩产竞赛的追加方；且 5.5 万片/月相对其月产能量级有限，2028 前不进损益。
- **结论**：**无关**于旧 thesis 的核心（估值与利润中枢），仅作远期供给背景，维持 watch。

### 2.7 珂玛科技（301611）— 弱利好 / 中（二阶）

- **旧 thesis（2026-06-26，watch）**：本土先进结构陶瓷份额约 72%、北方华创全球金牌供应商，生意优质但价格极端透支。
- **改变了哪个变量**：**隔一层的订单**——晶圆厂 capex → 整机厂（北方华创等）设备订单 → 陶瓷零部件。方向成立，但传导两阶、时滞落在 2027 之后，且本次未披露设备采购金额【缺】，无法量化。
- **结论**：方向性强化「设备国产化 → 零部件」逻辑，量级受限于二阶与时滞；价格透支这一核心矛盾不受影响，维持 watch。

### 2.8 扫描后判定无/弱传导（不展开）

- **硅片链（沪硅产业 / 西安奕材 / 有研硅 / 立昂微 / 神工股份 / 晶盛机电）**：5.5 万片/月对大陆 12 英寸硅片需求是个位数百分比增量，且这几家的核心矛盾是**过剩下的价格接受者地位**（沪硅、西安奕材、立昂微均为 exclude 或以「商品生意」定性），需求微增不改定价权缺失，且用量要等到 2028+。判弱利好·低。
- **功率同业（华润微 / 斯达半导 / 捷捷微电 / 东微半导）**：与士兰微同向的供给增加逻辑，但这四家自有产能或 fab-lite 结构使敞口小于士兰微，时间窗过远，不构成对旧 thesis 的动摇。判弱利空·低。
- **模拟/MCU fabless（圣邦股份 / 思瑞浦 / 纳芯微 / 希荻微 / 中颖电子 / 中微半导体）**：代工产能增加对 fabless 是成本与保供利好，同时削弱三档共同提到的「涨价定价伞」叙事，**两个方向互相抵消**且落在 2028+，净读数接近零。判弱利好·低。
- **后道/其他设备（ASMPT / 芯碁微装 / 赛腾股份）**：特色工艺前道扩产不传导到后道封装设备与 PCB 直写光刻，无影响。
- **境外标的（安森美 / Wolfspeed / 英诺赛科 / 三星电子）**：跑道（SiC / GaN / 存储）与 12 英寸特色工艺代工不重叠，无影响。

## 3. 操作含义

1. **唯一值得动作的是北方华创档的空方论据强度**：其 `thesis.md` §8「2028 落」的第二根支柱（华虹 capex 集中今明两年）已被本事件动摇，但**分歧的核心（2028 年扣非是 58 亿还是 124–166 亿）需要金额而非意向**——本次未披露设备采购金额，故记「动摇·中」，不改评级、不改估值。下一个决定性证据是华虹的正式 capex 指引或三期设备招标结果。
2. **士兰微的触发器时钟没变但更紧**：2026Q3 扣非是否转正仍是分水岭，本事件把「窗口有限」从机构预测升级为产业侧事实。
3. **至纯科技是唯一时间窗可能落在季度内的标的**，值得跟踪其新签订单公告；但注意订单利好与现金流修复在它身上方向相反。
4. **本体华虹宏力不因此事件改变 watch**：安全边际 −76.2% 的估值矛盾与本事件无关，且事件对「折旧阶梯 + 少数股东吃亏损」两条核心指控是强化而非缓解。需要重估请转模式 1。
5. **不要把这条新闻当成「设备板块普涨」的理由**：本档 7 只中量级以上的非本体标的里，5 只的核心矛盾都是估值而非订单，订单利好对它们的价格结论**没有任何影响**。
