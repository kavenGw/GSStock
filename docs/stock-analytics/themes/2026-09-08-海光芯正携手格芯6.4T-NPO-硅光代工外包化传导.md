## 2. 逐标的传导分析（仅中量级）

### 中际旭创（300308）— 中性偏空 / 中
- **旧 thesis（conviction_date 2026-09-07）**：量价齐升硬兑现、商业论点被超预期证实，但价格 price-in 顶部年利润，安全边际 −52.8%，维持 watch。
- **改变了哪个变量**：不是收入、不是成本，是 **bull 情景的成立条件**。旧档 bull（22% 概率、615.5 元）四条支柱之一即「**CPO 量产继续后移**」；同一份档也已把「3.2T / NPO / XPO / CPO 2026H1 收入贡献为零」列为风险 5。第三方通过代工厂直接推 6.4T NPO 量产，是该后移假设的方向性反证。
- **双面**：利空侧——NPO 从 IDM 自研门槛降为「买 GF 产能即可参与」，长期蚕食时点可能前移；利多侧——本体 12 亿收入、9% 毛利、框架无订单，2027 年前不具规模交付能力，且旭创自身硅光设计能力与 EML/CW 满载的成本优势未被触及。
- **结论**：**不改评级（仍 watch）**，但 bull 概率的门控理由多一条反证；旭创口径下这属于「已被 −52.8% 安全边际吸收的风险」，不构成新的卖出触发器。下次重做时须在 bull 门控里显式回应「NPO 代工路径」。

### 新易盛（300502）— 中性偏空 / 中
- **旧 thesis（2026-07-02）**：LPO 去 DSP + 硅光自研 + 光芯片 65% 自给的垂直整合构筑系统性高毛利护城河（毛利高旭创 6−7pct），CPO 2027+ 从交换机侧蚕食是核心 overhang，安全边际 −76%。
- **改变了哪个变量**：**护城河的稀缺性来源**。旧档写明「硅光 + 光芯片自给 + 垂直整合极难同时复制」——这个「难」的前提是硅光能力必须自建。GF 把硅光子工艺平台化开放后，一家亏损小厂即可对接 6.4T NPO，说明硅光正从「稀缺能力」向「可外购工艺」滑移，垂直整合的**溢价来源**被边际稀释（不是被证伪：良率、成本、封装耦合仍在自研方手里）。
- **双面**：利空侧——护城河宽度评级中「硅光自研=走宽」的斜率要下修；同时 CPO/NPO overhang 前移，而此前两篇 theme（2026-06-11 CPO 延后、2026-07-06 Kyber 延迟）给的都是**反向缓释**结论，本次是这条线上的第一条反向证据。利多侧——NPO 走的是交换机侧，短期不动 800G/1.6T 可插拔基本盘；新易盛自身也在做 12.8T XPO 预研。
- **结论**：**不改评级（仍 watch）**——安全边际 −76% 本就无翻转空间。真正的动作是**下次重做必须把「硅光自研」的护城河趋势由「走宽」重判为「走宽但被工艺外包化削斜率」**，并在 §6 空头段引本条证据。

### 天孚通信（300394）— 中性偏多 / 中
- **旧 thesis（2026-07-02）**：光器件「军火商」，1.6T 光引擎已量产、CPO 配套 FAU/ELS 是卡位；三重压制（Fabrinet 单客 63.31%、康宁玻璃桥替代 FAU/主动耦合、经营现金流恶化），安全边际 −86%。
- **改变了哪个变量**：**CPO/NPO 配套需求的时点与广度**。GF SCALE 明确在招募「设计、封装、连接、系统」层生态伙伴——连接层正是天孚的位置；旧档已判「CPO 对天孚是双刃、区别于模块厂的纯逆风」，本次事件把双刃里**受益的那一面**的时点往前拉。
- **双面**：利多侧——NPO 参与者变多 → FAU/ELS/透镜/插芯的配套盘子变大，且不依赖单一客户；利空侧——GF 平台化路径同样倾向晶圆级被动对准（与康宁玻璃桥同构），长期削弱天孚最赚钱的主动耦合环节，且 GF 生态的连接层供应商未必是中国厂商（地缘 + FCC 禁令背景，见 2026-08-05 theme）。
- **结论**：**不改评级（仍 watch）**。净判中性偏多，但受益的可实现性受地缘约束打折，不足以对 −86% 的安全边际形成任何缓解。

### 源杰科技（688498）— 利好 / 中
- **旧 thesis（2026-07-02）**：CW 光源数据中心业绩已真兑现（2026Q1 毛利 77.8%、数据中心占营收 65%），但远期 PE 274x、PB 99.4 分位，安全边际 −92.5%。
- **改变了哪个变量**：**需求量的中枢，而非质**。NPO/CPO 架构的定义特征之一是光源外置（ELS），单机 CW 用量显著高于可插拔架构。NPO 参与者从 IDM 龙头扩到代工客户，等于 CW 光源的潜在客户名单变长——这是旧档「CW 兑现」的量的强化。
- **双面**：利多侧同上；利空侧——海光芯正与 GF 的合作面向北美市场，其 CW 光源供应商大概率不是国产（源杰的可及份额受限于同一套地缘约束）；且 NPO 规模化在 2027+，对当期报表无贡献。
- **结论**：**不改评级（仍 watch）**，安全边际 −92.5% 下任何需求侧利好都不构成买入理由。归档意义在于：这是继 2026-07-21 H1 预告后，CW 光源结构性需求的又一条独立佐证。

- **罗博特科（300757）、炬光科技（688167）、沃格光电（603773）**：CPO 设备/微光学/玻璃载板的题材侧受益，但三者旧档共同判词都是「产品层卡位真实、业绩层为零、估值已把 CPO 想象充分定价」——本事件属**已 priced in 的同类题材催化**，不新增基本面，判弱利好-低。
- **仕佳光子（688313）、三安光电（600703）**：无源 AWG / InP 外延的潜在配套受益，链条三阶且份额未定，判弱利好-低。
- **光库科技**：CPO 只改封装不改材料，旧档已明确该结论，按反向证据优先原则维持无影响。

4. **本体（海光芯正 01191.HK）不在池内、本档不评级**。若需判断其投资价值，转模式 1 深度分析。
