## 2. 逐标的传导分析（仅中量级以上展开）

### 2.1 宏桥控股（002379）— 双面 / 中量级 / **强化 exclude**

**旧 thesis（2026-07-23 buffett 档，rating = `exclude`）**：生意质地不差（全球最低成本电解铝中游主体），差的是价格、治理与平台选择——PE 13.52x / PB 5.44x 板块断层最贵，期望内在价值每股 6.79 元 vs 现价 20.45 元，安全边际 -66.8%（bull 亦 -48%）；同一批资产在母公司 01378 上以更低估值 + 8 倍股息 + 更完整资产可得，故 exclude 而非 watch。旧档同时判定"**电解铝量已被 4,500 万吨红线钉死、无新增产能、无扩产资本开支压力**"。

**这条新闻改变了哪几个变量**：

**(a) 估值口径变量 —— 融资价 vs 内在价值，是"贵"的正面实证【本条最重要】**

定价基准日未定，按当前股价 20.77 元 × 定价下限 80% ≈ **16.6 元/股**测算【测算】：

```
发行股数 ≈ 120 亿 ÷ 16.6 元 ≈ 7.2 亿股
经济摊薄 ≈ 7.2 / 130.31 ≈ 5.5%
魏桥系持股 88.99% → 88.99% × 130.31/(130.31+7.2) ≈ 84.3%（被动稀释 -4.7pct）
发行价 / 每股期望内在价值 = 16.6 / 6.79 ≈ 2.4 倍
```

**管理层选择在市价约等于内在价值 2.4-3.0 倍的位置增发新股，而不是回购。** 这是 Buffett 回购纪律的镜像：低于内在价值时回购创造价值，高于内在价值时增发同样创造价值（对留下的老股东）。**这不是对 exclude 的反驳，而是它最锋利的旁证——公司自己用行动确认了这张 A 股股票是便宜的融资货币，而不是便宜的买入标的。** 旧档 §6"A/H 双平台定价断裂"的论点由此从"我的测算"升级为"发行人的行为证据"。

**(b) 摊薄口径陷阱：会计 0.83% ≠ 经济 5.5%【必须点破】**

公司摊薄公告给出的首年 EPS 摊薄仅 **0.83%**（1.3708 → 1.3595 元）。这个数字**不可直接理解为股东权益被稀释 0.83%**——它假设"2026 年 11 月底完成发行"，按加权平均股本只并入约 1 个月，是**首年会计口径**。永久性的经济摊薄是 **~5.5%**（若股价下跌、发行价走低，最高可至预案上限 10%）。**看到 0.83% 就认为"摊薄可忽略"是误读。**

**(c) 前提修正：旧档"量已封顶、无扩产资本开支"部分失效**

- 电解铝本身**仍封顶**（红线内、本次不含电解铝新增产能）——旧档主结论不变。
- 但公司**首次出现大额向下游/向能源侧的资本开支**：79 亿风光 + 23 亿铝深加工。旧档"无扩产资本开支压力，是分红能力的结构性支撑"这半句**被证伪**。
- **对分红的含义（负面）**：旧档已指出 002379 A 股股息率仅 0.9%、分红率 18.3%，是母公司 01378（65% / 7.28%）的八分之一，且【缺】A 股口径的高分红承诺。本次 120 亿募投（其中 18 亿直接用于**偿还银行贷款及补流**，本身是现金偏紧的信号）+ 摊薄公告的填补回报措施里**未见任何未来三年分红比例承诺**，意味着"002379 分红率向宏桥体系 60% 靠拢"这条旧档列明的重估触发条件**在可见期内更难兑现**。

**(d) 绿电项目：战略正确，但经济回报是公用事业级，不是主业级【双面核心】**

利好侧（承认）：42 号令 2026-08-01 生效 + CBAM 实质征税，绿电铝的合规与出口价值真实；宏桥云南水电铝 + 自建风光形成"水风光互补"，是产业方向上的正确动作。

风险侧（必须并列）：

```
年发电量测算【测算】：风电 1,055.25MW × ~2,200h ≈ 23 亿度
                      光伏 615MW × ~1,300h ≈ 8 亿度
                      合计 ≈ 31 亿度/年

自给率：002379 电解铝 645.9 万吨 × ~13,500 度/吨 ≈ 872 亿度/年
        31 / 872 ≈ 3.6%（若仅对云南段产能口径，亦仅约 10%）

单位造价：风电 56.5 亿 / 1,055.25MW = 5.35 元/W
          光伏 22.5 亿 / 615MW    = 3.66 元/W  （二者均高于当前行业均值，含送出/高原地形）

回报粗测：31 亿度 × 自发自用替代网电节省 ~0.10-0.15 元/度 ≈ 3-5 亿/年（税前）
          对 79 亿资本开支 ≈ 4-6% 税前回报
```

三点判读：

1. **自给率仅约 3.6%，"绿电铝转型"的叙事被自身量级证伪** —— 这不是一次能改变成本结构的转型，是一块补丁。
2. **合规成本本身极低，不构成 79 亿投资的理由**：按行业测算，50 万吨产能厂全年 11 亿度绿电缺口若全部以绿证补足，年成本仅约 660 万元，折合**约 13 元/吨铝**。相对 ~13,200 元/吨的完全成本是零头。**若目标只是满足 42 号令，买绿证就够了**——花 79 亿自建，理由只能是长期电价锁定与 CBAM（欧盟对绿证抵扣的认可度受限，实体绿电/直连更硬）下的出口资格，属于战略期权而非当期经济性。
3. **资本配置方向：从 ROE ~17% 的主业转向 4-6% 回报的类公用事业资产**，摊薄公司整体 ROIC。对一家分红率仅 18.3% 的公司，这意味着留存 + 新募的资金被投向低回报用途——Buffett 框架下这是资本配置的减分项，不是加分项。

**(e) 铝深加工 23 亿：三块里最合理的一块**

50 万吨高端铝板带 + 50 万吨高精铝合金扁锭，产品指向液冷板、复合钎焊箔。逻辑成立：铝水直供免重熔（成本优势可延伸）、加工费收入平滑纯周期波动、贴合数据中心液冷与汽车热管理需求。这是唯一实质性改善"纯周期无定价权"这一 002379 核心缺陷的动作。但：占募资仅 19%、建设期 2-3 年、且 002379 在深加工无既有品牌与客户认证积累，**属于中长期期权，当前不进任何估值口径**（旧档"蹭概念不进估值"的同一红线）。

**结论：维持 `exclude`，且本次事件是对该评级的强化而非动摇。**
- 估值：120 亿以 ~2.4 倍 IV 发行 → 每股 IV 从 6.79 元微升至约 **7.31 元**【测算：(885+120) 亿 ÷ (130.31+7.2) 亿股】，但股价 20.77 元 → 安全边际从 -66.8% 仅改善至约 **-64.8%**。**数量级不变，仍是"贵近三倍"。**
- 旧档列明的两条重估触发条件（几内亚上游资源注入 / A 股口径 60%+ 分红承诺）**一条都未触发**，其中分红条件反而更远。
- 新增监控项：定增落地进度与最终发行价（发行价越高，对老股东增厚越大、对新入场者安全边际越差）；风光项目实际造价与利用小时；深加工项目客户认证进展。
- 短期交易层面提示（非评级依据）：周五盘后公告、周一（2026-08-03）才反应。A 股对"绿电 + 液冷 + 定增扩产"三重题材常给正面情绪，但 5.5% 经济摊薄与 4-6% 项目回报是相反方向的基本面读数——情绪与基本面在此背离，**不追**。

### 2.2 中国宏桥（01378.HK）— 弱利好 / 中量级 / **强化 watch，不改评级**

**旧 thesis（2026-07-22 buffett 档，rating = `watch`）**：全球成本最低电解铝龙头，护城河真实；但 2025 年 226 亿 RMB 是周期峰值，用正确市值 ~2,250 亿 HKD 测算期望 IV ~1,425 亿 HKD（每股 14.51），安全边际 -37%，bull 亦 -6%；等跌破 ~15 HKD 或铝价企稳 $2,800+ 且中报证实盈利韧性再评。

**这条新闻改变的变量：01378 持有的 002379 权益价值（正向）**

01378 穿透持有 002379 **88.99%**。子公司增发不摊薄 01378 的自身股本，但摊薄其持股比例（→ ~84.3%）。关键在于**增发价远高于每股内在价值**，因此摊薄比例损失小于现金流入收益：

```
增发前：01378 持有的 002379 权益 IV = 88.99% × 885 亿 = 787.5 亿 RMB
增发后：84.3% × (885 + 120) 亿      = 847.2 亿 RMB
净增厚 = +59.7 亿 RMB ≈ +64 亿 HKD
占 01378 市值 2,409.7 亿 HKD（2026-07-31 收盘 24.54 HKD）≈ +2.7%
```

**这是本档给 01378 的新论点**：**A 股平台的高估值，此前只是"别买 002379"的理由（旧档 §6 的对照物）；这次它第一次转化为 01378 股东的一项实际资产——一台能以约 2.4 倍内在价值向外部投资者出售子公司股权、换回等额现金的融资机器。** 只要 A/H 断裂持续存在（旧档已论证它是制度性的、可长期不收敛），这台机器就一直可用。

**双面（必答）**：

- 反向侧一：**增厚依赖"120 亿现金按面值创造价值"这一假设**。若 79 亿绿电项目的实际回报只有 4-6%（§2.1(d)），低于资本成本，则这部分投出去的钱会低于账面价值，增厚打折。悲观情形下（募投整体价值毁灭 20%）净增厚降至约 +43 亿 RMB，仍为正——因为发行溢价太厚（2.4x IV），结论对该假设**不敏感**。
- 反向侧二：**look-through 权益产量下降**。01378 对应的 002379 电解铝权益产能从 574.8 万吨（645.9×88.99%）降至 544.5 万吨（-5.3%），在铝价 bull 情景下少分享的弹性更大。这与增厚不冲突——它正是"用未来的周期弹性换今天的确定现金"的对价，是一笔在周期顶部做的交易，方向正确。
- 反向侧三：**治理提示**。这笔交易的经济实质是"母公司通过在被高估的子公司平台增发，让外部 A 股投资者出资"。对 01378 股东有利，对 A 股新入股东不利。旧档已把"关联交易转移定价 + 少数股东保护弱"列为 002379 的治理折价来源——本次事件是同一治理结构在**另一个维度**的表现，进一步支持"两个平台不对等"的判断。

**结论：维持 `watch`，评级不动。**
- +2.7% 的增厚远不足以填补 -37% 的安全边际缺口。买入阈值维持 **~15 HKD**（观察区）/ **~10-12 HKD**（建仓区）。
- 但它**微幅上调了 01378 相对 002379 的优先级**——在"想配这批资产该选哪个平台"的问题上，01378 现在不仅更便宜、股息更高、资产更完整，还是这次融资溢价的净收益方。
- 需要跟踪：定增最终发行价与发行规模（决定增厚的真实量级）；01378 是否通过魏桥铝电部分参与认购（**若控股股东自己认购，则不存在外部溢价流入，本节增厚论点整体失效**——现有公开表述为"引入社会资本"，属【软】证，待正式发行方案确认）。

## 3. 操作含义

1. **这是公司事件，不是板块事件。** 池内 20 只候选中 18 只判低/无传导。任何把它包装成"铝板块利好""绿电/液冷/光伏风电利好"的解读都不成立——最有力的反证是自给率仅 3.6%、光伏采购量仅全国年装机 0.2%。
