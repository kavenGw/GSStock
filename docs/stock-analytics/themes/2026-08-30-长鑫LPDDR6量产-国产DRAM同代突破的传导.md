## 2. 逐标的传导分析（仅中量级以上展开）

### 长鑫科技（688825）— 利好 / 中 / 动摇（仅质地侧）

- **旧 thesis（2026-07-27）**：全球第四大 DRAM 原厂是真的，但 3.28 万亿首日定价隐含永续归母 ~2,400 亿；批判的核心论据之一是"DUV-only、制程落后 2~3 代、无 HBM 业绩"的**商品型周期股**属性。
- **改变了哪个变量**：改的是**质地侧的技术追赶判据**，不是估值侧。LPDDR6 是 JEDEC 新一代标准，长鑫在此代上**与三大原厂进入同一时间窗**——这是旧档"落后 2~3 代"表述第一次被具体产品打了折扣（注意：先进制程与产品代际是两件事，DUV-only 的制程约束依旧成立，长鑫走的是用成熟 DUV 做新标准产品的路线）。
- **双面**：利好侧——高端移动 DRAM 意味着产品结构与 ASP 中枢上移，脱离纯 legacy 商品定价；风险侧——① 无产能/良率/出货披露，DUV 多重曝光路线的成本与良率代价未知，"能做出来"≠"能挣钱地做"；② 首发客户是关联度极高的小米生态，独立客户验证尚未发生；③ 此事件**完全不触及** 3.28 万亿的定价批判——期望内在价值 5.79 元、安全边际 −88.2% 一分未动。
- **结论**：维持 **watch**，买点区间（2,150~2,800 亿市值）不变。这是"生意更好了一点、价格一点没变"的典型事件；本档不重估，若要把技术追赶折进正常化利润中枢，须转模式 1 承做。

### 小米集团-W（01810）— 利好 / 中 / 动摇

- **旧 thesis（2026-08-18）**：三条腿同时承压，其中第一条明确写着"**存储成本高位至 2027**"；期望内在价值 20.03 HKD，安全边际 −23.5%。
- **改变了哪个变量**：**成本端 + 供应链议价权**。玄戒 O3 首家适配长鑫 LPDDR6，等于在三星/SK/美光之外拿到第四个可谈判的移动 DRAM 供给源，且是自研 SoC 层面的深度适配（切换成本已由对方承担）。这是三条承压腿里第一条出现结构性缓解路径的。
- **双面**：利好侧——议价筹码 + 潜在 BOM 成本下行 + "自研 SoC × 国产内存"的垂直协同叙事对高端化有正向作用；风险侧——① 首发仅一款折叠旗舰（18 Fold 出货量级小），对整体 BOM 的量化影响在 2026 年内**接近噪音**；② 旧档的核心症结是手机分部毛利率 8.5%、汽车分部仍亏，存储成本只是其一，单点缓解不解决"以量换价失败"；③ 首发本身有承担新供应商良率风险的成本。
- **结论**：维持 **watch**，翻牌条件不变（手机分部毛利率回 10%+ 且汽车单季经营转正）。但**记一条正向观察项**：2026Q4~2027Q1 财报若见手机毛利率改善且管理层归因存储成本，即为本事件的业绩层验证点。

### 兆易创新（603986）— 中性偏多 / 中 / 无关（不改评级）

- **旧 thesis（2026-08-19）**：暴利是三巨头让渡的租金而非护城河，利基 DRAM 份额 1.7% 且**天花板是长鑫代工配额**；长鑫持股 642.61 亿走 OCI 永不进利润表；安全边际 −82.7%。
- **改变了哪个变量**：**同时拨动两端，方向相反**。① 资产端：长鑫的技术地位与长期估值锚被强化 → 642.61 亿 OCI 持股边际增值——但旧档已明确这部分**永不进利润表、锁定期未明**，对 DCF/PE 口径的内在价值贡献仍是折价 SOTP，增量有限；② 经营端：长鑫把产能与研发资源投向高 ASP 的移动 LPDDR6，**结构上不利于**兆易 legacy 利基 DRAM 的代工配额优先级——这正是旧 thesis 点名的天花板变量，方向是收紧而非放松。
- **双面**：市场极易把此事件读成"长鑫链纯利好 → 兆易持股增值"的单边叙事；本档明确反对——**产品结构上移的原厂，对其 legacy 代工客户是竞争性挤压而非提携**。
- **结论**：维持 **watch**，安全边际 −82.7% 与买点（市值跌破 320 亿）不变。若因该事件出现情绪性上涨，属于**强化不买理由**而非削弱。

### 深科技（000021）— 利好 / 中 / 强化 watch

- **旧 thesis（2026-06-08）**：HBM 量产 + 英伟达认证 + **长鑫扩产**使其从周期型封测代工升级为 AI 存储供应链核心节点；但 PE 50x 已部分定价、ROE 8.67% 偏低、安全边际不足。
- **改变了哪个变量**：把 thesis 里的"长鑫扩产"（量的变量）升级为"**长鑫产品结构上移**"（价的变量）。LPDDR6 封测复杂度高于 legacy DDR4，单位价值量与工艺门槛均向上，对国内配套封测厂是结构性利好，且与其 HBM 线的技术积累同源。
- **双面**：利好侧——量价双升的配套逻辑更完整；风险侧——① 未见长鑫 LPDDR6 封测由深科技承接的公开证据，传导为**推断而非确认**（置信度中）；② 封测始终是"吃加工费"生意，原厂产品升级的租金分配比例由原厂决定；③ 旧档的估值症结（PE 50x、ROE 8.67%）一点未改。
- **结论**：维持 **watch**，thesis 强化但不构成买点触发。承接证据（长鑫封测订单披露/客户结构）是后续应重点跟踪的确认点。

### 无影响 / 弱传导归并

- **澜起科技、聚辰股份**：产品分别是服务器内存接口芯片与内存条 SPD，手机 LPDDR 直连 SoC、无内存条与接口件形态，**结构上不存在传导路径**——不硬凑。
- **太极实业**：SK 海力士 DRAM 封测合资，属韩系链，长鑫产品迭代不改其订单。
- **东芯股份**：SLC NAND 利基赛道，与 LPDDR 无交集。
- **佰维存储、江波龙**：模组商长期受益于国产颗粒供给多元化，但 LPDDR6 早期产能全部指向旗舰机原厂直供，模组环节不参与；且旧档症结（周期 β 顺价、非产品 α）不变。
- **汇成股份（exclude）**：鑫丰联营对应的是长鑫 **DDR5** 封测期权，与 LPDDR6 非同一产品线；294x PE / 安全边际 −88% 的 exclude 理由不受本事件影响，**不重看**。
- **君正股份**：66.5% 营收为利基 DRAM/SRAM/NOR，与兆易同源逻辑但敞口更分散，量级更低。
- **SK 海力士 / 三星电子**：单一产品量产不改移动 DRAM 三寡头格局（合计份额 >90%），但作为"国产替代长期挤出"的**证据累积项**记一笔——与 2026-08-02 韩国出口档中"国产尚未形成挤出"的反向证据形成对冲，方向上有利于挤出论。
- **北方华创 / 神工股份 / 有研硅 / 雅克科技 / 通富微电 / 甬矽电子 / 赛腾股份**：设备材料与封测受益于**扩产资本开支**，本事件是产品迭代而非新增产能公告，无增量。
- **瑞芯微 / 富瀚微**：端侧 SoC 厂受益于内存供给多元化的情绪层利好，无业绩传导。

## 3. 操作含义

1. **无一只标的评级需要变更。** 四只中量级标的（长鑫、小米、兆易、深科技）全部维持 watch，买点/翻牌条件不动。
2. **这是质地事件不是价格事件。** 长鑫的技术判据被上修，但 −88.2% 的安全边际决定了操作结论不变；把"技术突破"读成"可以买"是本轮最容易犯的错。
3. **反单边叙事提醒**：市场会把"长鑫链"打包炒作。本档的独立判断是——长鑫产品结构上移对 **兆易（代工配额被挤压）** 是竞争性利空的一面被普遍忽略；若兆易/汇成因该消息情绪性拉升，属于强化不买理由。
4. **后续确认点（按优先级）**：① 小米 18 Fold 9 月上市后的第三方拆解与长鑫份额；② 长鑫 LPDDR6 的产能/良率/独立客户（小米之外）披露；③ 深科技封测承接的公开证据；④ 小米 2026Q4~2027Q1 手机分部毛利率与存储成本归因。
5. **若要重估长鑫本体**（把技术追赶折进正常化利润中枢与合理倍数），须转 **模式 1** 承做，本档不产估值数字。
