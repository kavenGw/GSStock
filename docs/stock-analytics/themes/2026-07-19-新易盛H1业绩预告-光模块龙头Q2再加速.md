## 2. 逐标的传导分析（仅中量级以上展开）

### 新易盛（300502）— 利好(超预期+反驳见顶)/高

- **旧 thesis（buffett 档 2026-07-02，rating=watch）**：全球第二光模块龙头，LPO 去 DSP + 硅光自研 + 光芯片 65% 自给 + 垂直整合构筑系统性高旭创 6-7pct 的高毛利护城河，AI 800G/1.6T 业绩已硬兑现（2025 归母 95 亿）；**但 PB 98.7% 分位（历史天花板）/ PE(TTM) 66，期望内在价值约 121 元/股、安全边际约 −76.2%（bull 压测仍 −59.9%）**。旧档三条 inversion 路径之首、§8 看空信号之首均是 **"2026Q1 归母环比 −13.25%（九季首次）+ 毛利回落 = 增速与毛利双见顶信号"**——这是把它按"成长全额定价"的最危险裂缝。
- **这条新闻改变了哪个变量**：改的是**业绩兑现证据（分子端）**，且恰好打在旧档最脆弱的那条空头线上：
  - **利好侧（分子端确认 + 反驳见顶）**：H1 +78-103% 拆出 Q2 归母 42-52 亿、**环比 Q1 +52-88%**——若属实，则旧档反复强调的"Q1 环比 −13.25% = 九季首次单季下滑 = 增速见顶"被证伪为**季节性扰动**，Q2 强势反弹坐实 1.6T 放量节奏；且该区间超 Q2 一致预期(36.33 亿)，属正向 surprise。旧档 §9 Bull 门控三要素里"(b) 客户 capex 能见度不足"得到部分补强（终端 CSP capex 兑现为出货）。
  - **偏空侧 / 不改的部分（分母端）**：**watch 的理由从来不在分子（业绩早已硬兑现 95 亿），而在分母**——PB 98.7% 分位、安全边际 −76.2%。即便按 H1 70-80 亿年化（约 140-160 亿），也远超旧档明确拒绝采用的"顶部年化"，估值只会更贵不会更便宜；旧档纪律明写"业绩已兑现 ≠ 价格合理，未兑现的年化利润不进 owner earnings 基础"。因此**估值透支结论不动**。
- **是否改质地/估值**：**不改**。Q2 再加速属"既有场景内的分子端确认"，未拓宽护城河宽窄或抬升穿越周期可持续利润中枢（旧档 Base 70 亿 / Bull 95 亿 的正常化口径不因单期峰值改动）；不触发 valuations.yaml 的 quality 覆写（**quality=4 维持**）。真正的估值锚仍是 PB 98.7% 分位。此事仅令旧档场景加权里 **Bear 情景（AI capex 见顶 + Q1 见顶坐实）的权重边际微降**，Base/Bull 假设已含 1.6T 放量、不上修。
- **结论**：**维持 watch，评级不动。** 这份预告把旧档最强空头论据（Q1 环比下滑=见顶）大概率证伪，是"好生意"叙事的又一次分子端硬确认，也降低了 bull 兑现难度——**但它不改变分母端 −76% 的安全边际黑洞**。升 config 需要**价格回调**而非利润上修；降 exclude 更无从谈起（基本面无瑕疵、护城河未毁）。买点阈值仍参照旧档：理想买区 ≤85-90 元/股、更可操作的"重新认真评估"触发线约 200-230 元/股且需 1.6T 放量 + 毛利维持 42%+ + 单季环比重回增长三条件同时具备——**本次预告恰好点亮了"单季环比重回增长"这一条**，但价格条件仍完全不满足。**新增观察项**：① 官方公告 / 8-25 半年报确认 +78-103% 与超预期属实；② Q2 毛利率是否守住 42%+（旧档另一见顶信号是毛利从 47.8% 回落至 43%，本次预告未含毛利口径，需待正式财报）；③ 存货 90 亿 + 关键审计事项在放量兑现下是否消化。
