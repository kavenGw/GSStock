> 撰写日期：2026-07-13
> 触发事件：北京君正（300223）公告预计 2026 半年度归母净利润 **10.79-12.82 亿元**，同比 **+431.03%~531.34%**；扣非 **10.49-12.53 亿**（+551.97%~678.58%）；H1 营收约 **39.89 亿**（+77%）。归因：存储大周期（DRAM 供应紧张、售价大涨；Flash 受益 AI 服务器/光模块销量增长）+ 计算芯片因 KGD 缺货涨价而调价。
> 目的：评估该事件对 docs 池内存储链旧 thesis 的影响。

## 0. 事件核实

**数字自洽、口径与公司近期披露一致，置信度高（唯预告未经审计）。**

- **预告本体**：为公司自身公告、今日新发，暂未检索到第三方独立复述（正常时滞）。**但内部自洽性可硬校验**：26Q1 已披露归母 3.19 亿（+331.61%）、营收 15.60 亿（+47.12%）→ H1 若达 10.79-12.82 亿，则 **Q2 单季归母 7.60-9.63 亿，环比 Q1 再 +138%~+202%**；H1 营收 39.89 亿 → Q2 单季 24.29 亿，环比 +56%。**利润环比增速远超营收环比增速 = 毛利率再度跃升 + 费用刚性的经营杠杆**，与公司 7-01 IR 调研原话"存储芯片持续涨价，预计各季度毛利率会环比有所增长"（Q1 综合毛利率已近 52%）**完全吻合**。
- **基数校验**：+431.03%~531.34% 反推 2025H1 归母 ≈ 2.03 亿 ✓（与招股书"2025H1 净利 2.02 亿"一致）。扣非增速（+551.97%~678.58%）高于归母增速，且非经常性损益仅 2950 万（上年同期 4220 万，**同比下降**）→ **利润全部来自主业，无一次性收益粉饰**，含金量口径上是干净的。
- **行业背景已核实**：2Q26 常规 DRAM 合约价 QoQ +58~63%、NOR 1H26 累计 +100~120%（TrendForce）；利基 DRAM（DDR3/DDR4）是本轮最紧一环，正是君正主业。

**唯一但关键的增量反面事实（本档核心）**：**3Q26 涨价开始收敛。** TrendForce 7-09：3Q26 server DRAM 合约价预计仅 **+13~18% QoQ**（vs 2Q26 的 +58~63%），原因是**美系 CSP 多年期 LTA 锁价 + 买方价格承受力见顶**，而非供给改善。即：**价格一阶导仍为正，二阶导已转负。**

**关键判断（先写结论）**：这条新闻**不改变池内任何标的的旧评级**，但它带来一个比"又一次 windfall 确认"重要得多的观测——

> **同样是超预期的 H1 预告，7-03 江波龙发布时君正当日 +10.6%、板块狂欢；7-13 君正自己发布时，君正 -13.52%、兆易/深科技/太极/德明利集体跌停、普冉 -14.22%、江波龙 -11.16%。**
>
> **市场对存储股的定价，已从"贴现周期利润"切换到"贴现周期拐点"。** 基本面兑现的顶点，成了股价定价范式切换的起点。这恰恰是 6-21 君正 exclude 档写下的那句话被实时验证：*"周期股业绩最好、价格最亢奋时，往往是股价最危险时。"*

## 2. 逐标的传导分析（仅中量级以上展开）

### 北京君正（300223）— 利好 / 高（主体）

**旧 thesis（buffett 2026-06-21, exclude）**：ISSI 车规利基存储是真护城河（SRAM 全球 #2/车规 #1）、本轮存储上行真实，但主体仍是强周期 commodity；三情景加权期望内在价值 **138.39 亿** vs 市值 899.86 亿，**安全边际 -85%**，bull 100% 兑现压测仍 -72%。旧档 §12 明列局限 1：**"26H1 业绩预告未披露（截至 6/21），研报'H1 累计 7.2-8.5 亿'无硬源。"**

**新闻改变的变量（三条，全部是对旧档的实质检验）**：

1. **局限 1 被填上，且方向对多头有利**：H1 实际 **10.79-12.82 亿**，**超过旧档所引研报预测上限（7.2-8.5 亿）26%~51%**。这不是"符合预期"，是**超过最乐观一方的预期**。旧档对多头研报的诸多证伪（50 亿利润、PE 12-14x）依然成立，但必须诚实承认：**在利润兑现这一维度上，旧档偏保守了。**
2. **利润质量是干净的**：扣非增速 > 归母增速，非经常性损益 2950 万反而同比下降。旧档 §3.4 的"含金量隐忧"（26Q1 OCF/净利 0.68、应收 +36.7%）**未被本预告证伪也未被确认**——预告不含现金流/应收数据，**8 月中报仍是关键验证窗口，此条监控项保留**。
3. **KGD 缺货 → 计算芯片被动调价，是护城河的反向注脚**：公告明言计算芯片"因原材料 KGD 缺货涨价而调价"。这与 5-28 IR 档记录的"KGD 缺货被迫分货、无法保证所有客户需求"一脉相承。**这是成本推动型涨价，不是定价权驱动的涨价**——君正把上游涨价转嫁下去了，说明短期供需极紧；但它同时暴露君正在 KGD 上的**上游依赖**，坐实旧档 §5"切换成本 ≠ 锁价权"的判断。**利好里藏着结构性软肋。**

**双面看**：
- **利好侧**：设计端 windfall 兑现程度超越所有多头预期；营收 +77%、Q2 环比 +56%，量价齐升是真的；Flash 打入 AI 服务器/光模块是**新的需求侧敞口**（旧档未计入）。
- **风险侧（更具决定性）**：① **3Q26 涨幅收敛**（server DRAM +13~18% vs Q2 +58~63%）——旧档 §8"供给紧张度临近超级周期峰值"的判断被**一手数据确认**，二阶导已转负；② 君正毛利率已近 52%（十年新高之上再新高），**均值回归的位能只增不减**；③ **股价的反应本身是最强的风险信号**：超预期利好当日 **-13.52%**。

**估值刷新（实时行情锚，2026-07-13，腾讯 qt.gtimg.cn/q=sz300223）**：股价 **190.17 元**（当日 **-13.52%**）/ 市值 **919.78 亿** / PE-TTM **148.04x** / PB **7.26**。
- 相对 6-21 档（186.05 元 / 899.86 亿）**仅 +2.2%**——但期间曾冲高至 PE-TTM 202x（约 250 元 / 1250 亿，见 7-03 江波龙档记录），**当前已从高点回落约 25%**。
- 按旧档期望内在价值 138.39 亿计：**安全边际 = (138.39 − 919.78) / 919.78 = −84.95% ≈ −85%**，与旧档纹丝不动。

**【关键】用新硬数字做激进上修压力测试（本档最有价值的裁决）**：

诚实起见——H1 硬数字（10.79-12.82 亿）已**超过旧档 bull 情景的全年正常化中枢（14 亿）的 3/4**，说明本轮周期顶的绝对高度高于旧档隐含预设。若把这一事实**尽可能激进地**灌进三档正常化中枢（远超本 skill 职权范围的上修，纯为压力测试）：

| 情景 | 概率 | 旧档正常化归母 | **激进上修后** | 倍数 | 内在价值 |
|---|---|---|---|---|---|
| Bear | 30% | 5.5 亿 | **7 亿**（周期底被 HBM 挤出+KGD 紧缺结构性抬高） | 11x | 77 亿 |
| Base | 48% | 9 亿 | **12 亿**（+33%） | 15x | 180 亿 |
| Bull | 22% | 14 亿 | **20 亿**（+43%） | 18x | 360 亿 |

- 期望内在价值 = 77×0.30 + 180×0.48 + 360×0.22 = 23.1 + 86.4 + 79.2 = **188.7 亿**
- **安全边际 = (188.7 − 919.78) / 919.78 = −79.5%**
- **Bull 100% 兑现压测** = (360 − 919.78) / 919.78 = **−60.9%**

> **即便把三档正常化中枢全面上修 27~43%（一个远比旧档慷慨、也慷慨于任何一致预期的假设），安全边际仍是 −79.5%，最乐观情景压测仍 −61%。没有任何一档能让 920 亿市值落入安全边际。**

**结论**：**维持 exclude，且论证基座比 6-21 档更硬——因为旧档最大的已知局限（H1 未披露）现在以"对多头有利"的方式被填上了，结论依然不变。** 这正是一个稳健结论该有的样子：**它在最不利于自己的新证据下依然成立。**

**买点阈值上修（本次实质产出）**：期望内在价值由 138 亿上修至（激进口径）~189 亿 → 合理买入市值 = 189 × 60-70% ≈ **113-132 亿**，对应 **23-27 元/股**（旧档为 83-97 亿 / 17-20 元）。**距现价 190.17 元 仍有约 7 倍距离。**

**质地星级**：**不动。** KGD 依赖暴露的是上游软肋（护城河的反向证据），周期 β 本质未变；windfall 是价格事件不是质地事件。按 skill 铁律，纯周期/价格变动不动 `quality`。

## 3. 操作含义

1. **无一只标的因本新闻升级评级。** 池内存储链 8 只有档标的（君正/兆易/普冉/东芯/江波龙/佰维/深科技/太极）评级**全部维持**。本新闻验证的是"周期弹性与兑现度"，不是"内在价值"。

2. **本次的增量不是"又一次 windfall"，而是市场定价范式的切换——这是本档与 7-03 江波龙档的根本区别。**
   - 7-03（江波龙 H1 超预期）：**利好兑现于股价**，板块大涨，君正当日 +10.6%。结论是"追涨陷阱"。
   - 7-13（君正 H1 超预期）：**利好兑现，股价崩塌**。君正 -13.52%、兆易/深科技/太极/德明利跌停、普冉 -14.22%。
   - **同样的超预期，相反的股价反应。市场已从贴现"周期利润"切换到贴现"周期拐点"。** 对纪律派而言，这是等待多时的信号——**但它是"开始"不是"结束"**：从 PE 148x/PB 7.3（君正）、PB 33x（普冉）到有安全边际的位置，距离仍以**倍数**计，不以百分比计。

3. **杀跌的真因必须与基本面拐点严格区分（否则会误判买点）。** 已核实：本轮存储股杀跌主因是 ① **SK 海力士 ADR 上市引发的跨市场套利**（外资卖韩股正股、买美股 ADR，外资连续 13 日净卖韩股，UBS 7-07 明确建议"买 ADR 卖韩股"）；② **Meta 出售算力**动摇"AI 基建可持续性"叙事；③ 半年涨 8 倍后的高位获利了结踩踏（始于 7-02）。**这些是资金面/叙事面事件，不是供需拐点**——TrendForce 口径下 3Q26 DRAM 仍"极度紧缺"，只是涨幅收敛（+13~18%）。
   **含义**：**不要把技术性杀跌当成"周期已见顶"，也不要把它当成"错杀该抄底"。** 前者会让你在 2027 年真正的下行期毫无防备，后者会让你在 PE 148x 上接刀。**两个错误都要避开——这正是 exclude/watch 的价值。**

4. **真正的领先指标已经转向，盯住它。** 3Q26 server DRAM 合约涨幅 **+13~18%（vs Q2 +58~63%）** = **价格二阶导首次转负**，且原因是**买方抗拒 + LTA 锁价**（需求侧），不是供给改善。历史上周期股股价见顶**从不等一阶导转负**——**它对二阶导定价**。这条数据与今日板块跌停在时间上高度重合，绝非巧合。
   **监控**：4Q26 合约价指引（若继续收敛至个位数 → 一阶导转负在望）、原厂库存周数（当前 3.3 周）、买方 LTA 覆盖比例。

5. **君正专属跟踪项（沿用 6-21 档卖出触发器，按新数据收紧）**：
   - **8 月中报是关键窗口**：本预告**未含现金流/应收数据**，旧档的含金量红线（26Q1 OCF/净利 0.68、应收环比 +36.7% > 营收环比 1.87x）**未被证伪也未被确认**。中报若确认应收增速持续 > 营收增速 1.5x → 渠道压货坐实。
   - 存储毛利率较 38.89% 峰值回落 > 4ppt → 涨价见顶早期信号。
   - 商誉 30.08 亿（占总资产 21.7%）减值预告 → 立刻清仓（持仓者）。
   - **PE-TTM 148x ≫ 50x 清仓线 → 持仓者仍深在清仓区**，今日 -13.52% 不改变这一点。
   - H 股 IPO 进展与 AH 折价（二次递表进行中）。

6. **质地排序参考（非买点，供周期回落后按图索骥）**：池内存储链质地优先级 = **深科技 ≈ 太极（真供应链节点，有实体卡位）> 兆易（利基龙头 + GD32 MCU 护城河）> 君正（车规利基护城河真实但窄，KGD 上游依赖是软肋）> 佰维 > 江波龙（纯模组顺价）> 普冉（PB 33x，最贵）> 东芯（最弱环节）**。**若本轮杀跌延续至给出安全边际，按此序观察——但没有一只已到买点。**
